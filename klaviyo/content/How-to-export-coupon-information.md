## You will learn

Learn how to export information about Klaviyo-generated and uploaded coupons, so that you can report on your coupons with the data directly from Klaviyo.

- For Klaviyo-generated coupons, you can determine which customer a code was sent to, coupon name, sent date, and more.
- For uploaded coupons, the export includes details about which codes are assigned versus unassigned.

## Export Klaviyo-generated coupon (integration-specific) information

For Klaviyo-generated (integration-specific) coupons you can only export information for previously assigned coupon codes that may be active or expired. Unassigned coupons cannot be exported.

1. Navigate to ****Content >**** ****Coupons**** in Klaviyo's left-hand navigation.
2. Find your coupon and click the 3 dots next to it.
3. From the dropdown, select ****View History****.
   ![](https://klaviyo.zendesk.com/hc/article_attachments/38522581535771)
4. On the coupons history page, select which versions of the coupon definitions you'd like to export.

   Note that any coupon versions created before August 26, 2020 will show as “unknown,” as coupon information before this point was not logged.

   ![A coupon selected under Coupon Definiton on the Coupon History page.](https://klaviyo.zendesk.com/hc/article_attachments/28717382279579)
5. Once you have selected the definitions, click ****Export**** at the bottom of the page.
6. From the **Export Coupon Report** modal that appears, select whether you want to export:
   - Active and expired codes (the default)
   - Active codes only
   - Expired codes only
7. Select ****Export Coupon Report****.
   ![The Export Coupon Report modal showing the option set to include active and expired codes](https://klaviyo.zendesk.com/hc/article_attachments/34401817519899)

The exported CSV file will show all of the coupon codes from your selected definitions. In addition, the following information will be shown for each code:

- Unique code (if applicable)
- Customer email
- Klaviyo profile ID
- Klaviyo coupon ID
- Coupon name
- Assigned date (when it was sent)
- Expiration date
- Code status
- Coupon definition
- Definition start date
- Definition end date

## Export uploaded coupon information

1. Navigate to ****Content > Coupons**** in Klaviyo's left-hand navigation.
2. Toggle to ****Uploaded Coupons.
   ![The Uploaded Coupons tab selected on the Coupons page.](https://klaviyo.zendesk.com/hc/article_attachments/28717382275739)****
3. Find your coupon and click the 3 dots next to it.
4. Click ****Export****.
   ![](https://klaviyo.zendesk.com/hc/article_attachments/38522581540507)
5. On the **Export Code Report** modal that appears, select whether you want to export:
   - Active and expired codes (the default)
   - Active codes only
   - Expired codes only
6. Choose whether you want to include:
   - Sent codes
   - Available codes
   - All codes
7. Click ****Export Coupon Report****.
8. ![The Export Coupon Report modal showing the options to include Active and expired codes and Sent codes selected](https://klaviyo.zendesk.com/hc/article_attachments/34401817519899)

The resulting CSV file will show both unassigned and assigned codes, and will include the following columns:

- Unique code
- Email
- Klaviyo profile ID
- Klaviyo coupon ID
- Current coupon name
- Assigned date
- Expiration date
- Code status
- Coupon definition
- Definition start
- Definition end
