## You will learn

Learn how to port an SMS sending number into Klaviyo.

## Before you begin

Please note that porting:

- Can take around 4 weeks. When migrating to Klaviyo, please build in time for this process.
- Will result in the loss of any voice capabilities.
- Requires up to ~2–5 business days of downtime when the number cannot be used (due to verification and carriers needing to re-route traffic to the number).

****Types of numbers that can be ported****

|  |  |
| --- | --- |
| ****Type of number**** | ****Can it be ported?**** |
| Toll-free | Yes |
| Short code | Yes |
| Shared short code | No |
| Branded sender ID | No, but you can set the ID to be the same as your previous one |
| Long code | Yes in the UK, Ireland, and Australia |

## Port a toll-free number

1. Navigate to ****Settings****.
2. Click ****SMS****.
   ![SMS_sender_information.jpeg](https://klaviyo.zendesk.com/hc/article_attachments/28720772629019)
3. Click into the ****Request Additional Numbers**** dropdown.
4. Select ****Port an Existing Number****.
5. Click ****Submit Port Request****.

![Modal to submit a port request](https://klaviyo.zendesk.com/hc/article_attachments/28720760831131)

## Port a short code

1. Navigate to ****Settings****.
2. Click ****SMS****.
3. Click ****Activate**** for the country your short code is for (e.g., if you have a US short code, click ****Activate**** where "United States" is the supported region).
4. Select ****Short Code**** from the list of numbers.
5. Click ****Complete Order**** to access the application.

## Outcome

After you submit your port request, you can expect to be contacted by a Klaviyo representative. After someone reaches out and you submit all required information, the porting process begins:

- For long codes, porting can take 2 to 4 weeks to complete.
- For toll-free numbers, porting can take 2 to 4 weeks to complete.
- For short codes, porting can take 4 weeks to complete.
