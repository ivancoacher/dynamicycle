## You will learn

Learn how to group your SMS subscribers by their country.

## Why segment SMS subscribers by country?

When your SMS program stretches [across multiple countries](https://help.klaviyo.com/hc/en-us/articles/23740503987099), you run into differences in language, compliance laws, [quiet hours](https://help.klaviyo.com/hc/en-us/articles/4408737146651), and more.

To better target SMS subscribers in a certain country, you can create location-based segments. While there are a few different ways to accomplish, the best approach is to use country code for the phone number.

## Create SMS segments using a number's country code

1. Navigate to ****Audience >**** ****Lists & segments****.
2. Click ****Create New > Create segment****.
3. Include the condition:
   **If someone can or cannot receive marketing > can receive > SMS marketing**
4. Add the country for this segment with the condition:
   **Properties about someone > Phone number > country code in**. In the below example, we use Canada.
   ![SMS country segment.jpg](https://klaviyo.zendesk.com/hc/article_attachments/28717993530139)
5. Repeat step 1–4 for every country where you have SMS subscribers.
