Only portfolio Owners can add or delete users.

## You will learn

Learn how to add or remove users from a portfolio.

This article is specific to [portfolios](https://help.klaviyo.com/hc/en-us/articles/24656917054747). If you need to add or remove users for a regular Klaviyo account, check out this [article on adding or deleting account users](https://help.klaviyo.com/hc/en-us/articles/360053547071).

## Before you begin

Before making any changes to your portfolio users, know that:

- Adding or removing users from the portfolio does not add or remove them from any linked account.
- Portfolio users may have access to data for every linked account.

For details on the differences between roles, check out our article on [portfolio user permissions](https://help.klaviyo.com/hc/en-us/articles/25181702319643).

## Add portfolio users

1. Make sure you’re logged in to your portfolio account.
2. Navigate to ****Manage > Users****.
   ![Users tab within a portfolio navigation menu](https://klaviyo.zendesk.com/hc/article_attachments/28718023072155)
3. In the ****Portfolio**** tab, click ****Add new user****.
   ![The User's tab in a portfolio, showing the button to add a new user](https://klaviyo.zendesk.com/hc/article_attachments/28717995271195)
4. In the modal that appears, enter the email address for the user you want to add.
5. Open the dropdown and select the user’s role.
6. Click ****Save****.

After you save this change, an email is sent to this user and invites them to join the portfolio.

The user must accept the invitation and then either create an account (if they are not a Klaviyo user already) or log in. Until they do, they will show as **Pending** in the portfolio.

If the user declines the invitation, they will not be added to the portfolio.

## Remove portfolio users

Note that you cannot delete the portfolio Owner. Learn how to [transfer portfolio ownership](https://help.klaviyo.com/hc/en-us/articles/25185303538587) instead.

1. Make sure you’re logged in to your portfolio account.
2. Navigate to ****Manage > Users****.
3. Click the 3 dot menu next to the user you want to delete.
   ![Delete user option in a portfolio's Users tab](https://klaviyo.zendesk.com/hc/article_attachments/28718023077915)
4. Select ****Delete****.
5. Confirm you want to remove the user from the portfolio by clicking ****Delete****.
