Learn how to set up a flow to send in multiple languages, depending on the language preferences of your audience. Klaviyo can translate email content to 60+ languages.

Localizing flows is great if you have or plan to expand to an international customer base. Sending emails in each subscriber’s preferred language allows you to reach a wider audience which can increase overall engagement.

## Before you begin

Enable Smart Translations from your [account settings](https://help.klaviyo.com/hc/en-us/articles/38068161225243).

If you haven’t already, learn the basics of [getting started with flows](https://help.klaviyo.com/hc/en-us/articles/115002774932). This article mainly covers translation features for flows.

![](https://fast.wistia.com/embed/medias/6tof0fhtzo/swatch)

## Translate a flow

Make sure your email is fully edited and ready to send in your original language before translating. Otherwise, you’ll have to go through the translation process again if you make edits to the original content.

1. Create a flow or edit an existing flow.
2. Click on an email you want to translate.
3. In the **Template** section of the sidebar, click ****Edit****.
4. In the editor, click ****Translate**** in the top right.
5. Choose the **Written in** language that the content was originally created in.
6. Select what languages you want to translate your content into by checking the box next to each language. This section will include any languages you chose in your translation settings.
7. If desired, click the dropdown under **Additional languages** to view and select languages that aren’t recommended.
8. If desired, choose a **Fallback language** for when a customer’s preferred language is unavailable. This can be different from the original language.
9. Click ****Translate****.
   ![](https://klaviyo.zendesk.com/hc/article_attachments/38070375173147)
10. On the next step, review all the email elements that will be translated. You can manually edit any of these elements if needed. You can also click the edit button next to listed images to change them to ones appropriate for the selected language.
11. Click the edit button next to a listed text block to review and edit the full text.
    ![](https://klaviyo.zendesk.com/hc/article_attachments/38070360254107)
12. If you selected multiple languages to translate into, click the arrows at the top or use the dropdown to switch between languages.
    ![](https://klaviyo.zendesk.com/hc/article_attachments/38070360254875)
13. If you want to add more languages or remove the currently selected language, click the name of the language.
    ![](https://klaviyo.zendesk.com/hc/article_attachments/38070375176987)
14. Once you’re done, click ****Save****.

## Editing original content after translating

If you edit the original content of the email after you’ve already translated, a warning will appear at the top of the editor notifying you that your edits will affect translation.

![](https://klaviyo.zendesk.com/hc/article_attachments/38070360260379)

To correct any potential translation errors:

1. Click ****Review translations**** next to the warning message.
2. Click ****Update translation**** to update all out-of-sync blocks which are highlighted in yellow.
   ![](https://klaviyo.zendesk.com/hc/article_attachments/38070360260763)
3. To individually edit an element, click the pencil icon and choose from the following:
   1. ****Re-translate**** - translates any changed text
   2. ****Match source**** - matches image or URL to the original source

- ****Edit - manually modify the element****
- ****Ignore**** - keep element as is

## See which messages are translated

In the flow canvas, you’ll see an icon on the message card for messages that have translations. Hover over the icon to see the translation settings.

![](https://klaviyo.zendesk.com/hc/article_attachments/38070496426523)

## Translations for cloned messages and A/B tests

If you clone a flow email with translations, the new email will keep all translations from the original which you can freely edit. Learn [how to clone a flow](https://help.klaviyo.com/hc/en-us/articles/24898429283739).

When you create an A/B test, new variations will keep translations from the original email.
