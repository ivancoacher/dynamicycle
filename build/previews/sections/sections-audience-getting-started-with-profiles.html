  • Source value reference

    Learn about the source ($source) profile property to better understand how your subscribers signed up. Klaviyo automatically assigns a $source property for profiles added using certain methods. For example, a profile’s $source is set to API if they were added through Klaviyo’s API , or set to Manually Initiated if you added them manually.
