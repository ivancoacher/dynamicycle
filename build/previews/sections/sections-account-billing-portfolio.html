• Getting started with portfolios

    Only Owners or Admins can set up a portfolio, and it must be from a paid account.

  • How to add or remove a portfolio user

    This article is specific to portfolios . If you need to add or remove users for a regular Klaviyo account, check out this article on adding or deleting account users .

  • How to add or remove an account from a portfolio

    You must be a portfolio Owner and also an Owner or Admin in the account(s) that you want to add or remove.

  • How to change the Owner of a portfolio

    This article is specific to portfolios. If you need to change the Owner for a regular Klaviyo account, check out this article on transferring account ownership .

  • How to close a portfolio account

    Learn how to close a portfolio account in Klaviyo, which permanently deletes the portfolio and its metrics. Closing a portfolio unlinks all accounts, but has no other impact on any linked account.

  • How to manage users in bulk across a portfolio

    With bulk user management, portfolio users with the correct user roles can manage user access across multiple linked accounts from a single, centralized interface. This eliminates the need to toggle between individual accounts to add, edit, or remove users, providing a "bird's-eye view" of your organization’s active users.

  • How to use portfolio-level mapped metrics

    Only the following permissions can map or edit metrics: Portfolio Owner Portfolio Admin The following permissions can view mapped metrics: Portfolio Manager Portfolio Analyst

  • Understanding account billing details in a portfolio

    Only portfolio Owners, Admins, and Managers can view and export billing details.

  • Understanding portfolio reporting

    Learn about the reporting tools and functionality for portfolios. These features enable you to easily aggregate and analyze your data across multiple accounts (such as if you have different brands or use separate accounts for different regions).

  • Understanding portfolio user roles

    Learn about the roles and permissions for portfolio users. This article outlines both static portfolio user roles and how to create a custom user role.

  • Understanding your portfolio settings

    Only Portfolio Owners and Admins have access to the portfolio’s settings, except the Personal tab.
