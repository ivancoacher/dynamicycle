<h1>使用文件夹组织模板</h1>

<h2>你将会学到</h2>
<p>使用 Klaviyo 模板库中的<strong><em>*文件夹</strong></em>*将您保存的电子邮件模板组织成与您的团队工作方式相匹配的结构 - 按品牌、营销活动类型、季节或任何其他分组。组织好的模板可以更快地查找和重用，这可以在您每次构建新电子邮件时节省时间。 ## 开始之前</p>
<ul>
<li>文件夹仅在模板库的****我的模板****选项卡上可用。主题模板选项卡不支持文件夹。 - 您必须具有****内容创建者****、****活动协调员****、****经理****、****管理员****或****所有者****角色才能创建、重命名、移动或删除文件夹。具有 ****Analyst**** 角色的用户可以查看和导航文件夹，但无法修改它们。 - 文件夹最多可嵌套 ****10 层深度****。 - 文件夹名称的最大长度为****255 个字符****。 - 预计时间：****在 1 分钟内**** 创建文件夹并将模板移入其中。 ## 概述</li>
</ul>
<p>文件夹可让您对保存的模板进行分组，但这对您的团队有意义。您可以：</p>
<ul>
<li>创建新文件夹并将它们嵌套在一起，</li>
<li>使用拖放或操作菜单将模板移动到文件夹中，</li>
<li>将整个文件夹移动到其他文件夹中，</li>
<li>重命名或删除您不再需要的文件夹，以及</li>
<li>一次选择多个模板和文件夹以批量移动或删除它们。在****我的模板****的根级别，仅显示尚未放置在文件夹中的模板 - 因此您的工作区在组织时保持整洁。无论您当前位于何处，搜索始终会查找所有文件夹。 ## 设置</li>
</ul>
<h3>创建文件夹</h3>
<p>1. 导航至<strong><em>*内容 > 模板</strong><strong>并打开</strong><strong>我的模板</strong><strong>选项卡。 2. 单击</strong><strong>创建文件夹</strong><strong>（或工具栏中的文件夹图标）。 3. 在</strong><strong>创建文件夹</strong><strong> 模式中，键入文件夹的名称。 4. 单击</strong><strong>创建</strong><strong>。新文件夹在模板网格中显示为卡片。 </strong><strong>提示</strong><strong>：要创建子文件夹，请首先通过单击导航到现有文件夹，然后重复上述步骤。您最多可以嵌套 10 层文件夹。 </strong><strong>警告</strong><strong>：如果您已达到最大文件夹深度（10 层），</strong><strong>创建文件夹</strong></em>* 选项将不可用。创建新文件夹之前，先移至较浅的级别。 ### 将模板移动到文件夹中</p>
<p><strong><em>*使用拖放：</strong></em>*</p>
<p>1. 单击并按住模板卡。 2. 将其拖到任意文件夹卡上。当您将其置于文件夹卡上时，文件夹卡会突出显示。 3. 松开鼠标将模板放入文件夹中。该模板将从当前视图中消失，现在位于文件夹内。 <strong><em>*使用操作菜单：</strong></em>*</p>
<p>4. 单击模板卡上的<strong><em></strong><strong></em></strong><strong>（更多）菜单。 5. 选择</strong><strong>移动</strong><strong>。 6. 在</strong><strong>移动</strong><strong>模式中，浏览或搜索目标文件夹。使用</strong><strong>最近</strong><strong>选项卡查看最近使用过的文件夹，或使用</strong><strong>全部</strong><strong>查看完整的层次结构。 7. 单击目标文件夹，然后单击</strong><strong>移动</strong><strong>。 </strong><strong>提示</strong><strong>：如果正确的文件夹尚不存在，您也可以直接在“移动”模式中单击“</strong><strong>创建新文件夹</strong>**”。 ### 将一个文件夹移动到另一个文件夹中</p>
<p>1. 单击文件夹卡上的<strong><em></strong><strong></em></strong><strong>（更多）菜单。 2. 选择</strong><strong>移动</strong><strong>。 3. 在</strong><strong>移动</strong><strong>模式中选择目标文件夹，然后单击</strong><strong>移动</strong><strong>。 4. 要将文件夹移回根级别，请在模式中选择</strong><strong>无文件夹（根）</strong>**。 ### 一次选择并移动多个项目</p>
<p>1. 单击任意模板或文件夹卡将其选中。卡上会出现一个复选标记。 2. 单击其他卡将其添加到您的选择中。使用 <strong><em>*Shift+单击</strong><strong> 选择范围，或 </strong><strong>Cmd/Ctrl+单击</strong><strong> 切换单个项目。 3. 屏幕底部会出现</strong><strong>批量操作栏</strong><strong>，显示已选择的项目数。 4. 单击批量操作栏中的</strong><strong>移动</strong><strong>，选择目标文件夹，然后单击</strong><strong>移动</strong><strong>。 </strong><strong>提示</strong><strong>：按</strong><strong>Escape</strong></em>* 可随时清除您的选择。 ### 重命名文件夹</p>
<p>1. 单击文件夹卡上的<strong><em></strong><strong></em></strong><strong>（更多）菜单。 2. 选择</strong><strong>重命名</strong><strong>。 3. 更新模式中的文件夹名称，然后单击</strong><strong>保存</strong>**。 ### 删除文件夹</p>
<p>1. 单击文件夹卡上的<strong><em></strong><strong></em></strong><strong>（更多）菜单。 2. 选择</strong><strong>删除</strong><strong>。 3. 在模态中确认删除。 </strong><strong>警告</strong>**：您无法删除仍包含模板或子文件夹的文件夹。首先移动或删除文件夹内的所有项目，然后重试。 ### 在文件夹之间导航</p>
<ul>
<li>单击任意文件夹卡将其打开。 URL 会更新以反映当前文件夹（例如 /templates/list/folder/{folder-id}）。 - 当您位于文件夹内时，****面包屑路径****会出现在模板网格的顶部。单击任何面包屑可跳回该级别。 - 单击面包屑中的****我的模板****，返回到根视图。</li>
</ul>
