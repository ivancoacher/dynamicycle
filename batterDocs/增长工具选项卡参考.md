<h1>增长工具选项卡参考</h1>

<p>了解 Klaviyo 中的“增长工具”选项卡，您可以在其中找到最佳实践并轻松设置功能以帮助扩大受众群体。增长工具可以在 Klaviyo 主导航中的<strong><em>*受众</strong></em>*选项卡下找到。</p>
<p>增长工具页面是 Klaviyo 工具的集中中心，可帮助您：</p>
<p>1. 收集有网络体验的订阅者</p>
<p>2. 为移动受众打造体验</p>
<p>3. 与第三方工具集成</p>
<p>Klaviyo 将监控您的帐户并提供建议来帮助您实现这 3 个目标。每个推荐功能都有一个相应的号召性用语按钮。当您点击号召性用语按钮时，Klaviyo 将引导您完成实现这一目标的旅程。</p>
<h2>收集具有网络体验的订阅者</h2>
<ul>
<li>****创建您的第一个注册表单****</li>
</ul>
<p>如果您还没有这样做，请构建弹出窗口、弹出窗口、整页或嵌入注册表单，以在您的网站上收集新的电子邮件或短信订阅者。</p>
<ul>
<li>****管理您的注册表单****</li>
</ul>
<p>如果您有现有的注册表单，请监控您的 Klaviyo 帐户中所有表单的状态、性能和功能。</p>
<p>有关构建注册表单的更多详细信息，请前往[注册表单入门](https://help.klaviyo.com/hc/en-us/articles/360026474752)。有关管理注册表单的更多详细信息，请前往[如何管理注册表单](https://help.klaviyo.com/hc/en-us/articles/360002049952)。</p>
<ul>
<li>****自定义订阅和偏好页面****</li>
</ul>
<p>编辑帐户的默认订阅页面和首选项页面（也称为同意页面）并设置样式。</p>
<p>默认情况下，所有列表都使用帐户级同意页面；但是，您可以为特定列表自定义唯一的同意页面。有关更多详细信息，请前往[同意页面入门](https://help.klaviyo.com/hc/en-us/articles/115005251848)。</p>
<ul>
<li>****将应用程序添加到您的 Shopify 页面以收集短信订阅者（仅限 Shopify）****</li>
</ul>
<p>征得同意后才能在结帐、感谢和订单状态页面上发送交易和/或营销信息。</p>
<p>有关更多详细信息，请前往[如何在 Shopify 结帐页面上收集交易短信同意](https://help.klaviyo.com/hc/en-us/articles/35067557759771)。</p>
<h2>为您的移动受众打造体验</h2>
<ul>
<li>****设置短信****</li>
</ul>
<p>在您的 Klaviyo 帐户中启用 SMS，以便通过短信与您的订阅者进行通信。要设置并运行 SMS，请参阅[如何在 Klaviyo 中设置 SMS](https://help.klaviyo.com/hc/en-us/articles/4404274419355)。</p>
<ul>
<li>****创建您的第一个订阅链接****</li>
</ul>
<p>创建一个链接以在社交媒体活动或电子邮件中共享以收集短信同意。</p>
<ul>
<li>****管理您的订阅链接****</li>
</ul>
<p>查找并跟踪您帐户的现有订阅链接。</p>
<p>有关订阅链接的更多详细信息，请参阅[如何创建短信订阅链接](https://help.klaviyo.com/hc/en-us/articles/14104388043931)。</p>
<h2>与第三方工具集成</h2>
<ul>
<li>****将 Klaviyo 连接到您的电子商务平台****</li>
</ul>
<p>将您的所有客户数据和活动同步到您的 Klaviyo 帐户中。</p>
<p>请访问我们的[电子商务业务集成参考](https://help.klaviyo.com/hc/en-us/articles/360020698171)，了解有关集成的更多详细信息。</p>
<ul>
<li>****与社交线索广告集成****</li>
</ul>
<p>将您的 Klaviyo 帐户连接到您的付费社交活动和营销应用程序。</p>
<p>请参阅我们关于[与 Google 广告集成](https://help.klaviyo.com/hc/en-us/sections/6353195754139) 或[与 Facebook 集成](https://help.klaviyo.com/hc/en-us/sections/115000036291) 的指南，了解更多信息。</p>
