<h1>如何优化注册表单的显示设置</h1>

<h2>你将会学到</h2>
<p>了解如何在 Klaviyo 注册表单上运行优化测试，以确定表单向网站购物者显示的最佳时间。在优化测试中，Klaviyo 运行了一系列人工智能生成的实验，以确定可提高表单提交率的最有效的显示计时设置。优化测试与 A/B 测试类似，其目的是识别效果良好或需要改进的区域。然而，优化测试使用人工智能，并且是完全自动化的，可以节省您的时间并提供更准确的结果。 ![](https://fast.wistia.com/embed/medias/fque2tcpwb/swatch)</p>
<h2>开始之前</h2>
<p>您必须至少拥有 400,000 个配置文件（请注意，这是配置文件总数）才有资格进行优化测试。 ## 创建优化测试</p>
<p>使用所需的测试设置创建并运行优化测试，以确定注册表单的最佳显示计时设置。完成人工智能优化测试后，您的注册表单将自动更新为新的显示时间设置，并且该版本将在您的网站上发布。请注意，您一次只能运行 1 个优化测试。要创建优化测试：</p>
<p>1. 从左侧导航栏中选择<strong><em>*注册表单</strong><strong>。 2. 创建一个新的注册表单，或者通过选择 3 个点，然后</strong><strong>编辑表单</strong><strong>来打开现有表单的表单编辑器。在优化测试运行时，您无法对注册表单进行任何编辑（例如样式、内容、行为等）。如果您确实需要在优化测试运行时进行更改，您可以选择结束测试，进行所需的更改，然后开始新的测试。 3. 在左上角，选择</strong><strong>创建 A/B 测试</strong></em>*。 ![“创建 A/B 测试”按钮突出显示，并从注册表单编辑器的顶部菜单栏中选择。](https://klaviyo.zendesk.com/hc/article_attachments/28720762175899)</p>
<p>4. 选择<strong><em>*优化测试</strong></em>*。如果当前正在进行 A/B 测试，则无法开始优化测试。 ![当您单击注册表单上的“创建 A/B 测试”并从菜单上的测试选项中选择“优化测试”时，会出现“创建测试”弹出窗口。](https://klaviyo.zendesk.com/hc/article_attachments/28720762194843)</p>
<p>5. 在<strong>测试名称</strong>下，您可以更改测试的默认名称。在此下方，验证<strong>设置</strong>旁边的对照组的计时设置。该控件是您当前的表单。 6. 选择<strong><em>*继续测试设置</strong><strong>。 7. 在出现的 </strong>测试设置</em>* 模式中，选择每个组的流量百分比：</p>
<ul>
<li>**对照组**</li>
</ul>
<p>该组将始终看到表单的当前版本<strong>。</strong></p>
<ul>
<li>**测试组**</li>
</ul>
<p>这是在优化测试的整个阶段中进行测试的组。！[](https://klaviyo.zendesk.com/hc/article_attachments/34320465316763)</p>
<p>8. 可选：如果您想进一步指定 AI 将生成并针对您当前表单进行测试的变体类型，请选择<strong><em>*高级设置</strong></em>*选项卡。从这里，您可以删除不想包含在测试中的任何计时设置，或者指定时间延迟或滚动百分比的值。 ![创建测试模式显示高级设置选项，您可以在其中选择 Klaviyo AI 将用于在优化测试中创建变体的显示规则。](https://klaviyo.zendesk.com/hc/article_attachments/28720790665371)</p>
<p>优化测试目前不允许页面浏览量变化，因此测试中不会考虑显示<strong>访问者看到一定数量的页面后</strong>的计时选项。如果您将注册表单设置为根据页面查看规则显示，您将看不到用于创建优化测试的选项。 9. 选择测试设置后，选择<strong><em>*开始优化。</strong></em>*</p>
<ul>
<li>如果您的注册表单没有足够的流量，则会出现一个标注，说明 Klaviyo 不建议在此表单上运行优化测试。我们建议对流量较高的注册表单进行优化测试，以查看最准确的结果。如果您选择以低流量形式运行测试，则测试最多将运行 90 天。优化测试将贯穿各个阶段，根据您的测试设置，使用人工智能来测试和测量您当前的表单与不同显示时序设置的变化。在第一阶段之后，Klaviyo 将选择一个需要更多数据的变体，以便在第二阶段和第三阶段继续进行测试。 实验过程将继续运行，直到 AI 建议 3 次修改表格，或者直到测试开始后 90 天过去。无论何时，测试都会结束，人工智能识别出的最佳显示时间设置将在您的注册表中自动更新。 ## 监控正在进行的优化测试</li>
</ul>
<p>要在运行时监控优化测试：</p>
<p>1. 从主导航中选择<strong><em>*注册表单</strong><strong>。 2. 单击正在进行优化测试的表单。它将在 </strong>状态<strong> 列中显示一个小的“运行优化”横幅。 3. 在菜单栏中，单击</strong><strong>A/B 测试结果</strong><strong> 选项卡。 4. 确保顶部的下拉菜单设置为 </strong>优化测试</em>*，以及您要查看的测试的名称。 ![A/B 测试结果选项卡包含正在进行的优化测试，显示顶部的两个下拉菜单，分别设置为优化测试和测试的正确名称。](https://klaviyo.zendesk.com/hc/article_attachments/28720790627867)</p>
<p>从这里，您将看到正在进行的优化测试的概述。这包括正在测试的注册表单的视觉效果，以及正在进行的阶段的以下结果的细分：</p>
<ul>
<li>******提交率提升******</li>
</ul>
<p>对照组的提交率与表现最好的变体的提交率之间的百分比差异。 - <strong><em>*获胜概率</strong></em>*</p>
<p>变体比对照组表现更好的可能性百分比。 - <strong><em>*流量分布</strong></em>*</p>
<p>您在最初创建测试时选择的流量百分比。它们分别反映了有多少流量流向对照组和测试变体（人工智能生成的表格变体）。 ![优化测试结果页面的上半部分，您可以在其中查看测试计划阶段的概述，以及描述提交率提升、获胜概率卡和流量分布的卡片。](https://klaviyo.zendesk.com/hc/article_attachments/28720762187035)</p>
<p>在 <strong>A/B 测试结果</strong> 选项卡的下半部分，结果表显示优化测试中每个已完成的阶段。每个阶段分为：</p>
<ul>
<li>****开始日期****</li>
</ul>
<p>此阶段开始的日期。 - <strong><em>*符合条件的独特景观</strong></em>*</p>
<p>在此测试阶段有资格查看注册表单的唯一用户数量。由于您正在测试显示时间，因此视图将按可能看到表单的唯一用户数量进行计数，以便准确比较表单变体。 - <strong><em>*合格的提交率</strong></em>*</p>
<p>提交的唯一表单事件数除以有资格查看表单变体的唯一用户数（<strong>合格的唯一浏览次数</strong>）。例如，如果 2 个唯一用户查看表单变体，其中 1 个提交表单，则提交率将反映 50%。 - <strong><em>*获胜概率</strong></em>*</p>
<p>针对对照组进行测试的变体的获胜概率。 - <strong><em>*提交率提升</strong></em>*</p>
<p>与对照组相比，提交率增加的百分比。单击任何阶段上的下拉箭头可查看对照组的关键详细信息和数据，以及该阶段测试的每个变体的原始数据细分（即<strong>提交率、获胜概率</strong>和<strong>提交率提升</strong>）。 ![优化测试结果页面底部的表格，您可以在其中查看迄今为止测试中已完成阶段和变化的数据细分。](https://klaviyo.zendesk.com/hc/article_attachments/28720762217755)</p>
<p>当至少 2 天过去，并且所测试的对照和变体都收到了至少 600 次浏览时，一个阶段将结束。对于第一阶段，当针对对照测试多个变体时，这些变体必须平均 600 个视图。或者，如果对照组在 1 天后具有统计上显着更好的表现，则阶段也将结束。优化测试将继续运行各个阶段，直到 1 个表单变体被识别为在多个连续阶段中具有最佳显示计时设置。您可以在优化测试结束时查看每个阶段的原始数据。 ### 编辑优化测试名称</p>
<p>要在优化测试进行时编辑其名称：</p>
<p>1. 在<strong>注册表单</strong>页面上，选择正在运行优化测试的表单。 2. 单击<strong><em>*A/B 测试结果</strong><strong> 选项卡。 3. 在右上角，选择 3 个点，然后</strong><strong>编辑详细信息</strong></em>*。 ![从优化测试结果页面右上角的 3 点下拉菜单中选择编辑详细信息的选项。](https://klaviyo.zendesk.com/hc/article_attachments/28720790636699)</p>
<p>4. 在<strong>测试名称</strong>下，将当前名称替换为所需的更改。 5. 单击<strong><em>*保存</strong></em>*。 ![重命名优化测试弹出窗口，您可以在其中更改之前设置的测试名称。](https://klaviyo.zendesk.com/hc/article_attachments/28720790642459)</p>
<p>当优化测试正在进行时，您无法对注册表单本身进行编辑。如果您进入正在进行测试的注册表单的编辑器，模式将询问您是否要结束测试以便对表单进行编辑，以及您希望如何结束它。您可以：</p>
<ul>
<li>****保持控制变化****</li>
</ul>
<p>选择此选项意味着选择在测试期间针对不同变体进行测试的控制注册表单作为性能最高的变体。请注意，不会进行任何更改，因为这是您最初开始测试时使用的注册表单。 - <strong><em>*用最高性能的变体替换控制</strong></em>*</p>
<p>选择此选项意味着选择最近测试阶段中性能最高的变体作为性能最高的变体。 Klaviyo 会将您开始测试时使用的注册表单替换为性能最高的表单变体。 ![如果您尝试进入正在进行优化测试的表单的注册表单编辑器，则编辑表单将结束出现的优化测试模式。](https://klaviyo.zendesk.com/hc/article_attachments/28720790645147)</p>
<p>如果您选择结束正在进行的测试以修改注册表单，则需要创建新的优化测试才能重新开始。 ## 手动结束优化测试</p>
<p>如果您需要调整测试设置（即站点流量分布或变体选择设置），您可以选择手动结束优化测试，而不是等待结果来确定获胜者，为此：</p>
<p>1. 在<strong>注册表单</strong>页面上，选择正在运行优化测试的表单。 2. 单击<strong><em>*A/B 测试结果</strong><strong> 选项卡。 3. 选择右上角的 3 个点，然后</strong><strong>结束测试</strong></em>*。 ![从优化测试结果页面右上角的 3 点下拉菜单中选择“结束测试”选项。](https://klaviyo.zendesk.com/hc/article_attachments/28720762209947)</p>
<p>4. 在确认模式中，选择一个获胜变体。您可以选择对照组或当前阶段测试的获胜者。 ![“结束测试”弹出窗口，您可以选择手动结束优化测试，并选择“保留控件变体”或“用迄今为止性能最高的变体替换控件”。](https://klaviyo.zendesk.com/hc/article_attachments/28720790652443)</p>
<p>如果您选择 <strong>当前获胜者</strong> 作为获胜版本，您的原始注册表单将自动更新为相应的显示设置。 5. 选择<strong><em>*选择获胜者并结束测试</strong></em>*。 ## 如何选择获胜变体</p>
<p>优化测试完成后，注册表单将自动更新为获胜显示计时设置，或者如果控件获胜则保持不变，并且<strong>A/B测试结果</strong>页面上的测试状态从<strong>实时</strong>更改为<strong>已完成</strong>。此时，将显示测试概述和最终结果以供您分析，并且将显示 3 个结果中的 1 个：</p>
<p>1. <strong>成功优化</strong>：确定了获胜的变体</p>
<ul>
<li>AI 测试发现了一个比对照组表现更好的变体。获胜者的描述将显示在**获胜版本**下。 2. **成功优化**：控制才是赢家</li>
</ul>
<ul>
<li>该控制优于所有针对它测试的变体。 **提交率提升**将显示 0%，并且控件显示计时设置的说明将显示在 **获胜变化** 下。 3. **不确定的结果**：</li>
</ul>
<ul>
<li>尽管运行了多个阶段，但人工智能测试在 90 天内没有足够的数据来得出结论性结果。因此，控件将显示为获胜变体，并且**提交率提升**将反映 0%。 ## 后续步骤</li>
</ul>
<p>请参阅[如何查看注册表单回复](https://help.klaviyo.com/hc/en-us/articles/4406228129051)，深入了解注册表单中从新订阅者收集的信息。 如果您的网站上有多个注册表单，请考虑[启用防碰撞显示设置](https://klaviyo.zendesk.com/hc/en-us/articles/19788320859419)，以防止同时显示多个注册表单。</p>
