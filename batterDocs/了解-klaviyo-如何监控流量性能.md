<h1>了解 Klaviyo 如何监控流量性能</h1>

<h2>****你会学到****</h2>
<p>了解 Klaviyo 如何监控流程性能异常下降并提醒您。当流的发送速率显着下降时，您将收到警报，以便您解决潜在问题。这种类型的监控也称为异常检测。 ## <strong><em>*流量性能监控的工作原理</strong></em>*</p>
<p>与您帐户的历史数据相比，如果您的流程中收到的消息事件数量有所下降，Klaviyo 会向您发出提醒。这包括以下消息类型的费率：</p>
<ul>
<li>电子邮件</li>
<li>短信</li>
</ul>
<p>当检测到指标活动异常下降时，您将收到不同方式的通知：</p>
<ul>
<li>主页上的应用内通知！[alert.jpg](https://klaviyo.zendesk.com/hc/article_attachments/28720901910171)</li>
<li>指标页面上针对特定消息接收事件的通知横幅</li>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28720901913755" alt="公制页面.jpg" />
</ul>
<h2>****关闭或抑制警报****</h2>
<p>如果活动下降是预期的或已经在调查中，您可以忽略或抑制警报以防止它们显示在您的帐户中。 - 解除警报将导致警报消息消失，直到再次触发为止。 - 抑制警报将防止该指标再次触发警报，直到指定的时间。要消除警报：</p>
<p>1. 如果您位于 <strong>主页</strong> 选项卡，请通过单击警报上的<strong><em>*查看指标</strong><strong>导航到受影响的流。通过导航到</strong><strong>分析 > 指标</strong><strong>并从主 Klaviyo 导航中选择</strong><strong>已接收电子邮件</strong><strong>或</strong><strong>已接收短信</strong><strong>来查找受影响的指标。 2. 在警报卡的右上角，单击</strong><strong>关闭</strong></em>*。要抑制警报：</p>
<p>1. 如果您位于 <strong>主页</strong> 选项卡，请通过单击警报上的<strong><em>*查看指标</strong><strong>导航到受影响的流。通过导航到</strong><strong>分析 > 指标</strong><strong>并从主 Klaviyo 导航中选择</strong><strong>已接收电子邮件</strong><strong>或</strong><strong>已接收短信</strong><strong>来查找受影响的指标。 2. 单击“</strong><strong>关闭</strong></em>*”按钮旁边的箭头。 3. 单击以下选项之一：</p>
<ul>
<li>****抑制30天****</li>
<li>****抑制 60 天****</li>
<li>****抑制120天****</li>
<li>****压制365天****</li>
</ul>
<p>选择抑制选项后，将显示一条成功消息，并显示抑制到期的日期。抑制期结束后，如果仍然检测到活动下降，警报将继续触发，直到您再次抑制它们。 ## <strong><em>*性能突然下降的故障排除</strong></em>*</p>
<p>虽然活动突然下降可能令人震惊，但对于这种现象有一些常见的解释。您的电子商务商店的具体原因包括：</p>
<ul>
<li>维护您的商店或其服务器</li>
<li>您的电子商务平台的服务器暂时中断</li>
</ul>
<p>如果您的商店处于离线状态，您的 Klaviyo 帐户将不会收到新订阅者或指标活动，因此这将导致发送率下降。检查商店的设置或内部日志以了解任何计划的维护。如果您托管在付费平台（例如 Spotify 或 BigCommerce）上，请检查其状态页面以获取有关服务器中断和停机时间的信息。对于 Klaviyo 特有的原因，请查看以下部分。单击该部分标题即可查看更多信息。在某些情况下，可能会应用多种场景。如果您不确定哪种情况适用于您的问题，请查看所有情况。 ### <strong><em>*您是否更改过任何个人资料过滤器？</strong></em>*</p>
<p>首先，检查您的过滤器，看看它们是否导致配置文件离开流程。为此，请按照下列步骤操作：</p>
<p>1. 单击流程的触发器。 2. 在左侧边栏中，单击<strong><em>*预览触发器设置</strong></em>*。 3. 在预览模式中，查看将触发您的流程的配置文件以及它们是否符合您的配置文件过滤器的条件。 ![](https://klaviyo.zendesk.com/hc/article_attachments/28720896543899)</p>
<p>4. 如果您发现许多配置文件在应进入流程时未通过配置文件过滤器，请检查您的配置文件过滤器以确保它们按照您预期的方式设置。 5. 如有必要，请在查看流量触发器时单击左侧边栏中的<strong><em>*配置文件过滤器</strong></em>*来更改配置文件过滤器。如果您不确定流程是否已更改，您可以检查流程的变更日志。如果更改的时间戳与您开始遇到流程问题的时间一致，则更改很可能是问题的根源。请按照以下步骤查看流的历史记录：</p>
<p>1. 在顶部栏中，单击<strong><em>*查看流历史记录</strong></em>*图标。 ![](https://klaviyo.zendesk.com/hc/article_attachments/46896468483995)</p>
<p>2. 查看屏幕右侧的流历史记录面板。 ![](https://klaviyo.zendesk.com/hc/article_attachments/46896468487323)</p>
<p>3. 查看更改日志以查看最近是否更改了任何流程的过滤器。有关“流程历史记录”面板的更多信息，请参阅我们关于[如何查看流程的变更日志](https://help.klaviyo.com/hc/en-us/articles/4402385748635) 的文章。 ### <strong><em>*您是否更改了发件人地址？ （电子邮件）</strong></em>*</p>
<p>您的发件人地址应与您的网站域匹配；否则，这可能会导致发送问题。例如，如果您的网站 URL 为 example.com，则您的发件人电子邮件地址应以 @example.com 结尾。使用个人电子邮件地址域（例如@gmail.com、@yahoo.com 或@outlook.com）发送的电子邮件将被阻止发送。要检查您的发件人地址：</p>
<p>1. 单击流程中的一封电子邮件。 2. 单击左侧边栏中的<strong><em>*编辑</strong><strong>。 3. 检查在</strong><strong>发件人电子邮件地址</strong></em>*字段中输入的地址。 ![sender_info.jpg](https://klaviyo.zendesk.com/hc/article_attachments/28720896539291)</p>
<p>4. 如有必要，请更改此地址。 ### <strong><em>*您的留言内容更新了吗？</strong></em>*</p>
<p>如果您更新了邮件内容，请确保内容遵守[电子邮件送达最佳实践](https://help.klaviyo.com/hc/en-us/articles/12034571748251)，以避免垃圾邮件过滤器。 - 避免垃圾邮件主题行，例如“仅在有限时间内仅此一次”</p>
<ul>
<li>在图像和文本之间找到平衡。 - 限制 URL 的数量。 - 避免在消息中添加不必要的代码。 - 使用动态变量来个性化消息。详细了解[送达率最佳实践](https://help.klaviyo.com/hc/en-us/articles/115005247008/#email-deliverability-best-practices4)。 ### ****对于欢迎系列或其他列表触发的流程，您是否仍在接收新订阅者？****</li>
</ul>
<p>当订户加入指定列表时，会触发欢迎系列流和其他列表触发流。为了确保您的列表仍在接收新订阅者：</p>
<p>1. 单击流程的触发器。 2. 在左侧边栏中，单击触发流程的列表的名称。 3. 在 <strong>添加日期</strong> 列中，检查上次添加配置文件的时间。 4. 如果很长一段时间没有将新的个人资料添加到您的列表中，请确保与您的列表相关的任何注册表单在您的网站上仍然可见。 ### <strong><em>*您的优惠券代码用完了吗？</strong></em>*</p>
<p>如果您使用 Shopify 或 Magento，您可以自动生成新的优惠券代码以避免用完。仅当您使用上传优惠券代码的选项时，此问题才适用。对于包含动态优惠券代码的流消息，如果没有剩余的优惠券代码，则不会发送该消息。要查看您还剩多少个优惠券代码：</p>
<p>1. 使用 Klaviyo 主导航栏，导航至<strong><em>*内容 > 优惠券</strong><strong>。 2. 单击</strong><strong>上传的优惠券</strong><strong>。 3. 查看优惠券右侧的</strong>可用/总计<strong>栏，查看优惠券代码剩余数量。 4. 如果没有剩余代码，请单击最右侧的操作按钮，然后选择</strong><strong>添加优惠券</strong><strong>以上传更多代码。请阅读我们关于[优惠券代码入门](https://help.klaviyo.com/hc/en-us/articles/115005084727) 的文章了解更多信息。 ### </strong><strong>对于分段触发的流程，您是否更改了分段定义？</strong></em>*</p>
<p>如果您的流是由分段触发的，则分段定义的更改可能会阻止新的配置文件进入该分段，从而导致流发送下降。为了确保您的细分市场仍在接收新成员：</p>
<p>1. 单击流程的触发器。 2. 在左侧边栏中，单击触发流程的分段的名称。 3. 如果分段中有配置文件，请检查 <strong>添加日期</strong> 列以查看上次添加配置文件的时间。 4. 如果该段中没有配置文件或长时间没有添加新的配置文件，请单击<strong><em>*编辑定义</strong></em>*以查看该段的定义。 5. 确保：</p>
<p>1. 配置细分定义以捕获您想要的人员。 2. 任何段条件都不会相互矛盾，如下例所示。在此示例中，有一个条件检查某人是否至少打开过一次电子邮件，以及一个条件检查某人是否从未打开过电子邮件。由于某人无法同时满足这两个条件，因此没有人会进入该细分市场。 ![segment.jpg](https://klaviyo.zendesk.com/hc/article_attachments/28720896541851)</p>
<p>6. 如有必要，更改段定义并单击<strong><em>*更新段</strong><strong>。 7. 细分触发流仅在人们有机进入细分时才会触发。如果人们由于定义更改而进入该细分，您将必须[通过流程手动发送旧的配置文件](https://help.klaviyo.com/hc/en-us/articles/360049924272)。 ### </strong><strong>请参阅特定流类型的故障排除指南</strong></em>*</p>
