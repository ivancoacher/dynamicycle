你将了解如何使用 Advanced KDP（Klaviyo 数据平台），在所有营销活动中获取更全面、深入的客户洞察。Advanced KDP 提供更高级的数据管理、处理和分析能力，并为你的各类受众及整体业务提供可执行的洞察与策略。

#### 什么是 Advanced KDP？

客户数据平台（CDP）是一种可大规模收集并整合多来源数据的系统，并将这些数据用于分析、洞察、营销自动化及广告平台。

Klaviyo 的 Advanced KDP 是一个完全整合的客户数据平台，可帮助你更高效地管理和激活数据。它提供数据丰富与转换工具、高级报表与预测模型，并支持将 Klaviyo 中的数据同步到外部系统。

#### 购买 Advanced KDP

Advanced KDP 不包含在 Klaviyo 标准营销应用中，需要单独订阅。

##### Klaviyo 新客户

如果你是新客户，可以在购买 Email 或 SMS 计划的同时，选择购买 Advanced KDP。

##### Klaviyo 现有客户

购买步骤如下：

1. 在左下角进入账户，选择 Billing
2. 点击 Change plan 进入结账页面
3. 在结账页选择 Advanced KDP，并输入所需的 Profile 数量
4. 点击 Continue to payment 完成支付

![](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/Add-on.jpg?resize=1024%2C616&ssl=1)

【注】在 Billing 中，Advanced KDP 显示名称为 CDP

##### 计费说明（Billing）

Advanced KDP 的定价基于你账户中的总 Profile 数量，而非可营销用户数量。
该数量包括所有 Email、SMS、Push Profile（无论是否活跃）。

****最佳实践建议：****

保留所有 Profile 数据，使用 Suppress（抑制）而非删除，这样 Advanced KDP 才能基于完整数据进行预测和分析。

另外，删除的 Profile 可能因再次互动而重新进入系统，触发不必要的自动化。同样，机器人或列表轰炸添加的邮箱也可能重复进入，影响送达率。

#### Intelligence 与 Data Management 的区别

Advanced KDP 功能分为两大类：

****1. Intelligence（智能分析）****


用于超越营销渠道表现的战略级分析，包括：

- 客户洞察（Customer insights）
- 商品洞察（Catalog insights）
- 预测模型（Predictive models）

****2. Data Management（数据管理）****


用于数据的转换、处理及系统间同步，提升数据可用性。

****界面（Interface）****

购买 Advanced KDP 后，Klaviyo 左侧导航中会新增 ****Advanced KDP**** 菜单，包含以下模块：

- Intelligence
- Data management

##### Intelligence 功能详解

###### RFM 分析报告

基于最近购买时间（Recency）、购买频率（Frequency）和消费金额（Monetary），自动将客户划分为不同群组（如忠诚客户）。

![](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/compare-distribution-tab.jpg?resize=900%2C541&ssl=1)

该报告可帮助你：

- 分析客户行为随时间的变化
- 发现营销优化空间
- 针对高风险客户制定挽回（Winback）策略，降低流失率

![](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/group-change-over-time-card-updated.jpg?resize=1000%2C653&ssl=1)

###### 漏斗分析报告（Funnel Analysis）

漏斗分析报告用于识别客户旅程中可能流失的环节。

你可以自定义分析路径，例如：
Placed Order → Fulfilled Order → Refunded Order（如图所示）

在此分析中，你可以查看每个步骤的客户数量和百分比，并识别优化营销工作的机会。

![](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/SMS-to-purchase.jpg?resize=1003%2C436&ssl=1)

###### 转化总览（Conversion Overview）

该仪表盘用于分析整体转化与营收，包括 Klaviyo 归因数据。
你可以查看：

- 不同转化次数的 Profile 数量
- 各自贡献的总营收

这一功能有助于优化营销活动，通过针对特定行为的客户群体进行精准投放，从而提高转化率。

![](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/%E5%B1%8F%E5%B9%95%E6%88%AA%E5%9B%BE-2025-12-17-163817.png?resize=1024%2C378&ssl=1)

###### 受众表现报告（Audience Performance）

受众表现报告让你快速评估各 Segment 的表现，识别表现优秀或不佳的群体。

报告内容包括：

- Segment 列表
- 每个 Segment 在各渠道的整体表现
- 总转化或总收入

基于这些洞察，你可以调整营销策略，对表现不佳的 Segment 进行优化或重新定位。

![](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/audience-performance-table-main.jpg?resize=735%2C372&ssl=1)

###### 队列分析（Cohort Analysis）

队列分析允许你对具有共同特征的一组客户（Cohort）随时间进行行为分析。

通过 Cohort 报告，你可以发现客户生命周期中参与度、转化及其他关键指标的趋势和模式。可追踪的客户行为示例包括：

- 重复购买行为
- 客户留存
- 订阅后购买行为

![](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/%E4%B8%8B%E8%BD%BD.png?resize=1024%2C559&ssl=1)

###### 商品洞察（Catalog Insights）

Advanced KDP 的产品分析仪表盘可帮助你理解客户对特定产品的购买行为，并据此制定营销策略。

你可以查看产品如何、何时及哪些产品推动了订单，从而在客户旅程的关键时机推荐相应商品。

策略性应用示例包括：

- 调整购后流程的发送时机
- 根据“下一次购买商品”推荐内容
- 基于弃购事件自动推荐组合/共购商品
- 指导商品营销策略，识别最佳组合或连续推广产品

![](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/product-analysis-main.jpg?resize=1024%2C561&ssl=1)

此外，产品分析仪表盘还会在预测分析模块中生成两个预测型客户属性：

1. 最佳加购日期（Best cross-sell date）


- 确定向客户进行交叉销售的最佳时间
- 需客户至少完成一次购买
- 基于购买相同商品的类似客户行为
- 每日动态更新，仅在客户有新购买时更新

2. 下一最可能购买商品（Next best product）

- 根据客户最近购买记录生成
- 自动排除不可售商品
- 排除购买后前 48 小时的数据，以避免退换影响
- 可在 Email 中通过 Next best product 模块动态展示客户最可能购买的商品

###### 可自定义 CLV 报告

客户终身价值（CLV）报告预测客户未来的购买行为，并提供每个营销渠道（Campaign、Flow、Form、Segment）当前购买习惯，然后基于这些数据建模潜在未来购买。

通过这些洞察，你可以：

- 制定交叉销售和追加销售策略
- 个性化客户购买体验
- 在关键时节或特定活动中优化营销策略

##### 数据管理功能（Data Management）

###### 数据仓库同步（Data Warehouse Sync）

数据仓库同步功能允许你将 Profile 和事件数据定期同步到第三方数据仓库，从而在 Klaviyo 外部存储和分析关键客户信息。

Klaviyo 支持以下数据仓库连接：

- Amazon Redshift
- Amazon S3
- Google BigQuery
- Microsoft Azure
- Snowflake

###### Webhooks

Klaviyo 中的 Webhooks 可用于基于 Klaviyo 捕获的事件在外部系统中构建 Webhook 应用。它们通过 HTTP POST 请求将信息发送到外部应用、工具或服务器，以通知事件发生。

Advanced KDP 支持的 Webhooks 包括与消息相关的事件，如 Unsubscribed（退订）、Received Email（邮件接收）、Clicked Email（邮件点击）。你也可以在不受 Flow 限制的情况下设置 Webhook。

![](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/create-webhook.jpg?resize=1000%2C971&ssl=1)

###### 数据转换（Data Transformation）

Klaviyo 的数据转换工具可在无需开发的情况下修改 Profile 属性。

你可以使用该工具对 Profile 属性进行格式化、标准化或合并，从而让数据更实用，并提高分段和个性化的准确性。

- ****格式化（Format）****
  可更新 Profile 属性值的格式

![](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/revise-dates.jpg?resize=736%2C664&ssl=1)

- ****标准化（Standardize）****
  可设定规则自动替换特定属性值

![](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/standardize.jpg?resize=1000%2C565&ssl=1)

- ****合并（Merge）****
  可将多个自定义 Profile 属性合并为一个

![](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/marge_hair_type.jpg?resize=1024%2C490&ssl=1)

###### Code

Code 功能允许你针对 Klaviyo 捕获的事件执行自定义函数。你可以在编辑器中编写 JavaScript 或 Python 代码，这些代码将直接在平台上执行。

通过 Code，你可以在无需建立公共 HTTP 接口的情况下将数据发送到外部系统，并在事件发生时触发自定义功能。Klaviyo 还提供了多种常用模块，便于创建自定义解决方案。

![](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/JS-editor-1024x432.jpg?resize=1024%2C432&ssl=1)

###### 自定义监控（Custom Monitors）

自定义监控可配置警报，帮助你快速发现并解决 Klaviyo 中关键指标和对象（如 Segment 和 Flow）的问题。

在 Klaviyo 中可以设置三类自定义监控：

1. ****单一 Flow 监控****：监控关键性能指标并接收警报
2. ****单一指标监控****：监控事件并接收警报
3. ****单一 Segment 监控****：监控 Segment 并接收警报

可设置的警报规则可包含触发条件，当条件满足时，系统会发出警报。

![](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/alert_rule-1.jpg?resize=1024%2C383&ssl=1)

#### 其他优势

##### 自定义指标（Custom Metrics）

虽然自定义指标在所有 Klaviyo 账户中可用，但购买 Advanced KDP 后，你的账户可用自定义指标数量将从 1 个增加到 50 个。

自定义指标允许你配置专属事件，以更准确地报告和反映业务运营。

Klaviyo 默认提供用于衡量业务绩效的指标，例如 Placed Order（下单）事件。但在某些情况下，你可能需要创建自定义指标以更精准地反映业务运营，例如：

- ****区分零售和电子商务事件（Shopify 或其他自定义集成）****
  - Shopify 和部分自定义集成会将线下零售（POS）与电子商务订单合并为单一事件
  - 你可以通过自定义指标，将 POS 订单与电商订单分开查看

![](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/POS.jpeg?resize=1024%2C164&ssl=1)

- ****移除重复订阅事件（Shopify、WooCommerce、BigCommerce）****
  - 默认集成会将订阅订单自动计入 Placed Order
  - 通过设置条件（例如“does not equal”），可只查看非订阅订单

![](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/subscription-.jpeg?resize=1000%2C199&ssl=1)
