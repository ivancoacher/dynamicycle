<h1>How to create and manage header blocks</h1>

## You will learn

Learn how to use header blocks to easily create a navigation bar for reuse in all of your email templates. You have full control over how your headers will look on both desktop and mobile devices.

## Add a header block and select a layout

1. Drag a Header bar block into your template
   ![The header block](https://klaviyo.zendesk.com/hc/article_attachments/28705662352667)
2. Complete all fields in the **Layout** and **Content** sections.
   - Click ****Add Link**** to add additional links, or click the trash can icon next to an existing link to remove it. Open each link menu to add your URL.
     ![Header bar link adjustment.png](https://klaviyo.zendesk.com/hc/article_attachments/34319983922459)
3. Once you're satisfied with the appearance and content of your block, hover over the block and click the star icon to save it for future use.
   ![Save header block](https://klaviyo.zendesk.com/hc/article_attachments/28705662355355)
4. Give your block a descriptive title like "Main Header Block," then click ****Create****.

When you add this block to other templates (by clicking ****Universal**** and dragging the block into a new template), changes made to the block in one template will apply to any other templates containing that block as well.
