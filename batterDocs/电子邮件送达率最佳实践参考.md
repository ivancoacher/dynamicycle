<h1>电子邮件送达率最佳实践参考</h1>

<h2>你将会学到</h2>
<p>了解电子邮件送达率的不同最佳实践。遵循这些最佳实践和建议操作是保持强大的交付能力并成功进入客户收件箱的关键。了解[电子邮件送达率及其重要性](https://help.klaviyo.com/hc/en-us/articles/115005247008)。 ## 基础设施设置</p>
<p>电子邮件传递基础设施是指用于将电子邮件传递给收件人的不同系统、工具和域。您的基础设施是收件箱提供商在确定您作为发件人的可信度并确定如何放置电子邮件时使用的重要考虑因素。它也是保护您的域名和客户免受试图使用您品牌的发送身份的恶意行为者侵害的关键部分。在 Klaviyo 中发送电子邮件时需要考虑的主要基础设施组件如下：</p>
<p><strong><em>*品牌发送域</strong></em>*</p>
<p>连接[品牌发送域](https://help.klaviyo.com/hc/en-us/articles/115000357752) 是最佳做法，它允许您使用品牌的域名而不是共享的 Klaviyo 域来发送电子邮件。它还允许您在品牌自己的域上建立发送声誉，并限制使用相同共享域的其他公司对您的域声誉和送达率的任何负面影响。换句话说，您是唯一会从您的域发送邮件的人，从而影响您的声誉。此外，连接品牌发送域允许您利用电子邮件安全协议，例如 [DMARC](https://help.klaviyo.com/hc/en-us/articles/4402601857307)。邮件服务器使用这些协议来验证传入的电子邮件是否来自合法发件人，从而保护您的品牌和客户免受恶意行为者的侵害。除了防止网络钓鱼和欺骗尝试之外，实施这些协议还可以帮助提高投递能力，因为邮箱提供商将能够更轻松地验证您的发件人身份。 Klaviyo 建议所有客户设置品牌发送域，因为根域、发送域和友好发件人地址之间的记录对齐对于支持成功的收件箱放置至关重要。 Klaviyo 建议数据库大小超过 5000 个配置文件的帐户使用 DMARC 设置品牌发送域，以避免由于 [Yahoo 和 Gmail 的发件人要求](https://academy.klaviyo.com/2024-new-sender-requirements-checklist/1817230) 导致性能中断。详细了解[品牌发送域](https://help.klaviyo.com/hc/en-us/articles/115000357752) 以及如何为您的帐户设置一个。 <strong><em>*专用IP</strong></em>*</p>
<p>在 Klaviyo 中，您可以使用共享 IP 地址或您自己的[专用 IP](https://help.klaviyo.com/hc/en-us/articles/7675517826587) 发送电子邮件。从共享 IP 地址发送意味着您将与其他几个 Klaviyo 客户一起发送，并具有共享的发送信誉。如果您每月持续发送超过 1,000,000 封电子邮件，建议使用专用 IP。对于没有定期发送计划的小型发件人来说，共享 IP 更有效。使用专用 IP 地址的主要好处是，IP 地址的声誉只能受到使用该地址的单个帐户的影响。因此，您可以完全控制自己的发件人声誉。同样，您还可以完全控制发送量，并且不会受到共享 IP 和一年中繁忙时段潜在的发送量峰值的影响。并非每个 Klaviyo 帐户都有资格获得专用 IP。详细了解[专用 IP 地址](https://help.klaviyo.com/hc/en-us/articles/7675517826587) 以及如何为您的帐户设置一个（如果适用）。 <strong><em>*使用 SSL 点击跟踪域</strong></em>*</p>
<p>当 Klaviyo 用户发送带有链接的电子邮件时，该链接会通过 Klaviyo 的域来为您的电子邮件启用点击跟踪。默认情况下，Klaviyo 使用共享域进行点击跟踪，但最佳做法是设置[专用点击跟踪](https://help.klaviyo.com/hc/en-us/articles/7676795223707)。专用点击跟踪是有益的，因为它可以让您的客户进一步信任来自您品牌的电子邮件，因为链接很容易识别。当将鼠标悬停在您电子邮件中的链接上时，他们将看到您的品牌名称，而不是来自 Klaviyo 编码链接（即 <strong>trk.klaviyomail.com</strong> 或 <strong>trk.klclick.com</strong>）的一长串字母和数字。 这可以增加他们点击您的链接的机会。 ![将鼠标悬停在链接上时显示为 klaviyo 链接跟踪的电子邮件示例](https://klaviyo.zendesk.com/hc/article_attachments/28711702864539)</p>
<p>此外，许多邮箱提供商和过滤软件都会考虑您的消息传递中使用的所有域的声誉。在专用点击跟踪链接和发送域中使用相同的根域可以使您的品牌保持一致，并使您的发送看起来更值得收件箱提供商信任。详细了解[专用点击跟踪](https://help.klaviyo.com/hc/en-us/articles/7676795223707)。 <strong><em>*电子邮件验证</strong></em>*</p>
<p>“[电子邮件身份验证](https://help.klaviyo.com/hc/en-us/articles/4402601857307)”是指允许验证电子邮件发件人身份的技术标准。最常用的电子邮件身份验证标准是 SPF 和 DKIM。 DMARC 也是依赖于这些身份验证方法的常见安全协议。邮件服务器使用这些身份验证协议来验证传入的电子邮件是否来自合法发件人，从而保护您的品牌和客户免受恶意行为者的侵害。除了防止网络钓鱼和欺骗尝试之外，实施这些协议还可以帮助提高投递能力，因为邮箱提供商将能够确认发件人的身份。当您从共享发送域发送时，该域已设置 SPF 和 DKIM 记录。同样，当您设置品牌发送域时，Klaviyo 提供的 CNAME 或 NS 记录将满足 DKIM 和 SPF 要求。然而，设置 DMARC 既是交付能力的最佳实践，也是 Google 和 Yahoo 等某些收件箱提供商的要求。详细了解[电子邮件身份验证](https://help.klaviyo.com/hc/en-us/articles/4402601857307) 以及如何为您的域进行设置。 ## 列表获取</p>
<p>列表获取是指如何获得订阅者并留住订阅者。建立有价值的订阅者列表可以让您向对您的品牌和联系人真正感兴趣的收件人发送邮件，从而实现强大的送达性能。为了使您的列表获取策略取得成功，您应该遵循的最佳实践是：</p>
<p><strong><em>*避免购买清单</strong></em>*</p>
<p>购买列表不仅违反了 Klaviyo 的[可接受的使用政策](https://www.klaviyo.com/legal/acceptable-use-policy)，而且会导致联系人列表充满未参与的个人资料，这些个人资料不会与您的发送互动，并且更有可能将您的电子邮件标记为垃圾邮件。购买列表中的配置文件会对您的交付能力构成威胁，并且不太可能转化为客户。此外，请避免以下做法：</p>
<ul>
<li>租赁清单</li>
<li>电子邮件联属营销</li>
<li>第 3 方选择加入</li>
<li>发送到之前由于缺乏参与而被抑制的列表</li>
</ul>
<p><strong><em>*使用注册资源</strong></em>*</p>
<p>Klaviyo 的[注册表单](https://help.klaviyo.com/hc/en-us/articles/360026474752) 是有机获取新订阅者的好方法，这些订阅者已同意并明确表明他们有兴趣接收来自您品牌的信息。在开始构建注册表单之前，请考虑您的目标。表单可以帮助您与潜在客户建立联系，了解有关受众的更多信息，将电子邮件订阅者转换为短信订阅者等等。一个简单的弹出窗口收集那些访问过您的网站但从未订阅过的人的联系信息，这是一个很好的起点。此外，请确保：</p>
<ul>
<li>明确您的价值主张</li>
<li>尽量减少您使用的字段数量</li>
<li>让人们选择自己的兴趣</li>
<li>创建一个[欢迎系列](https://help.klaviyo.com/hc/en-us/articles/115002775172)来设定期望</li>
</ul>
<p>详细了解 [Klaviyo 注册表单入门](https://help.klaviyo.com/hc/en-us/articles/360026474752)。 <strong><em>*安全表格</strong></em>*</p>
<p>为了防止表单提交中的无效电子邮件堆积在您的列表中，最佳做法是在您的列表中启用 [double-opt](https://help.klaviyo.com/hc/en-us/articles/115005251108)。双重选择加入是新订阅者在订阅给定列表之前必须确认其订阅的过程。当您将注册表单添加到您的网站时，您无法控制谁决定利用此表单。即使您添加额外的验证级别，也并不总是能够确保订阅者仅提交有效或准确的电子邮件地址和电话号码。 善意的订阅者可能只是错误地输入了他们的电子邮件或电话号码，但垃圾邮件机器人也可能找到您的表单并用虚假的电子邮件地址或电话号码淹没它。了解如何在 Klaviyo 中启用[双重选择加入](https://help.klaviyo.com/hc/en-us/articles/115005251108)。 <strong><em>*培养新订阅者</strong></em>*</p>
<p>将潜在客户转化为订阅者后，重要的是要利用[欢迎流程](https://help.klaviyo.com/hc/en-us/articles/115002775172)，该流程最初将客户引入您的电子邮件营销计划并设定期望。包含折扣作为注册电子邮件的激励也是很常见的。除了电子邮件营销之外，培养与客户关系的一些方法包括：</p>
<ul>
<li>社交媒体广告</li>
<li>网站联盟营销</li>
<li>[重新吸引](https://help.klaviyo.com/hc/en-us/articles/115000931551)订阅者</li>
<li>通过博客提高搜索引擎排名</li>
</ul>
<p>这些方法可以帮助您在一致的电子邮件通信之外培养与客户的关系，并有助于增加客户生命周期的价值和长度。此外，考虑在客户生命周期的关键时刻发送个性化通信。 ## 变暖</p>
<p>预热是指引入新的或“冷”IP（即过去 30 天内未使用过发送电子邮件的 IP 地址）或新的或“冷”根域（即过去 30 天内注册过或从未用于发送电子邮件的域）的过程。升温期是您建立合法或“良好”电子邮件发件人声誉的时期。这是在新基础设施上发送时的一个重要过程，因为在基础设施预热之前发送过多电子邮件可能会导致送达问题。 <strong><em>*新客户预热</strong></em>*</p>
<p>作为 Klaviyo 的新客户，重要的是要经历[预热过程](https://help.klaviyo.com/hc/en-us/articles/360025945671)，让自己成为一个好的发件人并拥有良好的送达率。取暖时需要牢记的一些取暖最佳做法是：</p>
<ul>
<li>****慢慢开始****</li>
</ul>
<p>从少量邮件开始，然后随着时间的推移慢慢增加发送量。 - <strong><em>*持续发送</strong></em>*</p>
<p>定期发送电子邮件并维持日常电子邮件量，以保持域名“温暖”并更快地建立声誉<strong><em>*.</strong></em>*</p>
<ul>
<li>****首先向您最好的联系人发送电子邮件****</li>
</ul>
<p>变暖过程中的每一次积极参与都有利于发送者的声誉。专注于向最近使用电子邮件的联系人发送高质量的邮件，因为他们更有可能打开并单击以后的邮件。 - <strong><em>*密切监控</strong></em>*</p>
<p>在整个变暖过程中密切关注您的交付率表现，以快速识别参与度下降的情况，以便您可以根据需要进行调整。此外，加热时，请务必采取以下措施：</p>
<ul>
<li>暂停任何第三方联属营销</li>
<li>暂停高风险流程（例如日落流程、赢回流程、重新参与流程）</li>
<li>清理过时的订阅者列表并抑制未参与的配置文件。 - 仅创建并发送给参与的细分受众群</li>
<li>遵循[每日、每周、每月发送计划](https://help.klaviyo.com/hc/en-us/articles/360037527052)</li>
<li>删除/导入之前已退回、取消订阅或将电子邮件标记为垃圾邮件的配置文件的黑名单</li>
</ul>
<p>了解有关 Klaviyo 的[不同变暖过程](https://help.klaviyo.com/hc/en-us/articles/360025945671) 的更多信息。 <strong><em>*品牌变革升温</strong></em>*</p>
<p>重命名发送域后，预热您的发送基础设施是必需的步骤。即使您仍将使用相同的 Klaviyo 帐户，收件箱提供商也会将每个新域视为完全独立的实体。如果您不重新开始发送，您的送达能力将面临受损的风险。在更新您的域名之前，请查看我们的指南 [了解在 Klaviyo 中使用哪种加热过程](https://help.klaviyo.com/hc/en-us/articles/360025945671)，以确保您在更改实施后立即为加热过程做好准备。如果您要转移到新注册的域或使用 Klaviyo 发送时间不足 30 天，则需要预热您的基础设施。如果您是一个现有帐户，具有 30 天的发送历史记录并且之前曾在要转移到的新域上发送过邮件，则无需重新预热。 ## 监控交付能力</p>
<p>为了提高并保持良好的送达率，必须使用 Klaviyo 持续监控您的电子邮件性能。 这使您能够快速解决问题，避免持久的交付问题。最好的方法是监控您的营销活动和流量打开率、点击率、退回率和垃圾邮件率。有关如何执行此操作的完整信息，请参阅我们关于[如何监控送达率性能]的文章(https://help.klaviyo.com/hc/en-us/articles/115000201131)。 <strong><em>*收件箱</strong></em>*</p>
<p>Klaviyo 无法了解 Gmail 和 Yahoo 等收件箱提供商如何对电子邮件发送后进行排序。但是，有几个因素可以用来衡量您的营销活动是否进入收件人的主收件箱或垃圾邮件文件夹。需要关注的一些关键指标，包括与之前的活动相比的任何显着下降，包括：</p>
<ul>
<li>开放率</li>
<li>转化率</li>
<li>点击率</li>
</ul>
<p>如果您看到良好的参与率，那么客户很可能会在他们的主收件箱中收到您的电子邮件。然而，低参与率可能表明您的[电子邮件将成为垃圾邮件](https://help.klaviyo.com/hc/en-us/articles/12034571748251)。 <strong><em>*送货</strong></em>*</p>
<p>当电子邮件未成功送达或被收件人的收件箱提供商拒绝时，就会发生“退回”。如果您的帐户有大量退回邮件，这可能会对您的送达率和发件人声誉产生负面影响，并导致收件箱提供商将您的电子邮件发送到垃圾邮件而不是收件人的主收件箱。高退回率向收件箱提供商发出信号，表明发件人没有定期清理其列表或遵循递送最佳实践。留意跳出率的增加至关重要，这样您就可以在问题变得更大之前快速解决问题。退回邮件有两种类型：</p>
<ul>
<li>****硬退回****</li>
</ul>
<p>Klaviyo 将硬退回定义为由于地址无效而无法投递的电子邮件。这可能是由多种原因引起的，包括拼写错误的电子邮件。 Klaviyo 会自动抑制任何硬退回的电子邮件地址。 - <strong><em>*软弹跳</strong></em>*</p>
<p>软退回总是由临时原因引起，例如收件人的收件箱已满或其电子邮件服务器暂时关闭时。如果电子邮件连续 7 次软退回，Klaviyo 将禁止该地址。要监控退回率，您可以使用 Klaviyo 中的电子邮件送达中心。送达中心上的退回详细信息页面提供有关发送退回的原因的信息。如果您发现退回问题，您可以分析此数据以采取纠正措施并提高整体电子邮件送达率。在跳出详细信息部分，您可以看到以下数据：</p>
<ul>
<li>****热门反弹类别****</li>
</ul>
<p><strong>顶级退回邮件类别</strong>卡提供有关您遇到的退回邮件类型以及每个类别的退回数量的信息。 ![交付中心中的退回类别报告](https://klaviyo.zendesk.com/hc/article_attachments/28711702856219)</p>
<ul>
<li>****跳出报告****</li>
</ul>
<p><strong>退回报告</strong>卡显示您帐户中退回的进一步细目。 ![交付中心中的退回报告](https://klaviyo.zendesk.com/hc/article_attachments/28711731847451)</p>
<p>详细了解如何在 Klaviyo 中监控[跳出率](https://help.klaviyo.com/hc/en-us/articles/115005250408)。 <strong><em>*声誉</strong></em>*</p>
<p>发件人声誉是指您的品牌作为电子邮件发件人的可信度。收件箱提供商根据多个不同的权重因素确定您的发件人信誉，并在对客户收件箱中的电子邮件进行排序时考虑这一点。具有良好发件人信誉的发件人更有可能将其电子邮件送达客户的收件箱，而具有较差发件人信誉的发件人则可能会看到其电子邮件被放入垃圾邮件或根本没有送达。由于这些原因，保持良好的发件人声誉对于电子邮件营销和 Klaviyo 的成功至关重要。您可以使用 Klaviyo 送达中心中显示的分数来监控您在 Klaviyo 中的发件人声誉。 Klaviyo 中的送达中心允许您在帐户级别分析和诊断您的电子邮件和短信送达状况。 ![Klaviyo 送达中心的送达率分数](https://klaviyo.zendesk.com/hc/article_attachments/28711731858203)</p>
<p>详细了解[发件人信誉](https://help.klaviyo.com/hc/en-us/articles/15332906406171) 和[Klaviyo 的送达中心](https://help.klaviyo.com/hc/en-us/articles/18378819907995)。 <strong><em>*关键指标</strong></em>*</p>
<p>共同确定您的整体送达率绩效并显示您到达订阅者收件箱的成功程度的指标包括：</p>
<h3>打开率</h3>
<p>打开率是指有多少收件人打开了他们收到的电子邮件。无论您属于哪个行业，最佳做法都是保持至少 33% 的打开率。如果您发现打开率较低，则表明客户通常对您发送的内容不感兴趣，或者您发送给不太可能与您的电子邮件互动的未参与的联系人。为了帮助提高打开率，请尝试以下策略：</p>
<ul>
<li>创建参与细分</li>
<li>创建有针对性的主题行</li>
<li>定期清理你的清单</li>
<li>选择正确的发送时间</li>
<li>继续监控绩效</li>
</ul>
<p>详细了解如何[提高打开率](https://help.klaviyo.com/hc/en-us/articles/360042454031)，并查看有关这些关键步骤的更多详细信息。 ### 点击率</p>
<p>点击率是指有多少收件人实际点击了他们收到的电子邮件中的某个 URL。无论您属于哪个行业，最佳做法都是将点击率保持在至少 1%。如果您看到客户打开您的电子邮件，但无法点击，则表明客户可能没有任何点击动机，或者电子邮件设计无助于推动点击。为了帮助提高打开率，请尝试以下策略：</p>
<ul>
<li>使用细分来推动更好的个性化，并发送与不同受众相关的内容。 - 使用明确的号召性用语 (CTA)，以便收件人清楚他们应该点击的位置。 - 测试不同的号召性用语，以确定哪种最适合您的受众。 - 吸引收件人访问您的网站。 - 添加号召性用语 (CTA)，为在社交媒体上关注您或点击访问您的网站提供一些特别的内容。详细了解如何[提高点击率](https://help.klaviyo.com/hc/en-us/articles/360057459931)。 ### 跳出率</li>
</ul>
<p>当电子邮件未成功送达或被收件人的收件箱提供商拒绝时，就会发生[退回](https://help.klaviyo.com/hc/en-us/articles/115005250408)。如果您的帐户出现大量退回邮件，可能会对您的送达率产生负面影响。最佳做法是将跳出率保持在 1.0% 以下。电子邮件地址硬退回或软退回的可能原因有多种，包括：</p>
<ul>
<li>内容</li>
<li>消息长度</li>
<li>消息大小</li>
<li>频率或音量过高</li>
<li>声誉</li>
<li>地址无效</li>
<li>邮箱不可用</li>
<li>技术</li>
</ul>
<p>降低跳出率的一些关键策略包括：</p>
<ul>
<li>通过电子邮件发送真实的、经同意的个人资料</li>
<li>启用[双重选择加入](https://help.klaviyo.com/hc/en-us/articles/115005251108)</li>
<li>定期[清理你的列表](https://help.klaviyo.com/hc/en-us/articles/115005078347)</li>
<li>删除软弹跳的配置文件</li>
</ul>
<p>详细了解[降低退回率](https://help.klaviyo.com/hc/en-us/articles/360057036052) 和[电子邮件为何退回](https://help.klaviyo.com/hc/en-us/articles/115005250408)。 ### 退订率</p>
<p>取消订阅率是指有多少收件人在收到电子邮件后取消订阅您品牌的进一步消息。虽然为用户提供轻松取消订阅的机会很重要，但如果太多人取消订阅，收件箱提供商可能会将其视为危险信号。最佳做法是将取消订阅率保持在 0.3% 以下。如果您发现退订率升高，则表明客户可能由于缺乏价值或内容未达到他们的期望而对您的内容失去兴趣，或者他们收到了太多来自您品牌的电子邮件并不知所措。降低退订率的一些关键策略包括：</p>
<ul>
<li>在注册[欢迎系列](https://help.klaviyo.com/hc/en-us/articles/115002775172)时设定期望。 - 通过细分提供个性化内容。 - 提供优惠以外的价值（例如，与受众相关的教育内容或幽默）。详细了解如何[降低退订率](https://help.klaviyo.com/hc/en-us/articles/360057471831)。 ### 垃圾邮件投诉率</li>
</ul>
<p>垃圾邮件投诉率是指有多少人将您的消息举报为垃圾邮件。最佳做法是将垃圾邮件投诉率保持在 0.01% 以下。 如果您发现垃圾邮件投诉率上升，则表明客户可能由于缺乏价值和不符合他们的要求而对您的内容失去兴趣</p>
<p>期望，或者他们收到太多来自您品牌的电子邮件并不知所措。降低垃圾邮件投诉率的一些关键策略包括：</p>
<ul>
<li>使退订方法清晰易懂。 - 在注册时设定明确的期望，以便客户知道他们注册的目的。 - 当收件人停止参与时，降低发送频率。详细了解如何[降低垃圾邮件投诉率](https://help.klaviyo.com/hc/en-us/articles/360057985791)。 ## 测试</li>
</ul>
<p>测试您的内容是可交付性的重要组成部分，可以识别与内容相关的垃圾邮件触发器，并确定哪些内容最适合您的受众，以保持高参与率和良好的可交付性。 <strong><em>*内容测试</strong></em>*</p>
<p>当您排除所有其他因素或仅在特定邮件上发生并且没有其他人进行测试时，测试电子邮件内容是查找导致邮件进入垃圾邮件文件夹或被阻止的内容的最佳方法。了解如何[测试您的电子邮件内容以识别垃圾邮件触发器](https://help.klaviyo.com/hc/en-us/articles/25617578366491)。 <strong><em>*打开率和主题行测试</strong></em>*</p>
<p>主题行是客户在收件箱中看到的电子邮件的第一部分，可能是客户是否打开您的电子邮件的区别。测试不同的主题行以了解对打开率的影响是确定最适合不同受众的主题行的好方法。在 Klaviyo 中，您可以对[流电子邮件](https://help.klaviyo.com/hc/en-us/articles/6960371049115)和[营销活动](https://help.klaviyo.com/hc/en-us/articles/115005228148)使用A/B测试来测试不同的主题行并衡量其成功程度。 A/B 测试可以为您的受众提供有价值的洞察，而 Klaviyo 可以让您轻松确定在发送时应使用哪些主题行。您不仅会了解 A/B 测试的获胜变量，还会了解其他重要因素，例如获胜置信度百分比和获胜指标详细信息。了解如何进行 A/B 测试[流程电子邮件](https://help.klaviyo.com/hc/en-us/articles/6960371049115) 和[营销活动](https://help.klaviyo.com/hc/en-us/articles/115005228148)。 ## 发送</p>
<p>您的发送实践对于保持良好的送达率和良好的发件人声誉至关重要，从而使您能够进入客户收件箱。以下是与您的发送相关的一些对您的整体成功影响最大的关键要素：</p>
<p><strong><em>*阻止列表</strong></em>*</p>
<p>阻止列表是拒绝访问特定系统协议的项目列表，例如 IP 地址、域名、URL 或用户名。电子邮件阻止列表是实时数据库，它使用多个标准来确定 IP 是否正在发送被视为垃圾邮件的电子邮件。 IP 地址和域都有黑名单，可能会严重影响声誉和送达率。这也称为黑名单。根据特定的收件箱提供商，阻止列表可能会产生不同的送达率影响。例如，Gmail 不依赖黑名单，而是使用 Google 自己的系统来评估发件人信誉。然而，其他收件箱提供商可能会在较小程度上考虑 SpamHaus，以及 SORBS 和 SpamCop。主要收件箱提供商不依赖任何其他阻止列表，并且对送达率几乎没有影响。 Klaviyo 密切监控 SpamHaus 列表，因为这是对递送能力影响最大的黑名单。 SORB 和 SpamCop 也受到监控，但影响要小得多。 <strong><em>*垃圾邮件过滤</strong></em>*</p>
<p>Klaviyo 负责发送您的电子邮件，但一旦这些电子邮件落入收件箱提供商（即 Gmail 或 Yahoo）手中，这些邮件就会根据每个提供商的规则进行过滤。所有收件箱提供商都有一个内置系统，可以扫描传入的电子邮件，并使用不公开的复杂算法自动对它们进行排序。遵循电子邮件送达最佳实践对于收件箱提供商将您的电子邮件分类到收件人的主收件箱而不是垃圾邮件文件夹中至关重要。发送到垃圾邮件的电子邮件极不可能被收件人查看，并且可能会对您的收入和 Klaviyo 的成功产生负面影响。如果您发现电子邮件成为垃圾邮件，请参阅我们的指南[排查电子邮件成为垃圾邮件的原因](https://help.klaviyo.com/hc/en-us/articles/12034571748251)。 <strong><em>*收件箱文件夹</strong></em>*</p>
<p>通过 [Gmail 的选项卡式收件箱](https://help.klaviyo.com/hc/en-us/articles/115005078307)，电子邮件可以进入以下任何选项卡：<strong>主要</strong>、<strong>社交</strong>、<strong>促销</strong>、<strong>更新</strong>或<strong>论坛</strong>。 Gmail 的算法旨在让用户更轻松地对原本拥挤的收件箱进行分类，因此重要的电子邮件具有很高的可见性。对于电子邮件营销人员来说，如果 Gmail 开始将您的电子邮件分类到可能会被忽略的选项卡中，这可能会出现问题。关于该主题的[完成的研究](https://returnpath.com/wp-content/uploads/2015/02/Return_Path_-_The_Tabbed_Inbox.pdf) 显示，登陆 <strong>促销</strong> 选项卡的营销电子邮件的打开率并未经历快速下降，并且可观察到的变化很小。事实上，营销人员的处境甚至可能会更好，因为现在在“促销”选项卡中找到安全位置的电子邮件可能会在 Gmail 的选项卡式收件箱之前被阻止或过滤到垃圾邮件文件夹中。 Gmail 用户自己可以通过将电子邮件从一个选项卡移动到另一个选项卡并选择让 Google 始终将来自特定发件人的邮件放在他们选择的选项卡中来更改默认排序系统。如果这对您很重要，您可以通过要求受众将您的新闻通讯拖到他们的<strong>主要</strong>选项卡上来吸引他们，以便轻松访问您的品牌信息。但是，您无法预先确定您的邮件将落入哪个选项卡，并且 Klaviyo 无法控制电子邮件成功发送后收件箱的放置位置。通常，如果电子邮件是个性化的，它们将自动排序在主收件箱中。较少的个性化电子邮件往往最终出现在“促销”选项卡中。 Gmail 的 <strong>促销</strong> 选项卡真正旨在捕获营销电子邮件，因此请考虑以下事项：</p>
<ul>
<li>****注意文本与图像的比例****</li>
</ul>
<p>采用以图像为主的电子邮件设计方法可能会影响收件箱的放置。垃圾邮件过滤器也会对主要由图像组成的电子邮件产生怀疑。 - <strong><em>*避免过度使用链接</strong></em>*</p>
<p>避免电子邮件中出现太多链接，并确保没有链接损坏。 - <strong><em>*个性化</strong></em>*</p>
<p>Klaviyo 可以轻松个性化您的电子邮件。例如，如果您的档案中没有姓名，则可以在电子邮件中插入名字并作为后备。虽然无法查看您的电子邮件将发送到哪个选项卡，但 [Litmus](https://www.litmus.com/) 等第三方工具也可以帮助进行测试。 <strong><em>*交易与营销</strong></em>*</p>
<p><a href="https://help.klaviyo.com/hc/en-us/articles/360003165732">交易电子邮件</a></p>
<ul>
<li>订单确认</li>
<li>发货确认</li>
<li>帐户创建确认</li>
</ul>
<p>不被视为交易电子邮件的触发电子邮件包括：</p>
<ul>
<li>欢迎系列</li>
<li>废弃的购物车</li>
<li>补货通知</li>
</ul>
<p>营销电子邮件和交易电子邮件之间的另一个关键区别是，交易电子邮件与某人是否订阅无关。即使客户取消订阅营销电子邮件，他们仍然希望收到有关订单或管理帐户活动的交易消息。因此，在 Klaviyo 中标记为事务性的电子邮件仍会发送给被抑制的收件人。详细了解 Klaviyo 中的[事务性电子邮件](https://help.klaviyo.com/hc/en-us/articles/360003165732)。 <strong><em>*垃圾邮件陷阱</strong></em>*</p>
<p><a href="https://help.klaviyo.com/hc/en-us/articles/360015537111">垃圾邮件陷阱</a></p>
<p>列表卫生是良好送达率的关键，因为它可以确保您的电子邮件列表由活跃、参与的配置文件组成，这些配置文件更有可能与您的发送内容进行交互。这最终会带来良好的发件人声誉，使收件箱提供商更有可能将您视为良好的发件人，并将您的电子邮件分类到主收件箱而不是垃圾邮件。 <strong><em>*再婚系列</strong></em>*</p>
<p>重新吸引您的订阅者，如果重新吸引失败，删除这些订阅者是电子邮件计划成功的关键因素。确保为客户继续提供令人信服的理由，并执行以下最佳实践：</p>
<ul>
<li>突出优点</li>
<li>包括推荐</li>
<li>提供更改电子邮件地址的机会</li>
<li>体现您的品牌个性</li>
</ul>
<p>同样，您可以在 Klaviyo 中创建[赢回流程](https://help.klaviyo.com/hc/en-us/articles/115002775192)，以培育超出正常购买周期的客户。详细了解如何在 Klaviyo 中开展[重新参与活动](https://help.klaviyo.com/hc/en-us/articles/115000931551)。 <strong><em>*夕阳西下</strong></em>*</p>
<p>日落流程旨在逐步淘汰不再与您的品牌互动的客户。您可以使用此流程作为赢回业务的最后努力，然后删除或压制任何不响应的人。这将帮助您维护一个干净的列表，并避免不活跃的客户为您的 Klaviyo 计费计划做出贡献，最终最大限度地提高您从活跃配置文件中获得的价值。了解如何在 Klaviyo 中[创建日落流](https://help.klaviyo.com/hc/en-us/articles/360017518492)。 <strong><em>*基于参与的频率发送</strong></em>*</p>
<p>使用基于电子邮件参与度的发送计划是实现高打开率并与订阅者保持积极关系的关键。过于频繁地向未参与的客户发送信息会损害您的发件人声誉，而过于频繁地向参与的客户发送则会浪费金钱。最好通过使用分段和发送时间表来实现快乐的媒介。建立跟踪后，开始发送有针对性且非常适合细分群体特定电子邮件习惯的营销活动。您可以选择同时向打开智能发送功能的所有分段发送电子邮件营销活动，也可以向每个分段发送单独的营销活动。如果您选择后者，这将使您能够直观地看到您从每个营销活动以及每个参与轨道中赚了多少钱。了解如何[根据参与度和频率创建发送计划](https://help.klaviyo.com/hc/en-us/articles/360037527052)。 <strong><em>*数据质量</strong></em>*</p>
<p>数据质量是确保您帐户上的数据准确、完整和可靠。数据质量对于确保使用此类数据的任何决策过程的准确性至关重要。维护帐户的高质量数据具有以下好处：</p>
<ul>
<li>避免因数据不准确（重复消息等）引起的问题</li>
<li>帮助您接触更多人（在正确的时间接触以避免倦怠）</li>
<li>帮助您接触到合适的人（向您的订阅者提供相关信息）</li>
<li>改善客户关系（高质量数据可帮助您了解订阅者的需求）</li>
</ul>
