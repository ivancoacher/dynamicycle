<h1>如何使用退货和换货技能</h1>

<h2>你将会学到</h2>
<p>退货和换货技能如何让客户代理指导购物者自动处理退货和换货请求。当您的先决条件满足后，代理会回答政策问题，检查订单资格，并将客户直接深层链接到您的退货门户。这减少了支持请求数量，提高了解决率，并提供更快的售后体验，从而提高了 CSAT。 ## 开始之前</p>
<p>在使用退货和换货技能之前，您需要满足以下条件：</p>
<ul>
<li>****客户代理****在您的帐户上启用。 - ****客户中心**** 已激活并已配置。 - 通过客户中心集成的****互联退货提供商****（例如 Loop 或 Aftership）。 - ****有关退货和换货政策的知识库内容****已上传到客户代理内容。 - 为客户代理配置至少一个活动渠道（****网络聊天****、****测试消息****、****电子邮件****或****WhatsApp****）。 ****注意：**** 如果没有客户中心或连接的退货提供商，代理会搜索您上传的有关退货政策的内容。 ## 概述</li>
</ul>
<p>退货和换货技能使客户代理能够处理最常见的售后支持请求，而无需人工干预。当顾客询问退货、换货或退款时，代理商：</p>
<p>1. 搜索您的内容以获取退货和换货政策答案。 2. 对客户进行身份验证并检索他们的个人资料。 3. 检查订单状态以确认资格。 4. 提供直接链接或操作卡，以便客户可以在连接的退货门户中开始退货或换货。 <strong><em>*什么时候使用这个技能</strong></em>*</p>
<p>如果您的品牌收到大量退货和换货查询，并且您希望：</p>
<ul>
<li>转移来自支持团队的重复票证。 - 让客户能够 24/7 即时访问退货和换货工作流程。 - 通过消除问题和行动之间的摩擦来提高解决率。 ****如何按渠道运作****</li>
<li>****网络聊天：**** 代理会显示一张订单卡，其中带有****开始退货****按钮，该按钮深层链接到退货门户。 - ****短信和 WhatsApp：**** 代理通过客户中心发送至退货门户的深层链接。 - ****电子邮件：**** 代理通过客户中心发送至退货门户的深层链接。 ## 设置</li>
</ul>
<h3>第 1 步：验证先决条件</h3>
<p>1. 确认您的帐户已启用客户代理。 2. 导航至<strong><em>*客户中心</strong></em>*并确认其处于活动状态。 3. 确认客户中心已连接退货提供商（例如 Loop 或 Aftership）。 ### 第 2 步：上传退换货政策内容</p>
<p>1. 导航至<strong><em>*客户代理 > 内容</strong><strong>。 2. 单击</strong><strong>添加内容</strong><strong>。 3. 上传或输入您的退货和换货政策。包括退货窗口、符合条件的商品、换货流程和退款时间表等详细信息。 4. 注意：如果此信息已在您的网站上，则代理可能已经可以访问它。您可以通过在</strong><strong>代理预览</strong><strong>选项卡中提问来进行验证。 5. 单击</strong><strong>保存</strong></em>*。有关详细指南，请参阅[如何管理客户代理内容](https://help.klaviyo.com/hc/en-us/articles/37659457059739)。 ### 第 3 步：确认技能已激活</p>
<p>1. 导航至<strong><em>*客户代理 > 技能</strong><strong>。 2. 在技能列表中找到</strong><strong>退货和换货</strong><strong>技能。当满足您的先决条件时，它默认处于活动状态。 3. 确认状态显示</strong><strong>Live</strong><strong>。如果显示</strong><strong>不可用</strong></em>*，请检查客户中心是否处于活动状态并且退货提供商是否已连接。 ![](https://klaviyo.zendesk.com/hc/article_attachments/46881389434779)</p>
<h3>第 4 步：查看技能详细信息</h3>
<p>1. 点击<strong><em>*退换货</strong></em>*技能，打开其详细信息页面。 2. 查看概述、响应行为和连接的工具。 ![](https://klaviyo.zendesk.com/hc/article_attachments/46881389437211)</p>
<h3>第 5 步：测试体验</h3>
<p>1. 导航至<strong><em>*代理预览</strong></em>*选项卡以测试您的客户代理。 2. 提出与退货相关的问题，例如“如何开始退货？”或“你们的退货政策是什么？”</p>
<p>3. 验证代理是否响应策略信息，并在身份验证后出示订单卡或深层链接。 ## 最佳实践</p>
<ul>
<li>****保持您的退货政策内容最新。**** 代理直接从您的知识库中提取答案。过时的内容会导致错误的响应并削弱客户的信任。 - ****在您的知识库中包含边缘案例。**** 添加涵盖不可退货商品、最终销售类别和国际退货程序的内容，以便代理商可以在无需交接的情况下处理这些问题。 - ****设定明确的退货期限期望。**** 在保单内容中指定确切的退货期限（例如，自交货后 30 天），以便代理能够准确确定资格。 - ****深思熟虑地配置移交消息。**** 当代理无法完成请求时（例如，没有连接退货提供商），精心编写的移交消息可以让客户放心，人工代理会跟进。 - ****每周监控解决率。**** 解决率下降可能表明策略内容存在差距或配置问题。检查您的知识库，如果发现下降，请返回提供商连接。 - ****同时使用网络聊天和短信渠道。**** 启用这两个渠道可以最大限度地扩大覆盖范围，并让客户可以使用他们喜欢的任何渠道。 ## 故障排除</li>
</ul>
<p><strong><em>*症状：</strong><strong> 座席立即将工作交给人工座席，而不是回答返回问题。 </strong><strong>可能的原因：</strong><strong> 客户中心未激活或未连接退货提供商。 </strong><strong>修复：</strong><strong> 导航至 </strong><strong>客户中心</strong><strong> 并确认其与连接的退货提供商（例如 Loop 或 Aftership）处于活动状态。如果客户中心不可用，客服人员将始终执行软切换。 </strong><strong>症状：</strong><strong> 代理无法访问客户的订单详细信息。 </strong><strong>可能原因：</strong><strong> 客户未登录，或未配置登录流程。 </strong><strong>修复：</strong><strong> 确认客户中心登录已启用。代理会提示客户先登录，然后再访问特定于订单的信息。如果未出现提示，请检查您的客户中心身份验证设置。 </strong><strong>症状：</strong><strong> 代理商说该订单不符合退货条件，但客户认为应该退货。 </strong><strong>可能的原因：</strong><strong> 订单超出了退货提供商中配置的退货范围，或者商品类别被排除。 </strong><strong>修复：</strong><strong> 检查退货提供商仪表板中的订单以确认资格。如果政策已更改，请在</strong><strong>客户代理 > 内容</strong><strong>中更新您的退货政策内容。代理使用知识库和订单状态来确定资格。 </strong><strong>症状：</strong><strong> 代理确认资格后，不会出现“开始退货”按钮或深层链接。 </strong><strong>可能的原因：</strong><strong> 退货提供商集成可能配置错误，或者无法根据客户的个人资料验证订单 ID。 </strong><strong>修复：</strong><strong> 验证客户中心中的退货提供商连接。确认 Shopify 订单数据正确同步。使用已知的有效顺序进行测试。 </strong><strong>症状：</strong><strong> 代理提供了不正确的策略信息。 </strong><strong>可能的原因：</strong><strong> 知识库内容已过时或缺少关键政策详细信息。 </strong><strong>修复：</strong><strong> 导航至 </strong><strong>客户代理 > 内容</strong></em>* 并更新您的退货和换货政策文件。代理只能根据您的知识库中的内容进行回答。 ## 常见问题解答</p>
<p><strong><em>*代理是否直接处理退货？</strong><strong> 不。代理通过提供直接链接和操作卡引导客户访问您的退货门户。实际的退货或换货是通过您连接的退货提供商（例如 Loop 或 Aftership）进行处理的。 </strong><strong>如果客户询问退款状态，会发生什么？</strong><strong> 退款状态查询将路由至退货和换货技能。代理检查连接系统中的订单和退货状态，并向客户提供最新信息。 </strong><strong>我可以在没有客户中心的情况下使用此技能吗？</strong><strong> 该技能在没有客户中心的情况下也可用，但它在有限的模式下运行。如果没有客户中心，代理会共享您知识库中的策略信息，然后执行软移交给人工代理以执行任何特定于帐户的操作。 </strong><strong>支持哪些退货提供商？</strong><strong> 客户中心支持 Loop 和 Aftership 作为退货提供商。通过客户中心连接您的提供商，以启用完整的自助服务退货流程。 </strong><strong>在此过程中客户的数据安全吗？</strong><strong> 是的。在代理访问任何特定于订单的信息之前，客户必须进行身份验证。订单 ID 会根据客户的个人资料进行验证，以防止未经授权的访问。 </strong><strong>此技能适用于所有渠道吗？</strong></em>* 退货和换货技能可通过网络聊天和短信使用。在网络聊天中，客服人员会显示带有操作按钮的订单卡。 通过短信，代理会发送一个指向退货门户的深层链接。 ## 后续步骤</p>
