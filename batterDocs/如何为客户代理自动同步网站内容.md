<h1>如何为客户代理自动同步网站内容</h1>

<h2>你将会学到</h2>
<p>您将了解如何为客户代理连接的网站启用自动重新索引（自动同步）。通过自动化此过程，您可以确保您的代理始终使用您网站上有关您的产品和政策的最新信息来回答问题，从而减少刷新知识库的手动工作，并避免因过时的答案而导致的支持请求。 ## 开始之前</p>
<ul>
<li>****先决条件：**** 您必须启用 ****客户代理**** 功能，并且至少将一个网站源添加到您的代理内容中。 - ****可用性：**** 此功能仅适用于****付费客户代理订阅者****。它不适用于试用或免费计划。 - ****角色：**** 您必须拥有 ****所有者****、****管理员**** 或 ****经理**** 权限才能管理代理内容。 - ****完成时间：**** ~2 分钟。 - ****重要提示：**** 自动同步会定期进行（大约每天一次）。对于即时更新（例如，10 分钟内启动限时抢购），您仍应执行手动重新索引。 ## 概述</li>
</ul>
<p>客户代理使用您上传的内容来准确回答客户的询问。以前，如果您添加了新产品或更改了退货政策，则必须手动触发“重新索引”，以便代理了解该信息。通过<strong><em>*自动同步</strong></em>*，Klaviyo 会定期抓取您连接的网站以检测更改。如果发现新页面或更新现有内容，代理会自动摄取这些更改。这种“一劳永逸”的功能对于经常添加新库存的高速商店来说是理想的选择。 ## 设置</p>
<p>1. 在主导航中选择<strong><em>*服务 > 客户代理</strong><strong>。 2. 单击</strong><strong>内容</strong><strong>选项卡。 3. 在表中找到</strong><strong>网站</strong><strong>内容类型。 4. 找到您想要保持更新的特定 URL（例如，您的店面或常见问题解答页面）。 5. 检查</strong><strong>自动同步</strong><strong> 设置为</strong><strong>开</strong></em>*。 ![](https://klaviyo.zendesk.com/hc/article_attachments/45985082500251)</p>
<p>6. <strong><em>*预期结果：</strong><strong> 系统现在将对此站点进行排队以进行定期抓取。可能会出现一个状态指示器，显示自动同步已激活。 </strong><strong>提示：</strong><strong> 默认情况下，您的主店面 URL 可能已切换为</strong><strong>开启</strong></em>*。检查您的设置以确保所有所需的子页面也已启用。 ## 最佳实践</p>
<ul>
<li>****针对高流量页面启用：**** 始终为您的主店面和“新品到货”页面启用自动同步，以捕获库存变化。 - ****监控“上次更新”日期：**** 使用内容表中的****上次更新****列来验证爬网程序上次刷新数据的时间。 - ****与手动索引结合：**** 自动同步定期运行。如果您在黑色星期五之前对运输政策进行了重要更新，请触发****手动重新索引****以立即生效。 - ****排除静态存档：**** 如果您已存档的博客页面永不更改，则可以保留自动同步****关闭****，以优先考虑活动页面的爬网带宽。 ## 衡量成功</li>
</ul>
<ul>
<li>****需要关注的关键指标：****</li>
<li>****上次更新时间戳：**** 确保这是最近的（最近 3-4 天内）。 - ****解决率：**** 监控代理是否成功回答有关新产品的问题。 - ****如果代理提供过时的答案：****</li>
</ul>
<p>1. 检查“<strong><em>*上次更新</strong><strong>”列中的源 URL。 2. 如果该日期早于您最近的站点更改，请手动单击</strong><strong>刷新</strong></em>*按钮。 ## 故障排除</p>
<p><strong><em>*症状：</strong><strong> 代理不知道我今天早上添加的产品。 </strong><strong>可能的原因：</strong><strong> 自动同步计划（大约每天）尚未运行。 </strong><strong>修复：</strong><strong> 手动单击网站 URL 旁边的</strong><strong>刷新</strong><strong> 以立即更新。 </strong><strong>症状：</strong><strong> 我无法打开“自动同步”（该开关呈灰色）。 </strong><strong>可能的原因：</strong><strong> 您正在使用试用计划。 </strong><strong>修复：</strong><strong> 升级到付费客户代理订阅以解锁自动重新索引。 </strong><strong>症状：</strong><strong>“最后更新”日期更改，但内容未更新。 </strong><strong>可能的原因：</strong><strong> 爬虫检测到页面上的内容与以前的版本相同，并跳过重新嵌入以节省处理时间。 </strong><strong>修复：</strong></em>* 验证您在网站上发布了更改，然后等待下一个周期或手动重新索引。 ## 常见问题解答</p>
<p><strong><em>*问：</strong><strong> 自动同步每次都会抓取我的整个网站吗？ </strong><strong>答：</strong><strong> 没有。 系统使用您的站点地图和“上次抓取”数据来仅识别已更改或新的页面。这确保了高效的处理。 </strong><strong>问：</strong><strong> 我可以关闭特定页面的自动同步吗？ </strong><strong>答：</strong><strong> 是的。该切换可在内容表中的每个网站/每个页面上使用。 </strong><strong>问：</strong><strong> 此功能适用于上传的 PDF 文件吗？ </strong><strong>答：</strong><strong> 否。自动重新索引当前仅适用于</strong><strong>网站</strong></em>*（“ENTIRE_SITE”和“SINGLE_PAGE”）。文件和文本片段必须手动更新。 ## 合规性和数据处理</p>
<p>启用自动同步后，即表示您授权 Klaviyo 定期抓取所提供 URL 的面向公众的内容。确保您网站的“robots.txt”文件不会阻止 Klaviyo 的爬虫，因为这会阻止更新。 <strong><em>*此信息不是法律建议。请咨询您的法律顾问以获取有关适用法律的指导。</strong></em>*</p>
