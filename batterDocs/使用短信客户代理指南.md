<h1>使用短信客户代理指南</h1>

<h2>简介</h2>
<p><strong><em>*什么是短信客户代理？</strong></em>*</p>
<ul>
<li>24/7 人工智能助手，可响应入站短信来回答问题、推荐产品并解决常见问题</li>
<li>支持收入驱动和服务用例（产品推荐、WISMO、常见问题解答）</li>
</ul>
<p><strong><em>*为什么在短信上使用客户代理？</strong></em>*</p>
<ul>
<li>通过短信回复增加收入</li>
<li>自动解决重复的支持问题</li>
<li>减少工单数量，同时提高响应速度</li>
<li>提供 24/7 协助</li>
</ul>
<h2>开始之前</h2>
<h3>要求</h3>
<ul>
<li>有效的短信计划</li>
<li>推荐 Shopify 提供完整功能（订单跟踪、推荐）</li>
<li>注意：SHAFT 品牌无法通过短信激活客户代理</li>
</ul>
<h3>它处理什么消息？</h3>
<p>客户代理将响应入站消息，除非：</p>
<ul>
<li>匹配合规性关键字（停止、帮助等）</li>
<li>触发订阅/取消订阅逻辑（关键字、取消订阅意图）</li>
<li>触发短信关键字自动化</li>
</ul>
<h3>如果代理无法解决问题会怎样？</h3>
<ul>
<li>遵循切换设置</li>
<li>如果您选择升级到帮助台，收到票证的客服人员将收到客户客服人员对话的记录</li>
<li>如果您选择不升级到帮助台，您将配置在客服人员无法解决客户需求时发送的结束消息</li>
</ul>
<h3>内置 Guardrails 来控制 SMS 成本</h3>
<ul>
<li>垃圾邮件或噪音消息将被忽略。例如，诸如“我正在驾驶时焦点打开”之类的自动回复消息不会触发客户代理对话。</li>
<li>客户代理尝试尽可能限制对单个短信段的响应</li>
<li>当客户代理无法解决客户的问题时，它会升级而不是发送过多的消息</li>
</ul>

<h2>通过短信客户代理增加收入的最佳实践</h2>
<h3>1. 在您的活动和流程中主动邀请回复</h3>
<p>客户代理仅在客户回复时才起作用。</p>
<p>鼓励回复：</p>
<ul>
<li>废弃的购物车消息（例如尺码、退货、款式问题）</li>
<li>欢迎系列（例如颜色匹配、个性化输入）</li>
</ul>
<p>包括：</p>
<ul>
<li>明确的邀请（“回答问题”）</li>
<li>基于漏斗摩擦的上下文特定提示</li>
</ul>
<p>在“设置”>“营销”中保存客服人员对话开头。您可以一键将此提示添加到流程和营销活动中。</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/47313754403867" alt="" />
<h3>2. 控制哪些配置文件可以与客户代理交互</h3>
<p>你有3个选择：</p>
<ul>
<li>您可以让所有个人资料与客户代理互动</li>
<li>您可以让客户代理专门针对特定细分市场，或排除某些细分市场</li>
<li>适合：将客户代理作为 VIP 专用功能进行操作（例如个人礼宾服务）</li>
<li>您可以要求某些关键字来启动客户代理对话，或排除某些关键字</li>
<li>适合：指导客户代理查询（例如“回复我的个性化推荐”）</li>
<li>好处：确保某些查询直接发送到您的服务台</li>
</ul>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/47313694679195" alt="" />
<h3>3. 一起规划短信+代理的使用</h3>
<p>客户代理消耗：</p>
<ul>
<li>人工智能对话（按每次对话定价）</li>
<li>SMS 段（适用标准 SMS 计费）</li>
</ul>
<p>最佳实践：</p>
<ul>
<li>确保 SMS 计划限制超出预期的代理使用量</li>
<li>考虑启用 Flex 或 AutoUpgrade 以避免限制</li>
</ul>
<h3>4. 衡量绩效并识别参与的客户</h3>
<ul>
<li>通过转到“性能”页面并按渠道过滤“关键指标”来监控 SMS 性能</li>
<li>注意：短信收入归因遵循账户的短信归因模型设置</li>
<li>通过创建细分来识别并重新定位与客户代理互动的个人资料</li>
<li>使用“某人做了什么”构建一个细分</li>
<li>选择：已解决的客户代理对话、升级的客户代理对话、已开始的客户代理对话</li>
</ul>
