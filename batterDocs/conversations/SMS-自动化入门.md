##### ****您将学习到****

了解 Klaviyo 中的自动化功能，您可以利用它与您的 SMS 订阅者创建自动化的 1 对 1 对话。自动化功能让您可以轻松地提出问题、识别回复，并为您的客户提供个性化的建议。

通过构建自动化，您可以：

- 创建调查以收集客户反馈。
- 构建购物指南以提供个性化推荐。
- 开展测验以深入了解订阅者并收集个人资料属性。

##### ****开始之前****

请注意以下事项：

- 在使用自动化之前，您必须先设置好 SMS。
- 自动化仅回复 SMS 订阅者。
- SMS 自动化不适用于品牌发件人 ID (Branded Sender IDs)，因为此类号码类型无法接收短信。
- 您的出站 SMS 消息将消耗计费套餐中的额度。入站 SMS（即发送给您品牌的短信）不消耗额度。

每个自动化必须至少包含：

- 1 条消息。
- 或 1 个推荐（且其前置有相关问题）。

##### ****Flows 与会话自动化的对比****

在这两种情况下，这些功能都作为自动触点供您与客户沟通，并可用于：

- 创建自定义消息
- 针对触发关键词和选项收集个人资料属性 (Profile properties)
- 自动化沟通

它们之间的主要区别如下表所示：

|  |  |  |
| --- | --- | --- |
|  | ****Flows**** | ****Conversations**** |
| ****触发器 (Trigger)**** | 可由客户在您网站上的行为、分众 (Segments) 和列表 (Lists)、日期等触发。 | 仅当有人发送特定词汇的消息时触发。 |
| ****消息类型**** | 任何渠道（邮件、****SMS****、移动端推送） | 仅限 ****SMS**** |
| ****响应时机**** | 无法等待回复，消息始终立即发送或在设定时间段后发送。 | 等待订阅者的短信中包含已识别的答案。 |

这意味着 Flows 更适合在客户旅程的关键时刻（如通过欢迎消息、弃单提醒、售后跟进）主动触达订阅者。

而对于自动化，它们更擅长处理来回对话、提出问题并根据反馈提供后续建议。

##### ****自动化示例：调查****

##### ****自动化的核心术语与设置****

###### 自动化功能

在设置自动化时，您必须包含以下一项或多项内容：

- Trigger keyword(s)：订阅者通过短信发送以进入自动化的单词或短语。一个自动化可以有多个触发关键词。这些关键词必须是唯一的，同一个单词不能用于多个自动化，也不能是合规词或订阅关键词。
- Question(s)：您在自动化流程中发送的包含问题的 SMS。每个问题必须包含 2 个或更多选项。如果包含推荐，则每个自动化至少需要 1 个问题。
- Choice(s)：供订阅者回答问题的选项。选项始终带有编号，订阅者可以回复选项单词/短语或其对应的数字。每个问题至少必须有 2 个选项。
- Message：在自动化结束时发送的 SMS。发送此类消息不需要在此之前设置问题。
- Recommendation：在自动化结束时发送的 SMS。如果使用此项，您必须在自动化末尾至少包含 1 个推荐。

##### ****自动化设置****

自动化具有以下核心设置：

- Reprompt response：当订阅者处于自动化流程中，但发送了无法与任何选项匹配的入站短信时，系统发送的回复。
- Fallback response：当有人达到最大重新提示次数或达到最大超时限制时发送的消息。
- Maximum number of reprompts：当订阅者发送的入站 SMS 不包含已识别的选项时，Klaviyo 尝试重新与其互动的次数。默认设置为 1 次。如果订阅者达到此上限后再次发送无法识别的选项，他们将退出自动化并收到后备回复。
- Maximum timeout（以小时为单位) ：自动化的会话时间，即自动化的激活时长。默认会话时间设置为 24 小时。计时从某人发送触发关键词并收到第一条消息时开始。当某人收到后续消息时，时间不会重置。如果有人在收到推荐之前达到了最大超时时间，他们将退出自动化。

##### ****自动化如何运行****

其运行方式如下：

- 有人向您发送了该自动化的触发关键词。

- 如果他们是 SMS 订阅者，则会收到自动化中的第一条消息。非 SMS 订阅者将收到您 SMS 设置中配置的自动回复消息。

- 如果订阅者回复了已识别的选项，他们将进入下一个问题或消息。如果回答未被识别，他们将收到重新提示消息。

当发生以下任何一种情况时，订阅者将退出自动化：

- 订阅者收到了推荐。
- 订阅者收到了消息。
- 订阅者达到了最大重新提示回复次数，随后收到了后备回复。
- 订阅者达到了最大超时时间。
- 当某人处于一个自动化流程中时，在退出之前，他们无法进入任何其他自动化。

##### 触发自动化

触发类型共有 2 种：

- Always on：这意味着任何时候只要有人发送触发关键词，该用户就会进入自动化流程。
- Message response：选择此选项时，您必须指定一个Campaign或Flow消息。用户必须在设定的时间范围内收到过所选消息，并且发送了触发关键词，才能进入该自动化。

![一张显示两个按钮的界面，分别标注为 'Always on' 和 'Message response'，指示触发设置在自动化流程中的作用。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-146.png?resize=898%2C368&ssl=1)

这两种触发类型的主要区别在于：用户是可以在其客户旅程的任何时间点进入，还是仅在收到另一条特定消息后才能进入。

例如，“Always on”更适用于自动化充当支持工具、常设测验或调查等场景。在这种情况下，您可以根据常用的短信词汇来设置触发关键词，或者在某个弹窗中、您的店内等位置展示该关键词。

另一方面，“Message response”更适用于您希望将Campaign或Flow的接收者引向某个自动化的场景。假设您只想调查那些最近收到过“Welcome flow”第二条消息的用户，在这种情况下，您可以在第二条消息中加入触发关键词，并将自动化设置为仅发送给最近收到过该消息的用户。

![Klaviyo SMS 自动化设置界面，显示消息响应类型的选项，包括从 Campaign 或 Flow 中回复的选择菜单。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-147.png?resize=906%2C428&ssl=1)

##### 触发关键词 (Trigger keywords)

当 SMS 订阅者发送触发关键词时，他们会进入自动化流程。每个自动化可以设置多个触发关键词。

请注意，触发关键词：

- 必须包含 3 个或更多字符。
- 允许使用表情符号（Emojis）。
- 不区分大小写。
- 只有当订阅者的入站短信与触发关键词完全匹配时才会被识别。
- 默认情况下无法识别拼写错误或缩写。
- 可以是一个短语。
- 可以是一个单词。
- 在每个自动化中必须是唯一的（即：您不能在多个自动化中使用相同的关键词）。
- 不能与订阅关键词或合规关键词（如：STOP、JOIN）关联。

以我们的宠物示例为例，假设我们使用了两个独立的触发器，如下表所示：

|  |  |  |
| --- | --- | --- |
| 触发关键词 | 可识别的输入 | 无法识别的输入 |
| Survey | SURVEY, survey | Usrvey (拼写错误) |
| Pets | Pets | Pet (少字符) |

##### 问题、消息与推荐

在任何自动化中都有 3 种选项，它们均为出站 SMS 消息：

- 问题 (Questions)
- 消息 (Message)
- 推荐 (Recommendation)

所有自动化都要求至少包含 1 条“消息”，或者 1 个“推荐”（且推荐之前必须带有“问题”）。

您可以在消息和推荐中使用模板标签（例如：first name）或 JSON，但请注意，这些标签和代码在预览中不可见。如果您想使用它们，请务必在向订阅者公布触发关键词之前，对实际运行的自动化进行测试。

###### 问题 (Questions)

当您创建一个问题时，必须包含：

- 问题文本（例如：“您养的是哪种宠物？”等问题）
- 2 个或更多选项（例如：“猫”和“狗”）

###### ****一个自动化流程中可以包含多少个问题？****

问题的数量上限取决于自动化的触发方式：

- Always on：限制为最多 4 个问题。
- Campaign) 或Flow：限制为最多 3 个问题。

最佳实践：建议在流程中包含不超过 2 个问题，以确保最佳的用户体验。

###### 问题选项 (Question choices)

选项按顺序进行编号，如上例所示。我们建议将每个问题的选项数量限制在 3-5 个左右。

选项可以是：

- 单个单词或短语
- 任何大小写形式

识别规则：

- 长句识别：包含在较长的单词或消息中也可识别（即自动化会检查订阅者的入站短信是否“包含”某个选项）。
- 模糊匹配：得益于模糊匹配技术，某些拼写错误（特别是 5 个字母以上的单词）也可能被识别。
- 数字或文本均可：既可以识别选项文本，也可以识别其对应的数字。

延续宠物的例子，自动化会将以下所有输入归类为第一个选项（“1. Cat”）：

- Cat, cat, 或 CAT
- 1
- I have a cat
- Catch

###### 什么是默认推荐？

默认推荐是一种“兜底”机制。如果您不需要为每个选项都提供个性化的推荐，或者希望为多个答案使用相同的推荐，您可以使用默认推荐来响应任何未分配特定推荐的选项。

###### 消息 (Message)

您也可以选择以“消息”而非“推荐”来结束自动化流程。消息是一种纯文本消息，可以包含 URL。

##### 指标 (Metrics)

任何自动化流程都有 3 个关键衡量指标：

- 已启动自动化 (Started Automation：当个人资料（Profile）进入某个自动化流程时触发。
- Fulfilled Automation：当个人资料收到来自自动化的推荐消息时触发。
- Ended Automation：当个人资料退出自动化流程时触发（例如：当他们超时未回复，或已经收到了最终推荐时）。
