<h1>如何创建应用内表单</h1>

<h2>你将会学到</h2>
<p>了解如何直接在您的移动应用程序中向用户显示表单。您可以使用这些表单共享有关新产品或库存产品、销售、应用程序更新等的信息。您的移动应用程序需要至少使用 iOS SDK v4.2.0、Android SDK v3.2.0 和 React Native SDK v1.2.0 才能使用应用内表单。 ## 开始之前</p>
<p>应用程序内表单是在移动应用程序用户主动使用应用程序时向其显示的消息。目前，Klaviyo 支持公告式表单，可向应用程序用户传达信息并提高用户参与度。截至目前，应用内表单：</p>
<ul>
<li>以弹出窗口、全页表单和弹出窗口形式提供。 - 定位列表或细分中的所有移动应用用户或特定配置文件</li>
<li>基于触发器显示，例如打开的应用程序、打开的推送通知或执行的事件</li>
</ul>
<p>您还不能使用它们来收集同意或个人资料信息，但类似于 Klaviyo 网络表单的附加功能即将推出。请继续关注！ ## 创建应用内表单</p>
<p>仅当您已在 Klaviyo 中设置推送通知时，您才能创建应用内表单。如需指导，请参阅我们的 [iOS](https://help.klaviyo.com/hc/en-us/articles/360023213971)、[Android](https://help.klaviyo.com/hc/en-us/articles/14750928993307) 或 [React本机](https://help.klaviyo.com/hc/en-us/articles/22344173696539) 指南。 1. 导航至<strong><em>*注册表单</strong><strong>选项卡。 2. 选择</strong><strong>创建表单</strong><strong>。 3. 在右侧边栏中，为表单命名，选择</strong><strong>应用内</strong><strong>，然后选择表单类型。然后点击</strong><strong>创建</strong></em>*。 ![“创建表单”界面，名称为“Summer Collection”，为频道选择“应用内”，下拉列表显示表单类型：弹出式、整页和弹出窗口。](https://cdn.sanity.io/images/6ct6b26e/help-center-prod/800bfeb94f6dec0551546f6495b6f081aef2e478-962x1730.png)</p>
<p>4. 选择<strong><em>*样式</strong><strong> 更新表单的外观，包括高度、颜色、背景图像等。 5. 选择</strong><strong>添加块</strong></em>* 以拖放文本、按钮或图像块。 - 如果您希望该按钮将用户重定向到不同的应用程序屏幕，请使用深层链接将他们发送到应用程序中的特定屏幕（例如您正在宣传的集合）。有关深层链接的问题，请参阅[在推送通知中使用深层链接](https://help.klaviyo.com/hc/en-us/articles/14750403974043)。 6. 可选：单击预览中的关闭图标以更改其颜色或大小。 ![应用内表单的样式选项](https://klaviyo.zendesk.com/hc/article_attachments/34593203192603)</p>
<h2>调整表单的显示选项</h2>
<h3>触发器</h3>
<p>您的移动应用程序必须至少使用 iOS SDK v5.1.0、Android SDK v4.1.0 或 React Native SDK v2.1.0 才能使用触发器设置。您可以选择哪些操作触发应用程序中的表单显示。 - 默认情况下，您的表单将在客户<strong><em>*打开应用程序时显示。</strong></em>* 您还可以选择在客户打开推送通知或执行事件时显示</p>
<ul>
<li>您可以选择当客户****打开推送通知****时显示</li>
<li>您需要输入推送通知的标题，该标题打开后将触发显示表单</li>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/42159902048795" alt="" />
<li>您可以选择在客户****执行活动****时显示</li>
<li>您将使用下拉菜单选择您帐户中可用的任何活动</li>
<li>仅当事件代表客户从应用程序中执行的操作时，才会触发该表单。换句话说，只有当事件通过您的移动应用程序发送到 Klaviyo 的移动 SDK 时，表单才会触发。 ![](https://klaviyo.zendesk.com/hc/article_attachments/42159902053147)</li>
</ul>
<h3>时间安排</h3>
<p>您的移动应用程序必须至少使用 iOS SDK v5.0.0、Android SDK v4.0.0 或 React Native SDK v2.0.0 才能使用计时设置。您可以选择何时在应用程序中显示表单。 - 默认情况下，您的表单将在选定的触发器后显示<strong><em>*立即</strong><strong>，这意味着用户一打开应用程序就会看到您的注册表单。 - 您还可以选择</strong><strong>在一段时间延迟后</strong></em>*显示注册表单。设置显示表单之前等待的秒数，范围为 1 到 86,400 秒（即 1 天）。显示计时器在应用程序屏幕上持续存在。这意味着当用户导航到应用内的其他页面时，显示计时器会从满足触发条件时开始继续倒计时。 请注意，如果应用程序会话在显示延时表单之前结束，则该表单将不会在下一个会话期间显示。该表单将根据其当前设置再次显示。 ![屏幕截图 2025-10-15 1.04.22 AM.png](https://klaviyo.zendesk.com/hc/article_attachments/42159916961563)</p>
<h3>频率</h3>
<p>设置向应用程序的用户显示注册表单的频率。当设置为 0 时，每次用户打开应用程序时都会显示表单。如果您想阻止表单向点击进入另一个应用程序屏幕的应用程序用户显示，请选中<strong><em>*如果个人资料点击“转到应用程序屏幕”按钮，则不再显示</strong></em>*。 ## 调整表单的定位设置</p>
<h3>按应用程序用户定位</h3>
<p>您的移动应用程序必须至少使用 iOS SDK v5.0.0、Android SDK v4.0.0 或 React Native SDK v2.0.0 才能使用定位。在表单编辑器的 <strong>受众</strong> 下的 <strong>定位和行为</strong> 部分中定义有资格查看应用内表单的应用程序用户集。您可以从两个定位选项中进行选择，以仅向某些用户显示表单：</p>
<ul>
<li>显示给所有移动应用程序配置文件 - 此表单将显示给您的 Klaviyo 帐户中存在的所有应用程序配置文件。 - 显示列表或分段中的特定配置文件 - 选择是否包含特定配置文件、排除特定配置文件或两者。您可以选择单个列表或段，也可以选择多个。请注意，不能同时选择列表或段来包含和排除。如果发生定位冲突，将使用排除规则。 ![targeting-behavior.png](https://klaviyo.zendesk.com/hc/article_attachments/39739564295707)</li>
</ul>
<p>当您的表单按照您想要的方式显示时，单击<strong><em>*发布</strong></em>*将其设置为活动。 ## 结果</p>
<p>单击发布后，目标受众中的任何人都将根据显示条件看到此表单。您的表单将继续显示，直到您取消发布它或直到用户单击表单中的按钮（取决于表单的显示设置）。</p>
