<h1>如何使用 ChatGPT 的 Klaviyo 应用程序</h1>

<p>您必须是 Klaviyo 的所有者、管理员或经理才能将您的帐户连接到 ChatGPT 的 Klaviyo 应用程序。 ChatGPT 的 Klaviyo 应用程序可让您直接在 ChatGPT 内查看和分析您的 Klaviyo 数据。您可以通过自然语言检查营销活动和流程绩效、表面见解并采取后续步骤。该应用程序在 Klaviyo MCP 服务器上运行，该服务器将您的 Klaviyo 数据安全地导入 ChatGPT。 ## 开始之前</p>
<p>开始之前：</p>
<ul>
<li>您需要一个支持应用程序的 ChatGPT 界面。 OpenAI 确定哪些设备和环境支持应用程序。如果您在 ChatGPT 中没有看到“应用程序”部分，则您的界面可能尚不支持它。 - 您必须使用 OAuth 验证您的 Klaviyo 帐户，以允许 ChatGPT 访问您的数据。 - ChatGPT 可能请求对 Klaviyo MCP 服务器支持的 Klaviyo 端点进行读写访问。大多数端点是只读的。有些启用草稿和模板操作。 ## 将 Klaviyo 连接到 ChatGPT</li>
</ul>
<p>1. 打开支持Apps的ChatGPT界面。 2. 在边栏中，浏览可用的应用程序并选择<strong><em>*Klaviyo</strong></em>*。 3. 出现提示时，登录您的 Klaviyo 帐户并批准请求的范围。 4. 身份验证后，Klaviyo 应用程序将出现在您的 ChatGPT 侧栏中。 ![便签本@2x (17).png](https://klaviyo.zendesk.com/hc/article_attachments/45959412558491)</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/45959446890267" alt="便签本@2x (13).png" />
<p>连接后，您可以通过输入“Klaviyo”来“呼叫”Klaviyo 应用程序，或者直接开始询问以下问题：</p>
<ul>
<li>“在我的 Klaviyo 帐户中，我的营销活动本周表现如何？”</li>
<li>“显示过去 7 天内表现最好的流量。”</li>
<li>“分析我的欢迎流程的性能。”</li>
</ul>
<h2>您可以使用 ChatGPT 的 Klaviyo 应用程序做什么</h2>
<h3>查看活动效果</h3>
<p>您可以询问最近的营销活动效果如何。 ChatGPT 返回一个交互式表，其中包括：</p>
<ul>
<li>发送和交付</li>
<li>打开率和点击率</li>
<li>归属收入</li>
<li>状态，例如正在发送、已发送或已计划</li>
<li>深入链接 Klaviyo 以获得完整报告</li>
</ul>
<p>选择任意行上的<strong><em>*分析</strong></em>*以查看详细的性能卡，其中包括：</p>
<ul>
<li>关键关键绩效指标</li>
<li>每周比较</li>
<li>ChatGPT 生成的微观见解</li>
<li>建议的后续步骤</li>
</ul>

<img src="https://klaviyo.zendesk.com/hc/article_attachments/45959595451931" alt="活动 2.gif" />
<h3>查看流量性能</h3>
<p>您可以索要流量性能数据来查看：</p>
<ul>
<li>发送和交付</li>
<li>打开率和点击率</li>
<li>收入趋势</li>
<li>参与度和转化率随着时间的推移而变化</li>
</ul>
<p>选择<strong><em>*分析</strong></em>*以显示流程深入卡，其中包含对逐步性能的见解。 ### 接收后续步骤指导</p>
<p>查看活动或流程后，您可以提出以下问题：</p>
<ul>
<li>“接下来我应该做什么？”</li>
<li>“为什么本周表现发生变化？”</li>
<li>“我怎样才能改善这个流程？”</li>
</ul>
<p>ChatGPT 提供指导，例如时间建议、测试想法、受众注意事项以及有关流程的结构见解。 ### 使用具有更广泛 MCP 功能的自然语言</p>
<p>Klaviyo 应用程序由 Klaviyo MCP 服务器提供支持。这意味着您可以使用自然语言调用任何 MCP 支持的端点，即使 ChatGPT 应用程序不包含用于该任务的专用 UI​​。例如，你可以问：</p>
<ul>
<li>“使用上周的优惠起草新的电子邮件活动。”</li>
<li>“创建 VIP 促销模板。”</li>
</ul>
<p>这些请求的工作方式与直接使用 MCP 服务器时的工作方式相同。仅营销活动和流量报告请求返回结构化卡片。 ## Klaviyo 应用程序不能做什么</p>
<p>Klaviyo 应用程序遵循与 Klaviyo MCP 服务器相同的边界。该应用程序不能：</p>
<ul>
<li>发送活动</li>
<li>构建或编辑流程</li>
<li>创建或发送短信活动</li>
<li>修改段或列表</li>
<li>生成除 ChatGPT 中显示的表格以外的图表</li>
</ul>
<p>如果您要求执行不受支持的操作，ChatGPT 可能会以对话方式回复，但不会在您的 Klaviyo 帐户中采取操作。 ## 最佳实践</p>
<h3>获得可靠的见解</h3>
<ul>
<li>使用清晰的提示，例如“分析我最近的三个营销活动”或“将本周与上周进行比较”。</li>
<li>需要时询问趋势解释或摘要。 ### 减轻幻觉</li>
</ul>
<ul>
<li>在做出决策之前验证 Klaviyo 中的关键指标。 - 要求 ChatGPT 引用其分析中使用的活动 ID、流程名称或日期。 - 在应用生成的内容或建议之前查看它们。 - 保持您的 Klaviyo 数据最新，以确保结果准确。 ### 使用深层链接进行操作</li>
</ul>
<p>每个营销活动或流程卡都包含返回 Klaviyo 的链接，以便您可以查看完整报告或在应用程序中采取后续步骤。 ## 结果</p>
<p>连接帐户后，您可以使用适用于 ChatGPT 的 Klaviyo 应用程序实时查看活动和流程绩效、了解发生变化的内容和原因、接收下一步建议并运行更深入的分析，而无需打开 Klaviyo 仪表板。</p>
