<h1>Setting up key hotel reports with Mews</h1>

| Dashboard | Metric Used | What It Shows | Use Case |
| --- | --- | --- | --- |
| Historical Daily Room Revenue from Stays | Completed Room Night | Total room revenue per night | View the revenue attributable to each night |
| ADR from Stays | Completed Room Night | Average nightly rate for stays | View the average daily rate historically |
| ADR from New Bookings | Confirmed Room Night | Average nightly rate at time of booking | View the average daily rate for new bookings to understand the impact of marketing efforts |

| Property | What It Means |
| --- | --- |
| $value | The nightly room rate for that specific night |
| PropertyName | The name of the hotel property |
| Origin | Where the booking came from (e.g., Commander, ChannelManager, Connector) |
| ResourceName | The room type or name (e.g., Executive Suite, Deluxe Queen) |
| StartDate | The calendar date the night begins |
