<h1>如何将 Loop Returns 连接到 Klaviyo Helpdesk</h1>

<p>Klaviyo Helpdesk 的循环退货集成允许您的支持代理查看退货状态、发起退货并共享退货标签，而无需离开工单视图。本指南介绍了如何设置集成以及如何在日常工作流程中使用它。</p>
<p>---</p>
<h2>开始之前</h2>
<p>要启用此集成，您必须具备：</p>
<ul>
<li>一个活跃的****Loop Return**** 帐户。</li>
<li>启用帮助台的 ****Klaviyo**** 帐户。</li>
<li>****所有者****、****管理员****或****经理****的用户权限访问集成设置。</li>
</ul>
<p>---</p>
<h2>连接循环返回</h2>
<p>连接 Loop Returns 需要在 Loop 中生成特定的 API 密钥并将其添加到您的 Klaviyo 设置中。</p>
<h3>第 1 步：生成您的 Loop API 密钥</h3>
<p>1. 登录您的<strong><em>*Loop Returns</strong></em>* 管理仪表板。</p>
<p>2. 导航至<strong><em>*设置 > 开发人员 > API 密钥</strong></em>*。</p>
<p>3. 单击<strong><em>*生成 API 密钥</strong></em>*。</p>
<p>4. <strong><em>*重要提示：</strong><strong> 选择此键的范围时，必须选中 </strong><strong>订单</strong><strong> 和 </strong><strong>退货</strong></em>* 复选框。</p>
<ul>
<li>**注意：如果没有这些特定权限，集成将无法查找订单详细信息或启动退货。**</li>
</ul>
<p>5. 复制生成的API Key。</p>
<h3>步骤 2：在 Klaviyo 中启用集成</h3>
<p>1. 登录<strong><em>*Klaviyo</strong></em>*。</p>
<p>2. 导航至<strong><em>*客户中心 -> 分机</strong></em>*</p>
<p>3. 将<strong><em>*Loop Returns</strong></em>* 设置为您的退货提供商。</p>
<p>4. 将<strong><em>*启用循环返回</strong><strong>设置切换为</strong><strong>打开</strong></em>*。</p>
<p>5. 将您的 <strong><em>*API 密钥</strong></em>* 粘贴到指定字段中。</p>
<ul>
<li>**注意：仔细检查您是否已复制完整密钥。 Klaviyo 不会在保存时验证密钥，因此不正确的密钥将导致稍后向您的代理显示错误消息。**</li>
</ul>
<p>6. 单击<strong><em>*保存</strong></em>*。</p>
<p>---</p>
<h2>帮助台中的退货流程</h2>
<p>连接后，退货状态和发起退货的能力将添加到现有订单卡中。</p>
<h3>查看退货状态</h3>
<p>当您打开票证时，集成会自动检查与客户订单历史记录关联的现有退货。你会看到：</p>
<ul>
<li>****当前状态：**** 退货的状态（例如，**打开**、**审核**、**关闭**、**取消**）。</li>
<li>****追踪：**** 承运人详细信息以及可点击的退货追踪号码。</li>
</ul>
<h3>发起退货</h3>
<p>如果客户要求退货或换货，您可以直接从侧边栏启动该流程：</p>
<p>1. 在侧栏中找到具体订单。</p>
<p>2. 单击<strong><em>*开始返回</strong></em>*。</p>
<p>3. 选择您希望如何与客户共享退货门户：</p>
<ul>
<li>****复制链接：**** 生成一个“深层链接”，使客户直接登录到该特定订单的退货门户。您可以将其粘贴到您的聊天或电子邮件回复中。</li>
</ul>
<p>---</p>
<h2>常见问题</h2>
<p><strong><em>*为什么我看不到“启动退货”按钮？</strong></em>* 仅当订单根据您的循环政策符合退货条件（例如，在退货窗口内）并且该订单没有已打开的有效退货时，该按钮才会出现。</p>
<p><strong><em>*我可以手动为客户创建退货标签吗？</strong></em>* 此时，集成允许您生成深层链接和二维码，引导客户访问门户以确认其物品。您无法在帮助台内代表他们完全完成退货选择。</p>
