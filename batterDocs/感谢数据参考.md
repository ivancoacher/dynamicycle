<h1>感谢数据参考</h1>

<h2>你将会学到</h2>
<p>了解哪些数据从 Thanx 同步到 Klaviyo 以及在哪里查看。这包括与所下订单和客户资料相关的信息。</p>
<p>如果您还没有阅读我们的 [Thanx 入门](https://help.klaviyo.com/hc/en-us/articles/19458074597659) 指南，了解有关集成的说明，然后再继续阅读本文。</p>
<h2>如何查看您的数据</h2>
<p>要查看您的 Thanx 数据：</p>
<p>1. 单击左侧导航侧栏中的<strong><em>*分析</strong></em>*下拉列表。</p>
<p>2. 选择<strong><em>*指标</strong><strong>。在这里，您可以查看帐户中的所有指标。按 </strong><strong>Thanx</strong></em>* 过滤以查看您的 Thanx 指标。</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28715966264475" alt="" />
<p>3. 点击<strong><em>*已下订单</strong></em>* 查看详细的指标信息。</p>

<h2>同步指标</h2>
<p>Thanx 发送 2 种类型的购买有效负载：</p>
<ul>
<li>****数据共享****</li>
</ul>
<p>如果 Webhook 使用者有资格进行数据共享，则发送。</p>
<ul>
<li>****无数据共享****</li>
</ul>
<p>如果 Webhook 使用者不符合数据共享资格，则发送。</p>
<p><strong>无数据共享</strong>例如，针对位置尚未选择数据共享的商场商家发送有效负载。</p>

<p>当客户通过您的 Thanx 忠诚度计划下订单时，会发生此事件。您可以根据以下条件过滤和定位已下订单事件：</p>
<ul>
<li>****购买 ID****</li>
</ul>
<p>购买的唯一标识符</p>
<ul>
<li>****商户 ID****</li>
</ul>
<p>商户的唯一标识符</p>
<ul>
<li>****订单 ID****</li>
</ul>
<p>订单 ID</p>
<ul>
<li>****订单提供商****</li>
</ul>
<p>接受订单的系统</p>
<ul>
<li>****商户名称****</li>
</ul>
<p>商户名称</p>
<ul>
<li>****位置 ID****</li>
</ul>
<p>购买地点的唯一标识符</p>
<ul>
<li>****地点名称****</li>
</ul>
<p>购买地点名称</p>
<ul>
<li>****地点****</li>
</ul>
<p>有关位置的附加信息，包括位置 ID 和地址</p>
<ul>
<li>****物品****</li>
</ul>
<p>有关所购买商品的详细信息</p>
<h2>同步访客数据</h2>
<p>除了 Klaviyo 从 Thanx 同步的指标之外，Klaviyo 还将为我们同步的每个客户创建一个独特的配置文件，其中包括：</p>
<ul>
<li>名字</li>
<li>姓氏</li>
<li>电子邮件地址</li>
<li>电子邮件同意</li>
<li>短信同意（包括电话号码）</li>
<li>感谢忠诚度等级</li>
<li>感谢忠诚积分余额</li>
<li>感谢忠诚度开始日期</li>
<li>谢谢生日</li>
<li>感谢生日那年</li>
<li>感谢生日月</li>
<li>感谢生日</li>
</ul>
<h2>同步频率</h2>
<p>Thanx <strong>已下订单</strong> 事件从您集成时开始持续同步，实时同步。</p>
<p>历史访客数据在集成时同步，然后每 30 分钟定期同步。</p>
