<h1>关于您的审核渠道</h1>

<p>了解从下订单到提交评论的路径，包括 Klaviyo 如何让您轻松查看评论渠道中每个订单的状态。</p>
<h2>关于订单选项卡</h2>
<p>如果您导航到<strong><em>*评论>订单</strong></em>*，您将看到最近订单的列表及其审核渠道状态。使用此页面可以了解某人何时会收到审核请求、更改审核请求时间等。</p>
<h2>请求状态</h2>
<p>在<strong><em>*订单</strong><strong>选项卡的</strong>请求状态</em>*列中，列出了每个订单的审核管道状态。可以使用以下状态：</p>
<ul>
<li>********已排队********</li>
</ul>
<p><strong><em></strong><strong></em> </strong><strong><em>*准备审核</strong><strong></em></strong><em> <strong></em><em>活动已根据您的设置安排在未来的日期/时间。</strong></em>*</p>
<ul>
<li>****准备审查****</li>
</ul>
<p>此订单已触发 <strong>准备审核</strong> 事件。前往客户的个人资料，确认他们已收到您的审核请求流程的第一条消息。请注意，如果配置文件未通过流程的过滤器，或者流程出现时间延迟，则可能不会发送审核请求。</p>
<ul>
<li>****已审核****</li>
</ul>
<p>客户已查看订单中的一件或多件商品。</p>
<ul>
<li>****排除****</li>
</ul>
<p>该订单不符合审核条件，因为其中的所有商品均已[排除](https://help.klaviyo.com/hc/en-us/articles/16684841274139)。</p>
<ul>
<li>****使用限制****</li>
</ul>
<p>您的审核计划对于您的订单量而言太小。升级您的评论计划以获得更高的数量。目前无法对因使用限制而跳过的订单重新触发审核请求。</p>
<ul>
<li>****丢失数据****</li>
</ul>
<p>该订单缺少必要的数据。大多数情况下，这意味着订单中的产品 ID 与您的 Klaviyo 目录中的任何产品 ID 都不匹配。</p>
<h2>如何手动调整审阅时间</h2>
<p>如果审核当前<strong>排队</strong>，您可以选择立即触发审核请求。请注意，这只会启动审核请求流程；如果收件人未通过流的过滤器，没有资格接收营销消息，或者如果流不是实时的，那么他们将不会收到审核请求。</p>
<p>这个过程不是立即的。单击<strong><em>*跳过等待时间</strong><strong>后，可能需要几分钟的时间才能触发 </strong>准备审核</em>* 事件。</p>
<h3>跳过单个订单的等待时间</h3>
<p>1. 导航至<strong><em>*评论 > 订单</strong></em>*。</p>
<p>2. 找到审核状态为<strong>已排队</strong>的订单。</p>
<p>3. 单击三点图标打开附加选项菜单。</p>
<p>4. 选择<strong><em>*跳过等待时间</strong></em>*。</p>
<h3>跳过所有排队订单的等待时间</h3>
<p>1. 导航至<strong><em>*评论 > 订单</strong></em>*。</p>
<p>2. 单击<strong><em>*操作</strong></em>*。</p>
<p>3. 选择<strong><em>*跳过等待时间</strong></em>*。</p>
