<h1>了解集成选项卡</h1>

<h2>你将会学到</h2>
<p>了解如何访问已安装的集成并探索 Klaviyo 的应用程序市场，您可以在其中浏览、安装和配置 Klaviyo 与其他平台之间的不同集成。该市场包括电子商务、登陆页面、支付系统等的集成。</p>
<h2>查看您的集成</h2>
<p>要导航到 Klaviyo 中的“集成”选项卡，请单击左侧导航栏中的“<strong><em>*集成</strong></em>*”。</p>
<p>在结果页面上，您可以查看当前为您的帐户启用的集成。</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/39449099429147" alt="" />
<p>该页面有以下列：</p>
<ul>
<li>****姓名****</li>
</ul>
<p>默认情况下，集成按名称按字母顺序列出。单击集成的名称可查看其配置。</p>
<ul>
<li>****类别****</li>
</ul>
<p>每个集成都会根据集成的应用程序分配一个类别。例如，Shopify 集成被列为<strong>电子商务平台</strong>。</p>
<ul>
<li>****状态****</li>
</ul>
<p>状态列通知您集成的当前状态：</p>
<ul>
<li>****已启用****</li>
</ul>
<p>集成已激活并正在同步数据。</p>
<ul>
<li>****禁用****</li>
</ul>
<p>集成不是同步数据。</p>
<ul>
<li>****需要采取行动****</li>
</ul>
<p>您应该解决集成问题。</p>
<p>在该页面的右上角，有3个按钮：</p>
<ul>
<li>****管理数据****</li>
</ul>
<p>打开包含以下选项的下拉菜单：</p>
<ul>
<li>****通过 CSV 导入****</li>
</ul>
<p>使用 CSV 文件导入集成事件数据。请阅读我们关于[如何手动导入历史事件数据]的文章(https://help.klaviyo.com/hc/en-us/articles/115005081247)了解更多信息。</p>
<ul>
<li>****SFTP 数据传输****</li>
<p><a href="https://developers.klaviyo.com/en/docs/use_klaviyos_sftp_import_tool">使用 SFTP</a></p>
<li>****设置网络跟踪****</li>
</ul>
<p>查看有关如何为您的网站设置 Klaviyo 现场跟踪的说明。</p>
<ul>
<li>****开发人员****</li>
</ul>
<p>打开包含以下选项的下拉菜单：</p>
<ul>
<li>****开发者工具****</li>
</ul>
<p>生成示例数据、查看 API 日志和活动等等。</p>
<ul>
<li>****管理应用程序****</li>
</ul>
<p>管理您开发的应用程序。</p>
<ul>
<li>****探索应用程序****</li>
</ul>
<p>查看 Klaviyo 的应用程序市场以安装应用程序或集成。有关详细信息，请参阅本文的下一部分。</p>
<p>##</p>

<h2>查看应用程序市场</h2>
<p>要查看应用程序市场：</p>
<p>1. 选择<strong><em>*集成</strong></em>*。</p>
<p>2. 单击右上角的<strong><em>*探索应用程序</strong></em>*。</p>
<p>您还可以在 [marketplace.klaviyo.com](https://marketplace.klaviyo.com/en-us/) 上找到市场，登录或注销 Klaviyo 后即可查看该市场。</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/39449055554971" alt="" />
<p>该应用程序市场有几个主要功能：</p>
<ul>
<li>发现集成和应用程序，包括新集成和应用程序以及您业务中流行的集成和应用程序（登录 Klaviyo 时）。</li>
<li>通过搜索框搜索或按类别过滤。</li>
<li>在每个应用程序列表页面上查看功能亮点、支持链接等，包括第三方构建的应用程序。</li>
</ul>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/39449099435675" alt="" />
<p>我们的应用程序市场包含由 Klaviyo 构建的应用程序以及由我们的生态系统构建的精选应用程序。如果您找不到所需的应用程序，请直接联系您的软件提供商。</p>
<h2>添加集成</h2>
<p>要添加集成或应用程序：</p>
<p>1. 选择<strong><em>*集成</strong></em>*。</p>
<p>2. 单击右上角的<strong><em>*探索应用程序</strong></em>*。</p>
<p>3. 搜索您要查找的集成并选择它。</p>
<p>4. 在下一页上，单击<strong><em>*安装</strong></em>*。</p>
<p>5. 按照下一页的说明集成特定平台。</p>
<p>对于 Klaviyo 构建的集成，[搜索我们的帮助中心](https://help.klaviyo.com/hc/en-us/search) 获取适当的 <strong>入门</strong> 指南。</p>
