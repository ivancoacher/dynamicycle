<h1>Setting up key hotel reports with Cloudbeds</h1>

| Dashboard | Metric | What It Shows | Use Case |
| --- | --- | --- | --- |
| Historical Daily Room Revenue from Stays | ****Completed Room Night**** | Total room revenue per night | View the revenue attributable to a given night |
| Average Daily Rate (ADR) from Stays | ****Completed Room Night**** | Average nightly rate for historical stays | View the average daily rate historically |
| ADR from New Bookings | ****Confirmed Room Night**** | Average nightly rate for new bookings | View the average daily rate for new bookings to understand the impact of marketing efforts |

| Property | What It Means |
| --- | --- |
| $value | The nightly room rate for that specific night |
| PropertyName | The name of the property/hotel |
| Source | Where the booking came from (e.g., Direct, Booking.com, Airbnb, Vrbo) |
| RoomTypeName | The room type or name (e.g., Deluxe Queen, Presidential Suite) |
| StartDate | The calendar date the night begins |
