<h1>电子邮件指标参考</h1>

<h2>你将会学到</h2>
<p>详细了解 Klaviyo 中的哪些具体指标与客户与您的电子邮件的交互相关。了解帐户中的指标对于深入了解营销计划的执行情况至关重要。</p>
<h2>电子邮件指标</h2>
<p>要查看您的电子邮件指标数据，请导航至<strong><em>*指标</strong></em>*，或查看[仪表板的活动源](https://www.klaviyo.com/dashboard/activity) 以查看您帐户中的电子邮件事件。</p>
<p>以下是每个指标的含义：</p>
<ul>
<li>****退回的电子邮件****</li>
</ul>
<p>当电子邮件被软退回或硬退回时。</p>
<ul>
<li>****点击电子邮件****</li>
</ul>
<p>当收件人单击电子邮件时。</p>
<ul>
<li>****已删除电子邮件****</li>
</ul>
<p>当 Klaviyo 中的抑制状态与 Klaviyo 可能使用的其他上游电子邮件服务提供商之间存在差异时发生。</p>
<ul>
<li>****合并的个人资料****</li>
</ul>
<p>当两个配置文件合并在一起时，一个配置文件“合并”到另一个配置文件中；其余的单个配置文件将跟踪此指标。</p>
<ul>
<li>****将电子邮件标记为垃圾邮件****</li>
</ul>
<p>当收件人将电子邮件标记为垃圾邮件时。</p>
<ul>
<li>****打开电子邮件****</li>
</ul>
<p>当收件人打开电子邮件时。</p>
<ul>
<li>****收到电子邮件****</li>
</ul>
<p>当收件人收到电子邮件时。</p>
<ul>
<li>****订阅恢复库存****</li>
</ul>
<p>当收件人订阅有关商品重新入库的通知时。</p>
<ul>
<li>[****订阅列表****](https://klaviyo.zendesk.com/hc/en-us/articles/360039666832)</li>
</ul>
<p>当有人选择加入列表时。</p>
<ul>
<li>****取消订阅****</li>
</ul>
<p>当有人在全球范围内取消订阅电子邮件时。</p>
<ul>
<li>****从列表中取消订阅****</li>
</ul>
<p>当有人取消订阅特定列表时。</p>
<p>随着 iOS15、macOS Monterey、iPadOS 15 和 WatchOS 8 的发布，Apple Mail 隐私保护 (MPP) 通过预取跟踪像素改变了我们接收电子邮件打开率数据的方式。随着这一变化，重要的是要了解开放率将会上涨。</p>
<p>要查看您的打开是否受到影响，我们建议创建一个包含 MPP 属性的[自定义报告](https://help.klaviyo.com/hc/en-us/articles/4416803987739)。您还可以在您的个人[订阅者细分](https://help.klaviyo.com/hc/en-us/articles/4416791883163)中识别这些开放。</p>
