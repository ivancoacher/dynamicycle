<h1>同意参考的流量过滤的更改</h1>

<h2>你将会学到</h2>
<p>了解 Klaviyo 在流程中的个人资料过滤的更新，使您能够过滤同意记录。 ## 通过电子邮件发送同意条件变更</p>
<p>随着 Klaviyo 对流程中个人资料过滤的更新，以下电子邮件同意条件会受到影响：</p>
<p><strong><em>*识别未被抑制的配置文件</strong></em>*</p>
<p>旧过滤条件：</p>
<ul>
<li>如果有人被或未被禁止发送电子邮件 ></li>
</ul>
<p>人没有被压抑</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28722611148699" alt="“人不受压制”的旧个人资料过滤器" />
<p>新的过滤条件：</p>
<ul>
<li>如果某人可以或不能接受营销></li>
</ul>
<p>人可以接收电子邮件营销</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28722611161371" alt="“人员可以接收电子邮件营销”的新个人资料过滤器" />
<p><strong><em>*识别被抑制的配置文件</strong></em>*</p>
<p>旧过滤条件：</p>
<ul>
<li>如果有人被或未被禁止发送电子邮件 ></li>
</ul>
<p>人被压制了</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28722599205275" alt="“人被压制”的旧过滤器" />
<p>新的过滤条件：</p>
<ul>
<li>如果某人可以或不能接受营销></li>
</ul>
<p>此人无法接收电子邮件营销</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28722599228827" alt="“人员无法接收电子邮件营销”的新过滤器" />
<p><strong><em>*识别已订阅且未被抑制的配置文件</strong></em>*</p>
<p>旧条件：</p>
<ul>
<li>如果有人被或未被禁止发送电子邮件 ></li>
</ul>
<p>人没有被压抑</p>
<p>和</p>
<ul>
<li>如果某人在或不在列表中 ></li>
</ul>
<p>此人位于[订阅者列表名称]中</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28722611151387" alt="“人员不受抑制”和“人员在列表中”的旧过滤器" />
<p>新条件：</p>
<ul>
<li>如果某人可以或不能接受营销></li>
</ul>
<p>人可以接收电子邮件营销></p>
<p>因为人们订阅了电子邮件营销</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28722611164315" alt="“人员可以接收电子邮件营销”的新过滤器和“人员订阅”的过滤器" />

<h2>新功能</h2>
<p>通过配置文件过滤的更新，您还可以过滤配置文件如何订阅或取消订阅，以及其被抑制的原因（仅限电子邮件）。 <strong><em>*识别通过特定方法（电子邮件）订阅的个人资料</strong></em>*</p>
<ul>
<li>如果某人可以或不能接受营销></li>
</ul>
<p>人可以接收电子邮件营销></p>
<p>因为此人订阅了电子邮件营销 ></p>
<p>订阅方式为Klaviyo form [表单名称]</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28722599247899" alt="使用订阅方法过滤“人员无法接收电子邮件营销”" />
<p>在此条件下，您还可以过滤：</p>
<ul>
<li>订阅方式</li>
<li>方法细节</li>
<li>自定义方法细节</li>
<li>订阅日期</li>
<li>如果个人资料被双重选择</li>
</ul>
<p><strong><em>*识别通过特定方法（短信）订阅的个人资料</strong></em>*</p>
<ul>
<li>如果某人可以或不能接受营销></li>
</ul>
<p>人可以接收短信营销 ></p>
<p>订阅方式为Klaviyo形式</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28722611186843" alt="过滤‘persn可接收短信营销’及订阅方式" />
<p><strong><em>*识别具有从未订阅状态的个人资料（电子邮件）</strong></em>*</p>
<ul>
<li>如果某人可以或不能接受营销></li>
</ul>
<p>人可以接收电子邮件营销></p>
<p>因为人们从未订阅过电子邮件营销</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28722611208731" alt="过滤“人员可以接收电子邮件营销”且从未订阅" />
<p><strong><em>*识别具有从未订阅状态的个人资料（短信）</strong></em>*</p>
<ul>
<li>如果某人可以或不能接受营销></li>
</ul>
<p>无法接收短信营销 ></p>
<p>因为人们从未订阅过短信营销</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28722599252635" alt="过滤“人员无法接收短信营销”并且从未订阅" />
<p><strong><em>*识别由于特定原因取消订阅的个人资料</strong></em>*</p>
<ul>
<li>如果某人可以或不能接受营销></li>
</ul>
<p>此人无法接收电子邮件营销></p>
<p>因为有人取消订阅电子邮件营销></p>
<p>而取消订阅方法就是取消订阅页面</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28722599261083" alt="过滤“无法接收电子邮件营销的人”和取消订阅方法" />
<p>您还可以过滤：</p>
<ul>
<li>取消订阅方法</li>
<li>方法细节</li>
<li>取消订阅日期</li>
</ul>
<p><strong><em>*识别由于特定原因而被抑制的配置文件</strong></em>*</p>
<ul>
<li>如果有人可以或不能接收电子邮件营销></li>
</ul>
<p>此人无法接收电子邮件营销></p>
<p>因为电子邮件营销中的人被手动禁止</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28722611198363" alt="过滤“人员无法接收电子邮件营销”，因为人员被手动抑制" />
<p>您可以过滤抑制，因为：</p>
<ul>
<li>取消订阅</li>
<li>手动抑制</li>
<li>无效的电子邮件</li>
<li>硬退回电子邮件</li>
</ul>
