<h1>代码入门</h1>

<h2>你将会学到</h2>
<p>了解代码以及如何创建由 Klaviyo 直接执行的自定义函数。代码需要定制开发，Klaviyo 的支持团队无法提供实际帮助。如果您的团队中没有开发人员并且不方便自己编写代码，请考虑向 Klaviyo 合作伙伴寻求帮助。 ## 开始之前</p>
<p><a href="https://help.klaviyo.com/hc/en-us/articles/17655007276059">高级 KDP</a></p>
<p>代码允许您执行自定义函数来响应可通过 [获取事件 API](https://developers.klaviyo.com/en/reference/get_events) 查询的任何事件。这些包括：</p>
<ul>
<li>电子邮件事件（例如，**点击电子邮件**、**将电子邮件标记为垃圾邮件**）</li>
<li>短信事件（例如，**发送短信**、**接收短信**）</li>
<li>推送通知事件（例如，**收到推送**、**退回推送**）</li>
<li>来自集成的事件（即来自 Klaviyo 创建的第一方集成的事件）</li>
<li>API 事件（即通过 Klaviyo 的 API 同步的事件）</li>
</ul>
<p>Klaviyo Code 不支持以下事件作为主题：</p>
<p>1. 电子邮件已打开</p>
<p>2. 收到邮件</p>

<p>预安装的 <strong>klaviyo</strong> 模块的 API 与您通常使用 <strong>klaviyo-api</strong> Python 模块实例化的 [Klaviyo SDK](https://github.com/klaviyo/klaviyo-api-python) 对象相同。您可以将 <strong>klaviyo</strong> 模块视为预实例化的 <strong>klaviyo</strong> SDK 客户端。例如，在传统工作流程中，您首先通过将 API 密钥传递给构造函数来实例化新的 Klaviyo SDK 客户端，然后使用生成的 SDK 对象。 ````</p>
<p>from klaviyo_api import KlaviyoAPIimport osdef handler(event, context): klaviyo = KlaviyoAPI(api_key=os.getenv("KLAVIYO_API_KEY")) print(klaviyo.Metrics.get_metrics())</p>
<p>````</p>
<p>使用代码，您只需导入 klaviyo 对象，身份验证就会为您处理。 ````</p>
<p>导入 klaviyodef 处理程序（事件，上下文）： print(klaviyo.Metrics.get_metrics())</p>

<p>查看[可用的 Klaviyo 对象及其方法](https://pypi.org/project/klaviyo-api)。 ### Javascript <strong>klaviyo</strong> 模块</p>

<p>Klaviyo 代码具有以下速率限制：</p>
<ul>
<li>****函数超时****</li>
</ul>
<p>代码中的函数在超时之前最多可以执行 15 秒。 - <strong><em>*功能速率限制</strong></em>*</p>
<p>代码中的函数允许每个函数最多 25 个并发执行。 ## 部署代码</p>
<p>要部署您在编辑器中编写的代码，请将状态下拉列表切换为 <strong>Live</strong>。 ![切换部署代码](https://klaviyo.zendesk.com/hc/article_attachments/28722610634139)</p>
