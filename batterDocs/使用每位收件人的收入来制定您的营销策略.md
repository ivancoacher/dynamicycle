<h1>使用每位收件人的收入来制定您的营销策略</h1>

<h2>你将会学到</h2>
<p>了解如何在营销策略中使用每位收件人的收入 (RPR) 来提高营销活动效果。 ## 开始之前</p>
<p>确保您的 Klaviyo 帐户已与[电子商务平台](https://help.klaviyo.com/hc/en-us/categories/115000032731)集成，并且您已发送营销活动或流程，以便您拥有数据来为每个收件人产生收入 (RPR)。您还可以使用自定义下订单指标来确定每个收件人的收入，只要该指标使用 <strong>$value</strong> 作为属性即可。我们建议您至少进行一个月的活动，以获得准确的 RPR 基线描述。有关生成 RPR 数字的更多信息，请查看我们的[如何计算每个收件人的收入 (RPR) 指南](https://help.klaviyo.com/hc/en-us/articles/360034724572)。 ## 使用 RPR 规划活动日历的好处</p>
<p>通过建立 RPR 预期，您可以更谨慎地计划每个月的收入并利用折扣（或其他激励措施）。例如，如果您在营销活动中提供 10% 的优惠券代码，您可以计算该电子邮件的 RPR，并根据提供折扣所花费的金额来衡量。因此，RPR 数据使您能够确定您为客户提供的服务是否对您的业务和利润有帮助。您还将了解哪种类型的电子邮件最适合您的受众，并更新您的[内容日历](https://academy.klaviyo.com/developing-a-content-calendar)以反映此类趋势。 RPR 对于营销活动分析非常重要，可确保您的企业实现每个营销活动的收入目标。营销活动效果排名前 25% 的商店每封电子邮件的收入约为 2.5-3 倍。 ## 使用 RPR 测量流动性能</p>
<p>同样，您可以通过此计算来衡量流程性能，以检查您的电子邮件是否充分发挥了推动业务的潜力。评估流程中哪些电子邮件表现良好，哪些电子邮件表现不佳。您可以关注盈利流程中的特征，以使 RPR 较低的其他人更加成功。例如，对于收入为 1-100 万美元且平均订单价值低于 28 美元的企业来说，排名前 25% 的企业每发送一封[废弃购物车电子邮件](https://help.klaviyo.com/hc/en-us/articles/115002779411) 至少赚取 81 美分。这 81 美分是他们针对该特定流量的 RPR。如果您发现某个流程的性能低于平均水平，请运行 [A/B 测试](https://help.klaviyo.com/hc/en-us/articles/115002775152) 以查看可以改进的地方。考虑测试不同的主题行、时间安排、电子邮件数量等。有关测量流性能的更多信息，请查看我们的[流性能基准]指南(https://help.klaviyo.com/hc/en-us/articles/360033669452)。 ## 提高 RPR</p>
<p>分析 RPR 可以帮助您迭代并了解受众的反应，以及反之，什么对您的业务不起作用。如果您的 RPR 低于预期，请考虑以下更改：</p>
<p>1. [列表清理](https://help.klaviyo.com/hc/en-us/articles/115005078347) 进行营销活动，或根据其[偏好](https://help.klaviyo.com/hc/en-us/articles/115000769631) 并使用 [flow] 将流量发送给更具体、参与度更高的受众过滤器](https://help.klaviyo.com/hc/en-us/articles/115002779051)。 2. 使用[细分](https://help.klaviyo.com/hc/en-us/articles/115005237908)向高度参与的受众发送营销活动，并继续在[细分参与度报告](https://help.klaviyo.com/hc/en-us/articles/115005906848)中检查参与程度。 3. 关注电子邮件趋势，了解电子邮件中最有效的内容，并更新内容日历以改进效果不佳的营销活动。 4. 确保您的激励措施对您的业务有帮助而不是有害（例如，如果 10% 的折扣产生边际利润，则可能不值得采取激励措施）。 5. 使用您的[概览仪表板](https://help.klaviyo.com/hc/en-us/articles/4708299478427) 和[自定义报告](https://help.klaviyo.com/hc/en-us/articles/360047725651) 找出哪些内容适合您的业务以及哪些内容需要调整。 6. 了解 RPR 与转化率和订单规模相关，尝试不同的想法来提高电子邮件性能并调整当前的电子邮件策略以通过电子邮件实现增长。 ## 使用 RPR 来告知您的发送策略</p>
<p>此外，使用您的参与列表和 RPR 来规划您当月的活动策略。 根据您的 RPR 率，进行一些更改，以反映似乎对您有用的方法。如果您的 RPR 低于预期，请考虑以下因素：</p>
<p>1. 您目前多久向订阅者发送消息？ 2. 哪些具体特征、样式和块在您的电子邮件和短信中最有效？ 3. 收到您电子邮件的受众的参与度如何？ 4. 您的电子邮件中的激励措施（例如折扣）是否有效？ 5.订阅者是否[收到您的电子邮件](https://help.klaviyo.com/hc/en-us/articles/11500524700)？您同样可以通过将电子邮件列表大小乘以营销活动数量，然后将该数字乘以您的 RPR 来找到您的预期电子邮件收入。 ## 其他资源</p>
