##### ****什么是品牌发件域名？****

品牌发件域名允许您发送看起来像是来自您自己品牌的电子邮件，并让您能够更好地全面控制自己的发件人信誉。任何公司都有资格创建品牌发件域名。

默认情况下，大多数用户在开始时会通过共享 IP 和 Klaviyo 域名发送邮件。该域名会显示在电子邮件顶部的发件人信息中（如下图所示），例如显示为“由…代发”或“通过 klaviyomail.com 发送” (via klaviyomail.com)。

在下方 Gmail 的示例中，您的收件人会看到您的发件人邮箱地址包含“via klaviyomail.com”，因为您当前使用的是共享发件域名。

![Gmail interface showing an email from a user with a 'via klaviyomail.com' tag in the sender information.](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2026/01/image-4.png?resize=951%2C200&ssl=1)

通过迁移到品牌发件域名，您将移除显示在发件人邮箱地址旁边的“via klaviyomail.com”信息。这也意味着您的电子邮件将不再通过共享域名发送，从而使收件箱服务商能够更轻松地验证您的身份，并顺利通过 ****DMARC**** 等邮件身份验证协议。

- Google 和 Yahoo 已宣布自 2024 年 2 月起开始实施新的发件人要求。虽然这原本就是最佳实践，但现在设置品牌发件域名已成为“大批量发件人”进入 Gmail 收件箱的****强制要求****。
- Google 将每天向 Google 账户发送 5,000 封或更多邮件的发件人视为“大批量发件人”。发件人的所有流量（包括交易类邮件）都会计入这 5,000 封邮件的阈值。

##### ****关于通过 Klaviyo 生成域名系统 (DNS) 记录****

连接品牌发件域名的关键环节是生成所需的 DNS 记录。为了生成这些记录，您在 Klaviyo 中设置品牌发件域名时需要输入以下信息：

###### ****Root domain（根域名）****

这是您向域名注册商购买或注册的域名，它代表了您品牌的网站域名。您可能还拥有基于此域名的电子邮件地址。例如，如果您的公司名为 Hello World，那么您的品牌根域名可能是 `helloworld.com`，而您的友好发件人地址（friendly from-address）可能是 `name@helloworld.com`。

###### ****Branded sending domain（品牌发件域名）****

这是将用于从 Klaviyo 发送电子邮件并显示在邮件头中的域名。请务必注意，品牌发件域名必须使用一个****唯一的、未被使用的子域名****，以免干扰根域名上任何外部邮件配置。在 Klaviyo，最常用的子域名是 “send”。沿用上面的例子，Hello World 的品牌发件域名可以是 `send.helloworld.com`。不过，您可以使用任何尚未被占用的子域名。

##### ****动态路由与静态路由****

在设置品牌发件域名时，您可以选择是否将子域名委托给 Klaviyo，以便其动态选择最佳的发送服务商选项。

通过委托子域名，您是在授权 Klaviyo 管理品牌的子域名并创建 DNS 记录。这些权限仅用于与您的邮件发送相关的任务，子域名委托不会影响您品牌的根域名或任何其他子域名。

您可以随时通过删除品牌发件域名设置过程中添加的相关 DNS 记录来撤销子域名委托。

在 Klaviyo 中设置品牌域名时，您可以选择以下路由选项：

- ****Dynamic（动态）****： 将您的子域名委托给 Klaviyo，以便动态选择邮件发送服务商，从而获得最佳的发送性能、信誉和稳定性。
- ****Static（静态）****： 允许 Klaviyo 通过单一且固定的邮件发送服务商发送电子邮件。

在生成 DNS 记录时，如果选择 Dynamic（动态） 路由选项，Klaviyo 将创建 NS 记录；如果选择 Static（静态） 路由选项，则会创建 CNAME 记录。

Klaviyo 建议选择 ****Dynamic（动态）**** 路由选项，以最佳化您的发送性能。

如果您目前使用的品牌发件域名是在此功能推出之前创建的，或者您决定从 Static（静态） 切换到 Dynamic（动态），请先在 Klaviyo 中移除您的域名，并删除 DNS 服务商处该子域名现有的 CNAME 记录。完成后，请选择 Dynamic（动态） 选项重新执行设置流程。请注意，记录生效（传播）可能需要长达 48 小时。

##### ****创建品牌发件域名的要求****

###### ****开始之前****

在开始此流程前，****新 Klaviyo 账户****应确保您有足够的时间来****预热您的基础架构 (Warm your infrastructure)****。

此外，至关重要的一点是：您必须拥有用于发送电子邮件的域名，并且您或您的团队成员拥有访问 DNS 托管商的权限，以便创建所需的记录。

****现有的 Klaviyo 客户****在迁移至品牌发件域名时，****无需****再次预热基础架构，只要满足以下条件：

- 域名已注册至少 30 天
- 您已经使用该域名发送过电子邮件（例如：您过去在之前的服务商或在 Klaviyo 的发件人地址中使用过该域名）。

在对您的账户应用任何域名更改之前，请****暂停所有发送任务****。一旦您应用了更改并完成测试，即可恢复 Flow并排期发送未来的 Campaign。

###### ****清单 (Checklist)****

- 连接品牌发件域名并生成 DNS 记录。
- 在您的 DNS 提供商处更新 DNS 记录（请注意，此操作不在 Klaviyo 内部完成）。
- 验证并应用您的域名。
- ****新 Klaviyo 账户****随后可以开始预热其发送基础架构。对于拥有至少 30 天发送历史的****现有 Klaviyo 账户****，可以恢复正常发送，无需再次预热。

##### ****在 Klaviyo 中生成 DNS 记录****

Klaviyo 需要 3 条 CNAME 记录或 4 条 NS 记录用于邮件身份验证，以及一条 TXT 记录用于域名所有权验证。Dynamic（动态） 路由选项使用 NS 记录，而 Static（静态） 路由选项使用 CNAME 记录。

只有拥有 ****Owner****、****Admin****、****Manage****r 和 ****Campaign Coordinator****用户角色 的人员才能设置品牌发件域名。

1.点击账户左下角的公司名称。

2.选择 ****[Settings](https://www.klaviyo.com/settings/account/personal)****。

![Klaviyo账户设置界面，包含最近的账户列表和设置选项。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2026/01/image-5.png?resize=452%2C552&ssl=1)

3.在主选项卡中选择 [Domains](https://www.klaviyo.com/settings/account/domains)。

4.选择 Add Domain。

5.验证您品牌的 Root domain（根域名） 是否正确。Klaviyo 会自动从您的账户信息中提取该域名。

![输入根域名的界面，提示用户提供将用于发送电子邮件的品牌网站域名，包含示例和警告信息的文本框.](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2026/01/image-6.png?resize=548%2C454&ssl=1)

6.点击 Next。

7.在 Sending domain（发件域名）下方指定一个自定义且未被使用的子域名（即目前尚未在营销活动其他地方使用的子域名，例如 “send”）。

![A screenshot of a Klaviyo interface showing the configuration options for a sending domain, including a preview of 'send.littlepiecesdesigns.com', input fields for a sending domain, and routing type options for dynamic and static email sending.](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2026/01/image-7.png?resize=1008%2C842&ssl=1)

8.选择您期望的 Routing类型（即 Dynamic 或 Static）。

- Dynamic选项仅适用于支持动态配置的域名。

9.选择是否要向您的域名添加 DMARC 记录（为了满足 Gmail 和 Yahoo 的发件人要求，建议勾选此项）。只有当前缺少 DMARC 记录的域名才会看到此选项。

10。选择您是想通过 Entri 连接域名，还是进行手动设置。

![一个界面，用于自动配置域名与 Entri 连接，包含便利功能的图示和按钮，如 'Connect with Entri' 和 'Set up manually'，同时有关于快速安全设置、准确的 DNS 检测和自动配置的说明。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2026/01/image-8.png?resize=1024%2C429&ssl=1)

如果您选择****手动设置****域名，系统将为您呈现生成的 DNS 记录，以便您手动将其添加到 DNS 中。若选择通过 ****Entri**** 进行****自动配置****，系统将代表您自动添加这些记录。

目前，无法在 Sendgrid 基础架构上同时使用“静态品牌发件域名”和“专用点击跟踪 (Dedicated Click Tracking)”。如果您正在使用 Sendgrid 的专用点击跟踪，请更新您的 CNAME 记录以使用 Klaviyo 基础架构，或者设置“动态品牌发件域名”。

##### ****DMARC****

DMARC 是一种****邮件身份验证****策略，它允许收件箱服务商验证电子邮件的真实性，使域名所有者能够保护其域名免受未经授权的使用。DMARC 策略也是 Gmail 和 Yahoo 为了能让邮件成功进入收件箱而建立的****发件人要求****。

如果您希望 Klaviyo 生成 DMARC 记录，请在设置品牌发件****弹窗****（此处指域名设置界面）时，开启“添加 DMARC 记录” (Add DMARC record) 选项。

![显示添加 DMARC 记录的弹窗，提示用户其域名缺少 DMARC 记录，可能影响邮件送达，建议添加 DMARC 记录以保护域名信誉。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2026/01/image-9.png?resize=540%2C392&ssl=1)

Klaviyo 将生成以下 DMARC 记录，该记录不会影响邮件的送达，但能满足 Gmail 和 Yahoo 的发件人要求： `v=DMARC1; p=none;`

##### ****更新您的 DNS 记录****

###### ****通过 Entri 自动发布记录****

若要让 Klaviyo 代表您自动发布 DNS 记录，请在品牌发件域名设置过程中选择 ****Connect with Entri**** 选项。

选择此选项后，Klaviyo 将分析您的域名以检测其托管的 DNS 提供商。识别完成后，系统会提示您使用相应的凭据登录您的 DNS 提供商，从而授予 Klaviyo 代表您发布记录的访问权限。

![Namecheap 登录界面，包含用户名和密码字段，以及继续按钮和其他选项。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2026/01/image-10.png?resize=660%2C650&ssl=1)

如果您团队中的其他成员负责管理 DNS 设置，您可以通过选择 ****Or forward login to someone else****（或将登录信息转发给他人）来发送登录链接。此外，您也可以通过选择 ****Show added DNS records****（显示已添加的 DNS 记录）来查看正在添加的记录。

登录成功后，Klaviyo 将自动设置必要的记录，您的域名即配置完成并可用于发信。配置完成后，您将看到确认信息。

![在品牌发件域名设置完成后的提示框，显示发送域名已配置成功的信息，包含完成状态和后续说明。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2026/01/image-11.png?resize=660%2C674&ssl=1)

##### ****手动设置您的域名****

如果您选择手动设置品牌发件域名，此步骤需要您在 Klaviyo 平台之外完成相关任务。您需要将 Klaviyo 生成的新 DNS 记录应用到您的域名中。请注意，您需要前往公司域名 DNS 提供商的平台进行这些更改。在执行以下后续步骤时，您可能还需要咨询您的 IT 团队。

****您无需在 DNS 设置中专门创建一个子域名。**** CNAME 和 NS 记录应直接添加到您品牌的****根域名****下，这些记录会自动将品牌域名设置过程中指定的子域名重定向至 Klaviyo 的基础架构。

并非所有的域名注册服务商都允许您直接编辑所有 DNS 记录。如果您无法更新这些记录，请联系您的 DNS 提供商，咨询如何进行更新。

在选择 ****Set up manually****（手动设置）后，请在 ****Find your DNS zone file****（查找您的 DNS 区域文件）页面选择您的域名提供商。Klaviyo 会根据您的域名提供商，显示在该提供商平台中查找区域文件的具体步骤。区域文件就是您添加生成的 DNS 记录的地方。

1. 选择 ****Next****（下一步）。
2. 将鼠标悬停并点击文本，将生成的 DNS 记录复制到剪贴板，以便将其添加到您的 DNS 区域文件中。
3. 在您的域名提供商平台中，将这些记录添加到您的区域文件中。

![一张展示如何在DNS区域文件中添加记录的图表，包含NS和TXT记录的类型、名称和值的列。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2026/01/image-12.png?resize=850%2C762&ssl=1)

##### ****验证并应用您的域名****

在执行以下步骤之前，请确保您已准备好开始使用该域名发送邮件。如果您连接的是一个全新的、没有邮件发送历史的品牌发件域名，您需要先****预热该域名 (Warm this domain)****。

如果您是一个****现有账户****，且在 Klaviyo 已有至少 30 天的发送历史，则****无需****重新预热。

1. 在将生成的记录添加到您的 DNS 后，点击 ****Verify****（验证）按钮开始验证流程。
2. 当您第一次进入“验证记录”步骤时，看到记录显示“尚未验证 (not been verified yet)”是正常现象。

![Klaviyo界面显示如何添加DNS记录，包括类型、名称和对应的值，用户可以设置品牌发件域名。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2026/01/image-13.png?resize=1024%2C578&ssl=1)

查看出现的提示信息。您将看到以下信息之一：

- ****如果存在冲突的 Campaign：**** 您将看到一条通知，提示送达率可能会受到影响。为避免冲突错误，最佳做法是确保当前没有正在发送或计划在短期内发送的 Campaign。此外，虽然不是强制要求，但最佳做法是在应用并测试更改之前，先暂停所有 Flow（自动化流）和 Campaign。
- ****如果您的记录有效：**** 您将看到一条成功消息。此消息可能会提示您需要重新预热基础架构。请注意，这****仅适用于****全新的 Klaviyo 账户或新注册的域名（过去 30 天内注册）。如果您是已有至少 30 天 Klaviyo 发送历史的现有账户，则****无需****重新预热。
