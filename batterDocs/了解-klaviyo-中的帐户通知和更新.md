<h1>了解 Klaviyo 中的帐户通知和更新</h1>

<h2>你将会学到</h2>
<p>了解 Klaviyo 如何通知您帐户发生重大变化。通知可以通过以下两种格式之一发送：</p>
<p>1. 电子邮件更新</p>
<p>2.应用内通知</p>
<p>这些通知可能涉及各种主题，包括：</p>
<ul>
<li>新功能发布</li>
<li>集成错误</li>
<li>付款失败</li>
<li>一般帐户更新或警报</li>
</ul>
<h2>电子邮件更新</h2>
<p>帐户所有者可能会收到来自 Klaviyo 的有关重要更新或帐户警报的电子邮件警报。</p>
<p>为确保您收到这些通知，请保留准确的联系信息并定期检查您的收件箱。</p>
<p>电子邮件更新的主要类别（附示例）如下：</p>
<ul>
<li>****交付能力****</li>
</ul>
<p>提醒您有关高[跳出率](https://help.klaviyo.com/hc/en-us/articles/115005250408) 或已取消的广告活动。这些警报仅针对因内容或信誉问题而导致的退回邮件发送，并且特定收件箱提供商的退回邮件率必须至少为 25%。</p>
<ul>
<li>****计费****</li>
</ul>
<p>当您达到帐户发送限额的 95%（在免费计划中）或付款失败时发送。请注意，帐户所有者或管理员可以[更新接收账单通知的人员。](https://klaviyo.zendesk.com/hc/en-us/articles/1260805043069)</p>
<ul>
<li>****集成****</li>
</ul>
<p>当您成功集成网站或集成失败时提供更新。</p>
<ul>
<li>****列表和细分****</li>
</ul>
<p>列表导入成功时通知您。</p>
<ul>
<li>****对话****</li>
</ul>
<p>当订阅者不使用关键字向您的 SMS 发送号码发送短信时通知您。</p>
<h2>应用内通知</h2>
<p>应用内通知提供有关您帐户的重要信息，包括：</p>
<ul>
<li>平台更新</li>
<li>访问基准报告下载</li>
<li>帐户更新</li>
</ul>
<p>如果您有权访问多个 Klaviyo 帐户，请注意，应用内通知并不特定于您当前登录的帐户，并且可以与您的任何一个帐户相关。</p>
<h3>访问应用内通知</h3>
<p>所有未读通知均由 Klaviyo 帐户顶部铃形图标上方的数字表示。单击响铃图标可查看所有未读消息的列表，最新消息列在最前面。</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28705663893275" alt="notifications_icon.jpg" />
<p>显示数量最多可显示 99 条未读消息。任何其他未读消息仍会捕获在通知列表中，但不会增加显示的计数。</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28705663895323" alt="klaviyo_notifications.jpg" />
<h3>如何阅读个人通知</h3>
<p>1. 单击响铃图标打开通知列表。</p>
<p>2. 根据需要滚动浏览通知。请注意，如果您到达列表的末尾，则会显示一条消息通知您<strong>您已到达末尾。</strong></p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28705637115035" alt="you_ve_reached_end_notifications.jpg" />
<p>3. 选择一个通知以将其展开以了解更多详细信息。每个通知还包含生成日期。这些细节可能涉及：</p>
<ul>
<li>如何调整您的帐户设置或其他帐户信息</li>
<li>如何修复特定错误</li>
<li>有关最近发布的功能的更多信息</li>
</ul>
<p>4. 查看通知后，未读计数减少，文本变为粗体，状态圈消失。</p>
<p>5. 单击<strong><em>*关闭</strong></em>* 或后退箭头返回到完整列表。</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28705663900187" alt="dismiss_or_go_back_notification.jpg" />
<h3>如何将所有消息标记为已读</h3>
<p>如果您想一次性将所有消息标记为已读以忽略所有通知：</p>
<p>当您收到应用内通知时，请务必阅读并采取必要的操作。仅当您了解每条通知及其相关详细信息时，才应将所有消息标记为已读，因为它们可能涉及对您的帐户成功至关重要的操作。</p>
<p>1. 单击响铃图标打开通知列表。</p>
<p>2. 选择<strong><em>*全部标记为已读</strong></em>*。</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28705663901211" alt="mark_all_as_read.jpg" />
<p>将所有通知标记为已读后，您的通知编号将重置，所有项目将不再以粗体显示并带有状态圈。</p>
