<h2>开始之前</h2>
<p>只有通过[帐户验证](https://klaviyo.zendesk.com/hc/en-us/articles/115000628331)的付费帐户才能启用自定义托管页面。</p>
<p>请注意，只有当您精通代码或您的团队中有[开发人员](https://connect.klaviyo.com/)时，您才应该尝试自定义代码自己的托管页面。 Klaviyo 目前不提供帮助构建自定义代码的服务，也不提供自定义代码故障排除的支持。请访问我们的[同意页面入门指南](https://help.klaviyo.com/hc/en-us/articles/115005251848-Getting-started-with-opt-in-lated-pages-for-a-list)，了解有关自定义 Klaviyo 内置页面的更多信息。</p>
<h2>关于托管页面</h2>
<p>托管页面使您可以灵活地创建感觉更“品牌”的自定义同意页面，使您的 Klaviyo 托管页面与您的网站设计保持一致。更大的灵活性也带来了更复杂的形式。在对表单进行编码时，您可以收集有关订阅者的大量信息，以用于细分和定位目的。</p>
<p>自定义托管页面必须使用 HTML 和 CSS 构建。仅当您精通代码或您的团队中有开发人员时，才尝试对您的同意页面进行自定义编码。 Klaviyo 目前不提供帮助构建自定义代码的服务，也不提供自定义代码故障排除的支持。</p>
<p>请注意，未发送到单个列表的电子邮件（例如，指标触发的流电子邮件或发送到分段的营销活动）将使用您的自定义托管同意页面，而发送到列表的电子邮件将使用该特定列表的同意页面。如果您希望这些更改反映在您的帐户中，请务必配置您的[列表的同意页面](https://klaviyo.zendesk.com/hc/en-us/articles/115005251848)，以将所有默认值替换为新的自定义托管页面。</p>
