<h1>如何使用订单编辑技能</h1>

<h2>你将会学到</h2>
<ul>
<li>订单编辑技能的用途以及它如何与客户中心配合使用。 - 激活该技能需要什么先决条件。 - 代理商如何指导客户修改和取消订单。 - 如何测量票据偏差和解决率。 ## 开始之前</li>
</ul>
<p>在使用订单编辑技能之前，您需要满足以下条件：</p>
<ul>
<li>****客户代理****在您的帐户上启用。 - ****客户中心**** 已激活并已配置。 [如何设置客户中心]</li>
<li>****Shopify 集成**** 连接并同步订单数据。 [待定：Shopify 集成文章的链接]</li>
<li>****有关您的订单修改和取消政策的知识库内容****已上传到客户代理。 [如何管理客户代理内容]</li>
<li>****管理员或所有者角色****来配置技能。所有角色都可以查看技能设置。订单编辑技能可在 ****webchat**** 和 ****SMS**** 渠道上使用。 ## 概述</li>
</ul>
<p>订单编辑技能可让客户代理自动处理订单修改和取消请求。当客户要求更改或取消订单时，代理商：</p>
<p>1. 在您的知识库中搜索您品牌的订单修改和取消政策。 2. 通过提示客户登录（如果尚未经过身份验证）来验证客户的身份。 3. 通过 Shopify 集成检索客户的个人资料并检查订单状态。 4. 确定订单是否仍可编辑（尚未履行或发货）。 5. 引导客户进行适当的下一步。 ### 根据订单状态会发生什么</p>
<p>| <strong><em>*订单状态</strong><strong> | </strong><strong>代理行为</strong></em>* |</p>
<p>| --- | --- |</p>
<p>| <strong><em>*未实现</strong></em>*（可编辑）|显示用于在客户中心编辑订单的直接链接或按钮。 |</p>
<p>| <strong><em>*部分履行</strong></em>* |解释哪些项目仍可以修改并相应地指导客户。 |</p>
<p>| <strong><em>*已履行/已发货</strong></em>* |通知客户并重定向至退货和换货技能。 |</p>
<h3>特定于渠道的行为</h3>
<ul>
<li>****Webchat：**** 显示带有内联编辑选项的订单卡以及指向客户中心的直接链接。 - ****短信和 WhatsApp：**** 发送到客户中心订单选项卡的深层链接，客户可以在其中进行更改。 - ****电子邮件：**** 发送指向客户中心订单选项卡的深层链接，客户可以在其中进行更改。 ****重要提示：**** 代理商不直接编辑订单。它引导客户进入客户中心，在那里他们自己完成修改。这可确保更改通过您的标准订单管理工作流程。 ## 设置</li>
</ul>
<h3>第 1 步：验证您的先决条件</h3>
<p>1. 确认您的 Shopify 集成已连接并同步。导航到<strong><em>*集成 > Shopify</strong><strong> 并检查活动连接。 2. 确认客户中心处于活动状态。导航至</strong><strong>客户中心</strong></em>*并验证设置是否已完成。 ### 第 2 步：上传您的订单政策</p>
<p>1. 转至<strong><em>*客户代理 > 内容</strong></em>*。 2. 上传或添加涵盖以下内容的知识库文章：</p>
<ul>
<li>您的订单修改政策（例如时间窗口、符合条件的变更）。 - 您的订单取消政策（例如，截止时间、补货费用）。 - 任何特定于产品的例外情况。 3. 保存您的更改。代理使用此内容提供准确的、针对特定品牌的答案。如果您的知识库中没有明确的政策，代理可能无法为客户提供明确的指导。 ### 第 3 步：确认技能已激活</li>
</ul>
<p>1. 转到<strong><em>*客户代理 > 技能</strong><strong>。 2. 在技能列表中找到</strong><strong>订单编辑</strong><strong>技能。当满足您的先决条件时，它默认处于活动状态。 3. 确认状态显示</strong><strong>Live</strong><strong>。如果显示</strong><strong>不可用</strong></em>*，请检查客户中心是否处于活动状态并且 Shopify 是否已连接。 ### 第 4 步：测试体验</p>
<p>1. 转至客户代理 > 代理预览来测试您的客户代理。 2. 发送一条测试消息，例如“我可以更改最近订单的尺寸吗？”或“我需要取消订单。”</p>
<p>3. 验证代理：</p>
<ul>
<li>提示您登录（如果未经过身份验证）。 - 检索正确的顺序。 - 显示要在客户中心编辑的链接或卡片。 ## 最佳实践</li>
</ul>
<h3>写出清晰、具体的订单政策</h3>
<p>代理的作用取决于您知识库中的内容。包括：</p>
<ul>
<li>****修改窗口。**** 明确说明客户下订单后多长时间可以进行更改（例如，“订单可以在下单后 1 小时内修改”）。 - ****符合条件的修改。**** 指定可以更改的内容：尺寸、颜色、送货地址、数量。 - ****取消规则。**** 定义取消截止日期、任何补货费用和退款时间表。 - ****例外。**** 注明无法修改的产品类别或订单类型（例如个性化商品、预订单）。 ### 设定对边缘情况的期望</li>
</ul>
<p>添加涉及以下内容的知识库内容：</p>
<ul>
<li>如果订单部分发货会发生什么情况。 - 如何处理添加新商品的请求（需要新订单或联系支持人员）。 - 当代理应该移交给人工代理时。 ### 为不支持的场景配置切换</li>
</ul>
<p>如果客户的请求超出了订单编辑技能的处理范围，客服人员会执行软移交给人工客服人员。确保您的切换配置是最新的。 [如何配置客户代理移交]</p>
<h2>故障排除</h2>
<h3>代理未参考您的取消政策</h3>
<p><strong><em>*症状：</strong><strong> 客户询问取消订单，代理商提供通用指导，而不是您品牌的具体政策。 </strong><strong>可能的原因：</strong><strong> 您的知识库不包含取消政策内容，或者该内容的结构不清晰，无法供代理检索。 </strong><strong>修复：</strong></em>*</p>
<p>1. 转至<strong><em>*客户代理 > 内容</strong></em>*。 2. 搜索您的取消政策。如果不存在，请添加。 3. 使用清晰的标题和直接的语言（例如“订单取消政策”），以便代理可以将内容与客户的问题相匹配。 ## 常见问题解答</p>
<p><strong><em>*代理商可以直接在 Shopify 中编辑或取消订单吗？</strong><strong> 不可以。代理商会引导客户前往客户中心，在那里他们可以自行更改。代理不会直接修改订单数据。 </strong><strong>如果客户想要向现有订单添加商品，会发生什么？</strong><strong> 代理解释说，不支持通过客户中心向现有订单添加商品。它建议客户下新订单或联系支持人员寻求帮助。 </strong><strong>如果没有客户中心，订单编辑是否有效？</strong><strong> 不行。自助编辑体验需要客户中心。如果没有客户中心，客服人员将执行软移交给人工客服人员，而不是引导客户编辑订单。 </strong><strong>哪些渠道支持订单编辑技能？</strong><strong> 微信和短信。在网络聊天中，客服人员会显示带有内联编辑选项的订单卡。在 SMS 上，代理将深层链接发送到客户中心订单选项卡。 </strong><strong>客户需要登录吗？</strong><strong> 是的。代理在检索订单数据之前需要进行身份验证。如果客户尚未登录，客服人员会提示他们先登录。这可确保订单数据仅与经过验证的帐户持有人共享。 </strong><strong>如果仅发货了部分订单怎么办？</strong></em>* 代理会检查行项目级别的履行状态。它解释了哪些项目仍然可以修改以及哪些项目已经发货。对于已发货的物品，客服人员会重定向至退货和换货技能。 ## 后续步骤</p>
