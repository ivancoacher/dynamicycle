<h1>开始使用 Wix</h1>

<h2>你将会学到</h2>
<p>了解如何轻松地将 Klaviyo 与您的 Wix 网站集成，以便将客户资料、订单和目录信息同步到 Klaviyo。有了这些数据，您将能够通过细分、自动化流程和营销活动，通过有针对性的消息传递来吸引客户。与 Wix 集成将：</p>
<ul>
<li>创建所有数据（客户、订单、目录）到您的 Klaviyo 帐户的历史同步。 - 今后将数据实时同步到您的 Klaviyo 帐户。 - 通过将 Klaviyo 的现场 JavaScript 自动添加到您的网站，启用 Klaviyo 注册表单和**活跃的网站**访客跟踪。通过 Klaviyo 注册表单，您可以收集电子邮件和短信订阅者。请注意，Klaviyo 嵌入式表单不适用于 Wix。 - 允许将 Wix 电子邮件订阅者（通过 Wix 页脚表单或结帐时收集）添加到 Klaviyo 列表（也称为受众）。 ## 开始之前</li>
</ul>
<p>为了使用 Klaviyo 与 Wix 的集成，您的 Wix 站点必须：</p>
<ul>
<li>有一个高级计划</li>
<li>有一个连接的域</li>
<li>发表</li>
</ul>
<p>当您将 Wix 与 Klaviyo 集成时，每个 Klaviyo 帐户只能连接一个 Wix 商店。如果您尝试添加第二个 Wix 商店，它将取代第一个商店，但您的帐户中仍然会有第一个商店的数据。如果您有多个 Wix 商店，您应该将它们连接到单独的 Klaviyo 帐户。 ## 集成视频</p>
<p>查看有关与 Wix 集成的分步视频。 ![](https://fast.wistia.com/embed/medias/hqgxzcxeu9/swatch)</p>
<h2>如何与 Wix 集成</h2>
<p>1. 如果您需要在 Klaviyo 中创建新列表，请导航至<strong><em>*受众</strong><strong>下拉列表中的</strong><strong>列表和细分</strong><strong>选项卡。 2. 单击</strong><strong>创建列表/段</strong><strong>。 3. 为列表命名并分配任何标签。 4. 单击</strong><strong>创建列表</strong><strong>。 1. 在您的 Klaviyo 帐户中，单击左侧导航栏中的</strong><strong>集成</strong><strong>。 2. 选择</strong><strong>探索应用程序</strong><strong>，搜索</strong>Wix<strong>，然后单击该卡。然后，单击</strong><strong>安装</strong><strong>。 3. 单击</strong><strong>连接到Wix</strong></em>*。 ![Klaviyo 中的页面让 Wix 与 Klaviyo 集成，并以黑色背景连接到 Wix](https://klaviyo.zendesk.com/hc/article_attachments/28717988326811)</p>
<p>4. 您将被带到您的 Wix 帐户并提示登录（如果您当前尚未登录）。 5. 登录后，检查权限并单击“<strong><em>*添加到站点</strong></em>*”以返回 Klaviyo。 ![Wix Klaviyo 集成权限页面，其中列出了权限，“添加到站点”为蓝色背景，“取消”为白色背景](https://klaviyo.zendesk.com/hc/article_attachments/28717994095131)</p>
<p>6. 检查您的商店 URL 设置，确保您选择了正确的 Wix 帐户来与 Klaviyo 集成。 ![Klaviyo 中的 Wix 集成设置页面，您即将完成商店 URL、现场 JavaScript 和电子邮件订阅者设置](https://klaviyo.zendesk.com/hc/article_attachments/28717988320539)</p>
<p>7、默认勾选<strong>自动添加Klaviyo现场JavaScript</strong>设置；如果您想启用 Klaviyo 的 <strong>Active on Site</strong> 跟踪和注册表单，请将其保留为选中状态。 8. 如果您愿意，请检查设置 <strong>将 Wix 电子邮件订阅者添加到 Klaviyo 列表</strong>；选择通过 Wix 发送电子邮件的客户（例如在结账时或使用 Wix 页脚表单）将自动添加到您选择的 Klaviyo 列表中。 9. 从下拉列表中选择您想要添加订阅者的 Klaviyo 列表，例如新闻通讯列表。 10. 单击<strong><em>*完成设置。</strong></em>*</p>
<p>11. 加载屏幕后，您应该会看到一条成功消息：<strong>您的 Wix 帐户现已连接到 Klaviyo！</strong></p>
<p>您已完成集成，您的 Wix 数据现在将开始同步到 Klaviyo。如果您需要编辑 Wix 设置：</p>
<p>12. 在您的 Klaviyo 帐户中，选择<strong><em>*集成</strong><strong>选项卡。 13. 在 </strong>启用的集成<strong> 列表中选择 </strong><strong>Wix</strong><strong>。 14. 您将进入集成设置页面，您可以在其中进行更改。 15. 单击</strong><strong>保存设置</strong></em>*。 ## 数据从 Wix 同步到 Klaviyo</p>
<p>要检查从 Wix 到 Klaviyo 的数据同步：</p>
<p>1. 在您的 Klaviyo 帐户中，选择<strong><em>*集成</strong><strong>选项卡。 2. 在列表中选择</strong><strong>Wix</strong><strong>。 3. 选择顶部的</strong><strong>数据</strong><strong>选项卡。在这里，您将看到从 Wix 同步到 Klaviyo 的最新数据，以及历史数据同步的同步进度条。如果您遇到同步问题，请在此处选择</strong><strong>重新启动导入</strong></em>*以重新启动历史数据同步。 从 Wix 同步到 Klaviyo 的数据包括：</p>
<ul>
<li>[已知网站访问者](https://help.klaviyo.com/hc/en-us/articles/115005076767-Guide-to-Klaviyo-Onsite-Tracking#who-klaviyo-tracks5) 被跟踪为 **Active on Site** 事件（如果您选中了现场 JavaScript 设置）</li>
<li>电子邮件订阅者（如果您选择将他们添加到 Klaviyo 列表）</li>
<li>与订单事件相关的个人资料信息</li>
<li>您的 Wix 目录</li>
<li>以下订单事件：</li>
<li>放弃结帐（请注意，**放弃结帐**事件没有历史同步，只有从集成时开始的同步）</li>
<li>已下订单</li>
<li>修改已下订单</li>
<li>订购的产品</li>
<li>已退款的订单</li>
<li>取消订单</li>
<li>已履行的订单</li>
<li>已履行部分订单</li>
</ul>
<p>有关与从 Wix 同步的每个事件关联的属性的更多信息，请查看我们的文章 [Wix 数据参考](https://help.klaviyo.com/hc/en-us/articles/6202715127579)。 ## 使用 Wix 创建自动消息传递</p>
<p>Klaviyo 的流程库中有许多针对 Wix 的预构建流程，您可以使用它们来个性化客户消息传递。这些流程可以通过以下方式访问：</p>
<p>1. 在 Klaviyo 中选择<strong><em>*Flows</strong><strong> 选项卡。 2. 单击右上角的</strong><strong>浏览创意</strong><strong>。 3. 从搜索栏旁边的过滤器下拉列表中选择 </strong><strong>Wix</strong></em>*。这些预先构建的流程包括废弃购物车提醒、客户赢回、交叉销售和重复购买培养流程。 ## 故障排除</p>
<h3>为什么我的 Wix 订阅者没有添加到我的 Klaviyo 列表中？如果您使用 Wix 注册表单来收集网站上的订阅者，但提交表单的订阅者没有添加到您的 Klaviyo 列表中，这很可能是因为这些联系人在 Wix 中没有被标记为“已订阅”。 Wix 注册表单有很多种，但并非所有注册表单都会为 Wix 中的联系人添加“订阅”标签。 Klaviyo 需要此“订阅”标签才能将配置文件正确添加到您在集成设置页面上指定的列表中。如果您的表单在联系人提交表单时添加“已订阅”标签，则该标签将显示在联系人上，如下所示：</h3>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28717988324635" alt="Wix 中的联系人，包含电子邮件地址和订阅标签" />
<p>如果此标签丢失，您需要更新您的 Wix 表单以确保它添加“订阅”标签。您可以[创建订阅表单](https://support.wix.com/en/article/wix-forms-adding-and-setting-up-a-subscribe-form#adding-a-subscribe-form-to-your-site)或[将订阅者字段添加到独立的form](https://support.wix.com/en/article/wix-forms-adding-and-setting-up-a-subscribe-form#add-a-subscriber-field-to-a-standalone-form)以确保添加标签。现在，您的订阅者应该从 Wix 正确同步到您的 Klaviyo 列表。 ## 结果</p>
<p>您已将 Wix 与 Klaviyo 集成并验证了您的同步数据。现在，您可以根据从 Wix 同步的数据创建自动流消息、个性化营销活动、细分列表等。</p>
