<h1>About your review pipeline</h1>

Learn about the path from a placed order to a submitted review, including how Klaviyo makes it easy to see every order’s status in your review pipeline.

## About the Orders tab

If you navigate to ****Reviews > Orders****, you’ll see a list of recent orders and their review pipeline status. Use this page to understand when someone will receive a review request, make changes to review request timing, and more.

## Request statuses

In the **Request status** column of the ****Orders**** tab, every order’s review pipeline status is listed. The following statuses are available:

- ********Queued********
  ****The**** ******Ready to review****** ****event has been scheduled for a future date/time, based on your settings.****
- ****Ready to review****
  A **Ready to review** event has been triggered for this order. Head to the customer’s profile to confirm they’ve received the first message of your review request flow. Note that a review request may not have been sent if the profile failed your flow’s filters, or if you have a time delay in the flow.
- ****Reviewed****
  The customer has reviewed one or more items from the order.
- ****Excluded****
  The order was not eligible for review because all items in it were [excluded](https://help.klaviyo.com/hc/en-us/articles/16684841274139).
- ****Usage limit****
  You have a review plan that is too small for your order volume. Upgrade your reviews plan for higher volume. It is not currently possible to re-trigger a review request for an order skipped due to usage limits.
- ****Missing data****
  The order is missing necessary data. Most often, this means the product IDs in the order don’t match any product IDs in your Klaviyo catalog.

## How to manually adjust review timing

If a review is currently **Queued**, you can elect to trigger the review request immediately. Note that this will only initiate the review request flow; if the recipient fails the flow’s filters, isn’t eligible to receive marketing messages, or if the flow is not live, then they will not receive a review request.

This process is not immediate. Once you click ****Skip waiting time****, it may take several minutes for the **Ready to review** event to fire.

### Skip waiting time for a single order

1. Navigate to ****Reviews > Orders****.
2. Locate an order with the review status **Queued**.
3. Click the three dots icon to open an additional options menu.
4. Select ****Skip waiting time****.

### Skip waiting time for all queued orders

1. Navigate to ****Reviews > Orders****.
2. Click ****Actions****.
3. Select ****Skip waiting time****.
