<h1>了解专用 IP 预热</h1>

<h2>你将会学到</h2>
<p>了解有关预热和设置专用 IP 地址的过程的更多信息。专用 IP 地址（不要与[专用发送域](https://help.klaviyo.com/hc/en-us/articles/7674941873947) 混淆）由满足 Klaviyo 上某些发送条件的 Klaviyo 托管帐户使用。使用专用 IP 地址的主要好处是，IP 地址的声誉只能受到使用该地址的单个帐户的影响。 [详细了解使用专用 IP 的优点和缺点](https://help.klaviyo.com/hc/en-us/articles/7675517826587)。要了解您是否有资格获得专用 IP 以及有关预热过程的更多详细信息，请联系您的客户成功经理以获取更多信息。有关计划和成功支持的更多信息，请详细了解[我们的免费和付费计划有何不同](https://help.klaviyo.com/hc/en-us/articles/360050759151-How-Free-and-Paid-Plans-Differ#talk-with-customer-success-managers-and-onboarding-specialists4)。 ## 专用 IP 升温有何不同</p>
<p>设置新的专用 IP 与增加共享 IP 是完全不同的过程，因为专用 IP 需要充分预热，而共享 IP 更专注于增加发送量。 [详细了解升温和升温之间的差异](https://help.klaviyo.com/hc/en-us/articles/7520811253275)。在开始以下任何流程之前，请务必联系您的客户成功经理，了解有关专用 IP 的更多信息以及您是否有资格获得专用 IP。想要开始使用新的专用 IP 的现有客户和新客户首先需要：</p>
<ul>
<li>暂停在其他地方进行的任何第三方联属营销。 - 更新、刷新或暂停任何表现不佳的电子邮件模板。 - 清理您的列表以删除未参与的个人资料和无效的电子邮件地址。请参阅我们的[列表清理指南](https://help.klaviyo.com/hc/en-us/articles/115005078347) 了解更多信息。 ## 升温计划</li>
</ul>
<p>然后，您需要在预热期的前 30 天内首先集中精力发送营销活动（即不是流量）。您的发送计划将取决于您是 Klaviyo 现有客户还是新客户、发送频率以及受众参与度。重要的是要关注活动而不是流量，因为您可以更好地控制选择加入同意；然而，某些流程（例如废弃的购物车或浏览废弃）很少包含此内容。您还必须避免任何列表轰炸策略的风险，因为这通常是由恶意行为者执行的，并且会损害您的发件人声誉。请注意，您必须与客户成功经理和成功团队合作，在整个专门的知识产权预热过程中提供量身定制的帮助。您的成功团队将帮助您制定适合您需求的计划。未能与您的团队密切合作可能会导致 IP 声誉问题，并且 Klaviyo 不允许客户因声誉问题而切换专用 IP。 ## 监控成功</p>
<p>设置并遵循发送计划后，将点击作为主要参与事件非常重要。自ios15和MPP发布以来，[打开可能会因机器驱动而倾斜](https://help.klaviyo.com/hc/en-us/articles/4416803987739)打开。在此期间，请重点关注发送一致性，而不是发送量。当将专用 IP 分配给适当分配流量的客户时，Klaviyo 的后端具有自动预热过程。 ## 自动 IP 预热</p>
<p>当开始在新的 IP 地址上发送电子邮件时，必须逐步发送电子邮件，以避免被之前未见过该 IP 活动的收件箱提供商阻止。这种预防措施是必要的，因为垃圾邮件发送者经常从新激活或长期休眠的 IP 发送大量电子邮件。为了防止引发怀疑，Klaviyo 最初通过专用 IP 发送一小部分电子邮件，同时通过共享 IP 路由其余电子邮件。随着时间的推移，通过专用 IP 发送的电子邮件的比例逐渐增加。一旦通过专用 IP 发送了 100% 的预期电子邮件量，IP 预热过程就会自动完成。此过程通常需要 3-4 周，但具体时间可能会根据发送量和模式而有所不同。关于专用 IP 预热，有几个关键方面需要注意：</p>
<ul>
<li>预热期的持续时间取决于发送量，但通常持续约 30-40 天。 - 变暖期间专用 IP 上的发送量以非线性曲线增加，大部分发送量增加发生在变暖结束时。 - 我们的客户支持团队在预热期间提供的分段建议是为了为新IP创建强大的发送声誉，而不关心总量。</li>
</ul>
