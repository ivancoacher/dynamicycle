<h1>在拖放编辑器中对电子邮件发表评论</h1>

<h2>你将会学到</h2>
<p>使用 Klaviyo 拖放式电子邮件编辑器中的<strong><em>*评论</strong></em>*，直接在电子邮件块上留下反馈、回复队友并跟踪未完成的更改 - 所有这些都无需离开编辑器。更快的审核周期意味着更少的来回消息和更快的发送时间。 ## 开始之前</p>
<ul>
<li>评论仅可在拖放****电子邮件编辑器****中使用。它们在短信、推送通知或表单中不可用。 - 您必须具有****内容创建者****、****活动协调员****、****经理****、****管理员****或****所有者****角色才能添加、编辑、删除、解决评论或对评论做出反应。具有 ****Analyst**** 角色的用户可以阅读和查看评论，但不能写入评论。 - 处于****只读****模式（无模板编辑访问权限）的用户将看不到块级注释按钮。 - 评论与模板相关联 - 任何有权访问该模板的人都可以看到所有主题。 - 发表评论预计时间：****1–2 分钟****；实时更新意味着队友可以立即看到。 ## 概述</li>
</ul>
<p>评论可让您的团队在发送电子邮件之前直接就电子邮件进行协作。您可以：</p>
<ul>
<li>添加评论到电子邮件中的任何特定块，</li>
<li>回复现有评论线程，</li>
<li>编辑或删除您自己的评论，</li>
<li>一旦反馈得到解决，就解决或取消解决线程，</li>
<li>用表情符号回应评论，</li>
<li>用@提及队友以直接通知他们，以及</li>
<li>控制如何通知您有关新活动的信息。评论仅限于模板并实时更新 - 无需刷新。原始电子邮件内容绝不会因发表评论而改变；注释是设计之上的一层。 ## 设置</li>
</ul>
<h3>打开评论面板</h3>
<p>1. 从 <strong><em>*模板</strong><strong>、</strong><strong>营销活动 > 电子邮件</strong><strong> 或 </strong><strong>流程 > 电子邮件</strong><strong> 打开任何电子邮件。 2. 在编辑器标题的右上角，单击</strong><strong>语音气泡</strong><strong>图标。图标上的徽章显示未解决或未读线程的数量。 3.</strong><strong>评论</strong><strong>面板在画布右侧滑动打开。此处列出了此电子邮件的所有现有主题。 </strong><strong>提示</strong></em>*：随时再次单击该图标即可折叠面板，而不会丢失在编辑器中的位置。 ### 添加评论到块</p>
<p>1. 将鼠标悬停在画布上的任何块上。快速操作工具栏出现在块上方。 2. 单击工具栏中的<strong><em>*评论</strong><strong>图标（对话气泡）。 3. 出现评论编辑器。输入您的反馈 - 您可以使用</strong><strong>粗体</strong><strong>、</strong>斜体<strong>、~~删除线~~和表情符号。 4. 要通知特定队友，请键入@，后跟其姓名，然后从下拉列表中选择他们。 5. 点击</strong><strong>提交</strong><strong>发表评论。一个小头像指示器出现在块的右边缘，表明它有一个活动线程。 </strong><strong>提示</strong></em>*：您还可以从“注释”面板开始 - 首先打开它，然后单击要注释的块。 ### 回复主题</p>
<p>1. 在<strong><em>*评论</strong><strong>面板中，单击任何现有线程以打开详细信息视图。 2. 在线程底部的编辑器中输入您的回复。 3. 单击</strong><strong>提交</strong></em>*。回复按时间顺序显示在原始评论下方。 ### 解决一个线程</p>
<p>1. 在<strong><em>*评论</strong><strong>面板中打开线程。 2. 单击线程标题中的</strong><strong>解决</strong><strong>。线程移动到已解析的视图，并且块指示器从画布上消失。 3. 要重新打开已解决的线程，请使用面板顶部的过滤器显示</strong><strong>已解决</strong><strong> 线程，然后单击</strong><strong>未解决</strong><strong>。 </strong><strong>提示</strong></em>*：任何具有写入权限的团队成员都可以解析或取消解析任何线程 - 您不必是原始作者。 ### 编辑或删除您自己的评论</p>
<p>1. 将鼠标悬停在话题中您的评论上。出现<strong><em></strong><strong></em></strong><strong>（更多）菜单。 2. 选择</strong><strong>编辑</strong><strong>来更新评论正文，然后单击</strong><strong>保存</strong><strong>。 3. 选择</strong><strong>删除</strong>**以删除评论。注释正文被替换为占位符，以保持线程的连续性。 ### 回复评论</p>
<p>1. 将鼠标悬停在线程中的任何评论上。 2. 单击出现的<strong><em>*表情符号</strong></em>* 图标。 3. 选择一个反应。您的头像会显示在反应中，以便队友知道谁做出了反应。 4. 再次单击相同的反应将其删除。 ### 管理通知设置</p>
<p>默认情况下，您将收到有关您评论过的模板上的所有新活动的电子邮件通知。 1. 在<strong><em>*注释</strong><strong>面板中，单击面板标题中的</strong><strong>齿轮</strong></em>* (⚙) 图标。 2. 选择以下三个设置之一：</p>
<ul>
<li>****所有活动**** — 通知您此模板上的每条新评论和回复。 - ****仅提及**** — 仅当有人@提及您时通知您。 - ****关闭**** — 禁用此模板的所有通知。 3. 您的偏好设置会自动保存。</li>
</ul>
