如何在 Klaviyo 中创建并上传 Unique Coupons 与 Static Coupons，从而有效地激励客户与品牌互动。提供这类激励措施能显著提升客户体验，进而带动销量并增加客户的 LTV。

##### ****开始之前****

- 在 Klaviyo 中，你可以通过多种方式使用优惠券。本指南将涵盖以下内容：
- 创建并使用 Static Coupons。
- 上传 Unique Coupons。
- 将优惠券添加至你的 Emails、SMS 以及注册表单的 Success Messages。
- 将优惠券显示为 Barcodes，以便在实体店中使用。
- 针对尚未使用的客户，设置 Coupon Reminders。
- 查看具体折扣码的使用记录。

##### ****Unique Coupons vs. Static Coupons****

在 Klaviyo 中，你可以使用两种类型的优惠券：Static Coupons 和 Unique Coupons。

- Static Coupons 是一个统一的短语或字母数字组合（例如：Welcome20），用于解锁特定的折扣。由于每个用户收到的都是同一个代码，这类优惠券极易在社交媒体上被传播。不过，它的优点是好记、易用，对转化很有帮助。

- Unique Coupons（也称为“动态优惠券”）是由随机数字或字母组成的序列，每个用户只能使用一次。每位收件人都会收到专属的代码，且互不重复。虽然 Unique Coupons 通常比 Static Coupons 更长、更复杂，但它们能有效防止折扣码被过度传播或滥用。

##### ****创建并使用 Static Coupons****

Static Coupons 的生成非常高效。创建完成后，你可以将其直接添加到 Klaviyo 的 Email、SMS 或注册表单的 Success Messages 中。

具体操作步骤如下：

1.在电商平台创建优惠券： 首先在你的电商后台（如 Shopify 等）完成折扣码的设置。

2.在 Message 中直接添加代码： \* 对于 Email 和 SMS 模板，在编辑器中将 Text Block 拖拽到你希望展示优惠券的位置。

3.在 Text Block 中直接输入你的 Static Coupons 代码，并确保字号足够大、清晰易辨。

##### ****上传 Unique Coupons 至 Klaviyo****

当你想要奖励完成特定操作（例如：订阅邮件新闻稿）的用户时，使用 Unique Coupons 是非常理想的选择。若要将 Unique Coupons 上传到 Klaviyo 并在 Email 或 SMS 中使用，你需要完成以下步骤：

1.启用 Uploaded Coupons 功能

2.准备一份 Unique Codes 列表

3.将 Unique Coupon Codes 上传至 Klaviyo

##### ****准备 Unique Codes 列表****

首先，你需要准备一份 Unique Codes 列表。你可以使用任何第三方工具来生成一批 Unique Coupons，并将其保存为 .csv 文件。

在上传前，请务必核对以下事项：

- 确保每个 Code 都是唯一的。
- 确保生成的 Codes 数量足够覆盖所有预计接收该消息的订阅者。
- 确保文件格式已保存为 CSV。
- 列表中的其中一列必须使用 Coupon 或 Coupon Code 作为表头（Header）。

##### ****将 Unique Codes 上传至 Klaviyo****

完成 CSV 文件的准备后，请按照以下步骤将其上传至 Klaviyo：

1.在左侧导航栏中点击 Coupons。

2.切换到 Uploaded Coupons 标签页。

![Klaviyo的优惠券管理界面，显示未上传的优惠券，并提供创建上传优惠券的选项和相关提示。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-54.png?resize=1024%2C484&ssl=1)

3.点击 Create Uploaded Coupon 按钮来添加新的优惠券。如果你之前已经上传过优惠券，该按钮会显示在页面的右上角。

4.设置 Name（名称）、Minimum coupon count（最小优惠券预警值）以及优惠券的 Expiration date（过期日期）。你可以选择 After 1 year（1年后过期）或 On a specific date（指定具体日期）。

![Klaviyo 优惠券创建界面，显示优惠券名称输入框、最小优惠券数量设置和有效日期选项，包括过期时间设置。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-55.png?resize=1024%2C523&ssl=1)

5.点击 Create Coupon 保存设置。

6.在 Uploaded Coupons 选项卡中，找到你刚创建的优惠券，点击旁边的 3 dots（三个点图标）并选择 Add codes。

![Klaviyo 上传的优惠券管理界面，显示优惠券名称、创建时间、最后更新时间以及可用数量。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-56.png?resize=1024%2C372&ssl=1)

7.通过拖拽文件或从电脑中选择文件，上传你准备好的 Unique Codes 列表。

8.预览 CSV 文件的前几行，确认所选的优惠券代码无误。

![Klaviyo 优惠券上传界面展示，包含 CSV 文件中优惠券代码的预览，左侧为添加优惠券代码的选项，右侧显示最近的优惠券上传记录。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-57.png?resize=864%2C724&ssl=1)

9.点击 Import Coupons。

10.导入完成后，你可以查看成功上传的 Codes 数量，以及因重复或数据缺失而被跳过的数量。点击 Done 即可。

![界面显示最近上传至 JustForYou 的优惠券信息，包括上传状态、开始时间、上传者和进度。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-58.png?resize=1024%2C229&ssl=1)

##### ****在 Message 中使用优惠券****

若要在任何消息中添加 Unique Coupon 代码：

1.在文本编辑框中打开 Personalization（个性化）菜单。该菜单通常显示为一个“小人像”图标，或者是一个标有 Personalization 字样的按钮。

![在 Klaviyo 中添加个性化选项的界面，显示一个标有'Add personalization'的按钮，旁边有相关图标。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-59.png?resize=332%2C232&ssl=1)

2.在 All types 菜单中，选择 Coupons。

3.选中你需要的优惠券。
4.优惠券代码将自动插入到文本框中。如果你想在不显示 Personalization 菜单的文本区域（例如 Button block 按钮模块）使用优惠券，可以先将 Tag（标签）插入到普通的 Text block 中，然后将其复制并粘贴到目标位置即可。

![An announcement card displaying a coupon offer of 10% off, with a placeholder for a unique coupon code 'BFCM2022' and a green call-to-action button that says 'Get It'.](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-60.png?resize=358%2C172&ssl=1)

##### ****Email****

每封 Email 中可以包含多个优惠券代码（但每条 SMS 仅限 1 个）。如果你在一条消息中使用了多个优惠券，请务必确保有足够的代码量，让每位收件人都能分配到代码。

对于 Email，你还可以利用 Hidden Blocks（隐藏模块）功能，根据用户所在地或其历史行为发送不同的优惠券。我们建议在使用此功能时保持谨慎，因为即使某些代码在最终显示的邮件中被隐藏了，系统仍可能将其分配给所有收件人；如果代码储备不足，这可能会导致你的邮件发送被拦截。

在 Email 发送完成后，你可以通过点击 Coupons 选项卡并查看 Available/Total（可用/总计）列来检查优惠券代码的剩余情况。

![Klaviyo的优惠券管理界面，显示已上传的优惠券信息，包括优惠券名称、创建日期和可用数量。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-61.png?resize=1024%2C249&ssl=1)

##### ****SMS 或 MMS****

移动端消息（SMS/MMS）仅限包含 1 个 优惠券代码。任何包含多个优惠券的 SMS/MMS 都会触发错误提示，且无法成功发送。

![A screenshot showing a message editor interface with coupon code placeholders and a URL link for a Shopify store.](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-62.png?resize=622%2C616&ssl=1)

##### ****预览消息中的 coupon codes****

发送至邮箱或手机预览： 如果你向自己的邮箱或手机发送预览，系统将真实消耗 1 个已生成的 coupon codes。

真实代码预览规则： 为了在收件箱中预览到真实的 coupon codes，你的账户中必须有可用的代码余量。同一个预览代码会在 1 分钟内重复显示，1 分钟后再次发送预览则会显示一个新的代码。
