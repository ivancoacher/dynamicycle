了解如何直接在 Klaviyo 中使用 Inbox Testing。无需离开您的 Klaviyo 账户或管理单独的订阅，即可使用 Mailgun Email Testing。

##### ****Inbox Testing 限制****

您的 Klaviyo 邮件订阅包含每位账户用户每月 100 次 Inbox Testing 额度。每生成一个收件箱预览即计为 1 次测试。例如，如果您选择 5 个收件箱进行测试，则计为 5 次测试。

因此，在选择要测试的收件箱时最好保持谨慎：请根据您的订阅者群体选择少数几个收件箱进行测试。了解如何查看订阅者收件箱的构成明细。

##### ****运行一次 Inbox Testing****

1.在任何[邮件界面](https://www.klaviyo.com/templates/list)，点击 Preview & Test。

2.在出现的弹窗中选择 Inbox Testing。

![Klaviyo界面中的Inbox Testing功能预览，展示选择和测试邮件的选项.](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-115.png?resize=890%2C676&ssl=1)

3.使用 Search Profiles 字段搜索一个 Profile 进行预览，或者切换到 Events 选项卡并选择一个指标来预览事件数据。请注意，只有在 Template或 Flow中配置邮件时，才能预览事件数据。

![Klaviyo Inbox Testing界面，显示选择个人资料和事件预览的选项，包含剩余测试次数信息。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-116.png?resize=622%2C544&ssl=1)

4.在 Select Inbox Tests 下方，选择 1 个或多个收件箱进行预览。由于每月生成的预览次数有限，我们建议根据您自身订阅者群体中最常用的收件箱选择少量样本。选项被归类在以下可展开的菜单中：

- 深色模式
- 移动端
- 桌面端
- Web

![Klaviyo Inbox Testing interface displaying selected inbox test options including Apple Mail, Gmail, and Dark Mode.](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-117.png?resize=492%2C820&ssl=1)

5.若要为下次 Inbox Testing 保存这些选项，请选择 Save selected as default inbox tests。

6.检查您的选择，然后点击 Run Test。

7.等待几分钟待预览生成。您可以离开此页面稍后返回，但在预览生成期间请勿对模板进行任何编辑，否则预览结果将与更新后的模板版本不匹配。

8.预览准备就绪后，点击对应的缩略图即可查看详细内容。

9.使用箭头在不同预览之间切换，或点击 Back to gallery 。

![Gmail inbox preview displaying a email with a bottle product labeled 'NEW' and a description about rehydrating skin.](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-118.png?resize=1024%2C840&ssl=1)

##### ****如何分享邮件预览链接****

1.进入[任何邮件的模板编辑器](https://www.klaviyo.com/templates/themed)。

2.点击 Preview & Test。

3.在出现的弹窗中选择 Inbox Testing。

4.运行一次 Inbox Testing。

5.当 Inbox Testing 完成后，开启 Share a preview link 设置。点击复制图标将分享 URL 复制到剪贴板。

![分享预览链接的设置界面，包含复制链接功能和链接过期提示。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-119.png?resize=926%2C374&ssl=1)

6.将此链接分享给任何您希望其评审该邮件的人员。

7.分享链接将在 6 天后过期；如果您禁用预览链接分享，链接将立即失效。预览者将能够看到您在运行 Inbox Testing 时选择的所有版本的邮件。

##### ****排查收件箱显示差异****

每个收件箱解析 HTML 的方式都略有不同，这可能会导致邮件呈现效果出现差异。例如，当收件人设备开启了深色模式（Dark Mode）时，收件箱服务商可能会调整或反转邮件颜色，以适应深色配色方案。

此外，某些收件箱对各类 HTML 元素的兼容性有限。通常情况下，Outlook 的支持最为受限，这可能会影响邮件的显示效果。幸运的是，Outlook 的用户通常只占邮件收件人的一小部分。
