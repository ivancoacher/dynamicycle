<h1>How to create static coupons for PrestaShop</h1>

## You will learn

Learn how to create PrestaShop coupons using the Klaviyo module in PrestaShop. You can upload these coupons to Klaviyo and include them in messaging to get your customers excited about promotions on your site.

## Before you begin

- Make sure you’ve already [integrated Klaviyo with PrestaShop](https://help.klaviyo.com/hc/en-us/articles/360054551492).
- In order to use the Klaviyo module to generate coupons, you’ll need to have already set up [cart rules in PrestaShop](https://docs.prestashop-project.org/1.7-documentation/user-guide/selling/managing-catalog/managing-discounts/cart-rules) for the coupons you want to generate.
  ![Cart rules setup page in PrestaShop](https://klaviyo.zendesk.com/hc/article_attachments/28704487105307)

## Create coupons

To create static PrestaShop coupons to use in Klaviyo, do the following:

1. In your PrestaShop admin, select ****Klaviyo**** from the left-hand menu (under **Configure**).
2. Scroll down to the **Coupons** section.
   ![Coupons section in Klaviyo PrestaShop module settings](https://klaviyo.zendesk.com/hc/article_attachments/28704479008283)
3. Provide the cart rule code. The cart rule code should correspond to the **Code** field for the cart rule in PrestaShop.
4. Enter quantity of coupons to generate.
5. Select ****Download coupons****.
6. Upload the coupons in Klaviyo following the [steps in our coupons guide](https://help.klaviyo.com/hc/en-us/articles/115005084727#upload-coupons-into-klaviyo6).

## Outcome

You’ve now created coupons using PrestaShop. After uploading them to Klaviyo, you’ll be ready to [include them in your messaging.](https://help.klaviyo.com/hc/en-us/articles/115005084727#h_01H9NXQT7NDZ7WRXRV7WRGVB3X)
