<h1>解决电子邮件成为垃圾邮件的原因</h1>

<h2>你将会学到</h2>
<p>了解电子邮件进入垃圾邮件文件夹的常见原因。了解电子邮件中那些增加您被发送到垃圾邮件文件夹的可能性的元素可以帮助您提高发件人声誉和订阅者参与率。 ## 开始之前</p>
<p>Klaviyo 负责发送您的电子邮件，但一旦这些电子邮件落入收件箱提供商（即 Gmail 或 Yahoo）手中，这些邮件就会根据每个提供商的规则进行过滤。所有收件箱提供商都有一个内置系统，可以扫描传入的电子邮件，并使用不公开的复杂算法自动对它们进行排序。有关电子邮件送达率和最佳实践的更多信息，请参阅我们的[了解电子邮件送达率]指南。(https://help.klaviyo.com/hc/en-us/articles/115005247008)</p>
<p>虽然收件箱提供商不会报告电子邮件被放入垃圾邮件的具体原因，但这通常是由于发送信誉度较低，这是由于发送给休眠订阅者而造成的。 ## 发件人信誉</p>
<p>发件人信誉是衡量收件箱提供商如何评估您作为发件人的可信度的指标。这决定了电子邮件的排序方式，对于任何电子邮件营销人员都至关重要。由于发送信誉不佳，收件箱提供商可以将发件人的电子邮件直接发送到垃圾邮件。当收件箱提供商确定每个域或 IP 的发件人信誉时，每个提供商都会评估各种指标。影响分数的一些主要指标包括：</p>
<ul>
<li>****参与度（例如打开率和点击率）****参与度是指人们在收到电子邮件后如何与您的电子邮件进行互动，保持高参与率对于良好的送达率非常重要。 - ****发送量和频率****一次发送多少封电子邮件以及发送频率。 - ****退回率****退回率是衡量您的电子邮件退回频率的指标。当电子邮件未成功送达或被收件人的收件箱提供商（例如 Gmail 或 Yahoo）拒绝时，就会发生退回邮件。 - ****垃圾邮件投诉****垃圾邮件投诉率衡量订阅者将您的电子邮件标记为垃圾邮件的频率。 - ****退订率****您的退订率衡量订阅者选择不接收您的电子邮件营销的频率。当个人资料点击您的取消订阅链接或在您的订阅和管理首选项页面中调整他们的同意时，就会发生取消订阅。 ### 参与度</li>
</ul>
<p>在没有“日落政策”的情况下，一遍又一遍地向休眠订阅者发送邮件可能会导致发送信誉随着时间的推移而降低。如果您的发送信誉度足够低，那么您需要[执行列表清理](https://help.klaviyo.com/hc/en-us/articles/115005078347#h_01HRFFZ0S08XSSNSDB2M8YBNSN)来解决问题。如果您发现自己的电子邮件被放入垃圾邮件或垃圾邮件中，我们强烈建议您创建并屏蔽那些[从未参与过](https://help.klaviyo.com/hc/en-us/articles/115005078347)（打开、点击或购买）的用户。 ### 垃圾邮件投诉</p>
<p><a href="https://help.klaviyo.com/hc/en-us/articles/360057985791">垃圾邮件投诉率</a></p>
<p><a href="https://help.klaviyo.com/hc/en-us/articles/360057471831">取消订阅率</a></p>
<p>在短时间内向邮件服务器发送过多电子邮件可能会导致拒绝邮件并将其放入垃圾邮件中。一般来说，每个收件箱每天超过一封电子邮件都是有风险的。如果您遇到电子邮件成为垃圾邮件的问题，那么您应该努力将您的品牌的<strong>每天每个收件箱的电子邮件</strong>降低到小于或等于 1。您可能还需要创建[基于客户参与度的发送计划](https://help.klaviyo.com/hc/en-us/articles/360037527052)，这是实现较高打开率并与订阅者保持积极关系的关键。过于频繁地向未参与的客户发送信息会损害您的发件人声誉，而过于频繁地向参与的客户发送则会浪费金钱。最好通过使用分段和发送时间表来实现快乐的媒介。 ### 跳出率</p>
<p>收件箱提供商在确定如何放置电子邮件时考虑的因素之一是与您的品牌相关的跳出率。当电子邮件未成功送达或被收件人的电子邮件提供商拒绝时，就会发生退回邮件。如果您的帐户出现大量退回邮件，这可能会对您的送达性能和发件人声誉产生负面影响。 [监控此指标](https://help.klaviyo.com/hc/en-us/articles/115000201131) 并在看到此比率上升时采取行动非常重要。您的目标应该是将跳出率控制在 1% 以下。如果您的帐户出现退回问题，请参阅我们的指南，了解如何[降低退回率](https://help.klaviyo.com/hc/en-us/articles/360057036052)。 ## 邮件内容</p>
<p>收件箱提供商使用垃圾邮件过滤器来确定您的电子邮件是否到达收件箱。虽然可以观察垃圾邮件过滤器行为的趋势，但垃圾邮件过滤器的设计使其无法完美地规避它们。您可以通过以下几种方法来明智地处理电子邮件内容：</p>
<ul>
<li>****避免“垃圾邮件”主题行。****</li>
</ul>
<p>很多单词可能会触发垃圾邮件过滤器；因此，我们编写了一些有关主题行单词选择的[注意事项](http://www.klaviyo.com/blog/the-ultimate-ecommerce-spam-trigger-word-list-guide)。一般来说，避免使用全部大写字母。 [研究表明](http://www.radicati.com/wp/wp-content/uploads/2014/01/Email-Statistics-Report-2014-2018-Executive-Summary.pdf) 85% 的收件人更喜欢全小写的主题行而不是全部大写的主题行。全部大写和过多的感叹号都可能触发垃圾邮件过滤器。避免以下情况：</p>
<ul>
<li>使用全部大写来宣传某些内容</li>
<li>使用大量符号!!!!!\*\*\*\*\*\*\*\*</li>
<li>在您的电子邮件中仅包含一张大图片</li>
<li>实施引人注目的或垃圾邮件触发短语，例如“仅此一次，限时”、“100% 免费！”、“立即行动！”</li>
</ul>
<ul>
<li>****在图像和文本之间找到平衡。****</li>
</ul>
<p>仅包含 GIF 和图像（或图像较多）的电子邮件可能会触发垃圾邮件过滤器。相反，电子邮件应包含图像和文本的组合。垃圾邮件发送者经常使用图像来避免垃圾邮件触发词，但收件箱提供商的发展速度更快。 [Email on Acid](https://www.emailonacid.com/blog/article/email-development/does_text_to_image_ratio_affect_deliverability) 发现电子邮件应包含至少 500 个文本字符，以避免直接发送到垃圾邮件。一些地区法律要求在电子邮件底部包含联系信息、法律免责声明、取消订阅链接和公司地址（小字印刷），这有助于增加字符数。另外，请为您的图像添加替代文本，以便订阅者可以在您的图像无法正确加载时阅读说明。替代文本对于确保您的电子邮件易于访问也至关重要。 - <strong><em>*限制 URL 数量。</strong></em>*</p>
<p>对于收件箱提供商来说，大量超链接文本可能被视为危险信号。垃圾邮件发送者通常包含尽可能多的链接，包括隐藏的和公开的。虽然包含一些适当的链接可能不会导致任何问题，但请考虑仅包含必要的链接并避免过度使用，特别是当您链接到您自己的网站以外的网站时。 - <strong><em>*避免模板中不必要的代码。</strong></em>*</p>
<p>如果您使用我们的拖放模板编辑器，我们会为您处理这件事。 如果您正在编写自己的 HTML 模板或在我们的模板编辑器中编辑文本块的源代码，请注意，额外的标签和不良代码可能会触发垃圾邮件过滤器。从某些软件（例如 Microsoft Word）复制和粘贴文本可能会带来增加代码重量的样式。要粘贴复制的文本而不使用关联的样式，请在 Windows 上使用 <strong>Ctrl + Shift + V</strong> 作为键盘快捷键，在 Mac OS 上使用 <strong>Cmd + Shift + V</strong>。 - <strong><em>*在您的消息中体现个性化。</strong></em>*</p>
<p>您的电子邮件越个性化，电子邮件客户就越有可能认为它们很重要，并且订阅者也可能更倾向于打开。如果电子邮件客户端确定您可能认识您要发送给的人，则这会显着降低您的电子邮件最终成为垃圾邮件的风险。 Klaviyo 可以轻松地[将收件人的名字插入电子邮件的主题行和正文](https://help.klaviyo.com/hc/en-us/articles/11613154130843)。您还可以要求您的联系人将您添加到他们的地址簿中，或者尝试使用纯文本电子邮件而不是格式化电子邮件。如有疑问，请通过免费的在线垃圾邮件过滤工具（例如 [Mail Tester](https://www.mail-tester.com/)）运行您的电子邮件模板。这可以帮助标记您的内容中可能导致电子邮件客户端标记您的电子邮件的问题。 - <strong><em>*添加 2 个取消订阅链接或按钮。</strong></em>*</p>
<p>考虑在电子邮件的顶部和底部添加取消订阅链接。当人们不再想接收电子邮件时，让他们选择退出将减少垃圾邮件投诉，并随着时间的推移提高打开率，因为您开始发送到总体上更活跃的列表。虽然您不希望取消订阅率很高，但您更希望有人取消订阅，而不是将您的电子邮件标记为垃圾邮件。这也有助于防止电子邮件因太大而被[剪辑](https://help.klaviyo.com/hc/en-us/articles/115000591251)。 ## 电子邮件验证问题</p>
<p>邮件服务器使用[电子邮件身份验证协议](https://help.klaviyo.com/hc/en-us/articles/4402601857307) 来验证传入电子邮件是否来自合法发件人，从而保护您的品牌和客户免受恶意行为者的侵害。最常用的电子邮件身份验证标准是 [SPF、DKIM 和 DMARC](https://help.klaviyo.com/hc/en-us/articles/360039295051-Deliverability-glossary)。如果您的电子邮件未通过此验证，可能会导致您的电子邮件被拒绝或被放入垃圾邮件中。确定您的品牌是否使用 DMARC 政策并确保其有效。为了符合 DMARC，您需要将品牌发送域（也称为专用发送域）连接到您的帐户，其中 DSD 的根域与发件人电子邮件地址（友好发件人地址）中使用的根域相匹配。例如，如果您使用 <strong>sales@example.com</strong> 作为发件人地址发送电子邮件，并且 <strong>example.com</strong> 受 DMARC 保护，则您的帐户将需要使用 <strong>send.example.com</strong> 等品牌发送域来满足 DMARC 要求。除了防止网络钓鱼和欺骗尝试之外，实施这些协议还可以帮助提高投递能力，因为邮箱提供商将能够确认发件人的身份。 ## Gmail 和 Yahoo 发件人要求</p>
<p>Google 和 Yahoo 已宣布新的发件人要求，计划于 2024 年 2 月开始实施。如果您看到电子邮件被归入垃圾邮件，请验证您是否满足 Gmail 和 Yahoo 设定的以下要求：</p>
<ul>
<li>****从您的友好发件人地址中删除 Gmail 或 Yahoo ****不要在您的友好“发件人”地址中使用 Gmail 或 Yahoo 电子邮件地址。如果您在电子邮件的“发件人”地址中使用@gmail.com 或@yahoo，请将“发件人”地址切换到您拥有的网站域。 - ****设置[品牌发送域](https://help.klaviyo.com/hc/en-us/articles/115000357752)****品牌发送域（也称为专用发送域）可让您更好地控制发件人声誉。他们还通过删除“通过 klaviyomail.com”发送的免责声明来改善收件箱“发件人”地址中的品牌形象。品牌发送域是一种很好的送达率最佳实践，也是从 2 月份开始定期向 Google 和 Yahoo 收件人发送电子邮件的批量发件人的要求。 - ****在根域上设置 [DMARC 策略](https://help.klaviyo.com/hc/en-us/articles/4402601857307)****DMARC 身份验证是服务器用来确保电子邮件来自合法发件人的协议策略。 品牌使用 DMARC 策略来保护发件人电子邮件地址中的域免遭不良行为者未经授权的使用。 DMARC 身份验证在您的 DNS 提供商（例如 GoDaddy 或 Cloudflare）中设置。 - ********将您的发件人地址域与您的品牌发送域对齐********为了符合 DMARC，您的友好“发件人”地址中的域必须与您的品牌发送域中的根域一致。 - ****轻松[取消订阅](https://help.klaviyo.com/hc/en-us/articles/115005078267)****审核您的营销活动模板和流程电子邮件，以确保您的电子邮件正文中的某个位置有取消订阅链接（页脚通常是最常见的）。 - ********保持[垃圾邮件投诉低](https://help.klaviyo.com/hc/en-us/articles/360057985791)********</li>
</ul>
<p>低垃圾邮件投诉是向收件箱提供商表明您是遵循递送最佳实践的合法发件人的关键方式。请访问 Klaviyo 中的[送达率中心](https://help.klaviyo.com/hc/en-us/articles/18378819907995) 查看您的送达率指标，或尝试使用 [Google Postmaster Tools](https://academy.klaviyo.com/use-google-postmaster-tools-to-monitor-your-spam-complaint-rate/1838637) 来监控您的送达率指标您的发送策略符合 Google 的要求。其中一些要求仅适用于批量发件人，或每天向 Gmail 收件人发送 5,000 封电子邮件的发件人。详细了解 [Gmail 和 Yahoo 即将推出的发件人要求](https://academy.klaviyo.com/2024-new-sender-requirements-checklist/)，以便电子邮件成功进入收件箱。 ## 其他资源</p>
