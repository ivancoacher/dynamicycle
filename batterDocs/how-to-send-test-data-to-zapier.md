<h1>How to send test data to Zapier</h1>

## You will learn

Learn how to send test data to Zapier via a POST request when creating a webhook to send email and SMS consent to Klaviyo.

This article builds off of the information in [How to send consent to Klaviyo via Zapier](https://help.klaviyo.com/hc/en-us/articles/4407486310683).

## Create a POST request

Before testing your trigger, you will need to send test data to your webhook via a POST request. The steps listed below explain how to make the POST request via Postman, but you’re welcome to use any program you’d like.

1. Copy the webhook URL generated by Zapier.
2. In Postman, click ****New**** to start a new request.
3. Select ****HTTP Request**** from the **Create New** menu.
   ![Postman’s Create New request menu, showing HTTP Request under the Building Blocks section](https://klaviyo.zendesk.com/hc/article_attachments/28717851667739)
4. Paste the Zapier webhook URL you copied earlier into the URL box.
5. Select ****POST**** from the dropdown to the left of the webhook URL.
   ![Postman setup to create POST request, with POST selected from the dropdown and the Zapier webhook URL entered into URL box](https://klaviyo.zendesk.com/hc/article_attachments/28717851660955)
6. Select the ****Body**** tab, choose the ****form-data**** radio button, and then enter the keys and appropriate test data from the following table. Make sure to [format phone numbers correctly](https://help.klaviyo.com/hc/en-us/articles/360046055671). You'll need to use a real phone number when testing your webhook in order for the profile to be added to your list.
   ![Postman form-data body setup for name, email, phone number, and SMS consent](https://klaviyo.zendesk.com/hc/article_attachments/28717851672219)

   |  |  |
   | --- | --- |
   | ****Key**** | ****Value**** |
   | `name` | <Test name> |
   | `email` | <Test email> |
   | `phone_number` | <Test phone number> |
   | `sms_consent` | true |
7. Click ****Send**** to send the test data to Zapier.
8. If the POST request is successful, you’ll see the line `"status": "success"` in the response.

![Postman POST request response, showing a successful response](https://klaviyo.zendesk.com/hc/article_attachments/28717851675163)

Now you can return to Zapier and complete the webhook setup process.
