<h1>通过多步骤注册表单跳转到成功</h1>

<p>在多步骤表单中使用<strong><em>*跳到成功按钮操作</strong><strong>，让访问者绕过可选步骤（例如短信选择加入），仍然可以看到您的成功屏幕，而不会关闭表单或失去原始奖励。本文是 </strong><strong>Forms 最佳实践</strong></em>* 合集的一部分。 ---</p>
<h2>你将会学到</h2>
<ul>
<li>何时在多步骤形式中使用****跳到成功****</li>
<li>**跳到成功****对于访问者和分析人员来说如何表现</li>
<li>如何在表单中添加 ****Skip to success**** 按钮</li>
<li>需要注意的重要限制和验证警报</li>
</ul>
<p>---</p>
<h2>开始之前</h2>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/46364562155803" alt="" />
<p>在添加<strong><em>*Skip to success</strong></em>*之前，请确保：</p>
<ul>
<li>您正在从****注册表单****选项卡（仅限标准表单）编辑****Klaviyo注册表单****。 - 您的表格是****多步骤****并包含****成功****步骤。 - 至少****之前的一个步骤包含所需的电子邮件或电话输入****。仅当表单在前面的步骤中具有必填的电子邮件或电话字段时，“跳到成功”才可用，因此访问者无法跳过所有必填信息。 - 形式****不****：</li>
<li>在任何步骤上使用****旋转获胜****</li>
<li>使用****年龄门****</li>
<li>将****跳到成功****放在****智能选择加入代码确认步骤****上</li>
</ul>
<p>如果不满足其中任何一个条件，该操作将不会出现在编辑器中，或者您将看到表单警报，提示您调整配置。 ---</p>
<h2>跳到成功如何运作</h2>
<p>当您添加 <strong><em>*Skip to success</strong></em>* 作为步骤上的按钮操作时：</p>
<ul>
<li>****访客看到什么****</li>
<li>单击按钮****跳过当前步骤和任何剩余步骤****，并立即显示****成功****步骤。 - 这非常适合 ****“不用了”****、****“跳过短信”**** 或 ****“无需电话继续”**** 等按钮。 - ****收集（和不收集）哪些数据****</li>
<li>****已在之前步骤中提交的任何字段****（例如，必填的电子邮件）仍照常保存。 - 当访问者单击“跳到成功”时，**** 在与“跳到成功”按钮相同的步骤上的任何输入都**** ****** 不会******** **** **** 提交****。 - 这可确保访问者不会意外提交他们跳过的步骤中的部分或不需要的信息。 - ****记录了哪些事件****</li>
<li>当访问者使用“跳过成功”到达成功步骤时，Klaviyo 仍会记录****已完成表单****事件，因此您的表单分析和渠道将继续按预期工作。即使访问者选择不提供短信同意等可选信息，此行为也会为访问者提供清晰的确认屏幕（例如，显示折扣代码或重定向到其邮箱）。 ---</li>
</ul>
<h2>使用 Skip 成功的最佳实践</h2>
<h3>1. 使用“跳到成功”作为可选步骤</h3>
<p>当用于<strong><em>*必填电子邮件或电话字段后面的可选步骤</strong></em>*时，“跳到成功”效果最佳，例如：</p>
<ul>
<li>****电子邮件然后短信****：</li>
<li>第 1 步：输入所需的电子邮件</li>
<li>第 2 步：使用电话号码字段或智能选择加入可选短信选择加入</li>
<li>第 2 步上的按钮：****“不用了，谢谢”→ 跳至成功****</li>
</ul>
<p>在这个模式中：</p>
<ul>
<li>**想要短信****的访客照常完成短信步骤。 - ****不想要短信****的访问者点击****“不，谢谢”****并直接进入成功屏幕，他们仍然可以：</li>
<li>查看他们的折扣代码</li>
<li>获取确认消息</li>
<li>请放心，他们提交的电子邮件已被捕获</li>
</ul>
<h3>2. 在跳到成功之前保留必填字段</h3>
<p>因为“跳到成功”可以让访问者绕过后续步骤：</p>
<ul>
<li>将****所有必填字段（电子邮件、电话、关键配置文件属性）**** 放在步骤******** 任何“跳到成功”按钮之前。 - 仅在以下情况后才使用“跳至成功”：</li>
<li>必填****电子邮件****或****电话****字段，以及</li>
<li>适用于您的用例的任何****必须具备的合规步骤****</li>
</ul>
<p>Klaviyo 的表单警报有助于强制执行此操作：如果<strong><em>*在所需输入之前</strong><strong>出现“跳到成功”按钮，或者如果</strong><strong>之前根本没有任何输入</strong></em>*，您将看到提醒您调整表单的警报。 ### 3. 不要依赖“跳过”步骤来获取重要数据</p>
<p>因为当访问者单击“跳过以成功”时，<strong><em>*“跳过”步骤上的数据未提交</strong><strong>，因此请避免在同一步骤上放置任何</strong><strong>关键字段</strong></em>*，例如：</p>
<ul>
<li>必须始终捕获的合法复选框</li>
<li>下游流所需的非可选配置文件属性</li>
</ul>
<p>相反：</p>
<ul>
<li>将必填字段放在****上一步****上，或者</li>
<li>将可选的丰富问题（例如“您要买什么？”）移至：</li>
<li>****相同的步骤****，但接受您只会从正常完成该步骤的访客那里收集它们，或者</li>
<li>单独的后续体验（例如偏好中心电子邮件）。 ### 4. 监控分析性能</li>
</ul>
<p>打开“跳到成功”后：</p>
<ul>
<li>比较启用该功能之前和之后的****提交率****和****完成的表单事件****，以确保在不减少关键同意（例如短信）的情况下提高完成度。如果您发现短信选择加入的下降幅度超过预期，请考虑调整您的短信步骤副本（例如，强化价值和激励）。 ---</li>
</ul>
<h2>如何添加“跳到成功”按钮</h2>
<p>按照以下步骤在多步骤注册表单上配置“跳过至成功”。 1.<strong><em>*打开您的表格</strong></em>*</p>
<p>1. 在 Klaviyo 中，从左侧导航转到<strong><em>*注册表单</strong><strong>。 2. 打开现有的</strong><strong>多步骤表单</strong></em>*或创建一个新表单。 3. 确保您的表格包含：</p>
<ul>
<li>****成功****一步。 - 至少一个****上一步需要输入电子邮件或电话****。 2.****选择访客可以选择退出的步骤****</li>
</ul>
<ul>
<li>导航到您希望访问者****跳过****的步骤（例如，短信步骤或可选的丰富步骤）。 - 确认在此步骤之前****已捕获任何****必须拥有的数据****。 3.****添加或选择按钮****</li>
</ul>
<p>1. 从<strong><em>*添加块</strong><strong>选项卡中，将</strong><strong>按钮</strong><strong>块拖到步骤上，或单击现有按钮（例如“不，谢谢”）。 2. 在阻止设置中，配置</strong><strong>文本</strong><strong>（例如，“现在不”或“无需电话继续”）。 4. </strong><strong>将按钮操作设置为“跳到成功”</strong></em>*</p>
<p>1. 在按钮设置中，找到<strong><em>*操作</strong><strong>下拉菜单（您通常在其中选择 </strong>关闭表单<strong>、</strong>提交表单<strong> 或 </strong>转到 URL<strong> 等操作）。 2. 从操作列表中选择</strong><strong>跳至成功</strong></em>*。 - 如果您没有看到此选项：</p>
<ul>
<li>确认您正在编辑****标准注册表单****，而不是“退货”或登陆页面表单。 - 确认上一步中****需要输入电子邮件或电话****。 - 确认表单的智能选择加入代码步骤中不包含 ****Spin-to-Win****、****Age Gate**** 或 ****Skip to success****。 5.****查看表单提醒（如果有）****</li>
</ul>
<ul>
<li>如果您的配置与最佳实践或被阻止的组合冲突（例如，“跳到成功”出现在任何输入之前），您将在编辑器中看到指向有问题的块或步骤的警报。 - 按照警报中的指导进行操作：</li>
<li>将“跳至成功”按钮移至后续步骤，或者</li>
<li>在流程的早期添加所需的输入，或者</li>
<li>删除不兼容的组件（例如 Spin-to-Win 或 Age Gate）。 6.****预览您的表格****</li>
</ul>
<ul>
<li>可以选择在非面向客户的页面上测试您的表单，以确保行为：</li>
<li>像访问者一样点击表单。 - 确认单击“跳到成功”按钮：</li>
<li>跳过预期的步骤。 - 显示****成功****屏幕，其中包含正确的副本、折扣代码或后续步骤</li>
</ul>
<p>7.<strong><em>*发布表格</strong></em>*</p>
<ul>
<li>当您对配置感到满意时，****发布****表单，以便更改在您的网站上生效。 - 监控表单分析的性能并随着时间的推移进行迭代改进。 ---</li>
</ul>
<h2>限制和边缘情况</h2>
<p>规划表单时请记住这些限制：</p>
<ul>
<li>****并非随处可用****</li>
<li>仅适用于****标准注册表****。 - 不适用于：</li>
<li>****回到库存形式****</li>
<li>****登陆页面****</li>
<li>表单的****第一步****或****成功****步骤。 - ****不兼容的功能****</li>
<li>使用以下任何一项的表单无法使用 Skip to success：</li>
<li>****旋转获胜****步骤</li>
<li>****年龄门****步骤</li>
<li>****成功执行智能选择加入代码步骤****</li>
<li>****在跳到成功之前没有输入****</li>
<li>如果****在最早的“跳到成功”操作之前没有输入字段****，Klaviyo 将显示阻止警报，这样您就不会意外发布让访问者在不提供任何信息的情况下到达成功步骤的表单。 - ****跳转成功后所需的输入****</li>
<li>如果“跳至成功”出现在****之前或与所需输入相同的步骤****，您将看到警告警报，以便您可以移动按钮或调整字段。在这些限制范围内配置表单可确保访问者始终拥有流畅、值得信赖的体验，并且您的列表增长和同意数据保持可靠。 ---</li>
</ul>
