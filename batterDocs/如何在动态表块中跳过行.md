<h1>如何在动态表块中跳过行</h1>

<h2>你将会学到</h2>
<p>了解如何跳过动态表块中的行（例如项目）。最常见的用例是从废弃的购物车电子邮件中隐藏不相关的项目，例如运输保险或免费礼品。但是，您可以对使用动态表块的任何电子邮件执行以下步骤。此过程涉及直接编辑电子邮件的代码。仅建议精通技术的营销人员或能够接触开发人员的人员使用此方法。我们的支持团队无法帮助您编写超出本文档涵盖的一般指导的自定义代码。为了维护数据的安全，Klaviyo 的支持团队无法打开 HTML 文件。 ## 开始之前</p>
<p>本文介绍如何隐藏现有动态表块中的项目。如果您尚未创建有效的动态表块（例如，废弃购物车中的产品或订单确认电子邮件），请了解如何[从头开始创建一个](https://klaviyo.zendesk.com/hc/en-us/articles/4408802597659) 或从我们的[流程中的消息开始]库](https://klaviyo.zendesk.com/hc/en-us/articles/115002779411)。 ## 写下你的 <strong>if</strong> 语句</p>
<p>在对模板进行更改之前，请使用文本或代码编辑器创建 2 个代码片段（您可以在以后复制并粘贴代码片段）。每个代码片段将由 3 部分组成：</p>
<p>1. [开始 <strong>if</strong> 标记](#h_01HY3CPMXG09XHJQTMZP0VJV82)，`{% if … %}`，指示哪些项目应出现在表格块中。 2. [内容](#h_01HY3CPMXGEPNZ4B9JC9SS91F2)，例如有关产品的图像标签或文字。 3. [结束标记](#h_01HY3CPMXGHQ358JG8EH463SGG), `{% endif %}`。 ### 创建开始 <strong>if</strong> 标签</p>
<p>以下是打开 <strong>if</strong> 标签的一些示例：</p>
<p>|  |  |</p>
<p>| --- | --- |</p>
<p>| <strong><em>*标签</strong><strong> | </strong><strong>含义</strong></em>* |</p>
<p>| {% if item.price != 0 %} |如果商品价格 (<strong>item.price</strong>) 不是 0。 |</p>
<p>| {% if item.product.name != "航线运输保险" %} |如果商品名称 (<strong>item.product.name</strong>) 不是“路线运输保险”。 |</p>
<p>| {% if item.product.title % 中不是“T 恤”} |如果商品的标题 (<strong>item.product.title</strong>) 不包含“T 恤”。 |</p>
<p>| {% if item.title %} |如果项目的标题 (<strong>item.title</strong>) 已设置（即具有任何值）。 |</p>
<p>这些标签区分大小写，并且必须与您的数据完全匹配。例如，如果商品价格的变量不是 <strong>item.price</strong>（例如 <strong>item.Price</strong> 或 <strong>item.details.line\_price</strong>），请更新代码以匹配您的数据源。 ### 创建 if 语句的内容</p>
<p>对于内容，请按照以下步骤使用动态表块中的现有内容。在代码或文本编辑器中编写此代码片段；您将在下一部分中将其添加到模板中。 1. 在表格块图像的<strong>单元格内容</strong>下，单击<strong><em>*替换</strong></em>*以查看图像占位符。 ![替换单元格内容按钮.jpg](https://klaviyo.zendesk.com/hc/article_attachments/28717391398811)</p>
<p>2. 从<strong>动态变量或动态 URL</strong> 字段复制整个代码。请注意，这可能是一个简单的动态变量，也可能是一个较长的代码片段；复制全部内容，无论长度如何。 ![废弃购物车产品图片变量.jpg](https://klaviyo.zendesk.com/hc/article_attachments/28717418658971)</p>
<p>3. 将此代码片段中的占位符替换为您从 <strong>动态变量或动态 URL</strong> 字段复制的代码。 ````</p>
<p><img src="PLACEHOLDER" style="宽度：200px；高度：自动；"宽度=“200”></p>
<p>````</p>
<p>如果您现有的表块有一个简单的图像动态变量，则生成的内容将如下所示：</p>
<p>````</p>
<p><img src="{{item.product.variant.images.0.src}}" style="width: 200px; height: auto;"宽度=“200”></p>
<p>````</p>
<p>如果您现有的表块包含较长的代码片段，则生成的内容可能如下所示：</p>
<p>````</p>
<p><img src="{% if item.product.variant.images.0.src %}{{item.product.variant.images.0.src}}{%else%}{{item.product.images.0.src|missing_product_image}}{%endif%}" style="宽度：200px；高度：自动；"宽度=“200”></p>
<p>````</p>
<h3>添加结束标签</h3>
<p>然后，将所有内容放在一起：开始 if 语句，然后是内容，最后是结束“{% endif %}”标记。 ### 重复文本内容</p>
<p>然后，使用表格块右侧的内容（例如文本内容）重复此过程。单击 <strong><em>*</></strong></em>* 打开代码编辑器并复制所有 HTML 内容，然后将此内容包装在与图像内容相同的 if 语句（步骤 1 和 3）中。 这是所有内容组合在一起的样子：</p>
<p>|  |  |</p>
<p>| --- | --- |</p>
<p>| <strong><em>*代码片段 1（产品图片）</strong><strong> | </strong><strong>代码片段 2（产品详细信息）</strong></em>* |</p>
<p>| ``` {% if item.product.name != "路线运输保险" %} <img src="{% if item.product.variant.images.0.src %} {{item.product.variant.images.0.src}}{%else%} {{item.product.images.0.src|missing_product_image}} {%endif%}"style="width: 200px; height:汽车；”宽度=“200”> {% endif %} ``` | ``` {% if item.product.name != "路线运输保险" %} <h3><a href="{{organization.url }}products/{{ item.product.url }}"> {{ item.product.name }} </a></h3> <p> 数量：{{ item.quantity|floatformat:0 }} — 总计：{%currency_format item.line_price|floatformat:2 %} </p> {% endif %} ``` |</p>
<p>以下是这些代码片段的细分：</p>
<p>|  |  |</p>
<p>| --- | --- |</p>
<p>| <strong><em>*代码片段 1（产品图片）</strong><strong> | </strong><strong>代码片段 2（产品详细信息）</strong></em>* |</p>
<p>| ``` {% if CRITERIA %} 图像占位符内容 {% endif %} ``` | ``` {% if CRITERIA %} 产品描述 {% endif %} ``` |</p>
<p>使用这些代码片段时，请确保使用直引号 (") 而不是弯引号 (“)，以确保代码正确呈现。编写完两个代码片段后，请在模板编辑器中继续执行以下步骤。 ## 跳过动态表块中的行</p>
<p>在编辑动态表块之前，请考虑将原始块保存为通用内容，以便您需要在将来的消息中引用它。然后取消链接块并单独编辑它，这样您的编辑就不会保存到通用内容块中。 1. 如果您的电子邮件是流程的一部分，请将其设置为 <strong>草稿</strong> 或 <strong>手动</strong>，以便在您编辑流程消息时不会发送消息。 2. 确保新表格块两列的 <strong>单元格内容</strong> 均设置为 <strong>文本</strong>。 ![](https://klaviyo.zendesk.com/hc/article_attachments/28717418651163)</p>
<p>3. 单击<strong><em>*</></strong></em>* 打开表格块左侧的 HTML 编辑器。 4. 复制您在上一节中创建的产品图像代码片段并将其粘贴到 HTML 字段中。 ![](https://klaviyo.zendesk.com/hc/article_attachments/28717418647579)</p>
<p>5. 单击左上角的<strong><em>*完成</strong><strong>。 6. 导航到表块右侧的编辑器。 7. 单击</strong><strong></></strong><strong> 打开表格块右侧的 HTML 编辑器。 8. 复制您在上一节中创建的产品详细信息代码段并将其粘贴到 HTML 字段中，替换所有先前的内容。 9. 单击</strong><strong>完成</strong></em>*。 10. 预览电子邮件以确保其按预期显示：跳过的项目不应出现，但所有其他项目将正常显示。确保预览包含您要隐藏的项目的事件，以便确保它被隐藏。 ### 条件语句和内联文本编辑器</p>
<p>当您将某些条件语句添加到文本块时，它们可能会从内联文本编辑器中消失。代码仍然存在；它只是被隐藏了。要查看和编辑条件语句，请打开文本块的<strong>源代码</strong>字段。以下标签仅在文本块的<strong>源代码</strong> 字段中可见：</p>
<ul>
<li>{% 为 ... %}</li>
<li>{% endfor %}</li>
<li>{% 如果...%}</li>
<li>{% elif ... %}</li>
<li>{%其他%}</li>
<li>{% endif %}</li>
<li>{% 与 ... %}</li>
<li>{% 结尾为 %}</li>
</ul>
<h2>故障排除</h2>
<p><strong><em>*预览中没有出现任何项目</strong></em>*</p>
<p>1. 确保您正在预览的事件与您使用的数据源相匹配（例如，针对废弃购物车消息的 <strong>开始结帐</strong>）。 2. 确认<strong>重复</strong>和<strong>行别名</strong>与原始块中的<strong>行集合</strong>和<strong>行别名</strong>完全匹配。 <strong><em>*应该跳过的项目仍然出现</strong></em>*</p>
<p>检查 if 语句的拼写和大小写。如果该产品仍然出现，则意味着它符合您的 if 语句中的条件，因此您的 if 语句配置不正确。详细了解[模板中的条件逻辑](https://help.klaviyo.com/hc/en-us/articles/7655926841499)。 ## 结果</p>
<p>执行这些步骤后，任何不符合 if 语句中条件的商品都不会出现在废弃购物车或订单确认电子邮件等消息中。 ## 其他资源</p>
