了解如何激活 Klaviyo 的 Customer Agent。这是一款 AI 驱动的工具，可为您的网站访问者提供即时支持。Customer Agent 会摄取来自您 Shopify 店铺的信息，并学习您提供的任何附加信息，从而通过 Web 聊天、短信和邮件（测试版）回答购物者的咨询。

##### ****开始之前****

Customer Agent 支持以下渠道：

- Web 聊天：应通过 Customer Hub 设置启用，并设置为在您的网站上上线。
- SMS：通过可接收上行消息的活跃发送号码（免付费号码、短码或长码）。

Customer Agent 对满足以下条件的账户提供完整支持：

- 拥有 Shopify 店铺。
- 使用英语进行对话。

##### ****[关于 Klaviyo 的 Customer Agent](https://help.klaviyo.com/hc/en-us/articles/37659268052635)****

Customer Agent 是一款 7×24 小时的虚拟助手工具，可帮助您的网站访问者快速获取问题答案。它会自动从您的 Shopify 店铺以及您提供的任何附加知识库中进行学习，从而减少人工支持团队需要处理的咨询量。

Customer Agent 可作为支持和销售问题的首要接触点。它能通过 Web 聊天、短信和邮件（测试版）回答问题，并具备以下能力：

- 提供量身定制的实时产品推荐。
- 即时回答常见咨询（例如：特定产品问题、店铺政策等）。
- 提供订单状态和物流跟踪更新。
- 将无法回答的问题升级转接给您的支持团队，或告知其他寻求帮助的途径。

##### ****启用 Customer Agent****

要启用 [Customer Agent](https://www.klaviyo.com/kagent/performance)，请按照以下步骤操作：

###### 完成设置

“Get started”页面提供了一个动态清单，引导您完成从初始同步到正式上线的全过程。

###### 1. 启用与同步

- 导航至 Service > Customer Agent。
- 如果这是您第一次操作，请点击 Get started 以启用 Customer Agent。
- 完成所有入驻步骤，包括添加您的网站 URL，以便 Agent 可以从您的网站中学习。
- 完成入驻步骤后，您将进入 Get Started 页面。

###### 2. 配置语气与风格 (Voice and Tone)

- 在 Get started 页面上，找到 Up next 卡片，或在任务列表中找到 Set voice and tone。
- 点击 Update voice and tone。
- 自定义 Agent 的沟通方式（例如：正式或友好），以匹配您的品牌形象。

###### 3. 连接[Helpdesk](http://klaviyo.com/inbox)

- 点击 Tell where to hand off 任务（或 Connect to Helpdesk）。
- 指定当 Customer Agent 无法回答客户问题时，您希望它如何处理对话：
- Send to helpdesk：Customer Agent 会在您的平台（如 Klaviyo Helpdesk, Zendesk, Gorgias）中创建一个新的支持工单。
- Send a message：输入自定义消息（例如：前往帮助中心的指引）。

###### 4. 训练与测试

- 点击 Add your FAQs 来上传文件、文本片段或 URL，涵盖产品页面上没有的政策内容。
- 点击 Take for a test drive 或 Test skills。
- 在 Agent Preview (Agent 预览) 选项卡中，询问有关您的产品或政策的问题。
- 提示：尝试提出后续问题，以进一步探测 Customer Agent 的知识储备。

###### 5. 发布

当您对回答的效果感到满意时，点击进入您想要发布 Agent 的对应渠道发布页面，并按照该页面上的步骤进行操作。

##### ****测试并训练您的 Customer Agent****

[Customer Agent](https://www.klaviyo.com/kagent/content) 通过抓取您的网站页面进行学习，但它可能无法立即回答所有类型的问题。为了确保您的 Customer Agent 提供准确且有帮助的回答，在预览环境（Klaviyo 中的 Playground 选项）中针对您的网站提出各种问题进行测试至关重要。在正式发布 Customer Agent 之前请进行广泛测试，并在上线后继续定期测试。

如果您在测试过程中发现知识盲点，或者想要主动应对常见的客户咨询，可以通过在 Knowledge选项中手动添加信息来完善 Customer Agent 的知识储备。

您可以上传：

- 文件
- 文本片段
- 网页

##### ****扩展其可见性与影响力****

当您的 Customer Agent 已上线并训练好能够回答问题时，提高其可见性至关重要，这样可以提示客户与之互动并告知他们可以随时咨询。以下是实现这一目标的最佳实践：

###### 针对 Web 聊天：

- 将 Web 聊天设置面向All users：确保任何网站访客都能与 Customer Agent 互动，而不仅限于已登录的访客。操作路径：Customer Hub -> Extensions -> Web Chat -> Visibility。
- 注意：您还需要在 Customer Agent -> Settings -> Channels 中将 Web 聊天切换为开启状态，以在该渠道启用 Customer Agent。
- 在产品页面创建并展示FAQs：当购物者点击某个问题时，会触发 弹窗 界面，Customer Agent 将在“Chat”选项中进行回答。
- 启用Hub launcher：这是一个悬浮的聊天小组件，点击后可打开 弹窗 中的聊天选项卡。

###### 针对Text Messaging：

- 设置对话引导语：在短信渠道开启 Customer Agent 后，您可以在 Customer Agent > Settings > Marketing 选项卡中指定“Agent 对话引导语”。如果您勾选了“包含 Agent 对话引导语”，这段预设文字将自动插入到短信编辑器中。
- 更新Abandonment flows：询问客户是否有 Customer Agent 可以协助解答的问题。使用自然的问句，例如：“在您结算前，有什么我可以帮您解答的吗？”
- 更新Welcome flow：向客户介绍您的 Customer Agent。使用引导性问题，如：“不确定哪种风格适合您？直接在这里回复即可。”
- 更新Post-purchase flows：告知客户他们可以针对订单问题进行咨询。
- 在发送Campaign 时：告知客户他们可以通过回复短信来提问。
