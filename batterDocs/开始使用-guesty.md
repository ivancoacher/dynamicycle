<h1>开始使用 Guesty</h1>

<p>了解如何将 Klaviyo 与短期租赁物业管理平台 Guesty 集成。 Klaviyo 同步来自 Guesty 的宾客、预订和消息，让您可以个性化向宾客发送的消息。 ## 将 Klaviyo 与 Guesty 集成</p>
<p>首先，您需要从 Guesty 获取 API 密钥：</p>
<p>1. 登录您的 Guesty 管理员。 2. 选择<strong><em>*集成 > 市场</strong><strong>。 3. 搜索 </strong>Klaviyo</em>*，然后选择 Klaviyo 列表。 ![](https://klaviyo.zendesk.com/hc/article_attachments/38043405531035)</p>
<p>4. 单击<strong><em>*连接</strong></em>*。 5. 复制新生成的Guesty API Key。 ![](https://klaviyo.zendesk.com/hc/article_attachments/38043390294299)</p>
<p>然后，您需要在 Klaviyo 中设置集成：</p>
<p>6. 登录 Klaviyo。 7. 选择<strong><em>*集成</strong><strong>选项卡。 8. 单击</strong><strong>探索应用程序</strong><strong>。 9. 搜索 </strong>Guesty<strong> 并选择该卡。 10. 单击</strong><strong>安装</strong></em>*。 11. 将您复制的 Guesty API 密钥粘贴到框中。 ![](https://klaviyo.zendesk.com/hc/article_attachments/38043390298011)</p>
<p>12. 单击<strong><em>*连接</strong><strong>。 13. 检查 Klaviyo 中的权限并单击</strong><strong>允许</strong></em>*。 ![](https://klaviyo.zendesk.com/hc/article_attachments/38043390299931)</p>
<p>14. 在下一页上，选中复选框<strong>将您的 Guesty 电子邮件订阅者同步到 Klaviyo</strong>（如果您愿意）。 ![](https://klaviyo.zendesk.com/hc/article_attachments/38043405546139)</p>
<p>15. 如果您选择了上述设置，请从下拉列表中选择要添加 Guesty 电子邮件订阅者的列表。确保此列表设置为[单一选择加入](https://help.klaviyo.com/hc/en-us/articles/115005251108#h_01HZ5G5ZQBDHTV20V1BE7D4YAT)，以避免触发从 Guesty 同步的向访客发送选择加入电子邮件。 16. 完成后，单击<strong><em>*完成设置</strong></em>*。 17. 您将收到一条成功消息，确认您的 Guesty 集成现已连接。 ![](https://klaviyo.zendesk.com/hc/article_attachments/38043390305819)</p>
<h2>更新您的 Guesty 集成</h2>
<p>要更新您的集成：</p>
<p>1. 登录 Klaviyo。 2. 选择<strong><em>*集成</strong><strong>选项卡。 3. 单击</strong><strong>来宾.</strong></em>*</p>
<p>4. 单击横幅中的<strong><em>*更新</strong></em>*按钮。 ![屏幕截图 2026-01-30 下午 4.27.40.png](https://klaviyo.zendesk.com/hc/article_attachments/46089570265499)</p>
<p>5. 单击<strong><em>*连接</strong><strong>。 6. 检查 Klaviyo 中的权限并单击</strong><strong>允许</strong></em>*。 ![](https://klaviyo.zendesk.com/hc/article_attachments/38043390299931)</p>
<p>7. 在下一页上，选中复选框<strong>将您的 Guesty 电子邮件订阅者同步到 Klaviyo</strong>（如果您愿意）。 ![](https://klaviyo.zendesk.com/hc/article_attachments/38043405546139)</p>
<p>8. 如果您选择了上述设置，请从下拉列表中选择要添加 Guesty 电子邮件订阅者的列表。确保此列表设置为[单一选择加入](https://help.klaviyo.com/hc/en-us/articles/115005251108#h_01HZ5G5ZQBDHTV20V1BE7D4YAT)，以避免触发从 Guesty 同步的向访客发送选择加入电子邮件。 9. 完成后，单击<strong><em>*完成设置</strong></em>*。 10. 您将收到一条成功消息，确认您的 Guesty 集成现已连接。 ![](https://klaviyo.zendesk.com/hc/article_attachments/38043390305819)</p>
<h2>添加现场跟踪</h2>
<p>如果您使用的是 Guesty 的预订引擎，则可以通过安装自定义代码片段将 Klaviyo 现场跟踪添加到您的网站。此代码段还允许在您的网站上使用 [Klaviyo forms](https://help.klaviyo.com/hc/en-us/articles/360026474752)。要在您的网站上安装代码：</p>
<p>1. 在 Klaviyo 中，在左下角选择您的帐户名。 2. 选择<strong><em>*设置</strong><strong>。 3. 单击</strong><strong>API 密钥</strong><strong>。 4. 复制您的公共 API 密钥。 1. 登录Guesty。 2. 选择顶部的</strong><strong>操作</strong><strong>下拉列表，然后选择</strong><strong>增长 > 分布</strong></em>*。 ![](https://klaviyo.zendesk.com/hc/article_attachments/49254970231323)</p>
<p>3. 选择<strong><em>*宾客预订引擎</strong><strong>。 4. 单击预订引擎旁边的三个点，然后选择</strong><strong>编辑预订引擎</strong><strong>。 5. 滚动到 </strong>自定义代码片段<strong> 部分，并确保</strong><strong>打开自定义代码片段</strong></em>* 已打开。 6. 从 Github 复制 [GuestyEvents 代码](https://gist.github.com/cbarley10/64ebafb5c8043ef5b2c8cb61145d9f5e) 并将其粘贴到自定义代码片段框中。 ![](https://klaviyo.zendesk.com/hc/article_attachments/49254970233115)</p>
<p>7. 在代码片段中，将 COMPANY\_ID 替换为您的 Klaviyo 公共 API 密钥。要查找您的 Klaviyo 公共 API 密钥：</p>
<p>8. 单击<strong><em>*下一步</strong><strong>，直到到达编辑器的最后一步。 9. 选择</strong><strong>保存预订引擎。</strong></em>*</p>
<p>您现在已经为 Guesty 安装了现场跟踪。 此代码跟踪[已知浏览器](https://help.klaviyo.com/hc/en-us/articles/115005076767#h_01HADAYAACVVC4BXQ0ES5Y50TC)的以下事件并将它们同步到Klaviyo：</p>
<ul>
<li>现场活跃</li>
<li>查看列表</li>
<li>开始结账</li>
</ul>
<h2>查看您的 Guesty 数据</h2>
<p>要查看您的 Guesty 数据：</p>
<p>1. 导航至<strong><em>*分析 > 指标</strong><strong>。在这里，您可以查看帐户中的所有指标。带有 Guesty 图标的指标代表从 Guesty 集成同步的所有指标。 2. 使用 </strong>所有集成<strong> 下拉列表并选择 </strong>Guesty</em>* 以仅查看 Guesty 指标。 ![](https://klaviyo.zendesk.com/hc/article_attachments/38043390310043)</p>
<p>要查看您的 Guesty 对象（注意：需要最新版本的集成）：</p>
<p>3. 导航至<strong><em>*内容 > 对象</strong></em>*。在这里，您可以查看帐户中的所有对象。带有 Guesty 图标的对象代表从 Guesty 集成同步的所有对象。了解[有关您的 Guesty 数据的更多信息](https://help.klaviyo.com/hc/en-us/articles/37673417604507)。 ## 使用 Guesty 数据对客人进行细分</p>

<p>您可以使用 Guesty 指标来触发流程或自动化操作序列。 Klaviyo 使用 Guesty 数据提供多个预构建流程。这些流程包括预订确认、入住前流程等。要查看这些预构建的流程：</p>
<p>1. 在 Klaviyo 中，选择<strong><em>*流程</strong><strong>选项卡。 2. 单击</strong><strong>创建流程</strong><strong>。 3. 按 </strong>Guesty</em>* 过滤以查看所有 Guesty 流。 ![](https://klaviyo.zendesk.com/hc/article_attachments/38043405558555)</p>
<p>您还可以使用 Guesty 对象创建流。例如，要创建到达前流程，您可以：</p>
<ul>
<li>导航到流程 > ****创建流程**** > ****构建您自己的流程。****</li>
<li>为流程命名并选择标签（可选）。 - 选择 **日期属性** 触发器。 ![屏幕截图 2026-01-28 下午 5.10.42.png](https://klaviyo.zendesk.com/hc/article_attachments/46002390176155)</li>
<li>从日期属性下拉列表中选择 Guesty、Reservation：CheckInDateAndTime。 - 选择您想要开始流程的时间。 - 添加相关消息。您还可以从头开始创建自己的流程。</li>
</ul>
