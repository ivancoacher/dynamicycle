<h1>How to create a dynamic cross-sell flow using the product analysis report</h1>

## You will learn

Learn how to create a flow that automatically sends messages to customers based on product-level repeat purchase timing. This flow helps to increase repeat purchases rate for your business and reduce the time between purchases.

## Before you begin

To create a dynamic post purchase cross-sell flow, you’ll need access to the [product analysis dashboard](https://help.klaviyo.com/hc/en-us/articles/26685770823451).

[Advanced KDP](https://help.klaviyo.com/hc/en-us/articles/17655007276059) and [Marketing Analytics](https://help.klaviyo.com/hc/en-us/articles/33789259613595) are not included in Klaviyo’s standard marketing application, and a subscription is required to access the associated functionality.Head to our [billing guide](https://help.klaviyo.com/hc/en-us/articles/115000976672) to learn about how to purchase these plans.

## Create a dynamic cross-sell flow

By creating a flow based on the **Best cross-sell date** property, you can automatically target customers on the day of or leading up to the optimal time to cross-sell to them. There are a few ways you can create this flow:

### From the flow library

You can quickly create a dynamic cross-sell flow from the flow library.

1. Navigate to the ****Flows**** tab and select the ****Create flow**** button.
2. In the flow library, search for **Next best product cross-sell** and select the flow.
   ![](https://klaviyo.zendesk.com/hc/article_attachments/34404072440091)
3. On the modal that appears, name your flow and add any tags if relevant.
4. Select the ****Create flow**** button.
5. In the flow builder, select the trigger and click on the ****Edit****button.
6. In the trigger settings, define whether you’d like the flow to start **Before the date property** value or **On the date property value**.
7. Select a time of day for the flow to send and if you’d like to delay the flow until any specific days of the week. Note that since the flow trigger dynamically identifies the best time to send, you may want to avoid adding delays.
8. Customize your flow messages to meet your needs.
9. ****Optional:**** For your flow to dynamically recommend the next best product for each profile, add the [**Next best product** block](https://help.klaviyo.com/hc/en-us/articles/26685770823451) to your email templates.
10. Set the flow to the **Live** or **Manual** status.

### From scratch

Learn [how to create a flow](https://help.klaviyo.com/hc/en-us/articles/115002774932) in Klaviyo.

1. To create a dynamic cross-sell flow from scratch, navigate to the **Flows** page and select ****Create new flow****.
2. To create your own flow, select ****Build your own****.
3. For your flow trigger, select the ****Best cross-sell date**** property.
   ![flow trigger.jpg](https://klaviyo.zendesk.com/hc/article_attachments/34404072443547)
4. In the flow builder, select the trigger and click on the ****Edit**** button.
5. In the trigger settings, define whether you’d like the flow to start **Before the date property** value or **On the date property** value.
6. Select a time of day for the flow to send and if you’d like to delay the flow until any specific days of the week. Note that since the flow trigger dynamically identifies the best time to send, you may want to avoid adding delays.
7. Customize your flow messages to meet your needs.
8. ****Optional:**** For your flow to dynamically recommend the next best product for each profile, add the [**Next best product** block](https://help.klaviyo.com/hc/en-us/articles/26685770823451) to your email templates.
9. Set the flow to the **Live** or **Manual** status.
