<h1>Klaviyo 帮助台：固定属性指南</h1>

<h2>你将会学到</h2>
<p>通过固定的个人资料属性，您可以直接在帮助台编辑器中显示最多五个最重要的客户属性（例如，忠诚度积分、VIP 等级、生日）。设置仅需不到两分钟，可帮助您的团队：</p>
<ul>
<li>无需打开完整档案，从而缩短第一响应时间</li>
<li>通过查看关键上下文来减少平均处理时间</li>
<li>提供更快、更准确的答案，提高客户满意度</li>
</ul>
<h2>开始之前</h2>
<ul>
<li>必须在您的 Klaviyo 帐户中启用服务台。</li>
<li>****角色：**** 所有者、管理员和经理可以编辑帮助台设置。</li>
<li>仅选择纯文本、数字或日期属性。不支持嵌套或 JSON 属性。</li>
<li>完成时间：约 2 分钟。</li>
</ul>
<h2>概述</h2>
<p>固定配置文件属性是一项帮助台设置，它告诉 Klaviyo 最多五个客户属性应始终显示在工单侧栏中。这种快速快照消除了上下文切换，使座席能够专注于对话。</p>
<h2>设置</h2>
<p>1. 在 Klaviyo 中，转至<strong><em>*帮助台 > 设置 > 固定属性</strong></em>*。</p>
<p>2. 单击<strong><em>*添加属性</strong></em>*。将打开“键入时搜索”下拉列表。</p>
<p>3. 开始输入财产名称（例如“忠诚度积分”）。</p>
<ul>
<li>从列表中选择属性。</li>
<li>所选属性在搜索栏下方显示为一个芯片。</li>
</ul>
<p>4. 重复此操作，直至添加最多 5 个属性。</p>
<ul>
<li>****注意：**** 您不能添加重复项。</li>
<li>****警告：**** 选择 JSON 属性会触发 toast“尚不支持 JSON 属性类型”。选择一个普通的属性。</li>
</ul>
<p>5. 单击<strong><em>*保存更改</strong></em>*</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/43416370396187" alt="" />
<h2>查看属性</h2>
<p>保存后，进入任何票证并确认属性现在显示在右侧边栏上。</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/43416386136091" alt="" />
<h2>最佳实践</h2>
<ul>
<li>选择代理商在大多数门票上引用的属性（例如忠诚度状态、最后订单日期、优惠券代码）。</li>
</ul>
<h2>衡量成功</h2>
<p>1. 转至<strong><em>*帮助台 > 报告 > 座席绩效</strong></em>*。</p>
<p>2. 比较启用固定属性前后的以下指标：</p>
<ul>
<li>首次响应时间</li>
<li>平均处理时间</li>
<li>票务解决时间</li>
</ul>
<p>3. 如果数字没有改善：</p>
<ul>
<li>确认代理知道面板存在并折叠/展开行为。</li>
<li>替换很少有人居住的属性。</li>
<li>审核可能抵消收益的其他工作流程变更（例如新的 SLA）。</li>
</ul>
<h2>故障排除</h2>
<p>| <strong><em>*症状</strong><strong> | </strong><strong>可能的原因</strong><strong> | </strong><strong>修复</strong></em>* |</p>
<p>| --- | --- | --- |</p>
<p>| Composer 中缺少关键属性面板 |尚未保存任何属性 |导航至<strong><em>*帮助台 > 设置 > 固定属性</strong></em>* 并添加至少一个字段 |</p>
<p>|属性显示“—” |个人资料没有价值 |验证客户的个人资料或选择覆盖范围更广的房产 |</p>
<p>| Toast 出现“尚不支持 JSON 属性类型” |所选属性是嵌套/JSON 字段 |改为固定纯文本、数字或日期属性 |</p>
<p>| <strong><em>*保存更改</strong></em>*按钮被禁用 |您已经选择了五个属性 |移除芯片以释放插槽 |</p>
<h2>常见问题解答</h2>
<p><strong><em>*我可以固定五个以上的房产吗？</strong></em>*</p>
<p>目前还不行。该限制使作曲家保持整洁并确保最佳性能。</p>
<p><strong><em>*不同的代理可以有不同的固定属性吗？</strong></em>*</p>
<p>不会。固定属性对于帮助台工作区来说是全局的，因此每个客服人员都会看到相同的上下文。</p>
<p><strong><em>*现有门票上的固定属性是否会更新？</strong></em>*</p>
<p>是的。当您更改“设置”中的列表时，Composer 会刷新所有工单（打开的工单和新工单）。</p>
