##### ****开始之前****

在 Klaviyo 的左侧导航栏中选择 [Sign-up Forms](https://www.klaviyo.com/forms) 选项卡，即可查看账户中所有表单的列表，以及它们的详细信息和关键指标。请注意，只有当你至少创建了一个 Sign-up Form 之后，才能看到这个表单列表页面。

![Klaviyo账户中所有表单的列表，包括表单名称、类型、状态、提交数量、提交率、性能和总收入的关键指标。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-71.png?resize=1024%2C234&ssl=1)

##### ****更改订阅********弹窗********的发布状态****

若要验证现有订阅弹窗的发布状态，请前往左侧导航栏中的 Sign-up forms 选项卡。在这里，每个已创建弹窗的 Status列会显示 Live、Editing 或 Draft。

- Live： 此状态表示该弹窗已发布，目前正在你的网站上实时运行。
- Editing：此状态表示该弹窗目前虽然在网站上运行，但存在一些尚未发布的修改。例如： 如果你发布了一个订阅弹窗，几天后又在编辑器里给它添加了一张图片，此时弹窗状态会显示为 Editing。你需要再次发布该弹窗，这些改动（如新添加的图片）才会同步到网站前台。
- Draft：此状态表示该弹窗目前未在你的网站上运行。

![Klaviyo 的注册表单页面，显示不同表单的名称、类型及其状态，包括 Live、Editing 和 Draft。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-72.png?resize=1024%2C514&ssl=1)

如何更改弹窗的状态（例如：发布草稿弹窗，或将已上线的弹窗设回草稿模式以取消发布）：

1. 点击 3 个点图标 > Edit form，在编辑器中打开该弹窗。
2. 在右上角，选择状态下拉菜单（即显示 Live、Editing 或 Draft 的位置）。
3. 根据需要调整状态。例如，将弹窗的状态从 Draft 更改为 Live，即可将其发布到你的网站上。

![A screenshot displaying a status dropdown menu with options for 'LIVE', 'DRAFT', and 'EDITING' in a user interface, alongside buttons for exit and publish changes.](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-73.png?resize=674%2C220&ssl=1)

要取消发布已上线的弹窗，请将状态从 Live 更改为 Draft。这样做会将该弹窗从您的网站上移除；不过，它仍会作为草稿保留在 Sign-up forms 页面中。最近的所有编辑内容都会自动保存，您可以随时通过再次发布来重新激活该弹窗。

##### ****更改弹窗提交后关联的名单****

在 [Sign-up forms](https://www.klaviyo.com/forms) 选项卡中，每个弹窗所连接的名单会显示在 Form Name列的下方。若要更改弹窗关联的名单（即切换订阅者在提交时被加入的名单），请按照以下步骤操作：

- 从左侧导航栏中选择 Sign-up forms 选项卡。
- 在您的弹窗旁边，点击 3 个点图标 > Edit form。
- 在弹窗编辑器中，点击预览界面里的提交按钮 (submit button)。
- 在 List to Submit（提交至名单）下方，从下拉菜单中选择一个新名单。
- 在编辑侧边栏中点击 Back（返回）。
- 选择 Publish changes（发布更改）以保存此项修改。

##### ****管理与编辑选项****

在 Sign-up forms 选项卡中，点击任何一个弹窗旁边的 3 个点图标，即可看到用于管理和编辑该独立弹窗的选项菜单。这些选项包括：

- 编辑弹窗
- 定时发布弹窗
- 查看弹窗的数据分析
- 为弹窗创建 A/B 测试
- 重命名弹窗
- 克隆弹窗
- 删除弹窗

![Klaviyo Sign-up Forms overview showing form names, types, statuses, submitted form counts, performance metrics, and options to edit, schedule, analyze, A/B test, rename, clone, or delete each form.](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-74.png?resize=1024%2C441&ssl=1)

##### ****编辑弹窗****

在弹窗编辑器中，您可以修改弹窗的样式、内容、Targeting以及行为设置。要访问现有弹窗的编辑器：

1.从左侧导航栏选择 Sign-up forms。

2.找到您的弹窗，点击 3 个点图标 > Edit form。

3，根据需要编辑该弹窗及其成功提示消息，您可以利用：

- Styles选项卡： 调整弹窗的设计和尺寸。了解更多关于弹窗样式（如字体和背景颜色）的信息。
- Targeting & behaviors选项卡： 调整弹窗显示的时间以及受众。了解更多关于弹窗定向与行为（如显示时机和触发选项）的信息。
- Add blocks选项卡： 调整弹窗的内容和输入字段。了解更多关于区块和输入字段（如电话号码字段或优惠券区块）的信息。

![Klaviyo弹窗编辑器的概述界面，包含样式、目标与行为、添加区块等选项菜单，展示了弹窗的设计和设置功能。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-75.png?resize=976%2C758&ssl=1)

##### ****定时发布弹窗****

若要设置弹窗在网站上显示或隐藏的具体时间：

- 从左侧导航栏选择 Sign-up forms。
- 找到您的弹窗，点击 3 个点图标 > Schedule。
- 设置您的弹窗开始显示或停止显示在网站上的日期。

![弹窗调度表单界面，包含开始和结束日期及时间的选择器，用于设置订阅弹窗的显示时间。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-76.png?resize=1024%2C465&ssl=1)

##### ****查看弹窗数据分析****

了解网站上弹窗的表现情况是受众增长策略的关键组成部分。每一个已上线的弹窗都有其独立的数据分析报告页面。要查找特定弹窗的数据分析页面：

- 从左侧导航栏选择 Sign-up forms。
- 找到您的弹窗，点击 3 个点图标 > Analytics。

##### ****创建 A/B 测试****

您可以对弹窗运行 A/B 测试，以衡量弹窗中不同元素（如文案、颜色或触发时机）的表现。若要为现有弹窗创建 A/B 测试：

- 从左侧导航栏选择 Sign-up forms。
- 在您的弹窗旁边，点击 3 个点图标 > Create A/B test。

##### ****重命名弹窗****

若要更改现有弹窗的名称：

- 从左侧导航栏选择 Sign-up forms。
- 在您的弹窗旁边，点击 3 个点图标 > Rename。
- 在重命名弹窗弹窗中更新名称。
- 点击 Save Form。

![弹窗重命名界面，显示输入框和保存按钮，用于更新弹窗的名称。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-77.png?resize=1024%2C405&ssl=1)

##### ****克隆弹窗****

若要复制您现有的其中一个弹窗：

- 从左侧导航栏选择 [Sign-up forms](https://www.klaviyo.com/forms)。
- 在您的弹窗旁边，点击 3 个点图标 > Clone。
- 为您克隆出的新弹窗命名。
- 点击 Clone Form。

![弹窗克隆对话框，包含克隆选项、克隆名称输入框和警告消息，指导用户选择优化过的模板](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-78.png?resize=1024%2C959&ssl=1)

##### ****删除弹窗****

删除弹窗会将其从您的账户中永久移除。一旦删除，您将无法恢复该弹窗。如果您只是希望关闭弹窗，使其不再显示在网站上，而不愿将其彻底删除，请在编辑器中将弹窗的状态更改为 Draft（草稿）。

若要删除弹窗：

- 在左侧导航栏中选择 Sign-up forms 选项卡。
- 在您的弹窗旁边，点击 3 个点图标 > Delete。
- 点击 Delete Form，将其从您的账户中移除。

![弹窗删除确认对话框，提示用户确认是否删除表单及其相关的分析数据。](https://i0.wp.com/dynamicycle.com/wp-content/uploads/2025/12/image-79.png?resize=1024%2C430&ssl=1)

##### ****查看从弹窗中收集的数据****

一旦您收集到了几位订阅者，就可以在他们的个人资料页（Profile pages）中查看他们通过弹窗分享的信息。

- 前往 [Audience > Profiles。](https://www.klaviyo.com/people)
- 搜索该用户的姓名或电子邮件地址以找到他们。
- 向下滚动到他们的 Information（信息）板块，即可查看他们在弹窗中分享的数据。
- 或者，您可以使用 Klaviyo 的名单板块来查看每个特定名单（例如与您的弹窗关联的名单）的完整成员列表。选择 Lists and segments，然后选择您的名单。点击该页面中的某个成员，将跳转到其对应的个人资料页。

##### ****[合规页面](https://www.klaviyo.com/settings/other/consent-pages)****

合规页面（即订阅页面、偏好设置页面和取消订阅页面）是订阅者进行加入、确认同意、选择接收营销内容的特定偏好或选择Opt-out的地方。

当人们通过弹窗注册时，根据名单的配置，他们可能会看到一系列合规页面。例如，如果名单设置为双重确认（Double opt-in），当有人通过弹窗注册时，他们将看到邮件确认页面和加入成功确认页面。
