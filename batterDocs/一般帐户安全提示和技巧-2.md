<h1>一般帐户安全提示和技巧</h1>

<h2>对于非管理员/所有者</h2>
<p>1.使用强密码</p>
<ul>
<li>为您的 Klaviyo 帐户创建一个独特的强密码，其中包含数字、字母、符号和至少 12 个字符。</li>
<li>切勿与其他人（包括您的队友或同事）分享您的密码，也切勿在不同网站上重复使用该密码。</li>
</ul>
<p>2. 启用多重身份验证 (MFA)</p>
<ul>
<li>打开 MFA（如果适用于您的帐户）以提供额外保护，并添加备份方法以防止帐户锁定。</li>
<li>Klaviyo 建议使用基于身份验证器应用程序的短信 MFA，但任何形式的 MFA 都比没有好。</li>
</ul>
<p>3.谨防网络钓鱼</p>
<p><strong><em>*Klaviyo 员工绝不会询问您的密码、MFA 代码或恢复代码。永远不要把这些交给别人</strong></em>*</p>
<ul>
<li>在打开任何与 Klaviyo 相关的电子邮件之前检查发件人地址。我们只会直接从 @[klaviyo.com](http://klaviyo.com) 电子邮件地址向您发送电子邮件，因此请在打开之前仔细检查。</li>
<li>切勿点击可疑链接或下载未知附件。</li>
<li>不要在不熟悉的网站上输入您的 Klaviyo 登录凭据。如果您不确定，请直接导航至 [www.klaviyo.com](http://www.klaviyo.com)。</li>
</ul>
<p>4. 仅从受信任的设备访问 Klaviyo</p>
<ul>
<li>登录 Klaviyo 时避免使用公共/共享计算机或不安全的 Wi-Fi。</li>
<li>会话结束后务必注销，尤其是在共享设备上。</li>
</ul>
<p>5.及时报告安全问题</p>
<ul>
<li>如果您发现 Klaviyo 帐户中存在可疑电子邮件、意外密码提示或异常行为，请立即联系 [reportphishing@klaviyo.com](mailto:reportphishing@klaviyo.com)，并通知您的 IT 部门、安全团队（如果适用）。</li>
<li>我们还建议您立即更改密码，以防止任何人访问您的帐户。</li>
<li>分享您可以安全收集的尽可能多的信息 - 例如您收到内容的电子邮件地址、电子邮件标题或您认为相关的任何屏幕截图。</li>
</ul>
<h2>对于管理员/所有者</h2>
<p>1. 需要强认证</p>
<ul>
<li>指导所有用户为其 Klaviyo 帐户创建强而独特的密码。</li>
<li>在您组织的帐户上强制执行 MFA（注意：如果您使用的是付费帐户，我们已经为您完成了此操作！）</li>
<li>如果您的组织有身份提供商 (IdP)，建议启用单点登录 (SSO)</li>
<li>注意：这仅适用于付费计划</li>
</ul>
<p>2.定期审核用户访问</p>
<ul>
<li>定期检查您的 Klaviyo 帐户中的所有用户和角色。</li>
<li>删除不再需要访问权限的用户（例如前员工、合作伙伴、营销机构或承包商）。</li>
<li>遵循最小特权原则。当您设置[权限](https://help.klaviyo.com/hc/en-us/articles/115005231648)时，请为您的用户提供完成其工作所需的最小范围的权限，而不是更多</li>
</ul>
<p>确保您<strong><em>*绝不</strong></em>*在多人之间共享登录凭据 - 您可以免费在您的 Klaviyo 帐户上拥有任意数量的人。共享用户帐户使您无法判断谁在您的帐户中执行了操作，也使 Klaviyo 更难以检测是否有人在不应该访问您的帐户。</p>
<p>3. 监控账户活动</p>
<ul>
<li>验证帐户中的用户和角色，检查是否有任何看起来不熟悉的新用户。</li>
</ul>
<p>4. 谨慎管理集成和 API 密钥</p>
<ul>
<li>通过分配适当的用户角色来限制谁可以创建或管理 API 密钥和集成。</li>
<li>尽可能将 API 密钥迁移到 OAuth</li>
<li>定期轮换您帐户中的 API 密钥。这意味着定期生成新密钥来替换旧密钥，并删除旧密钥，通过限制密钥泄露时的潜在损害来增强安全性。</li>
<li>****提示：**** 您可以通过[克隆现有 API 密钥](https://help.klaviyo.com/hc/en-us/articles/115005062267#h_01HWR57G5STR2SW10YW0VBNEFQ) 在 Klaviyo 中轻松完成此操作，以便轻松替换。限制每个集成仅访问其所需的数据。</li>
</ul>
<p>5. 保持联系和恢复信息最新</p>
<ul>
<li>确保您组织在 Klaviyo 存档的管理员联系信息始终保持最新，以支持紧急情况下的帐户恢复。</li>
</ul>
<p>6. 随时了解情况</p>
<ul>
<li>监控 Klaviyo 的状态[页面](https://status.klaviyo.com/)、[博客](https://www.klaviyo.com/blog) 和[信任中心](https://www.klaviyo.com/trust) 以获取重要更新或安全建议。</li>
<li>随着新的安全功能或威胁的出现，调整您的实践。</li>
</ul>
