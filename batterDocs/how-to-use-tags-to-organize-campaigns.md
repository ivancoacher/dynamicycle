<h1>How to use tags to organize campaigns</h1>

## You will learn

Learn how you can use [tags](https://help.klaviyo.com/hc/en-us/articles/360025834271) to organize your campaigns by type, location, and more. Tagging can help you sort and search through your campaigns more easily, allowing to get a high-level look at a certain group's performance. This can be especially important for larger businesses where multiple people are creating campaigns.

If you'd like to learn how to add dynamic content to your campaigns, head to our guide on [message personalization](https://klaviyo.zendesk.com/hc/en-us/articles/4408802648731).

## Add tags when creating a new campaign

1. Go to ****Campaigns > Create campaign****.
2. Name the campaign and select the channel.
3. Scroll down until you see the **Tags** section.
4. Start typing to either find an existing tag or to add a new one.
   ![The Tags field when creating a new campaign](https://klaviyo.zendesk.com/hc/article_attachments/34635148619675)
5. Select ****Continue**** to finish drafting your campaign.

Campaigns can have more than one tag unless the tag belongs to a tag group that is exclusive.

## Add tags to an existing campaign

1. Navigate to the ****Campaigns**** tab in Klaviyo.
2. Click the checkbox next to one or more campaigns from the list view.
3. Click ****Add tags.****

   ![Add tags to campaigns](https://klaviyo.zendesk.com/hc/article_attachments/28704476561179)
4. Choose or create a new tag.
5. Click ****Add tags**** to save your changes.
