<h1>了解应用内表单</h1>

<h2>你将会学到</h2>
<p>了解应用程序内表单以及如何使用它们与移动应用程序用户共享重要消息。本指南概述了应用程序内表单，包括它们的工作方式以及表单编辑器中的自定义选项。要了解如何创建新的应用内表单，请参阅我们的指南[如何创建应用内表单](https://help.klaviyo.com/hc/en-us/articles/34567685177883)。 ## 什么是应用内表单？移动应用内表单是在移动应用内向用户显示的消息，类似于注册表单在网站上的显示方式。它们旨在在用户打开应用程序时适时吸引用户的注意力。所有打开您的应用程序的用户都可以看到在 Klaviyo 中创建的应用程序内表单（取决于表单的显示设置），这使其成为在用户积极使用您的应用程序并更有可能采取行动时吸引用户的有效工具。任何拥有移动应用程序的帐户都可以使用应用程序内的表单；但是，它们仅支持在 iOS 和 Android 设备上显示。您的移动应用程序必须至少使用 iOS SDK 4.2.0 版、Android SDK 3.2.0 版或 React Native SDK 1.2.0 版才能显示应用内表单。请注意，应用内表单的某些功能（例如时间延迟和事件触发器）仅适用于最新的 SDK 版本。 <strong><em>*应用内表单与移动推送通知</strong></em>*</p>
<p>应用程序内表单和移动推送通知都可以与应用程序用户进行通信，但它们的功能却截然不同。了解这些差异对于制定这些沟通策略至关重要。 |  |  |  |  |</p>
<p>| --- | --- | --- | --- |</p>
<p>| <strong><em>*功能</strong><strong> | </strong><strong>显示位置</strong><strong> | </strong><strong>目的</strong><strong> | </strong><strong>用户详细信息</strong></em>* |</p>
<p>|应用内表格 |在移动应用程序内，在应用程序屏幕上 |向用户更新新闻和/或在应用程序内提示特定操作 |用户无需启用通知设置即可查看应用内表单 |</p>
<p>|移动推送通知 |在锁定屏幕上或通知中心内 |吸引用户使用移动应用 |用户必须启用应用程序通知才能接收推送通知 |</p>
<p>简而言之，移动推送通知和应用程序内表单不同但互补：推送通知驱动应用程序打开，其中应用程序内表单提供集成到应用程序体验中的视觉内容。 ## 如何使用应用内表单？应用程序内表单允许您通过移动应用程序与所有用户进行交流，包括那些禁用了推送通知的用户，从而确保您的消息传递的广泛范围。与 Web 表单不同，应用内表单不能用于收集同意或个人资料数据，因此不需要连接到列表。应用内表单非常适合：</p>
<ul>
<li>通知用户重要更新，例如促销、产品发布或现场活动。 - 鼓励用户采取可以提高参与度和转化率的具体行动。 ## 构建应用内表单</li>
</ul>
<p>表单编辑器允许您为移动应用程序创建弹出表单、整页表单和弹出表单。您可以使用 Klaviyo 表单编辑器中的各种自定义选项修改外观、内容和行为。应用内表单的预构建模板很快就会在表单库中提供。 ![Klaviyo 中的表单编辑器在预览中显示示例应用程序内表单以及用于自定义表单的选项菜单。](https://klaviyo.zendesk.com/hc/article_attachments/34609859892507)</p>
<p>在构建时，根据需要使用菜单栏中的撤消和重做按钮（圆形箭头）。即使您离开并稍后返回，编辑器也会在您进行更改时自动保存您的工作。请注意，您必须发布更改才能在应用程序内表单上看到它们。 ### 将内容添加到应用内表单</p>
<p>您可以自定义应用内表单中的内容以满足您的需求。应用内表单只需一步，因为它们专注于有效的消息传递，这使其成为公告式消息的理想选择。它们不包含成功步骤或支持电子邮件或电话号码输入字段的同意收集。在 <strong>添加块</strong> 选项卡中，您可以将以下内容块拖放到表单预览中：</p>
<ul>
<li>****文本****</li>
<li>添加自定义文本以提供说明、上下文或其他相关信息，以指导用户的表单体验。 - ****按钮****</li>
<li>包括交互式按钮，将用户引导至应用程序内的其他页面或提示特定操作。 - 如果添加按钮，您可以将其配置为深层链接到应用程序中的特定页面（例如特色集合）。 请注意，此功能需要为您的应用程序设置深层链接。有关深层链接的更多信息，请咨询您的开发人员，或参阅我们的文章[在推送通知中使用深层链接](https://help.klaviyo.com/hc/en-us/articles/14750403974043)。 - ****图片****</li>
<li>合并视觉元素以增强表单的外观并吸引用户。 ![Klaviyo 表单编辑器中的“块”选项卡显示 3 个块选项：文本、按钮和图像。 ](https://klaviyo.zendesk.com/hc/article_attachments/34609859895067)</li>
</ul>
<p>添加到表单预览后，单击任何块即可访问其样式和自定义选项（例如字体样式、大小和颜色等）。 ### 设置应用内表单的样式</p>
<p>使用表单编辑器中的 <strong>样式</strong> 选项卡修改表单的设计，包括：</p>
<ul>
<li>****表格类型****</li>
<li>弹出窗口</li>
</ul>
<p>显示在移动应用程序屏幕的中间。弹出窗口引人注目且转化率高，但可能会破坏用户体验。 - 整页</p>
<p>显示在整个移动应用程序屏幕上，吸引用户的全部注意力。整页表单的转化率很高，因为用户不容易忽视它们；然而，它们也更具侵入性，因为用户必须与它们交互才能关闭它们。 - 弹出按钮</p>
<p>从移动应用程序屏幕的顶部或底部滑入。弹出窗口在可见性和微妙性之间取得了平衡，足够引人注目以推动参与，同时允许用户继续与屏幕的其余部分进行交互。 - <strong><em>*高度</strong></em>*</p>
<ul>
<li>调整表单的大小及其在屏幕上占用的空间。 - ****背景颜色****</li>
<li>选择表格的背景颜色。 - ****背景图片****（可选）</li>
<li>包含背景图像并调整其设置。 - ****叠加颜色****</li>
<li>选择在表单后面显示的颜色。半透明的覆盖层将突出显示表单并使应用程序的内容变暗。 ![屏幕截图 2025-08-29 2.29.44 PM.png](https://klaviyo.zendesk.com/hc/article_attachments/40535404479771)</li>
</ul>
<p>这些设置是一些关键的设计元素，但还有其他可用的样式选项，您可以在我们的[如何设置注册表单样式](https://help.klaviyo.com/hc/en-us/articles/4413537049883)指南中了解更多信息。 ### 配置表单的行为</p>
<p>表单编辑器的 <strong>定位和显示行为</strong> 选项卡包含 <strong>受众、计时、触发器</strong> 和 <strong>显示频率</strong> 设置。使用这些设置来选择谁可以看到应用内表单、在什么情况下、何时以及频率。请参阅[如何创建应用内表单](https://help.klaviyo.com/hc/en-us/articles/34567685177883) 指南，了解有关为应用内表单设置定位和行为的更多信息。我们还建议启用<strong>如果单击“转到应用程序屏幕”按钮则不再显示</strong>设置，以防止用户使用表单后再次出现。请注意，应用内表单可以安排上线或恢复为草稿状态。请参阅[如何安排注册表单](https://help.klaviyo.com/hc/en-us/articles/10391017061019) 指南了解更多信息。 ![屏幕截图 2025-08-29 2.36.27 PM.png](https://klaviyo.zendesk.com/hc/article_attachments/40535427165211)</p>

<h2>应用内表单分析</h2>
<p>创建应用内表单草稿后，您可以在 Klaviyo 帐户的表单列表视图中<strong><em>*注册表单</strong></em>*选项卡下找到它。应用程序内表单标有“应用程序内”徽章，以将其与您的网站表单区分开来。 ![Klaviyo 中的注册表单选项卡在列表视图中显示示例帐户的现有表单。](https://klaviyo.zendesk.com/hc/article_attachments/34609859901723)</p>
<p>发布后，您可以通过单击其他操作菜单（3 个点）然后<strong><em>*分析</strong></em>*来查看应用程序内表单的分析。分析页面显示以下指标：</p>
<ul>
<li>景观</li>
<li>提交</li>
<li>提交率</li>
</ul>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/34609859903771" alt="示例应用内表单的概述分析报告，显示表单的提交率以及提交和查看次数。" />
<p>当用户与您的表单交互并单击“转到应用程序屏幕”按钮时，Klaviyo 将跟踪表单的视图和提交，您可以在 <strong>表单概述</strong> 报告中分析表单的这些汇总计数。请参阅我们的[了解表单分析](https://help.klaviyo.com/hc/en-us/articles/360015960712)指南，了解有关这些指标以及如何评估应用内表单性能的更多信息。</p>
