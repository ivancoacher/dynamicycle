<h1>如何配置通信风格规则</h1>

<h2>你将会学到</h2>
<p>沟通风格规则是什么，它们可以做什么和不能做什么，以及如何编写能够有意义地影响客户代理的写作方式的规则。</p>
<h2>开始之前</h2>
<p>你需要：</p>
<ul>
<li>****所有者****、****管理员****或****经理****角色</li>
<li>语气设置（推荐 - 规则层位于语气之上）</li>
</ul>
<h2>沟通风格规则是什么</h2>
<p><strong><em>*沟通风格规则</strong></em>*是具体的写作指南，适用于所有客户代理的响应、各种技能和渠道。基调决定了整体氛围，而沟通风格规则则负责处理机制——句子长度、格式、特定的单词选择、要避免的短语。</p>
<p>您最多可以创建 <strong><em>*20 条规则</strong></em>*。大多数品牌只需要 3-5 个。</p>
<h3>规则可以做什么</h3>
<ul>
<li>替换特定词语（“永远不要说‘不幸’”）</li>
<li>强化词汇（“称之为‘骑行’而不是‘旅行’”）</li>
<li>禁止特定短语</li>
<li>添加免责声明（例如，“始终提醒购物者咨询医生”）</li>
<li>设置格式（句子长度、项目符号列表、表情符号使用）</li>
</ul>
<h3>规则不能做什么</h3>
<p>这是最常见的混淆 - 通信风格规则是关于客户代理<strong>如何</strong>编写，而不是<strong>它做什么</strong>。规则<strong><em>*不能</strong></em>*：</p>
<ul>
<li>查找客户数据</li>
<li>检查库存或订单状态</li>
<li>在外部系统中采取行动</li>
<li>决定哪个技能处理请求</li>
</ul>
<p>如果你需要任何这些行为，你需要的是技能或工具，而不是规则。</p>
<h2>设置</h2>
<p>1. 导航至<strong><em>*客户代理 > 指导 > 沟通方式</strong></em>*。</p>
<p>2. 单击<strong><em>*添加规则</strong></em>*。</p>
<p>3. 写下<strong><em>*标题</strong></em>*（最多 100 个字符）——简短且具有描述性。</p>
<p>4. 编写<strong><em>*描述</strong></em>*（最多 500 个字符）——实际规则以及客户代理需要遵循的任何上下文。</p>
<p>5. 单击<strong><em>*保存</strong></em>*。</p>
<p>6. 在操场上测试规则。</p>
<h2>编写好的规则</h2>
<p>好的规则是：</p>
<ul>
<li>****具体**** —“将回答控制在三句话以内”胜过“简洁”</li>
<li>****可操作**** — 表述为客户代理可以明确执行或不执行的操作</li>
<li>****单一用途**** - 每个概念一个规则，因此它们很容易启用、禁用和调试</li>
</ul>
<p>模糊的规则（“乐于助人”、“让顾客满意”）不会改变行为。他们重复已经做过的语气。</p>
<h2>示例</h2>
<p>有意义地改变行为的五个规则：</p>
<ul>
<li>****谨慎使用表情符号**** — 每个回复最多使用一个表情符号，并且仅当它增加温暖时才使用。切勿在道歉或升级时使用表情符号。</li>
<li>****将回复控制在三句话以内**** — 冗长的回复让聊天中的购物者不知所措。以答案引导；根据要求提供详细信息。</li>
<li>****永远不要说“不幸”**** — 这表示没有答案。重新构建以我们能做的事情为主导。</li>
<li>****当询问是开放式的时，始终以问题结束**** — 保持对话继续并提出下一个需求。</li>
<li>****不要为我们无法控制的事情道歉**** — 不要为承运商、天气或订单时间造成的运输延误道歉。陈述情况并提供前进的道路。</li>
</ul>
<h2>编辑和禁用规则</h2>
<p>您可以打开或关闭任何规则，而无需删除它。适用于：</p>
<ul>
<li>暂时禁用季节性规则</li>
<li>暂停在操场上产生意想不到结果的规则</li>
</ul>
<p>要完全删除规则，请单击其旁边的垃圾桶图标。</p>
<h2>何时使用规则与其他规则</h2>
<p>如果您不确定新行为属于哪里：</p>
<ul>
<li>****想要改变**** ******氛围******** ****每个回复的****？**** → 更新语气。</li>
<li>****想要在任何地方应用特定的书写规则吗？**** → 添加沟通风格规则。</li>
<li>****希望客户代理做一些新的事情（查找数据，采取行动）？**** → 建立一项技能或工具。</li>
<li>****希望客户代理在特定情况下升级？**** → 添加升级规则。</li>
</ul>
<h2>常见问题解答</h2>
<p><strong><em>*我可以有多少条规则？</strong></em>*</p>
<p>最多20个。大多数品牌使用3-5个；超过这个数量，规则往往会发生冲突。</p>
<p><strong><em>*规则适用于所有技能吗？</strong></em>*</p>
<p>是的。规则是全球性的——它们适用于所有技能和渠道的每一个响应。</p>
<p><strong><em>*如果两条规则冲突怎么办？</strong></em>*</p>
<p>客户代理将尝试同时遵循两者，但冲突的规则会产生不一致的结果。定期审查您的规则并巩固或消除冲突。</p>
<h2>后续步骤</h2>
<ul>
<li>****为需要人工的情况配置升级规则****</li>
<li>****在操场上进行测试****，看看您的规则如何影响响应</li>
</ul>
