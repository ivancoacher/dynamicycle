<h1>如何使用忠诚技能</h1>

<h2>你将会学到</h2>
<p>忠诚度技能如何让客户代理自动回答忠诚度和奖励问题。您的客户可以检查他们的积分余额，发现可用的奖励，并了解您的忠诚度计划 - 所有这些都无需打开支持票证。忠诚度技能通过网络聊天、短信、电子邮件和 WhatsApp 为购物者提供即时、自助式答案，从而避免重复的忠诚度查询、提高计划参与度并提高客户满意度。 ## 开始之前</p>
<p>在使用忠诚度技能之前，您需要满足以下条件：</p>
<ul>
<li>****客户代理****在您的帐户上启用。 - ****客户中心**** 与连接的忠诚度提供商（例如 Yotpo 或 Smile.io）保持活跃。 - ****有关您的忠诚度计划的知识库内容****已上传到客户代理（赚取规则、兑换选项、计划等级、常见问题解答）。 - 为客户代理配置至少一个活动渠道（****网络聊天****、****短信****、****电子邮件****或****WhatsApp****）。 > ****注意：**** 如果没有客户中心或连接的忠诚度提供商，代理会搜索您上传的有关忠诚度计划的内容。对于特定于帐户的问题，代理会执行软切换到人工代理。 - ****可用性：**** 可供所有客户代理客户使用。可通过网络聊天、短信、电子邮件和 WhatsApp 渠道使用。所有账号角色均可查看技能； ****管理员****和****所有者****可以配置它。 - ****完成时间：**** 启用该技能大约需要 5 分钟（假设客户中心和忠诚度提供商已连接）。 - ****重要提示：**** 代理商不能直接代表客户兑换奖励。它提供了客户中心忠诚度门户的深层链接，客户可以自行完成兑换。 ## 概述</li>
</ul>
<p>忠诚度技能可让客户代理自动回答忠诚度和奖励问题。它处理两类查询：</p>
<ul>
<li>****一般问题****（无需身份验证）——计划详细信息、赚取规则、兑换选项、等级说明以及如何加入。代理从您上传的知识库内容中回答这些问题。 - ****帐户特定问题****（需要身份验证）— 积分余额、注册状态和可用奖励。客户登录后，客服人员会出示会员卡或深层链接，以便客户可以查看和管理他们的奖励。 ****什么时候使用这个技能****</li>
</ul>
<p>当您的客户提出以下问题时，客户代理会使用忠诚度技能：</p>
<ul>
<li>“你们有奖励计划吗？”</li>
<li>“我有多少积分？”</li>
<li>“我如何兑换我的奖励？”</li>
<li>“我的积分什么时候到期？”</li>
</ul>
<p><strong><em>*如何按渠道运作</strong></em>*</p>
<ul>
<li>****网络聊天：**** 代理会显示一张忠诚积分卡，其中显示注册状态、积分余额和兑换信息。 - ****短信和 WhatsApp：**** 客服人员会发送一个指向客户中心忠诚度部分的深层链接。 - ****电子邮件：**** 代理发送简短回复，其中包含指向客户中心忠诚度部分的深层链接。 ****它与相邻技能有何不同****</li>
<li>****订阅技能**** — 处理订阅管理（暂停、取消、更新）。忠诚度技能特别关注忠诚度计划和奖励。 - ****一般问答技巧**** — 从您的知识库中回答一般品牌问题，无需身份验证。忠诚度技能将知识库答案与经过身份验证的会员卡呈现相结合，以获取特定于帐户的数据。忠诚度技能与其他客户代理技能一起发挥作用。客服人员会根据客户的问题自动路由到正确的技能。 ## 设置</li>
</ul>
<h3>第 1 步：验证先决条件</h3>
<p>1. 确认您的帐户已启用客户代理。 2. 导航至<strong><em>*客户中心</strong><strong>并确认其处于活动状态。 3. 确认客户中心已连接忠诚度提供商（例如 Yotpo 或 Smile.io）。 </strong><strong>注意：</strong><strong> 如果客户中心未激活或未连接忠诚度提供商，该技能将显示</strong><strong>不可用</strong></em>* 状态，并且客服人员会软移交至人工客服人员来解决忠诚度问题，而不是直接回答。 ### 第 2 步：上传忠诚度计划内容</p>
<p>1. 导航至<strong><em>*客户代理内容</strong><strong>。 2. 单击</strong><strong>添加内容</strong></em>*。 3. 上传或输入您的忠诚度计划详细信息。 包括：</p>
<ul>
<li>如何赚取积分（购买、推荐、社交分享等）</li>
<li>如何兑换奖励（折扣代码、免费产品等）</li>
<li>计划等级和福利（如果适用）</li>
<li>报名须知</li>
<li>积分过期政策</li>
</ul>
<p>4. 单击<strong><em>*保存</strong><strong>。 > 有关详细指导，请参阅[如何管理客户代理内容](#)。 </strong><strong>提示：</strong></em>* 您的知识库内容越全面，代理在无需身份验证的情况下处理一般忠诚度问题的效果就越好。 ### 第 3 步：确认技能已激活</p>
<p>1. 导航至<strong><em>*客户代理技能</strong><strong>。 2. 在技能列表中找到</strong><strong>忠诚</strong><strong>技能。当满足您的先决条件时，它默认处于活动状态。 3. 确认状态显示</strong><strong>Live</strong><strong>。如果显示</strong><strong>不可用</strong></em>*，请检查客户中心是否处于活动状态并且忠诚度提供商是否已连接。 ### 第 4 步：查看技能详细信息</p>
<p>1.点击<strong><em>*忠诚度</strong></em>*技能，打开技能详情页面。 2. 查看概述、响应行为和连接的工具。 ### 第 5 步：测试体验</p>
<p>1. 打开您的网络聊天小部件或通过短信、电子邮件或 WhatsApp 发送测试消息。 2. 询问忠诚度问题（例如，“我如何赚取积分？”或“我的积分余额是多少？”）。 3. 验证代理是否使用您知识库中的忠诚度信息进行响应，并在身份验证后出示忠诚度卡（网络聊天）或深层链接（短信、WhatsApp、电子邮件）。 <strong><em>*注意：</strong></em>* 对于帐户特定的问题，客户必须登录。经过身份验证后，客服人员会通过会员卡或客户中心的链接提供会员数据，包括注册状态、积分余额和可用奖励。 ## 最佳实践</p>
<ul>
<li>****保持您的知识库内容最新**** — 每当您的忠诚度计划发生变化时，更新赚取规则、兑换选项和等级详细信息。陈旧的内容会导致错误的答案并使客户感到沮丧。影响：解决率、客户满意度。 - ****上传有关您的忠诚度计划的详细常见问题解答内容**** — 涵盖过期政策、如何组合折扣和最低兑换阈值等边缘情况。影响：票据偏差、解决率。 - ****促进客户中心注册**** — 鼓励客户创建客户中心帐户，以便代理可以立即提供个性化忠诚度数据。影响：忠诚度计划参与度、解决率。 - ****使用多种渠道**** — 网络聊天显示丰富的会员卡；短信和 WhatsApp 发送深层链接；电子邮件发送带有简短回复的链接。提供多种渠道可以最大限度地扩大影响范围。影响：门票偏转、节目参与度。 ## 衡量成功</li>
</ul>
<h3>在哪里查看结果</h3>
<p>导航到 <strong>客户代理分析</strong> 以查看性能数据。单击“<strong>客户代理技能</strong>”页面上的“<strong><em>*忠诚度</strong><strong>”技能，可在“</strong><strong>绩效</strong></em>*”选项卡上查看技能级别指标。 ### 需要关注的关键指标</p>
<p>|公制|它告诉你什么 |</p>
<p>| --- | --- |</p>
<p>| <strong><em>*分辨率</strong></em>* |座席在没有人工交接的情况下解决的忠诚度对话的百分比</p>
<p>| <strong><em>*票偏转</strong></em>* |减少与忠诚度相关的支持请求|</p>
<p>| <strong><em>*切换率</strong></em>* |代理升级为人工代理的频率 — 越低越好 |</p>
<p>| <strong><em>*忠诚度计划参与</strong></em>* |在忠诚度门户的分析中：由代理深层链接驱动的忠诚度门户访问和兑换的增加。 |</p>
<h3>如果指标较低，请尝试这些修复</h3>
<ul>
<li>****低票偏差**** — 检查您的知识库，了解忠诚度内容中的差距。检查哪些问题会触发交接并添加内容来涵盖这些问题。确保客户中心正确连接，以便自动解决特定于帐户的问题。 - ****低分辨率**** — 通过更详细的赚取和兑换规则扩展知识库内容。确认您的忠诚度提供商集成正确同步。检查切换规则是否过于激进，从而导致不必要的升级。 - ****低忠诚度参与度**** — 将注册提示添加到非注册客户的知识库内容中。验证忠诚度门户的深层链接在所有渠道中是否正常工作。查看对话日志，以确保代理清楚地展示奖励和兑换选项。 ## 故障排除</li>
</ul>
<p><strong><em>*症状：</strong><strong> 客服人员不回答忠诚度问题并立即将其移交给人工客服人员。 </strong><strong>可能的原因：</strong><strong> 客户中心未激活或未连接忠诚度提供商。 </strong><strong>修复：</strong></em>* 导航至客户中心设置并确认忠诚度提供商（例如 Yotpo 或 Smile.io）已连接且处于活动状态。如果客户中心尚未激活，请设置它。一旦两者都到位，忠诚度技能就会自动激活并直接处理问题。 ---</p>
<p><strong><em>*症状：</strong><strong> 客服人员回答一般忠诚度问题，但无法显示客户的积分余额或奖励。 </strong><strong>可能的原因：</strong><strong> 客户未登录，或者忠诚度提供商未同步个人资料数据。 </strong><strong>修复：</strong></em>* 确认客户已登录。代理应自动提示登录以解决特定于帐户的问题。如果客户已登录但数据丢失，请检查客户中心中的忠诚度提供商集成，以确保个人资料数据同步。如果问题仍然存在，请让客户刷新页面并重试。 ---</p>
<p><strong><em>*症状：</strong><strong> 代理商提供了不正确或过时的忠诚度计划详细信息（例如，错误的赚取规则或过期的奖励）。 </strong><strong>可能的原因：</strong><strong> 知识库内容已过时。 </strong><strong>修复：</strong><strong> 在</strong>客户代理内容</em>*中更新您的忠诚度计划内容。删除过时的文章并上传当前计划详细信息，包括赚取规则、兑换选项和任何最近的计划更改。 ---</p>
<p><strong><em>*症状：</strong><strong> 忠诚积分卡未出现在网络聊天对话中。 </strong><strong>可能的原因：</strong><strong> 客户未经过身份验证，或者无法从提供商处检索忠诚度数据。 </strong><strong>修复：</strong></em>* 确保客户已登录。如果他们已登录但卡仍未出现，请验证忠诚度提供商集成是否处于活动状态并返回数据。检查客户中心设置是否有连接错误。如果问题仍然存在，请联系支持人员。 ---</p>
<p><strong><em>*症状：</strong><strong> 忠诚度门户的深层链接在短信、WhatsApp 或电子邮件中不起作用。 </strong><strong>可能的原因：</strong><strong> 客户中心深层链接配置错误或客户中心中未启用忠诚度部分。 </strong><strong>修复：</strong></em>* 验证客户中心是否处于活动状态并且忠诚度部分可以访问。直接在浏览器中测试深层链接 URL。确认已为客户代理启用相关通道。 ## 常见问题解答</p>
<p><strong><em>*问：代理商可以代客户兑换奖励吗？</strong></em>*</p>
<p><strong><em>*答：</strong><strong> 不会。代理会提供有关可用奖励的信息，并向客户发送指向客户中心忠诚度门户的链接，客户可以在其中自行完成兑换。这可确保客户直接评论并确认任何奖励选择。 </strong><strong>问：如果客户询问忠诚度但未登录，会发生什么？</strong></em>*</p>
<p><strong><em>*答：</strong><strong> 对于一般问题（例如，“我如何赚取积分？”），代理会根据您的知识库进行回答，无需进行身份验证。对于特定于帐户的问题（例如，“我有多少积分？”），客服人员会提示客户首先登录，然后通过卡片或链接显示他们的忠诚度数据。 </strong><strong>问：支持哪些忠诚度提供商？</strong></em>*</p>
<p><strong><em>*答：</strong><strong> 忠诚度技能与通过客户中心连接的忠诚度提供商合作。 Yotpo 和 Smile.io 是受支持的提供商。检查客户中心文档以获取支持的集成的最新列表。 </strong><strong>问：如果客户未加入忠诚度计划会怎样？</strong></em>*</p>
<p><strong><em>*答：</strong><strong> 代理商提供有关忠诚度计划的信息以及如何加入的说明。在网络聊天中，它可以包含指向客户中心注册页面的链接。 </strong><strong>问：忠诚度技能适用于所有频道吗？</strong></em>*</p>
<p><strong><em>*答：</strong><strong> 是的。在网络聊天中，客服人员会显示丰富的忠诚度积分卡，其中包含注册状态、积分余额和兑换信息。在短信和 WhatsApp 上，客服人员会发送指向客户中心忠诚度部分的深层链接。在电子邮件中，代理会发送带有深层链接的简短回复。深层链接可用于注册、积分余额和积分兑换。 </strong><strong>问：我是否需要为忠诚度创建单独的知识库内容，或者代理是否从忠诚度提供商处获取所有内容？</strong></em>*</p>
<p><strong><em>*答：</strong></em>* 你两者都需要。忠诚度提供商提供通过忠诚度卡或深层链接显示的特定于账户的数据（积分余额、注册状态、可用奖励）。您的知识库内容提供了代理程序用于回答一般问题的详细信息 - 赚取规则、兑换选项、等级权益和常见问题解答。上传全面的忠诚度内容以获得最佳效果。 ## 后续步骤</p>
<ul>
<li>****设置客户中心**** — 如果您还没有这样做，请连接您的忠诚度提供商并配置客户中心以支持特定于帐户的忠诚度响应。 - ****连接您的忠诚度提供商**** — 确保您的忠诚度提供商已连接到客户中心。 - ****上传忠诚度计划内容**** — 将有关您的收入规则、兑换选项、等级和常见问题解答的详细文章添加到您的客户代理知识库。 - ****配置切换设置**** — 为代理无法解决的边缘情况设置切换路径，例如有争议的余额或手动点调整。 - ****查看对话日志**** — 启动后，查看忠诚度对话以找出知识库中的差距并提高解决率。</li>
</ul>
