<h1>了解 Klaviyo 中的自动监视器</h1>

<h2>你将会学到</h2>
<p>了解 Klaviyo 中的自动监视器。 Klaviyo 自动监控您的账户绩效，以发现流量和活动等关键对象的异常情况。这使您能够在性能问题产生更大影响之前快速识别并解决它们。</p>
<h2>开始之前</h2>
<p>如果您是[高级 KDP](https://help.klaviyo.com/hc/en-us/articles/17655007276059) 客户，您还可以访问[自定义监视器](https://help.klaviyo.com/hc/en-us/articles/27160071187739) 功能。</p>
<h2>可用的自动监视器</h2>
<p>Klaviyo 自动监控您帐户中的以下对象，以提醒您以下性能问题：</p>
<ul>
<li>****流量触发器****</li>
</ul>
<p>与指标触发的流相关的事件数量异常（即触发流的次数下降）。</p>
<ul>
<li>****流消息发送****</li>
</ul>
<p>流中发送的消息数量异常（即流发送的电子邮件、短信或推送通知数量下降）。</p>
<ul>
<li>****每个电子邮件提供商的活动送达率****</li>
</ul>
<p>与每个收件箱提供商（例如 Gmail 和 Yahoo）相关的跳出率异常。请注意，仅监控由于内容或声誉问题而导致的退回邮件。</p>
<p>流程对象每 24 小时检查一次，营销活动交付率监视器在发送后 3 天内可见。</p>
<h2>监控警报</h2>
<p>要查看您的自动监视器，请导航至帐户左下角的<strong><em>*帐户</strong><strong> > </strong><strong>设置</strong><strong> > </strong><strong>监视器</strong></em>*。</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/31528813661595" alt="设置页面上的“监视器”选项卡" />
<p>如果您是高级 KDP 客户，您可以在同一页面上查看自定义监视器和自动监视器。</p>
<h3>监视器列表</h3>
<p>在主<strong>监视器</strong>页面上，您将看到现有自动监视器的列表视图。在每个自动监视器旁边，您将看到以下信息：</p>
<ul>
<li>****显示器名称****</li>
</ul>
<p>正在监控的 Klaviyo 对象的名称（即流、活动或段）。</p>
<ul>
<li>****状态****</li>
</ul>
<p>自动监控器的状态。这些可以是：</p>
<ul>
<li>****活跃****</li>
</ul>
<p>监视器已启用，并且在上次检查期间未触发警报。</p>
<ul>
<li>****警报****</li>
</ul>
<p>监视器已启用，并且在上次检查期间触发了警报。下次检查将在 24 小时内进行。</p>
<ul>
<li>****显示器类型****</li>
</ul>
<p>监视器类型本身（例如，流触发器、发送的流消息、活动可交付性）。</p>
<ul>
<li>****警报规则****</li>
</ul>
<p>关联监视器的警报规则集的预览。这将显示正在监控的指标以及是否存在与预期事件数量的偏差。</p>
<ul>
<li>****通知****</li>
</ul>
<p>自动监视器的通知始终处于启用状态。</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/31528813666587" alt="自动监视器列表" />
<h3>监控摘要</h3>
<p>如果您单击列表视图上的监视器，您将进入<strong>监视器摘要</strong>，您可以在其中找到有关监视器的更多信息。你会看到：</p>
<ul>
<li>****关键信息描述****</li>
</ul>
<p>显示器关键细节的摘要。</p>
<ul>
<li>****公制预览****</li>
</ul>
<p>随时间变化的指标预览，可以按日、周或月进行分组。</p>
<ul>
<li>****活动日志****</li>
</ul>
<p>您的监视器创建的最新警报的时间线。</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/31529635552667" alt="" />
<h3>警报日志</h3>
<p>要查看通过自动监视器发送的警报日志，请选择<strong><em>*警报日志</strong></em>*按钮。</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/31528813668379" alt="监控摘要" />
<p>在这里，您可以查看自动监控器触发的警报的时间线。如果在警报日志时间轴上展开事件，您可以看到有关该警报的更多信息，包括：</p>
<ul>
<li>具有触发警报的异常的 Klaviyo 对象</li>
<li>相关指标</li>
<li>违反规则导致警报</li>
</ul>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/31528861612699" alt="警报日志页面" />
<h3>通知</h3>
<p>默认情况下，<strong>所有者</strong>、<strong>管理员</strong>、<strong>经理</strong>和<strong>分析师</strong>用户角色将收到 [Klaviyo 主页上的通知](https://help.klaviyo.com/hc/en-us/articles/360049968412)。</p>
<p>此外，帐户所有者还将收到有关自动监控器警报的电子邮件通知。</p>
