<h1>了解短信抽奖和竞赛的合规性</h1>

<h2>你将会学到</h2>
<p>了解在美国和加拿大运行短信抽奖计划以及在英国运行免费抽奖和有奖竞赛的要求。抽奖、竞赛和免费抽奖可以成为快速增加名单的好工具。但是，它们须遵守州和联邦法律以及移动运营商的要求。 Klaviyo 仅支持在美国和加拿大通过批准的短代码进行的抽奖和竞赛。英国允许进行符合政府标准的免费抽奖和有奖竞赛，无需 Klaviyo 或运营商审查。此信息不是法律建议。 Klaviyo 建议所有客户咨询其法律顾问，以确保他们遵守与其营销活动相关的适用法律。 Klaviyo 无法就执行抽奖或竞赛的法律要求提供任何指导。本指南仅概述无线运营商审核和批准抽奖的流程和要求。 ## 开始之前</p>
<p>虽然 Klaviyo 作为短代码申请流程的一部分对计划条款和选择加入工作流程进行总体审查，但上游提供商和移动运营商最终自行决定批准或拒绝条款和披露。请注意：</p>
<ul>
<li>在美国和加拿大，运营商将抽奖活动限制为短代码。 - 在美国和加拿大，您无法使用免费号码、长代码或品牌发件人 ID 运行短信抽奖计划。 - 英国不允许任何号码类型的抽奖活动。 - 建议至少提前2个月提交抽奖请求。 - 审核过程大约需要 4 至 8 周。 - 一旦您的品牌获得抽奖批准，您无需在每次发起新的抽奖或竞赛时重新申请。建议至少在活动启动前 2 个月提交抽奖请求。一旦您的品牌获得抽奖批准，您无需在每次发起新的抽奖或竞赛时重新申请。 ## 比赛类型</li>
</ul>
<h3>抽奖活动</h3>
<p>抽奖是一种竞赛形式，其特点是机会因素和奖品颁发。不允许考虑（即随机抽取获胜者）。抽奖活动须遵守州和联邦法律以及移动运营商的要求。移动运营商单独审查抽奖计划，并保留自行决定批准或拒绝的权利。抽奖活动的一个例子是 SMS 注册表单或注册表页面，用于收集竞赛条目，并向一个或多个订阅者随机奖励一份礼物。条目必须是免费的，并且抽奖规则页面和移动条款清楚地显示在注册表单和网站上。仅允许在美国和加拿大进行抽奖[短代码](https://help.klaviyo.com/hc/en-us/articles/14476797072795)。 ### 免费抽奖</p>
<p>免费抽奖是一种竞赛类型，参与者可以参加抽奖以获得赢得奖品的机会。免费抽奖是英国的一个名称，类似于美国和加拿大的抽奖活动。在英国，“抽奖”仅支持付费参与方式，并被视为受英国赌博委员会监管的彩票。所有在英国禁止抽奖的英国发送号码均支持免费抽奖。免费抽奖的著名例子包括无需技巧即可参与的文字获胜活动。 ### 有奖竞赛和技巧游戏</p>
<p>有奖竞赛的结果由参与者的技能、判断力或知识决定。此类竞赛的一个例子包括多轮问题的付费问答比赛，参赛者因答案错误而被淘汰，唯一的获胜者因正确回答所有问题而获得奖金。 ## 抽奖短信合规性</p>
<p>在提交抽奖或竞赛以供批准之前，您必须满足以下条件：</p>
<p>请务必咨询您的法律团队，以验证您的抽奖或竞赛是否符合当地和联邦的要求。 - 拥有有效的短代码或目前正在申请一个。 - 在线提供您的抽奖或竞赛规则。 - 确保您的移动条款包含有关抽奖活动的计划信息。 - 您应该与您的法律团队确认您的移动条款符合必要的要求。 - 确保注册表单、电子邮件和网站横幅等号召性用语 (CTA) 包含有关抽奖活动的信息（如果适用）。 - 规则的位置必须列在 CTA 附近（例如，抽奖/竞赛规则页面的链接）。 - [移动条款](https://help.klaviyo.com/hc/en-us/articles/360049177511) 包括抽奖/竞赛（例如促销信息、购物车提醒、抽奖和/或竞赛促销）。请注意，满足这些最低要求并不能保证运营商获得批准。 ## 地区赛要求</p>
<h3>美国</h3>
<p>官方规则的细节可能会根据促销的性质而有所不同，但大多数州通常要求竞赛和抽奖都可以通过公司网站进行，并明确说明：</p>
<ul>
<li>免费入场方式</li>
<li>抽奖活动的生效日期</li>
<li>资格要求（例如年龄）和排除情况（例如赞助商员工的家庭成员）。 - 参赛期间的开始和结束日期（以及时间和时区，如果适用）</li>
<li>可以参加抽奖的所有州的列表</li>
<li>所颁发奖品的性质和数量以及奖品的大致零售价值 (ARV) 的完整描述</li>
<li>有关为竞赛获奖者提供的奖品、抽奖日期、规定的竞赛期限、奖品数量、奖品的任何区域分配以及获奖机会的详细信息必须包含在所有具有竞赛元素的项目的申请表中。对于其他比赛，大多数州还要求：</li>
</ul>
<ul>
<li>选择获胜者的标准。 - 出现平局时确定获奖者的方法。否则，一些州要求两名获奖者获得相同价值的奖金。 ### 加拿大</li>
</ul>
<p>抽奖在加拿大被称为竞赛，加拿大运营商批准的要求略有不同。最低要求是：</p>
<ul>
<li>所有竞赛必须提供“无需购买”的参与方式。 - 竞赛规则和条例必须遵守所有适用的地方、省、地区和联邦法律，并且必须在计划启动前根据要求向任何无线运营商提供。 - 所有带有竞赛元素的项目的申请表必须包括以下内容：</li>
</ul>
<ul>
<li>- 有关所提供奖品的详细信息，包括数量和任何区域分配。 - 获胜的机会。 - 规定的比赛期限。 - 绘制日期。 - 不得提供针对个别无线运营商的特定价格（例如，“赢得一年的 Acme 电视捆绑包”）。 - 比赛获胜者将根据技能或随机方式选出并分配奖品。还鼓励举办竞赛的组织参考以下加拿大政府资源：</li>
</ul>
<ul>
<li>[竞赛局促销竞赛执行指南](https://competition-bureau.canada.ca/promotional-contests-enforcement-guidelines)</li>
<li>[魁北克酒类、课程和游戏 Régie](https://www.racj.gouv.qc.ca/la-regie/mandat0.html)</li>
</ul>
<h3>英国</h3>
<p>英国还针对可以举办的比赛类型及其要求制定了立法。根据 2005 年赌博法，未经英格兰、威尔士和苏格兰赌博委员会许可，不得组织抽奖活动。因此，Klaviyo 不支持在英国进行抽奖活动。然而，英国还可以举办其他类型的比赛。 <strong><em>*免费抽奖</strong></em>*</p>
<p>并非所有机会游戏都受到赌博委员会的监管。允许所有参赛作品免费或同时具有付费和免费参赛途径的免费抽奖活动。虽然免费抽奖不受赌博委员会审查，但他们可能会提出任何疑虑并要求比赛规则和其他信息。如果您通过付费参赛路线进行免费抽奖，则应平等对待免费参赛者和付费参赛者。确保：</p>
<ul>
<li>人们可以选择不付费参与。 - 免费参赛作品提交必须与付费参赛作品一样方便。 - 免费入场路线必须以与付费路线相同的水平进行宣传和展示。 - 确定奖品的系统不应将付费和免费参赛路线视为不同。 - 涵盖资格的充分服务条款必须公开。 ****有奖竞赛和技能比赛****</li>
</ul>
<p>有奖竞赛的组织者必须能够证明所需的技能、知识或判断力将：</p>
<ul>
<li>劝阻那些希望进入的人这样做，因为这太困难了。 - 阻止部分参赛者获奖。 例如，多项选择题或如果您的第一个答案错误则允许第二次机会的问题很少符合此标准。关于什么构成足够技能水平的服务被确定为有奖竞赛的规则尚未明确定义，因此有奖竞赛不太常见。还鼓励在英国举办免费抽奖或有奖竞赛的组织参考[英国博彩委员会免费抽奖和有奖竞赛](https://www.gamblingcommission.gov.uk/public-and-players/guide/page/free-draws-and-prize-competitions)信息。 ## 其他资源</li>
