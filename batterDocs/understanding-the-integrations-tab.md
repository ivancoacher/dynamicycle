<h1>Understanding the integrations tab</h1>

## You will learn

Learn how to access your installed integrations and explore Klaviyo’s app marketplace, where you can browse, install, and configure different integrations between Klaviyo and other platforms. The marketplace includes integrations for ecommerce, landing pages, payment systems, and more.

## View your integrations

To navigate to the Integrations tab in Klaviyo, click ****Integrations**** in the left-hand navigation.

On the resulting page, you can review the integrations currently enabled for your account.

![](https://klaviyo.zendesk.com/hc/article_attachments/39449099429147)

This page has the following columns:

- ****Name****
  By default, integrations are listed by name in alphabetical order. Click the name of an integration to view its configuration.
- ****Category****
  Each integration is assigned a category based on the integrated app. For example, the Shopify integration is listed as an **eCommerce platform**.
- ****Status****
  The status column informs you on the current state of the integration:
  - ****Enabled****
    Integration is active and syncing data.
  - ****Disabled****
    Integration is not syncing data.
  - ****Action Required****
    There is an issue with the integration that you should address.

    At the top right of this page, there are 3 buttons:
- ****Manage data****
  Opens a dropdown with the following options:
  - ****Import via CSV****
    Import integration event data using a CSV file. Learn more from our article on [how to manually import historical event data](https://help.klaviyo.com/hc/en-us/articles/115005081247).
  - ****SFTP data transfer****
    Import integration event data [using SFTP](https://developers.klaviyo.com/en/docs/use_klaviyos_sftp_import_tool).
  - ****Set up web tracking****
    View instructions on how to set up Klaviyo onsite tracking for your website.
- ****Developers****
  Opens a dropdown with the following options:
  - ****Developer tools****
    Generate sample data, view API logs and activity, and more.
  - ****Manage apps****
    Manage apps you’ve developed.
- ****Explore apps****
  View Klaviyo’s app marketplace to install an app or integration. See the next section of this article for more information.

## View the app marketplace

To view the app marketplace:

1. Select ****Integrations****.
2. Click ****Explore apps**** in the upper right.

You can also find the marketplace at [marketplace.klaviyo.com](https://marketplace.klaviyo.com/en-us/), which can be viewed when logged in to or out of Klaviyo.

![](https://klaviyo.zendesk.com/hc/article_attachments/39449055554971)

The app marketplace has a few key features:

- Discover integrations and apps, including new ones and those popular for your business (when logged in to Klaviyo).
- Search via the search box or filter by category.
- View feature highlights, support links, and more on each app listing page, including for apps built by third parties.

![](https://klaviyo.zendesk.com/hc/article_attachments/39449099435675)

Our app marketplace contains apps built by Klaviyo and select apps built by our ecosystem. If you can't find an app that you're looking for, reach out to your software provider directly.

## Add an integration

To add an integration or app:

1. Select ****Integrations****.
2. Click ****Explore apps**** in the upper right.
3. Search for the integration you're looking for and select it.
4. On the next page, click ****Install****.
5. Follow the instructions on the next page to integrate the specific platform.

For integrations built by Klaviyo, [search our Help Center](https://help.klaviyo.com/hc/en-us/search) for the appropriate **Getting started** guide.
