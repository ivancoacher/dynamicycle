<h1>如何配置您的选择退出关键字设置</h1>

<p>您必须是所有者、管理员或经理才能使用此功能。</p>
<h2>你将会学到</h2>
<p>了解如何控制选择退出关键字何时导致取消订阅。</p>
<p>选择退出关键字是一种合规关键字，需要操作和响应（即删除同意，然后确认选择退出）。借助此功能，当订阅者发送选择退出关键字时，您可以选择删除同意：</p>
<ul>
<li>Anywhere in an SMS (contains word)</li>
</ul>
<p>或</p>
<ul>
<li>作为短信中的唯一单词（完全匹配）</li>
</ul>
<p>此信息仅用于教育和信息目的，<strong><em>*不</strong></em>*应被解释为法律建议。所提供的内容本质上是一般性的，可能不反映最新的信息。 Klaviyo 强烈建议您咨询合格的法律顾问，以确保您遵守与使用我们的服务相关的适用法律和法规。</p>
<h2>开始之前</h2>
<p>请注意以下事项：</p>
<ul>
<li>对于美国的任何订阅者，您无法将 STOP 关键字设置为**完全匹配**。</li>
<li>每当美国号码在短信中包含“停止”一词时，Klaviyo 就会自动立即删除短信同意。</li>
<li>这是为了保护您免受潜在的合规问题的影响，因为美国有关 STOP 关键字的法律更为严格。</li>
<li>无论使用哪个选择退出关键字，选择退出关键字的自动响应始终使用“停止”一词。</li>
<li>您无法编辑选择退出关键字的自动响应。</li>
</ul>
<p>有关更多信息，请参阅这篇[有关合规性关键字如何工作的文章。](https://help.klaviyo.com/hc/en-us/articles/29928896469531)</p>
<h2>How each option for opt-out keywords works</h2>
<p>当消息包含选择退出关键字时，Klaviyo 提供 2 个选项：</p>
<p>1.<strong><em>*包含单词</strong></em>*（默认）</p>
<ul>
<li>如果选择退出关键字出现在短信中的任何位置，或者该词完全匹配，则订阅者将选择退出（例如，如果有人发短信“取消订阅”，则会删除短信同意）。</li>
<li>推荐给：那些想要严格遵守规定的人。</li>
</ul>

<p>2.<strong><em>*完全匹配</strong></em>*</p>
<ul>
<li>当消息仅包含选择退出关键字而没有其他内容时，订阅者将选择退出（例如，某人必须发短信“取消”（不区分大小写）才能同意删除）。</li>
<li>推荐用于：使用“取消”、“取消订阅”、“结束”和“退出”等词语的订阅业务。 （客户可以在讨论订阅本身时发送这些内容，而不是在短信同意时发送。）</li>
</ul>

<h2>Change your opt-out keyword settings</h2>
<p>对于美国订阅者，您无法配置 STOP 关键字的设置。</p>
<p>1. 在左下角选择您的帐户名。</p>
<p>2. 导航至<strong><em>*设置 > 短信 > 关键字响应</strong></em>*。</p>
<p>3. 单击选择退出关键字旁边的<strong><em>*编辑</strong></em>*。</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/29154311168027" alt="" />
<p>4. 选择您要配置的退出关键字旁边的下拉列表（例如，<strong>取消</strong>）。</p>
<ul>
<li>此功能不适用于美国的 STOP 关键字。！[](https://klaviyo.zendesk.com/hc/article_attachments/29158591823131)</li>
</ul>
<p>5. 选择：</p>
<ul>
<li>****Contains word**** (default)</li>
</ul>
<p>The opt-out keyword appears anywhere in an SMS.</p>
<ul>
<li>****完全匹配****</li>
</ul>
<p>The opt-out keyword is the only word in the SMS.</p>
<p>6. 在保存之前查看有关更改选择退出关键字设置的警告消息。</p>
<p>7. 选择<strong><em>*保存</strong></em>* 将此设置用于 opt 关键字。</p>
