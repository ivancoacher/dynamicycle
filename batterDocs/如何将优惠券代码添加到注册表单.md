<h1>如何将优惠券代码添加到注册表单</h1>

<h2>你将会学到</h2>
<p>了解如何将静态且唯一的优惠券代码添加到您的注册表单中，以提高提交率和转化率，并鼓励客户在您的网站上花费更多。最佳做法是将优惠券代码直接添加到表单的成功消息中，因为它可以激励注册并允许您的购物者无需离开您的网站即可领取优惠券。如果您在注册表单上使用 Shopify 和独特的 Shopify 优惠券，则当客户填写表单时，优惠券将自动应用到客户的购物车中。 ## 开始之前</p>
<p>优惠券有以下几种类型：</p>
<ul>
<li>****独特代码****</li>
</ul>
<p>独特的（也称为“动态”）优惠券代码是接收者可以使用一次的一系列随机数字或字母。每个收件人都会收到自己的优惠券代码，并且不会有 2 个收件人拥有相同的代码。唯一的优惠券代码通常比静态代码更长、更复杂。 - <strong><em>*静态优惠券</strong></em>*</p>
<p>静态优惠券代码是供所有客户使用的单一代码（例如，Welcome20）。每个人都会收到相同的代码以在您的网站上使用。静态代码可以共享出去；然而，它们更容易记住和使用。配置优惠券的过程将根据您使用的优惠券类型（即静态优惠券、唯一 Shopify 优惠券或上传的唯一优惠券）而有所不同；但是，无论优惠券类型如何，都应遵循本指南的前 2 部分。不收集电子邮件或短信同意的横幅表单只能包含静态优惠券。收集电子邮件或短信同意的横幅必须在成功步骤中包含一个唯一的优惠券块。 ## 准备您的注册表单</p>
<p>1. 选择 Klaviyo 左侧导航栏中的<strong><em>*注册表单</strong><strong>选项卡。 2. 从这里，您可以通过几个选项来创建包含优惠券的表单。 - 选项 1：选择 1 个现有表单进行编辑并添加优惠券。 - 选项 2：从表单库中选择一个已包含优惠券块的预构建模板。为此，请选择右上角的</strong><strong>创建注册表单</strong></em>*，然后选中菜单栏中的框以过滤表单库中的搜索。 ![在页面顶部勾选了优惠券和优惠框的表单库以缩小搜索范围](https://klaviyo.zendesk.com/hc/article_attachments/28723522657819)</p>
<ul>
<li>选项 3：从头开始创建一个全新的表单并为其配置优惠券。为此，请选择右上角的****创建注册表单****，然后****创建新的注册表单****。 3. 进入您计划添加优惠券的注册表单的表单编辑器。使用上述任何选项，您都可以轻松地将优惠券块添加到表单生成器中的注册表单中。 ## 将优惠券块添加到表单的成功步骤</li>
</ul>
<p>进入注册表编辑器后，您可以添加和配置优惠券。请按照以下静态优惠券和唯一优惠券的设置说明进行操作：</p>
<p>1. 在表单编辑器中，选择预览中的提交按钮。 ![表单编辑器中显示的示例表单的按钮菜单，其中“操作”设置为“提交表单”，“提交后”设置为“显示下一步”](https://klaviyo.zendesk.com/hc/article_attachments/28723522654491)</p>
<p>2. 将 <strong>按钮单击操作</strong> 设置配置为以下内容：</p>
<ul>
<li>**行动**：****提交表格****。 - **要提交的列表**：选择您的列表。 - **提交后**：****显示下一步****。 3. 在页面顶部，选择****成功****以打开表单的成功步骤。这是访问者提交表单时将看到的页面。 ![在示例表单的表单编辑器的菜单栏中选择的成功步骤](https://klaviyo.zendesk.com/hc/article_attachments/28723522660763)</li>
</ul>
<p>4. 在<strong>概述</strong>页面的左侧，选择<strong><em>*添加块</strong><strong>选项卡。 5. 将</strong><strong>优惠券</strong><strong>块（位于</strong>元素<strong>下）拖放到预览中您希望优惠券出现在表单中的任意位置（如果那里还没有优惠券）。 6. 在表单预览中单击</strong><strong>配置优惠券</strong></em>*。 ![](https://fast.wistia.com/embed/medias/psyi573645/swatch)</p>
<p>1. 在左侧显示的设置菜单中，选择在表单中设置静态或唯一优惠券。 ## 在表单中设置静态优惠券</p>
<p>1. 在优惠券设置菜单顶部，选择<strong><em>*静态优惠券</strong></em>*。 2. 在文本框中输入静态优惠券代码的名称（例如Welcome10）。 - 如果您没有准备好现有的静态代码，您首先需要[在电子商务平台中手动创建一个](https://help.klaviyo.com/hc/en-us/sections/14545347290651)。 3. 如果您刚刚创建了新的静态代码，请在将其键入文本框之前重新加载表单构建器页面。 ![注册表单生成器中的优惠券菜单显示选定的静态优惠券及其在文本框中输入的名称](https://klaviyo.zendesk.com/hc/article_attachments/28723522627227)</p>
<p>4. 编辑块样式（例如背景颜色、圆角半径、边框样式、边框粗细、填充），使优惠券大而醒目。 5. 完成编辑后，单击后退箭头保存优惠券。 ![优惠券块编辑器内的后退箭头](https://klaviyo.zendesk.com/hc/article_attachments/38308316851867)</p>
<p>6. 跳到最后部分[完成编辑并发布表单](https://help.klaviyo.com/hc/en-us/articles/6038674938523#h_01HA28D5B1V3AKQ76C5N6TJBGJ)。 ## 在您的表单中设置唯一的优惠券代码</p>
<p>在优惠券设置菜单顶部，选择<strong><em>*独特优惠券</strong></em>*。根据您使用的是 Shopify 唯一优惠券还是上传的唯一优惠券，您的设置会略有不同。目前，在成功消息中显示唯一优惠券代码的功能仅适用于 Shopify 优惠券、上传的优惠券和 API 优惠券。虽然可以在 Klaviyo 中为 WooCommerce、Magento 2 和 PrestaShop 创建独特的优惠券，但目前无法在注册表单中显示这些代码。或者，按照[上传的优惠券](https://help.klaviyo.com/hc/en-us/articles/6038674938523#h_01HA28D5B051GZENA8E4DCJJCR)或[API优惠券](https://developers.klaviyo.com/en/docs/use_klaviyos_coupons_api)说明添加唯一的优惠券代码形式。 ### Shopify 优惠券</p>
<p>1. 选择 <strong><em>*Shopify 优惠券</strong><strong> 作为您的 </strong>唯一优惠券类型。</em>*</p>
<p>2. 单击<strong><em>*独特优惠券</strong><strong>旁边的下拉菜单选择现有优惠券，或单击</strong><strong>(+)独特 Shopify 优惠券</strong></em>*创建新优惠券。 ![注册表单编辑器中打开的优惠券菜单显示所选的独特优惠券类型](https://klaviyo.zendesk.com/hc/article_attachments/34483817889819)</p>
<p>3. 如果您选择创建新的、唯一的 Shopify 优惠券代码，则会出现<strong><em>*创建唯一的 Shopify</strong></em>* 优惠券模式，要求您：</p>
<ul>
<li>为您的优惠券命名（例如 10OFF），并添加可选的前缀。 - 选择您想要为客户提供的折扣类型（固定金额、百分比或免费送货）。 - 选择优惠券运作方式的设置（金额、应用、激活和过期）。 - 请注意，如果您为 **过期** 选择 ****1 年之后**** 或 ****在特定日期****，Klaviyo 将在将优惠券添加到表单时生成初始批次 600 个唯一代码，并在可用数量低于 400 时生成更多代码。如果您选择在一定天数/小时后，Klaviyo 将生成一批 600 个代码天.![](https://klaviyo.zendesk.com/hc/article_attachments/38308326776091)</li>
</ul>
<p>4. 单击右下角的<strong><em>*创建独特的 Shopify 优惠券</strong><strong>。这将带您返回表单生成器，并选择在表单中使用新创建的优惠券代码。 5. 添加现有的静态优惠券作为</strong>后备优惠券<strong>。这是一个静态代码，仅当您用完唯一的优惠券代码时才会出现，以便您的客户仍然可以获得相同的折扣。您需要首先在 Shopify 中创建静态优惠券，然后将其粘贴到 </strong>后备优惠券</em>* 文本框（例如 10PERCENT）。 6. 跳到最后部分[完成编辑并发布表单](https://help.klaviyo.com/hc/en-us/articles/6038674938523#h_01HA28D5B1V3AKQ76C5N6TJBGJ)。 ### 已上传优惠券</p>
<p>如果您尚未启用，请确保您已启用上传优惠券。导航至<strong><em>*设置 > 其他 > 个人资料维护</strong><strong>，然后打开 </strong>上传优惠券</em>* 选项。 ![打开此选项时上传优惠券切换的显示方式](https://klaviyo.zendesk.com/hc/article_attachments/34483801682971)</p>
<p>1. 在您的表单中，选择<strong><em>*上传的优惠券</strong><strong>作为您的</strong>唯一优惠券类型<strong>。 2. 单击 </strong>唯一优惠券<strong> 旁边的下拉列表以选择现有优惠券，或单击</strong><strong>创建上传的优惠券</strong></em>* 链接。 ![从唯一优惠券设置菜单中选择的创建上传优惠券链接](https://klaviyo.zendesk.com/hc/article_attachments/28723544584091)</p>
<p>3. 如果您选择现有优惠券，请确保您已将代码上传到该优惠券。 4. 如果您选择创建新上传的优惠券，<strong>创建优惠券</strong>页面将在新选项卡中打开。从这里开始：</p>
<ul>
<li>配置以下详细信息：</li>
<li>姓名（例如 JustForYou）</li>
<li>优惠券最低数量（例如 500 张）</li>
</ul>
<p>优惠券数量必须是 100 - 5000 之间的值。不接受该范围之外的值。如果未指定最小值，则默认计数将为 500。 - 到期日期</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/39700139947931" alt="" />
<ul>
<li>点击右上角的****创建优惠券****。这将带您进入**上传的优惠券**页面。 - 在 **上传的优惠券** 页面上，单击您想要用于表单的优惠券右侧的 ****3 个点**** ****> 添加代码****。 ![](https://klaviyo.zendesk.com/hc/article_attachments/38522139367451)</li>
<li>上传您的 CSV 文件以处理这些代码。您可以参考[我们的独特优惠券上传指南](https://help.klaviyo.com/hc/en-us/articles/115005084727#h_01HMW7FB2WV5RT1T0EZ3N7TMJ9)寻求帮助。 - 导航回注册表单生成器选项卡并重新加载页面。 5. 选择********成功********步骤，然后在预览中单击****配置优惠券****。 6. 在**独特优惠券**旁边，从下拉列表中选择您新上传的优惠券。 ![注册表单编辑器中的“独特优惠券”下拉列表中选择您刚刚上传的优惠券作为优惠券选项](https://klaviyo.zendesk.com/hc/article_attachments/28723522650523)</li>
</ul>
<p>7. 添加现有的静态优惠券作为<strong>后备优惠券</strong>。这是一个静态代码，仅当您用完唯一的优惠券代码时才会出现，以便您的客户仍然可以收到一些优惠券。 - 您需要首先将静态优惠券上传到 Klaviyo，然后粘贴到 <strong>后备优惠券</strong> 文本框（例如 10PERCENT）。 ![为注册表单配置优惠券后出现的后备优惠券消息](https://klaviyo.zendesk.com/hc/article_attachments/28723544592795)</p>
<h2>完成编辑并发布表单</h2>
<p>为您的表单设置优惠券后：</p>
<p>1. 对优惠券的外观和文本或表单上的其他步骤进行最终样式更改。 2. 当您准备好设置表单时，单击<strong><em>*发布</strong></em>*。 3. 转到您的网站并重新加载页面以查看您的表单。在生成唯一的优惠券代码时，表格可能需要一段时间才会出现在您的网站上。 4. 填写表格以测试您的优惠券是否已正确处理。一旦完成，客户将直接在您表单的成功消息中收到优惠券代码，以便在您的网站上复制和使用。如果您在注册表单中使用 Shopify 优惠券，则在客户到达表单的最后一步时，它将自动应用于客户的 Shopify 结帐页面。</p>
