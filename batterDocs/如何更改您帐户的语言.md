<h1>如何更改您帐户的语言</h1>

<h2>你将会学到</h2>
<p>了解如何更改 Klaviyo 帐户的组织和个人语言设置。更改语言还会更新区域格式（例如数字和日期）。 ## 了解组织语言设置与个人语言设置</p>
<p>每个 Klaviyo 帐户都有 2 种语言设置：</p>
<p>1. 组织语言设置</p>
<ul>
<li>只有帐户所有者和管理员才能更新此设置。 - 此设置适用于整个帐户，并用于管理通信（例如计费消息）。 - 帐户的组织设置不会影响您在 Klaviyo 应用程序中看到的语言。 2. 个人语言设置</li>
</ul>
<ul>
<li>Klaviyo 帐户中的每个个人用户都可以设置他们的个人语言设置。 - 此设置决定您在 Klaviyo 中看到的语言。它适用于您访问的所有帐户，并在浏览器会话中持续存在。 - 从 Klaviyo 发送给各个收件人的电子邮件（除帐单消息外）将以他们个人选择的语言发送。 [向帐户添加新用户](https://help.klaviyo.com/hc/en-us/articles/360053547071#h_01HBRSGK50EGR5QMTB3XZNB7V9) 时，所有者和管理员可以选择他们的个人语言首选项。这将在邀请和入职流程中使用，尽管新用户可以根据需要稍后修改其个人语言设置。更改您的**语言和区域格式**设置不会自动更改您的[**时区**](https://help.klaviyo.com/hc/en-us/articles/115005232388)或[**帐户货币**](https://help.klaviyo.com/hc/en-us/articles/115005061007)设置。例如，如果您从美国英语更改为法语，您会看到数字 $123, 345. 89 格式为 123456, 89$；但是，默认货币不会从美元更改为欧元。 **时区**和**帐户货币**都将保留在您帐户的默认选择中，除非在[**组织设置**](https://www.klaviyo.com/settings/account/organization)[页面](https://www.klaviyo.com/settings/account/organization)上单独调整。本指南将介绍如何更改 Klaviyo 帐户的组织和个人语言设置。有关如何更改投资组合语言的说明，请参阅[了解您的投资组合设置](https://help.klaviyo.com/hc/en-us/articles/25185154392603#h_01HWNQTZWDX28CAZNN2Y1P5TCG)。 ## 更改您的组织语言设置</li>
</ul>
<p>只有帐户 [所有者和管理员](https://klaviyo.zendesk.com/hc/en-us/articles/115005231648) 可以配置组织语言设置。为此：</p>
<p>1. 单击 Klaviyo 左下角您的组织名称。 2. 导航至<strong><em>*设置 > 组织</strong></em>*。 ![在菜单中选择组织的帐户设置页面。](https://klaviyo.zendesk.com/hc/article_attachments/28716334330907)</p>
<p>3. 向下滚动到<strong>组织语言和区域格式</strong>部分。 ![组织设置页面的组织语言和区域格式部分显示示例帐户的组织语言设置为英语。](https://klaviyo.zendesk.com/hc/article_attachments/28889377430427)</p>
<p>4. 单击进入<strong><em>*组织语言</strong></em>* 下拉列表并选择一种语言。目前，Klaviyo 支持以下语言：</p>
<ul>
<li>英语</li>
<li>法语（**法语**）</li>
<li>德语（**德语**）</li>
<li>意大利语（**意大利语**）</li>
<li>韩语 (한국어)</li>
<li>葡萄牙语（**葡萄牙语**）</li>
<li>西班牙语（西班牙）- (**Español (España)**)</li>
<li>西班牙语（墨西哥）- (**西班牙语（墨西哥）**)</li>
<li>瑞典语 (**Svenska**)</li>
<li>荷兰语（**荷兰**）</li>
<li>波兰语（**波兰语**）</li>
</ul>
<p>5. 单击<strong><em>*保存</strong></em>* 确认更改。 ## 更改您的个人语言设置</p>
<p>要更新您的个人语言设置：</p>
<p>1. 单击左下角您的组织名称。 2. 导航至<strong><em>*设置 > 个人</strong></em>*。 ![帐户设置页面显示从左侧菜单中选择的个人。](https://klaviyo.zendesk.com/hc/article_attachments/28889350000411)</p>
<p>3. 滚动到 <strong>个人语言和区域格式</strong> 部分，然后单击 <strong>语言</strong>** 下拉列表。 4. 从列表中选择您的首选语言。 请注意，目前 Klaviyo 支持以下语言：</p>
<ul>
<li>英语</li>
<li>法语（**法语**）</li>
<li>德语（**德语**）</li>
<li>意大利语（**意大利语**）</li>
<li>韩语 (한국어)</li>
<li>葡萄牙语（**葡萄牙语**）</li>
<li>西班牙语（西班牙）- (**Español (España)**)</li>
<li>西班牙语（墨西哥）- (**西班牙语（墨西哥）**)</li>
<li>瑞典语 (**Svenska**)</li>
<li>荷兰语（**荷兰**）</li>
<li>波兰语（**波兰语**）</li>
</ul>
<p>5. 如果您不想翻译事件和指标名称，请选择“显示英文指标和事件名称”。如果您习惯了这些事件的英文名称或需要以编程方式引用它们，这可能会很有用。 ![个人设置页面的个人语言和区域格式部分显示示例帐户的个人语言设置为英语。](https://klaviyo.zendesk.com/hc/article_attachments/43693418328091)</p>
<p>6. 单击<strong><em>*保存</strong></em>*。此更改将立即应用于您访问的所有帐户。 [Klaviyo 帮助中心](https://help.klaviyo.com/)[r](https://www.klaviyo.com/legal) 还提供每种支持的语言版本，以在平台导航时提供指导。 ## 用新语言导航 Klaviyo</p>
<p>当您设置新的个人语言时，Klaviyo 平台的大多数元素都会翻译。然而，有些仍将保留英语。以下是您可以期待的：</p>
<h3>什么会翻译成您的个人语言设置</h3>
<ul>
<li>Klaviyo 应用程序中的所有页面和页面元素（例如标题、按钮、副文本等）</li>
<li>[主题行助手](https://help.klaviyo.com/hc/en-us/articles/5051278887835)</li>
<li>数据的区域格式，包括：</li>
<li>日期</li>
<li>时间</li>
<li>时区；这仅指时区的格式。 - 数量</li>
<li>货币；这仅指货币的格式，例如货币值中的空格和分隔符（例如小数点或逗号）。 - 百分比</li>
<li>Klaviyo 主页上的帐户提醒</li>
<li>事件和指标名称（例如，**已下订单**）</li>
</ul>
<p>电子邮件支持和我们的虚拟助理适用于每种受支持的语言。 [了解如何联系支持人员](https://klaviyo.zendesk.com/hc/en-us/articles/115001002272)。 ### 剩下的英文内容</p>
<ul>
<li>流程和细分人工智能</li>
<li>每个内容库中几乎所有预构建的模板（例如，活动模板、流程模板、表单模板等）。请注意，某些翻译模板仅提供法语版本。 - 最初以英语或其他语言编写的任何表格或消息内容</li>
<li>请注意，对于您创建的任何新模板，您仍然需要手动[根据语言自定义内容](https://help.klaviyo.com/hc/en-us/articles/115005239028)。 - 动态变量（例如，取消订阅标签，如 {% unsubscribe %} ）</li>
<li>当您设置新语言时，**时区**和**帐户货币**设置不会自动更改。仅它们的格式会根据所选语言进行调整。</li>
</ul>
