<h1>如何跨产品组合批量管理用户</h1>

<h2>****概述****</h2>
<p>通过批量用户管理，具有正确用户角色的投资组合用户可以从单个集中式界面管理多个链接帐户的用户访问权限。这样就无需在各个帐户之间切换来添加、编辑或删除用户，从而提供组织活动用户的“鸟瞰图”。</p>
<p>在本文中，您将学习如何：</p>
<ul>
<li>同时将新用户添加到多个帐户。</li>
<li>批量编辑用户角色和权限。</li>
<li>一次性将用户从所有投资组合链接账户中移除。</li>
<li>了解 SSO 和活动日志的影响。</li>
</ul>
<h2>****开始之前****</h2>
<p>批量用户管理仅在产品组合级别可用。要访问此功能，您必须具有以下角色之一：</p>
<ul>
<li>****投资组合所有者****</li>
<li>****用户管理编辑****权限设置</li>
</ul>
<h2>****批量添加新用户到关联帐户****</h2>
<p>您可以一次邀请一名或多名用户访问多个帐户，确保新团队成员拥有他们在整个品牌组合中所需的访问权限。</p>
<p>1. 导航至左侧导航栏中的<strong><em>*用户</strong></em>*选项卡。</p>
<p>2. 单击<strong><em>*邀请用户</strong></em>*。</p>
<p>3. 在<strong><em>*电子邮件地址</strong><strong>字段中，输入您想要邀请的个人的电子邮件地址。您可以使用逗号、空格或按 </strong><strong>Enter</strong></em>* 分隔多个地址。</p>
<p>4. 为这些用户选择首选<strong><em>*语言</strong></em>*。</p>
<p>5. 在<strong><em>*选择帐户</strong></em>*下，选中您希望用户访问的每个帐户旁边的框。</p>
<p>6.<strong><em>*为每个选定的帐户分配角色</strong><strong>。请注意，</strong>支持</em>*是默认角色；如有必要，请使用下拉菜单进行更改。</p>
<p>7. 单击<strong><em>*查看更改</strong></em>* 查看邀请摘要。</p>
<p>8. 单击<strong><em>*发送邀请</strong></em>*。</p>
<h2>****批量编辑用户角色****</h2>
<p>有两种方法可以编辑角色：单击特定用户的个人资料或使用一组帐户的批量复选框选择。</p>
<h3>****通过用户个人资料编辑角色****</h3>
<p>1. 在 <strong><em>*Users</strong></em>* 列表中找到用户并单击其姓名。</p>
<p>2. 查看用户当前访问的每个帐户及其特定角色的列表。</p>
<p>3. 要更新角色，请从特定帐户旁边的<strong><em>*角色</strong></em>*下拉列表中选择新角色。</p>
<p>4. 查看并<strong><em>*确认</strong></em>*更新。</p>
<h3>****跨帐户批量更新角色****</h3>
<p>1. 在用户的个人资料视图中，选中您要修改的每个帐户名称旁边的<strong><em>*复选框</strong></em>*。</p>
<p>2. 从批量操作栏中选择新的<strong><em>*角色</strong></em>*。</p>
<p>3. 单击<strong><em>*查看更改</strong></em>*。</p>
<p>4. 单击<strong><em>*更新角色</strong></em>*。</p>
<h2>****批量删除用户****</h2>
<p>快速撤销不再需要特定帐户或整个投资组合权限的用户的访问权限。</p>
<p>1. 在 <strong><em>*Users</strong></em>* 列表中找到用户并单击其姓名。</p>
<p>2. 查看用户当前访问的账户列表。</p>
<p>3. <strong><em>*要删除单个帐户的访问权限：</strong></em>*</p>
<ul>
<li>单击帐户旁边的****更多（三点）**** 菜单。</li>
<li>选择****删除访问****。</li>
</ul>
<p>4. <strong><em>*要删除多个帐户的访问权限：</strong></em>*</p>
<ul>
<li>选择每个帐户名称旁边的****复选框****。</li>
<li>从批量操作菜单中选择****删除访问****。</li>
</ul>
<p>5. 查看删除摘要并<strong><em>*确认</strong></em>*。</p>
<h2>****活动日志和安全****</h2>
<p>跟踪批量用户管理界面中采取的每项操作，以确保安全性和合规性：</p>
<ul>
<li>****审计跟踪：**** 当用户的角色发生更改或从组合中删除时，会在每个受影响帐户的****活动日志****中自动创建一个事件。</li>
<li>****可追溯性：**** 日志条目将指定更改是从 ****Portfolio 级别**** 发起的，从而识别执行该操作的 Portfolio 管理员。</li>
</ul>
<h2>****故障排除****</h2>
<ul>
<li>****为什么我无法编辑特定用户？**** 如果用户通过身份提供商（启用了 JIT 的 SSO）进行管理，则他们的角色将被锁定在 Klaviyo 中。您必须在 IDP 中更新他们的权限（例如 Okta 或 Azure）。</li>
<li>****为什么我看不到“用户”选项卡？**** 确保您处于产品组合级别（不在特定品牌帐户内）并且您的用户角色包括用户管理编辑权限。</li>
<li>****为什么我无法更新或删除所有者用户？**** 您无法通过投资组合批量管理界面更新帐户所有者的角色或将其从帐户中删除。由于所有者角色对个人账户承担最高级别的法律责任，因此这些更改必须由当前所有者在个人账户级别执行。</li>
</ul>
