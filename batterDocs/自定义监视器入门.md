<h1>自定义监视器入门</h1>

<h2>你将会学到</h2>
<p>了解 Klaviyo 中的自定义监视器。通过自定义监视器，您可以配置警报以快速识别和解决 Klaviyo 中关键指标和对象（即段和流）的问题。此外，请参阅我们的[推荐使用案例](#h_01J21X13C8N1WF8YJZD53NRM10)，快速设置监视器，以领先于问题并发现趋势。 [高级 KDP](https://help.klaviyo.com/hc/en-us/articles/17655007276059) 不包含在 Klaviyo 的标准营销应用程序中，需要订阅才能访问相关功能。请访问我们的[计费指南](https://help.klaviyo.com/hc/en-us/articles/115000976672)，了解如何购买此计划。 ## 开始之前</p>
<p>除了自定义监视器之外，高级 KDP 客户还将在“监视器”页面上看到自动监视器功能。 Klaviyo 的自动监控器会自动监控您的账户绩效，以发现流量和营销活动等关键对象的异常情况。请参阅我们的 Klaviyo [自动监视器](https://help.klaviyo.com/hc/en-us/articles/31141239059611) 指南，了解有关该功能的更多信息。 ## 创建自定义监视器</p>
<p>1. 要在 Klaviyo 中创建自定义监视器，请导航至<strong><em>*高级 KDP</strong><strong></em></strong><em>> 数据管理 > 监视器<strong></em><em>。 2. 选择</strong><strong>创建自定义监视器</strong><strong>或选择监视器类型（即</strong>单流<strong>）以开始该过程。如果没有以前创建的监视器，您将看到一条通知，指示您没有设置，以及</strong>创建自定义监视器<strong>按钮。如果您已经设置了监视器，</strong>创建自定义监视器</em>*按钮将出现在页面顶部。 ![BasicLayoutMain.jpg](https://klaviyo.zendesk.com/hc/article_attachments/31960096165531)</p>
<p>您可以在 Klaviyo 中设置 3 种类型的自定义监视器：</p>
<ul>
<li>****单流量监测器****</li>
</ul>
<p>用于监控关键性能指标并接收相关警报的流程。 - <strong><em>*单公制监视器</strong></em>*</p>
<p>用于监视和接收警报的事件。 - <strong><em>*单段监视器</strong></em>*</p>
<p>用于监视和接收警报的段。选择 <strong>创建监视器</strong> 按钮后，您需要配置 3 组信息来设置自定义监视器。下面的说明更详细地介绍了这些部分。 ### 监控详情</p>
<p>在 <strong>显示器详细信息</strong> 部分，您将输入有关显示器本身的命名、类型和设置的信息。 ![需要配置的监控设置](https://klaviyo.zendesk.com/hc/article_attachments/28723546468379)</p>
<p><strong><em>*显示器类型</strong></em>*</p>
<p>设置监视器的类型（即单流、单指标、单段）。 <strong><em>*显示器名称</strong></em>*</p>
<p>为自定义监视器设置名称。 <strong><em>*对象名称</strong></em>*</p>
<p>设置您要监控的流量、指标或段。根据监视器类型，您将看到可用指标、段或至少包含 1 条消息的活动流的列表。 <strong><em>*指标名称</strong></em>*</p>
<p>设置您将监控对象的特定性能指标。对于<strong>单个指标</strong>监控类型，您只能选择<strong>总数</strong>（即指标的计数）。对于 <strong>单段</strong> 监视器类型，您可以选择：</p>
<ul>
<li>****会员总数****</li>
<li>**添加成员**</li>
<li>**删除成员**</li>
</ul>
<p>对于 <strong>单流</strong> 监视器类型，可以使用以下指标：</p>
<ul>
<li>****打开率****</li>
<li>**点击打开价格**</li>
<li>**跳出率**</li>
<li>**垃圾邮件投诉率**</li>
<li>**点击率**</li>
<li>**转化率**</li>
<li>**退订率**</li>
<li>**收件人总数**</li>
<li>**总转化次数**</li>
<li>**交付总量**</li>
</ul>
<p><strong><em>*转化指标</strong></em>*</p>
<p>如果您选择 <strong>转化率</strong> 或 <strong>总转化次数</strong> 作为指标，则会出现一个包含可用转化指标的附加下拉列表。 <strong><em>*留言通道</strong></em>*</p>
<p>设置您要监控的消息渠道（即电子邮件或短信）。根据正在分析的指标，您将看到可用的可监控消息通道。对于以下指标，只能监控电子邮件：</p>
<ul>
<li>****打开率****</li>
<li>**点击打开率**</li>
<li>**跳出率**</li>
<li>**垃圾邮件投诉率**</li>
</ul>
<p>对于以下指标，可以监控电子邮件或短信：</p>
<ul>
<li>****点击率****</li>
<li>**转化率**</li>
<li>**交货率**</li>
<li>**退订率**</li>
</ul>
<p>对于以下指标，您可以选择电子邮件、短信或同时监控这两个渠道：</p>
<ul>
<li>****收件人总数****</li>
<li>**总转化次数**</li>
<li>**交付总量**</li>
</ul>
<p>您还将看到指标预览，可以将其展开以查看每日、每周、每月的选定指标绩效。 ![添加分段成员的指标预览](https://klaviyo.zendesk.com/hc/article_attachments/28723524584987)</p>
<h2>警报规则</h2>
<p>在 <strong>警报规则</strong> 部分中，定义将触发警报的规则。输入与触发警报的时间和内容相关的信息。 ![警报规则示例](https://klaviyo.zendesk.com/hc/article_attachments/28723546476187)</p>
<p><strong><em>*关系</strong></em>*</p>
<p>您的实际表现与您设定的预期值之间的运算符。您可以选择阈值运算符（例如，小于、大于、等于等）或比较运算符（例如，相对增加、绝对增加等）。 <strong><em>*相对与绝对比较运算符</strong></em>*</p>
<p>警报规则生成器中的比较运算符可以设置为基于相对或绝对基础来比较值的变化。当使用相对基础比较时，它将测量相对于原始值的百分比变化。选择绝对比较运算符将根据原始值的数值增加或减少来衡量变化。例如，假设您有以下相对条件：</p>
<p>当最近 3 天内的打开率相对于前 3 天增加超过 10% 时发出警报。 ![相对比较运算符示例](https://klaviyo.zendesk.com/hc/article_attachments/28723524569883)</p>
<p>如果前 3 天的打开率为 20%，则要满足此条件，打开率需要相对增加 10%（即 1.1 倍）至 22%。即使正在评估的指标以比率（例如打开率或点击率）表示，相对增加和减少也被评估为与前一时期相比的百分比变化。同时，如果将条件设置为绝对，则它看起来像下面的示例设置。与前 3 天相比，过去 3 天内的打开率绝对增加超过 10% 时发出警报</p>
<img src="https://klaviyo.zendesk.com/hc/article_attachments/28723546489883" alt="绝对比较运算符示例" />
<p>如果前 3 天期间的打开率为 20%，则要满足此条件，打开率需要增加绝对 10%（即增加 10%）到 30%。 <strong><em>*价值</strong></em>*</p>
<p>将与您的表现进行比较的价值。如果您选择的指标是比率，则该值以百分比表示，并且必须介于 0 到 100 之间。<strong><em>*时间段</strong></em>*</p>
<p>要监控的时间段（例如前一天、过去 7 天）。 <strong><em>*和/或连接器</strong></em>*</p>
<p>您可以使用 And/Or 运算符组合多个条件。要在满足两个条件时发送警报，请使用 <strong>And</strong>。要在满足某一条件时发送警报，请使用 <strong>或</strong>。一条警报规则中最多可以有 2 个条件。 ## 通知</p>
<p>在 <strong>通知</strong> 部分中，您可以配置发送自定义监视器通知的渠道。如果您希望在触发时将此自定义监视器的通知发送到您在 Klaviyo 中的主页，请将开关切换为<strong>打开</strong>。默认情况下，<strong>所有者</strong>、<strong>管理员</strong>、<strong>经理</strong>和<strong>分析师</strong>用户角色将在 Klaviyo 主页上收到通知。您还可以通过选择 <strong>添加频道</strong> 按钮来配置电子邮件警报。电子邮件提醒每天早上发送，一封电子邮件将包含有关您所有自定义提醒的信息。对于电子邮件警报，您还可以选择将接收通知的用户角色。仅针对 <strong>流程触发器</strong> 和 <strong>营销活动交付率</strong> 监控类型发送电子邮件通知。 ![自定义警报的通知设置](https://klaviyo.zendesk.com/hc/article_attachments/28723546470683)</p>
<p>成功创建自定义监视器后，将首先在下一个监视周期（即当地时间凌晨 2 点左右）对其进行检查。定制监视器每 24 小时评估一次。 ## 监控警报</p>
<p>在主 <strong>监视器</strong> 页面上，您可以看到现有自定义监视器的列表以及警报日志。 ### 监视器列表</p>
<p>在<strong>监视器列表</strong>选项卡上，您将看到现有自定义监视器的列表视图。在每个自定义监视器旁边，您将看到以下信息：</p>
<ul>
<li>****显示器名称****</li>
</ul>
<p>自定义监视器的名称。 - <strong><em>*状态</strong></em>*</p>
<p>自定义监视器的状态。这些可以是：</p>
<ul>
<li>****活跃****</li>
</ul>
<p>自定义监视器已启用，并且在上次检查期间未触发警报。 - <strong><em>*警报</strong></em>*</p>
<p>自定义监视器已启用，并且在上次检查期间触发了警报。下次检查将在 24 小时内进行。 - <strong><em>*禁用</strong></em>*</p>
<p>当前未启用监视器。 - <strong><em>*警报规则</strong></em>*</p>
<p>关联自定义监视器的警报规则集的预览。 - <strong><em>*显示器类型</strong></em>*</p>
<p>监视器类型本身（即单流、单指标、单段）。 - <strong><em>*通知</strong></em>*</p>
<p>自定义监视器的通知是打开还是关闭。 - <strong><em>*最后一次运行</strong></em>*</p>
<p>上次检查自定义监视器的时间。如果您在列表中展开自定义监视器，您还可以看到：</p>
<ul>
<li>正在监视的对象。 - 上次触发警报的时间。 ![Klaviyo 中的监视器列表页面](https://klaviyo.zendesk.com/hc/article_attachments/28723524562971)</li>
</ul>
<p>您可以选择自定义监视器旁边的三点菜单来删除、禁用或编辑它。 ### 警报日志</p>
<p>在 <strong>警报日志</strong> 选项卡上，您可以查看为自定义监视器触发的警报的时间线。如果在警报日志时间轴上展开事件，您可以看到有关该警报的更多信息，包括：</p>
<ul>
<li>经历警报的对象</li>
<li>相关指标</li>
<li>违反规则导致警报</li>
</ul>

<h2>自定义监视器的推荐用例</h2>
<p><strong><em>*监控网站访问者</strong></em>*</p>
<p>通过<strong>单一指标</strong>监视器，您可以主动监控 Klaviyo 中捕获的<strong>活动站点</strong>事件的数量，并在网站流量下降时收到警报。以下是您可以为 <strong>Active on Site</strong> 事件设置的自定义监视器的示例。设置<strong>监控类型</strong>和<strong>指标名称</strong>后，您可以使用<strong>指标预览</strong>来查看每日、每周或每月的<strong>活跃站点</strong>事件数，以用作警报规则中的值的基准。对于警报规则，创建以下 2 个条件，如下例所示：</p>
<ul>
<li>当过去 **7 天** 的网站活跃总数**小于 9300** 时发出警报</li>
</ul>
<p>或者</p>
<ul>
<li>当过去 **30 天** 与前 **30 天** 的 **平均** 相比，网站活跃总数 ** 相对减少 ** 超过 **15** 时发出警报。根据指标预览，使用与您帐户中的**网站活跃**事件量相匹配的值。 ![监控网站流量的警报规则示例](https://klaviyo.zendesk.com/hc/article_attachments/28723546505371)</li>
</ul>
<p>此监视器中的第一个条件计算过去 7 天内<strong>站点上活动</strong>事件的数量，并将其与阈值 9300 进行比较。如果该数量低于此阈值，则会触发警报。此警报中的第二个条件计算过去 30 天内<strong>活跃的网站</strong>事件的平均数量，并将其与前 30 天的平均值进行比较。如果差异超过 15%，则会触发警报。 <strong><em>*监控流量的退订率</strong></em>*</p>
<p>通过<strong>单流</strong>监视器，您可以创建一个监视器来主动监视帐户上关键流的取消订阅率。这是轻松识别流程中退订率问题的好方法，以便您可以在送达率受到影响之前解决这些问题。您可以选择帐户上的任何流量以及要监控的渠道（即电子邮件或短信退订率）。设置<strong>监控类型</strong>和<strong>指标名称</strong>后，您可以使用<strong>指标预览</strong>查看每日、每周或每月取消订阅率，以用作警报规则中值的基准。对于警报规则，创建以下 2 个条件，如下例所示：</p>
<ul>
<li>当过去 7 天内 [flow] 的退订率大于 0.5 时发出警报</li>
</ul>
<p>或</p>
<ul>
<li>当**[流]**的退订率在过去 1 天内与前 1 天相比 **绝对增加超过 0.2** 时发出警报</li>
</ul>
<p>根据指标预览，使用与流程取消订阅率相匹配的值。 ![监控流量取消订阅率的警报规则示例](https://klaviyo.zendesk.com/hc/article_attachments/28723524577179)</p>
<p>此监视器中的第一个条件检查过去 7 天内流的取消订阅率，并将其与 0.5% 的阈值进行比较。如果取消订阅率超过 0.5%，则会触发警报。此警报中的第二个条件检查最后一天与前一天相比的流取消订阅率。如果退订率较前一天增加超过 0.2%，则会触发警报。 <strong><em>*监控流量转化</strong></em>*</p>
<p>通过<strong>单流</strong>监控器，您可以创建一个监控器来主动监控帐户中关键流的转化总数。这是一种发现流量中转化次数下降的方法，以便您可以在收入受到重大影响之前解决这些问题。您可以选择帐户上的任何流程以及要监控的渠道（即电子邮件或短信转化）。设置<strong>监控类型</strong>和<strong>指标名称</strong>后，您可以使用<strong>指标预览</strong>来查看每日、每周或每月的转化次数，以用作警报规则中的值的基准。在下面的部分中，<strong>已下订单</strong>用作转换指标。对于警报规则，创建以下 2 个条件，如下例所示：</p>
<ul>
<li>当过去 7 天内 [flow] 的总转化次数低于 1000 时发出提醒</li>
</ul>
<p>或</p>
<ul>
<li>当[flow]的平均总转化次数在过去 3 天内与前 3 天的平均值相比绝对减少 20 时发出警报。根据指标预览，使用与您帐户中的转化量相匹配的值。此监视器中的第一个条件检查过去 7 天内流量的转化次数，并将其与阈值 1000 进行比较。如果转化次数低于此阈值，则会触发警报。 ![监控流量转化的警报规则示例](https://klaviyo.zendesk.com/hc/article_attachments/28723524583707)</li>
</ul>
<p>此警报中的第二个条件检查过去 3 天内与前 3 天内相比流量的平均转化次数。如果这些时间段之间的转化次数下降了 20，则会触发警报。 <strong><em>*监控细分市场增长</strong></em>*</p>
<p>使用<strong>单段</strong>监视器，您可以创建一个监视器来主动监视关键段中添加的配置文件的总数。如果您的帐户上有任何重要的细分，则可以通过这种方式检查这些细分是否按预期增长率增长，以便您可以快速调查增长率的下降情况。以下是您可以为分段设置的自定义监视器的示例。设置<strong>监控类型</strong>和<strong>指标名称</strong>后，您可以使用<strong>指标预览</strong>来查看每日、每周或每月添加的分段成员的数量，以用作警报规则中的值的基准。对于警报规则，创建类似于以下 2 个条件的内容：</p>
<ul>
<li>当过去 30 天内[细分]添加的平均会员数低于 1400 时发出警报</li>
</ul>
<p>或</p>
<ul>
<li>当[细分]的添加成员总数在过去 7 天内相对于前 7 天的总数相对减少 15% 时发出警报。使用与您在指标预览中看到的添加成员数量相匹配的值。 ![监控细分增长的警报规则示例](https://klaviyo.zendesk.com/hc/article_attachments/28723546501787)</li>
</ul>
<p>第一个条件检查过去 30 天内添加的平均成员数，如果下降到阈值 1400，则会触发警报。第二个条件检查过去 7 天内添加的成员数量与前 7 天相比，如果这些期间之间减少了 15%，则会触发警报。 <strong><em>*监控入站数据同步</strong></em>*</p>
<p>通过<strong>单一指标</strong>监视器，您可以使用关键入站指标的计数来主动监控自定义或第 3 方集成的运行状况。以下是您可以为从第 3 方集成同步的名为 <strong>填写表单</strong> 的事件设置的监视器示例。设置<strong>监控类型</strong>和<strong>指标名称</strong>后，您可以使用<strong>指标预览</strong>来查看每日、每周或每月的事件数量，以用作警报规则中的值的基准。对于本示例，警报规则具有以下条件，如下所示：</p>
<ul>
<li>当过去 **3 天** 与前 **7 天** 的 **平均** 相比， **填写的表格** 总数 ** 相对减少 ** 超过 **50** 时，发出警报。 ![监控集成运行状况的警报规则示例](https://klaviyo.zendesk.com/hc/article_attachments/28723524588699)</li>
</ul>
<p>此条件计算过去 3 天内 <strong>填写表单</strong> 事件的平均数量，并将其与前 7 天的平均值进行比较。如果与前 7 天的平均值相比下降超过 50%，则会发送通知，并可能表明您的集成运行状况存在问题。</p>
