<h1>了解升温与升温</h1>

<h2>你将会学到</h2>
<p>详细了解预热和加速之间的差异，以及何时在开始电子邮件营销或编辑发送基础设施时执行。这些术语通常可以互换使用，但了解它们具体应用时的差异非常重要。</p>
<h2>了解变暖与升温</h2>
<p><strong><em>*变暖</strong></em>*</p>
<p>所有从新的专用基础设施（即新的专用 IP 或新注册的品牌发送域）发送的 Klaviyo 客户必须完成关联 IP 或域预热。当您引入新的或“冷”IP（即过去 30 天内未使用过发送电子邮件的 IP 地址）或新的或“冷”根域（即过去 30 天内注册过或从未用于发送电子邮件的域）时，就会发生变暖。升温期是您建立合法或“良好”电子邮件发件人声誉的时期。</p>
<p><strong><em>*斜坡</strong></em>*</p>
<p>升级是一个有助于整体升温过程，成为信誉良好的发件人的过程，无论您使用的是专用还是共享 IP。当增加专用 IP 时，这将是您整体预热过程的一部分，因为它与您的新基础设施相关。扩大共享 IP 涉及新客户，需要提高他们与 Klaviyo IP 的新关系的声誉。</p>
<p>渐增涉及从较小数量的电子邮件发送开始，然后随着时间的推移逐渐增加该数量。根据您发送的电子邮件量，在您完全发送或发送所有电子邮件后，整个预热过程可能会继续。例如，增加到 10 万封电子邮件量可能只需 10 天，但您的电子邮件服务提供商 (ESP) 或邮箱提供商 (MBP) 通常需要长达 30 天的时间才能对您的声誉做出初步决定。在此期间，您可能还会注意到，在验证您的声誉时，您的电子邮件性能（即打开次数和点击次数）可能会波动长达约 120 天。</p>

<li>****邮箱提供商（MBP）介绍****</li>
<li>****斜坡****</li>
</ul>
<p>提高电子邮件发送量用于引入 MBP 基础设施的变化。这是变暖的一个关键组成部分。</p>
<ul>
<li>****变暖****</li>
</ul>
<p>预热用于为新的或“冷”的 IP 或新的或“冷”的发送域在 MBP 中建立积极的声誉。</p>
<ul>
<li>****电子邮件服务提供商（ESP）介绍****（即平台介绍流程）</li>
<li>****斜坡****</li>
</ul>
<p>提高电子邮件或发送量是负责任地加入 Klaviyo 或任何新 ESP 的一项重要功能。</p>
<ul>
<li>****变暖****</li>
</ul>
<p>Warming 用于在 Klaviyo 共享网络中建立发送者的声誉。一旦发送者建立了声誉，他们就会升级到适当的共享基础设施。</p>
<ul>
<li>****发送时不带历史参与数据****</li>
<li>****斜坡****</li>

<ul>
<li>****变暖****</li>
</ul>

<li>****假期发送****</li>
<li>****斜坡****</li>
</ul>

<li>****变暖****</li>

<li>****斜坡****</li>
</ul>
<p>当您的发件人声誉出现问题时，常见的做法是只向参与度高的收件人发送邮件。一旦您的电子邮件性能得到改善，您就可以恢复到正常发送的参与量和频率。</p>

<li>****变暖****</li>
