<h1>如何在 Klaviyo Helpdesk 中配置高级路由规则</h1>

<p><strong><em>*高级路由规则</strong></em>* 允许您根据 Klaviyo 中已有的所有客户数据自动将收到的工单分配给正确的团队或查看。</p>
<p>在本文中，您将了解如何超越基本路由（基于标签）并利用完整的 Klaviyo 数据平台（包括预测分析、购买历史记录和实时事件）来确定支持队列的优先级。</p>
<h2>开始之前</h2>
<ul>
<li>****用户权限：**** 您必须是****所有者****、****管理员****或****经理****才能创建或编辑路由规则。</li>
<li>****团队设置：**** 在设置路由规则之前，请确保您的团队（例如“VIP 支持”、“退货”）已在帮助台设置中创建。</li>
<li>****数据可用性：**** 路由规则可以使用客户配置文件中当前可用的任何数据，包括来自第三方集成的自定义属性（如充值）和预测分析（如流失风险）。</li>
</ul>
<p>---</p>
<h2>第 1 步：访问路由规则生成器</h2>
<p>路由配置位于您的帮助台设置中。</p>
<p>1. 登录 Klaviyo 并选择您的帐户。</p>
<p>2. 导航至<strong><em>*帮助台</strong></em>*</p>
<p>3. 从侧边栏中选择<strong><em>*路由</strong></em>*</p>
<p>4. 单击<strong><em>*添加规则</strong></em>* 按钮打开构建器。</p>
<p>---</p>
<h2>步骤 2：定义逻辑条件</h2>
<p>规则生成器使用与 Klaviyo 段生成器相同的逻辑接口。您可以使用三个主要数据类别的任意组合来定义规则。</p>
<h3>客户行为（事件）</h3>
<p>这最适合捕获诸如“我的订单在哪里？”之类的紧急问题。或取消。</p>
<ul>
<li>****示例：**** 将过去 2 小时内下订单的客户转至“紧急修改”队列。</li>
<li>****如何设置：****</li>
<li>选择****某人做了什么（或没有做什么）****。</li>
<li>选择一个事件（例如“已下订单”）。</li>
<li>添加时间限制（例如，“过去 2 小时内”）。</li>
</ul>
<h3>按配置文件属性路由</h3>
<p>将此用于静态属性，例如位置、语言或自定义数据点。</p>
<ul>
<li>****示例：**** 将法语客户转至“法国支持团队”。</li>
<li>****如何设置：****</li>
<li>选择****某人的属性****。</li>
<li>选择一个属性（例如“$country”）。</li>
<li>设置值（例如“等于法国”）。6</li>
</ul>
<h3>按票证属性划分的路线</h3>
<p>利用工单的主题和渠道帮助客户找到合适的人或团队。</p>
<ul>
<li>****示例：**** 将 SMS 订单问题发送给 A 团队</li>
<li>****如何设置：****</li>
<li>如果 Ticket\_channel = SMS 并且 Ticket\_tags 包含订单，请选择。</li>
</ul>
<p>---</p>
<h2>第 3 步：选择目的地</h2>
<p>一旦门票符合您的条件，您必须决定它的去向。您有两个选择：</p>
<h3>1. 分配给团队</h3>
<p>此操作将票证的所有权转移给特定的代理组。</p>
<ul>
<li>****最适合：**** 需要特定技能的专业工作流程（例如退货、B2B、VIP）。</li>
<li>****结果：**** 票证将从常规“未分配”队列中删除，并直接放入团队的收件箱中。</li>
</ul>
<h3>2.另存为视图</h3>
<p>此操作将工单标记到可过滤列表中，但<strong>不会</strong>立即将其分配给特定团队。</p>
<ul>
<li>****最适合：**** 监控高风险问题或创建主管可以审查的“观察列表”（例如，潜在欺诈、负面情绪）。</li>
<li>****结果：**** 该票证仍可供任何客服人员领取，但会显示在特定的筛选视图中，以便于查看。</li>
</ul>

<h2>常见用例</h2>
<p>以下是两个可帮助您入门的标准配置：</p>
<h3>“流失防御”（高风险）</h3>
<p>在不满意的顾客离开之前拦截他们。</p>
<ul>
<li>****条件：****`某人的属性`>`流失风险`>`等于高`</li>
<li>****行动：**** 分配给团队：****保留专家****1</li>
</ul>
<h3>“紧急订单模组”（快速通道）</h3>
<p>优先考虑刚刚购买的客户，以防止运输错误。</p>
<ul>
<li>****条件：****`某人做了什么`>`已下订单`>`在`过去2小时`内至少有一次`</li>
<li>****操作：**** 另存为视图：****紧急修改****</li>
</ul>
