## You will learn

Learn about the roles and permissions for portfolio users. This article outlines both static portfolio user roles and how to create a custom user role.

Note that this article only goes over portfolio user permissions. Learn how to [add or remove users in a portfolio](https://help.klaviyo.com/hc/en-us/articles/25185184021019).

## Before you begin

Please note that portfolio user roles:

- Are entirely separate from [account user roles](https://help.klaviyo.com/hc/en-us/articles/115005231648).
- Have access to data from every account in the portfolio.
- Do not have to be users in any (or every) linked account.

****What does it mean that the portfolio and account user roles are separate?****

The portfolio is designed to be an overview of several accounts, which may require different settings, currencies, etc. Due to this, the portfolio can’t influence or be influenced by any of those accounts.

Your user role in an account has no effect on your role in a portfolio, and vice versa.

For instance, you can be a Portfolio Analyst in the portfolio, but an Admin in all the linked accounts.

## Portfolio static user roles

There are 4 static roles in a portfolio:

- Portfolio Owner
- Portfolio Admin
- Portfolio Manager
- Portfolio Analyst

### Portfolio Owner

There can only be 1 Owner for a portfolio.

The Portfolio Owner has full access to the portfolio. It is the only role that can:

- View all portfolio and account details.
- Add or remove accounts from the portfolio.
  Note that they must also be an Owner or Admin in the account to add it to a portfolio.
- View and manage users in the portfolio.
- Close the portfolio.

### Portfolio Admin

The Portfolio Admin of the portfolio can do almost anything in the account, including:

- View and export billing information.
- View and export reports and metrics.
- Manage portfolio settings.
- View portfolio accounts and users.

The Portfolio Admin cannot:

- Close the portfolio.
- Add or remove accounts.
- Manage users.

### Portfolio Manager

The Portfolio Manager role has access to the data from all linked accounts, but cannot make any changes to the portfolio.

A Portfolio Manager can:

- View and export billing information.
- View and export reports and metrics.

The Portfolio Manager cannot:

- Manage portfolio settings.
- View and manage accounts that are part of this portfolio.
- View and manage portfolio users.

### Portfolio Analyst

The Analyst is the most limited role in the portfolio.

A Portfolio Analyst can:

- View and export reporting details.

A Portfolio Analyst cannot:

- View any settings or users.
- Add or remove accounts.
- View or export billing details.

## Portfolio custom user roles

Custom user roles allow you to tailor user permissions to your team's specific needs, ensuring each user has access only to the areas of the product required for their job. Fine-grained access control shortens onboarding, reduces security risk, and keeps billing, data, and messaging settings in the right hands — improving deliverability and ROI.

## ****Product Areas****

You can choose between the following areas to create your custom user role.

|  |  |
| --- | --- |
| ****Product Area**** | ****Description**** |
| Settings | Ability to configure permissions for portfolio settings, inclusing MFA, SSO, consent preferences and activity logs. |
| Reporting | Ability to configure permissions for reporting across all accounts linked to the portfolios. Users can view campaign, flows and manage their metrics with this permission set. |
| User Management | Ability to view users across linked accounts, including assigned roles and access levels.  **\*Only portfolio owners can add or remove users on the portfolio.** |
| Billing | View billing information across all linked accounts. |
