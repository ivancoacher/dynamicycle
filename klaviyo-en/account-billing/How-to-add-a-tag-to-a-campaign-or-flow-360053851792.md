## You will learn

Learn how to add tags to campaigns and flows.

### Why use tags?

In Klaviyo, tags act as labels that help you organize and manage your account’s content efficiently. Tags can be attached to various elements, such as campaigns and flows, allowing you to quickly identify, categorize, sort, and filter data.

For campaigns, you can tag all related to specific product lines, making it easy to access and manage them as a group. For flows, tags can be used to identify those linked to particular marketing initiatives. Tags promote organization and collaboration, as team members can easily find and work on relevant elements.

Tags can be added when creating campaigns and flows or applied to existing ones for seamless workflow management in Klaviyo.

## Add a tag to a campaign

For new campaigns:

1. In Klaviyo's left-hand navigation, select Campaigns.
2. In the top right corner, click ****Create campaign.****
3. Select the **Tag** dropdown on the first page of the campaign creation modal.
4. Choose either an existing tag or create a new one by typing it out in the search bar.
   ![The creation modal for a new campaign showing the Tags dropdown where you can add an existing tag or create a new one for the new campaign.](https://klaviyo.zendesk.com/hc/article_attachments/31422153031067)

For existing campaigns:

1. In Klaviyo's left navigation, select ****Campaigns****.
2. Click the checkboxes beside each campaign that you want to add a the tag to.
3. Select ****Add Tags****. You can add tags to all campaigns regardless of whether or not they have already been sent.
   ![Two existing campaigns selected on the campaigns page in Klaviyo and the banner showing the button to Add tags.](https://klaviyo.zendesk.com/hc/article_attachments/31422153031579)

## Add a tag to a flow

Tags can't be applied to archived flows.

When creating a new flow from the [Flow Library](https://help.klaviyo.com/hc/en-us/articles/115002774932):

1. Select the flow template you want to use.
2. Under **Tags**, select the existing tag you want to apply. You can also create a new tag by typing it into the **Filter** textbox.
   ![The creation modal that appears when you choose a template from the flow library where you can name and add tags to the new flow.](https://klaviyo.zendesk.com/hc/article_attachments/31422153032219)
3. Click ****Create Flow****.

For existing flows:

1. Navigate to ****Flows****
2. To the right of the flow you want to tag, click the 3 dots then ****Edit details****.
3. Click the ****Tags**** dropdown.
4. Select an existing tag or type a new one into the textbox to create it.
   ![The Edit Details modal for an example flow where you can add tags or change the flows name.](https://klaviyo.zendesk.com/hc/article_attachments/31422153032731)
