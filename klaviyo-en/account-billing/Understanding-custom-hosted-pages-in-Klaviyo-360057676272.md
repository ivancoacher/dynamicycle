## You will learn

Learn about custom hosted pages in Klaviyo, including what they are and what they can do.

This article provides information about hosted pages. If you need guidance on how to enable them or set one up, see the following resources:

## Before you begin

Only paid accounts that have passed [account verification](https://klaviyo.zendesk.com/hc/en-us/articles/115000628331) have the ability to enable custom hosted pages.

Please note that you should only attempt to custom code your own hosted pages if you are code-savvy or have a [developer](https://connect.klaviyo.com/) on your team. Klaviyo does not currently offer services to help build out custom code, nor do we provide support for custom code troubleshooting. Head to our [guide on getting started with consent pages](https://help.klaviyo.com/hc/en-us/articles/115005251848-Getting-started-with-opt-in-related-pages-for-a-list) for more information about customizing Klaviyo's built-in pages.

## About hosted pages

Hosted pages give you the flexibility to create custom consent pages that feel more “on-brand,” aligning your Klaviyo-hosted pages to your website design. With more flexibility also comes more sophisticated forms. When coding your forms, you can collect extensive information about your subscribers for segmenting and targeting purposes.

Custom hosted pages must be built using HTML and CSS. Only attempt to custom code your consent pages if you are code-savvy or have a developer on your team. Klaviyo does not currently offer services to help build out custom code, nor do we provide support for custom code troubleshooting.

Note that emails not sent to a single list (e.g., metric-triggered flow emails or campaigns sent to a segment) will use your custom hosted consent pages, whereas emails sent to a list will use that specific list’s consent pages. Make sure to configure your [list’s consent pages](https://klaviyo.zendesk.com/hc/en-us/articles/115005251848) to replace any defaults with your new custom hosted pages if you want these changes reflected across your account.
