Learn how to use Email AI to create AI-generated email content. This tool can create layouts including images, text blocks, and buttons.
There are several Email AI features available, including template generation, text revision, and content creation. This article covers creating content (e.g., a layout including text and images). Learn more about [text revision](https://help.klaviyo.com/hc/en-us/articles/34411474977947) or [template generation](https://klaviyo.zendesk.com/hc/en-us/articles/28242227715227) in their respective articles.

## Before you begin

Email AI accepts descriptive, plain-text inputs and generates complete section layouts, ready for you to edit and finalize. Designs generated by this tool may include the following content:

- Text blocks, including AI-generated copy
- Image blocks
- 2- or 3-column layouts
- Button blocks
- Dividers
- Spacers
- Product blocks
  - Note that product blocks are not automatically configured. Before sending the template, [select a product feed](https://help.klaviyo.com/hc/en-us/articles/115005082787).

Other block types not listed here (e.g., table blocks) are not supported.

The generated sections use the fonts, colors, and styles from your template’s **Styles** tab and are fully editable once you select a section layout.

## Use AI to create email content

This assistant creates email sections using generative AI technology, however you are still responsible for the final content.

1. If you'd like to generate new options based on your prompt, proceed to the 4th page and click ****Generate more drafts****. To modify your description and generate additional options, click ****Update description****.

1. In an email built using Klaviyo’s drag-and-drop editor, add a section (or select an existing section).
   ![AI section.jpg](https://klaviyo.zendesk.com/hc/article_attachments/28720660305307)

   If you select an existing section, its content will be replaced once you choose an AI-generated section. Click the undo icon within the editor to recover the original content.
2. Click the AI icon (a star) next to the selected section.
   ![emailAI.jpg](https://klaviyo.zendesk.com/hc/article_attachments/37118783273115)
3. Input a text description of the section you’d like to generate, (e.g., “Create a sale reminder with urgency to order before midnight, and include an image at the top and a button right below”).
4. Click ****Generate drafts****.
5. After a few moments, 3 options will appear. Use the arrows to toggle between these options.
   ![Generated option.jpg](https://klaviyo.zendesk.com/hc/article_attachments/28720672023067)
6. Click ****Insert draft**** to insert your preferred section content.
7. Once you’ve selected a section and inserted it into the template, edit as needed (e.g., add images, add links to buttons, finalize copy, etc.)

## Example prompts

Not sure where to start? Try these sample inputs to see what this tool can do.

- Create a section with images and text laid out in a zigzag pattern. At the bottom, add a button encouraging readers to take a look.
- Create a friendly message with links to follow us on social media.
- Add 3 columns with a text block and a button in each one. Add in copy teasing an exciting new release.

## Email AI limitations

Each Klaviyo user can generate up to 99 email sections per day using Email AI. Each entry generates 3 results, which means you can generate content 33 times in a 24-hour period. Once you reach this limit, wait 24 hours before trying again.

Certain elements (like product blocks, images, links, and buttons) are not fully configured by the generation tool. You must add in these elements manually after selecting a generated section:

- Products or feeds in a product block
- Images
- Alt text for images
- URLs for buttons and links
