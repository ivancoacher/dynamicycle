## ****You will learn****

How to create a static list of profiles who converted from one or most previously sent campaigns.  These lists created using converted profiles can be use to retarget profiles who converted to send targeted upsell and cross-sell campaigns or exclude profiles who converted from follow up sends.

This is a ****one‑time population****: the list is a snapshot of converters at the time you create it and does ****not**** update automatically with new conversions. Currently, attribution data like attributed message (ex. the message an order was attributed to) is not available in segmentation, and the differences between lists and segments can be found [here](https://help.klaviyo.com/hc/en-us/articles/115005061447)

## ****Adding converted profiles to a list****

1. Navigate to ****Audience > Lists & segments****.
2. Select the list you want to add your contacts to (e.g., Newsletter).
   - If you want to create a new list, instead select Create New > Create list and name the new list.

![](https://klaviyo.zendesk.com/hc/article_attachments/48460584325787)

3. If the list is empty, you can add converted profiles to the list using the quick action as shown below

****![](https://klaviyo.zendesk.com/hc/article_attachments/48460584327707)****

- If the list has profiles you can add converted profiles to the list via the manage lists action menu

![](https://klaviyo.zendesk.com/hc/article_attachments/48460612821659)

4. To add converted profiles to a list, select from the list of campaigns shown in the list view.  After selecting one or more campaigns with one or more attributed conversions, the estimated list size will update to show the estimated number of profiles that will be added to the list

![](https://klaviyo.zendesk.com/hc/article_attachments/48460612822299)

5. When you are finished selecting campaigns, you can click Add to List in the top right

The list view can be filtered using send date and channel, and the conversion metric can be updated to use any conversion metric in your Klaviyo accounts

## ****Example use cases****

Here are a few common patterns for this feature:

1. Exclude converters from follow‑up sends
   - Create a list of profiles who converted from your BFCM campaign.
   - Exclude that list from future reminder or sale campaigns so you don’t keep pushing the same offer to people who already purchased.
2. Create a cross‑sell audience
   - Build a list of profiles who converted from a specific product-launch campaign.
   - Use that list as the audience for a follow‑up campaign highlighting accessories, refills, or complementary products.
3. Re‑engage high‑intent converters
   - Create a list of profiles who converted from “winback” or “back‑in‑stock” campaigns.
   - Use this list in a flow or campaign journey designed to move them toward a higher-value purchase or subscription.
