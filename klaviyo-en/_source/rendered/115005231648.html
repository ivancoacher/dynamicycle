User management and privileges reference for Static User Roles

Estimated 4 minute read
|
Updated Mar 25, 2026, 12:00 AM EST
Table of contents
  • You will learn
  • Available user roles
  • Charts showing user permissions
  • Additional resources

Note only Owners and Admins can add new users to an account.

You will learn

Learn about the different Klaviyo user roles, their account permissions and access, as well as their potential restrictions inside the platform. Depending on your role, the view of Klaviyo may look different. For instance, Owners see different account setting options than Admins do.

This article on discusses the permissions for account users. If this isn't what you're looking for, you may want to see our articles on how to add or remove an account user or on portfolio user permissions.

Available user roles

There are currently the following user roles:

  • Owner
  • Admin
  • Manager
  • Analyst
  • Campaign Coordinator
  • Content Creator
  • Support
  • Social Media Manager

Open the dropdowns to learn more about each role.

Owners

An account can only have 1 Owner who can:

  • Access the full account
  • Edit and close an account
  • Create private API keys
  • Edit the domain authentication page

By default, the first person to create a Klaviyo account will be the account's Owner. Over time, they will receive important account notifications from Klaviyo, and can edit who in their company receives billing-related notifications.

If you want to change Owners, learn how to transfer account ownership.

Admin

Admins have full account access. An admin can:

  • Edit account details (such as updating payment plans)
  • Add or delete users
  • Cancel a paid subscription from billing
  • Create private API keys
  • Edit the domain authentication page
  • Edit who in their company receives billing-related notifications
  • Access the Reviews tab

Admins cannot: fully close an account (e.g., disable an account and remove all users).

Manager

Managers have access to all core Klaviyo features, but with some limitations in flows, lists, segments, and analytics.

The tabs they have access to are:

  • Campaigns tab
    • Can create campaigns, export analytics, etc.
    • Cannot export any recipient activity.
  • Flows tab
    • Cannot export any recipient activity
  • Reviews tab
  • Sign-up forms tab
  • Audience tab
    • Lists & segments
      • Cannot export any active or suppressed addresses from Klaviyo
    • Profiles
  • Analytics tab
    • Can access:
      • Dashboard
      • Metrics
      • Benchmarks
      • Custom reports
    • Cannot export analytics (except custom reports)
  • Settings tabs, in which they:
    • Can
      • Edit certain account details (such as change to any paid plan or hosted pages)
      • Set up SMS
    • Cannot
      • Access the downloads tab
      • Edit or delete account users
      • Downgrade to a free plan
      • Cancel the account
Analyst

Analysts have access to analytics, segments, and reporting.

The tabs they have access to are:

  • Campaigns tab
    • Can only view the list of draft campaigns and details for sent campaigns
  • Flows tab
    • Can only view analytics, export analytics, and preview flow messages
  • Sign-up forms tab
    • Can only see form analytics
    • Do not have access to the Form Builder or A/B test setup
  • Audience tab
    • Lists & segments
    • Profiles
      • Cannot create, update, or delete profiles or access the Messages tab (i.e., they cannot view which messages were sent, skipped, or scheduled for a profile)
  • Integrations
    • Can view which integrations are installed
    • Cannot edit, add, or remove an integration
  • Analytics tab
    • Dashboards
    • Metrics
    • Benchmarks
    • Custom reports
Campaign Coordinator

Campaign Coordinators can create and send campaigns and create and edit templates. The tabs they have access to are:

  • Campaigns tab
  • Flows tab
    • Can only edit flow details (name and tag), edit message content, and preview flow messages
  • Audience tab
    • Lists & segments
  • Content tab
    • Templates
    • Data feeds
    • Coupons
  • Settings tab
    • Consent pages
    • Domain page
Content Creator

Content creators can create and edit templates. The tabs they have access to are:

  • Campaigns tab, but only to view this tab; they can't schedule or send campaigns, edit templates, or see analytics from sent campaigns
  • Flows, but they can only edit flow details (name and tag), edit message content, and preview flow messages
  • Sign-up forms, but they cannot create or delete forms, see analytics, publish any changes, publish an A/B test, or publish changes to variants in a running test.
  • Lists and segments, but they can only view segment definitions
  • Content tabs and consent pages
Support

Support representatives have access to the Inbox, which will be their default landing page upon logging into Klaviyo. The tabs they have access to are:

  • Inbox tab
    • Can view profile information and use the inbox chat console.
    • Cannot adjust settings.
  • Profile tab
    • Can see the profile list view, profile details, activity feed, contact information, and channels.
Social Media Manager

Social Media Managers can create, edit, and manage social media content and data within your Klaviyo account. They have access to:

  • Social tab
  • Audiences tab
    • Lists & Segments
  • Content tab
    • Media & Brand
  • Analytics tab
    • Dashboards
    • Metrics
    • Custom reports
