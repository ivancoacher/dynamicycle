You will learn

Learn how to view the history for any Klaviyo-generated coupon so you can track which codes have been used, expired, or are still active. 

Find a code on an individual’s profile

If you want to know which code (and thus which coupon version) was sent to a subscriber:

  1. Head to their profile in Klaviyo.
  2. On the Details tab, scroll down until you see the Coupons section.
  3. There, view all of the subscriber's code(s) as well as the status and expiration date.

Clicking the code takes you to the latest version of the coupon definition, not the version the code is associated with.

View coupon history from the coupons tab

If you want an overview of a coupon’s history:

Note that your site must be built on a platform that natively integrates with Klaviyo to view coupon history. You can not view history for custom uploaded coupons.  

  1. Navigate to Content > Coupons tab.
  2. Find the coupon you want, then click the 3-dot dropdown on the right-hand side.
  3. Select View History.
    • It is not possible to view coupon history for Prestashop and WooCommerce coupons. 

You will be brought to a page where you can see the different versions of a coupon that had codes assigned to it. If you edited a coupon but then changed it before generating any codes, you will not see this reflected in the coupon history.

The coupon history shows the following:

  • Full coupon definition, including discount type and activation/expiration dates.
  • Start and end dates for each version of the coupon.
  • Number of codes assigned to each version.

This information is not available for coupon versions created before August 26, 2020. This is when Klaviyo began logging coupon history and no information was recorded before that point.

Next steps

Export the coupon history to see how many codes for a coupon are active or expired by checking the box next to the coupon definition, then selecting Export.
