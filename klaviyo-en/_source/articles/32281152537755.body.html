You will learn

Learn how to use the social links block to feature your social media accounts in emails. 

Configure your social links

Before you add a social links block to an email template, configure your social links in your account’s images and brand library. 

  1. Navigate to Content > Images & brand.
  2. Select Brand. 
  3. Select the Social icons tab.
  4. Within each dropdown, add in your social media profile URL for the selected platform (e.g., your brand’s Facebook, Instagram, X, and Pinterest profiles). 
  5. If you don’t have a profile for a platform that’s shown, click the trash icon to delete it. 
  6. Click the Add link button to add additional profiles. 
  7. Click Update brand in the bottom right corner. 

Updating your social icons here will not change any existing social icon blocks (i.e., those that have already been added to a template, campaign, or flow email). Any new social links blocks will use the updated links. 

Add a social links block to an email

To add a social links block to an email template: 

  1. Navigate to the editor for any email. 
  2. Drag and drop a Social links block into the canvas wherever you’d like to place it (e.g., in the footer).
  3. Note the icons, which reflect the social profiles you added to your brand library. 
  4. Use the Add icons button to add additional social profiles, if desired. 
  5. To choose a different icon style or size, adjust the selections under Icon styles.
  6. Optionally, save the block as universal content to use it in other emails. 

Use custom icons for social links

Klaviyo offers several versions and sizes of icons you can use for social links. However, if you’d like to use your own designs, you can use the Custom option to upload your own social media icons. 

If you use a custom icon for one social profile, we recommend using custom icons for all of them. This allows you full control over the size and shape of the icons. If you mix your own icons with Klaviyo’s, you may notice visual alignment issues, since the icons might not be exactly the same size.
