Only Owners, Admins, and Managers can access this feature.  

You will learn

Learn how to update, turn off, or delete your automations in Klaviyo. In all cases, you must have an active automation. 

When you edit, turn off, or delete an automation, it drops anyone currently going through that automation.  

Before you begin

Please note that: 

  • You must turn off an automation to edit it.
  • Deleting is permanent; you can’t recover deleted automations. 
  • All the numbers shown for an automation are cumulative (i.e., they don’t reset when you edit or turn off an automation).
    • Currently, there is no way to see the performance of a specific version of an automation.
Difference between turning off and deleting an automation

When you turn off an automation, it simply stops people from triggering it. All of the data, messages, and recommendations stay intact. 

Deleting an automation permanently removes it from your Klaviyo account. If you wanted to recreate it, you’d have to start from scratch. 

Edit or turn off an automation

To either change or disable an automation: 

  1. Navigate to the Automations tab and select the automation. 
  2. Click the Turn off button in the upper right corner. 
    1. Please note that when you do this, everyone in the automation immediately exits (i.e., they do not receive a recommendation or the fallback response). 
  3. If you want the automation off, stop here; otherwise, make any changes you want to the automation (update messages, recommendations, etc.)
  4. Click Turn on to save your changes and allow the automation to start triggering again. 

Delete an automation

Please note that you cannot recover an automation once it’s deleted. When you delete, it also removes all data, messages, etc. for that automation. Additionally, if the automation is turned on, deleting the automation ends any conversations for anyone in it. 

To delete an automation: 

  1. Navigate to Conversations > Automations tab.
  2. Find the automation you want to delete. 
  3. Click the 3 vertical dots.
  4. Select Delete. 
  5. Confirm you want to delete the automation to proceed.
