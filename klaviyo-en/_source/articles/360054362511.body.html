Learn how to add a tag to a list or segment in Klaviyo.

For lists and segments, you can either add tags when creating a list or segment, or you can add tags retroactively when they are already built in your account. This article will cover both methods.

Why use tags?

In Klaviyo, tags serve as labels that help you efficiently organize and manage items in Klaviyo (i.e., contact lists and segments). By attaching tags to lists and segments, you can quickly categorize and identify specific groups within your audience. For example, you can tag segments to distinguish between existing customers and prospects, or group lists that'll be used for a specific promotions.

This streamlined organization makes it easier to filter, manage, and collaborate on different audience segments, enhancing your ability to target communications.

Add a tag when creating a list or segment

To add a tag when creating a list or a segment: 

  1. Navigate to Audience > Lists & Segments tab.
  2. Click Create List/Segment.
  3. Choose to either create a list or a segment.
  4. In the Tags dropdown, select the tag you want to add, or create a new one by typing it into the textbox.
  5. Click Create.

Add a tag retroactively

If you want to add tags to lists and segments that are already in your Klaviyo account:

  1. Navigate to Audience > Lists & Segments.
  2. Click the checkboxes next to any lists and segments that you want to apply tags to.
  3. Click the Add/Remove Tags dropdown at the top of the page.
  4. Click Add Tags.
  5. Click the dropdown under Tags in the modal that appears.
  6. Select existing tags or input a new tag to create it.
  7. Click Add Tags.
