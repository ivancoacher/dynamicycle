You will learn

Learn how to create Square Online static coupon codes. Then, add coupon codes to your Klaviyo emails to incentivize new subscribers and past customers to make a purchase.

Before you begin

A static coupon code means that there's a single code for all customers to use (e.g., Welcome20). Everyone will receive the same code to use on your website. Static codes are easy to remember and use; however, they can be shared out, which can dampen exclusivity.

Create a static coupon code

To create a static code in your Square Online account:

  1. Navigate to your Square Online admin.
  2. Click Items > Coupons.
  3. Click Add Coupon.
  4. Enter the following details:
    • Coupon code
    • Total number of coupons available
    • Limit coupon per customer
    • Start date
    • Expiration date
    • Coupon type
    • What is discounted?
    • Percentage off, etc. (depending on the discount type)
  5. Click Save.

Use the coupon code in an email

To share the coupon you just created in an email:

  1. For the coupon you just created, click Share > Copy link.
  2. Paste the link wherever you would like the coupon to appear in your Klaviyo email template. 
  3. Recommended: Try displaying your coupon through a button so it’s easy for customers to find. To do this, paste the link you copied in the URL box, and add the coupon code in the button text box.

Coupon strategy

In your email, make sure to use a large font and a color so the coupon stands out. Also, include a text block above or below the coupon to help inform your customers about what the code is, and how to use it.

There are a few things to keep in mind when using static coupons:

  • If you're worried about your coupon spreading to too many customers, you can remedy this by controlling the expiry date, and changing it every few weeks. Just be sure to make this information visible to your customers so they understand how long their coupons are valid.
  • Klaviyo doesn't manage any of the specifics about how your coupons function, including the code, expiration date, discount amount, etc. All of this information is managed inside of your Square Online store.
  • If you're offering a coupon for a specific product, include a link to the product page so your customers can easily click through your email to make a purchase.

Outcome

You’ve now learned how to create a static coupon code in Square Online and use it in Klaviyo messaging.
