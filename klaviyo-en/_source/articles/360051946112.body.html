Learn how to transfer ownership of a Klaviyo account to a new Owner. 

This article is specific to standard Klaviyo accounts. For details on transferring ownership for a portfolio, see how to transfer ownership of a portfolio.

Before you begin

Please note the following: 

  • Only the current account Owner can assign a new Owner.
  • An account can only have 1 Owner.
  • Once a new Owner is assigned, the former Owner's role automatically changes to Admin, and only the new Owner has the ability to revert this change.

What if I bought a store from someone else?

If you've acquired a store from someone else (the previous Owner), it's crucial to collaborate with them to gain access to the Klaviyo account. If you cannot reach the prior Owner, you can reset the account's password using the email associated with the Owner's account.

Can Klaviyo transfer ownership?

To ensure the security of our customers' accounts, Klaviyo cannot initiate ownership transfers without the current Owner's approval and permission. If you're locked out of your account, the current Owner must assist you in regaining access.

If owner has left business?

If you cannot get in touch with the previous owner and they have left the business, please reachout to support to begin the verification process and discuss next steps. 

Update your account’s Owner

If the new Owner is not yet listed as a user in Klaviyo, the current Owner must first add a new user. If you're transferring ownership to a different user that already has access to the account, skip ahead to Assign a user as the Owner.

Add the new Owner as a user in your account

First, add the new person as a user so they can access the Klaviyo account:

  1. Select your organization name in the bottom left corner of Klaviyo.
  2. Select Settings > Users.
  3. Select Add New User.
  4. Input the new user’s contact information and add them an Admin role.
  5. Click Add User to save their information.

Assign a user as the Owner

Once the new user is added to an account, you can assign them as the Owner:

  1. Navigate to Settings > Users. 
  2. Click the name of the user you want to make the Owner. 
  3. Open the User Role dropdown.
  4. Select Owner. 

    Only the current Owner can transfer ownership. If you are not the Owner, you will not have the ability to choose Owner from the dropdown.

  5. Click Update to save the change.

Once the changes save, the new roles will reflect in the Users tab. Next, the new Owner should update the account details to align with their personal information. 

Next steps for the new owner

After the ownership transfer, the new Owner is responsible for updating the account to accurately reflect their contact information. The new Owner should:

  • Update the personal information (e.g., the Owner's name)
    • Navigate to Owner’s name to Settings > Account > Personal.
  • Adjust the Organization's details
    • If needed, head to Settings > Account > Organization to update the organization's address.
  • Manage users with access to the account
    • Select Settings > Users to remove any users who should no longer have account access.
  • Review branding
    • Use the Setup Wizard to adjust any brand elements.

If the new Owner is rebranding the company entirely, refer to the Klaviyo rebranding guide to implement best practices in design and communication to customers.
