Learn how to use Email AI to revise copy in your text blocks. Use this tool to adjust the content’s length or change its tone.

There are several Email AI features available, including template generation, text revision, and content creation. This article covers revising text. Learn more about content creation or template generation in their respective articles.  

This feature is only available for paid Klaviyo accounts.

Before you begin

Email AI can make revisions to text blocks to change their tone, length, or style. Use this feature to cure writer’s block, improve existing drafts, or adjust copy for different audiences. You can use Klaviyo’s default prompts (e.g., Simplify, Make longer), or write your own prompt.

Use AI to revise text

This assistant revises email copy using generative AI technology; however, you are still responsible for the final content.

  1. Within any template, select a text block that contains text you’ve written. 
  2. Click Rewrite text.
  3. Write your own prompt or select from the default options.
  4. Toggle between the 3 generated options.
  5. Once you’ve selected one you’d like to use, click Insert.

Email AI limitations 

Each Klaviyo user can generate up to 99 revisions per day using Email AI. Each entry generates 3 results, which means you can generate copy 33 times in a 24-hour period. Once you reach this limit, wait 24 hours before trying again.
