You will learn

Learn how to change your notification settings for new tickets in Klaviyo Helpdesk. You can enable notifications to help you keep track of new tickets.

Types of notifications

There are 2 types of notifications you can choose:

  • Email notifications
  • Unread conversations badge

Email notifications

If you'd like to be notified via an email notification when you receive new ticket in Helpdesk, you can enable email notifications. This setting is off by default.

If you choose to enable these email notifications, you must set at least 1 recipient; however, you can add any number of email addresses.

Recommendation: turn this setting on if you use Helpdesk to manage your customer support communications; otherwise, leave this setting off.

Turn on email notifications

  1. Go to Service > Helpdesk in Klaviyo's main navigation menu.
  2. Click Settings.
  3. Select the Inbound messages tab in the top menu bar.
  4. Under Email notifications, toggle the setting On.
  5. Add the email addresses you want the notifications to send to.
  6. Optional: Click the dropdown arrow to add another email address, then select Add email.
  7. Click Save.

Unread conversations badge

The unread conversations badge setting is on by default. This setting, when enabled, displays a red badge on the Helpdesk tab in Klaviyo's main navigation with a count of your unopened tickets.

Note that the count is based on a ticket-level per profile, not by the number of messages. For example, if person A texts you 3 times, the badge will show only 1 unread ticket. If persons A, B, and C each text you 1 time, the badge will show 3 unread tickets.

Recommendation: leave this setting on so you can monitor the number of tickets coming in.

Disable unread conversations badge

  1. Go to Service > Helpdesk in Klaviyo's main navigation menu.
  2. Click Settings.
  3. Select the General tab in the menu bar at the top.
  4. Under Unread conversation notifications, click Off.
  5. Click Save. The unread conversations badge will no longer show in Klaviyo's navigation.
