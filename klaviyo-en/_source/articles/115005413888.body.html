You will learn

Learn how to create, edit, and use universal or saved content to reuse specific blocks or sections within a template and avoid duplicative work. For example, if you have a header or a footer that you use in all your email templates, you can save it to avoid recreating it from scratch in every new email.

In Klaviyo’s template editor, you can save blocks or sections as universal content. When you do, you can choose to apply future edits to every instance of the universal block, across all templates. 

Create and use universal content 

The following sections will cover how to:

  • Save a block in a template for reuse
  • Save a section in a template for reuse
  • Access and use universal content

Save a block for reuse 

To save a block in an email template for reuse, save it as new universal content:

  1. In the template editor, hover over the block that you want to save. Make sure it's formatted the way you would like it to save.
  2. Select the star icon that appears.
  3. On the Create universal content modal that appears, name your block. Choose a memorable and descriptive name so it's easy to find later.
  4. Click Create.

Your block will now be saved in the Universal content tab in Klaviyo.

Save a section for reuse

To save a section in an email template for reuse in other templates, save it as universal content:

  1. In the template editor, hover over the section you'd like to save. To make sure that you're selecting the section (rather than a block within the section), click on the empty space the right of the template's section. 
  2. Select the star icon.
  3. On the Create universal content modal that appears, name your section. Name it something that will allow you to find it easily, like "Header" or "Footer."
  4. Click Create.

Your section will now be saved in the Universal content tab in Klaviyo.

Access and use universal content 

To access and reuse a block or section you saved as universal content:

  1. Open your email template in the editor.
  2. In the configuration panel along the right, select Content > Universal.
  3. All of your universal content will show in a list view. You can search by the content’s name, filter based on type, or scroll through all your universal content to choose one.
    • If you have a large amount of universal content to sift through, use the Expand button at the bottom of the sidebar.
  4. Once you find the block or section you would like to reuse, click and drag it into your template wherever you'd like it to go.

Edit existing universal content

You can edit universal content in 2 locations: 

  • By navigating to the Universal content in Klaviyo's main navigation.
  • In a template where the content is used.

Manage and edit content from the Universal content tab

To edit content from the Universal content tab in Klaviyo, go to Content > Universal content in Klaviyo's main navigation. Here you'll find a library of all of your saved universal content. You can filter this page to search universal content based on features like device type (i.e., mobile vs. desktop) and content type.

When you select a universal content block or section, you have the following management options:

  • Edit
  • Rename
  • View content usage
  • Preview
  • Delete

When editing, you’ll have access to a limited editor with only the options relevant to the universal content block or section you’re editing.

    • If you’re editing a block, the editor will include block styling options for that specific block, but not any other block types. 
    • When editing a section, you’ll be able to add blocks, but not sections (since a section cannot contain another section).

Edit content from within a template

To edit a universal content block or section within a template:

  1. Open your email template in the editor.
  2. Select the piece of universal content in the template preview. Or, if you have not added any to the template yet, drag and drop from the Universal tab. 
  3. You'll see 2 options for editing:
    1. Edit across all instances
      Choose this option if you’d like your edits reflected in every template containing this piece of universal content. Selecting the # of email or template shows your a list view of materials where this piece of universal content currently exists.
    2. Unlink and edit independently
      Choose this option if you’d like your edits to only apply to the content in template you’re currently editing.
  4. Make any desired edits to the universal content.

Note if you chose to Edit across all instances, editing other blocks in your template will temporarily be disabled. After you select Publish changes, the other blocks in the current template will become editable again.
