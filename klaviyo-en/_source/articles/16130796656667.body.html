You will learn

Learn about the data that is synced when you integrate Boulevard with your Klaviyo account. When you integrate, we sync all historic data stored in Boulevard and then sync ongoing data in real time. 

How to view your data

To view your Boulevard data:

  1. Click the Analytics dropdown in the left-hand navigation sidebar.
  2.  Select Metrics. Here, you can view all of the metrics in your account. The metrics with a Boulevard icon represent all of the metrics synced from your Boulevard integration. 
  3. Filter this view to see only Boulevard metrics by using the filter selector next to the search bar.

Appointment metrics

Booked Appointments

This event is tracked when a client books a new appointment.

  • Staff Names
    The list of staff members associated with the appointment.
  • Service Names
    The list of services associated with the appointment.
  • Start At
    The start date timestamp of the appointment in UTC format, i.e., YYYY-MM-DDThh:mmTZD.
  • End At
    The end date timestamp of the appointment in UTC format, i.e., YYYY-MM-DDThh:mmTZD.
  • Order ID
    The ID of the purchase associated with the appointment.
  • Location Name
    The name of the location associated with the appointment.
  • Location ID
    The ID associated with the location.
  • Duration
    The duration of the appointment in minutes.
  • Booked By
    Who booked the appointment, e.g., Client.

    The total cost of the membership.
  • Membership Names
    The list of the names of the membership plans activated.

Other metrics

Placed Order

This event is tracked when a client places an order through Boulevard and the payment is complete. Orders can include retail products, gift cards, or services.

  • Applied Vouchers
    The list of any vouchers applied to the purchase.
  • Closed By
    The name of the staff member who closed the purchase.
  • Order ID
    The order ID associated with the purchase.
  • Location Name
    The name of the location associated with the order.
  • Location ID
    The ID of the location associated with the order.
  • Order Number
    The unique number associated with the order.
  • Summary
    The list of payment details including discounts, gratuity, subtotal, and total.
  • Line Groups
    The list of items associated with the order.
  • Note
    The list of any notes associated with the order.
  • Refunds
    The list of any items that were refunded.
  • Total
    The total value of the order.

Synced client data

Klaviyo creates or updates profiles for every client with Email, First and Last Name, Phone Number, and will set a custom profile properties of:

  • Appointment Count
    Total count of appointments.
  • Boulevard ID
    ID assigned to the client in Boulevard.
  • Email Marketing
    Whether or not a client has opted-in to receive marketing emails. (true/false)
  • SMS Marketing
    Whether or not a client has opted-in to receive marketing SMS. (true/false)
  • Push Marketing
    Whether or not a client can receive marketing push notifications. (true/false)
  • Email Reminder
    Whether or not a client can receive transactional emails. (true/false)
  • SMS Reminder
    Whether or not a client can receive transactional SMS. (true/false)
  • Push Reminder
    Whether or not a client can receive transactional push notifications. (true/false)
  • Boulevard Tags
    Any tags assigned to the client in Boulevard.
  • Birthday
    The client’s date of birth.
  • Primary Location Name
    The client’s primary location for receiving services.
  • Primary Location ID
    The ID of the client’s primary location.

Klaviyo also syncs email and SMS consent from Boulevard to Klaviyo profiles.
