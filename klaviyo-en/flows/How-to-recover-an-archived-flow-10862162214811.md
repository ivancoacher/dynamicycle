## You will learn

Learn how to recover an archived flow so you can edit and use it to send messages again. A recovered flow will return to the main Flows tab view with its status set to draft. From there you can edit it and change its status to live or manual.

## Recover an archived flow

1. Navigate to the ****Flows**** tab.
2. Click the ****Options**** dropdown in the top right.
3. Click ****View Archived Flows**** to navigate to the **Archived** view.
   ![Options dropdown in the top right of the Flows tab with the option 'View Archived Flows' selected.](https://klaviyo.zendesk.com/hc/article_attachments/28716066614043)
4. Click the ****Actions**** icon to the right of the flow you would like to recover.
5. Click ****Unarchive****.
   ![Action button clicked next to the name of a flow in the Archived tab with the Delete option selected.](https://klaviyo.zendesk.com/hc/article_attachments/28716066618011)
6. You can easily navigate back to the main Flows tab to view the recovered flow by clicking the ****Options**** dropdown and choosing ****View Unarchived Flows****.
   ![Options dropdown in the top right of the Archived view with the option 'View Unarchived Flows' selected.](https://klaviyo.zendesk.com/hc/article_attachments/28716066621979)
