Learn how to create and send an email campaign in multiple languages, depending on the language preferences of your audience. Klaviyo can translate a campaign’s content to 60+ languages.

Localizing campaigns is great if you have or plan to expand to an international customer base. Sending emails in each subscriber’s preferred language allows you to reach a wider audience which can increase overall engagement.

## Before you begin

Enable Smart Translations from your [account settings](https://help.klaviyo.com/hc/en-us/articles/38068161225243).

If you haven’t already, learn the basics of [how to create and send an email campaign](https://help.klaviyo.com/hc/en-us/articles/115005054847). This article mainly covers translation features for campaigns.

## Translate a campaign

Make sure your email is fully edited and ready to send in your original language before translating. Otherwise, you’ll have to go through the translation process again if you make edits to the original content.

1. Create a campaign or edit an existing draft campaign.
2. On the **Recipients** step of the campaign wizard, make sure to add lists or segments to your campaign’s audience that you know have multiple language preferences.
3. If you haven’t already, add an email template to your campaign.
4. On the **Message** step, click ****Edit**** to open the template editor.
5. Click ****Translate**** in the top right.
6. Choose the original language that the content will be created in.
7. Select what languages you want to translate your campaign into by checking the box next to each language. The recommended languages are based on the preferred languages of your campaign’s audience. This section will also include any languages you chose in your translation settings.
8. If desired, click the dropdown under **Additional languages** to view and select languages that aren’t recommended.
9. If desired, choose a **Fallback language** for when a customer’s preferred language is unavailable. This can be different from the original language.

   ![](https://klaviyo.zendesk.com/hc/article_attachments/38069943006235)
10. Click ****Translate****.
11. On the next step, review all the email elements that will be translated. You can manually edit any of these elements if needed. You can also click the edit button next to listed images to change them to ones appropriate for the selected language.

    ![](https://klaviyo.zendesk.com/hc/article_attachments/38070154519067)
12. Click the edit button next to a listed text block to review and edit the full text.

    ![](https://klaviyo.zendesk.com/hc/article_attachments/38070154521371)
13. If you selected multiple languages to translate into, click the arrows at the top or use the dropdown to switch between languages.
14. If you want to add more languages or remove the currently selected language, click the name of the language.

    ![](https://klaviyo.zendesk.com/hc/article_attachments/38070123317403)
15. Once you’re done, click ****Save****.

## Regionalizing product content

Regionalizing product content allows your customers to see your product information, currency, and pricing that match their preferences.

### Dynamic Product Blocks

Regionalizing product content is available for the Shopify integration when Shopify Markets is enabled.

Dynamic Product Blocks used in Smart Translations will automatically match your customers language and country with product information, currency, and pricing that match their preferences. When a product is not sold in a given country, that product will not be recommended to your customers in that country.

1. Within the Smart Translations editor, select a Fallback catalog locale. This will be used with the customers country is unknown
   1. A default Fallback catalog locale for each language can be configured from your account settings.
2. If you selected multiple languages to translate into, click the arrows at the top or use the dropdown to switch between languages.

![](https://klaviyo.zendesk.com/hc/article_attachments/45234757087131)

### Static Product Blocks

Static Product Blocks used in Smart Translations can be manually configured for each language following the instructions in **Translate a campaign** based in the feed.

## Editing original content after translating

If you edit the original content of the email after you’ve already translated, a warning will appear at the top of the editor notifying you that your edits will affect translation.

![](https://klaviyo.zendesk.com/hc/article_attachments/38070300262299)

To correct any potential translation errors:

1. Click ****Review translations**** next to the warning message.
2. Click ****Update translation**** to update all out-of-sync blocks which are highlighted in yellow.

   ![](https://klaviyo.zendesk.com/hc/article_attachments/38070300263963)
3. To individually edit an element, click the pencil icon and choose from the following:

- ****Re-translate**** - translate any changed text.
- ****Match source**** - match image or URL to the original source.
- ****Edit**** - manually modify the element
- ****Ignore**** - keep element as is.

## Translations for cloned messages and A/B tests

If you clone a campaign with translations, the new campaign will keep all translations from the original which you can freely edit. Learn [how to clone a campaign](https://help.klaviyo.com/hc/en-us/articles/24898429283739#h_01HVKNA3S6JX5ZXN5N734J7QTT).

When you create an A/B test, new variations will keep translations from the original email.
