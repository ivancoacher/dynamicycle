Learn how to create and send an SMS campaign in multiple languages, depending on the language preferences of your audience. Klaviyo can translate a campaign’s content to 60+ languages.

Localizing campaigns is great if you have or plan to expand to an international customer base. Sending messages in each subscriber’s preferred language allows you to reach a wider audience which can increase overall engagement.

Smart Translations are also available for [email campaigns](https://help.klaviyo.com/hc/en-us/articles/38069585109787).

## Before you begin

Enable Smart Translations from your [account settings](https://help.klaviyo.com/hc/en-us/articles/38068161225243).

If you haven’t already, learn the basics of [how to create and send an SMS campaign](https://help.klaviyo.com/hc/en-us/articles/360040039971). This article mainly covers translation features for campaigns.

## Translate an SMS campaign

Make sure your message is fully edited and ready to send in your original language before translating. Otherwise, you’ll have to go through the translation process again if you make edits to the original content.

1. Create a campaign or edit an existing draft campaign.
2. On the **Recipients** step of the campaign wizard, make sure to add lists or segments to your campaign’s audience that you know have multiple language preferences.
3. On the **Message** step, write the message you want to send to customers. Add an image if desired.
4. On the **Review** step, ****click Translation**** to expand the view and see what languages and translations have been completed. This section will include any languages you chose in your translation settings.
   ![](https://klaviyo.zendesk.com/hc/article_attachments/45680603159451)
5. If desired, click ****Review**** under the Translation Section languages to view and select more languages.
6. Select what languages you want to translate your campaign into by clicking the language in the drop down menu.
   ![](https://klaviyo.zendesk.com/hc/article_attachments/45680603161499)
7. If you selected multiple languages to translate into, click the arrows at the top to switch between languages.
8. Click the edit button next to the message text to see the full message and its translation.
9. You can manually edit the translated text if needed by clicking into the message in the edit view.
10. If you want to add more languages or remove the currently selected language, click the drop down at the top.
11. Once you’re done, click ****Done****.

## Editing original content after translating

If you edit the original content of the message after you’ve already translated, a warning will appear at the review step in the Translation Section.

![](https://klaviyo.zendesk.com/hc/article_attachments/45680590115483)

To correct any potential translation errors:

1. Click ****Edit**** in the Translation section.
2. Click ****Update translations**** to update all out-of-sync blocks which are highlighted in yellow.
   ![](https://klaviyo.zendesk.com/hc/article_attachments/45680603170587)
3. To individually edit an element, click the three dot menu and choose from the following:

- ****Re-translate**** - translates any changed text
- ****Ignore**** - keep element as is
- ****Edit -**** manually modify the element

![](https://klaviyo.zendesk.com/hc/article_attachments/45680603172635)
