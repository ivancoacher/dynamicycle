Learn how to create a multilingual WhatsApp campaign in Klaviyo using Smart Translations. This feature helps you automatically translate and send your WhatsApp message in each recipient’s preferred language.

With Smart Translations, you can reach global audiences in multiple languages without creating separate campaigns for each one.

Smart Translations are also available for [email](https://help.klaviyo.com/hc/en-us/articles/38069585109787), [SMS](https://help.klaviyo.com/hc/en-us/articles/39896599432347) and [push](https://help.klaviyo.com/hc/en-us/articles/45609327372571) campaigns.

## Before you begin

Enable Smart Translations form your [account settings.](https://help.klaviyo.com/hc/en-us/articles/38068161225243)

If you haven't already, learn the basics of [how to create a WhatsApp template](https://help.klaviyo.com/hc/en-us/articles/40116644987675). This article mainly covers translation features for campaigns.

## Create a multilingual WhatsApp campaign

Keep in mind that WhatsApp messages and their translations need to be reviewed by Meta before being marked as approved, so make sure your message is fully edited and ready to send in your original language before translating it. Otherwise, you'll have to go through the translation and wait for approval again if you make edits to the original content.

1. Create a campaign or edit an existing draft campaign.
2. On the **Recipients** step of the campaign wizard, make sure to add lists or segments to your campaign’s audience that you know have multiple language preferences.
3. Create a new template or choose from an existing one.
4. On the **Message** step, write the message you want to send to customers. Add an image, links, buttons, rich text or multiple cards if desired.
5. At the top right corner of the editor, click on the ****Translate**** button.

   ![](https://klaviyo.zendesk.com/hc/article_attachments/45620280372763)
6. Select the original language that the content was written in. This will default to your account language.
7. Select what languages you want to translate your campaign into by selecting them from the ****Additional languages**** dropdown.
8. If desired, choose a Default language for when a customer’s preferred language is unavailable. This can be different from the original language.

   ![](https://klaviyo.zendesk.com/hc/article_attachments/45620280374043)
9. Click ****Translate****.
10. On the next step, review the text message that will be translated. You can manually edit the text if needed. You can also click the edit button next to a listed image to change it to one appropriate for the selected language.
11. Click the edit button next to the message text to see the full message.
12. If you selected multiple languages to translate into, click the arrows at the top or use the dropdown to switch between languages.
13. If you want to add more languages or remove the currently selected language, click the name of the language.
14. Once you’re done, click ****Done****.

Once you Submit for review, you won't be able to make any changes to the translations or add/delete any languages until the template is reviewed by Meta. Once reviewed, your template status will change and you will be able to make changes.

## Editing original content after translating

If you edit the original content of the message after you’ve already translated, a warning will appear at the top of the editor notifying you that your edits will affect translation.

![](https://klaviyo.zendesk.com/hc/article_attachments/45620280374555)

To correct any potential translation errors:

1. Click ****Review translations**** next to the warning message.
2. Click ****Update translation**** to update all out-of-sync blocks which are highlighted in yellow.
3. To individually edit an element, click the pencil icon and choose from the following:

- ****Re-translate****: translates any changed text
- ****Match source****: matches image or URL to the original source
- ****Edit****: manually modify the element
- ****Ignore****: keep element as is

## Translations for cloned messages

If you clone a campaign with translations, the new campaign will keep all translations from the original which you can freely edit. [Learn how to clone a campaign.](https://help.klaviyo.com/hc/en-us/articles/24898429283739#h_01HVKNA3S6JX5ZXN5N734J7QTT)

## Best practices

- Keep messages concise. WhatsApp messages have lower character limits than email or SMS.
- Avoid slang or idiomatic expressions that may not translate clearly.
- Always double-check punctuation and line breaks in translated versions.
- Use consistent formatting across all language versions.
