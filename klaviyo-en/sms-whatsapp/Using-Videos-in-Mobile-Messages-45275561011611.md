This article provides an overview of how to manage and send video content within your mobile messaging channels, including WhatsApp, RCS, MMS, and Push.

## ****The Media Library****

To better accommodate video content, the "Images & brand" section of Klaviyo has been renamed to ****Media & brand****.

### ****Uploading and Managing Videos****

You can now upload ****MP4**** and ****MPEG**** files directly to your library.

- ****File Size Limit****: Individual video uploads are capped at ****10MB****.
- ****Organization****: You can use the new ****File type filter**** to toggle between viewing images (PNG, JPG, GIF) and videos (MP4, MPEG).
- ****Thumbnails****: Klaviyo automatically generates a thumbnail for uploaded videos.
- Clicking a thumbnail in the library opens a preview tab with full playback controls.

## ****Adding Videos to Mobile Messages****

You can attach videos to messages within the editor for WhatsApp, RCS, MMS, and Push notifications. The workflow is identical to adding images: browse the Media Library or upload a file directly from the editor.

### ****Channel-Specific Requirements****

|  |  |  |
| --- | --- | --- |
| ****Channel**** | ****File Types Supported**** | ****File Sizes Supported**** |
| ****WhatsApp**** | Supports ****MP4 only****; MPEG files will appear disabled in the library. | Video files attached cannot exceed ****10MB.**** |
| ****RCS**** | Supports MP4 and MPEG for rich cards. | Video files attached cannot exceed ****10MB.**** The total media file size across all cards in an RCS message cannot exceed ****100MB.**** |
| ****MMS**** | Supports MP4 and MPEG. | Video files attached cannot exceed ****10MB.**** Video files greater than ****600KB**** can be attached to an MMS, however Klaviyo does not recommend this. |
| ****Push**** | Videos and GIFs are only supported on ****iOS devices****; these will be skipped for Android recipients. | Video files attached cannot exceed ****10MB.**** |

## ****Important Considerations****

- ****MMS File Sizes****: If a video in an MMS exceeds ****600KB****, a warning banner will appear in the editor. Larger files may be subject to carrier limitations or compression.
- ****Email Editor****: Videos are ****not supported**** in the email editor. If you access the Media Library from an email template, videos will appear in a disabled state.
- ****Image Remix****: You cannot use videos with the Image Remix tool.
- ****Compression****: Videos are currently exempt from Klaviyo’s automatic image compression settings and will be handled similarly to GIFs.
