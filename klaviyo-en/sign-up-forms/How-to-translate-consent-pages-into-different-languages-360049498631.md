## You will learn

Learn how to translate the text in your consent pages (i.e., subscribe, unsubscribe, and manage preferences pages) into the language that your subscribers use.

Each of your Klaviyo lists is connected to your account's default consent pages by default. This means that any emails sent to one or more of these lists will use the default preference page, subscribe page, and unsubscribe page. You also have the option to customize consent pages for a particular list (list-specific consent pages). If you do this, any emails sent to that list will use the customized consent pages, rather than the account-level pages. This guide will walk you through how to find and edit the text in each kind of consent page so you can translate it into your preferred language.

Head to our guide on [getting started with consent pages](https://help.klaviyo.com/hc/en-us/articles/115005251848#about-consent-pages-in-emails1) for more information about these pages and how they work.

## Translate a consent page

By default, Klaviyo’s consent pages use American English; however, all text fields in your consent pages are fully editable, so you can change them to a different language. Note that this also includes buttons, privacy disclosures, and error messages.

### Translate your account's default consent pages

1. In Klaviyo, navigate to ****Audience > Growth tools****.
2. Next **Customize subscribe and preference pages,** click ****Customize****.
3. Select ****Account default pages****.
   ![Selecting Account default pages from beneath Customize subscribe and preference pages on the Growth tools tab.](https://klaviyo.zendesk.com/hc/article_attachments/28722558311323)
4. Below the page type you’d like to edit (e.g., preference page), click ****Edit Page****.
   ![Selecting Edit page next to the Preference page tile on the Consent pages page.](https://klaviyo.zendesk.com/hc/article_attachments/28722596704155)
5. Click any text in the preview that you want to edit to see a **Text** menu appear along the left side.
6. Delete the default text and replace it with any text in your preferred language. Note that you can also customize **Required Text** language and **Invalid Input** language that comes with input fields (e.g., email field) in your subscribe page. This helps you ensure that the text for any error messages that a shopper may see is consistent with the rest of your consent page's language.
   ![The Block validation section within the Text menu where you can customize the Required Text and Invalid Input language.](https://klaviyo.zendesk.com/hc/article_attachments/28722596707355)

   Make sure to complete this for all steps, including the **Success page** in the menu bar**.**
7. Click ****Publish**** to publish your changes.

### Translate a list-specific consent page

1. Navigate to ****Audience > Lists & Segments**** in Klaviyo.
2. Choose a list.
3. Select ****Subscribe & preferences pages**** in the menu bar.
   ![The Subscribe & preferences pages tab selected in the menu bar of a specific list's page.](https://klaviyo.zendesk.com/hc/article_attachments/28722558315163)
4. Click ****Customize for this List**** (if you haven’t yet customized any of this list’s pages).
   ![The Subscribe and preferences tab for a specific list with the option to Customize for this list being selected.](https://klaviyo.zendesk.com/hc/article_attachments/28722596715803)
5. Below the page type you’d like to edit (e.g., subscribe page), click ****Edit Page****.
6. Click on any text you want to edit in the preview to see a **Text** menu appear with editing options.
7. Delete the default text and replace it with any text in your preferred language. Note that you can also customize **Required Text** language and **Invalid Input** language that comes with input fields (e.g., email field) in your subscribe page. This helps you ensure that the text for any error messages that a shopper may see is consistent with the rest of your consent page's language.

   Make sure to complete this for all steps, including the **Success page**, which you can find in the menu bar.
8. Click ****Publish**** to publish your changes.
