## You will learn

Learn how to integrate Klaviyo with Canva in order to bring images from Klaviyo into Canva, and designs from Canva into Klaviyo. Once Canva designs are in your Klaviyo image library, you can use them within email templates, SMS content, sign-up forms, and more.

This integration allows the importing/exporting of images between Klaviyo and Canva. It does not handle importing/exporting HTML email templates.

Additionally, please note:

- A single Canva user can only connect to one Klaviyo account at a time (per Canva team). Thus, if you work with multiple Klaviyo accounts, it may be best to export and upload your images manually.
- This integration only supports JPG, PNG, and GIF files.
- You can export a maximum of 100 designs a day from Canva to Klaviyo.
- Designs exported from Canva can have a maximum size of 5 MB.
  - Please note that the [recommended image size in Klaviyo emails is 1MB or smaller](https://help.klaviyo.com/hc/en-us/articles/115005253688).

## How to set up the Canva integration

1. Log in to your Klaviyo account.
2. In Klaviyo, select the ****Integrations**** tab.
3. Click ****Explore apps****, then search for **Canva** and click the card.
4. On the next page, click ****Install**** to be directed to Canva.
   ![](https://klaviyo.zendesk.com/hc/article_attachments/30732208589595)
5. You’ll be brought to the Klaviyo listing on the Canva apps marketplace. Select ****Use in a design.**** **Note: The Klaviyo integration will only work with the types of files in the dropdown menu. These options do not include Canva Email designs.**
   ![image-20260212-233135.png](https://klaviyo.zendesk.com/hc/article_attachments/46625697063579)
6. You’ll be prompted to log in to Canva, if needed.
7. On the next page, click ****Connect****.
   ![](https://klaviyo.zendesk.com/hc/article_attachments/29553940844059)
8. Review the permissions and select ****Allow****.

![](https://klaviyo.zendesk.com/hc/article_attachments/28943967353883)

You’re done setting up your Canva integration! Read on to learn how to export Canva designs and import Klaviyo images.

## Export Canva designs to your Klaviyo image library

To export a Canva design to your Klaviyo image library:

1. From within a Canva design, click on the Klaviyo icon in the lower left.
2. In the sidebar, rename your image file, or use the default.
   ![](https://klaviyo.zendesk.com/hc/article_attachments/29553940856475)
3. Click ****Start export****.
4. Choose the file type (PNG, JPG, or GIF).
   ![](https://klaviyo.zendesk.com/hc/article_attachments/29553940862235)
5. The following additional settings are are only available for Canva Pro Users:

   - Select the file size, if you’d like to resize the image.
   - Choose whether you’d like a transparent background.
   - Choose if you’d like to compress the file (this results in lower quality).
6. If you are exporting a multi-page design: Below the size settings, you’ll see an option to select which page(s) you want to export. If you choose to export multiple pages, each page will appear as its own image in Klaviyo.

   In Klaviyo, the file name for each image will be the file name you set for the export with the page number added, like this:
   ![](https://klaviyo.zendesk.com/hc/article_attachments/29553940867995)
   ![](https://klaviyo.zendesk.com/hc/article_attachments/28943967365147)
7. When you’re done with page selection, click ****Done****.
8. When you’re ready to export, select ****Export****. When the image export is complete, you will see a success message that links to your Klaviyo image library.

![](https://klaviyo.zendesk.com/hc/article_attachments/29553940874139)

You can view all of the images in your Klaviyo account, including those exported from Canva, by navigating to your Klaviyo account and selecting ****Content > Images & brand****.

Once an image has been uploaded to Klaviyo, you can easily drag it into your Klaviyo content, including email templates, MMS messages, rich push notifications, and sign-up forms.

## Import Klaviyo images into Canva designs

To import an image from Klaviyo to Canva:

1. From within a Canva design, click on the Klaviyo icon in the lower left.
2. Select the ****Import images**** tab within the sidebar.
   ![](https://klaviyo.zendesk.com/hc/article_attachments/29553940878875)
3. Search by image name to see all relevant images from Klaviyo.
4. Select an image and click ****Add to design**** to import it into your current Canva design. This will also make the image available in your Canva uploads for future designs.

![](https://klaviyo.zendesk.com/hc/article_attachments/29553940883099)

Canva has some total storage limits for uploads. See [Canva's help center](https://www.canva.com/help/upload-media/#:~:text=Free%20Canva%20accounts%20can%20upload,accounts%20have%201TB%20of%20storage) for more.

## Outcome

You've now integrated Canva with Klaviyo, learned how to export Canva designs to your Klaviyo image library, and learned how to import images from your Klaviyo image library to your Canva designs.
