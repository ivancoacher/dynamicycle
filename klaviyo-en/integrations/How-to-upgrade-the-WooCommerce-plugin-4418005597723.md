## You will learn

Learn how to update your Klaviyo WooCommerce plugin to the latest version from an existing WooCommerce integration. Visit [Getting started with WooCommerce](https://klaviyo.zendesk.com/hc/en-us/articles/115005255808) if you need to enable your WooCommerce integration for the first time.

Are you using a WooCommerce plugin version below 3.3.0? We recommend upgrading immediately to version 3.3.0 or higher. Older versions of the plugin use Klaviyo’s v1 and v2 APIs which have been retired and no longer operate as expected.

## Before you begin

- You do not need to remove your existing integration in order to upgrade to the latest plugin version.
- The WooCommerce integration syncs data to Klaviyo in real time.

## Update the Klaviyo plugin in WooCommerce

The newest Klaviyo plugin can be installed and updated directly from WooCommerce:

1. In WooCommerce, click the ****Plugins**** tab.
2. Scroll down to locate the **Klaviyo** plugin.
3. If there is a banner showing an available update, click ****update now****.
4. You can click ****enable auto-updates**** if you wish to do so.

When updating your plugin version, you may wish to review what features have been modified. To learn about changes made in each version, head to [our Changelog](https://wordpress.org/plugins/klaviyo/#developers).
