## Overview

Klaviyo's APIs are designed to help users and developers alike integrate with Klaviyo.

These guides aim to help you get the most from your experience developing with Klaviyo's API:

- ****JavaScript API****The JavaScript API to used to easily track people on your website. From start to finish, it should take between 5-10 minutes to go through the entire guide.
- ****Server-Side API****The Server-Side API is composed of the Identify API and the Track API. These APIs are used for tracking people and the events/actions they do on and off your website. They are optimized for low latency and high numbers of requests, so they do not adhere to the same REST principles our other APIs use.
- ****Metrics API****The Metrics API is used for retrieving historical event data in Klaviyo.
- ****Profiles API****The Profiles API is used for managing person records in Klaviyo.
- ****Lists API****The Lists & List Management API is used for creating and managing lists in Klaviyo.
- ****Campaigns API****The Campaigns API is used for creating and sending campaigns in Klaviyo.
- ****Templates API****The Templates API is used for interacting with email templates stored in Klaviyo.
