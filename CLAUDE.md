# Dynamicycle Docs Agent Rules

Follow `AGENTS.md` as the canonical repository instructions.

Before every task, read `PROJECT_STATE.md`. Record every user-directed task in
`PROJECT_STATE.md` and append its result to `PROJECT_HISTORY.md`. At completed
checkpoints, commit scoped task changes and push the current branch so another
account or device can resume.

When the user says `落库`, persist the latest rules in `AGENTS.md` and update or
create the appropriate project skill under `.agents/skills/`.
