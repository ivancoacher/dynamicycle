## ****概述****

作为 Klaviyo 拖放编辑器中文本编辑升级的一部分，此推出分两个阶段进行：首先，所有新创建的模板将默认使用新编辑器；然后，仍使用旧文本编辑器的现有模板将自动迁移。本文解释了每个阶段的预期内容。

## ****第一阶段：新模板****

从接下来的几周开始，您创建的任何新电子邮件模板都将使用升级后的文本编辑器来处理文本块、表格块和拆分块。如果克隆现有模板，克隆的模板将继承原始模板使用的编辑器。

打开新模板时，您可能会注意到一个横幅，让您知道它正在使用新编辑器。该横幅将暂时显示，大约一个月后将被删除。

如果您的旧编辑器上仍有现有模板，它们将继续像以前一样工作，直到部署的第 2 阶段到达您的帐户。

## ****第二阶段：现有模板****

第 1 阶段完成后，Klaviyo 将开始迁移仍使用旧文本编辑器的现有模板。此推出是渐进式的 — 在对您的帐户进行任何更改之前，您将通过应用内横幅收到至少 2-4 周的提前通知。

### ****转换如何进行****

当迁移到达您的帐户时，Klaviyo 将自动尝试转换现有模板中的每个文本块、表格块和分割块：

- ****如果该块可以转换**** — 它将自动升级到新编辑器，无需您执行任何操作。
- ****如果块无法转换**** — 这适用于具有复杂内容的块，例如表格、自定义样式或嵌入样式标签。这些块将转换为 HTML 块，保留所有内容，同时让您直接控制代码。

请注意，这不仅适用于文本块，还适用于使用富文本编辑的拆分块和表格块。

### ****源代码查看****

通过此更改，源代码视图将从文本块、表块和拆分块中删除。如果您需要直接编辑 HTML，您可以使用专用的 HTML 块，这使您可以完全控制代码。要使用 Django 标签添加动态内容而无需编写代码，请使用新的 Django 标签生成器。

### ****发生了什么变化****

- 源代码视图已从文本、表格和分割块中删除。您现在可以使用我们新的 Django 标签生成器在这些块中创建个性化标签。
- 表格和分割块将移至画布内文本编辑。您将不再通过侧面板编辑这些块中的文本。

### ****什么没有改变****

- 您的电子邮件内容和设计将在整个过程中保留。作为新的文本块、表格块或分割块，或者作为 HTML 块。
- 您可以像今天一样继续构建和编辑电子邮件，唯一的区别是文本编辑将不再包括源代码视图。

## ****推出期间会发生什么****

1. ****提前通知**** — 在您的帐户开始迁移之前，您将通过应用内横幅收到至少 2-4 周的通知。
2. ****逐步推出**** — 迁移将在账户之间逐步推出。
3. ****自动转换**** — Klaviyo 将在可能的情况下自动转换您的文本块。
4. ****HTML 后备**** — 无法转换的块将成为 HTML 块。发生这种情况时，您会在应用程序内收到通知。

## ****如何准备****

在迁移到达您的帐户之前，请检查您的现有模板：

- ****文本块内的表格****
- ****自定义样式或内联样式标签****
- ****嵌入 HTML**** 或其他复杂格式

对于此类别的模板，请考虑主动迁移到 HTML 块，或简化格式以使其能够干净地转换。
