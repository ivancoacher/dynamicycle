## 你将会学到

了解如何导出有关 Klaviyo 生成和上传的优惠券的信息，以便您可以直接使用 Klaviyo 的数据报告优惠券。

- 对于 Klaviyo 生成的优惠券，您可以确定代码发送给哪个客户、优惠券名称、发送日期等。
- 对于上传的优惠券，导出包括有关已分配代码和未分配代码的详细信息。

## 导出 Klaviyo 生成的优惠券（特定于集成）信息

对于 Klaviyo 生成的（特定于集成）优惠券，您只能导出之前分配的可能有效或已过期的优惠券代码的信息。未分配的优惠券无法导出。

1. 在 Klaviyo 左侧导航中导航至****内容 >**** ****优惠券****。
2. 找到您的优惠券并单击旁边的 3 个点。
3. 从下拉列表中，选择****查看历史记录****。
   ![](https://klaviyo.zendesk.com/hc/article_attachments/38522581535771)
4. 在优惠券历史记录页面上，选择您要导出的优惠券定义版本。

   请注意，2020 年 8 月 26 日之前创建的任何优惠券版本都将显示为“未知”，因为在此之前未记录优惠券信息。

   ![在优惠券历史页面上的优惠券定义下选择的优惠券。](https://klaviyo.zendesk.com/hc/article_attachments/28717382279579)
5. 选择定义后，单击页面底部的****导出****。
6. 从出现的 **导出优惠券报告** 模式中，选择是否要导出：
   - 有效和过期代码（默认）
   - 仅有效代码
   - 仅限过期代码
7. 选择****导出优惠券报告****。
   ![导出优惠券报告模式显示设置为包含有效代码和过期代码的选项](https://klaviyo.zendesk.com/hc/article_attachments/34401817519899)

导出的 CSV 文件将显示您所选定义中的所有优惠券代码。此外，每个代码都会显示以下信息：

- 唯一代码（如果适用）
- 客户电子邮件
- Klaviyo 个人资料 ID
- Klaviyo 优惠券 ID
- 优惠券名称
- 指定日期（发送时）
- 有效期
- 代码状态
- 优惠券定义
- 定义开始日期
- 定义结束日期

## 导出上传的优惠券信息

1. 在 Klaviyo 左侧导航中导航至****内容 > 优惠券****。
2. 切换至****上传优惠券。
   ![在优惠券页面上选择上传的优惠券选项卡。](https://klaviyo.zendesk.com/hc/article_attachments/28717382275739)****
3. 找到您的优惠券并单击旁边的 3 个点。
4. 单击****导出****。
   ![](https://klaviyo.zendesk.com/hc/article_attachments/38522581540507)
5. 在出现的 **导出代码报告** 模式中，选择是否要导出：
   - 有效和过期代码（默认）
   - 仅有效代码
   - 仅限过期代码
6. 选择是否要包括：
   - 发送代码
   - 可用代码
   - 所有代码
7. 单击****导出优惠券报告****。
8. ![导出优惠券报告模式显示包含有效代码和过期代码以及选定的已发送代码的选项](https://klaviyo.zendesk.com/hc/article_attachments/34401817519899)

生成的 CSV 文件将显示未分配和已分配的代码，并将包括以下列：

- 独特的代码
- 电子邮件
- Klaviyo 个人资料 ID
- Klaviyo 优惠券 ID
- 当前优惠券名称
- 指定日期
- 有效期
- 代码状态
- 优惠券定义
- 定义开始
- 定义结束
