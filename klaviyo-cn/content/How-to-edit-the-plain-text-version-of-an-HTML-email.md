## 你将会学到

了解如何自定义 HTML 电子邮件的纯文本版本（即使用 Klaviyo 的拖放编辑器构建的电子邮件）。

本文将教您如何自定义在 Klaviyo 拖放编辑器中内置的电子邮件附带的自动生成的纯文本 MIME 类型。如果您想发送简单的文本电子邮件，请[了解如何使用 Klaviyo 的纯文本电子邮件编辑器](https://klaviyo.zendesk.com/hc/en-us/articles/12415384810651)。

当您发送 HTML 电子邮件时，Klaviyo 会自动包含纯文本版本。这是因为并非所有收件箱都接受 HTML 电子邮件，纯文本电子邮件可以帮助您区分垃圾邮件发送者，因此包含替代选项非常重要。这些版本的电子邮件称为 MIME（多用途 Internet 邮件扩展）类型。 Klaviyo 支持 3 种电子邮件 MIME 类型：HTML、纯文本和 [AMP](https://developers.klaviyo.com/en/docs/send_amp_emails_in_klaviyo)（某些收件箱支持的高级消息类型）。

作为发件人，您无法检测收件人能够（或选择）查看哪种 MIME 类型。出于安全原因或可访问性，收件箱可能仅支持纯文本电子邮件。

Klaviyo 自动生成使用我们的拖放编辑器构建的所有电子邮件的纯文本版本。

## 创建活动电子邮件的纯文本版本

要调整营销活动的纯文本：

1. 点击 Klaviyo 侧栏中的****营销活动****。
2. 单击任何未发送的电子邮件活动。
3. 导航至广告活动编辑器的第 2 步，**内容**。
4. 打开**编辑电子邮件**菜单。
5. 单击****编辑纯文本版本****。
   ![编辑电子邮件活动纯文本版本的选项](https://klaviyo.zendesk.com/hc/article_attachments/28720892658331)
6. 对自动生成的电子邮件进行所需的编辑。
7. 单击****保存纯文本****。

## 创建流电子邮件的纯文本版本

要调整流电子邮件的纯文本：

1. 单击 Klaviyo 侧栏中的****流程****。
2. 打开流程。
3. 单击您要编辑的电子邮件。
4. 打开 **编辑电子邮件** 菜单。
5. 单击****编辑纯文本版本****。
   ![编辑流程电子邮件纯文本版本的选项](https://klaviyo.zendesk.com/hc/article_attachments/28720847522075)
6. 对自动生成的电子邮件进行所需的编辑。
7. 单击****保存纯文本****。

如果您对模板的纯文本版本进行任何编辑，请记住，Klaviyo 将不再使该版本与您的 HTML 模板同步。这意味着，如果您将来对内容进行更改，则需要在两个位置进行更新：在拖放编辑器中，然后在电子邮件纯文本版本的编辑器中进行更新。

![纯文本编辑器内容](https://klaviyo.zendesk.com/hc/article_attachments/28720892651163)

如果您手动编辑 HTML 电子邮件的纯文本版本，然后希望恢复到 Klaviyo 自动保持这两个版本同步的状态，您可以单击选项****自动生成纯文本。****

![在显示“自动生成纯文本”的链接上方，工具提示文本显示消息“根据您的 HTML 版本恢复为自动生成的纯文本”](https://klaviyo.zendesk.com/hc/article_attachments/28720847517339)

如果您选择让 Klaviyo 自动从 HTML 模板生成纯文本，并且您过去曾进行过任何手动编辑，则这些编辑将被丢弃。

## 表情符号和纯文本电子邮件

截至 2024 年 2 月，所有 Klaviyo 电子邮件编辑器（即拖放编辑器、混合编辑器、纯文本编辑器和自定义 HTML 编辑器）均支持所有表情符号。
