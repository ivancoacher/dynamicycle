## 你将会学到

了解如何创建和使用静态 WooCommerce 优惠券代码来激励新注册并鼓励老客户再次购买。

静态优惠券代码是解锁特定折扣的单个短语或字母数字字符串（例如，Welcome20）。每个人都会收到相同的代码，以便可以广泛共享；然而，它们更容易记住和使用。

如果您想为 WooCommerce 创建和使用独特的优惠券，请参阅[如何为 WooCommerce 创建独特的优惠券代码](https://help.klaviyo.com/hc/en-us/articles/22168739689627)。

## 在 WooCommerce 中创建优惠券

您首先需要在 WooCommerce 中启用优惠券（如果尚未启用）。

1. 登录您的 WooCommerce 帐户。
2. 导航到 ****WooCommerce > 设置 > 常规。****
3. 勾选复选框以启用优惠券。
4. 保存您的更改。

接下来您需要创建优惠券。

1. 在您的 WooCommerce 帐户中，导航至****营销 > 优惠券。****
2. 点击****添加优惠券****。或者，如果您尚未创建优惠券，请单击****创建您的第一张优惠券****。
   ![您的 Woocommerce 帐户中的优惠券页面，其中选择了添加优惠券按钮。](https://klaviyo.zendesk.com/hc/article_attachments/28717381245211)
3. 为您的优惠券命名并添加说明以供您理解。
4. 输入您的优惠券数据。
   ![创建新优惠券时的数据输入页面，您可以在其中选择折扣类型、名称和有效期。](https://klaviyo.zendesk.com/hc/article_attachments/28717387513115)
5. 如果您有任何使用限制或限制，请在相关选项卡中输入。
6. 完成编辑后，单击****发布****。

## 在电子邮件或短信中使用您的优惠券

在 WooCommerce 中制作优惠券后，您可以将静态代码直接输入到短信中或作为电子邮件的文本块。在块样式选项卡下添加边框，使其看起来像剪纸优惠券。

![示例电子邮件模板，其中的静态代码写在文本块中，周围有醒目的边框。](https://klaviyo.zendesk.com/hc/article_attachments/28717381251995)

## 将优惠券批量导入到 WooCommerce

查看 WooCommerce 的文档，了解如何[通过 CSV 文件将优惠券批量导入 WooCommerce](https://docs.woocommerce.com/document/smart-coupons/how-to-import-coupons-in-bulk-using-a-csv-file/) 或 [为WooCommerce](https://help.klaviyo.com/hc/en-us/articles/22168739689627)。

## 最佳实践

使用静态优惠券时需要注意以下几点：

- 如果您担心优惠券传播给太多客户，请控制过期日期并在需要时再发送另一张优惠券。
- Klaviyo 不管理有关静态优惠券的任何元数据，包括代码、到期日期、折扣金额等。所有这些信息都在您的 WooCommerce 商店内部管理。
- 如果您提供特定产品的优惠券，请包含该产品的链接，以便您的客户可以轻松点击您的电子邮件进行购买。
