## 你将会学到

了解如何在 Klaviyo 中发送简单的纯文本电子邮件。纯文本电子邮件可以包含有限的格式和图像，但通常在样式和结构上比 HTML 电子邮件简单得多（例如，在 Klaviyo 的拖放编辑器中构建的电子邮件）。本文指的是主要或完全由文本组成的电子邮件。了解如何[自定义 HTML 电子邮件的纯文本版本](https://help.klaviyo.com/hc/en-us/articles/360037894891)，以提高您在拖放编辑器中构建的电子邮件的送达率和可访问性。 ## 关于纯文本电子邮件

如果您希望您的邮件具有非常个性化的感觉，纯文本电子邮件是一个不错的选择。这些电子邮件看起来与您从个人收件箱发送的消息类似，并且通常包含比标准 HTML 电子邮件更少的品牌内容和设计元素。纯文本电子邮件可能是一个不错的选择：

- ****欢迎系列中的消息****
  您可以在欢迎流程中包含一封纯文本电子邮件作为消息，并附上有关您的公司如何成立或您与其他品牌的区别的个人说明。 - ****道歉电子邮件****
  当您的公司犯了错误并需要通知客户时，请考虑发送纯文本电子邮件。 - ****文字较多的消息****
  如果您要发送一封大部分或全部是文本的长电子邮件，则纯文本电子邮件将更方便屏幕阅读器、智能手表和其他辅助技术阅读您的消息。由团队成员（例如您的创始人/首席执行官）签署的纯文本电子邮件通常最有影响力。虽然它们并不适合所有用例，但纯文本电子邮件的点击率通常比完全设计的 HTML 电子邮件更高。 ## 如何创建纯文本电子邮件

### 创建纯文本营销活动电子邮件

1. 导航至 Klaviyo 中的****营销活动****选项卡。 2. 单击****创建活动****。 3. 选择****电子邮件****并单击****继续****。 4. 为您的营销活动选择收件人和跟踪设置，然后单击****下一步****。 5. 单击附加选项（三个点）菜单，然后选择****切换到纯文本编辑器****。 ![模板页面上的切换到纯文本编辑器按钮。](https://klaviyo.zendesk.com/hc/article_attachments/39392085135131)

创建纯文本电子邮件后，请了解如何[将其作为营销活动发送](https://help.klaviyo.com/hc/en-us/articles/115005054847)。 ### 创建纯文本流电子邮件

要创建全新的纯文本电子邮件：

1. 导航至 Klaviyo 中的****Flows**** 选项卡。 2. 选择您想要添加纯文本电子邮件的现有流程，或单击****创建流程****并继续执行步骤以[配置新流程](https://help.klaviyo.com/hc/en-us/articles/115002774932)。 3. 打开流程后，拖入****电子邮件****操作。 ![Klaviyo 流程生成器中的电子邮件操作](https://klaviyo.zendesk.com/hc/article_attachments/28715964797339)
4. 单击您刚刚添加的消息，然后单击 ****编辑****。 5. 在**消息内容**菜单中，单击****仅限文本****。 ![Flow 内容页面上的纯文本按钮。](https://klaviyo.zendesk.com/hc/article_attachments/39392075398299)

要将现有流电子邮件替换为新的纯文本电子邮件：

1. 选择流程中的电子邮件。 2. 从附加选项（三个点）菜单中，选择****编辑****。 3. 在下一页上，打开附加选项（3 个点）菜单并选择****更改模板****。 ![更改模板选项](https://klaviyo.zendesk.com/hc/article_attachments/29587274518427)
4. 选择****仅文本****。 ![纯文本模板选项](https://klaviyo.zendesk.com/hc/article_attachments/28715971347227)

一旦您的流程电子邮件准备就绪，请了解如何[打开您的流程](https://help.klaviyo.com/hc/en-us/articles/115002774932)。 ## 设计并起草一封纯文本电子邮件

1. 创建纯文本营销活动或流程电子邮件后，请在文本编辑器中编写消息。请注意，您可以添加个性化设置（例如，[名字变量](https://help.klaviyo.com/hc/en-us/articles/11613154130843)）、包含图像、更改字体样式和颜色、添加项目符号点或编号列表以及使用其他有限的样式选项。要添加图像，请点击 ****来源**** 并添加 HTML 图像标签：**<img src="YOUR\_IMAGE\_URL">**

   ![纯文本电子邮件示例。](https://klaviyo.zendesk.com/hc/article_attachments/39392075402395)
2. 当消息准备好发送时，单击****保存****。所有纯文本电子邮件的大小限制为 1.05 MB。 要验证您的电子邮件没有超出此限制，请将电子邮件预览发送到您的收件箱。如果不发送，则可能太大。 ## 表情符号和纯文本电子邮件

截至 2024 年 2 月，所有 Klaviyo 电子邮件编辑器（即拖放编辑器、混合编辑器、纯文本编辑器和自定义 HTML 编辑器）均支持所有表情符号。 ## 其他资源
