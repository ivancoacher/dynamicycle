## ****你会学到****

了解 Klaviyo 即将升级到电子邮件模板中使用的[纯文本编辑器](https://help.klaviyo.com/hc/en-us/articles/12415384810651)，包括更改内容、预期内容以及如何准备。 ## ****概述****

Klaviyo 正在升级电子邮件模板中使用的纯文本编辑器。此更改提高了电子邮件内容处理方式的可靠性和一致性，并引入了新功能，包括 Django 标签生成器，这是一种用于向电子邮件添加动态标签的可视化工具。作为此次部署的一部分，Klaviyo 将开始为一部分帐户启用新编辑器，并随着时间的推移逐步扩大访问范围。在对您的帐户进行任何更改之前，您会收到提前通知。 ## ****发生了什么变化****

**纯文本编辑器**** 是编辑电子邮件的纯文本版本时使用的编辑界面。此次升级将底层编辑器替换为改进的版本，可以更一致地处理您的电子邮件内容并添加新功能。 ## ****对现有模板的影响****

对于几乎所有帐户，此更改将是无缝的，与您的模板没有视觉差异。升级后，少数模板可能会出现细微的视觉或布局差异。在极少数情况下，具有复杂内容（例如自定义样式、表格或嵌入样式标签）的模板可能无法完全转换，您可以选择将其转换为 HTML 模板，从而保留您的内容，同时让您可以直接控制代码。 ## ****预览文本****

使用我们之前的纯文本编辑器，预览文本必须通过将其添加为 HTML 来手动更新。在我们新的纯文本编辑器中，编辑器内将有一个专用的输入字段，用于添加和编辑预览文本。如果此字段留空，则预览文本将自动设置为实际电子邮件内容的前几个字符。还可以选择完全隐藏预览文本，使其在收件人的收件箱中显示为空白。 ## ****什么没有改变****

- 您的电子邮件设计和内容将在整个过程中保留。 - 您可以像今天一样在纯文本编辑器中继续构建和编辑电子邮件。 - 如果您的模板转换为 HTML 模板，您的内容将保持不变并可以直接编辑。 ## ****关于源代码查看****

作为此升级的一部分，****源代码视图将从纯文本编辑器中删除****。如果您需要在电子邮件中使用自定义 HTML，请使用为此目的设计的专用 ****HTML 模板****。 HTML 模板使您可以完全控制代码。如果您想在纯文本电子邮件中添加和编辑 Django 标签，您可以使用新的 ****Django 标签生成器**** 来完成此操作，而无需编写任何代码。 ## ****推出期间会发生什么****

升级将分阶段进行。该过程如下所示：

1. ****提前通知**** — 在对您的帐户进行任何更改之前，您将通过应用内横幅收到至少 2 周的通知。 2. ****逐步推出**** — 更改将在两周内逐步向帐户推出。 3. ****自动模板转换**** — 当您的帐户升级时，Klaviyo 会自动将您现有的纯文本模板转换为新编辑器。 ****HTML 模板后备**** — 对于包含新编辑器无法自动处理的内容的少量模板（例如表格或自定义样式标签），您可以选择继续进行文本编辑器升级，或将整个模板转换为 HTML 以保留您最初设计的所有现有内容。发生这种情况时，您将看到应用内通知，并且您将能够预览以前的版本与新版本。 ## ****如何准备****

在升级到达您的帐户之前，最好查看纯文本模板，其中可能包括：

- ****自定义 HTML 或内联样式标签****
- ****表格****
- ****大量定制的格式****超越标准文本样式

对于此类别中的模板，请考虑主动将内容迁移到 HTML 模板，或简化格式以使其能够干净地转换。 ## ****其他资源****
