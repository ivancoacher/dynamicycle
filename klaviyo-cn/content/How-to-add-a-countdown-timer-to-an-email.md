## 你将会学到

了解如何使用倒计时器为您的电子邮件增添紧迫感。这些对于闪购、特别促销或节日信息特别有效。 Klaviyo 没有内置倒计时器功能，因此您需要使用第三方工具，例如 [MailTimers](https://mailtimers.com/)。

## 生成一个倒计时器

在此示例中，我们将使用通过 [MailTimers](https://mailtimers.com/) 生成的倒计时器。您可以使用任何提供 HTML 的倒计时器生成器，您可以将其复制并粘贴到电子邮件模板中。

1. 使用 MailTimers 创建帐户。
2. 单击****创建计时器****。
3. 在**事件日期和时间字段**中选择您想要倒计时的日期和时间。
4. 根据需要调整计时器的外观，然后单击****保存****。
5. 单击****复制嵌入代码****。
   ![MailTimers 中的计时器嵌入代码](https://klaviyo.zendesk.com/hc/article_attachments/28717849491867)

需要更多帮助来生成倒计时器吗？前往 [MailTimers 的支持文档](https://mailtimers.com/how-to)。

## 在电子邮件中添加倒计时器

创建计时器并复制嵌入代码后，您就可以将其添加到电子邮件中。

1. 打开任何现有电子邮件（即模板、未发送的电子邮件营销活动或流电子邮件）。
2. 将 HTML 块添加到您的模板中。
   ![HTML 块](https://klaviyo.zendesk.com/hc/article_attachments/29553534264347)
3. 删除 HTML 块中的任何现有代码。
4. 粘贴​​您从上一节复制的代码。
   ![包含复制代码的 HTML 块](https://klaviyo.zendesk.com/hc/article_attachments/29553534276123)
5. 单击后退箭头应用更改。
   ![电子邮件中倒计时器的示例](https://klaviyo.zendesk.com/hc/article_attachments/28717849497883)

## 收件箱支持倒计时器

大多数电子邮件收件箱都支持倒计时器。但是，倒计时器可能无法在 Apple Mail 中正确呈现。这是因为 Apple Mail 通常会在打开电子邮件之前预加载电子邮件，这可能会导致收件人打开邮件时倒计时器显示不正确的时间。

此外，早期版本的 Outlook（2007、2010 和 2013）不支持 GIF，只会显示 GIF 中的第一帧。
