## 你将会学到

如果您在电子邮件模板中遇到错误或警告，您可能需要在发送消息之前解决它们。在此资源中搜索您遇到的错误消息或警告，以查找解决问题的提示。 ## 活动发送警告

- ****我们在您的电子邮件中发现 # 个块，其中默认文本仍然未修改或为空白。请在继续之前查看您的电子邮件。****
  如果您遇到此警告，请在模板中查找空块或占位符内容（例如，“这是一个文本块。单击此处对其进行编辑。”）。检查模板的桌面版和移动版。如果您找不到空块或占位符内容，请向自己发送预览消息并在桌面和移动设备上查看。如果预览看起来不错，则可以安全地发送消息并忽略此警告。 - ****可能的电子邮件内容问题。您的电子邮件中似乎没有任何链接。您是否忘记将它们添加到您的电子邮件中？****
  如果您的纯文本或自定义 HTML 电子邮件不包含任何链接，则会出现此警告。查看消息以确保已添加所有内容，包括任何号召性用语的链接。如果您不想在电子邮件中包含任何链接（取消订阅链接除外），则可以忽略此警告。 - ****取消订阅链接。我们在您的电子邮件中找不到取消订阅链接。如果您不添加，Klaviyo 会在发送电子邮件时自动添加取消订阅链接。****
  如果您尚未在邮件中添加取消订阅标签（例如，{% unsubscribe %} 或 {% unsubscribe\_link %}），则会出现此警告。 [添加取消订阅链接](https://help.klaviyo.com/hc/en-us/articles/115006054267-How-to-Add-an-Unsubscribe-Link-to-Email-Campaigns)以避免将 Klaviyo 的默认页脚附加到您的消息中。 ## 预览错误

预览消息时，您可能会遇到以下错误消息：

****显示的消息不带标签或变量****
****修复无效的模板标签或变量以预览具有实际配置文件和事件的消息。****

此错误意味着您的消息中某处存在无效语法。要找到错误的根源，请检查邮件的主题行和正文内容中是否存在不符合 [Klaviyo 帮助中心资源](https://help.klaviyo.com/hc/en-us/articles/115005084927) 中概述的格式的变量、标签或条件语句（即模板中用大括号 **{}** 括起来的任何内容）。以下是一些定位错误的提示：

- 检查您的消息的桌面版和移动版。 - 如果您的消息包含[动态优惠券](https://help.klaviyo.com/hc/en-us/articles/115005084727-How-to-Use-Coupon-Codes-in-Klaviyo)，请确保优惠券名称正确，并且您的优惠券已在 **优惠券** 选项卡中配置。 ## 自定义 HTML 模板错误

- ****我们找不到以下图像：...确保它们包含在您上传的 zip 文件中。****
  检查您是否正确拼写了所有图像源路径，并且它们是否与您上传的图像的文件名匹配。如果错误消息中未提供图像路径，请检查 HTML 文件中是否有空背景属性（例如 **background=””**）
- ****需要一个 {% unsubscribe %} 标签。****
  将 [Klaviyo 取消订阅标签](https://help.klaviyo.com/hc/en-us/articles/115005078267) 添加到消息页脚以解决此错误。 - ****无法解析余数：“XYZ”中的“Z”。****
  此错误意味着 Klaviyo 无法识别您的标签之一（任何被 {% %} 包围的标签）。请参阅我们的[消息个性化参考](https://klaviyo.zendesk.com/hc/en-us/articles/4408802648731)指南以查看接受的标签。 ## 目录错误

如果您的模板使用[目录查找标签](https://klaviyo.zendesk.com/hc/en-us/articles/360004785571)，您可能会遇到错误****无法找到代码为：\_\_的项目。它可能已被删除。****

如果您看到此错误，则意味着我们无法识别选项卡中包含的项目 ID。确保：

- 您正在预览包含项目 ID 的事件（如果项目 ID 动态引用事件数据）。 - 对事件数据的项目 ID 的引用格式正确。 - 您的活动数据中的商品 ID 与您的 Klaviyo 目录中的商品 ID 相匹配。 ## Shopify 模板错误

- { % for item in... - {% endfor %}
- {% 如果... - {% elsif... - {%其他%}
- {% endif %}

- ****Body html Liquid 语法错误：未知标签“取消订阅”****
  ****正文 html Liquid 语法错误：未知标签“web\_view”****

  ****正文 html Liquid 语法错误：“if”标签从未关闭****
