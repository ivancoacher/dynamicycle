## 你将会学到

了解如何在需要时向电子邮件添加栏以使您的模板更加美观。有几种方法可以将列添加到模板中。本文将介绍向电子邮件添加栏的所有方法以及如何根据设备优化设计。

## 何时使用分割块、列或表

使用 Klaviyo 的电子邮件编辑器可以通过 3 种方式并排排列内容：分割块、列和表格块。每个选项都有一定的优点和权衡。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| ****内容布局**** | ****列数**** | ****宽度选项**** | ****允许的内容类型**** | ****列可以在移动视图上堆叠吗？**** |
| ****分割块**** | 2 |精确控制（使用 **拆分设置 > 列宽**）|仅图像或文本 |是的 |
| ****专栏**** | 1-4 | 1-4选择有限|任何类型的内容块（例如文本块、图像块、评论引用块）|是的 |
| ****桌块**** |任意数量 |精确控制（使用**列宽** > **手动**）|仅图像或文本 |没有 |

表格对于可访问性来说可能具有挑战性，因为屏幕阅读器很难解析它们。

## 在电子邮件中添加分割块

要将分割块添加到电子邮件：

1. 将 **Split** 块拖到您的模板中。
2. 调整 **布局** 百分比以自定义 2 列的宽度。
3. 在**内容**部分中，选择分割块的每一侧是否应包含文本或图像。
4. 单击**列选择器** 下的图标可在列之间切换。
5. 单击****保存**** 保存该块。

## 将列添加到电子邮件

要将列添加到电子邮件：

1. 拖入**布局**下的**列**选项，以在电子邮件中创建列。
2. 从模式中的选项中选择您所需的布局。
3. 将任何类型的块拖到您的列中。

与分割块不同，您可以使用任何块，在同一列中具有多个块，并选择具有两列以上。例如，这是一封一侧带有图像、另一侧带有文本和按钮的电子邮件。

![左侧为文本和按钮、右侧为图像的列示例](https://klaviyo.zendesk.com/hc/article_attachments/28720621027995)

此外，当移动浏览器打开电子邮件时，各列将相互堆叠，左侧堆叠在右侧顶部。如果您不希望将列堆叠在移动设备上，请[选择使用表格块](https://help.klaviyo.com/hc/en-us/articles/115000807711#table-block3)。

## 将表块添加到电子邮件中

您可以使用表格块在电子邮件中创建列。虽然表格块只能包含文本和图像，但它们允许您通过在移动设备上维护并排列来自定义电子邮件的列。就像任何块一样，将表格块拖放到您的电子邮件中即可开始。

要更改表格块的外观，请转到块设置，您可以在其中调整列周围的填充或间距以及边框颜色和字体。

要优化移动体验，请测试表格的移动视图。如果您有一个包含许多列的表格，它可能只在桌面上看起来很理想。要更改或隐藏移动设备的列，请调整列选项卡中的设置。
