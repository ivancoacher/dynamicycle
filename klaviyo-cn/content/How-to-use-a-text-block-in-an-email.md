## 你将会学到

了解如何在 Klaviyo 的电子邮件模板编辑器中使用文本块，包括如何设置文本块的样式、添加个性化标签以及使用 AI 起草和修改您的副本。 ## 添加文本块到模板

1. 在电子邮件模板编辑器中，找到 **内容** 下的 **文本**** 块。 2. 将块拖到电子邮件画布中并将其放在您希望其显示的任何位置。 ![用户拖动文本块并将其放入画布中](https://klaviyo.zendesk.com/hc/article_attachments/32200923731611)
3. 双击文本字段开始编辑文本。如果您在 Klaviyo 编辑器之外（例如，在 Google Docs 或 Microsoft Word 中）编写副本，请确保在将文本粘贴到编辑器中时粘贴为纯文本。使用 Command+Shift+V (Mac) 或 Ctrl+Shift+V (Windows) 以纯文本形式粘贴。否则，某些样式标签将与文本一起粘贴，这可能会导致设计问题。 ## 使用AI修改内容

Klaviyo 的人工智能修改工具可以帮助解决作家的障碍、改进现有草稿或针对不同受众调整文案。此功能仅适用于付费帐户。 1. 在任何模板中，选择包含您编写的文本的文本块。 2. 单击****修改文本****。 ![AI 修改文本按钮](https://klaviyo.zendesk.com/hc/article_attachments/32200923734171)
3. 编写您自己的提示或从默认选项中进行选择。 ![文本修改提示选项](https://klaviyo.zendesk.com/hc/article_attachments/32200938549019)
4. 选择****生成****。 5. 在 3 个生成的选项之间切换。 6. 选择要使用的选项后，单击****插入****。 ## 设置文本块的样式

有两种方法可以设置文本块的样式：

- [使用电子邮件的****样式****选项卡](#h_01JFWG39EDKM7KAJX700RVK1B8)，为整个电子邮件设置默认样式（推荐）
- [使用块的格式化菜单](#h_01JFWG39EDCTPGX7C33BEVJBY0)

最佳做法是，首先使用****样式****选项卡将格式应用于所有块，然后根据需要在各个块中进行细微调整。遵循此过程会导致：

- 更容易重复使用的电子邮件设计
- 较低的代码重量（即，[电子邮件剪辑](https://help.klaviyo.com/hc/en-us/articles/115000591251)的可能性较小）
- 风格更加一致，手动编辑更少

### 应用电子邮件级别样式

1. 导航至主****样式****选项卡。 ![主样式选项卡](https://klaviyo.zendesk.com/hc/article_attachments/32200938550299)
   - 您可能首先需要单击后退箭头退出当前正在编辑的块。主 **样式** 选项卡与块的 **样式** 选项卡不同。 ![文本块的“样式”选项卡](https://klaviyo.zendesk.com/hc/article_attachments/32200938550683)
2. 滚动到**文本和标题**。 ![文本和标题部分](https://klaviyo.zendesk.com/hc/article_attachments/32200923739163)
3. 选择 **正文** 文本的设置（即默认段落格式）。 4. 从菜单中选择不同的文本样式（例如，标题 1、标题 2 等）并为其选择样式。 ![文本样式下拉菜单](https://klaviyo.zendesk.com/hc/article_attachments/32200923739931)
5. 对所有文本样式重复此过程。作为最佳实践，请使用：
   - **正文** 适用于大部分文本
   - **标题 1** 用于最重要的标题
   - **标题 2** 用于副标题
   - 等等 ### 应用块级样式

1. 选择电子邮件中的文本块。 2. 双击文本字段以打开样式菜单。 3. 突出显示您要调整的文本。您可以突出显示块中的所有文本，或仅突出显示其中的一部分。 4. 在画布顶部的格式栏中，选择文本样式（例如正文、标题 1）以应用您在主 **样式** 选项卡中设置的样式，或手动选择字体、字体大小、颜色等。 ![其他文本格式选项](https://klaviyo.zendesk.com/hc/article_attachments/32201199886363)

## 为电子邮件添加个性化设置

个性化标签是与订阅者联系的好方法，让每封电子邮件都显得有意而独特。添加个性化标签：

1. 添加文本块或在电子邮件模板中找到现有文本块。 2. 双击打开格式化菜单。 3. 单击菜单右侧的个性化图标。 ![个性化图标](https://klaviyo.zendesk.com/hc/article_attachments/32200923747483)
4. 使用 **所有类型** 菜单选择类型（例如，配置文件、组织等）、按属性名称搜索或滚动选项。 5. 选择个性化标签。 6. 在 **设置** 模式中，可以选择添加默认值并选择大写。 7. 单击****插入****。个性化菜单提供某些有限的个性化选项。要添加更复杂的个性化（例如，事件数据、目录标签等），请详细了解[消息个性化](https://help.klaviyo.com/hc/en-us/articles/4408802648731)。 ## 文本块和 RTL 语言

要以使用从右到左 (RTL) 脚本的语言（例如希伯来语）添加副本，请将以下代码片段添加到模板顶部的 HTML 块中：

````
<样式类型=“文本/css”>
      p, h1, h2, h3, h4, ol, li, ul { 方向：rtl; }
</风格>
````

这会将 RTL 格式应用于电子邮件中的所有文本块。 ## 支持的字符

Klaviyo 的电子邮件编辑器使用 UTF-8 编码标准，这意味着它支持拉丁字符、表情符号、双字节字符等。 ## 其他资源
