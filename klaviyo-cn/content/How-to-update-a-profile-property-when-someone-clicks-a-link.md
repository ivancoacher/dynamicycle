## 你将会学到

了解如何使用按钮构建电子邮件模板，这些按钮根据订阅者单击的选项用信息标记他们。当他们单击链接时，您可以使用此过程添加配置文件属性。 SMS/MMS 消息当前不支持此过程。 ## 通过链接收集信息的用例

在 Klaviyo 中，您可以使用链接或按钮自动从电子邮件收件人收集信息。例如：

- 在您的新闻通讯活动中，添加按钮，让用户指定每周希望收到您发送的电子邮件的次数。 - 在发给新客户的感谢电子邮件中，提示收件人更新性别等个人资料详细信息。 - 在赢回电子邮件中，提示客户选择他们最有兴趣了解更多信息的产品类别。 ## 添加更新配置文件属性的按钮或链接

请注意，当您添加可更新配置文件属性的按钮或链接时，收件人只能选择一个值。如果他们已经具有属性集的值，则他们的选择将覆盖现有值。这包括具有列表数据类型的属性：整个列表将被覆盖，并且不可能简单地将列表项附加到现有列表。使用下面提供的代码片段时，请确保使用直引号 (') 而不是弯引号 (')，以确保代码正确呈现。这可以通过复制下面的代码并使用“粘贴为纯文本”功能（Ctrl+Shift+V 或 Cmd+Shift+V）将其直接粘贴到模板中来实现。 ### 按钮

1. 前往您要使用的电子邮件模板。 2. 在电子邮件模板中添加按钮。 3. 单击要添加此功能的按钮。 4. 在 **URL** 字段中输入以下内容：

   ````
   {% update_property_link 'profile_property' 'property_value' 'redirect_link' %}
   ````
5. 更改代码的每个部分以反映：
   - ****'profile\_property'****：您想要更新或创建的配置文件属性；例如，最喜欢的\_颜色。 - ****'property\_value'****：特定按钮对应的值；例如，蓝色。 - ****'redirect\_link'****：您希望他们在单击按钮后重定向到的 URL。这些字段不支持动态内容或 unicode 字符。仅支持标准 URL（即格式为 https://www.klaviyo.com）。此代码适用于您通常添加链接的任何地方。为获得最佳结果，属性值应为文本或数字。请注意，如果已为特定收件人设置此属性，则当他们单击按钮时，该属性将被覆盖。 ### 链接文本

1. 导航到您要使用的电子邮件模板。 2. 突出显示您要链接的文本。 3. 单击文本编辑器中的超链接图标。 ![文本字段中的超链接图标](https://klaviyo.zendesk.com/hc/article_attachments/28720668080411)
4. 在 **URL** 字段中输入以下内容。 ````
   {% update_property_link 'profile_property' 'property_value' 'redirect_link' %}
   ````
5. 更改代码的每个部分以反映：
   - ****'profile\_property'****：您想要更新或创建的配置文件属性；例如，最喜欢的\_颜色。 - ****'property\_value'****：特定按钮对应的值；例如，蓝色。 - ****'redirect\_link'****：您希望他们在单击按钮后重定向到的 URL。 ## 使用链接收集信息的示例

假设我们想通过询问订阅者是否喜欢蛋糕或馅饼来收集他们的甜点偏好信息。要创建此调查：

1. 将“profile\_property”设置为 **dessertsurvey**。 2. 将“property\_value”更改为 **pie**。 3. 将链接重定向到感谢页面。在这种情况下，我们的代码如下所示。 ````
{% update_property_link 'dessertsurvey' 'pie' 'http://www.your-website.com/survey_response' %}
````

每当有人单击“pie”按钮时，它都会将“dessertsurvey”配置文件属性更新为“pie”，然后转到您创建的感谢登陆页面。 ![饼图按钮调查链接](https://klaviyo.zendesk.com/hc/article_attachments/28720656278939)

现在我们已经从客户那里收集了数据，我们可以在电子邮件中使用它。此数据的存储方式与常规客户属性一样，可用于创建使用这些属性作为定义中的条件的分段、按不同属性拆分流以及使用此数据对消息进行个性化设置。 ## 测试并查看您的结果

要测试新按钮的功能，请将消息保存为模板并[将其作为个人电子邮件发送给自己](https://klaviyo.zendesk.com/hc/en-us/articles/115005246328)。如果您发送预览而不是个人电子邮件，按钮/链接将定向到占位符页面，并且不会更新您的个人资料。一旦有人点击实时电子邮件中的更新属性链接，他们的回复就会存储在他们的个人资料中。您可以导航到个人资料以查看个人的回复，也可以创建一个细分来识别单击特定选项的每个人。 {% update\_property\_link ... %} 按钮或链接不支持 UTM 参数。如果您为此消息启用了 UTM 参数，它们将不会附加到最终的动态链接中。作为解决方法，您可以在 **redirect\_link** 字段中手动包含 UTM 参数。 ### 查看个人结果

要查看某人在其个人资料中选择了哪个选项：

1. 使用电子邮件地址或姓名在 Klaviyo 中搜索个人资料。 2. 单击结果中的配置文件以查看所有详细信息。 3. 找到配置文件的 **自定义属性** 部分。 4. 在更新属性链接中找到配置文件属性集（上例中的“dessertsurvey”）。 5.记下该财产的价值（例如“蛋糕”）。 ### 根据答案创建一个细分

要创建单击更新配置文件属性链接或按钮的所有配置文件的分段：

1. 导航至****列表和段****页面。 2. 单击****创建列表/细分****，然后单击****细分****。 3. 在 **维度** 字段中，选择您的配置文件属性，然后在 **维度值** 字段中添加您的属性值。 ![调查链接段](https://klaviyo.zendesk.com/hc/article_attachments/28720656287643)
4. 最后，单击****创建细分****，为单击更新属性链接/按钮的每个人生成细分。 ## 其他资源
