## 你将会学到

了解如何同时使用短信、电子邮件和推送通知，包括每个渠道的独特之处、首先发送的内容等等。 ## 每个通道的差异

****电子邮件****

电子邮件的存在时间最长，感兴趣的网站访问者通常愿意向公司发送电子邮件。它也没有任何特定于频道的技术要求，因此开始收集订阅者和发送订阅者很简单。 |  |  |
| --- | --- |
| ****积极**** | ****负面**** |
|拥有最大的影响力。 |并非所有收件人都会阅读电子邮件。 |
|可以最常发送。 |它的参与率最低。 |
|对于所有企业来说，这是最简单且通常最实惠的入门方式。 |人们打开邮件也需要更长的时间，因此电子邮件不适合传递关键或时间敏感的信息。 |
|允许多种消息（销售、信息等）。 |  |

****短信****

SMS 是一种相对较新的消息传递渠道，但增长迅速。它的受欢迎程度因国家而异，但短信正变得越来越普遍和接受，越来越多的人愿意向企业提供自己的电话号码。 |  |  |
| --- | --- |
| ****积极**** | ****负面**** |
|它会立即到达订阅者，消息一送达就直接 ping 收件人。 | SMS 具有具体且严格的[合规性要求](https://help.klaviyo.com/hc/en-us/articles/7956171032091)，这可能会让入门变得令人生畏。 |
|它是会话式的、随意的，并且可以让您更加个性化地发送消息。 |与电子邮件相比，短信通常是一种更昂贵的消息传递渠道。 |
|短信往往比电子邮件具有更高的参与度和转化率。 |与其他渠道相比，列表增长和覆盖范围最慢且最小。 |
|某些行业 (SHAFT) 无法使用短信营销来接触其客户。了解[短信禁止行业](https://help.klaviyo.com/hc/en-us/articles/4401822831771)。 |  |

****推送通知****

推送通知的一个独特之处在于，订阅者往往认为它们很有帮助，而不是纯粹以销售为中心。它们通常会提醒订阅者如何充分利用您的应用程序，无论是实现个人目标还是找到最优惠的价格。然而，如果订阅者超载或者通知不相关，这种看法可能会改变。 |  |  |
| --- | --- |
| ****积极**** | ****负面**** |
|推送是即时且直接的，让您可以直接在锁定屏幕上联系客户。 |您需要一个应用程序来使用推送，使其更适合大中型企业而不是刚刚起步的公司。 |
|推送被认为比 SMS 具有更少的侵入性，因为可以在不中断用户当前活动的情况下传递消息。 |推送通常没有短信或电子邮件那么大的覆盖范围，因为用户需要下载移动应用程序并选择接收通知。 |
|与 SMS 不同，推送并没有受到严格的监管，因此更多的公司（包括 SHAFT 行业的公司）有资格使用此渠道。 |推送消息一旦打开或关闭就会消失，因此无法像电子邮件和短信那样重新访问。 |
|推送的主要目的是让人们进入您的应用程序，通常被认为比电子邮件或短信更有帮助。 |  |

## 收集订阅者

在扩大列表时，重要的是要考虑如何一起使用所有渠道。这不仅包括您拥有的渠道（如电子邮件、短信和推送），还包括社交媒体。对于电子邮件和短信，您可以通过多种方式使用表单或订阅页面。例如，它们可以直接位于您的网站上，但您也可以通过二维码、社交媒体帖子、电子邮件横幅等链接到它们。至于推送，获得同意的唯一方法是在您的应用程序中。但是，您可以使用与电子邮件和短信相同的方法鼓励人们下载您的应用程序。例如，它可以将用户带到您的应用列表，而不是链接到注册表单的二维码。 ****针对谁****

关键是针对可能有兴趣注册多个渠道的人群，例如：

- 贵宾
- 新订阅者
- 最近的购买者
- 补货订户
- 您试图赢回的订阅者或客户（看看他们是否想通过不同的渠道收到您的消息）
- 购物促销的人（通过其他渠道告诉他们您的优惠）
- 移动用户（短信或推送）

****获得同意的技巧****

每当您寻求同意时，请明确每个渠道的不同之处及其提供的好处。您可以：

- 为注册提供特殊奖励。 - 游戏化注册。 - 创建短信关键字作为特殊折扣隐藏搜索的一部分。 - 根据人们订阅的频道数量来奖励他们。 - 包括一种在访问者可以从订阅中受益的时刻选择加入的方式（结账时、订阅缺货提醒时、促销或活动启动时等）。 - 鼓励现有电子邮件或短信订阅者下载您的移动应用程序并注册更新。奖励：针对 VIP，将推送视为专属渠道。 ## 定位您的订阅者

无论通过何种渠道，您都希望您的消息具有个性化的感觉。您可以为每个通道制作相同的分段，然后调整标准：

- 所有订阅者
- 订阅 1 个频道（电子邮件、短信或推送通知）
- 贵宾
- 性别
- 年龄
- 地点
- 偏好、兴趣或爱好
- 1 个频道已参与/未参与

  重新创建分段时，请注意通道之间的分段不应相同。 - 短信和推送通知段的时间范围应比电子邮件短。 - 推送可以包含自定义指标（例如，在应用程序上处于活动状态），具体取决于您的设置。 - 主要参与度指标因渠道而异：
  - 电子邮件使用打开率或点击率。 - SMS 使用点击率。 - 推送通知使用打开率。 ## 向所有 3 个频道发送消息

如果您使用全部 3 个通道，您不希望同时发出多条消息。想象一下，如果同时收到来自同一家公司的电子邮件、短信和推送通知，那将是多么奇怪。选择优先发送到的频道。几个小时后通过其他渠道进行跟进，确保排除任何收到较早消息的人。假设您的应用和网站正在进行冬季促销，活动将于中午 12 点开始。下表显示了如何通过您拥有的渠道定位不同群体的示例。 |  |  |  |  |
| --- | --- | --- | --- |
| ****频道**** | ****时间**** | ****观众**** | ****留言详情**** |
|推 |中午12点|所有推送订阅者 | “抢先为冬天备货。高达 30% 折扣！” |
|短信|下午 1 点| SMS 订户，不包括推送订户 | “这个冬天感觉温暖舒适。现在到周日均可享受 30% 的折扣。” |
|电子邮件 |下午 4 点 |参与的订阅者，不包括过去 4 小时内购买的任何人。 | “这些冬季优惠正在升温” - 包括产品照片、有关商品的更多信息和评论。 |

## 最佳实践：通用链接和应用程序链接

通过电子邮件和/或短信发送消息时，我们建议使用通用链接和应用程序链接。这些链接会将您的客户引导至您的移动应用程序中的内容，或者如果未安装该应用程序，则引导至您网站上的相同内容。这使您可以在所有营销渠道中使用一致的 URL，同时为您的客户（无论他们使用什么设备）创建无缝体验。详细了解[如何设置 iOS 通用链接和 Android 应用程序链接。](https://help.klaviyo.com/hc/en-us/articles/41701832186523)
