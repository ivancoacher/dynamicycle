## 你将会学到

熟悉移动推送通知，包括它们的含义、外观以及您需要开始发送哪些信息。 ## 什么是推送通知？首先，让我们澄清一下推送通知的含义，因为实际上有两种类型：

1. ****移动推送通知****是由移动应用程序发送给用户的消息，通常显示在移动设备的锁定屏幕上。 2.****网络推送通知****，也称为“浏览器通知”。这些由网站发送到浏览器，即使该网站未打开也可能显示。 Web 推送通知可在桌面和移动设备上使用。 Klaviyo 目前不支持网络推送，尽管您可以[通过 API 调用触发网络通知](https://medium.com/klaviyo-developers/solution-recipe-25-how-to-trigger-web-push-notifications-through-klaviyo-14a8361eb9f4)。在这两种情况下，通知都会显示为可点击的消息，将用户直接带到应用程序或网站。这两种类型经常被一起谈论；然而，它们实际上在设置、要求甚至外观方面都截然不同。在这里，我们只关注一种类型的推送通知：移动。 ### 如何使用移动推送通知？移动推送通知对于吸引人们使用您的应用程序非常有效。就像短信一样，应用程序用户几乎总是会看到推送通知。不同之处在于推送通知是：

- 通常被认为不太受收件人的销售驱动
- 在更广泛的用例中提供帮助
- 通常发送费用较低

  移动推送通知非常适合：
- 提醒（例如，锻炼、练习语言、观看表演）
- 仅限应用程序的交易或收藏
- 时间敏感的警报
- 产品提醒
- 询问信息（例如“填写您的个人资料”）

有人必须打开应用程序通知才能接收推送通知。 ![应用程序的选择加入消息示例](https://klaviyo.zendesk.com/hc/article_attachments/28720762464795)

### 我应该多久发送一次移动推送通知？答案取决于应用程序用户需要通知的频率。以下是一些示例：

- 健康、保健或教育品牌可能会发送每日提醒（例如，吃药、锻炼、学习等）。 - 对于服装和配饰公司来说，这可能取决于顾客购物的频率：
  - 对于频繁和高价值的购物者，每周或每两周一次。 - 每月向所有其他客户提供。 - 大多数可能每周或每两周发送一次。 - 奢侈品牌可能会按受众划分发送内容。 - 家具店可能会降低发送推送通知的频率：例如，在新产品发布或假期时。不过，通常每周发送的推送通知不要超过 3-5 次，除非您看到客户的参与度很高。发送超过此数量可能会使订阅者超载并导致他们取消订阅。 ## 推送通知的结构

让我们来看看推送通知发送时的结构。下面是 Android 推送通知的示例，尽管 iOS 通知看起来类似。从左到右：

1. 应用标志
2. 标题
3. 时间戳
4. 消息正文
5. [富媒体](https://help.klaviyo.com/hc/en-us/articles/16917302437275)

   - Android：仅图像
   - iOS：图像或 GIF
6. 箭头展开

![Android 设备锁定屏幕上显示的推送通知示例](https://klaviyo.zendesk.com/hc/article_attachments/28720762467739)

请注意，通知的外观会根据是否附加图像或 GIF、消息的长度以及收件人的设备而变化。 ### 字符限制

作为一般规则，您希望保持推送通知清晰简洁。如果超出字符限制，您的移动推送通知可能会被切断，并且收件人将看不到完整的消息。为了避免这种情况，您需要遵守以下字符限制。但是，请记住，限制可能会有所不同：

- 手机的软件版本（例如，旧版本可能比新版本允许更多字符，反之亦然）。 - 留言内容：
  - 表情符号比普通字符占用更多空间
  - 当您包含富媒体时，推送通知往往会显示更少的字符。 |  |  |  |

## 发送推送通知需要什么

推送通知营销首先需要的是应用程序。 如果您还没有应用程序，我们建议[联系开发人员](https://connect.klaviyo.com/) 或其他第三方为您创建一个应用程序。开发人员通常需要设置推送通知以及您的应用程序。要将您的应用程序与推送提供商连接，必须有人使用 SDK（推荐）或创建自定义集成。 ****什么是 SDK？****

SDK代表软件开发工具包，它是一组用于为特定平台或服务开发应用程序的工具、库和程序。基本上，它是开发人员的工具包，用于将应用程序与任何其他平台（例如 Klaviyo）连接。 ### 决定你想要什么功能

应用程序必须能够实际发送推送通知。最基本的要求是推送的标题和消息正文。但是，您可能需要与应用程序开发人员合作来包括其他可选功能：

- ****富媒体****
  允许您在推送通知中包含图像和（对于 iOS）GIF。 - ****深度链接****
  深层链接是直接链接到应用程序中页面的能力。如果没有深层链接，所有推送通知都会将收件人带到应用程序的主屏幕。对于深层链接，您的开发人员需要为您的应用程序提供 URI 方案。这是您的应用程序自定义的，但您的开发人员可以帮助您获取这些链接。此外，您可能需要考虑要在推送通知中使用哪些信息。您的开发人员在设置应用程序和推送提供商之间的连接时需要包含这些内容。例如，一些有用的自定义指标是：
- **打开的应用程序**
- **完成的个人资料**
- **设置商店位置**

### 向您的推送提供商提供关键信息

在应用程序中完成所有设置后，您必须将其连接到推送提供商。为此，您必须提供有关您的应用程序的某些信息。虽然根据提供商的不同，要求可能会略有不同，但下表显示了您在 Klaviyo 中需要的内容，其他提供商应该类似。您可能需要与应用程序开发人员合作才能获取此信息。 |  |  |
| --- | --- |
| ****平台**** | ****必填信息**** |
| [Android](https://help.klaviyo.com/hc/en-us/articles/14750928993307) |包名、Google服务认证密钥（JSON私钥文件）|
| [iOS](https://help.klaviyo.com/hc/en-us/articles/360023213971) | APNs 身份验证密钥（通过 .p8 证书）、密钥 ID、团队 ID、捆绑 ID |

请注意，如果您的应用程序同时在 Apple App 和 Google Play 商店中列出，则您必须分别进行设置。 ### 通过您的推送令牌进行测试

****什么是推送令牌？****

推送令牌是一个唯一的匿名 ID，用于识别特定设备上的特定应用程序，由 Apple 推送通知服务 (iOS) 或 Firebase 云消息传递 (Android) 生成。无论您使用哪个推送平台，该应用程序和设备组合的令牌都将是相同的。连接应用程序和推送平台后，测试以下内容非常重要：

- 您的应用程序可以发送推送通知。 - 推送通知可以深层链接或包含媒体（如果您打算使用这些功能）。 - 您的推送提供商正在正确接收来自您的应用程序的信息。有关操作的详细信息，请参阅以下部分。 #### 选择推送

1. 从您的个人设备打开您的应用程序。 2. 选择推送通知。如果系统没有自动提示您启用推送，请进入您的应用程序设置并打开通知。 #### 创建一个列表来测试您的推送通知

1. 前往您的推送提供商。这里，我们以 Klaviyo 为例。 2. 创建一个列表以通过以下方式预览推送通知：

   - 导航至****受众 > 列表和细分 > 新建 > 创建列表****。 - 为列表命名（例如“推送预览”）并选择****创建列表****。 3. 找到您的推送令牌。在 Klaviyo 中，导航至****受众 > 个人资料****，然后搜索您的个人资料，或查看最近更新的个人资料。 ![在accpimt中搜索最近的推送配置文件](https://klaviyo.zendesk.com/hc/article_attachments/28720762463259)
4. 单击进入该配置文件。 5. 转到配置文件中的****列表和分段****选项卡，然后单击****添加到列表****。 ![配置文件中的列表和分段选项卡，显示将该配置文件添加到列表的选项](https://klaviyo.zendesk.com/hc/article_attachments/28720762474395)
6. 找到您创建的列表，然后选择****添加到列表****。 如果您同时拥有 Android 和 iOS 应用程序，我们建议将每种类型设备的推送令牌添加到预览列表中。这将使您能够看到推送通知在两个系统上的显示方式，因为它们看起来往往略有不同。 #### 执行测试和检查

我们建议[执行多个单独的测试](https://help.klaviyo.com/hc/en-us/articles/18011985278875)：

1. 发送简单的推送通知（即仅内容）。 2.添加图片测试丰富推送。 3. 包含深层链接。另外，进入您的应用程序并单击以测试您的自定义指标（例如，如果您为 **完成的个人资料** 添加了自定义指标，请在应用程序中填写您的个​​人资料）。然后，返回到您的推送提供商以查看这些指标和事件是否已正确记录。 ## 其他资源
