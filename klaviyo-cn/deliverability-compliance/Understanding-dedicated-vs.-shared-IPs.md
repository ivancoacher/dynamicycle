## 你将会学到

详细了解专用 IP 与共享 IP、它们的优点和缺点，以及如何在发送基础设施中使用 IP。请注意，专用 IP 仅适用于符合条件的帐户。要了解您是否有资格获得专用 IP，请联系您的客户成功经理以获取更多信息。有关计划和成功支持的更多信息，请参阅我们的文章[免费和付费计划有何不同](https://help.klaviyo.com/hc/en-us/articles/360050759151-How-Free-and-Paid-Plans-Differ#talk-with-customer-success-managers-and-onboarding-specialists4)。 ## 专用 IP 与共享 IP

邮箱提供商在确定将电子邮件放置在何处（收件箱、垃圾邮件等）时会考虑您的整体声誉，包括您的 IP。 IP 声誉、域名声誉、收件人积极和消极参与度只是影响您的[整体送达率](https://help.klaviyo.com/hc/en-us/articles/115005247008) 的几个因素。从共享 IP 地址发送意味着您将与其他几个 Klaviyo 客户一起发送，这也意味着共享的发送信誉。转移到专用 IP 地址（不要与[品牌发送域](https://help.klaviyo.com/hc/en-us/articles/7674941873947) 混淆）将允许您完全拥有 IP 声誉，因为您将是唯一使用它进行电子邮件流量的人。 ## 保持共享 IP

****保留默认共享IP的好处****
大多数小型企业或刚刚开始使用 Klaviyo 的企业将使用共享 IP。根据您的电子邮件实践和数量，这应该足以满足您的发送和声誉需求。 Klaviyo 会自动将共享 IP 地址分配给大多数新帐户。通过共享 IP，您可以从其他发件人那里受益，从而保持 IP 池声誉并提高整体流量。 Klaviyo 持续监控这些 IP 并删除任何有害发件人。 ****保留共享 IP 的缺点****
共享 IP 旨在供不定期发送的小型发件人使用。这样做的原因是小发件人可以联合起来创造声誉。因此，如果您定期发送大量数据以保证专用 IP，那么无论如何您都将控制共享池中的声誉。在节假日和其他高流量时段，流量可能会波动，并可能影响您的表现。如果您有资格获得专用 IP，最好转而使用专用 IP。 ## 迁移到专用 IP

****迁移到专用 IP 的好处****
使用专用 IP 地址的主要好处是，IP 地址的声誉只能受到使用该地址的单个帐户的影响。因此，您可以完全控制自己的发件人声誉。同样，您还可以完全控制发送量，并且不会受到共享 IP 和一年中繁忙时段潜在的发送量峰值的影响。此外，如果您遇到交付问题，您可以更轻松地查明根本原因，因为这只是您的消息传递。当多个发件人使用相同的 IP 时，很难找出问题的根源以及如何修复它。通过使用专用 IP，您只需维护自己的发送和 IP 地址。即使您对专用 IP 声誉负全部责任，但如果您发现可交付性问题，我们的支持团队可以更好地帮助您确定原因并提供解决方案选项。 ****迁移到专用 IP 的缺点****
使用专用 IP 地址的潜在负面影响是您必须以一致的节奏进行大量发送。这有助于确保您能够在送达率方面保持良好的发件人声誉，并被邮箱提供商视为信誉良好的发件人。此外，您将需要更新您的 DNS 记录，并以一种不同的、更注重参与的方式预热您的基础设施。 [了解有关专用 IP 预热的更多信息](https://help.klaviyo.com/hc/en-us/articles/7521152741403)。 ## 专用IP预热

开始使用新 IP 地址时，您必须经历[预热过程](https://help.klaviyo.com/hc/en-us/articles/7521152741403)，以建立收件箱提供商信任的健康发件人声誉。在预热过程中，必须逐步发送电子邮件，以避免被之前未发现该 IP 活动的收件箱提供商阻止。 Klaviyo 最初通过专用 IP 发送一小部分电子邮件，同时通过共享 IP 路由其余电子邮件。 随着时间的推移，通过专用 IP 发送的电子邮件的比例逐渐增加，直到所有流量都通过专用 IP 发送。关于专用 IP 预热，有几个关键方面需要注意：

- 预热期的持续时间取决于发送量，但通常持续约 30-40 天。 - 变暖期间专用 IP 上的发送量以非线性曲线增加，大部分发送量增加发生在变暖结束时。 - 我们的客户支持团队在预热期间提供的分段建议是为了为新IP创建强大的发送声誉，而不关心总量。
