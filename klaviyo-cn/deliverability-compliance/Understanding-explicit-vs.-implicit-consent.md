## 你将会学到

详细了解 Klaviyo 中不同类型的同意（显式同意与隐式同意）以及您可以或不可以向谁发送电子邮件。能够向订阅者发送电子邮件基本上可以归结为获得适当的同意。有两种类型的同意：

- ****明确****（有时也称为明确同意）
- ****隐式****（有时也称为默示或推断同意）

此信息****不是****法律建议。 Klaviyo 建议您咨询您的法律顾问，以确保您遵守与营销活动相关的适用法律。 ## 明确同意

当有人直接告诉您他们希望接收来自您的品牌的营销信息时，即表示明确同意。当他们满足以下条件时，您可以获得明确同意：

- 通过表格注册
- 在现场邮寄名单上（在您的商店或展位上）向您提供他们的信息
- 口头告诉您他们希望从您那里获得营销信息并向您提供他们的联系信息
- 打开应用程序时通过权限提示选择推送通知

在明确同意的情况下，订阅者必须在知情的情况下同意接收营销信息。 ### 明确同意的优点和缺点

|  |  |
| --- | --- |
| ****优点**** | ****缺点**** |
|提供更高质量的订户 |可能会导致订户减少|
|总是允许|
|不会过期 |
|使用 Klaviyo 发送短信需要 |

当您明确同意后，您可以自由地向订阅者发送营销消息，直到他们选择退出 - 它不会过期。使用 Klaviyo 发送短信[需要明确同意](https://help.klaviyo.com/hc/en-us/sections/29514448877467)。对于其他营销渠道（例如电子邮件），这取决于收件人所在国家/地区的法律，有些需要明确同意。例如，[加拿大的反垃圾邮件立法](https://help.klaviyo.com/hc/en-us/articles/4402385511579) 要求除特定情况外，所有商业电子消息均需获得明确同意。明确同意的一个缺点是，明确选择加入的人比隐含选择加入的人少。因此，列表增长可能会较慢，但那些订阅的人将比那些没有故意或明确同意的人成为更高质量的联系人。 ## 默示同意

默示同意是指某人向您提供了他们的联系信息（例如电子邮件地址、电话号码等），但没有明确表示他们希望接收来自您品牌的营销信息。隐式同意的一个常见示例是客户进行购买并在结账时提供电子邮件。他们没有明确表示希望收到品牌的营销信息，但可以推断他们对相关内容感兴趣。在这种情况下，您拥有他们的信息，但他们尚未同意接收营销通讯。默示同意的示例包括：

- 注册封闭内容或资源（例如论坛、文章、Wi-Fi 网络等）
- 在结账时输入联系信息（如果他们没有选中复选框或以其他方式同意接收营销信息）
- 给您一张名片
- 向您购买或租赁服务、商品或产品
- 同意与您签订合同（书面或电子）
- 与您一起参与游戏或投资机会
- 向您捐款（如果您是注册慈善机构或政治组织）
- 为您提供志愿服务（如果您是注册慈善机构或政治组织）
- 成为您所在组织的俱乐部、协会或非营利志愿者团体的成员

[有关默示同意的法律因国家/地区而异](https://help.klaviyo.com/hc/en-us/sections/360000775792)；通常，当允许默示同意时，它要么被限制在一定的时间范围内（例如，只能在两年内有效），要么在特定情况下有效。 ### 默示同意的优点和缺点

|  |  |
| --- | --- |
|优点 |缺点 |
|提供更多数量的订户 |导致订阅者质量低下和送达率问题
|  |通常会在一段时间后过期 |
|  |在某些司法管辖区被禁止或受到严格限制 |
|  |使用 Klaviyo SMS 时不允许 |

默示同意的优点是，与明示同意相比，您可以通过默示同意收集更多的联系人。然而，由于这些联系人实际上并未同意接收来自您品牌的营销信息，因此他们更有可能选择退出或将您标记为垃圾邮件，从而导致送达率问题。 如果投诉数量足够多，您可能会被列入电子邮件服务提供商（例如 Gmail 和 Yahoo）的黑名单。某些司法管辖区不允许默示同意，而在其他司法管辖区，仅在特殊情况下才允许。因此，通过依赖默示同意，您可能会遇到合规问题，具体取决于您的收件人所在的位置。使用 Klaviyo SMS 时，默示同意也会过期且不允许。 ## 同意的最佳实践

您应该遵循一些征求同意的最佳做法：

- 获得明确同意/避免发送给那些默示同意的人
- 明确收件人选择的内容
- 记录收集同意的方法（即某人何时、何地以及如何给予明确同意）
- 使用[双重选择加入](https://help.klaviyo.com/hc/en-us/articles/115005251108)

我们建议尽可能获得明确同意。如果您收集默示同意并且您发送到的司法管辖区允许这样做，请为那些默示同意的人使用单独的列表。此外，重新定位这些联系人以尝试获得他们的明确同意，例如[通过社交媒体定位他们](https://help.klaviyo.com/hc/en-us/articles/360039769672)或注册表单。 ![使用表单定位列表或分段的选项](https://klaviyo.zendesk.com/hc/article_attachments/28717851607195)
