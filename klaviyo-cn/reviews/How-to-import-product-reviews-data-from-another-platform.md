## 你将会学到

了解如何将评论和自定义问题从您之前的平台导入到 Klaviyo Reviews 中。导入评论有两种方法：

- 导出评论并直接上传到 Klaviyo（仅限支持的提供商）
- 格式化您的 CSV 文件并上传到 Klaviyo（所有其他提供商）

仅导入与真实客户提交的完全相同的有效评论。在从之前的平台导出评论并将其上传到 Klaviyo 之间，请勿编辑评论。本文介绍导入产品评论。如果您对整个品牌有评论，请[了解如何导入商店评论](https://help.klaviyo.com/hc/en-us/articles/27291102795547)。 ## 从您之前的评论平台导出评论

从之前的评论平台导出评论所需的步骤取决于您之前使用的平台。请参阅他们的支持文档，了解如何将评论导出为 CSV。确保导出个人评论，而不是评论摘要。了解如何导出评论：

- [Yotpo](https://support.yotpo.com/docs/exporting-reviews-from-yotpo)
- [Okendo](https://help.octaneai.com/en/articles/7932726-exporting-reviews-from-okendo)
- [已盖章](https://stampedsupport.stamped.io/hc/en-us/articles/8839244356891-Exporting-Reviews-Checkout-Comments-or-NPS)
- [Reviews.io](https://support.reviews.io/en/articles/9185047-how-to-export-your-reviews)
- [Judge.me](https://help.judge.me/en/articles/8236266-exporting-reviews)
- [Loox](https://help.loox.io/article/21-how-do-i-export-my-reviews)

## 进口要求

对于大多数评论平台，您只需导出评论并将其直接导入到 Klaviyo 中即可。您不太可能需要对 CSV 文件进行编辑。您的 CSV 文件必须包含包含以下信息的列：

- 产品 ID 与从您的商店同步到 Klaviyo 的产品 ID 完全匹配
  - 导入与产品无关的商店评论时，该字段可能为空；产品 ID 列仍为必填项
- 审阅文本
- 审稿人的电子邮件

## 确定您之前的评论提供商是否受支持

Klaviyo 为各种评论提供商提供自动上传工具。如果您过去的评论提供商受支持，****不要对您导出的评论的 CSV 文件进行任何编辑****。要检查支持哪些评论提供商：

1. 单击 Klaviyo 侧栏中的****评论****。 2. 导航至****所有评论****选项卡。 3. 选择****选项****。 4. 单击****导入评论****。在这里，您将看到所有支持的评论提供商。 - 如果您在此处看到您的提供商，请了解如何[导入您的评论](#h_01HS15C65QTH13PSHJRXGNGB5V)。 - 如果您没有看到您的提供商，请了解如何[上传前格式化您的 CSV](#h_01HS15C65Q8NZ2HNVTHR66R0PH)。 ## 从受支持的提供商处导入您的评论

大多数评论可以直接上传到 Klaviyo Reviews。 1. 单击 Klaviyo 侧栏中的****评论****。 2. 导航至****所有评论****选项卡。 3. 选择****选项****。 4. 单击****导入评论****。 5. 从提供的选项中选择您之前的评论平台。如果您没有看到您的平台列出，请选择****其他/不确定****。如果您选择****其他/不确定****，则必须先使用[下节中的模板](#h_01HS15C65Q8NZ2HNVTHR66R0PH) 格式化您的 CSV，然后再继续。 6. 单击****选择文件**** 或将 CSV 文件拖放到上传工具中。 7. 如果准确，请选中**我确认导入的评论是真实的**旁边的框。只有合法的评论才可以上传到 Klaviyo。 8. 检查上传的字段映射并根据需要进行调整。 9. 单击****下一步****。在上传过程中，您将看到一个带有状态栏的模式。上传完成后，该模式将显示 CSV 中成功上传和失败审核的数量。 ## 导入视频评论

如果您的 CSV 包含视频 URL 列，则可以导入视频评论。以下平台提供此栏目：

- 约特波
- 大剑道
- 盖章

  Klaviyo 接受以下文件类型：
- MP4
- MOV

每个视频的最大文件大小为 200 MB。 ### 导入自定义问题（仅限 Yotpo）

如果您之前的评论提供商是 Yotpo 并且您使用了他们的自定义问题功能，则可以将评论者的答案直接导入 Klaviyo。要上传自定义问题，请按照上面部分中的步骤操作。然后，将 Yotpo 自定义问题映射到 Klaviyo 中的自定义问题。 请遵循以下提示以确保您的问题正确导入：

- 不要编辑从 Yotpo 导出的 CSV 文件； Klaviyo 会自动检测您的自定义问题并建议将其映射到哪些 Klaviyo 自定义问题。 - 请务必选择 ****Yotpo**** 作为您之前的评论提供商。 - 如果您决定不导入自定义问题，请使用复选框取消选择它。 - 在映射页面上，标签图标表示自定义问题仅与某些产品相关。您可以在 Klaviyo 自定义问题设置中更新此设置。如果您之前导入了评论并尝试重新导入，则该评论将被跳过，即使它在初始导入期间不包含自定义问题。上传评论时，您将有机会在 Klaviyo 中配置自定义问题（如果尚未设置）。要导入自定义问题：

1. 按照上述标准上传步骤，选择 ****Yotpo**** 作为您以前的提供商。 2. 映射标准审核字段后，单击****下一步****。 3. 对于每个自定义问题，选择现有的自定义问题或单击****添加问题****。 ![](https://klaviyo.zendesk.com/hc/article_attachments/33630036170523)
4. 完成所有自定义问题的这些步骤后，单击****下一步****并继续导入过程。 ## 从其他平台导入您的评论

要从上传页面上列出的平台以外的平台导入评论，请使用下面的模板。 [下载此模板的副本以从其他平台导入评论。](https://drive.google.com/file/d/1rVwBtGtYvlv1Os-Z2de7ZvEoztHjUYR3/view?usp=sharing)

请注意，您需要调整 CSV 文件以匹配此示例格式，否则上传将无法进行。包括这些必需的列：

- ****产品 ID (产品\_id)****
  必须与您的 [Klaviyo 产品目录](https://help.klaviyo.com/hc/en-us/articles/115005082787) 中的产品 ID 完全匹配（最多 255 个字符）；或者，使用 ****product\_handle****、****product\_sku**** 或 ****product\_name**** 作为您的产品标识符
- ****审稿人电子邮件（审稿人\_email）****
  必须是有效的电子邮件地址（最多 3,000 个字符）
- ****评论分数（评级）****
  数字 1-5，代表客户提交的评级
- ****评论创建日期 (review\_date)****
  使用[接受的日期格式]格式化的审稿提交日期(https://help.klaviyo.com/hc/en-us/articles/360039859932)
- ****审核状态（状态）****
  审查状态（即**已发布**、**未发布**）；未发布的评论在 Klaviyo 中标记为 **待处理**，直到您批准并发布它们

  （可选）如果需要，可以包含这些列：
- ****审阅者显示名称（审阅者\_name）****
  一般为名字 + 姓氏首字母（例如 **Mark R.**）（最多 300 个字符）
- ****评论内容 (review\_content)****
  客户提交的评论（最多 10,000 个字符）
- ****发布的图像 URL (image\_urls)****
  有效的、可公开访问的图像 URL（或多个以逗号分隔的 URL）； Klaviyo 将保存并存储这些图像
- ****评论标题（评论\_title）****
  评论的简短标题（最多 3,000 个字符）
- ****评论已验证买家（是/否）（已验证）****
  评论者是否是经过验证的购买者；只接受**是**和**否**
- ****审稿人所在国家/地区（审稿人\_地点）****
  例如，美国、英国、加拿大、澳大利亚（最多 3,000 个字符）
- ****回复内容(reply\_content)****
  您的品牌对客户评论的回复（最多 3,000 个字符）
- ****回复日期（回复\_日期）****
  您的品牌回复客户评论的日期
- ****商店评论（真/假）（is\_store\_review）****
  评论是否针对您的整个商店。接受“真”或“假”。

将文件格式化为匹配 [Klaviyo 的模板](https://drive.google.com/file/d/1D5Flq0J4Y_XytJRiBgZemyIoqMDDXhUk/view?usp=drive_link) 后，上传它：

1. 单击 Klaviyo 侧栏中的****评论****。 2. 导航至****所有评论****选项卡。 3. 选择****选项****。 4. 单击****导入评论****。 5. 选择****其他/不确定****。 6. 单击****选择文件**** 或将 CSV 文件拖放到上传工具中。 7. 如果准确，请选中**我确认导入的评论是真实的**旁边的框。只有合法的评论才可以上传到 Klaviyo。 8. 检查上传的字段映射并根据需要进行调整。 9. 单击****下一步****。 ## 解决上传失败的问题

如果您从其他平台通过 CSV 方式上传评论失败，请检查 CSV 中包含的产品 ID。它们必须与 Klaviyo 中找到的产品 ID 完全匹配，这些产品 ID 会自动从您的电子商务平台中提取。要检查 CSV 中的产品 ID 是否已同步到 Klaviyo：

1. 导航至 Klaviyo 侧栏中的****内容 > 产品****。 2. 在 **Items** 选项卡上的目录搜索栏中，从 CSV 中搜索产品 ID。 3. 如果未找到结果，请将 CSV 中的产品 ID 替换为 Klaviyo/Shopify 中找到的正确产品 ID，然后重试上传。确保您的电子表格软件尚未将您的产品 ID 转换为科学记数法。 ![以科学计数法表示的产品 ID](https://klaviyo.zendesk.com/hc/article_attachments/30005015803419)

如果有，请将科学计数法产品 ID 替换为更正的产品 ID。
