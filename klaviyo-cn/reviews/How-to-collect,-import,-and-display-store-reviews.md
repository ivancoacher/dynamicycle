## 你将会学到

了解商店评论（也称为网站评论），它反映您的整个品牌而不是单个产品，以及如何在您的商店中展示它们。 ## 关于商店评论

Klaviyo 有 2 种类型的评论：

- ****产品评论****
  与特定产品相关的评论
- ****商店评论****
  对您整个公司/品牌的评论。 ## 收集商店评论

要启用商店评论收集：

1. 导航至****评论 > 评论设置 > 评论提交页面****。 2. 在**成功页面**部分中，选择**请求商店审核**选项。 3. 选择****保存更改****。选择此选项后，评论提交成功页面将包含一个选项，供评论者留下商店评论（如果他们之前没有留下过商店评论）。 ![商店审核提示](https://klaviyo.zendesk.com/hc/article_attachments/28881040890395)

商店评论显示在 [SEO / 所有评论小部件](https://help.klaviyo.com/hc/en-us/articles/16691401577883)中。将此小部件添加到您网站上的独立页面，以改善 SEO，并为购物者提供一个单一位置来查看您对产品和整个商店的所有评论。 ### 中等商店评论

商店评论可以[审核](https://help.klaviyo.com/hc/en-us/articles/19351110471323)，就像产品评论一样。要审核您的商店评论：

1. 导航至****评论 > 所有评论****。 2. 在 **类型** 下，选择 ****Store**** 并取消选择 ****Product****（如果已选择）。 ![类型菜单已过滤为仅包含商店评论](https://klaviyo.zendesk.com/hc/article_attachments/28881024889883)
3. 查看任何待处理的商店审核。根据需要发布或拒绝它们。 ### 将产品评论转换为商店评论

如果产品评论与您的整个商店相关，您可以将其转换为商店评论。 1. 导航至****评论 > 所有评论****。 2. 选择评论旁边的三个点（附加选项）图标。 3. 选择****另存为商店评论****。 ![另存为商店评论选项](https://klaviyo.zendesk.com/hc/article_attachments/28881024890395)
4. 在出现的模式中，选择****商店和产品评论****或****仅商店评论****。 5. 选择****保存评论****。保存为商店评论后，它将显示在您的 SEO/所有评论小部件中。如果您选择将其保存为商店评论和产品评论，它也将保留在适用的产品评论小部件上。您无法将没有文字的产品评论转换为商店评论。 ### 将商店评论转换为产品评论

要将商店评论转换为产品评论：

1. 导航至****评论 > 所有评论****。 2. 选择评论旁边的三个点（附加选项）图标。 3. 选择****另存为产品评论...****
   ![另存为产品评论...选项](https://klaviyo.zendesk.com/hc/article_attachments/28881040893211)
4. 如果评论尚未连接到产品，请从显示的模式中选择产品。 5. 选择评论是产品评论还是商店评论，还是仅产品评论。选择****保存评论****。 ## 导入商店评论

Yotpo、Stamped 和 Okendo 目前支持导入商店评论。对于自定义上传（即从其他提供商上传），请按照[以下部分](#h_01HS15C65Q8NZ2HNVTHR66R0PH)中的步骤操作。您可以导入商店评论以直接在您的网站上展示（即在 SEO/所有评论小部件中）。导入商店评论：

1. 从您以前的提供商导出评论。 2. 单击 Klaviyo 侧栏中的****评论****。 3. 导航至****所有评论****选项卡。 4. 选择****选项****。 5. 单击****导入评论****。 ![导入评论按钮](https://klaviyo.zendesk.com/hc/article_attachments/28711732172315)
6. 选择 ****Stamped****、****Yotpo**** 或 ****Okendo**** 作为您之前的评论提供商。 7. 按照导入模式中的步骤操作。完成这些步骤后，在导入中标记为商店评论的所有评论都将在 Klaviyo 中显示为商店评论。 ## 从其他平台导入商店评论

要从上面列出的平台以外的平台导入商店评论，请使用下面的模板。 [下载此模板的副本以从其他平台导入评论。](https://drive.google.com/file/d/1rVwBtGtYvlv1Os-Z2de7ZvEoztHjUYR3/view?usp=sharing)

请注意，您需要调整 CSV 文件以匹配此示例格式，否则上传将无法进行。 包括这些必需的列：

- ****产品 ID (产品\_id)****
  必须与您的 [Klaviyo 产品目录](https://help.klaviyo.com/hc/en-us/articles/115005082787) 中的产品 ID 完全匹配（最多 255 个字符）；或者，使用 ****product\_handle****、****product\_sku**** 或 ****product\_name**** 作为您的产品标识符
- ****审稿人电子邮件（审稿人\_email）****
  必须是有效的电子邮件地址（最多 3,000 个字符）
- ****评论分数（评级）****
  数字 1-5，代表客户提交的评级
- ****评论创建日期 (review\_date)****
  使用[接受的日期格式]格式化的审稿提交日期(https://help.klaviyo.com/hc/en-us/articles/360039859932)
- ****审核状态（状态）****
  审查状态（即**已发布**、**未发布**）；未发布的评论在 Klaviyo 中标记为 **待处理**，直到您批准并发布它们

  即使您的评论仅针对您的商店，产品 ID 列也是必需的。如果评论与产品无关，请将产品 ID 列留空。 （可选）如果需要，可以包含这些列：
- ****审阅者显示名称（审阅者\_name）****
  一般为名字 + 姓氏首字母（例如 **Mark R.**）（最多 300 个字符）
- ****评论内容 (review\_content)****
  客户提交的评论（最多 10,000 个字符）
- ****发布的图像 URL (image\_urls)****
  有效的、可公开访问的图像 URL（或多个以逗号分隔的 URL）； Klaviyo 将保存并存储这些图像
- ****评论标题（评论\_title）****
  评论的简短标题（最多 3,000 个字符）
- ****评论已验证买家（是/否）（已验证）****
  评论者是否是经过验证的购买者；只接受**是**和**否**
- ****审稿人所在国家/地区（审稿人\_地点）****
  例如，美国、英国、加拿大、澳大利亚（最多 3,000 个字符）
- ****回复内容(reply\_content)****
  您的品牌对客户评论的回复（最多 3,000 个字符）
- ****回复日期（回复\_日期）****
  您的品牌回复客户评论的日期
- ****商店评论（真/假）（is\_store\_review）****
  评论是否针对您的整个商店。接受“真”或“假”。

将文件格式化为匹配 [Klaviyo 的模板](https://drive.google.com/file/d/1D5Flq0J4Y_XytJRiBgZemyIoqMDDXhUk/view?usp=drive_link) 后，上传它：

1. 从您以前的提供商导出评论。 2. 单击 Klaviyo 侧栏中的****评论****。 3. 导航至****所有评论****选项卡。 4. 选择****选项****。 5. 单击****导入评论****。 ![导入评论按钮](https://klaviyo.zendesk.com/hc/article_attachments/28711732172315)
6. 选择****其他/不确定****作为您之前的评论提供商。 7. 按照导入模式中的步骤操作。 ## 显示商店评论

导入商店评论后，您必须打开一个设置，以便它们与产品评论一起出现在您的 SEO/所有评论小部件中。 1. 导航至 Klaviyo 中的 ****Reviews****。 2. 单击****评论设置****。 3. 选择****现场小部件****。 ![现场小部件设置卡](https://klaviyo.zendesk.com/hc/article_attachments/28711703158683)
4. 选择****SEO/所有评论小部件**** 卡。 5. 单击****商店评论****。 6. 开启**显示商店评论**设置。 7. 选择商店评论应显示的位置：**包含产品评论的单个列表**或**商店评论的单独选项卡**。 ![商店评论设置已开启](https://klaviyo.zendesk.com/hc/article_attachments/28711732178843)
8. 单击****发布更改****。
