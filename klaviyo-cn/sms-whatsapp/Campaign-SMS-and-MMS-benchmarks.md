## 你将会学到

了解短信和彩信活动的平均点击率、转化率和退订率。

以下信息基于美国使用 SMS 的 Klaviyo 客户的数据。这些范围可能会根据您的行业和受众而有所不同。

## 短信和彩信

短信和彩信的费率几乎相同。彩信的每个收件人的平均收入略高，退订率略低，但除此之外，两种消息类型的性能相同。

### 点击率

|  |  |
| --- | --- |
| ****太棒了**** | 14.6%及以上 |
| ****好**** | 8.9%–14.5% |
| ****有改进的余地**** | 6.0–8.8% |
| ****关键**** |低于 5.9% |

### 转化率

|  |  |
| --- | --- |
| ****太棒了**** | 2.1%及以上|
| ****好**** | 1.0–2.0% |
| ****有改进的余地**** | 0.5–0.9% |
| ****关键**** |低于 0.5% |

### 退订率

请注意，高于平均取消订阅率可能会导致消息限制或被无线运营商阻止。

|  |  |
| --- | --- |
| ****太棒了**** |低于 0.5% |
| ****好**** | 0.6–1.4% |
| ****有改进的余地**** | 1.5–1.9% |
| ****关键**** | 2.0%及以上|

### 每个收件人的收入

|  |  |
| --- | --- |
| ****太棒了**** | 2.42 美元及以上 |
| ****好**** | 0.66–2.41 美元 |
| ****有改进的余地**** | 0.18–0.65 美元 |
| ****关键**** |低于 0.18 美元 |
