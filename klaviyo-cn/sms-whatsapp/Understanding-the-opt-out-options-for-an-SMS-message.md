了解短信的 2 个退出选项：取消订阅说明或取消订阅链接。本文介绍了这两个选项，包括它们的工作原理以及何时可以使用它们。在您的消息中添加一种让收件人选择退出短信的方式始终很重要。除了作为任何营销渠道的最佳实践之外，大多数国家/地区还要求 SMS。某些国家/地区还要求您在发送的每条短信中提供选择退出的方式。 ## 关于 Klaviyo 的短信选择退出选项

Klaviyo 包含 2 种内置方式供 SMS 收件人在消息中取消订阅：

- 取消订阅说明
- 取消订阅链接

在任何给定时间，单个 SMS 中仅包含其中一个选项。使用的选项取决于[发送号码](https://help.klaviyo.com/hc/en-us/articles/6637671573403)。有关每个发送号码使用哪个选项的详细信息，请参阅下表。 |  |  |  |  |
| --- | --- | --- | --- |
|  | ****为此选项发送号码**** | ****\*字符数**** | ****能够在 Klaviyo 中关闭**** |
|取消订阅说明 |免费电话 长代码 短代码 |默认 21 个字符 |是的 |
|取消订阅链接 |品牌发件人 ID |默认情况下约 31 到 34 个字符 |没有 |

\* 确切的字符数可能会有所不同。通过取消订阅说明，您可以在短信设置页面中编辑消息。至于取消订阅链接，链接的长度可能会发生变化，具体取决于您使用的是默认 Klaviyo 链接还是[品牌缩短链接](https://help.klaviyo.com/hc/en-us/articles/17649597637147)。当客户通过任一选项取消订阅时，它会自动删除短信交易和促销同意。目前，您的订阅者不能选择仅退出交易短信或仅退出促销短信。 ****为什么取消订阅说明不适用于品牌发件人 ID？****

取消订阅指令依赖于订阅者向您的品牌号码发送关键字短信。但是，品牌发件人 ID 无法接收传入消息。即使订阅者尝试向您发送“停止”短信，品牌发件人 ID 也永远不会收到此消息。因此，取消订阅指令根本不适用于品牌发件人 ID。如果您使用品牌发件人 ID 并具有任何其他号码类型，请务必预览消息以检查字符数。除非您专门过滤或[按国家/地区细分](https://help.klaviyo.com/hc/en-us/articles/4402954226459)，否则单条消息可能会对某些收件人使用取消订阅链接，而对其他收件人则使用说明。这会改变字符数，并可能导致您使用比预期更多的积分。默认情况下，对于 Klaviyo 中的每个短信活动和流消息，选择退出选项始终处于打开状态。 ****为什么我无法关闭取消订阅链接？****

许多国家/地区都有严格的规定，要求公司在每条短信中添加选择退出的方式。对于品牌发件人 ID，这并不容易。其他号码类型都将 STOP 作为立即退订的方式；但是，品牌发件人 ID 没有通用的取消订阅链接。为了保护用户，Klaviyo 会自动将取消订阅链接添加到从品牌发件人 ID 发送的消息中。 ### 取消订阅说明

在 Klaviyo 中，取消订阅指令为收件人提供了一个关键字，他们可以通过短信选择退出短信。作为最佳实践，我们建议至少每月发送一次选择退出指令。默认情况下，取消订阅说明为：“发送短信停止以选择退出。”

取消订阅说明：

- 不适用于品牌发件人 ID。 - 可以编辑。 - 对于每个收件人都保持相同（即不会自动翻译为其他语言）。 ![带有默认取消订阅说明的文本示例](https://klaviyo.zendesk.com/hc/article_attachments/28716334419483)

对于使用免费电话号码的任何人，如果订阅者使用关键字“STOP”取消订阅，则必须使用关键字 UNSTOP 或 START 重新订阅。否则，无线运营商将阻止发送至收件人号码的消息，即使该人已选择使用表单、其他关键字等重新接收消息。#### 编辑取消订阅说明

您必须是所有者或管理员才能更改帐户中的取消订阅说明。 1. 在左下角选择您的帐户名。 2. 导航至****设置 > 短信****。 3. 向下滚动到**消息附加组件**部分。 ![选择退出说明.jpg](https://klaviyo.zendesk.com/hc/article_attachments/30080400115611)
4. 编辑文本。 注意：您必须在消息中包含“STOP”。 5. 单击****保存****。保存后，它将更新任何短信流或预定活动消息中的取消订阅说明。 ### 取消订阅链接

取消订阅链接允许收件人单击链接以选择退出短信。一旦收件人单击该链接，他们就会被重定向到一个页面，以通过**取消订阅**按钮确认选择退出。请注意，客户需要单击“**取消订阅**”按钮才能选择退出，而不仅仅是单击链接。此选项仅适用于从品牌发件人 ID 发送的消息，因为取消订阅指令不适用于此号码类型。请记住，与取消订阅指令相比，取消订阅链接会向消息添加更多字符。这个链接：

- 仅适用于品牌发件人 ID。 - 不计入消息的点击率。 - 无法编辑（即更改单词“STOP”，或选择不同的域）

![带有取消订阅链接的文本示例](https://klaviyo.zendesk.com/hc/article_attachments/28716334421659)

此外，此链接指向一个页面：

- 根据浏览器的设置自动翻译为以下语言：
  - 英语（如果未设置或不支持浏览器语言则默认）
  - 法语
  - 德语
  - 荷兰语
- 无法手动编辑（即无法更改文本、颜色等）
