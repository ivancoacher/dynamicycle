只有所有者、管理员和经理才能设置短信。

了解如何在 Klaviyo 中启用短信。如果您已在 Klaviyo 帐户中设置了电子邮件，则适用这些步骤。如果您正在通过设置向导同时设置电子邮件和短信，步骤可能有所不同。

您必须先启用短信并拥有发送号码，然后才能执行以下任何操作：

- 导入或收集短信订阅者
- 发送短信或彩信

请注意，[并非所有行业都有资格使用短信](https://help.klaviyo.com/hc/en-us/articles/4401822831771)。

星号（\*）表示此号码类型：

- 是 Klaviyo 中的默认发送号码，所有帐户均可免费使用。
- 对于所有可用的国家/地区使用相同的号码。
  - 例如，同一个品牌发件人 ID 收集同意并向英国、德国、澳大利亚等地发送短信。

非默认发送号码（即长代码和短代码）需要付费套餐。这也适用于比利时和匈牙利，其中长代码是唯一的发送号码。

**默认发送号码**

通过品牌发件人 ID 和免费电话号码，使用同一个号码来收集同意并发送到多个国家/地区。它们会自动执行此操作，因此如果您不想收集同意或发送到特定国家/地区，请按国家/地区定位您的表单，创建基于位置的细分，然后拆分您的流程。

按国家/地区区分对于了解在哪里使用短信积分也很关键。由于积分因国家/地区而异，基于位置的定位可帮助您跟踪花费、参与人数以及每条消息的投资回报率。这样，您就知道向何处以及向谁发送短信消息。

## 启用短信

如果您在 Klaviyo 设置向导期间没有设置短信，可以在短信设置页面中启用。

![](https://fast.wistia.com/embed/medias/dx8q97zx8c/swatch)

1. 点击左下角的帐户名称。
2. 导航至**设置 > 短信**。
3. 点击**免费设置短信**。
   如果您没有看到此按钮，请点击**添加国家/地区**并选择您要开始发送的国家/地区。
4. 在弹出的窗口中，选择您要使用短信的国家/地区（勾选所有适用项）。
   ![选择要发送短信的国家/地区](https://klaviyo.zendesk.com/hc/article_attachments/28722596951835)
5. 点击**下一步**。
6. 填写您的公司信息。
   ![](https://klaviyo.zendesk.com/hc/article_attachments/47593800502811)
7. 检查或选择您的发送号码。有关号码的完整比较，请参阅我们关于[短信发送号码](https://help.klaviyo.com/hc/en-us/articles/6637671573403)的文章，主要要点包括：

   - 有时，同一个发送号码会用于多个国家/地区，除非您有其他优先号码。
     - 美国和加拿大使用相同的免费电话号码，除非您拥有其中一个或两个国家/地区的短代码。
     - 同一个品牌发件人 ID 用于每个可用的国家/地区，除非您在特定国家/地区拥有长代码或短代码。
     - 短代码和长代码始终与特定国家/地区关联。
   - 某些国家/地区仅提供 1 种发送号码：
     - 比利时：唯一的选择是申请长代码。
     - 新西兰：唯一的选择是申请短代码。
   ![在 Klaviyo 中创建品牌发件人 ID 的窗口](https://klaviyo.zendesk.com/hc/article_attachments/28722558533659)
8. 点击**下一步**。
9. 某些国家/地区要求发送号码在使用前必须经过验证或注册。这包括：

   - 所有[短代码](https://help.klaviyo.com/hc/en-us/articles/26886941270171)（无论哪个国家/地区）。
   - 美国或加拿大的[免费电话号码](https://help.klaviyo.com/hc/en-us/articles/4415873897499)。
     - 请注意，无需执行任何操作即可开始免费电话号码的验证过程。
   - 澳大利亚和爱尔兰的[品牌发件人 ID](https://help.klaviyo.com/hc/en-us/articles/14953787622427)。
     - 请注意，爱尔兰要求您通过其国家注册机构 [ComReg](https://senderid.comreg.ie/) 进行注册。
   - 澳大利亚、比利时和爱尔兰的[长代码](https://help.klaviyo.com/hc/en-us/articles/26705180655003)。
10. 选择以下后续步骤之一：

- 创建注册表单（适合短信新手）。
- 上传以前的短信订阅者列表（适合从其他短信提供商切换的用户）。

请注意，如果您已经在 Klaviyo 中使用 UTM 跟踪，我们还建议导航至**设置 > 其他 > UTM 跟踪**，并将 UTM 媒介调整为*消息类型*。否则，短信消息可能无法被正确跟踪。

## 结果

您现在可以开始收集短信订阅者并向他们发送短信了。在此之前，请先在 Klaviyo 学院学习[短信合规性最佳实践](https://academy.klaviyo.com/en-us/courses/best-practices-for-sms-compliance/2011622)。
