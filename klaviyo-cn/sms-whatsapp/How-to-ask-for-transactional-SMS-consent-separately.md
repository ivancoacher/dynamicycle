您必须：

- 成为所有者、管理员或经理。 - 已在 Klaviyo 中设置短信。 - 使用付费帐户。 ## 你将会学到

了解如何与促销同意分开收集交易短信同意。如果您计划仅发送事务性消息（例如基于订阅的业务）或希望为客户提供 SMS 消息的选择，则指定同意类型会很有帮助。对于所有其他情况，您不需要指定同意类型。默认情况下，它设置为促销同意，允许您发送任何类型的短信。 ## 关于不同类型的短信同意

在 Klaviyo 中，有 3 种类型的短信同意：

- ****促销****
  允许您发送任何类型的 SMS 消息，包括活动和所有流。经促销同意，您还可以发送交易消息。 - ****交易****
  同意所有交易消息，包括订单更新和其他购买后流程消息。 - ****订单更新****（仅限 Shopify）
  最有限的短信同意类型。此类同意与特定购买相关联，并且仅允许从购买后流程发送有关此 1 个订单的短信。详细了解 [Shopify 短信订单更新](https://help.klaviyo.com/hc/en-us/articles/18389135527323)。将 SMS 同意类型可视化为层次结构，类似于下图。促销是最广泛的类别，包括交易消息，而交易消息又包括订单更新。有关更多信息，请参阅[了解事务消息](https://help.klaviyo.com/hc/en-us/articles/26024442679835)。 ![不同短信同意类型图](https://klaviyo.zendesk.com/hc/article_attachments/34593429544731)

## 开始之前

请注意以下有关收集交易同意的事项：

- 交易同意始终使用单一选择加入，这意味着您不能使用：
  - 交易的双重选择。 - 适用于包含交易同意的表单的任何两步同意收集方法（例如智能选择加入）。 - 仅交易订阅者不会添加到列表中，但交易同意会显示在个人资料上。 - 如果您之前在帐户中设置了披露语言，则可能需要对其进行编辑以提及交易消息。请注意，您可以在表格的同一页或两个不同的步骤中收集交易和促销同意书。选择取决于您（无需注意合规性注意事项）。 ## 以表格形式收集交易同意书

仅当您需要单独选择加入选项以获取交易同意和促销同意时（例如，如果您计划[使用美国短代码](https://help.klaviyo.com/hc/en-us/articles/26886941270171)），或者您专门收集交易同意，则只需按照这些步骤操作。否则，您可以简单地收集促销同意书，这是默认设置。您可以将交易同意添加到现有表单或构建新表单。一般来说，建议您使用已有品牌的现有表单。但是，请注意，您不能通过智能选择加入或点击文本功能来使用交易同意，请注意，这些功能将被禁用。当您添加交易同意时，它会禁用智能选择加入和点击文本。打开下面的下拉菜单，查找有关创建包含电子邮件、短信交易和短信促销的新表单的说明，或者直接跳到了解如何将短信交易添加到现有表单以获取电子邮件和短信促销同意。 ****构建用于电子邮件、短信交易和短信促销的新表单****

1. 导航至 Klaviyo 中的****注册****表单选项卡。 2. 单击右上角的****创建表单****来构建新表单。 3. 为表单命名（例如电子邮件和短信）。 4. 选择该表单应进入的列表。 - 建议：选择您的主要订阅者列表（例如时事通讯）。 - 请注意，仅交易订阅者不会添加到此列表中。 5. 选择表单类型。 - 建议：由于此示例收集多种类型的同意，因此最佳实践是使用弹出窗口、弹出窗口或全页表单。！[显示表单类型下拉列表的表单创建模式](https://klaviyo.zendesk.com/hc/article_attachments/31780026556955)
6. 建议：为您的表单使用预告片。 7. 选择****保存并设计****。 8. 可选：更改您的[预告片设置](https://help.klaviyo.com/hc/en-us/articles/4411540984859)。 9. 在预览上方的中间，选择****电子邮件选择加入****。 ![表单生成器中的电子邮件选择加入选项](https://klaviyo.zendesk.com/hc/article_attachments/31779971718171)
10. 设计您的电子邮件页面。温馨提示：

    - 您的表单至少需要一个电子邮件输入字段和按钮。 - 建议为名字和姓氏添加文本输入字段。！[收集电子邮件、名字和姓氏的表单示例](https://klaviyo.zendesk.com/hc/article_attachments/31779971723163)
11. 单击 ***** 步骤**** 按钮。 ![在表单生成器中添加步骤按钮](https://klaviyo.zendesk.com/hc/article_attachments/31779971725339)
12. 在出现的模式中，选择****短信选择加入****，然后单击****下一步****。 ![显示添加步骤以收集短信同意的选项的模式](https://klaviyo.zendesk.com/hc/article_attachments/31780026568347)
13. 选择您的短信订阅者列表。 - 请注意，会自动选择 **传统短信双重选择加入**，但这不适用于短信交易同意。！[选择短信订阅者列表的模式](https://klaviyo.zendesk.com/hc/article_attachments/31779971736347)
14. 单击****添加步骤****。 15. 选择电话号码字段。 ![选择电话号码字段的表单](https://klaviyo.zendesk.com/hc/article_attachments/31780026572571)
16. 在左侧面板中，打开 **短信同意** 下拉列表。 ![短信同意下拉菜单](https://klaviyo.zendesk.com/hc/article_attachments/34593404157979)
17. 如果您选择：

    - **单步 - 交易和促销**，这会添加一个用于促销同意的复选框。或
    - **多步骤 - 交易和促销**，这为表单添加了一个新步骤。 |  |  |
    | --- | --- |
    | ****单步**** | ****多步骤**** |
    | ![具有交易和促销短信同意的单步表格](https://cdn.sanity.io/images/6ct6b26e/help-center-dev/bdf1272a97bb459a1c00d52b682a570fd2214909-882x796.png) | ![当您选择多步骤交易和促销时，为收集促销同意而创建的步骤](https://cdn.sanity.io/images/6ct6b26e/help-center-dev/2429dd8ecb08a83cf190afd78b13e291c0192a0b-886x798.png) |
18. 根据您收集的同意更新披露语言：

    - 仅交易：专门提及交易消息（例如订单更新）。 - 交易和促销：包括对交易消息（例如订单更新）和促销消息（例如折扣、公告等）的引用。 19. 完成表单设计，然后单击“****发布****”将其设置为生效。 ### 从现有表单中收集交易同意

请按照以下步骤了解如何创建收集交易 SMS 同意的表单。请注意，向表单添加交易同意会删除任何智能选择加入或点击文本功能，因为这些功能不能与交易一起使用。 1. 导航至 Klaviyo 中的****注册****表单选项卡。 2. 选择您想要收集短信同意的表单旁边的 3 个点，然后单击****编辑表单****。 3. 在表单编辑器中，选择电话号码字段。 ![选择电话号码字段的表单](https://klaviyo.zendesk.com/hc/article_attachments/31780026572571)
4. 在左侧面板中，打开 **短信同意** 下拉列表。 ![](https://klaviyo.zendesk.com/hc/article_attachments/31780026577307)
5. 如果您选择：

   - **单步 - 交易和促销**，这会添加一个用于促销同意的复选框。或
   - **多步骤 - 交易和促销**，这为促销同意表格添加了一个新步骤。 |  |  |
   | --- | --- |
   | ****单步**** | ****多步骤（促销）**** |
   | ![具有交易和促销短信同意的单步表格](https://cdn.sanity.io/images/6ct6b26e/help-center-dev/bdf1272a97bb459a1c00d52b682a570fd2214909-882x796.png) | ![当您选择多步骤交易和促销时，为收集促销同意而创建的步骤](https://cdn.sanity.io/images/6ct6b26e/help-center-dev/2429dd8ecb08a83cf190afd78b13e291c0192a0b-886x798.png) |
6. 建议：对于单步表单，请确保标记电话号码字段用于交易 SMS 消息。 ![单步表单，其中电话号码字段被标记为用于交易短信](https://klaviyo.zendesk.com/hc/article_attachments/31781599736219)
7. 根据您收集的同意更新披露语言：

   - 仅交易：专门提及交易消息（例如订单更新）。 - 交易和促销：包括对交易消息（例如订单更新）和促销消息（例如折扣、公告等）的引用。 8. 对表单感到满意后，选择****发布****。一旦您的表格生效，您就可以开始收集与促销同意分开的交易同意。您还可以[查看个人资料中的同意类型](https://help.klaviyo.com/hc/en-us/articles/360035056972)。 ## 在结帐时收集交易同意（仅限 Shopify）

Shopify 客户可以通过应用程序块在感谢和订单状态页面上收集交易短信同意并将其同步到 Klaviyo。此外，Shopify Plus 客户可以使用应用程序块在其结帐页面上收集交易短信同意。这些应用程序块在 Klaviyo 中设置，然后安装在 Shopify 中。了解如何[在 Shopify 结帐页面上收集交易短信同意](https://help.klaviyo.com/hc/en-us/articles/35067557759771)。
