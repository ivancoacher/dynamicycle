在重新提交被拒绝的澳大利亚品牌发件人 ID 注册之前，请使用此清单。 ## ****如何修复被拒绝的申请：****

从第一列中的电子邮件或应用内通知中查找拒绝原因，然后在重新提交之前完成该行中的每项检查。 ACMA 要求发件人 ID 明确链接到实体的****注册企业名称、公司名称、商标或域名****。完整注册指南：[acma.gov.au/registering-sender-ids](https://www.acma.gov.au/registering-sender-ids)。 ****在重新提交之前修复通知中列出的所有拒绝原因。****

### ****商业登记：****

|拒绝原因 | ACMA 要求 |重新提交前检查 |
| --- | --- | --- |
| ****官方商业登记文件丢失**** **K0012** |企业必须拥有在澳大利亚相关机构注册的有效 ABN 或 ACN。状态必须为活动 (ABR) 或已注册 (ASIC)。 | † 文件是政府颁发的最新官方注册记录 † 文件上的企业名称与注册表完全一致 † 显示 ABN 或 ACN 且正确 † 企业状态为“活跃”或“已注册”（未取消或注销） † Pty Ltd：来自 [connectonline.asic.gov.au](http://connectonline.asic.gov.au) 的新 ASIC 公司摘录。确保这是列出“注册官员”的**完整**摘录。正确、完整摘录的示例可以[参见此处](https://download.asic.gov.au/media/ldmneiyw/current-company-extract-paid-feb-2026.pdf)。个体经营者：abr.business.gov.au 的 ABN 确认 信托：信托实体的 ABN 注册 合伙企业：合伙实体的 ABN 注册 |
| ****授权代表未在商业登记摘录中列出**** **K0129** |授权代表必须是 ABN 的 ABR 联系人——管理企业 ABN 的人。对于公司：必须是 ASIC 摘录中的上市董事或高级职员。 | ☐ 代表在 ASIC 摘录（私人有限公司）上被列为现任董事或高级职员 ☐ 或者是 ABR 注册中显示的 ABN 持有人（个体经营者） ☐ 或者是信托契约上的指定受托人（信托） ☐ 或者是合伙协议中的指定合伙人（合伙） ☐ 如果代表不是所列官员：确保在您重新提交时上传由所列官员签署的 LOA。 LOA 必须是[此模板](https://docs.google.com/document/d/1CGC76PLzmMl3Qo9AfgZGmU5BsG_ykUXE/edit)。 ☐ 文件上的代表姓名与表格上的姓名完全一致 |
| ****文件详细信息与注册表不符**** **K0028** |上传文件的所有详细信息必须与注册表中输入的详细信息完全一致。 | ☐ 公司名称与表格完全匹配 - 检查标点符号、空格、缩写（Pty Ltd 与 Pty. Ltd.） ☐ 文件上的 ABN/ACN 与表格完全匹配 ☐ 文件上的地址与表格完全匹配 ☐ 文件是新副本 - 不是包含过时详细信息的旧摘录 ☐ 扫描清晰，所有文本均可读 |

### ****业务和代表验证****

|拒绝原因 | ACMA 要求 |重新提交前检查 |
| --- | --- | --- |
| ****联系人必须是具有验证权限的正式业务代表**** **K0058** |授权代表必须是可根据商业登记摘录进行验证的正式商业代表。 | ☐ 代表在商业登记摘录中列为董事或高级职员 ☐ 如果未列出：确保在重新提交时上传由所列高级职员签署的 LOA ☐ 表格上的代表姓名、电子邮件和电话号码正确且完全匹配 |
| ****授权代表的电子邮件地址与业务领域不符**** **K0057** |代表的电子邮件必须使用企业的官方域名，而不是 Gmail 或 Outlook 等通用提供商。 |邮箱以企业域名结尾（例如@mybusiness.com.au） 电子邮件不是@gmail.com、@yahoo.com、@outlook.com 或类似的通用域名 电子邮件域名与企业网站域名相匹配 |
| ****电子邮件域名与网站域名不匹配**** **K0109** |电子邮件域和网站域必须匹配。 |电子邮件域名（@ 后面的部分）与网站域名匹配，例如电子邮件：name@mystore.com.au，网站：mystore.com.au |
| ****公司名称与网站 SSL 证书或 URL 不匹配**** **K0010** |公司名称必须可根据网站进行验证。 该网站必须实时、安全并显示注册的企业名称。 |网站可公开访问 网站 URL 以 https:// 开头（有效的 SSL 证书） 网站上清晰显示公司名称 网站上的公司名称与注册上的名称完全一致|
| ****网站不隶属于该企业，也不代表该企业**** **K0110** |网站必须由注册实体拥有和运营。 |网站由企业所有，而不是市场店面（例如，不是 Shopify/Etsy/Amazon 卖家页面） 网站显示企业名称、联系方式和 ABN（如果可能） |

### ****授权书 (LOA)****

|拒绝原因 | ACMA 要求 |重新提交前检查 |
| --- | --- | --- |
| ****需要授权书 (LOA)**** **K0131** |当完成注册的人不是商业登记摘录中所列的官员时，需要提供 LOA。 | ☐ 使用正确的 LOA 模板。您必须使用[此模板。](https://docs.google.com/document/d/1CGC76PLzmMl3Qo9AfgZGmU5BsG_ykUXE/edit) ☐ LOA 通过名称和 ABN/ACN 明确标识该企业 ☐ 说明被授权人的法定全名 ☐ 说明其权限（例如“代表[企业]注册和管理短信发送者 ID”） ☐ 由姓名出现在商业登记摘录中的董事或高级职员 包括签字日期 明确说明签字人的全名和职责 |
| ****授权书 (LOA) 包含不完整信息**** **K0130** | LOA 必须完整且包含所有必填字段。 |提供所有必填字段：原因、授权人姓名、公司名称/ABN、签字人姓名和角色 签字人是商业登记摘录中列出的官员 |
| ****授权书 (LOA) 未注明日期**** **K0132** | LOA 必须包含签署日期。 |签署日期明确显示在 LOA 上 如果在原始签署后添加了日期，则 LOA 已重新签署 |
| ****授权书 (LOA) 未签署**** **K0133** | LOA 必须由授权官员签署，其姓名出现在商业登记摘录中。 | † 重新提交注册时，确保上传列出授权官员的文件 † LOA 由注册摘录中列出的董事、官员或企业主签署 |

### ****发件人 ID****

|拒绝原因 | ACMA 要求 |重新提交前检查 |
| --- | --- | --- |
| ****发件人 ID 与您的法定企业名称没有明确关联**** **K0015** |发件人 ID 必须通过以下之一明确代表实体：注册企业名称（ASIC，已注册）、公司名称（ABR，有效）、注册商标（IP Australia，已注册）或注册域名（WHOIS，实体是注册人，有效）。 |发件人 ID 与 asic.gov.au 上的注册企业名称匹配 — 状态为“已注册” 或与 abr.gov.au 上的公司名称匹配 — 状态为“活跃” 或与 search.ipaustralia.gov.au 上的商标匹配 — 状态为“已注册” 或与 whois.auda.org.au 上的域名匹配 — 实体为注册人，网站/电子邮件处于活动状态 bury 如果使用品牌名称：确保重新提交时上传商标证书或域名所有权证书 bury发件人 ID 不通用、具有误导性或冒充其他实体 |
| ****发件人 ID 被 ACMA 拒绝**** **K0101** |发件人 ID 不得包含 ACMA 定义的禁止、攻击性、欺骗性或限制性词语。 |发件人 ID 不包含限制性词语 — 请检查 acma.gov.au/restricted-terms-sender-ids 发件人 ID 不具有攻击性、欺骗性或误导性 发件人 ID 不包含“未经验证”一词 如有需要，请创建新的发件人 ID 并在 Klaviyo 中更新：设置 > 短信 > 发件人信息 |
| ****发件人 ID 太通用，与您的品牌或企业名称无关**** **K0104** |发件人 ID 必须特定于品牌或企业 - 不接受通用术语。 | ☐ 发件人 ID 是该业务特定的 — 不是常用词（例如 不是“商店”、“商店”、“交易”） ☐ 如果边界：确保在重新提交以证明链接时上传商标证书或域名所有权证书 |
| ****发件人 ID 丢失或与预期格式不匹配**** **K0146** |发件人 ID 格式规则 (ACMA)： • 2–11 个字符 (ASCII 32–126) • 不仅仅是数字 • 没有前导/尾随空格或下划线 • 不包含“未验证”|发件人 ID 介于 2 到 11 个字符之间 仅包含字母、数字和空格，无特殊字符 没有前导或尾随空格 发件人 ID 与 Klaviyo 帐户设置完全匹配 |

### ****用例****

|拒绝原因 | ACMA 要求 |重新提交前检查 |
| --- | --- | --- |
| ****用例描述丢失**** **K0141** |必须提供 SMS 用例的具体、准确的描述。 |描述是具体的 - 不仅仅是“营销消息” 包括：消息类型、受众以及收件人如何选择加入 示例：“向通过我们网站结账选择加入的客户发送的促销活动和交易订单通知”。 |
| ****示例消息丢失或超过 160 个字符**** **K0142** |必须提供真实的示例消息，不得超过 160 个字符。 |样本消息不超过 160 个字符 样本反映了将要发送的实际消息（不是占位符） 包括相关的选择退出语言（例如“回复停止取消订阅”）|
| ****每月估计的消息量丢失**** **K0143** |必须提供估计的每月消息量。 |已输入实际的每月交易量估算 字段不为空 |

### ****公司地址****

|拒绝原因 | ACMA 要求 |重新提交前检查 |
| --- | --- | --- |
| ****邮政信箱不是可接受的地址形式**** **K0113** | ACMA 需要完整的实际营业地址。不接受邮政信箱。 | DDR 地址是完整的实际街道地址 地址与官方商业登记摘录中的地址相符 |
| ****不接受部分地址**** **K0114** |必须提供完整的地址，不接受部分地址。 |地址包括：街道号码、街道名称、郊区、州和邮政编码 地址与官方商业登记摘录相符 |

### ****政府颁发的身份证件****

|拒绝原因 | ACMA 要求 |重新提交前检查 |
| --- | --- | --- |
| ****所提供的身份证件不是可接受的身份证明形式**** **K0115** |必须是政府颁发的带照片的身份证件。 | ☐ 身份证件是政府签发的带照片的身份证件（澳大利亚护照或澳大利亚驾照，或由非澳大利亚政府签发的） ☐ 不是 Medicare 卡、员工 ID、会员卡或任何非照片文件 |
| ****所提供的身份证件已过期**** **K0116** | ID 必须是最新且未过期的。 | ☐ 检查过期日期，提交时身份证件必须有效 ☐ 已获取并上传新的当前身份证件 |
| ****政府颁发的身份证件上的姓名与授权代表的详细信息不符**** **K0117** |身份证件上的姓名必须与表格上输入的授权代表的姓名完全一致。 | ☐ 身份证件上的法定全名与表格上的姓名完全一致 - 包括中间名、连字符、姓名首字母缩写 ☐ 表格上没有使用昵称或简称 ☐ 如果姓名变更（例如婚姻）：上传支持文件（结婚证书、法定声明） |
| ****文件的签发机构或国家与所提供的信息不符**** **K0118** |身份证件的签发机构和国家/地区必须与表格上提供的信息一致。 |表格上的国家/地区与身份证件上的国家/地区一致 如果是外国护照：在重新提交之前联系 Klaviyo 支持人员 |
| ****身份证明未显示可见地址**** **K0119** | ID 必须显示可见的物理地址。 | † 身份证件显示实际地址 † 对于澳大利亚驾照：正面和背面均已上传，因为地址位于背面 |
| ****出生日期表明申请人未满 18 岁**** **K0120** |授权代表必须年满 18 岁。 | ☐ 代表年满 18 岁或以上 ☐ 如果未满 18 岁：已提名另一位代表 |
| ****身份证件质量问题**** **K0121 / K0122 / K0123 / K0124 / K0125 / K0126** |身份证件必须满足所有质量要求： • 政府颁发的带照片身份证件 • 彩色复印件（非黑白） • 两面（如果是双面） • 清晰可辨 • 真实且未经涂改 | † 身份证件是政府签发的带照片的身份证件（护照或驾照） † 上传的是彩色副本 † 上传双面身份证件的正面和背面（例如澳大利亚驾照） † 图像清晰、清晰且完全可见 † 文档的四个角均可见 † 不是屏幕的复印件或屏幕截图 |
| ****支持文件不清晰**** **K0127** |所有支持文件必须清晰易读。 | ☐ 所有上传的文档均清晰，所有文本均可读 ☐ 重新扫描或重新拍摄任何模糊、发暗或被裁剪的文档 |
