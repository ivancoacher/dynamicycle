## 你将会学到

了解如何将短信发送号码移植到 Klaviyo 中。

## 开始之前

请注意移植：

- 可能需要大约 4 周。迁移到 Klaviyo 时，请及时构建此过程。
- 将导致失去任何语音功能。
- 当号码无法使用时（由于验证和运营商需要将流量重新路由到该号码），需要最多约 2-5 个工作日的停机时间。

****可携号转网的号码类型****

|  |  |
| --- | --- |
| ****号码类型**** | ****可以移植吗？**** |
|免费电话 |是的 |
|短代码 |是的 |
|共享短代码|没有 |
|品牌发件人 ID |否，但您可以将 ID 设置为与之前的 ID 相同 |
|长代码 |在英国、爱尔兰和澳大利亚是的 |

## 移植免费电话号码

1. 导航至****设置****。
2. 单击****短信****。
   ![SMS_sender_information.jpeg](https://klaviyo.zendesk.com/hc/article_attachments/28720772629019)
3. 单击进入****请求附加号码****下拉列表。
4. 选择****移植现有号码****。
5. 单击****提交端口请求****。

![提交端口请求的模式](https://klaviyo.zendesk.com/hc/article_attachments/28720760831131)

## 移植一个短代码

1. 导航至****设置****。
2. 单击****短信****。
3. 单击您的短代码所在国家/地区的****激活****（例如，如果您有美国短代码，请单击****激活****，其中“美国”是受支持的区域）。
4. 从号码列表中选择****短代码****。
5. 单击****完成订单**** 以访问该应用程序。

## 结果

提交携号转网请求后，Klaviyo 代表将会与您联系。当有人联系您并提交所有必需的信息后，移植过程开始：

- 对于长代码，移植可能需要 2 到 4 周才能完成。
- 对于免费电话号码，移植可能需要 2 到 4 周才能完成。
- 对于短代码，移植可能需要 4 周才能完成。
