本文概述了如何在移动消息传递渠道（包括 WhatsApp、RCS、MMS 和推送）中管理和发送视频内容。

## ****媒体库****

为了更好地适应视频内容，Klaviyo 的“图像和品牌”部分已更名为****媒体和品牌****。

### ****上传和管理视频****

您现在可以将 ****MP4**** 和 ****MPEG**** 文件直接上传到您的库。

- ****文件大小限制****：单个视频上传的上限为****10MB****。
- ****组织****：您可以使用新的****文件类型过滤器****在查看图像（PNG、JPG、GIF）和视频（MP4、MPEG）之间切换。
- ****缩略图****：Klaviyo 自动生成上传视频的缩略图。
- 单击库中的缩略图将打开一个带有完整播放控件的预览选项卡。

## ****将视频添加到移动消息****

您可以在 WhatsApp、RCS、MMS 和推送通知的编辑器中将视频附加到消息中。工作流程与添加图像相同：浏览媒体库或直接从编辑器上传文件。

### ****频道特定要求****

|  |  |  |
| --- | --- | --- |
| ****频道**** | ****支持的文件类型**** | ****支持的文件大小**** |
| ****WhatsApp**** |仅支持****MP4****； MPEG 文件将在库中显示为禁用。 |附加的视频文件不能超过 ****10MB.**** |
| ****RCS**** |支持 MP4 和 MPEG 丰富的卡。 |附加的视频文件不能超过****10MB。**** RCS 消息中所有卡上的媒体文件总大小不能超过****100MB。**** |
| ****彩信**** |支持 MP4 和 MPEG。 |附加的视频文件不能超过 ****10MB。**** 大于 ****600KB**** 的视频文件可以附加到彩信，但 Klaviyo 不建议这样做。 |
| ****推**** |仅 ****iOS 设备**** 支持视频和 GIF； Android 收件人将跳过这些。 |附加的视频文件不能超过 ****10MB.**** |

## ****重要注意事项****

- ****彩信文件大小****：如果彩信中的视频超过****600KB****，编辑器中将出现警告横幅。较大的文件可能会受到运营商限制或压缩。
- ****电子邮件编辑器****：电子邮件编辑器****不支持****视频。如果您从电子邮件模板访问媒体库，视频将显示为禁用状态。
- ****Image Remix****：您无法通过 Image Remix 工具使用视频。
- ****压缩****：视频目前不受 Klaviyo 的自动图像压缩设置的限制，并将以与 GIF 类似的方式处理。
