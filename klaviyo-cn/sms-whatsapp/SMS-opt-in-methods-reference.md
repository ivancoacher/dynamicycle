请记住，您的所有受众都是潜在的短信订阅者，从新网站访问者到一次性客户、电子邮件订阅者或社交媒体关注者。在收集短信同意时，请记住一些最佳实践，以扩大受众群体并增加收入：

- SMS 必须是可选的，并且不能看起来是必需的。为了实现这一点，短信同意应与任何其他营销渠道分开收集。 - 作为一般最佳实践，如果您同时要求提供电子邮件和电话号码，请使用多步骤表单，以便有一个清晰、单独的短信选择加入按钮。 - 设置 SMS 合规性基础知识，以与客户建立信任并从法律角度保持信心：
  - [创建移动服务条款](https://help.klaviyo.com/hc/en-us/articles/360049177511) (TOS) 以链接到您收集短信同意的任何地方。 - [更新您的隐私政策](https://help.klaviyo.com/hc/en-us/articles/4404199571867)，包括您的短信营销计划的说明、您如何存储电话号码和位置数据，以及您将通过短信发送的消息类型。 - [创建短信披露语言](https://help.klaviyo.com/hc/en-us/articles/11644128409371)，必须包含在您收集短信同意的任何地方。在注册表单上，最佳做法是将披露语言放在提交按钮上方，以便订阅者在注册之前了解他们选择的内容。 - 虽然表单中有多种短信选择加入方法，但[智能选择加入](https://help.klaviyo.com/hc/en-us/articles/24743883751451)是列表增长和简化短信订阅体验的优化方法。 ## 短信选择加入方法

Klaviyo 提供了多种不同的方式来收集短信同意：

- [注册表单](https://help.klaviyo.com/hc/en-us/articles/27902671291419#h_01J472TF8016NMR0QED2C51BZ9)，可以通过以下方式收集电话号码：
  - 智能选择加入
  - 点击文本
  - 电话号码输入字段
- [短信订阅链接](https://help.klaviyo.com/hc/en-us/articles/27902671291419#h_01J472TF80CTZTZRFWB7X44CVM)
- [订阅关键词](https://help.klaviyo.com/hc/en-us/articles/27902671291419#h_01J472TF80JCW3QWS3Z03JCG6Q)
- [结账时同意](https://help.klaviyo.com/hc/en-us/articles/27902671291419#h_01J472TF81SWB8YFR5VAGFCAPJ)，适用于：
  - 购物
  - Magento 2
  - 大商务
  - WooCommerce
  - Prestashop
- [API](https://help.klaviyo.com/hc/en-us/articles/27902671291419#h_01J472TF81450BCHPSQVX6G9V7)

如果您使用表格或订阅链接来收集电话号码，则可以在电子邮件或 Instagram 页面上直接链接到这些电话号码。 ### 表格

可通过 3 种方法在注册表单中收集网站访问者的电话号码：

1. 智能选择加入（列表增长的最佳实践）
2. 点击文本
3. 电话号码输入栏

#### 智能选择加入

您必须有付费短信计划才能在注册表单中配置智能选择加入。工作原理：

1. 在注册表中输入电话号码的网站访问者会立即收到一条包含一次性密码的消息。 2. 注册表单显示另一个步骤，要求提供一次性代码以确认订阅并加入您的列表。 3. 一次性代码会自动填充在 iOS 和 Android 浏览器上，因此网站访问者可以无缝地双重选择加入，而无需在其消息应用程序中采取操作。 ![显示互联网浏览器的移动设备，有人在表单的输入字段中输入电话号码，然后单击填充的自动填充一次性代码，并确认订阅。](https://fast.wistia.com/embed/medias/6n4a2zlbw6/swatch)

好处：

- 优化列表增长
  - 智能选择加入是增加列表增长的最佳实践，因为它可以在选择加入过程中让购物者留在您的网站上，减少摩擦并提高选择加入率。 - 为您的购物者提供无缝选择加入体验
  - 通过智能选择加入，网站访问者无需在消息应用程序中执行任何操作，从而最大限度地减少分心的机会，并为短信选择加入体验带来速度和轻松。 - 适用于所有设备和发送号码
  - 智能选择加入适用于所有设备（例如桌面和移动设备）和发送号码类型（例如长代码、短代码、品牌发件人 ID 等）。 - 采用两步同意流程，类似于双重选择加入
  - 通过智能选择加入收集短信同意类似于双重选择加入流程，访问者需要执行 2 个步骤来选择加入：输入他们的电话号码，然后输入他们收到的一次性代码。强烈建议在收集短信同意时使用双重选择加入，在美国，如果您计划将短信添加到废弃的购物车流程，则需要双重选择加入。有关智能选择加入的设置指南，请参阅[如何使用智能选择加入收集短信同意](https://help.klaviyo.com/hc/en-us/articles/24743883751451)。 #### 点击文本

工作原理：

1. 移动和桌面设备上的网站访问者会看到不同的选项：
   1. 在桌面上：用户在输入字段中手动输入号码。 2. 在移动设备上：
      - 用户单击表单中的按钮。 - 用户的消息传递应用程序将打开，并显示一条包含订阅关键字的预填充消息。 - 用户发送消息。 2. 下一步取决于您订阅消息中的关键字是使用单选择加入还是双选择加入：
   - 单次选择加入：用户立即成为订阅者。 - 双重选择加入：用户在完全成为短信订阅者之前必须确认其订阅。 ![用户通过 Klaviyo 的 Tap to Text 成功订阅文本更新的视频](https://klaviyo.zendesk.com/hc/article_attachments/43033458821531)

如果您计划发送到多个国家/地区，则点击发送文本要求您设置多个表单，并且它也不适用于品牌发件人 ID。一般来说，我们建议使用智能选择加入，它具有所有相同的优点，但没有这些缺点。 ![用户在桌面或移动设备上使用点击文本订阅服务的两种方法的流程图。](https://klaviyo.zendesk.com/hc/article_attachments/28716119302427)

好处：

- 流程简单
  - 用户只需点击一个按钮并发送一条预先填充的消息，使选择加入过程变得快速而简单。 - 减少用户错误
  - 用户无需在移动设备上手动输入电话号码或其他详细信息，从而最大限度地降低拼写错误或错误号码的风险。 - 采用两步选择加入流程
  - 默认情况下，用户必须执行 2 个步骤才能成为 SMS 订阅者：点击按钮并发送文本。这不仅有利于合规性（因为它类似于双重选择加入），而且还可以生成更清晰、更准确的订阅者列表，因为发送文本会验证该号码是否有效并由订阅者拥有。 - 移动优化
  - 点击文本对于移动设备上的购物者来说是一种有效的选择加入方法，因为它利用了移动电话的本机功能。您可以使用动态块以一种形式创建不同的视图，以便移动购物者看到点击文本体验，而桌面购物者看到电话号码输入字段。有关点击文本的设置指南，请参阅[如何通过点击文本表单收集短信同意](https://help.klaviyo.com/hc/en-us/articles/9351341171995)。 #### 电话号码输入字段

工作原理：

1. 网站访问者可以单击注册表单中的输入字段。 2. 用户手动输入电话号码。 3. 单击按钮提交表单并订阅短信营销。 ![单击注册表单编辑器中的电话号码输入字段块，然后拖放到示例表单的预览 SMS 选择加入步骤中。](https://fast.wistia.com/embed/medias/u2waz8b93t/swatch)

好处：

- 轻松设置
  - 可以将电话号码输入字段从表单编辑器中的 **添加块** 选项卡拖动到任何注册表单中，并且无需配置任何其他操作。 - 熟悉的流程
  - 注册表单中的电话号码输入字段以适用于所有设备类型的简单、熟悉的方式收集电话号码。电话号码字段是标准字段，但不像智能选择加入或点击文本那样适合移动设备或简化。一般情况下，仅在桌面设备上显示此字段。有关电话号码输入字段的设置指南，请参阅[了解表单块和字段](https://help.klaviyo.com/hc/en-us/articles/4413550187035)

### 短信订阅链接

工作原理：

1. 您创建短信订阅链接并设计订阅页面。 2. 您在电子邮件中分享该链接或将其发布在社交媒体故事中。 3. 点击链接会自动重定向：
   - 移动用户获得点击文本体验
   - 桌面用户通过电话输入字段访问订阅页面

短信订阅链接只能由长代码、短代码和免费发送号码使用。它们不适用于品牌发件人 ID，因为它们无法接收短信。 ![新用户促销的流程，专门用于注册短信提醒以获得 15% 折扣，显示桌面和移动设备上的短信订阅链接工作流程。](https://klaviyo.zendesk.com/hc/article_attachments/28716058536603)

好处：

- 促进短信列表增长
  - 短信订阅链接是动态的，可为每个购物者的设备启动最佳的短信选择加入体验，从而减少摩擦并允许购物者快速注册。 - 跨平台的可访问性和规模
  - 在社交媒体帖子或故事中分享短信订阅链接的功能允许观众从任何平台订阅，从而扩大您的覆盖范围。请记住，订阅链接仅适用于 1 个发送号码。例如，如果您在美国和加拿大都使用免费电话号码，则可以使用单个订阅链接来收集这两个国家/地区的 SMS 订阅者。但是，假设您在加拿大使用短代码。在这种情况下，您需要为每个国家/地区创建单独的订阅链接。然后，您需要显示一个仅指向美国的链接，另一个仅显示指向加拿大的链接。有关如何创建和共享短信订阅链接的指南，请参阅[如何创建短信订阅链接](https://help.klaviyo.com/hc/en-us/articles/14104388043931)。 ### 订阅关键词

工作原理：

1. 在您的 Klaviyo 帐户中创建自定义订阅关键字（例如“JOIN”、“TEXT”、“SUBSCRIBE”）。 2. 通过各种渠道（例如您的网站、电子邮件和社交媒体）宣传该关键字和您的专用发送号码。 3. 人们将该关键字发送到您的发送号码以选择加入短信营销。 4. 向关键字发送短信后，会发生什么情况取决于关键字是使用单选择加入还是双选择加入：
   - 单次选择加入：订阅者会收到一条自动确认消息，确认其订阅，并且通常会提供欢迎消息或优惠。 - 双重选择加入：用户在完全成为短信订阅者之前必须确认其订阅。订阅关键字只能由长代码、短代码和免费发送号码使用。它们不适用于品牌发件人 ID，因为它们无法接收短信。 ![显示用户通过发送包含专用订阅关键字的短信来订阅短信营销的流程图。](https://klaviyo.zendesk.com/hc/article_attachments/28716119304987)

好处：

- 易于使用
  - 通过简单的关键字订阅对客户来说既快捷又简单，减少了选择加入的障碍。 - 即时选择加入
  - 该过程是即时的，允许客户实时订阅，而无需浏览表格或页面。 - 用途广泛
  - 关键字可以在各种环境中使用（例如，在活动期间、销售期间、销售点等），并且可以在多个地点进行推广以吸引广泛的受众。请注意，如果您有[回复入站短信的流程](https://help.klaviyo.com/hc/en-us/articles/360049930372)，则该流程可以回复任何单词（包括但不限于订阅关键字）。有关如何使用订阅关键字的指南，请参阅[如何添加自定义关键字](https://help.klaviyo.com/hc/en-us/articles/360050384091)。 ### 结账时收集短信

工作原理：

- 如果您使用 Shopify、Magento 2、BigCommerce、WooCommerce 或 PrestaShop，您可以在结帐时请求短信同意，以定位与您的品牌高度互动的购物者。 - 如果客户有兴趣选择短信营销，则在结账时填写个人信息也可以选中一个复选框。 - 提供电话号码的客户可以通过在结账过程中单击继续前往运送详细信息页面来确认此选择。当他们确认订单时，他们也确认了他们同意短信营销。 ![示例结帐页面上的短信同意复选框显示选择订阅短信营销，然后在输入字段中输入电话号码的用户。](https://klaviyo.zendesk.com/hc/article_attachments/28716058534811)

好处：

- 简化的用户体验
  - 通过在客户已经提供信息时请求同意，这种方法可以无缝集成到用户体验中，最大限度地减少摩擦并增加获得同意的可能性。 - 针对参与且感兴趣的受众
  - 在结帐阶段获得同意可确保您瞄准对您的产品真正感兴趣的个人，从而为未来的营销工作带来更高质量的潜在客户。有关谁可以在结帐时收集短信同意以及如何设置的更多信息，请参阅我们的[在您网站上结帐时收集短信同意的指南](https://help.klaviyo.com/hc/en-us/articles/25220861016091#h_01HWDX24XA6VWQKE862ZN0SY8K)。 ### API

工作原理：

- 您可以从第三方应用程序或通过 API 将短信同意导入 Klaviyo。使用此方法，我们建议您的开发人员或具有 API 调用经验的人员测试您是否正确地将短信同意导入到 Klaviyo 中。好处：

- 您可以使用此方法从您可以构建的任何平台导入短信同意。有关收集和同步同意的指南，请参阅[如何通过 API 收集短信同意](https://developers.klaviyo.com/en/docs/collect_email_and_sms_consent_via_api)。 ## 使用这些选择加入方法的灵感

### 在电子邮件中包含订阅链接或注册表单链接

发送一封包含订阅链接或指向您的注册表单的链接的电子邮件，以鼓励现有电子邮件订阅者选择加入短信营销。电子邮件订阅者已经与您的品牌建立了良好的关系，因此他们更有可能信任您，并且愿意分享他们的电话号码进行短信通信。使用电子邮件中的订阅链接或注册表单链接：

- [在电子邮件中分享短信订阅链接](https://klaviyo.zendesk.com/hc/en-us/articles/14104388043931)
  您可以创建一个短信订阅链接以在您的电子邮件中共享，以便任何点击该链接的人都可以轻松选择加入短信营销。 - [电子邮件中注册表单的链接](https://help.klaviyo.com/hc/en-us/articles/8185730542235)
  您可以在网站的登陆页面中嵌入短信注册表单，然后向现有的电子邮件订阅者发送消息（例如流程或活动），将他们引导至可以选择加入短信营销的登陆页面。 ### 定位你的 Instagram 受众

在 Instagram 故事中分享短信订阅链接，以鼓励已经关注您的内容的观看者立即采取行动。 Instagram 故事具有很高的可见度，因此在故事中分享短信订阅链接可以帮助您快速吸引更多受众。在 Instagram 故事中使用订阅链接：

- 创建短信订阅链接以在您的社交媒体渠道（例如 Instagram）中分享，以便任何点击它的人都可以轻松选择加入短信营销。 - 短信订阅链接是动态的，因为它们会自动优化所有设备上购物者的注册体验，将移动购物者重定向到点击文本体验，并将桌面购物者发送到 Klaviyo 列表的取消订阅页面。有关在 Instagram 上收集短信同意的更多指南，请参阅[如何通过点击文本链接收集短信订阅者](https://help.klaviyo.com/hc/en-us/articles/360059544911#01H8PG1DGTHWPXGZ26TBCSX0YE)。 ### 将短信订阅链接转换为二维码

您可以将短信订阅链接转换为二维码，使客户可以轻松共享他们的联系信息，而不会减慢结账速度。通过在实体店或促销材料上放置二维码，购物者可以快速扫描进行注册。通过二维码将访问者引导至订阅页面可帮助您扩大短信订阅者列表，以便您可以发送个性化消息和优惠，鼓励重复购买。要为您的订阅链接创建二维码：

1. 在 Klaviyo 中，导航至****受众 > 增长工具****。 2. 滚动到**管理订阅链接**，然后单击****管理****。如果您尚未创建，请创建您的第一个短信订阅链接。请注意，为了实现合规性最佳实践，您的链接所绑定的订阅页面应仅收集电话号码。 3. 在您要使用的订阅链接旁边，点击****复制****。 4. 使用第三方工具（例如 Swapt）生成二维码，将复制的短信订阅链接粘贴为目标 URL。 5. 生成代码并发挥创意；将其添加到海报、名片、传单等中。 ### 在您的网站上显示关键字

通过竞赛、调查或测验等互动元素来增强网站的参与度。通过向您的发送号码发送特定关键字的短信来鼓励访问者参与。将关键字与竞赛或赠品结合起来是一种创新策略，可以提高短信选择加入并推动互动；但是，无论您在何处放置关键字，请务必包含披露语言。请注意，订阅关键字不适用于品牌发件人 ID，因为它们无法接收短信。在您的网站上使用关键字进行调查：

1. 使用第三方工具创建测验。 2.
