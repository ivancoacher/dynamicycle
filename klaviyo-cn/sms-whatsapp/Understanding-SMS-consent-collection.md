## 你将会学到

了解短信同意，包括什么算作短信同意、如何收集同意以及重新订阅的工作原理。短信同意是指某人是否选择加入（即，他们是否同意接收来自您的品牌的营销短信）。有关如何判断个人资料是否同意短信的信息，请参阅有关 [Klaviyo 如何存储同意](https://help.klaviyo.com/hc/en-us/articles/360037101072) 的文章。 ## 开始之前

在 Klaviyo 中，您必须具备 2 件事才能收集短信同意：

- [短信已开启](https://help.klaviyo.com/hc/en-us/articles/4404274419355)。 - 您想要收集短信同意的国家/地区的有效[发送号码](https://help.klaviyo.com/hc/en-us/articles/6637671573403)。该号码可能还需要验证或注册。如果您尚未启用短信，或者没有该国家/地区的发送号码，则无法收集短信同意。您只能在[可使用 Klaviyo SMS 的国家/地区]收集订阅者(https://help.klaviyo.com/hc/en-us/articles/4402914866843)。 ## 什么才算是短信同意

短信比大多数其他营销渠道受到更严格的监管。因此，对于什么才算是正确的短信同意有更严格的要求。下面，我们将详细介绍您需要对短信执行哪些操作。 ### 个人必须明确同意接收短信

无论您发送的是营销消息还是交易消息，都必须有人同意接收来自您的品牌的短信。通常，有人通过在结帐时选中复选框或通过表格注册来订阅。短信同意还必须与任何其他营销渠道分开收集。例如，虽然您可以以同一表格收集电子邮件和短信同意，但您必须明确短信是可选的（通常通过单独的复选框或按钮）。不能向多个品牌或组织提供单一同意。客户必须明确同意接收来自贵公司的消息。潜在客户开发、关联公司相关或购买的列表不是有效的短信同意。 ### 您不能强制短信同意

强迫某人注册短信才能进行购买是违法的。此外，提供短信同意不能**显得**好像是必需的。即使您的客户可以选择是否给予短信同意，但如果**似乎**需要短信同意，您也可能会面临罚款或合规问题。例如，不建议在注册表单的同一步骤中收集短信和电子邮件同意，因为客户可能认为如果他们想要注册电子邮件，就必须注册短信。 ### 无论您在何处收集短信同意，都使用披露语言

短信订阅者在注册之前必须了解他们同意的内容。为了明确这一点，请在您收集短信同意的任何地方添加[披露语言](https://klaviyo.zendesk.com/hc/en-us/articles/4412878737051)，无论是在结帐页面、表单、电子邮件中的横幅、社交媒体帖子还是第三方测验或表单（当使用 API 发送同意时）。这适用于所有选择加入的方法，从注册表单到订阅关键字。任何潜在订阅者在点击提交或输入关键字之前都应该了解他们正在注册的内容。 ![点击文本表单突出显示披露语言](https://klaviyo.zendesk.com/hc/article_attachments/28720771282459)

****披露语言应该在表格中放在哪里？****

您应该将披露语言放在短信同意复选框或按钮上方。这样，人们在选择加入之前就会看到披露语言。 ### 如果使用购物车放弃消息，请使用双重选择加入（美国）

虽然始终建议双重选择加入，但这也是美国运营商对任何购物车放弃流程（例如放弃购物车、添加到购物车等）的要求。通过双重选择加入，某人在被添加为您帐户中的订阅者之前必须执行 2 个操作，例如输入电话号码，然后通过短信确认，或单击按钮，然后发送关键字短信。 ### 常见问题解答

****拥有某人的电话号码是否视为同意发送短信？****

不。如果有人向您提供了他们的电话号码，并不意味着他们允许您向他们发送短信。虽然您确实需要电话号码才能给某人发短信，但他们也必须明确表示他们希望接收营销短信。 ****同意电子邮件是否视为同意短信？****

不。同意电子邮件并不意味着您同意短信。 个人必须专门选择短信营销；选择使用任何其他营销渠道（包括电子邮件）并不视为同意短信。 ****我应该对电子邮件和短信使用相同的选择加入复选框或按钮吗？****

不可以。例如，如果您只有一个复选框来收集电子邮件和短信的同意，则您将面临不合规的风险。作为最佳实践，您应该始终使用单独的复选框或按钮来表示短信同意。 ****我可以使用通用的“同意营销”复选框或按钮进行短信吗？****

不。最好有一个专门用于短信的复选框或按钮。在大多数国家/地区，一般的“同意营销”选项对于 SMS 来说并不足够。 ****在收集电子邮件和短信同意时我应该使用单页或多步骤表单吗？****

一步收集电子邮件同意，另一步骤收集电话号码的多步骤表单是收集电子邮件和短信同意的最佳选择，因为它们允许您单独收集每个渠道的同意。可以使用单步表单，但仅限于双重选择加入，并且短信同意显然是可选的。除了不需要短信同意之外，您还应该有一个标签，说明它是可选的（例如，“接收短信营销的电话号码（可选）”）。 ## 如何收集同意

您可以通过多种不同的方式收集短信同意。其中一些选项应在您首次开始使用短信时完成，而其他选项可以留到以后或仅在某些情况下完成。因此，我们将它们分为 3 类：

1. 基础（每个人一开始使用短信就应该做的事情）
2. 中级（可以留到以后再做）
3. 高级（只有特定用户才应该执行的操作）

我们将在本文中简要介绍收集短信同意的不同方法，并链接到其他更详细的文章，以获取当您准备好建立同意渠道时的分步说明！ ### 基本方法

这些是每个人首次设置 SMS 时都应该采取的操作。收集短信同意的基本形式有两种：

1. 创建针对新订阅者和当前电子邮件订阅者的注册表单（预计时间：10-15 分钟）。 - 一般来说，最有效的表单类型是[智能选择加入](https://help.klaviyo.com/hc/en-us/articles/24743883751451)；但是，这不适用于收集短信交易同意的表单。 2. 在您的电子商务商店结账时收集短信同意：（预计时间：10 分钟）。 - [Shopify](https://help.klaviyo.com/hc/en-us/articles/360056824732)
   - [WooCommerce](https://help.klaviyo.com/hc/en-us/articles/360057745791)
   - [BigCommerce](https://help.klaviyo.com/hc/en-us/articles/360058194032)
   - [Magento 2](https://help.klaviyo.com/hc/en-us/articles/360058698511)
   - [PrestaShop](https://help.klaviyo.com/hc/en-us/articles/26534999577243)

![短信弹出表单示例](https://klaviyo.zendesk.com/hc/article_attachments/28720771280923)

****为什么要使用注册表单？****

[创建收集短信同意的表单](https://help.klaviyo.com/hc/en-us/articles/27902671291419#h_01J472TF8016NMR0QED2C51BZ9)使访问您网站的任何人都可以轻松注册。弹出窗口是收集订阅者的最常见方式之一，您可以使用它们来定位那些全新或已经是电子邮件订阅者的人。您还可以使用[智能选择加入](https://klaviyo.zendesk.com/hc/en-us/articles/24743883751451) 创建表单，以便在桌面和移动设备上轻松收集短信同意。如果您在收集短信同意的同时收集电子邮件同意，我们强烈建议您使用多步骤表单。 ****为什么要在结账时收集短信同意？****

增加短信列表最快、最简单的方法之一是在结账时收集同意。结帐时的同意为您提供了一种非侵入性、简化且简单的方式供客户注册。通过 Klaviyo 的集成，您可以利用这种方法并通过短信营销吸引更广泛的受众。 ### 中间方法

您不需要在设置 SMS 后立即执行这些同意方法。相反，请等到您完成基本同意收集步骤、关键短信流程的设置，例如短信[欢迎](https://help.klaviyo.com/hc/en-us/articles/360036122291)、[废弃购物车](https://help.klaviyo.com/hc/en-us/articles/9352115400219)和购买后流程；以及我们的[短信入门](https://academy.klaviyo.com/en-us/collections/getting-started-with-sms)中推荐的其余步骤。 1. [使用电子邮件收集短信同意](https://help.klaviyo.com/hc/en-us/articles/8185730542235)（预计时间：10分钟）。 2. [创建订阅链接以在广告或社交媒体上分享](https://help.klaviyo.com/hc/en-us/articles/14104388043931)（预计时间：5-10 分钟）。 - [通过 Instagram 贴纸收集短信同意](https://help.klaviyo.com/hc/en-us/articles/360059544911)（预计时间：5 分钟）。请注意，这些步骤仅适用于已经在使用 Instagram 的企业。 ****如何使用电子邮件来收集短信同意？****

如果您当前有仅电子邮件订阅者的列表，您也可以要求该组注册短信。特别是，高度参与的订户和 VIP 是很好的目标群体。在购买后流程中宣传您的短信计划（以及如何注册）也很有用。另一种策略是在赢回流程中使用纯文本电子邮件询问人们是否愿意通过短信收到您的消息。使用电子邮件收集 SMS 订阅者的方法有两种。 1. 链接到电子邮件中的嵌入表单。 2. 创建要在电子邮件中使用的点击文本横幅。请注意，只有当收件人在移动设备上打开电子邮件并且未使用 Gmail 或 Outlook 时，这些横幅才会起作用。我们的文章[如何使用电子邮件收集短信同意](https://help.klaviyo.com/hc/en-us/articles/8185730542235) 讨论了这两种方法。 ****如何使用订阅链接来收集订阅者？****

您可以[创建订阅链接](https://klaviyo.zendesk.com/hc/en-us/articles/14104388043931)通过广告、社交媒体帖子等来扩大您的短信列表。订阅链接为移动设备上的用户提供了简单的点击文本体验，并为桌面设备上的用户提供了订阅页面。然后，您可以将此链接作为 Instagram 贴纸的一部分发布。因此，您可以更轻松地获得看到它的任何人的同意。 ![带有收集短信同意链接的 Instagram 贴纸示例](https://klaviyo.zendesk.com/hc/article_attachments/28720759412123)

### 高级方法

高级同意收集方法需要开发人员或具有 API 调用经验的人员。通过进行 API 调用，您可以将第三方注册表单或测验信息中的短信同意传输至 Klaviyo。有关详细信息，请参阅我们的开发者门户[有关通过 API 收集电子邮件和短信同意的文章](https://developers.klaviyo.com/en/docs/collect_email_and_sms_consent_via_api#relevant-endpoints)。对于某些第三方（包括 [Privy](https://help.privy.com/hc/en-us/articles/360038080413#Synctootherproviders) 和 [Justuno](https://support.justuno.com/en/collect-more-information-with-klaviyo-sms-integration)），您无需自行设置 API 调用，因为他们会通过整合。请注意，无论您在何处收集同意，您仍然需要适当的披露语言，包括如果您正在使用 API。 ## 重新订阅短信

请注意，对于 UNSTOP 和 START [关键字](https://klaviyo.zendesk.com/hc/en-us/articles/360050384091)，您必须有一个“短信订阅者”列表，标题和大写与所示完全相同。根据某人选择退出的方式，他们可能需要以某种方式重新订阅。如果您有免费电话号码，并且有人之前发过短信“停止”，那么他们重新订阅的唯一方法就是发短信“开始”或“停止”。无线运营商需要这样做才能传递消息。如果他们使用其他方法重新订阅，个人资料将显示该个人已选择加入，但无线运营商不会向该收件人发送任何消息，直到他们发送“开始”或“停止”一词。如果您的客户没有通过 STOP 关键字选择退出，而是使用取消订阅链接，他们可以使用表单、START 或 UNSTOP 或通过结账重新订阅。同样，如果您有短代码，您的客户可以通过任何方法重新订阅。 ## 其他资源
