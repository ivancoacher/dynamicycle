## 你将会学到

了解每个营销渠道（短信、电子邮件或移动推送）的优势以及首先发送给每个渠道的时间。

请注意，没有单一的“正确”答案。使用的最佳渠道取决于您的受众和信息。这里分享的建议只是一个起点，您应该始终测试和评估什么最适合您的品牌。

## 开始之前

每个渠道都有自己的优点和缺点。

例如，渠道的优点是：

|  |  |  |
| --- | --- | --- |
| ****电子邮件**** | ****短信**** | ****手机推送**** |
| - 覆盖范围/列表增长幅度大 - 发送频率高 - 技术要求低 - 合规性规定较低 - 消息寿命长 | - 立即 - 中等覆盖范围/列表增长 - 高参与度 - 低技术要求 | - 即时 - 高参与度 - 低合规性要求 |

## 短信和电子邮件

您可以对短信和电子邮件使用 3 种策略。您可以：

- 先发送短信，然后发送电子邮件。
- 先发送电子邮件，然后发送短信。
- 同时发送电子邮件和短信，然后通过收件人参与的任何渠道进行跟进。

|  |  |  |  |
| --- | --- | --- | --- |
|  | ****专业**** | ****Con**** | ****最适合**** |
| ****短信优先**** |收件人可以立即查看并参与您的消息，并且发送之间的时间更短。 |它更昂贵，因为您需要发送给所有参与的短信订阅者。 |时间敏感的消息，例如产品发布或限时抢购。 |
| ****先发送电子邮件**** |您可以节省[学分](https://help.klaviyo.com/hc/en-us/articles/13502982552347)，同时吸引相同的受众并获得出色的表现。 |交错参与，不像先发送短信那么立即。 |任何对时间不敏感的流程或活动，例如向上/交叉销售自动化和时事通讯活动 |
| ****同时发送短信和电子邮件**** |通过首选渠道吸引用户。 |意味着立即向短信订阅者发送双重消息，如果他们同时收到短信和电子邮件提醒，可能会感到沮丧。 |具有高参与度的流程，例如废弃的购物车或购买后。请勿在战役、日落流程或赢回流程中使用。 |

这些策略都是不错的选择。您可以选择其中一个并将其用于所有消息传递，也可以根据情况在它们之间进行切换。

例如，一些企业更喜欢首先使用电子邮件设置混合短信和电子邮件流。原因是流消息（欢迎流除外）往往不像营销活动那样对时间敏感。由于您稍后发送短信，因此这种方法使用的积分比从短信开始要少。

## 通过电子邮件或短信进行移动推送

一般来说，推送应优先于短信或电子邮件。您希望吸引人们进入您的应用程序并让他们再次与您互动。

在以下情况下，这可能不是推送通知的良好用例：

- 您希望再次引用该信息。
- 收件人应该访问您的网站（而不是您的应用程序）。
- 您希望收件人在 Klaviyo 中回复并记录该数据（查看项目或回答调查）。
- 某些流程中的推送可能会被视为奇怪（感谢流程或取消订单）。
