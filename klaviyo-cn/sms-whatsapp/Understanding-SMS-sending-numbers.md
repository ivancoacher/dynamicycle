在许多国家/地区，无线运营商要求您注册或验证您的发送号码。这样运营商就可以检查您是否是可信的发件人。验证或注册您的号码所需的时间因号码类型和国家/地区而异。举例来说：

- [免费电话](https://help.klaviyo.com/hc/en-us/articles/4415873897499) 需要 2 到 5 个工作日。 - [长代码](https://help.klaviyo.com/hc/en-us/articles/26705180655003) 在澳大利亚、爱尔兰和比利时需要 1 到 3 个工作日。 - [品牌发件人 ID](https://help.klaviyo.com/hc/en-us/articles/14953787622427) 在澳大利亚和爱尔兰需要 7 到 10 个工作日。 - [短代码](https://help.klaviyo.com/hc/en-us/articles/26886941270171) 花费的时间最长，来自：
  - 5 至 6 周（新西兰）。 - 12 至 16 周（加拿大）。除短代码外，验证或注册通常不超过 7 至 10 个工作日。 ## 发送号码费用

免费电话号码、品牌发件人 ID 和长代码均免费提供。短代码和个性短代码是唯一需要每月支付额外费用的发送号码，费用因国家/地区而异。 ## 免费电话号码

免费电话号码是 Klaviyo 中美国和加拿大的默认发送号码。一旦您设置 SMS，它们就会自动创建。使用相同的免费电话号码发送至这两个国家。 如果存在以下任何情况，您应该使用免费电话号码：

- 您是短信营销新手。 - 您一次发送的消息少于 300,000 条。 - 您主要通过流程或向小型、分段的群组发送文本。 - 您想要将图像或 GIF 发送到加拿大。 - 注意：免费电话号码是唯一可以发送彩信的加拿大发送号码。免费电话号码必须经过[验证](https://help.klaviyo.com/hc/en-us/articles/4415873897499)，但并非所有行业都符合资格。我们不建议使用未经验证的免费电话号码发送信息。免费电话号码验证通常需要 2 到 5 个工作日。 ****如何验证免费电话号码****

当您打开短信时，系统会要求您提供[信息](https://help.klaviyo.com/hc/en-us/articles/4415873897499)，以便接收免费电话号码。填写此信息后，Klaviyo 将为您分配一个号码并自动提交以供验证。 ****释放免费电话****

不建议释放免费电话号码。已释放的免费电话号码无法恢复。美国和加拿大使用相同的免费电话号码。如果您释放显示的美国免费电话号码，加拿大的该号码也会被删除。您可能想要释放免费电话号码的唯一情况是您已经拥有美国和加拿大的短代码。 ## 品牌发件人 ID

[品牌发件人 ID](https://help.klaviyo.com/hc/en-us/articles/14953787622427)（也称为字母数字 ID）是英国、爱尔兰、德国、法国、奥地利、西班牙、瑞士、丹麦、挪威、芬兰、瑞典、意大利、葡萄牙、波兰和澳大利亚的 Klaviyo 中的默认选项。所有国家/地区都使用相同品牌的发件人 ID。如果品牌对您很重要，那么品牌发件人 ID 最适合您的业务。品牌发件人 ID 有 3 个主要好处；他们：

- 可以根据您的品牌进行定制，以便收件人始终知道他们的消息来自谁。 - 比长代码适用于更多国家/地区。 - 发送速度比长代码更快，因此更适合大型活动。澳大利亚有一个品牌发件人 ID 的注册流程，需要 7 至 10 天才能完成。在您的号码注册之前，您将无法发送给澳大利亚订阅者；但是，您仍然可以使用品牌发件人 ID 发送给其他国家/地区（例如英国）的收件人。借助品牌发件人 ID，您的客户可以通过取消订阅链接选择退出。 ### 品牌发件人 ID 限制

此 ID 的缺点是它无法接收消息，因此您的收件人无法给您回复短信。这意味着您无法将以下 Klaviyo 功能与品牌发件人 ID 一起使用：

- 点击文本表格和电子邮件横幅
- 订阅和取消订阅关键字
- 短信对话/双向消息传递
- 双重选择加入

## 长代码

[长代码](https://help.klaviyo.com/hc/en-us/articles/26705180655003) 仅适用于覆盖 1 个特定国家/地区的订阅者。例如，如果您只有澳大利亚长代码，则无法使用该号码发送至爱尔兰。与品牌发件人 ID 不同，长代码能够接收入站消息，这使您可以更灵活地使用 SMS 进行操作。您将能够使用：

- 双重选择加入
- 点击文本表格和电子邮件横幅
- 订阅关键词
- 短信对话/双向消息传递
- 可以在澳大利亚发送彩信
- 可以寄往比利时

这允许您的客户选择使用订阅关键字、获得一对一支持、分享他们的偏好和兴趣等。 ### 长代码限制

与品牌发件人 ID 相比，长代码有一些缺点，包括：

- 它们没有品牌。该号码看起来与任何其他号码一样，客户不会自动知道是谁在给他们发短信。 - 长代码的发送速度比品牌发件人 ID 慢。 - 在澳大利亚和爱尔兰，长代码必须经过验证过程。此过程需要 1-3 个工作日，并且在号码获得批准之前您无法发送。 ## 短代码（虚荣和非虚荣）

所有[短代码](https://help.klaviyo.com/hc/en-us/articles/26886941270171)都是完全相同的，除了两件事：

- 虚荣短代码允许您选择您的号码（只要可用）。请注意，每个国家/地区都有自己的可用个性短代码列表。 - 非个性短代码仅适用于美国，而个性短代码适用于美国、加拿大、英国和新西兰。 为了简单起见，我们将使用“短代码”来讨论这两种数字类型。短代码仅发送给 1 个特定国家/地区的收件人。如果您计划发送至多个国家/地区，则需要获取单独的短代码，并为您想要发送的每个新国家/地区获得批准。例如，如果您有英国的短代码，则不能在澳大利亚、新西兰等地使用相同的短代码。 ### 谁应该获得短代码

短代码最适合大批量发件人，例如满足以下任一条件的发件人：

- 如果您向超过 30,000 人发送短信营销活动。 - 您一次发送超过 300,000 条消息（例如，通过流或多个同时进行的活动）。详细了解[何时获取短代码](https://help.klaviyo.com/hc/en-us/articles/14476797072795)。并非所有企业和行业都有资格获得短代码。您必须申请并获得批准。此审批过程需要数周时间，因此即使您符合资格，您也无法立即开始发送短代码。 ## 常见问题解答

### 当您有多个发送号码时会发生什么？您可以拥有 1 个包含多个发送号码的 Klaviyo 帐户。 Klaviyo 会自动检测每个收件人所在的位置，然后使用该国家/地区的号码发送给他们。假设您有一个美国的免费电话号码和一个英国的长代码。要发送给所有订阅者，您无需设置多个广告活动。相反，您只需要 1 个活动，因为 Klaviyo 会自动为美国号码的收件人使用您的免费电话号码，为英国号码的收件人使用您的长代码。 ### 如果将号码更改为短代码会发生什么？当您获得短代码时，它将成为批准该代码的国家/地区的主要发送号码。例如，如果您仅发送到美国，您的短代码将取代免费电话号码作为主要发送号码。请注意，如果您在美国和/或加拿大使用点击文本表单，则需要更新表单以仅适用于 1 个国家/地区。例如：

- 将**发送区域**更新为**美国**（不是**美国、加拿大**）。 - 更改定位行为以仅在美国显示表单。然后，您可以克隆该表格并更改这些方面以仅适用于加拿大。 ### 如果您有免费电话号码和短代码会怎样？在这种情况下，短代码会将所有消息发送到获得批准的国家/地区，而免费电话号码将发送到其他国家/地区。 ### 如果您有很长的代码和品牌发件人 ID，会发生什么情况？如果您同时拥有长代码和品牌发件人 ID，则长代码通常优先。唯一的例外是在澳大利亚，注册了品牌发件人 ID 而未注册长代码。但是，长代码一旦注册，就具有优先权。
