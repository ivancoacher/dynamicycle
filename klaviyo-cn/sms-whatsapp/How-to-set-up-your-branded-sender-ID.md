对于设置，您必须是所有者、管理员或经理。了解 Klaviyo 中的品牌发件人 ID，包括如何设置它们、它们的可用位置等等。本文仅讨论品牌发件人 ID。有关其他号码类型的信息，请参阅我们的[有关所有短信发送号码的文章](https://help.klaviyo.com/hc/en-us/articles/6637671573403)。 ## 开始之前

品牌发件人 ID（也称为字母数字发件人 ID）是以下国家/地区的默认发送号码选项：

- \*澳大利亚
- 奥地利
- 丹麦
- 芬兰
- 法国
- 德国
- \*\*爱尔兰
- 意大利
- 卢森堡
- 挪威
- 波兰
- 葡萄牙
- 西班牙
- 瑞典
- 瑞士
- 英国

\* 在澳大利亚，您必须先注册您的品牌发件人 ID，然后才能开始收集短信同意或发送消息。 \*\* 爱尔兰要求品牌发件人 ID 必须通过 ComReg 注册，并且该 ID 对于给定 SMS 提供商必须是唯一的。品牌发件人 ID 不适用于美国、加拿大、新西兰、比利时或匈牙利。每个国家/地区都使用相同的品牌发件人 ID，因此您无法为每个地区提供唯一的 ID。此外，如果您为 1 个国家/地区设置 ID，则系统会自动为其他每个国家/地区激活该品牌发件人 ID。 ## 品牌发件人 ID 可以做什么和不能做什么

与其他发送号码不同，品牌发件人 ID 不仅仅是一串数字。相反，他们可以使用字母和数字的组合来代表您的品牌。例如，SWAK Lipcare 品牌可以将其品牌发件人 ID 设为：SWAKLipcare

由于品牌发件人 ID 允许自定义，因此您可以确保收件人始终知道短信来自谁。 ### 品牌发件人 ID 限制

品牌发件人 ID 有 2 个主要缺点：他们：

1. 无法接收短信，即无法使用以下功能：

   - 点击文本表单和电子邮件横幅。 - 订阅和取消订阅关键字。 - SMS 对话和双向消息传递。 2. 无法发送彩信。 - 彩信也不适用于其他发送号码，具体取决于所在国家/地区。请注意，您可以[使用智能选择加入](https://help.klaviyo.com/hc/en-us/articles/24743883751451) 获取品牌发件人 ID。 ****我可以在一个国家/地区同时拥有长代码和品牌发件人 ID 吗？****

是的，但不建议这样做。长代码将优先于品牌发件人 ID，因此注册这两种号码类型不会给您的业务带来好处。此外，您选择的发送号码应基于您的业务案例。有关更多信息，请参阅这篇[比较发送号码的文章](https://help.klaviyo.com/hc/en-us/articles/6637671573403)。 ## 设置您的品牌发件人 ID

如果您在最初[设置短信](https://help.klaviyo.com/hc/en-us/articles/4404274419355)时没有创建品牌发件人 ID，您可以随时创建一个。设置品牌发件人 ID 将使其在每个可用的国家/地区都有效。唯一的例外是该国家/地区已有发送号码（即，如果您使用长代码或短代码，这些号码优先于品牌发件人 ID）。 1. 在左下角选择您的帐户名。 2. 导航至****设置 > 短信****。 3. 在“**国家/地区**”框顶部附近，选择“****添加国家/地区****”。 ![添加国家.jpg](https://klaviyo.zendesk.com/hc/article_attachments/28715965418139)
4. 从下拉列表中选择可以使用品牌发件人 ID 的国家/地区（例如英国）。 5. 选择****品牌发件人 ID****（这可能是唯一的选项，具体取决于您选择的国家/地区）。 ![选择品牌 ID.jpg](https://klaviyo.zendesk.com/hc/article_attachments/28715965414811)
6. 选择****下一步****。 7. 要么：

   - 自定义您的品牌发件人 ID，其中必须包含：
     - 4 到 11 个标准字符。 - 至少 1 个字母（大写或非大写）。 - 没有特殊字符或标点符号。 - 开头或结尾没有空格。 - 字符之间只有 1 个空格（无双空格）。 - 对于爱尔兰，请前往 ComReg 注册您的品牌发件人 ID。 8. 单击****下一步****。如果您计划在爱尔兰或澳大利亚使用您的品牌发件人 ID，则必须在征得同意或向该国家/地区的居民发送消息之前注册您的号码。对于所有其他国家/地区，您可以开始增加列表并立即发送消息。 ## 爱尔兰和澳大利亚注册

****爱尔兰****

在爱尔兰，每个 SMS 服务提供商的每个品牌发件人 ID 都必须是唯一的。 例如，2家使用Klaviyo的公司不能使用ID“SWAK Lipcare”。

爱尔兰要求您通过 [ComReg 的发件人 ID 注册表](https://senderid.comreg.ie/) 注册您的品牌发件人 ID。您需要：

- 添加有关您的业务的信息（业务类型、联系信息、邮政编码等）
- 要么：
  - 输入以下内容 1：
    - 爱尔兰公司注册处 (CRO) 号码
    - 商标号码
    - 税务登记号
  - 选择“我没有 CRO 编号”的选项，并尽可能包含任何其他信息，例如：
    - 您的公司注册证书/公司注册证书的副本（或您所在国家/地区的同等证书）
    - 任何其他证明文件
- 确保您的 ComReg 帐户中的 OPA 和第三方部分将 Twilio 反映为 OPA，将 Klaviyo 反映为第三方：

1. 登录您的 ComReg 门户帐户并导航至 **我的发件人 ID**。在那里，您将看到您注册的发件人 ID 的列表。 2. 确保 ComReg 中的发件人 ID 与 Klaviyo 中的发件人 ID 完全匹配。 3. 在 **OPA** 部分中，添加“Twilio”。 Twilio 是 Klaviyo 的爱尔兰 SMS 上游合作伙伴。 4. 在**第三方**列表中，添加“Klaviyo”。与其他国家/地区不同，Klaviyo 无法了解注册过程，也无法协助您进行注册。如果您对该流程有疑问，您必须直接联系 ComReg。一旦您的爱尔兰品牌发件人 ID 获得 ComReg 批准，您将收到一封确认电子邮件。如果您已将 Twilio 添加为 OPA，将 Klaviyo 添加为第三方，Klaviyo 将收到通知激活您的品牌发件人 ID。此过程从批准之日起可能需要 7-10 个工作日。如果您没有正确添加 OPA 和第三方字段，即使 ComReg 批准后，Klaviyo 将无法激活您的发件人 ID。 ****澳大利亚****

**此信息仅用于教育和信息目的，不应被视为法律建议。所提供的内容本质上是一般性的，可能不反映最新的信息。 Klaviyo 强烈建议您咨询合格的法律顾问，以确保您遵守与使用我们的服务相关的适用法律和法规。**

****留出足够的时间。**** 注册需要 ****7-10 个工作日**** 来处理，拒绝后重新提交也需要同样的时间。 Klaviyo 没有办法加快这一过程。我们强烈建议尽早注册——在六月中旬之前尚未提交完整注册的帐户可能无法在截止日期之前获得批准。 #### ****谁需要注册****

如果****同时满足以下条件，您必须注册：

- 您使用澳大利亚电话号码向收件人发送短信或彩信
- 您使用品牌（字母数字）发件人 ID（例如“YourBrand”而不是数字短代码或长代码）

如果您不确定您的帐户是否使用品牌发件人 ID，请检查 Klaviyo 中的短信设置。 #### ****在我的注册等待期间我可以继续发送吗？****

****现有发件人：**** 如果您在 Klaviyo 中已拥有有效的品牌发件人 ID，并且目前正在向澳大利亚收件人发送邮件，则您可以在 ACMA 注册期间继续发送，直至 2026 年 7 月 1 日。 ****新发件人：**** 如果您尚未开始向澳大利亚收件人发送邮件，请不要发送任何 SMS 消息（包括欢迎消息），直到您的发件人 ID 成功注册。 #### ****开始之前您需要什么****

##### ****业务文档****

您必须提供有效的商业登记证明。 接受的文件包括：

- 澳大利亚商业号码 (ABN)
- 澳大利亚公司号码 (ACN)
- 澳大利亚注册机构编号 (ARBN) — 可供非澳大利亚企业使用
- 原住民公司编号 (ICN)
- 在您注册成立的国家/地区进行公司注册——适用于非澳大利亚企业

****重要提示：**** 您的公司名称必须与营业执照上的名称一致。如果存在差异，您的申请可能会被拒绝。请参阅****如果我的发件人 ID 与我的公司名称不匹配怎么办？下面.****

#### ****商业登记****

#### ****ABN 企业：ASIC 公司摘录（ABN 企业）****

除了您的 ABN 或同等文件外，您还必须提供澳大利亚证券和投资委员会 (ASIC) 提供的****完整的最新公司摘要****。您可以在 [ASIC 注册表](https://connectonline.asic.gov.au/RegistrySearch/faces/landing/bn/SearchBnRegisters.jspx) 上检索此信息。 - 摘录必须完整——部分或简短的摘录是拒绝的常见原因。注意：在“查看摘要 (PDF)”链接下**找不到**
- 摘录必须列出现任公司职员

#### ****非 ABN 商业文件（非澳大利亚企业）****

如果您的企业未在澳大利亚注册，则无需提供 ASIC 公司摘要。相反，您必须提交您所在国家/地区的同等正式公司注册文件。该文件必须确认您企业的法定名称、注册号和当前状态。接受的非 ASIC 文档包括：

- 公司注册证书 — 由您所在国家/地区的国家或州企业注册处颁发（例如，英国的公司注册处、菲律宾的 SEC 注册、美国的特拉华州公司注册证书）
- 公司注册证书——由相关政府机构签发的正式文件，确认您的企业已合法注册
- 公司章程或章程 - 确立公司合法存在的创始文件，这是您所在司法管辖区的标准注册文件
- 组织章程大纲——在许多英联邦和欧洲司法管辖区用作主要公司注册文件

该文件必须是最新的、清晰的，并且由官方政府或法定机构颁发或可通过官方政府或法定机构验证。不接受非官方摘要、自行生成的文档或来自第三方聚合商的文档。 #### ****身份验证****

作为注册过程的一部分，您的 ASIC 摘录（或同等文件）的“官员和其他角色”部分中列出的公司高管必须使用政府颁发的 ID 来验证其身份。如果公司管理人员无法完成身份验证，则其他公司人员必须完成身份验证并上传由公司管理人员签署的授权书。在开始之前，请确保您在公司中找到了合适的人员，因为您需要他们的参与才能完成注册。 #### ****发件人 ID 所有权文档（如果您的发件人 ID 与您的公司名称不匹配）****

如果您的品牌发件人 ID 与您注册的公司名称不完全匹配，您将需要至少提供以下其中一项：

- 域名所有权证明
- 商标文件显示您使用该名称的权利

请参阅****如果我的发件人 ID 与我的公司名称不匹配怎么办？**** 了解您的选项。 #### ****如何注册您的发件人 ID****

注册可直接在您的 Klaviyo 帐户中完成，该帐户自 2026 年 4 月起可用。 1. 登录您的 Klaviyo 帐户
2. 导航至****设置 > 短信****
3. 选择您要注册的发件人ID
4.点击****开始注册****
5. 填写指导表格 — Klaviyo 将尽可能预先填写您帐户中已有的信息。确保预先填写的信息是最新的。 6. 上传所需文件（ASIC 公司摘录、公司高管的身份验证**或**其他个人的验证和签署的 LOA，以及所有权证明（如果您的发件人 ID 与您的公司名称不匹配））
7. 提交您的注册信息

提交后，您的申请将被审核并提交至 ACMA 发件人 ID 注册处。您可以随时在 Klaviyo SMS 设置中跟踪您的状态。 #### ****注册状态****

提交后，您将在 Klaviyo 中看到以下状态之一：

- ****需要采取的行动：**** 您尚未完成注册请求，或者您已提交请求，但 Klaviyo 尚未处理。 - ****正在审核中：**** 您的注册请求已提交并正在审核中。 - ****有效：**** 您的注册已获得批准，您可以继续使用您的品牌发件人 ID 在澳大利亚发送。 - ****需要采取的行动：**** 您的注册被拒绝，可能是由于信息缺失或不正确，或者处于未经验证的状态。注册处理完成后（无论是批准还是拒绝），帐户所有者将收到一封电子邮件。 #### ****如果我的发件人 ID 与我的公司名称不匹配怎么办？****

如果您的发件人 ID 与注册的公司名称不一致，您有两种选择：

****选项 1 – 提供支持文档。**** 提交您拥有或有权使用发件人 ID 的证明 — 域名所有权记录或商标文档。 ****选项 2 – 更新您的发件人 ID。**** 更改您的发件人 ID 以匹配您注册的公司名称或域名。这通常是获得批准的更快途径，并且无需额外的所有权文件。如果您需要有关哪个选项适合您的帐户的指导，请联系 Klaviyo 支持人员。 #### ****如果我的注册被拒绝怎么办？****

如果您的注册被拒绝，请查看电子邮件中提供的拒绝原因并更正您的提交，然后重新提交。审核过程还需要 7 至 10 个工作日，因此请尽快采取行动。 ****拒绝的常见原因：****

- 许可证上的企业名称与登记表上的企业法定名称不符
- 缺乏证据证明母子公司之间的关系
- 缺乏证据证明品牌发件人 ID 的所有权
- 所提供的文件部分或全部模糊
- 提供的文件不是有效的营业执照或公司摘要
- 提交了不完整或部分 ASIC 公司摘录

#### ****如何修复被拒绝的申请：****

在重新提交被拒绝的注册之前，请使用此清单。从第一列中的电子邮件或应用内通知中查找拒绝原因，然后在重新提交之前完成该行中的每项检查。 ACMA 要求发件人 ID 明确链接到实体的****注册企业名称、公司名称、商标或域名****。完整注册指南：[acma.gov.au/registering-sender-ids](https://www.acma.gov.au/registering-sender-ids)。 ****在重新提交之前修复通知中列出的所有拒绝原因。****

#### ****常见问题****

****我不打算在澳大利亚使用我的品牌发件人 ID。我需要注册吗？****

不可以。仅当您使用品牌发件人 ID 向澳大利亚的收件人发送短信或彩信时，注册才适用。但是，如果您认为将来可能会扩展到澳大利亚收件人，我们建议您主动注册以避免日后延误。 ****我之前在另一家 SMS 提供商处注册了我的品牌发件人 ID。我需要通过 Klaviyo 再次注册吗？****

是的。当您更换短信提供商时，澳大利亚的 ACMA 无法确认您的身份或您之前在不同的提供商处注册了相同的发件人 ID。无论之前是否注册过，您都必须通过 Klaviyo 重新注册。 ****我已经通过 Klaviyo 注册了我的品牌发件人 ID。我需要再次注册以满足 ACMA 要求吗？****

是的。 ACMA 注册是一项新的、单独的要求。您现有的 Klaviyo 发件人 ID 注册不满足 ACMA 要求。您必须完成本文中描述的新注册过程。 ****我是一家国际企业，总部不在澳大利亚。我还需要注册吗？****

是的，如果您使用品牌发件人 ID 向澳大利亚收件人发送短信或彩信，则无论您的企业总部位于何处，该要求均适用。国际企业可以使用其注册所在国的 ARBN 或公司注册。请联系 Klaviyo 支持以获得针对您情况的指导。 ****注册需要多长时间？****

初步审核需要 7-10 个工作日。拒绝后重新提交需要相同的时间。 Klaviyo 无法加快这一过程。尽早注册非常重要，以确保有充足的时间获得批准。 ****如果我错过 2026 年 7 月 1 日截止日期会怎样？****

2026 年 7 月 1 日之后，任何使用未注册的品牌发件人 ID 向澳大利亚收件人发送的邮件都将被 Klaviyo 拦截。您可以随时重新注册，但在您的注册获得批准之前，向澳大利亚收件人的发送将保持暂停状态。 #### ****其他资源****
