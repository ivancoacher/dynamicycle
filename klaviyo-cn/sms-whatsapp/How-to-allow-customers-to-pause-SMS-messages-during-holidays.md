## 你将会学到

了解如何允许客户暂停接收短信营销活动，而无需完全取消订阅短信。在发起大型多消息营销活动之前或在可能敏感的假期前后使用此策略。 ****为什么要让人们选择暂停短信？****

通过为人们提供暂停消息的选项，您可以：

- 保留可能选择退出的订户。 - 让您的客户选择是否想要某些消息，从而为他们提供更积极的体验。 - 与规模更小、更感兴趣的受众互动，节省短信积分，并在后续消息中实现更高的点击率和转化率。 ****我应该在一年中的什么时间进行此操作？****

提供在一年中最大的发送时间和任何敏感假期之前暂停的选项，包括：

- 黑色星期五/网络星期一
- 母亲节和父亲节
- 情人节和白色情人节
- 圣诞节
- 回到学校
- 复活节
- 澳大利亚国庆日

## 开始之前

允许客户暂停的流程是：

1. [决定表示暂停的属性。](#h_01HZ29GD9ANSNG394C6MY5AA8S)
2. 要求订阅者：
   - [某个单词中的文本](#h_01HZ29GD9A98Q4VT61RKXMWQDB)。 \*请注意，这不适用于品牌发件人 ID。 - [单击注册表单上的按钮](#h_01HZ29GD9BD6A61MKVVB2SD41Z)。 3. [创建拥有该财产的人群](#h_01HZ29GD9B9VCJZN0RE10BB3FS)。 4. [从与该假期相关的任何广告活动中排除该段](#h_01HZ29GD9BBBVAEGKM9G1DYSMP)。 ## 决定指示暂停的属性

该属性将在您的流程、表单、段等中使用，因此在开始设置这些属性之前仔细考虑您想要使用的内容非常重要。您可以每次使用相同的属性，也可以在每次重大促销或节日时更改它。每种方法都有其自身的优点和缺点，如下表所示。 |  |  |  |
| --- | --- | --- |
|  | ****专业**** | ****Con**** |
| ****重复使用相同的属性**** |您每次只需进行最少的更改即可重复使用单一设置 |无法了解谁在过去的某个假期或活动中暂停了短信 |
| ****每次都使用独特的属性**** |允许您分析谁选择退出过去的活动 |要求您更新每个新营销活动的流程和细分 |

一旦您决定了您的财产，请将其添加到您帐户中的至少 1 个个人资料中。接下来，我们讨论如何从订阅者那里收集此属性，首先要求客户输入某个单词的文本。如果您只有品牌发件人 ID，请跳转至[了解如何使用注册表单中的按钮收集财产](#h_01HZ29GD9BD6A61MKVVB2SD41Z)。 ## 要求客户发短信一句话

如果您有一个可以接收短信的号码（即不是品牌发件人 ID），您可以：

1. [选择订阅者要输入的文字](#h_01HZ29GD9AYN28NKSPV61NMAS5)。 2. [准备您的活动，要求人们给您发送某个单词的短信](#h_01HZ29GD9A3KYN103MYDCVT6BW)。 3. [使用流程为发送关键字的任何人添加个人资料属性](#h_01HZ29GD9AXXV5H05CGK2V798K)。 ### 选择订阅者要输入的文字

您选择使用的词应该是：

- 足够独特，订阅者不会意外地发短信（例如，在情人节期间不要使用“心”）。 - 不是某人可能发短信的另一个常见单词的一部分（例如，不要使用“no”，因为它是许多其他单词的一部分，例如“not”、“afternoon”等）
- 订阅者可以轻松地拼写并向您发送短信。 ### 准备一个活动来询问订阅者是否想要暂停

我们说“准备”是因为虽然您需要来自活动的信息，但在完成流程设置之前您不想实际发送它。 1. 导航至****营销活动****选项卡。 2. 单击****创建活动****。 3. 为活动命名并选择****短信****。 4. 选择****继续****。 5. 选择您的收件人（即您计划在假期期间进行营销的任何人）。 6. 选择****下一步****。 7. 设计您的信息。 ![](https://klaviyo.zendesk.com/hc/article_attachments/33627695129883)
8. 返回****营销活动****选项卡。 9. 找到您刚刚创建的营销活动并将其悬停在其上。 10. 在弹出的模式中，点击****复制消息 ID****。注意：对于营销活动，使用 URL 中的 ID 或营销活动 ID（通常约为 26 位数字）不起作用。您必须复制消息 ID，如下所示。 ![复制消息ID.jpg](https://klaviyo.zendesk.com/hc/article_attachments/32593201251867)
11. 在设置流程（下一节中讨论）之前，请勿发送此营销活动。 ### 创建一个流程，当订阅者发送短信时触发

我们会说“暂停”是订阅者将发短信的单词。现在，我们需要一个流程来响应并在订阅者使用该单词发短信时添加配置文件属性。我们在这里提供基本步骤；不过，请参阅这篇关于[创建响应入站 SMS 消息的流程](https://help.klaviyo.com/hc/en-us/articles/360049930372) 的文章，了解提示和更多详细信息。 1. 导航到****流 > 创建流 > 构建您自己的****。 2. 为流命名，然后单击****创建流****。 3. 选择****所有触发器> 指标****。 4. 选择****发送短信**** 作为触发流程的操作。 5. 在**触发器过滤器**部分中，单击****添加****。 6. 单击****添加触发过滤器****。 7. 使用以下过滤器：
   1. **消息 > 等于** [添加复制的消息 ID]AND
   2. **消息正文 > 包含** 暂停
      或
   3. **消息正文>包含**暂停
      或
   4. 注意：通过在过滤器之间添加 ****OR**** 来包含替代拼写、错别字或大写字母。 ![](https://klaviyo.zendesk.com/hc/article_attachments/34235862491675)
8. 单击****保存 > 确认并保存****。 9. 在触发器正下方添加 SMS 消息。 10. 在右侧边栏中，单击“**内容**”部分中的“****编辑****”。 11. 自定义该短信的内容。 ![](https://klaviyo.zendesk.com/hc/article_attachments/33627695134107)
12. 选择****保存并继续****。 13. 在 SMS 下，添加 **配置文件属性更新** 操作。 14. 单击****+ 添加步骤****。 15. 将操作设置为 ****创建新属性**** 并命名新属性（例如，对于通用属性，将其命名为 **Paused？**；如果您想针对每次促销进行更改，则将其命名为 **Paused-BFCM2024**）。请注意，该属性必须存在于至少 1 个配置文件中，然后才能将其用于 **配置文件属性更新** 操作。 16. 将属性类型设置为****Boolean****，值设置为****True****，然后单击****保存****。 ![为想要在流程中暂停的人添加个人资料属性](https://klaviyo.zendesk.com/hc/article_attachments/28717888255003)
17. 单击****查看并打开****。 18. 将流程设置为****Live****，然后保存。 19. 返回并发送活动询问订阅者是否要暂停 SMS。如果您还使用品牌发件人 ID，请继续阅读。否则，请向前跳至[了解如何创建要求暂停的人员细分](#h_01HZ29GD9B9VCJZN0RE10BB3FS)。 ## 使用表单上的按钮收集属性

对于品牌发件人 ID，您需要一种不依赖于人们回短信的方法。有两个步骤：

1. [创建一个表单，询问订阅者是否要暂停](#h_01HZ29GD9BJ6YH0VWYH221VVEB)。 2. [发送链接到您的表单的活动。](#h_01HZ29GD9B9CTZEQR9YBD7GPVB)

### 创建一个表单，询问订阅者是否要暂停

您可以创建一个表单，并在有人单击按钮时收集隐藏的配置文件属性。为此：

1. 在 Klaviyo 中创建一个全页表单。 2. 根据您的需要设计表单，但确保至少包含 1 个按钮。 ![带有一个按钮的表单，询问客户是否要暂停](https://klaviyo.zendesk.com/hc/article_attachments/28717888260635)
3. 单击按钮（例如上例中的“暂停”）。 4. 在 **按钮单击操作** 下，设置以下内容：
   1. **采取行动** **提交表格****。 2. **提交后**至****显示下一步****。 ![表单按钮设置，让点击按钮的人进入下一步](https://klaviyo.zendesk.com/hc/article_attachments/28717888262683)
5. 在“**提交隐藏字段**”下，单击“****+ 添加属性****”。 6. 设置所需的属性（例如，**Paused？** 对于通用属性，或者 **Paused-BFCM2024** 如果您想为每次促销更改它）。请注意，您的帐户中至少有 1 个个人资料必须具有此属性，您才能在表单中使用它。 ![向按钮添加隐藏的配置文件属性](https://klaviyo.zendesk.com/hc/article_attachments/28717888267931)
7. 在表单预览上方，选择****成功****来设计用户单击按钮后显示的页面。 ![突出显示表单顶部的成功步骤按钮](https://klaviyo.zendesk.com/hc/article_attachments/28717882219803)
8. 在 **成功** 页面上，确认用户将不再收到该假期的短信。 ![确认用户单击按钮后暂停的成功页面示例](https://klaviyo.zendesk.com/hc/article_attachments/28717888277403)
9. 选择****定位和行为****。 10. 在****显示****选项卡中，设置以下内容：
    1. **时间**至****立即****。 2. **频率** 至 ****0 天****。如果您计划在将来的任何假期重复使用此表单，请取消选中****如果提交表单或单击“转到 URL”按钮，则不再显示****复选框。这将允许每次有人导航到该链接时显示该表单。 3. **设备** 至 ****桌面和移动设备****。 ![立即向所有用户显示表单的设置](https://klaviyo.zendesk.com/hc/article_attachments/28717882242715)
11. 滚动到侧边栏顶部，然后单击“****定位****”选项卡。 12. 更改定位设置，以便：
    1. **访客** ****显示到任何现有的个人资料****。 2. **URL** 至 ****仅在某些 URL 上显示**** ****>**** ****包含 > #pause****
       请注意，此处的“#pause”是我们将用于营销活动的锚链接。主题标签是必需的，但您可以用其他单词替换“暂停”。 ![表单定位设置以在锚链接上显示表单](https://klaviyo.zendesk.com/hc/article_attachments/28717882230683)
13. 单击****发布****以设置表单。 ### 使用表单链接创建您的营销活动

1. 导航至****营销活动****选项卡。 2. 单击****创建活动****。 3. 为活动命名并选择****短信****。 4. 选择****继续****。 5. 选择您的收件人和标签。 6. 选择****下一步****。 7. 设计您的信息。 8. 对于链接，添加您的网站，然后在末尾添加锚链接（例如#pause）。示例：[www.mywebsite.com#pause
   ![](https://klaviyo.zendesk.com/hc/article_attachments/33627695136539)](http://www.mywebsite.com#pause)
9. 单击****下一步****。 10. 安排或发送活动。 ## 创建一个暂停的人群

下一步是创建使用您在流程中添加的个人资料属性发送短信的每个人的细分。 1. 导航至****列表和分段> 新建> 创建分段****。 2. 为您的片段命名（例如，暂停片段）。 3. 添加配置文件属性作为分段的条件（例如 **Paused？** 或 **Paused-BFCM2024**）：
   **有关某人的属性** > **已暂停？等于 true**！[任何暂停者的分段条件](https://klaviyo.zendesk.com/hc/article_attachments/28717882232091)
4. 单击****创建分段****。 ## 从您的广告系列中排除该细分

创建此细分后，只需将其从与该假期或一年中的时间相关的任何营销活动、流程或表单中排除即可。下面的示例显示了 Klaviyo 营销活动的外观。 ![从活动中排除暂停的片段](https://klaviyo.zendesk.com/hc/article_attachments/28717882236315)
