## 你将会学到

了解如何将您的品牌名称添加到 Klaviyo SMS 消息中的缩短链接。对您的缩短链接进行品牌化，使它们更加符合您的品牌个性化和可信度，向收件人表明此链接会将他们带到您的网站或页面。您必须加入付费短信套餐才能创建品牌 Klaviyo 或自定义链接。 ## 开始之前

有 2 个选项可用于为您的缩短链接添加品牌：

- [品牌 Klaviyo 链接](#h_01H9N9JVZ6SPV89G6K6CKHN935)，类似于 SMS 短链接的自定义前缀。 - [品牌自定义链接](#h_01H9N9JVZ7RD0X0XNM1HNEWT6A)，这是一个完全可自定义的缩短链接。举个例子，对于一家名为“James Black”的公司来说，链接的开头可能是这样的。

|  |  |
| --- | --- |
| ****链接类型**** | ****示例**** |
|克拉维约链接 | klv3.io |
|品牌 Klaviyo 链接 | jblck.klv3.io |
|品牌定制链接| sms.JamesBlack.com |

有关不同短链接选项的更多信息，请参阅[了解短信短链接的差异](https://help.klaviyo.com/hc/en-us/articles/17649677926299)。 ## 品牌 Klaviyo 链接

在链接中包含您的组织名称，以便在 SMS 消息和您的网站之间提供更简化的体验。您的品牌 Klaviyo 链接必须：

- 不超过 25 个字符。 - 仅包含字母或数字（无特殊字符）。 - 是唯一的（您不能与其他人拥有相同的子域）。 - 不包含任何不恰当的词语。请注意，当您创建、编辑、更改或删除任何品牌 Klaviyo 链接时，所有以前的链接将继续按预期工作。 ****最佳实践****

创建品牌 Klaviyo 链接时需要考虑两个关键的最佳实践。 - ****使链接易于理解****
  您始终希望您的 Klaviyo 链接能够直接反映您的品牌。毕竟，如果您的收件人无法将其连接回您，那么使用品牌 Klaviyo 链接就没有意义。 - 好：Klaviyo、KLVYO
  - 坏：K
- ****不要让它们太长。****
  无论您选择什么品牌，都会使您的链接更长，这意味着您在短信中使用的字符会更少。 - 好：克拉维约
  - 不好：KlaviyoMarketingTech

### 创建品牌 Klaviyo 链接

按照以下步骤创建您独特的品牌 Klaviyo 链接。 1. 导航至****设置 > 域名****
2. 单击 **品牌短链接** 框中的 3 个垂直点。 3. 选择****自定义****。 - 品牌 Klaviyo 链接仅适用于付费 SMS 计划的用户。如果您没有使用付费计划，您将首先看到升级提示。 4. 在右侧的 **子域名** 下，输入您想要在缩短的链接中作为品牌名称的内容（例如 jamesblack）。 - 您的子域必须遵循以下要求：
     - 不超过 25 个字符。 - 仅包含字母或数字（无特殊字符）。 - 是唯一的（您不能与其他人拥有相同的子域）。 - 不包含任何不恰当的词语。 - 注意：您无法编辑 **根域**（例如，下例中的“kvo.7.io”）。！[用于添加 Klaviyo 品牌链接的设置界面，显示带有根域和子域字段的模式](https://klaviyo.zendesk.com/hc/article_attachments/38091980603163)
5. 单击****保存****。保存后，您将在 SMS **短链接** 页面中看到品牌 Klaviyo 链接以及状态。 ### 编辑品牌 Klaviyo 链接

在编辑品牌 Klaviyo 链接之前，请注意，一旦更改前缀，它可能就不再可用。编辑子域可以有效地释放它，让其他公司有机会使用它。要编辑您的品牌 Klaviyo 链接，请按照以下步骤操作：

1. 导航至****设置 > 域名****
2. 单击 **品牌短链接** 框中的 3 个垂直点。 3. 单击****编辑****。 ![品牌 Klaviyo 链接的编辑按钮](https://klaviyo.zendesk.com/hc/article_attachments/38092019422107)
4. 在**子域**下更改您的品牌。 - 注意：您无法更改品牌 Klaviyo 链接的**根域**。 5. 单击****保存****。 ### 删除品牌 Klaviyo 链接

删除品牌 Klaviyo 链接意味着您的缩短链接不再包含品牌前缀，从而将其从您帐户中的缩短链接中删除，并允许其他公司使用它。 Klaviyo 每个帐户一次仅允许一种品牌链接类型。因此，如果您请求品牌自定义链接并获得批准，您的品牌 Klaviyo 链接将被删除。要删除您的 Klaviyo 品牌链接，请按照以下步骤操作：

1. 导航至****设置 > 域****
2. 单击 **品牌短链接** 框中的 3 个垂直点。 3. 单击****删除子域****。 ![](https://klaviyo.zendesk.com/hc/article_attachments/38091980613787)
4. 选择****删除链接****以确认您要从您的帐户中删除品牌 Klaviyo 链接。 ![确认删除品牌 Klaviyo 链接的模式](https://klaviyo.zendesk.com/hc/article_attachments/28716057116955)

## 品牌自定义链接

品牌自定义链接不显示默认 Klaviyo URL 的任何部分（例如 klv.io）。相反，您可以专门针对您的组织或 SMS 计划进行定制。此外，使用品牌自定义链接进行点击跟踪是使用[短信中的通用链接和应用程序链接](https://klaviyo.zendesk.com/hc/en-us/articles/41701832186523-How-to-set-up-iOS-universal-links-and-Android-App-Links)的先决条件。与 Klaviyo 品牌链接不同，品牌自定义链接在 DNS 记录传播后获得批准并激活。此过程通常会在 10 分钟或更短的时间内完成，但最长可能需要 48 小时。品牌自定义链接必须：

- 是独一无二的（您不能与其他人拥有相同的链接）。 - 清楚地代表您的品牌。最重要的是客户知道该链接代表您的品牌。但是，我们建议使用尽可能少的字符：您的品牌自定义链接越短，它在短信中使用的字符就越少。 ### 请求品牌自定义链接

请注意，品牌自定义链接不可编辑。如果您需要更改此链接，请提交支持票以获取帮助。要请求品牌自定义链接：

1. 单击左下角您的帐户名称。 2. 转至****设置 > 域名****。 3. 在**品牌短链接**下，选择****连接域****。 4. 在生成的模式中，选择是否包含子域。 ![](https://klaviyo.zendesk.com/hc/article_attachments/38092019428763)
5. 选择****下一步****。 6. 选择是否要将域与 Entri 连接，或手动设置。只有符合 Entri 集成条件的域才会看到自动设置选项。 ![](https://klaviyo.zendesk.com/hc/article_attachments/38092019429787)

如果您选择手动设置域，则会向您显示生成的 DNS 记录，以便您可以手动将它们添加到您的 DNS。通过 Entri 自动配置，记录将代表您自动添加。 ### ****注册您的域名的缩短版本以节省成本****

为了节省短信中的字符（和成本），您可以注册并获得缩短版域名的所有权。例如，您可以注册 ****jb.co****，而不是使用 ****sms.jamesblack.com****。缩短的自定义域可保持链接的品牌可识别性，同时使用更少的字符，从而在每条消息中留出更多空间。为此，您需要：

- 向域名注册商注册您选择的缩短域名
- 取得所有权并将其连接到您的 Klaviyo 帐户（通过 DNS 设置或 Entri）

使用较短的品牌域可以减少每条消息的字符数，有助于优化支出，同时保持信任和品牌认知度。 ##
