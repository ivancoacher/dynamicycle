## 你将会学到

了解如何提高短信转化率以及活动和流程的绩效基准。

转化率显示有多少短信收件人成为客户。该比率对于您的短信营销工作的成功程度起着至关重要的作用。

## 开始之前

转化率是指短信或彩信带来的转化次数除以收件人数量。

下面的基准显示了哪些因素被认为对短信转化率有利。

|  |  |
| --- | --- |
|  | ****转化率基准**** |
| ****活动**** | 1.2–2.2% |
| ****流动**** | 1.8–2.2% |

## 提高转化率

### 提高点击率

当您希望提高转化率时，请首先按照点击率概述的步骤进行操作。毕竟，点击链接的人越多，访问您网站的人就越多，并且可能转化的人就越多。

### 查看您的号召性用语

如果您发现很多点击您链接的人没有发生转化，则您的内容（尤其是 CTA）可能存在问题。您的 CTA 应该设定正确的期望，以便导航到您网站的人确切知道他们会看到什么。

例如，如果您的短信内容是：“嘿朋友，在接下来的 2 小时内，享受 10% 的折扣”，但是当有人点击该链接时，他们发现 10% 的折扣只适用于鞋类，那么您的内容就有问题了。由于预期（商店内任何商品 10% 折扣）与实际情况（鞋类 10% 折扣）不符，这可能会导致转化率降低。

要解决此问题，请在消息本身中包含所有重要详细信息。例如，如果您的短信内容是：“嘿朋友，在接下来的 2 小时内，所有鞋类均可享受 10% 的折扣”，您就更有可能看到对您的鞋子销售感兴趣的用户进行转化。在发送之前大声朗读消息也是一个好主意，因为它可以帮助您捕获任何丢失的信息。

### 创造个性化体验

使您的消息对收件人来说更加个性化的两种方法包括：

- 为活动创建目标细分
- 在流中使用分割

这两种策略的目标都是根据订阅者的喜好、购物行为、他们如何与您的消息互动以及您拥有的任何其他可用信息发送量身定制的消息。

#### 活动

克隆您原来的参与细分并使其更有针对性。

向细分添加条件，使其适合您的买家角色之一。起初，这可能只是一个条件，比如性别、偏好、爱好或地点。您还可以将那些通常购买特价商品或购买最新产品的人分组。

当您收集更多有关客户的信息时，您可以结合条件并进一步定制您的细分；例如，将那些购买打折女装的人分组。

#### 流量

您将对流应用类似的方法。在这种情况下，请根据客户的偏好和之前的行为使用拆分来区分客户。

![在流中使用拆分发送更多个性化消息的示例](https://klaviyo.zendesk.com/hc/article_attachments/28723633003163)

### Flows：添加动态图像

在您的流程中添加动态图像，以向订阅者显示他们查看或开始结帐的产品。与电子邮件一样，显示某人感兴趣的确切产品可以让他们更有可能完成购买。

有关更多信息，请查看这篇[有关如何添加动态图像的文章](https://help.klaviyo.com/hc/en-us/articles/1260806102230)。

### 优化移动端结账体验

较低的转化率可能并不表示您的消息内容存在问题，而是表明结账体验不佳。如果用户很难完成订单，许多潜在客户就会放弃。

优化您的移动体验尤其重要。在这种情况下，由于许多客户将通过手机短信访问您的商店，因此这些人将通过移动结账。任何摩擦点都会导致转化率降低，如果不加以解决，退订率也会更高。
