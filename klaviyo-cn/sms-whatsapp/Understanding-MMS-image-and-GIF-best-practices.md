## 你将会学到

了解在短信中发送图像和 GIF 的最佳实践，以便它们能够很好地显示给收件人。 ### 为什么要遵循彩信最佳实践？有多种因素会影响图像或 GIF 在收件人手机上的显示效果，包括无线运营商、手机类型（iOS 或 Android）以及手机版本。通过遵循 MMS 最佳实践，您可以最大限度地提高媒体对所有收件人来说都美观的机会。 ## 开始之前

当您将图像或 GIF 添加到短信时，该消息会自动从短信变成彩信。关于彩信，请注意以下事项：

- 您无法更改彩信中图像的位置，并且它在 iOS 和 Android 设备上的显示可能有所不同。 - 彩信仅适用于某些国家和[发送号码类型。](https://help.klaviyo.com/hc/en-us/articles/4402914866843)
  - 美国：免费电话号码和短代码。 - 加拿大：免费电话号码。 - 澳大利亚：长代码。始终针对受众的 SMS 消息进行 A/B 测试 MMS。平均而言，SMS 的性能往往与 MMS 消息相同或更好，但 MMS 需要更多积分。详细了解 [短信和彩信信用系统](https://help.klaviyo.com/hc/en-us/articles/13502982552347)。 ## 支持的媒体类型

Klaviyo 支持以下彩信媒体类型：

- 巴布亚新几内亚
- JPEG
- 动图

其他文件类型（包括 MP4 和 WebP）不适用于彩信。例如，您将无法将此文件附加到消息中（例如 MP4），或者移动运营商可能拒绝传送您的消息（例如 WebP 图像）。不过，您可以上传 WebP 文件并选择让 Klaviyo 将其转换为 PNG 文件。如果您选择上传图像，Klaviyo 的[自动图像压缩](https://help.klaviyo.com/hc/en-us/articles/115005253688#h_01JVN2QQXD9N2QT2MQ9D7PGX6S) 工具会优化清晰度并确保快速加载时间。 ### PNG 与 JPEG

PNG 和 JPEG 都有各自的优点和缺点：

- PNG：
  - 绝不模糊或扭曲。 - 保留图像中的所有数据，因此无论编辑多少次，始终显示相同的内容。 - 可以有透明背景（尽管不建议对彩信图像这样做）。 - JPEG
  - 可以轻松调整大小。 - 每次图像变小时都会丢失数据，因此可能会变得模糊。简而言之，尽可能使用 PNG。如果您有较大尺寸的图像需要缩小，请使用 JPEG。 ****为什么 PNG 和 JPEG 图像不同？****

PNG 和 JPEG 之间的差异在于这些图像的压缩方式。图像使用两种类型的压缩过程之一：有损或无损。 - ****有损****
  图像在调整大小时会永久删除数据。 - ****无损****
  编辑图像时不会丢失任何数据，因此它们看起来始终相同并且不会变得模糊或扭曲。 ## 文件大小限制

所有图像和 GIF 必须低于 600 KB。如果文件大小大于600 KB，则图像或GIF可能会因运营商限制而被压缩和扭曲。将媒体控制在 600 KB 以下可确保收件人以您希望的方式以尽可能最高的质量看到媒体。此外，如果消息中的图像或 GIF 超过 600 KB，则可能无法传送该消息。 ![带图片的短信.jpg](https://klaviyo.zendesk.com/hc/article_attachments/28720847978779)

****减小文件大小的技巧****

Klaviyo 在上传过程中内置了一个[自动图像压缩工具](https://help.klaviyo.com/hc/en-us/articles/115005253688#h_01JVN2QQXD9N2QT2MQ9D7PGX6S)。上传图像时，您将看到原始版本和压缩版本，以及文件大小和百分比差异。使用切换开关选择要上传的版本。 Klaviyo 会推荐一个，但是如果压缩版本失去清晰度，您可以覆盖它。或者，您可以将文件导出为 JPEG，然后[使用程序减小文件大小](https://www.makeuseof.com/how-to-reduce-jpeg-file-size/)。如果您需要缩小 GIF：

- 使用剪切（而不是淡入淡出），因为剪切最多可以将 GIF 的大小缩小 50%。 - 减少每秒的帧数。 - 添加颜色叠加，这会减少 GIF 中的颜色数量。 ## 比率

您的图像和 GIF 不应太宽或太高。手机会调整多媒体以适应短信的宽度，因此超过 9:16（或 16:9）的比例可能会显得失真。一般来说，图像和 GIF 可以采用以下任何格式。 |  |  |  |
| --- | --- | --- |
|  |比率|尺寸示例 |
|广场| 1:1 | 480 x 480、600 x 600 像素 |
|肖像| 9:16 | 480 x 640、1080 x 1920 像素 |
|风景| 16:9 | 16:9 500 x 375、1920 x 1080 像素 |

至于选择哪种，纵向往往是最佳选择，其次是方形。纵向尺寸的媒体在大多数设备上看起来都不错。这种格式不太可能被切断或裁剪，因为所有媒体都会根据消息的宽度进行调整。 ## GIF 长度

虽然 GIF 的长度可以在 0 到 60 秒之间，但 [GIPHY](https://support.giphy.com/hc/en-us/articles/360019914771-GIF-Creation-Best-Practices) 建议将 GIF 的长度设置为 6 秒或更短。 ## 最佳实践

为 MMS 创建图像和 GIF 有一些注意事项。如果您不遵循这些最佳实践，您的图像可能会与您的预期不同或看起来质量较低。 ### 执行

检查您的图像或 GIF 是否具有：

- ****高色彩对比度****
  确保顶部的图像及其背景彼此不同，因此图像看起来不会模糊或看起来像是一种纯色。 - ****高梯度对比度****
  如果有渐变，请确保渐变中的颜色彼此不要太接近。否则，它可能看起来像纯色图像。 ### 不该做的事

请勿在图像或 GIF 中包含以下任何内容：

- ****透明背景****
  在消息线程中，透明背景看起来是纯色的，并且选择了随机颜色作为背景。因此，收件人不会按照您预期的方式看到您的图像，并且它可能看起来模糊或像纯色图像。 - ****边界****
  某些 iOS 设备会导致边框偏离图像中心。 - ****不透明度过渡 (GIF)**** 避免不透明度过渡有 2 个原因：它们可能显示为随机颜色，并可能导致文件大小较大。 ## 其他资源
