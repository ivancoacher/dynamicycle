可供使用 Marketing Analytics 或 Advanced Klaviyo Data Platform (AKDP) 产品的客户使用。 ### ****概述****

通过在****漏斗分析****页面中添加****可操作性****，您现在可以构建在漏斗中特定点完成或退出的配置文件片段。这使您可以通过从渠道数据构建细分来快速根据洞察采取行动，而无需离开营销分析体验。例如，您可以快速构建以下部分：

- 将商品添加到购物车但未下订单的顾客
- 打开营销活动但未点击的个人资料
- 开始结账但未在渠道时间范围内完成结帐的访问者

这些细分使用[用于细分的事件漏斗](https://help.klaviyo.com/hc/en-us/articles/42691974773147)中提供的相同****顺序事件逻辑****，帮助您将漏斗洞察转化为活动和流程的可操作受众。 ### ****如何从漏斗创建细分****

1. 导航至****营销分析**** > ****客户洞察**** > ****漏斗分析****。 2. 将鼠标悬停在****漏斗台阶****（蓝色条）或****下降****（较浅的对角线连接器）上以查看工具提示。 ![将鼠标悬停在漏斗上可查看可操作的工具提示](https://klaviyo.zendesk.com/hc/article_attachments/42766454485787)
3. 单击工具提示并选择****创建段****。 ![单击工具提示创建分段](https://klaviyo.zendesk.com/hc/article_attachments/42766454486171)
4. ****创建段****抽屉出现在页面的右侧。 - 细分定义是根据您选择的渠道事件或投放点****预先填充的****。 - 应用于漏斗的任何****细分过滤器****都会自动包含在细分定义中。 - 分段名称和****“漏斗分析”标签****也会自动添加。！[带有分段定义的分段创建抽屉](https://klaviyo.zendesk.com/hc/article_attachments/42766454486299)
5. 查看分段定义和成员资格预览。 6. 选择以下选项之一：

- ****创建分段**** — 立即创建分段并显示成功的 Toast 确认。 - ****在构建器中编辑**** — 打开分段构建器，您可以在其中进一步自定义定义。创建后，您将在****细分****页面上找到新细分，标记为**漏斗分析**。 ![细分列表页面上的漏斗细分](https://klaviyo.zendesk.com/hc/article_attachments/42766454486683)

### ****该段是如何构建的****

该细分是使用****事件漏斗细分条件****构建的（**某人按特定顺序采取的步骤**）。它使用您选择的漏斗步骤并自动应用这些设置：

|  |  |
| --- | --- |
| ****漏斗设置**** | ****它如何应用于段定义**** |
| ****分段过滤器**** |如果应用于漏斗，则包含在内 |
| ****事件过滤器**** |当前不支持（应用于漏斗中各个步骤的过滤器不会转移到该段）|
| ****日期范围**** |匹配漏斗分析日期范围，最长 1 年（365 天）|
| ****完成窗口**** |捕捉到分段中最接近的受支持窗口：1 小时、1 天、3 天、5 天、1 周、1 个月、3 个月、6 个月或 1 年。如果未设置，则默认为**所有时间**。 |

****注意：**** 创建后，您可以随时在分段生成器中编辑这些默认值。 ### ****最佳实践和限制****

- 使用此功能****快速将见解转化为行动**** - 例如，重新吸引流失者或培养转化者。 - 对于更复杂的顺序逻辑，请在****段生成器****中打开段并进一步修改。 - 自动分段创建尚不支持****单个漏斗事件****的过滤器。 - 创建的细分的****最大日期范围****是****1年****，即使您的渠道设置为更长的范围。 ### ****示例用例****

- ****重新参与：**** 创建一个在 3 天内 **查看过产品** 但 **未添加到购物车** 的客户群。 - ****放弃恢复：**** 为过去 7 天内 **开始结账** 但 **未购买** 的用户建立细分。 - ****营销活动定位：**** 创建一个**打开**特定营销活动但**未点击**的个人资料片段。 ### ****其他资源****
