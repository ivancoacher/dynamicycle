# ****什么是多电子邮件配置文件？****

多电子邮件配置文件 (MEP) 是 Klaviyo 的一项功能，可让您在单个客户配置文件上存储和管理最多 5 个电子邮件地址。您的客户每次使用不同的电子邮件时都不会显示为多个单独的个人资料，Klaviyo 将所有内容都保存在一个位置，因此您始终可以完整、准确地了解他们是谁。这意味着更好的个性化、更清晰的分析以及您使用的每个渠道中更一致的体验。 # ****为什么这很重要？****

您的客户不会只使用一个电子邮件地址。他们可能会使用个人 Gmail 进行注册，使用工作地址进行结账，然后点击用于购物的第三个地址中的链接。如果没有 MEP，这些交互中的每一个都会在 Klaviyo 中创建一个单独的配置文件，从而导致：

- 重复的个人资料使您的帐户混乱
- 自动化流程中断和错过触发
- 不一致的同意和抑制记录
- 碎片化的数据使得个性化变得更加困难
- 联系数量夸大和分析不准确

MEP 通过将客户的所有电子邮件地址统一到一个配置文件下来解决这一问题。 # ****配置文件如何合并****

## ****什么触发合并？****

当 Klaviyo 可以确认个人资料属于同一个人时，就会合并这些个人资料。当两个配置文件共享一个*​​**外部 ID****（您的商店或集成提供给 Klaviyo 的唯一标识符，例如来自您的电子商务平台的客户 ID）时，就会发生这种情况。可以通过三种方式将电子邮件地址添加到个人资料中：

- ****自动合并：**** 当两个配置文件共享外部 ID 时，Klaviyo 会自动合并它们并组合它们的电子邮件地址。 - ****Klaviyo UI：**** 您可以直接在 Klaviyo 的个人资料页面上手动添加辅助电子邮件地址。 - ****PATCH API：**** 开发人员可以使用 PATCH API 使用 Klaviyo 的身份解析规则以编程方式添加电子邮件。 ## ****配置文件合并时会保留什么？****

当配置文件合并时，Klaviyo 会指定一个作为****目标配置文件**** - 保留其主要电子邮件和身份的配置文件。其他配置文件中的所有内容都折叠在：

- 其他电子邮件地址（最多 5 个电子邮件地址）
- 配置文件属性
- 事件历史和活动
- 同意和禁止记录

****重要提示：**** 每个电子邮件地址在合并后都会保留自己的同意和禁止状态。订阅或取消订阅一封电子邮件不会影响其他电子邮件。 ## ****当个人资料已有 5 封电子邮件时会发生什么？****

每个配置文件最多可以包含 5 个电子邮件地址。如果添加第 6 个：

- 添加新地址。 - 个人资料中最近最少更新的地址将自动删除，以保持在限制范围内。 # ****Klaviyo 如何选择主要电子邮件****

每个个人资料都有一个****主电子邮件**** - Klaviyo 在发送营销活动和流程时默认使用的地址。以下是 Klaviyo 确定哪个地址获得该角色的方法：

****第 1 步 — 同意****

Klaviyo 选择选择加入或订阅营销的电子邮件。能够主动合法接收邮件的地址永远是第一位的。 ****第 2 步 — 参与****

如果多封电子邮件均获得同意，则与最近下订单或非机器人电子邮件点击相关的一封将成为主要电子邮件。最活跃的地址是联系客户的最佳选择。 ****步骤 3 — 后备****

如果没有明确的同意或参与信号，Klaviyo 会使用最近添加的电子邮件作为决胜局。 ## ****主要电子邮件何时更新？****

主要电子邮件未修复 - Klaviyo 会自动重新评估它。 ****实时（大约一小时内）：****

- 新的电子邮件地址已添加到个人资料中
- 当前的主要电子邮件取消订阅、退回或被删除

****每天晚上：****

- Klaviyo 每晚对所有个人资料进行检查，以确认正确的主要电子邮件仍然有效且有效

# ****哪个电子邮件地址收到消息？****

| ****发送类型**** | ****哪个电子邮件收到消息**** |
| --- | --- |
| ****活动和细分**** |当您向分段发送营销活动时，每个配置文件都会通过其主要电子邮件接收该营销活动。辅助电子邮件不包含在营销活动发送中。 |
| ****事件触发流**** |对于由事件触发的流（例如废弃购物车流），Klaviyo 会发送到与触发事件关联的电子邮件地址 - 不一定是主电子邮件。 |

****示例：废弃的购物车****

您的客户使用他们的工作电子邮件进行浏览并将商品留在购物车中。 废弃购物车事件链接到他们的工作电子邮件，因此 Klaviyo 会将流程发送到该地址 - 即使他们的主要电子邮件不同。如果该事件电子邮件被取消订阅或无法访问，Klaviyo 会完全跳过该流程。它不会回退到主要电子邮件或个人资料上的任何其他地址。 # ****常见问题****

****MEP 是如何创建的？****

MEP 入门非常简单。合并个人资料或添加电子邮件的方式有以下三种：

- ****通过外部 ID 自动合并：**** 当 Klaviyo 检测到两个配置文件共享相同的外部 ID（通常是您商店中的客户 ID）时，它会自动将它们合并到单个 MEP 中。无需手动步骤。 - ****通过 Klaviyo UI 手动：**** 您可以直接在 Klaviyo 的任何个人资料页面上添加辅助电子邮件。 - ****通过 PATCH API：**** 开发人员可以使用 PATCH API 以及 Klaviyo 现有的身份解析规则以编程方式添加电子邮件。合并是全自动的——您和您的客户都不需要确认或批准任何事情。 ****个人资料中包含多个电子邮件会影响我的账单吗？****

计费基于个人资料，而不是个人电子邮件地址。具有 3 个电子邮件地址的个人资料仍算作您计划中的 1 个联系人。事实上，MEP 可以帮助减少您的计费联系人数量。如果您之前使用不同的电子邮件地址为同一客户拥有重复的个人资料，则将它们合并到一个 MEP 个人资料中可以删除这些重复项，这意味着总体上的联系人数量会减少。 ****如果主电子邮件被取消订阅或在发送时无法访问会发生什么？****

****对于营销活动：**** Klaviyo 仅发送到主电子邮件。如果在发送时取消订阅或无法访问，则将完全跳过该配置文件。 Klaviyo 不会退回到辅助电子邮件。 ****对于事件触发的流：**** Klaviyo 发送到与触发事件相关的电子邮件，该电子邮件可能与主电子邮件不同。如果该事件电子邮件已取消订阅或无法访问，则将跳过该流程。没有备用电子邮件地址或个人资料上的任何其他地址。 ****如果我尝试向个人资料中添加超过 5 封电子邮件，会发生什么情况？****

如果 CSV 包含同一配置文件的多行，每行具有不同的电子邮件地址，则行为取决于提取方法。 #### 列表导入 UI / SFTP

转换层在处理之前对行进行重复数据删除，因此仅保留配置文件的****最后一行****（在同一块内）。较早的电子邮件值将被丢弃。要保留多封电子邮件：

- ****SFTP:**** 使用 `append_emails` 列
- ****列表导入 UI：**** 映射多个电子邮件列

两种方法都会生成“patch_identifiers”有效负载，该有效负载会正确附加所有电子邮件。 #### 批量 API

所有行都发送到配置文件服务，其中“_merge_payloads()”合并同一配置文件的更新。 `patch_identifiers` 使用专用的合并路径 (`_merge_patch_identifiers()`) 累积追加/取消追加操作而不是覆盖它们，因此所有电子邮件地址都跨行保留。 #### 用户界面行为

在 UI 中手动添加电子邮件时，横幅会提示您在添加新电子邮件之前删除现有电子邮件。
