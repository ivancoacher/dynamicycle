## ****什么是列表和段限制？****

为了保持 Klaviyo 快速可靠，每个帐户中可以创建的列表和分段有最大数量。一旦您的帐户达到限制，您可能会看到警告或被阻止创建新列表或细分。

对于大多数帐户，默认限制为：

|  |  |
| --- | --- |
| ****项目**** | ****限制**** |
|帐户中的总列表 |多达 1,000 个列表 |
|帐户中的活跃段总数 |多达 1,000 个活跃段 |
|加星标的片段 |无单独上限（计入段限制内）|
|不活跃段 |无限制|
|每个段的标准（过滤器）|多达 100 个条件 |

由于旧配置或批准的覆盖，某些帐户可能有不同的限制。

## ****我怎样才能知道我何时接近极限？****

当你接近极限时：

- ****列表和细分****页面上会出现一个计数器，显示您拥有多少列表和细分，以及距离上限有多近。

当你达到极限时：

- 如果您在达到上限后尝试创建新列表或细分，您将看到一条警告，说明您的帐户已达到上限。
- 在释放空间或增加限制之前，您将无法保存或创建其他列表或细分。

作为此强制执行的一部分，不会自动删除任何现有列表或段。

## ****达到上限后创建更多列表或段****

如果您已达到限制，您有两种选择：

1.****通过删除或归档现有组来释放空间****
   - 查看您的“列表和细分”页面，了解您不再使用的列表或细分。
   - 删除或归档不需要的组。
   - 清理后，您可以立即再次创建新的列表或段（计数更新时可能会有几秒钟的短暂延迟）。
2. ****请求更高的限制（针对符合条件的用例）****
   - 如果您有更多列表或细分的合法业务需求（例如，复杂的多区域设置或大型产品目录），您可以联系 Klaviyo 支持。
   - 在您的请求中，请包括：
     - 您的帐户名或 ID
     - 为什么您需要更高的限制以及您今天如何使用列表/细分
     - 您请求多少个附加列表或片段

Klaviyo 将根据您的使用案例进行审查并可能批准有条件的增加。限制以受控增量提高，以确保您的帐户和更广泛的平台的性能和可靠性。

## ****保持在限制范围内的最佳实践****

1. 整合相似的细分市场，而不是创建许多近似重复的细分市场。
2. 尽可能使用细分条件（例如属性、参与标准）而不是单独的列表。
3. 定期检查和清理旧的、未使用的列表和段。
4. 使用非活动段来存储不需要主动运行的定义，而不计入活动段上限。

这些做法可以帮助您保持在限制范围内，同时让您的帐户更易于管理，并且随着时间的推移，性能会更高。
