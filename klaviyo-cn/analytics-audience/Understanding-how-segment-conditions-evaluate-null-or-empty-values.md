## 你将会学到

了解 Klaviyo 中未设置或没有值的分段和属性。这些更改于 2023 年 4 月实施。除了下面概述的更改之外，所有日期分段现在都使用 UTC 时区。了解[使用日期分段](https://help.klaviyo.com/hc/en-us/articles/4403222359451) 的更改。 ## 关键术语

- ****属性未设置****配置文件中不存在的属性
- ****没有价值的财产****
  在配置文件上设置但没有关联值的属性

## 未设置的属性和布尔值

在布尔条件（即真/假条件）中，评估中不再考虑不存在的属性。 - ****旧系统****属性不存在的配置文件过去常常被评估为False。 - ****新系统****不存在属性的配置文件现在被排除在评估之外。考虑条件****关于某人的属性 > VIP > 为假****。 Klaviyo 帐户包含以下配置文件：

|  |  |  |
| --- | --- | --- |
| ****个人资料**** | ****旧系统下：**** | ****新系统下：**** |
| 100 个个人资料，其中 ****VIP = true**** | 🚫 从细分中排除 | 🚫 从细分中排除 |
| 50 个个人资料，其中 ****VIP = false**** | ✅ 包含在细分中 | ✅ 包含在细分中 |
| 25 个配置文件，其中 ****VIP 属性**** 未设置 | ✅ 包含在细分中 | 🚫 从细分中排除 |

更改之前，此段包含 ****75 个配置文件****。更改后，它包括****50 个配置文件****。 ### 为什么这样更好

新系统更准确地仅评估 True 或 False 条件，并且您可以选择显式包含未设置该属性的配置文件（如果需要），方法是添加条件****或关于某人的属性 > [配置文件属性] > 未设置****。 ## 未设置的属性和文本条件

从历史上看，当评估文本条件不存在的配置文件属性时，这些值被视为包含文本“无”。现在，这些值被排除在文本条件的考虑范围之外。 - ****旧系统****搜索“N”、“No”和“None”等字符串的文本条件包括未设置的属性。 - ****新系统****配置文件中不存在的属性现在被排除在评估之外。考虑条件****某人的属性>你吃豆腐>包含“否”****。 Klaviyo 帐户包含以下配置文件：

|  |  |  |
| --- | --- | --- |
| ****个人资料**** | ****旧系统下：**** | ****新系统下：**** |
| 50 个配置文件****你吃豆腐=是**** | 🚫 从细分中排除 | 🚫 从细分中排除 |
| 25 个人资料****你吃豆腐=不**** | ✅ 包含在细分中 | ✅ 包含在细分中 |
| 15个配置文件中属性****你吃豆腐****没有设置| ✅ 包含在细分中 | 🚫 从细分中排除 |

更改之前，该段包含 ****40 个配置文件****。它将计算回答“否”的 25 个配置文件，以及未设置该值的 15 个配置文件，因为它将其空值视为“无”。变更后，包含****25个配置文件****。 ### 为什么这样更好

新系统不会在未设置的配置文件属性中错误地设置字符串“None”。这意味着任何包含“N”、“否”、“非”和“无”的搜索将不再包含这些属性。 ## 未设置的属性和否定条件

当段使用否定条件（即配置文件属性“不是”特定值或“不包含”特定字符串）时，该段将不再包含未设置的属性。 - ****旧系统****未设置的属性过去常常包含在具有否定条件的段中。 - ****新系统****未设置的属性现在被排除在评估之外。考虑条件****某人的属性>最喜欢的颜色>不等于>红色****。 Klaviyo 帐户包含以下配置文件：

|  |  |  |
| --- | --- | --- |
| ****个人资料**** | ****旧系统下：**** | ****新系统下：**** |
| 60 个配置文件，其中****最喜欢的颜色 = 红色**** | 🚫 从细分中排除 | 🚫 从细分中排除 |
| 45 个配置文件，其中****最喜欢的颜色 = 蓝色**** | ✅ 包含在细分中 | ✅ 包含在细分中 |
| 100 个配置文件，其中属性 **** 最喜欢的颜色 **** 未设置 | ✅ 包含在细分中 | 🚫 从细分中排除 |

更改之前，此段包含 ****145 个配置文件****。变更后，包含****45个配置文件****。 ### 为什么这样更好

以前的系统是不明确的，并且不清楚为什么某些配置文件在没有配置文件属性的情况下被包含在内。如果需要的话，也没有直接的方法来排除这些配置文件。新系统明确表示仅包含设置了该属性的配置文件。如果您想要包含未设置个人资料属性的个人资料，您可以通过添加****或有关某人的属性 > [个人资料属性] > 未设置****来实现。 ## 未设置的国家和“是否属于欧盟 (GDPR)”标准

当分段标准包含定义“如果某人位于或不在欧盟 (GDPR)”“位置不在欧盟/美国境内”时，该分段将不再包含未设置“国家/地区”属性的配置文件。 - ****旧系统****属性不存在的配置文件曾经包含在该段中。 - ****新系统****
  不存在财产的个人资料现在被排除在评估之外。考虑条件****如果某人在或不在欧盟 (GDPR) 内 > 位置不在 > 在 > 欧盟内****。 Klaviyo 帐户包含以下配置文件：

| ****个人资料**** | ****旧系统下：**** | ****新系统下：**** |
| 50 个个人资料，其中 ****国家**** = 美国 | ✅ 包含在细分中 | ✅ 包含在细分中 |
| 40 个配置文件，其中 ****国家**** = 西班牙 | 🚫 从细分中排除 | 🚫 从细分中排除 |
| 20 个配置文件，其中 ****国家**** = 法国 | 🚫 从细分中排除 | 🚫 从细分中排除 |
| 100 个配置文件，其中属性 ****Country**** 未设置 | ✅ 包含在细分中 | 🚫 从细分中排除 |

更改之前，此段包含 ****150 个配置文件****。更改后，它包括****50 个配置文件****。 ### 为什么这样更好

新系统更准确地仅评估已知国家/地区的资料。如果需要，您可以选择显式包含没有已知国家/地区的个人资料，方法是添加条件****或有关某人的属性 > 国家/地区 > 未设置****。
