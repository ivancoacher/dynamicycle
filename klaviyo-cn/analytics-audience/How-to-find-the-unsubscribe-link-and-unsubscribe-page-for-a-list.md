## 你将会学到

了解如何访问列表的取消订阅页面编辑器以及您可以根据请求向订阅者提供的可共享取消订阅链接。

取消订阅链接会将客户直接带到 Klaviyo 托管的给定列表的取消订阅页面。请注意，除了您可以通过以下流程访问的链接之外，您的订阅者还可以随时单击您发送的任何电子邮件底部的取消订阅链接。

## 找到您列表的取消订阅页面

要查找列表的取消订阅链接：

1. 单击 Klaviyo 侧栏中的****受众 >**** ****列表和细分****。
2. 单击列表（不是段）。
3. 单击****订阅和首选项页面****。
4. 滚动到**电子邮件取消订阅页面**图块。
   ![替代](https://klaviyo.zendesk.com/hc/article_attachments/34319088435355)
5. 单击****编辑页面****。

## 找到列表的取消订阅链接

要查找列表的取消订阅链接：

1. 单击 Klaviyo 侧栏中的****受众 >**** ****列表和细分****。
2. 单击列表（不是段）。
3. 单击 ****设置****。
4. 转到 ****同意****选项卡。
   ![列表设置中的可共享取消订阅链接](https://klaviyo.zendesk.com/hc/article_attachments/34319049875099)
5. 向下滚动到**取消订阅**部分，您将在其中看到取消订阅链接。

列表设置中提供的链接可以手动与请求取消订阅的任何人共享。无需在您的电子邮件中包含此链接；相反，包含动态 {% unsubscribe %} 标记。
