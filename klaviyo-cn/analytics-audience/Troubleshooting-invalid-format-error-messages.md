## 你将会学到

了解“无效_格式”错误消息的含义以及使用 CSV 文件上传列表时如何避免这些消息。

## 关于不匹配的数据类型

当您将列表导入 Klaviyo 时，字段映射页面使您能够将任何属性与其在 Klaviyo 中相应的数据类型进行匹配。例如，**电子邮件**始终具有**文本**数据类型；然而，如果您上传 **生日** 的自定义属性，您将需要将数据类型设置为 **日期**。

查看下面的数据类型、可接受的格式和示例。

- ****文本****
  任何文本或文本和数字的组合。如果您不确定数据的格式，请选择此选项。
  - 示例：
    电子邮件@example.com
    你好，世界
    5.00 美元
- ****数字****
  所有数字。请勿在数字字段中包含货币符号。
  - 示例：
    2
    5.0031
    130.0
- ****布尔****
  真值或假值。
  - 示例：
    真实
    假的
- ****日期****
  请参阅我们的[配置文件和事件属性可接受的日期和时间戳格式](https://help.klaviyo.com/hc/en-us/articles/115005253428) 指南，了解可接受的日期格式。
  - 示例：
    2014-09-01 13:34:08
- ****列表****
  数据必须格式化为 JSON 数组。
  - 示例：
    [“苹果”、“香蕉”、“橙子”]
    [“苹果”]
- ****同意****
  同意的格式为渠道（电子邮件、短信等）和同意类型（如果 Klaviyo 中有多种类型可用）。电子邮件的唯一选项是**电子邮件营销同意**；对于短信，可以是**短信营销同意**或**短信交易同意**；等等。此字段的值必须是“订阅”、“从未订阅”或“取消订阅”。

有关不同数据类型的含义以及导入列表时选择哪些数据类型的更多信息，请参阅我们的[了解数据类型]指南(https://help.klaviyo.com/hc/en-us/articles/115005237648)。

## 错误：列表格式无效

为了使用“列表”数据类型，您的数据必须格式化为 JSON 数组。 JSON 数组始终用方括号括起来，每个列表项用引号括起来。除最后一项之外的每个列表项后面都必须跟一个逗号。

确保使用直引号 (" ") 而不是弯引号 (“ ”)。

以下是格式正确的 JSON 数组：

- [“苹果”、“香蕉”、“橙子”]
- [“苹果”]

## 错误：布尔格式无效

布尔值必须是“true”或“false”。如果您的布尔值列包含“true”或“false”以外的任何内容，请替换这些值或将属性上传为文本。

## 错误：数字格式无效

“数字”数据类型接受整数（例如 1、63）和浮点数（例如 1.5、233.018）。此数据类型不允许任何特殊字符，包括货币符号。

## 错误：电子邮件格式无效

Klaviyo 自动跳过格式无效的电子邮件地址条目。有效的电子邮件地址（例如 jane@example.com）由本地部分 (jane)、@ 符号和不区分大小写的域部分 (example.com) 组成。如果缺少任何这些必需部分，我们将认为该电子邮件无效。如果电子邮件地址中存在错误的空格，我们也会认为该电子邮件无效。

您可以在 CSV 中搜索无效电子邮件。突出显示电子邮件地址列表，然后选择****数据 > 过滤器****。然后，过滤掉任何不包含“@”或“.”等符号的电子邮件地址。在重新尝试导入之前修复或删除这些无效电子邮件。

![](https://fast.wistia.com/embed/medias/l4gja9eki9/swatch)

如果您的电子邮件地址格式均正确，但您仍然收到此错误消息，请检查单元格内是否有换行符并将其删除。 CSV 中单元格内的换行符将被解释为上传中的新行，从而导致数据和标题之间不对齐。

## 错误：电话号码格式问题

电话号码必须包含国家/地区代码或指示所在国家/地区的单独列，并且必须遵循可接受的电话号码格式。了解如何[正确设置电话号码格式并上传](https://help.klaviyo.com/hc/en-us/articles/360035428731)。
