## ****你会学到****

如何创建从一个或之前发送的最多营销活动转换的配置文件的静态列表。  这些使用转换后的个人资料创建的列表可用于重新定位已转换的个人资料，以发送有针对性的追加销售和交叉销售活动，或排除从后续发送中转换的个人资料。

这是****一次性填充****：该列表是您创建它时转换器的快照，并且****不****随着新转换自动更新。目前，诸如归因消息（例如订单归因于的消息）之类的归因数据在分段中不可用，列表和分段之间的差异可以在[此处](https://help.klaviyo.com/hc/en-us/articles/115005061447)找到

## ****将转换后的配置文件添加到列表****

1. 导航至****受众 > 列表和细分****。
2. 选择您想要添加联系人的列表（例如新闻通讯）。
   - 如果您想创建新列表，请选择“新建”>“创建列表”并命名新列表。

![](https://klaviyo.zendesk.com/hc/article_attachments/48460584325787)

3. 如果列表为空，您可以使用快速操作将转换后的配置文件添加到列表中，如下所示

****！[](https://klaviyo.zendesk.com/hc/article_attachments/48460584327707)****

- 如果列表有配置文件，您可以通过管理列表操作菜单将转换后的配置文件添加到列表中

![](https://klaviyo.zendesk.com/hc/article_attachments/48460612821659)

4. 要将转换后的配置文件添加到列表中，请从列表视图中显示的营销活动列表中进行选择。  选择具有一项或多项归因转化的一个或多个广告系列后，预计列表大小将更新，以显示将添加到列表中的个人资料的预计数量

![](https://klaviyo.zendesk.com/hc/article_attachments/48460612822299)

5. 选择完营销活动后，您可以单击右上角的“添加到列表”

可以使用发送日期和渠道来过滤列表视图，并且可以更新转化指标以使用 Klaviyo 帐户中的任何转化指标

## ****示例用例****

以下是此功能的一些常见模式：

1. 从后续发送中排除转换器
   - 创建从 BFCM 活动转换的个人资料列表。
   - 从未来的提醒或促销活动中排除该列表，这样您就不会继续向已购买的人推送相同的优惠。
2. 创建交叉销售受众
   - 建立从特定产品发布活动转化的个人资料列表。
   - 使用该列表作为后续活动的受众，突出显示配件、补充装或补充产品。
3. 重新吸引高意向转化者
   - 创建从“winback”或“back-in-stock”活动转化的个人资料列表。
   - 在旨在推动他们进行更高价值的购买或订阅的流程或活动旅程中使用此列表。
