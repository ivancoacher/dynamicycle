## 你将会学到

了解单次选择加入和双重选择加入之间的区别、为什么双重选择加入对于短信和电子邮件都很重要，以及如何更新 Klaviyo 中列表或关键字的选择加入设置。 ## 什么是双重选择加入？双重选择加入是新订阅者在订阅给定列表之前必须确认其订阅的过程。对于电子邮件和短信订阅者来说都是一样的。可以在列表级别设置双重选择加入。如果列表具有双重选择加入功能，则订阅该列表的每个人都必须在注册后立即发送确认消息来确认其兴趣，然后才能添加。此消息将提示他们确认订阅。只有确认订阅的订阅者才会成功添加到列表中，并排队等待欢迎系列。 SMS 关键字也存在双重选择加入。对于通过 SMS 关键字选择加入的订阅者，关键字的选择加入设置将覆盖列表的设置。您应该始终对短信列表使用双重选择加入。运营商经常需要它，特别是对于废弃的购物车消息。 ### 双重选择加入如何与品牌发件人 ID 配合使用？品牌发件人 ID 无法接收短信，因此订阅者无法确认他们是否要选择加入。因此，对于您使用品牌发件人 ID 的任何国家/地区，都会自动跳过双重选择加入确认文本。但是，如果您使用的是付费套餐，请考虑使用智能选择加入作为收集短信同意的默认设置。通过智能选择加入收集短信同意类似于双重选择加入流程，访问者需要执行 2 个步骤来选择加入：输入他们的电话号码，然后输入他们收到的一次性代码。 ### 双重选择加入如何与短信交易配合使用？目前，双重选择加入不适用于短信交易同意。仅注册交易短信的任何人都不会收到确认消息。相反，交易短信同意会立即添加到配置文件中。如果有人选择加入交易短信和促销短信，则交易同意会立即添加到个人资料中，但双重选择加入文本会发送促销同意。在这种情况下，您将能够发送交易短信，但在通过双重选择加入确认个人资料之前，您无法发送促销短信。 ## 为什么双重选择很重要？当您将注册表单添加到您的网站时，您无法控制谁决定利用此表单。即使您添加额外的验证级别，也并不总是能够确保订阅者仅提交有效或准确的电子邮件地址和电话号码。善意的订阅者可能只是错误地输入了他们的电子邮件或电话号码，但垃圾邮件机器人也可能找到您的表单并用虚假的电子邮件地址或电话号码淹没它。双重选择加入流程可帮助您扩大列表，同时最大限度地减少滥用并防止无效或错误输入的电子邮件和电话号码的累积。对于电子邮件来说，这一点尤其重要，因为大多数主要电子邮件客户端（如 Google 和 Yahoo）都会跟踪收件人如何与您所在域的电子邮件进行交互 - 有多少邮件被标记为垃圾邮件、有多少邮件被打开、有多少邮件被退回等。他们使用此信息来确定您的电子邮件是否被分类为垃圾邮件。如果您的列表中存在大量不感兴趣的人或大量无效电子邮件，只会损害您联系那些真正想要接收您的电子邮件的人的努力。列表导入不会触发双重选择加入。 ## 更新选择加入设置

在某些特定情况下，您可能希望删除双重选择加入并使您的列表成为单一选择加入。大多数情况下，品牌在使用其他第三方注册表单或工具时会选择实施单一选择加入，并且在注册工作流程中的其他点会提示客户进行双重选择加入确认。例如，如果您的第三方注册表单启用了双重选择加入功能，您可能需要在 Klaviyo 列表上禁用双重选择加入，以便客户不会遇到多次选择加入确认消息。不建议对 SMS 使用单选择加入，因为某些运营商和废弃购物车消息（在美国和加拿大）需要双选择加入。新列表是使用您的[默认选择加入设置](https://www.klaviyo.com/settings/account/api-keys) 创建的。更改此设置不会更新现有列表，以启用给定列表的单一选择加入：

1. 单击要编辑的列表。 2. 选择****设置****。 3. 选择****同意****。 ![同意标签.jpg](https://klaviyo.zendesk.com/hc/article_attachments/28717991555099)
4. 选中**单一选择加入**旁边的框。
   ![settings.jpg 中的单选](https://klaviyo.zendesk.com/hc/article_attachments/28717985684379)
5. 单击****保存****。一旦此设置发生更改，当有人订阅（电子邮件、短信或两者）时，他们将不需要确认订阅。例如，如果有人通过表单订阅，并且他们发送到的列表是单选加入，那么他们将立即添加到该列表中。默认情况下，短信关键字设置为单一选择加入。但是，您也可以控制关​​键字的选择加入设置。要更改关键字的选择加入设置：

1. 单击左下角您的组织名称。 2. 导航至****设置 > 短信 > 自动化****。 3. 找到**订阅关键字**部分。 4. 展开所需订阅关键字的菜单，然后选择****编辑****按钮以设置所需的选择加入状态。 ![keywordoptin.jpg](https://klaviyo.zendesk.com/hc/article_attachments/28717991544219)

## API 双重选择加入设置

如果您使用 [Klaviyo 的 API](https://developers.klaviyo.com/en/docs/collect_email_and_sms_consent_via_api) 收集同意，则双重选择行为取决于订阅的个人资料是否带有列表。 ### 有一个列表

通过 API 使用列表订阅配置文件时，列表的选择加入设置决定用于订阅该 API 调用的配置文件的选择加入流程。当提供列表时，帐户的[默认选择加入设置](https://www.klaviyo.com/settings/account/api-keys) 将不会对此处的行为产生影响。 ### 没有列表

通过 API 订阅没有列表的配置文件时，用于订阅配置文件的选择加入流程取决于帐户的[默认选择加入设置](https://www.klaviyo.com/settings/account/api-keys)。 ## 如果有人不确认订阅会发生什么

如果有人通过启用了双重选择加入的[订阅页面](https://help.klaviyo.com/hc/en-us/articles/115005251988)订阅列表，则在客户确认其订阅之前不会创建个人资料。如果某人通过 Klaviyo 注册表单或设置为双重选择加入的关键字订阅列表，但未能确认双重选择加入消息，Klaviyo 会为此人创建一个空白个人资料。这意味着该联系人不会添加到列表中，并且除了表单的常规属性（例如名字、姓氏、电子邮件地址和电话号码）之外，其个人资料中没有列出更多信息或活动。但是，如果您使用第三方表单，或者通过我们的 API 进行注册，Klaviyo 将不会创建空的个人资料 - 相反，订阅者只有在确认选择加入后才会同步到您的帐户。在此阶段，联系人可能会成为 [cookied](https://klaviyo.zendesk.com/hc/en-us/articles/360034666712)，这意味着他们未来与您的品牌的互动将作为其个人资料中的事件进行跟踪。这意味着即使它们没有订阅任何特定列表，也可以将它们添加到基于行为的细分中。值得注意的是，这些个人资料无法通过 UTM 跟踪来识别，因为 Klaviyo 不会跟踪谁确认了双重选择加入消息。双重选择加入电子邮件的有效期为 72 小时。 ## 其他资源
