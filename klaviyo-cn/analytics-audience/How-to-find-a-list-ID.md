## 你将会学到

了解如何找到分配给 Klaviyo 中每个列表的唯一 ID。除了列表之外，还包括每个用户、流量、活动、细分等等。

## 查找您的列表 ID

要查找现有 Klaviyo 列表的列表 ID：

1. 导航至您帐户的****列表和细分****选项卡。
2. 单击特定列表。
3. 单击进入****设置****选项卡。
4. 在这里，您将在页面顶部附近找到您的列表 ID。
   ![查找列表ID.jpg](https://klaviyo.zendesk.com/hc/article_attachments/28704484548635)

此外，在查看此列表时，您可以在浏览器的 URL 中找到列表的 ID。在 URL 中，您将看到一串简短的数字和字母 — 这是列表 ID。

![在列表 URL 中找到的列表 ID](https://klaviyo.zendesk.com/hc/article_attachments/28704484547739)
