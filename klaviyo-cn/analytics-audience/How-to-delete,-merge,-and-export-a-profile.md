## 你将会学到

了解如何在 Klaviyo 中删除、合并和导出配置文件，以保持您的帐户井井有条。有关配置文件的一般信息，请参阅我们关于 [Klaviyo 中的配置文件](https://klaviyo.zendesk.com/hc/en-us/articles/115005247088) 的文章。 ## 删除、合并或导出配置文件

1. 在帐户顶部标有“**搜索”的主搜索栏中输入特定个人资料的电子邮件地址或姓名，然后选择“**在个人资料中搜索**”选项，即可导航至特定个人资料。 2. 进入客户的个人资料后，选择****个人资料操作****按钮
   ![profile.jpg 标题中的配置文件操作按钮](https://klaviyo.zendesk.com/hc/article_attachments/28720667101211)

### 删除个人资料

要删除 Klaviyo 配置文件：

1. 单击“**配置文件操作**”下拉列表中的“****删除配置文件****”。 2. 在出现的弹出窗口中，选择****删除个人资料。****

详细了解[记录 GDPR 删除请求](https://help.klaviyo.com/hc/en-us/articles/360004217631-How-to-Handle-GDPR-Requests#record-gdpr-deletion-requests)。对于个人资料的事件历史记录，任何特定于客户的信息都将替换为“已编辑”一词，并且客户的信息将从 Klaviyo 中永久删除。对于与配置文件关联的每个收件人记录，配置文件的电子邮件地址将替换为以“已编辑”一词开头的随机电子邮件地址。例如，redacted.11bab993-58bb-4cc9-a654-c152dbe009e1@example.com。 ![经过编辑的电子邮件地址](https://klaviyo.zendesk.com/hc/article_attachments/28720621746587)

如果某人从列表中删除，然后重新添加到同一列表中，他们将不会重新进入该列表触发的任何流。了解有关[配置文件和列表触发流](https://help.klaviyo.com/hc/en-us/articles/360003031652-Guide-to-Creating-a-List-Triggered-Flow)的更多信息。 ### 合并 2 个配置文件

在某些情况下，您可能希望将一个配置文件与另一个配置文件合并。示例情况包括：

- 您帐户中的同一联系人有 2 个不同的个人资料和 2 个不同的电子邮件地址；合并这些个人资料将仅生成 1 个个人资料，其中包含该联系人的 1 个电子邮件地址。 - 同一联系人有 2 个个人资料，其中一个的电子邮件地址存在拼写错误；合并将确保您仅使用活动配置文件并合并错误配置文件的数据。要合并配置文件：

1. 导航到个人资料并选择 **个人资料操作下的 **合并个人资料****。**
2. 在出现的弹出窗口中，输入您要合并到（保留）的个人资料的电子邮件地址或名称，然后使用键盘上的 Return 或 Enter 按钮进行搜索
3. 从搜索结果中选择个人资料
   - 如果您没有看到要合并的个人资料，请确保搜索中没有拼写错误，然后使用 Return 或 Enter 按钮再次搜索
4. 单击****合并配置文件****

合并过程需要一些时间才能完成。此操作是永久性的。合并配置文件时，会重播事件并显示晚于事件时间戳的**记录日期**。 ![用户合并两个 Klaviyo 配置文件](https://fast.wistia.com/embed/medias/gmbodq21od/swatch)

您保留的个人资料上的属性将保持不变。仅当您删除的配置文件中的属性尚不存在于剩余配置文件中时，才会将其添加到您保留的配置文件中。有 2 个例外：

- ****时区****
  将保留源配置文件中的时区
- ****地点****
  位置信息保留在包含大多数位置信息的个人资料中。例如，如果源配置文件具有完整的街道地址，而目标配置文件仅具有城市，则合并的配置文件将具有完整的街道地址。 |  |  |  |

合并配置文件时，源配置文件的所有事件数据也将复制到目标配置文件。如果将抑制的配置文件与活动的配置文件合并，则默认情况下生成的配置文件将被抑制。 ### 导出配置文件的数据

1. 导航到您要导出的配置文件，然后单击 **配置文件操作** 下拉列表下的 ****导出配置文件****。 2. 在出现的模式中，点击****开始导出****，导出配置文件数据

绿色标注将确认您的个人资料数据在您的[**下载**页面](https://www.klaviyo.com/downloads)上可用。从您的 **下载** 页面，单击 ****下载**** 将您的个人资料数据导出为 .zip 文件。 ![Klaviyo的文件下载按钮](https://klaviyo.zendesk.com/hc/article_attachments/28720621743643)
