## 你将会学到

了解非活动分段的标准、如何手动停用分段以及如何重新激活分段。非活动分段是指您在过去 45 天（对于常规分段）或 365 天（对于加星标分段）内未使用过的任何分段。这些细分会自动移至“列表和细分”页面的“非活动细分”部分。一旦某个细分被标记为非活动状态，您将不再看到它可用于营销活动、流程触发器和过滤器、导出或注册表单。不活动的段可以随时重新激活。您还可以手动停用分段。当您需要减少帐户中的活动分段数量，或者只是想清理它们以使帐户更易于导航时，您可能希望执行此操作。如果您认为将来可能想再次使用或引用该段，则停用段是永久删除段的替代方法。 ## 非活跃段的标准

任何未使用的段将自动移至“非活动段”选项卡。只要分段连续 45 天满足以下所有条件，就会被标记为不活跃：

- 未连接到任何流程、注册表单或出站广告同步（例如 Facebook、Google Ads）
- 尚未在任何活动中使用
- 尚未在您的仪表板中加星标
- 名称或定义尚未更新
- 尚未使用公共 API 端点
- 分段成员资格尚未导出
- 未查看分部业绩报告和增长报告
- 分段尚未打开/查看（注意：这意味着单击分段链接；仅在列表和分段页面中展开定义不算）

如果该段已加星标，则上述标准成立，但不活动窗口为连续 365 天（而不是标准的 45 天）。一般段活动（即，根据其定义移入和移出段的配置文件）确实****不会****阻止段变得不活动。此外，如果 Klaviyo 帐户未采用付费计划并且在 12 个月内处于非活动状态，则该帐户中的所有分段都将被停用（包括加星标的分段）。此时，只有 Klaviyo 可以停用某个分段。您无法手动停用分段。 ## 如何防止段停用

为了防止分段被停用，您可以采取以下任何符合条件的操作：

1. 在营销活动中使用（通过在收件人列表或排除列表中选择分段）
2. 用于分段触发流程。只要流处于活动状态，该段也将保持活动状态。 3.以形式使用。只要表单处于活动状态，该段也将保持活动状态。 4. 用于广告同步操作。只要广告同步处于活动状态，该分段也将保持活动状态。 5. 使用公共 API 端点作为分段/列表成员资格
6. 导出分段成员资格
7. 查看分部业绩或分部增长报告
8. 更新段名称或定义
9. 单击打开并在 UI 中查看分段（注意：您必须单击分段链接；仅在列表和分段页面中展开定义不算）
10. 在 UI 中为该片段加注星标。这将使该细分市场即使没有任何符合条件的操作，也能在 365 天内保持活跃状态​​。详细了解[加星标的片段](#h_01K8Y0AQGJEQKPT6GR5R15DX2Z)。 ##

## 如何手动停用分段

1. 找到您想要停用的分段。 2. 单击分段菜单（屏幕右侧的三个点）。 3. 从下拉菜单中选择****停用段****。系统将提示您确认是否要停用该分段。 ![](https://klaviyo.zendesk.com/hc/article_attachments/46630692439451)
4. 确认后，将该段移至列表/段页面上的非活动段部分。 ## 重新激活不活动的段

要重新激活非活动段：

1. 导航至****受众 >**** ****列表和细分****。 2. 选择****非活动段****。 ![](https://klaviyo.zendesk.com/hc/article_attachments/46630728552987)
3. 找到您要重新激活的段。 4. 单击****重新激活****。 ****！[重新激活按钮](https://klaviyo.zendesk.com/hc/article_attachments/28711676853659)****
5. 单击****更新段****。 ****！[更新片段按钮](https://klaviyo.zendesk.com/hc/article_attachments/28711676855067)****

然后，该细分会出现在您的活动列表和细分中。 ## 什么是加星标分段以及如何使用它们？ 对细分加注星标可以让该细分避免 45 天不活动限制，并将不活动窗口延长至 365 天。这意味着加星标的分段最多可以保留 365 天，而无需采取任何[合格操作](#h_01HCWV4J0HDZ8KPC5XVD6GCENR)。 365 天过去后，如果没有任何符合条件的操作，加星标的分段将变为非活动状态。可以使用[与上述相同的步骤](#h_01HCWV4J0HHK0JBS4HKFNE7M1B) 重新激活它。注意：此****不适用于****订阅我们的[高级 KDP/营销分析产品](https://help.klaviyo.com/hc/en-us/articles/17655007276059) 的 Klaviyo 帐户。对于 MA/AKDP 客户，加星标的细分永远不会变得不活跃。要为某个分段加注星标，请单击该分段名称旁边的星形图标。 ![如何为某个片段加注星标](https://klaviyo.zendesk.com/hc/article_attachments/28711676849947)

加星标的片段还可以通过以下方式在 Klaviyo 应用程序中使用：

(1) 作为列表和细分页面上的标签/过滤器

(2) 指定哪些细分显示在有权访问我们的高级 KDP/营销分析产品的账户中的[受众群体绩效仪表板](https://help.klaviyo.com/hc/en-us/articles/17798068936219) 上。 ## 其他资源
