## 你将会学到

了解注册表单编辑器的 **定位和行为** 部分，您可以在其中控制和更改表单何时出现在您的网站上以及谁可以看到它。打开现有注册表单的表单编辑器，然后选择****定位和行为****来调整本指南中介绍的显示和定位设置。 ![选择“目标和行为”选项卡在表单编辑器中打开示例注册表单。](https://klaviyo.zendesk.com/hc/article_attachments/28716331240859)

## 开始之前

在 **定位和行为** 选项卡中，您可以在 ****显示**** 和 ****定位**** 菜单之间切换。 ![显示和定位在表单编辑器的“定位和行为”选项卡中切换。](https://klaviyo.zendesk.com/hc/article_attachments/28716331243419)

在****显示****菜单上您可以编辑：

- **时间**
- **频率**
- **设备**
- **自定义触发器**

  在****定位****菜单上，您可以通过定位来选择谁可以看到您的表单：
- **访客**
- **网址**
- **UTM 参数**
- **地点**

本指南将引导您完成“显示”菜单中的每个选项，然后是“定位”菜单中的每个选项。根据您在 Shopify 中的客户隐私设置，Klaviyo 可能不会跟踪欧盟、欧洲经济区、英国和瑞士 Shopify 商店访客的现场活动（因此不会应用某些类型的表单定位），除非他们已表示同意。总体而言，如果访问者未同意，并且按照定位要求本来会被包含在内，则他们将看不到该表单，因为不会识别他们的身份。这些访问者的定位将适用如下：

- 如果您选择“不向现有 Klaviyo 个人资料显示”，访问者仍会看到该表单，因为他们不会被识别为现有个人资料。 - 如果您选择“列表或分段中的目标访问者”，则访问者将看不到表单（即使他们位于列表或分段中），因为他们不会被识别。 - 如果您选择“向所有访客显示”，访客将看到它。 - 如果您选择“显示给任何现有的个人资料”、“仅显示给电子邮件订阅者”或“仅显示给短信订阅者”，访问者将看不到表单，因为他们不会被识别为现有的个人资料、电子邮件或短信订阅者。 - 某些基于cookie信息和用户属性的自定义触发器由于缺乏识别而不会触发。 - 按位置定位不受影响。 - 定位在设备类型（桌面、移动）上显示不受影响。 ## 调整表单的显示选项（时间、频率、设备显示等）

### 时间安排

在 **显示** 菜单的 **时间** 部分中，您可以选择注册表单何时显示在您的网站上。默认情况下，您的表单将设置为显示****立即****，这意味着当有人访问您网站上的页面时，它将立即显示。您还可以选择显示表单：

- ****基于规则****
  根据以下 1 个或多个规则触发您的注册表单显示：

  - ****当访问者退出页面时****
    当站点访问者即将离开页面时触发要显示的表单。该表单通常称为“退出意图表单”，当有人将鼠标悬停在桌面上的视口上方、悬停在页面的两侧或在移动设备上快速向上滚动时，就会出现该表单。 - ****延迟一段时间后****
    延迟一定时间后触发表单显示。您可以输入表单加载之前某人必须在页面上停留的秒数。一般来说，访问者在每个页面上停留的时间通常不会超过几秒钟。如果您的消息至关重要，请立即或 1 或 2 秒后显示该表单。 - ****访问者滚动一定数量后****
    当访问者滚动到页面上的某个点后触发表单显示； 0% 是网页的顶部，而 100% 是底部。 - ****访问者看到一定数量的页面后****
    当访问者在您的网站上看到一定数量的页面后触发显示表单。例如，如果您输入 3 个页面，则当访问者查看您网站上的 3 个唯一页面（例如 3 个不同的产品页面）时，将显示该表单。 ![输入了 3 页的表单编辑器中显示的基于规则菜单中的“经过一定数量的页面”选项。](https://klaviyo.zendesk.com/hc/article_attachments/28716331236891)

    显示注册表单**访问者看到一定数量的页面**后将保留每个浏览器会话的计数。如果有人在您的网站上查看了 2 个唯一页面，关闭您的网站，然后在新窗口中再次打开您的网站，则其页面计数将从 1 重新开始。同样，如果访问者两次查看相同的产品页面，则将计为已查看的 1 个唯一页面。唯一页面由 URL 确定，并且在计数中忽略查询参数和片段。时间延迟选项下方将出现一个开关，允许您**仅在满足所有选定规则时才显示**。如果您选择多个延迟，则必须满足所有延迟才能显示表格。例如，如果您选择退出意图并将表单设置为在某人滚动页面中途后显示，则访问者需要完成这两个操作（向下滚动页面一半，然后显示退出意图）才能显示表单。 ![在表单编辑器的“目标和行为”选项卡的“计时”部分中选择“基于规则”选项。](https://klaviyo.zendesk.com/hc/article_attachments/28716331233051)
- ****仅在自定义触发器上****
  根据任何条件触发表单显示，例如单击按钮或在您自己的代码中。有关更多详细信息，请参阅[如何在单击按钮时触发注册表单显示](https://klaviyo.zendesk.com/hc/en-us/articles/4418052317339)。这些设置可用于弹出、浮出和整页表单；嵌入的表单总是在页面加载时立即出现。在 **Timing** 下方，Shopify 用户将看到一个启用潜在客户捕获的选项。有关更多信息，请参阅我们的关于[使用 Shop 设置潜在客户捕获]的指南(https://klaviyo.zendesk.com/hc/en-us/articles/17292871409947)。 ### 频率

在“显示”菜单的“频率”部分中，您可以确定注册表单对每个站点访问者显示的频率。您可以编辑弹出窗口、浮出窗口或整页表单的显示频率。嵌入表单将始终显示，因为它们是您网站页面的一部分。 ![表单编辑器的“显示”菜单中的“频率”部分显示设置为 5 天后再次显示的表单。](https://klaviyo.zendesk.com/hc/article_attachments/28716331247131)

- ****访客关闭此表单后，在**** *****\_\_ 天后再次显示******
  使用此设置可以确定关闭表单的访问者应该看到该表单的频率。 - 将此选项设置为 **0 天** 以在每次访问时显示表单。 - 选择较长的时间范围（例如 5 天）以限制表单出现得太频繁。 - ****如果提交表单或单击 URL 按钮，则不再显示****
  使用此设置确定访问者在完成表单后是否会再次看到该表单。 - 如果您希望表单在有人填写后不再出现，请选中该框。 - 如果您希望同一访问者有机会多次填写表单，请不要选中此选项。这些设置依赖于 Klaviyo 的 cookie，因此如果访问者清除其 cookie 或使用隐身浏览器，该表单可能会在下次访问您的网站时重新出现。 ### 设备

在 **显示** 菜单的 **设备** 部分中，您可以选择是否希望向在桌面设备、移动设备或两者上浏览的访问者显示注册表单。对于包含点击文本按钮（其**操作**设置为**通过短信订阅**的按钮）的注册表单，**设备**设置将被禁用，因为它们将自动仅显示在移动设备上。 ![表单编辑器中“显示”菜单的“设备”部分显示设置为在桌面和移动设备上显示的表单。](https://klaviyo.zendesk.com/hc/article_attachments/28716331249947)

- ****桌面和移动****
  设置为在两种设备上显示的注册表单都会向所有购物者显示，无论他们使用什么设备进行浏览。 - ****仅限桌面****
  设置为在桌面上显示的注册表单不会向移动设备上的购物者显示。设置为在台式机上显示的表单也将在平板电脑上显示。 - ****仅限移动设备****
  设置为在移动设备上显示的注册表单不会向桌面设备上的购物者显示。 您还可以为注册表单中的每个块和字段选择可见性设置（例如，将图像块设置为仅在桌面设备上可见，但在移动设备上显示时不可见）。详细了解[注册表单中的动态块](https://klaviyo.zendesk.com/hc/en-us/articles/11286232753051)。 #### 单击外部表单关闭

弹出窗口、弹出窗口和全页注册表单都会在右上角自动添加一个关闭图标（X 按钮）。观众必须单击 X 按钮才能关闭注册表单；但是，如果您使用弹出表单类型，您还可以选择允许查看者通过单击表单外部的区域来关闭表单。 ![弹出表单的“显示”部分中的“单击外部表单以关闭”选项显示桌面和移动设备均已选中。](https://klaviyo.zendesk.com/hc/article_attachments/28716331267995)

- ****在桌面上****
  选中此选项可允许桌面上的查看者除了 X 按钮之外还可以通过单击表单外部的区域来关闭表单。 - ****在移动设备上****
  选中此选项可允许移动设备上的查看者除了 X 按钮之外，还可以通过单击表单外部的区域来关闭注册表单。如果两个选项都被选中，用户可以在表单外部单击以在两台设备上关闭它。嵌入式表单无法关闭，浮出式表单和整页表单只能通过单击关闭按钮或填写表单来关闭。 ## 调整表单的定位设置（按访问者、URL、UTM、购物车内容等）

在表单编辑器的 **定位和行为** 部分中，切换到 ****定位**** 菜单。从这里，您可以进一步定位您的注册表单，根据浏览器在 Klaviyo 中的个人资料数据为他们提供个性化体验。您可以从多个定位选项（即按访问者、按 URL、按 UTM 或按位置定位）中进行选择，以仅向某些人显示。 ![表单编辑器中“目标和行为”选项卡中的“目标”菜单，您可以在其中编辑表单的目标方式。](https://klaviyo.zendesk.com/hc/article_attachments/28716331251739)

### 按访问者定位

在 **定位** 菜单的 **访问者** 部分，您可以选择仅向符合特定条件的访问者显示您的注册表单。请注意，只有满足所有条件（包括您选择的**设备**和**计时**设置）时，才会向访问者显示表单。访问者定位依赖于 Klaviyo 的 cookie，最近清除了 cookie、正在使用新设备或使用隐身浏览器访问您的网站的访问者将被视为新的匿名访问者。 ![“定位”菜单的“访客”部分，下拉菜单打开，显示按访客条件定位的所有选项。](https://klaviyo.zendesk.com/hc/article_attachments/28716331255579)

- ****不向现有的 Klaviyo 个人资料显示****
  该表格只会向 Klaviyo 不认识的访客显示。 - ****向所有访客展示****
  该表格将向所有网站访问者显示。 - ****显示到任何现有的个人资料****
  该表格将向您的 Klaviyo 帐户中现有个人资料的任何人显示（这意味着拥有有效个人资料的任何人都有资格查看该表格，无论他们是否选择加入）。 - ****仅向电子邮件订阅者显示****
  该表单将向尚未注册 SMS 营销的电子邮件订阅者显示。 - ****仅向短信订阅者显示****
  该表单将向尚未注册电子邮件营销的短信订阅者显示。 - ****显示列表或片段中的特定配置文件****
  - ****包括这些列表和片段****
    该表单将向属于您选择的任何列表或细分的 cookie 访问者显示。 - ****排除这些列表和段****
    该表格只会向不知道是您选择的任何列表或细分的成员的访问者显示，包括匿名访问者和被 cookie 记录但不知道是任何选定组的成员的访问者。每当有人加入分段或列表或从分段或列表中删除时，这些更改都会自动反映在注册表单的定位中。请参阅我们关于[了解分段如何更新](https://help.klaviyo.com/hc/en-us/articles/115005233488) 的文章，了解更多信息。 ### 通过 URL 定位

在 **Targeting** 菜单的 **URL's** 部分中，您可以配置表单显示和不显示的 URL。 ![“定位”菜单中的 URL 部分，其中两个选项均已选中“仅在某些 URL 上显示”和“不在某些 URL 上显示”。](https://klaviyo.zendesk.com/hc/article_attachments/28716354283291)

- ****仅在某些 URL 上显示****
  选中此选项可选择显示注册表单的特定 URL。 - ****不要在某些网址上显示****
  选中此选项可选择应隐藏注册表单的 URL。虽然 Klaviyo 支持单页应用程序 (SPA) 中注册表单的 URL 定位，但请注意，SPA 目前不支持 **不要在某些 URL 上显示** 选项。您可以为每个设置在**包含或****完全匹配**之间切换。 - ****含有****
  此选项包括带有您输入的部分值的任何 URL。例如，如果您输入“包含 www.klaviyo.com/”，则这将包括 www.klaviyo.com/blog、www.klaviyo.com/features 等。 - ****完全匹配****
  此选项意味着您可以定位 1 个特定 URL。例如，“https://help.klaviyo.com/The-Signup-Form-Editor”将仅包含该确切 URL，而不会包含“https://help.klaviyo.com/The-Template-Editor”。如果您选择 **完全匹配**，请务必在 URL 开头包含正确的协议（例如，http:// 或 https://）。星号 (\*) 可以用作 URL 中的通配符。例如，如果您希望注册表单显示在“help.klaviyo.com/The-Signup-Form-Builder”和“help.klaviyo.com/The-Template-Builder”上，请将表单设置为显示在包含“help.klaviyo.com/The-\*-Builder”的 URL 上。 ### 通过 UTM 参数定位

在 **定位** 菜单的 **UTM 参数** 部分中，您可以根据添加到 URL 的 UTM 值来定位客户（例如，仅向从 Facebook 访问您网站的购物者显示注册表单）。 UTM 参数可以帮助您向目标受众提供原始广告中的独特优惠或承诺内容。 ![“目标”菜单的 UTM 参数部分，您可以在其中将 UTM 参数和值添加到目标。](https://klaviyo.zendesk.com/hc/article_attachments/28716354281371)

选择 **UTM 参数** 选项，然后在相应的文本框中输入 **值**。请记住，URL 中的空格无效，因此您需要在 **Value** 字段中必要时使用下划线。您可以通过单击****添加参数****来添加多个参数。 Klaviyo 使用 AND 逻辑来定位您添加的每个 UTM 参数（不是 OR 逻辑）。例如，如果您添加 **Source** 和 **Medium** 参数，则只有从同时包含 UTM\_source 和 UTM\_medium 的 URL 访问您网站的购物者才会看到注册表单。该表单不会向来自仅包含其中之一的 URL 的购物者显示。 Klaviyo 支持以下 UTM 参数，并且能够添加多个：

- 来源
- 中号
- 活动
- 期限
- 身份证号码

或者，您可以使用基于 UTM 参数的 URL 定位。要进行此设置，请选择****仅在某些 URL 上显示****选项并输入包含 UTM 参数的 URL。例如，如果您想基于 utm\_content 参数进行定位，请选择****仅在某些 URL 上显示 > 包含****，然后输入您的参数（例如“utm\_content=example”）。 ![表单编辑器中“目标”菜单的 URL 部分，显示示例表单的目标设置，设置为“不在包含示例内容 UTM 参数的特定 URL 上显示”。](https://klaviyo.zendesk.com/hc/article_attachments/28716354292507)

您还可以选择**在同意的情况下将 UTM 参数存储在购物者的个人资料中**。通过启用此功能，Klaviyo 会将购物者来源的 UTM 参数存储为其 Klaviyo 个人资料中的自定义属性。这使您可以查看订阅者的来源，以便您可以使用此信息[在未来的活动和流程中进行细分](https://help.klaviyo.com/hc/en-us/articles/115000250912#h_01H9NJJNC9PEM4Y5T449BP383Y)。如果您有一个基于 UTM 参数定位的注册表单，并且将第二个表单设置为始终立即向访问者显示，则[冲突预防设置](https://klaviyo.zendesk.com/hc/en-us/articles/19788320859419) 可能会阻止预期的 UTM 触发的注册表单出现。为了确保基于 UTM 参数的表单按预期触发，请在第二个表单上添加定位限制，以便它不会显示在带有 UTM 参数的 URL 上。 通过选择 ****不要在某些 URL 上显示********> 完全匹配**** 将其添加到 URL 部分，然后粘贴带有 UTM 参数的 URL。 ### 按位置定位

在 **定位** 菜单的 **位置** 部分中，您可以根据访问者的位置选择是否向他们显示注册表单。 ![“定位”菜单中的“按位置定位”部分显示了“向某些位置的访问者显示”和“不向某些位置的访问者显示”选项，这两个选项都已选中。](https://klaviyo.zendesk.com/hc/article_attachments/28716331265819)

- ****在某些地点向访客展示****
  注册表单将向网站访问者显示其位置在指定位置被识别。 - ****不在某些地点向访客展示****
  注册表单不会向其位置在指定位置被识别的访问者显示。 Klaviyo 使用每个站点访问者的 IP 地址来确定他们是否符合标准。如果您在某些国家/地区进行销售并希望根据客户所在位置向客户显示特定于语言的表单，这会很有帮助。例如，如果您想要为欧盟用户添加特定的数据保护语言，但不希望其他地区的浏览器看到相同的信息，这可能会很有用。 ### 按购物车内容定位

在 **定位** 菜单的 **购物车内容** 部分，您可以选择根据购物者的购物车属性（例如，购物车总价值、购物车中的商品总数或特定产品标准）触发注册表单。有关更具体的说明，请参阅我们的指南[根据购物车内容触发注册表单](https://help.klaviyo.com/hc/en-us/articles/22173812171291)。按购物车内容定位目前仅适用于 Shopify 用户。 。 ![定位菜单中的购物车内容部分，您可以在其中选择根据某些购物车属性触发表单的显示。](https://klaviyo.zendesk.com/hc/article_attachments/28716354290715)

## 示例行为和定位设置

### 欢迎报名表

要为还不是订阅者的网站访问者创建注册表单，请从****定位和行为****部分中的以下设置开始：

- 在**显示：**下
  - **时间**：****立即****
  - **频率**：
    - ****关闭后 90 天再次显示****
    - ****如果提交了表单或单击了“转到 URL”按钮，则不再显示****
  - **设备**：****台式机和移动设备****
- 在**定位**下：
