## 你将会学到

了解如何创建和自定义订阅页面，以便您的客户可以轻松注册以了解您品牌的更多信息。本指南将介绍如何查找和自定义您的订阅页面，例如通过问题来衡量个人偏好，以及如何使用订阅页面来扩大您的列表，例如通过在社交媒体上分享唯一的 URL 或将其嵌入您的网站。 ![解释如何将问题添加到表单中并将其与个人资料属性相关联，以便从新订阅者那里了解和捕获信息。](https://fast.wistia.com/embed/medias/pfkr3txgaf/swatch)



## 找到您的订阅页面

默认情况下，每当您创建新列表时，它都会自动使用您帐户的默认同意页面（管理首选项页面、订阅页面和取消订阅页面）。帐户的默认同意页面标准化了订阅者的一致体验；但是，您也可以选择专门为 1 个列表创建一组新的同意页面。要查找您的默认订阅页面：

1. 单击主菜单左下角的组织名称。 2. 单击****设置。****
3. 从顶部选择****其他****。 4. 在**订阅页面**下，点击****编辑页面****进入编辑器。 ![帐户默认同意页面，位于帐户设置中的其他选项卡下。](https://klaviyo.zendesk.com/hc/article_attachments/28717991640987)

如果您为特定列表自定义了一组同意页面，或者您愿意，导航到该列表的唯一订阅页面：

1. 选择****受众 >**** ****列表和细分****。 2. 选择您的列表。 3. 从顶部选择****订阅和首选项页面****。 ![从菜单栏中选择订阅和首选项页面选项卡的特定列表页面。](https://klaviyo.zendesk.com/hc/article_attachments/28717985755291)
4. 单击****为此列表自定义****（如果您尚未自定义此列表的任何同意页面）。 5. 在订阅页面下方，点击****编辑页面****进入编辑器。 ## 设置订阅页面的样式并添加字段

在编辑器中，您可以使用各种选项来自定义订阅页面的样式和内容。您可以编辑页面的样式设置，更改任何默认文本以匹配您的语气或首选语言，还可以添加块或输入字段以从客户那里收集更多信息。如果您的列表设置为双重选择加入，那么您还可以自定义电子邮件确认页面。有关编辑器的更多详细信息，请参阅我们的[如何编辑同意页面指南](https://help.klaviyo.com/hc/en-us/articles/115005251848#edit-the-design-of-your-consent-pages4)。请注意，Klaviyo 的最佳做法是在订阅页面上仅收集两项同意中的一项：电子邮件或短信同意。本指南将介绍收集电子邮件，但如果您想通过订阅页面增加短信受众，请前往[如何创建短信订阅链接](https://help.klaviyo.com/hc/en-us/articles/14104388043931)。如果您向订阅页面添加输入字段（例如日期字段），您还可以从下拉菜单中添加[个人资料属性](https://help.klaviyo.com/hc/en-us/articles/115005074627-Guide-to-Properties)，该属性会将个人信息添加到某人的 Klaviyo 个人资料中。从下拉菜单中选择一个属性。 ![添加到表单的日期字段中的配置文件属性下拉菜单选项](https://klaviyo.zendesk.com/hc/article_attachments/28717985752987)

如果您没有看到要使用的属性，请在**筛选器**框中输入您自己的[自定义属性](https://help.klaviyo.com/hc/en-us/articles/115005074627-Guide-to-Properties#custom-vs--klaviyo-properties2)，然后单击****创建属性。****

## 分享您的订阅页面 URL

对设计感到满意后，您可以复制列表订阅页面的 URL 以在各种营销活动中共享。查找订阅页面 URL：

1. 导航至****列表和段。****
2. 选择您的列表。 3. 从顶部菜单栏中，选择****注册表单。****
4. 向下滚动到页面底部。 - 如果您为此列表自定义了新的同意页面，您将在页面底部找到**订阅页面**卡。单击三点菜单，然后选择****复制 URL****。 ![特定列表的订阅页面的订阅页面图块，带有用于复制所选 URL 的下拉选项。](https://klaviyo.zendesk.com/hc/article_attachments/28717991638683)
   - 如果您的列表使用默认同意页面，您会看到一个菜单提醒，提示您可以为此特定列表自定义同意页面。在此提醒下方，单击****复制订阅页面 URL****。 ****！[在列表页面的注册表单选项卡中找到复制订阅页面 URL 链接。](https://klaviyo.zendesk.com/hc/article_attachments/28717991645211)****

您可以在社交渠道中分享此链接，例如在 [Instagram 故事](https://help.klaviyo.com/hc/en-us/articles/360059544911#add-your-link-to-an-instagram-story4) 中。单击此链接的收件人将被带到作为登陆页面的订阅页面，他们可以在其中注册以了解您品牌的更多信息。 ## 嵌入订阅页面

使用订阅页面 URL，您还可以嵌入表单以显示为网站一部分的登录页面。嵌入式表单对于出于订阅目的来到您的网站的客户很有帮助。要将此页面嵌入您的网站：

1. 复制下面的代码片段。 2. 将 ****SUBSCRIBE\_URL**** 替换为您要嵌入的页面的 URL。 3. 在后台打开您的网站。 4. 在您​​希望显示订阅页面的页面上粘贴代码。 ````
<iframe id =“klaviyo_subscribe_page”src =“SUBSCRIBE_URL＆embed = 1”无缝=“无缝”宽度=“100％”滚动=“否”> </ iframe>
<script type="text/javascript" src="//a.klaviyo.com/media/js/lib/iframeresizer.js"></script>
<script type="text/javascript">iFrameResize({}, '#klaviyo_subscribe_page');</script>
````

由于粘贴代码需要访问您网站的 HTML 和平台，因此我们的支持团队无法提供实际帮助。如果您对代码不满意或者您的团队中没有开发人员，请考虑联系 [Klaviyo 合作伙伴](https://klaviyo.partnerpage.io/)。 ## 其他资源
