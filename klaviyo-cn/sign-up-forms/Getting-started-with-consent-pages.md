## 你将会学到

了解与 Klaviyo 列表相关的不同同意页面，包括首选项、订阅和取消订阅页面，以及如何自定义它们。在您的 Klaviyo 帐户中，有 1 组所有列表默认使用的帐户同意页面。这些帐户级同意页面包括您的默认首选项页面、订阅页面、电子邮件确认页面和电子邮件取消订阅页面。您可以编辑样式和设计，以标准化帐户默认同意页面的外观，以获得一致的体验。但是，如果您希望某个特定列表拥有自己的同意页面（即为您的 VIP 列表提供自己的订阅页面），您可以断开列表与默认页面的连接，并为特定列表自定义一组唯一的同意页面。本文将介绍如何在 Klaviyo 中使用和管理同意页面；但是，如果您希望设计自己的自定义编码同意页面，则可以探索 [Klaviyo 的托管页面功能](https://help.klaviyo.com/hc/en-us/articles/115005077067-How-to-custom-code-an-unsubscribe-or-manage-preferences-page)。导航至****设置 > 其他 > 托管页面**** 以启用此功能。只有通过[帐户验证](https://help.klaviyo.com/hc/en-us/articles/115000628331-About-Account-Verification)的付费计划帐户才能访问此设置。 ## 关于电子邮件中的同意页面

您帐户的默认同意页面默认用于：

- 发送至分段的电子邮件
- 电子邮件发送到多个列表和/或分段
- 分段触发流
- 由事件触发的流程
- 日期触发的流量
- 价格下降流

这意味着，当您将取消订阅标签 {% unsubscribe %} 或管理首选项标签 {% manage\_preferences %} 插入发送到细分的广告活动时，将使用帐户默认同意页面。当您将这些标签插入由事件触发流的流电子邮件时，情况也是如此。如果您要将管理首选项标记添加为消息中的链接文本，请使用 {% manage\_preferences %}。但是，如果您要将管理首选项标记添加到消息中的按钮或图像块，则必须使用 {% manage\_preferences\_link %}。当您向使用一组自定义同意页面的列表发送电子邮件时，不会使用默认的同意页面。相反，将使用您为该特定列表创建的自定义同意页面。要进一步编辑这些页面，请导航到要编辑页面的列表，然后选择****订阅和首选项页面****。虽然您帐户的默认同意页面有助于为订阅者集中一致的体验，但选择为列表自定义一组独特的同意页面通常也很有帮助。例如，如果特定列表用于[特殊竞赛或订阅者优惠](https://help.klaviyo.com/hc/en-us/articles/115000798472)，您可能希望此列表的同意页面以某种方式显示并显示一组独特的订阅者首选项。 ## 找到您帐户的默认同意页面

要导航到您的默认同意页面：

1. 在 Klaviyo 中，导航至****受众 > 增长工具****。 2. 选择****自定义订阅和首选项页面。****
3. 选择****帐户默认页面****。可编辑的页面包括：

![所有可编辑的同意页面，包括首选项页面、订阅页面、电子邮件确认页面和电子邮件取消订阅页面。](https://klaviyo.zendesk.com/hc/article_attachments/28705636071835)

****首选项页面****

- ****首选项页面****
  现有订阅者可以更新其偏好的页面。在这里，您可以为订阅者提供分享更多有关他们自己的信息（例如年龄、性别或生日）的机会，还可以分享更详细的信息（例如他们的首选电子邮件频率或产品兴趣）。 - 在偏好页面上收集的信息将显示在网站访问者的个人资料中。 [详细了解如何查看表单回复以及根据此信息创建细分](https://help.klaviyo.com/hc/en-us/articles/360040841811#h_01HSXZRBZ32393XVEDZJFWEVRZ)。 - ****首选项成功页面****
  页面订阅者在更新其偏好后将看到。 ****订阅页面****

- ****订阅页面****
  感兴趣的购物者可以在该页面注册以了解您品牌的更多信息。如果您的列表使用单一选择加入，则订阅者在提交表单后将直接进入订阅成功页面。 对于双重选择加入列表，订阅者将首先看到确认页面，然后需要在确认电子邮件中确认其订阅，最后，他们将被引导至订阅成功页面。 - ****确认页****
  如果您的列表是双重选择加入的，则这是新订阅者在提交订阅页面后将看到的页面，指示他们检查电子邮件以确认订阅。请注意，只有付费帐户才能在此页面上添加和编辑链接和源代码。 ****电子邮件确认页面****

- ****确认电子邮件****
  对于双重选择加入列表，这是订阅者通过订阅页面或注册表单订阅后发送给他们的电子邮件。它包括一个按钮，单击该按钮会将他们带到订阅成功页面。请注意，只有付费帐户才能在此页面上添加和编辑链接和源代码。 - ****订阅成功页面****
  订阅者通过订阅页面注册后将看到的页面。默认情况下，此页面包含一个链接到首选项页面的按钮，允许新订阅者管理他们的首选项。请注意，如果有人再次填写订阅页面，则不会显示管理首选项页面的按钮，因为不会创建新的个人资料。 ****电子邮件取消订阅页面****

- ****电子邮件取消订阅页面****
  当某人点击电子邮件中的取消订阅链接时将看到的页面。默认电子邮件取消订阅页面底部包含指向您的首选项页面的链接。同时使用取消订阅和管理首选项页面可以鼓励收件人更改他们的电子邮件首选项，而不是完全取消订阅。 - ****电子邮件取消订阅成功页面****
  用户取消订阅电子邮件后将看到的页面。在您的帐户取消订阅成功页面上，按钮设置将显示**主要操作**和**次要操作**。当列表使用此页面时，**辅助操作**就会发挥作用。例如，如果列表使用默认同意页面而不是自定义页面，则该列表的订阅者在单击按钮时将看到辅助操作（即重新订阅）。 ![在预览中选择的按钮和左侧显示的按钮菜单，主要操作设置为“转到 URL”，辅助操作设置为“重新订阅”。 ](https://klaviyo.zendesk.com/hc/article_attachments/28705662808603)

当您构建将新订阅者添加到列表中的注册表单时，上面列出的这些同意页面就会发挥作用。通过查看和更新​​这些页面，您可以控制订阅者在首次选择加入、更新首选项以及取消订阅时看到的体验和消息。当您选择创建新列表时，每个列表将默认使用您帐户的默认同意页面。 ## 自定义特定列表的同意页面

您可以选择断开列表与默认同意页面的连接，而是为特定列表自定义一组唯一的同意页面。仅当电子邮件仅针对一个列表（单个静态列表）时，才会使用特定于列表的同意页面。这包括：

- 营销活动发送到一个列表
- 由列表触发的流（例如，“添加到列表”流）

如果列表没有自己的自定义页面，Klaviyo 会退回到帐户默认同意页面。要自定义列表的同意页面，请按照以下步骤操作：

1. 导航****受众 > 增长工具****。 2. 选择****自定义订阅和首选项页面****。 3. 选择****对于特定列表****。 4. 选择****取消链接并自定义****以覆盖默认页面****.****
5. 在这里您将看到一组新的同意页面可供编辑。找到您要编辑的同意页面（例如首选项页面），单击****编辑页面。****
6. 在编辑器中完成页面自定义后，单击****发布。****

请注意，如果您不再希望列表使用这些自定义页面，则可以恢复到帐户的默认同意页面。但是，如果重置回默认值，之前的所有自定义设置都将丢失且无法恢复。单击页面底部的****将所有页面重置为默认****，将您的列表重新链接到默认同意页面。 ## 编辑同意页面的设计

无论是默认同意页面还是特定列表的独特同意页面集，您都可以自定义每个页面的样式和设计，为网站访问者提供一致的品牌体验。 如果您希望根据自己的偏好自定义代码、订阅或取消订阅页面，请单击下拉箭头并选择****使用托管页面****。请参阅我们的[使用托管同意页面指南](https://help.klaviyo.com/hc/en-us/articles/115005077067-How-to-custom-code-an-unsubscribe-or-manage-preferences-page)了解更多详细信息。 1. 找到您要编辑的同意页面（例如首选项页面），单击****编辑页面****
2. 选择同意页面将带您进入其各自的编辑器，您可以在其中自定义样式和设计以适合您的品牌。选择您要编辑的内容，其中包括：
   - ****风格****
     使用此部分编辑设计设置，例如 **表单背景**、**页面背景**、**表单样式** 等 - ****添加块****
     使用此部分将元素添加到您的同意页面，例如文本或图像块。您还可以通过单击预览中的任何文本并将默认文本替换为您自己的文本来编辑预览中的任何文本。 ![示例首选项页面的编辑器，显示添加块或编辑样式的选项。](https://klaviyo.zendesk.com/hc/article_attachments/28705662819611)

     在向首选项页面和订阅页面添加块时，您还可以选择[添加输入字段](https://help.klaviyo.com/hc/en-us/articles/4413550187035-Understanding-form-blocks-and-fields#input-fields6)，例如日期字段或复选框。 - ****按钮****
     单击预览中的按钮（例如**取消订阅**按钮或**更新您的首选项**按钮）以获取编辑**按钮文本**、**按钮样式**和**块样式的选项。**
     **！[当您在预览表单中选择按钮时，左侧出现的按钮菜单，您可以在其中编辑各种按钮功能和样式设置。](https://klaviyo.zendesk.com/hc/article_attachments/28705662821787)**
3. 当您准备好共享您的同意页面时，单击****发布****。请务必编辑您想要自定义的同意页面的每个步骤。您还可以单击编辑器顶部菜单栏中的****成功页面****来调整收件人填写表单时显示的成功消息的设计。 ### 添加配置文件属性

如果您将输入字段（例如日期字段）添加到同意页面，请使用****个人资料属性****下拉列表选择相应的属性（例如生日）。这使得 Klaviyo 能够在访问者提交表单时跟踪其专用个人资料上的信息。 Klaviyo 支持许多个人资料属性，您可以选择将个人信息添加到某人的个人资料中。请注意，您不能在表单上的多个输入字段中使用相同的配置文件属性，因为这可能会导致跟踪问题。例如，如果表单中有两个文本输入字段来收集名字和姓氏，则每个字段都必须有自己专用的配置文件属性，例如名字和姓氏。 ![添加到同意页面的任何输入字段附带的配置文件属性下拉列表，显示选择或创建新属性的选项。](https://klaviyo.zendesk.com/hc/article_attachments/28705662823579)

如果您在列表中没有看到要使用的属性，您还可以通过在 **筛选器** 框中键入要使用的属性，然后单击 **创建属性****来[收集自定义属性](https://help.klaviyo.com/hc/en-us/articles/115005074627-Guide-to-Properties#custom-vs--klaviyo-properties2)。 ### 将同意页面翻译成不同的语言

如果您的客户群由不同的母语人士组成，那么您创建他们能够理解的内容就很重要。同意页面上的语言默认为美式英语。但是，要编辑语言，请按照以下步骤操作。 1. 导航至您想要翻译的任何同意页面的构建器。 2. 单击预览中的任意文本进行编辑。 3. 在左侧显示的菜单中，删除默认文本，然后键入您希望以所选语言显示的文本。请注意，您可以单击预览表单中的任何文本，将其自定义为不同的语言，包括错误消息和输入字段所需的文本警报。 ![在首选项页面预览中选择默认文本，然后在出现的文本菜单中将其删除并输入新文本。](https://fast.wistia.com/embed/medias/ne451y53to/swatch)

   请务必按照此流程执行您想要翻译的每个步骤和每个同意页面（例如，首选项页面、订阅页面、电子邮件确认页面和电子邮件取消订阅页面）。 4. 当您准备好共享您的同意页面时，单击****发布****。绿点表示页面处于活动状态，而绿色圆圈表示页面处于活动状态，但有未发布的编辑。 ## 找到您的订阅页面 URL

Klaviyo 会自动为您帐户中的每个列表创建一个订阅页面，您可以使用该页面让潜在订阅者注册您的电子邮件或短信营销。完成设计编辑后，您可以复制订阅页面 URL 以在电子邮件或其他地方共享，以扩大受众群体。要查找列表的订阅页面 URL：

1. 导航至****列表和段。****
2. 选择您的列表。 3. 从菜单栏中选择****注册表单。****
   ![注册表单选项卡带有下划线，并从特定列表页面的菜单栏中选择。](https://klaviyo.zendesk.com/hc/article_attachments/28705636091035)
4. 在这里您将看到与此列表相关的所有注册表单。滚动浏览这些内容即可找到列表的订阅页面。 ****！[复制从特定列表页面内的注册表单选项卡底部选择的订阅页面 URL。](https://klaviyo.zendesk.com/hc/article_attachments/28705662825115)****

您还可以通过单击“****编辑页面****”并从概述菜单中复制订阅页面 URL 来检索 URL。您的订阅页面 URL 现在已复制到剪贴板，可以在营销活动或社交渠道中使用。请在您的网站上查看[有关使用订阅页面作为登陆页面的指南](https://help.klaviyo.com/hc/en-us/articles/115005251988-How-to-embed-a-full-subscribe-page-on-your-website)以了解更多信息。 ## 将选择加入的收件人重定向到不同的网站页面

当您网站上的访问者通过双重选择确认其订阅并登陆确认页面时，您可以选择将他们重定向到不同的 URL，例如您网站上的特定页面。这是最大化感兴趣的订户的网站流量的好方法。要在确认页面中使用重定向 URL：

1. 导航至您的同意页面（这可以是您帐户的同意页面或特定列表的同意页面）。要访问默认同意页面，请导航至****设置>其他****。要导航到特定列表的同意页面，请导航到****受众 > 列表和细分****，选择一个列表，然后单击****订阅和首选项页面。****
2. 在**订阅页面**下，单击****编辑页面。****
   ****！[在帐户默认订阅页面上选择“编辑”页面。](https://klaviyo.zendesk.com/hc/article_attachments/28705636086427)****
3. 在顶部菜单栏中，选择****成功页面。****
4. 单击****自定义重定向。****
   ****！[编辑器中订阅页面成功步骤中选择的自定义重定向选项。](https://klaviyo.zendesk.com/hc/article_attachments/28705636088347)****
5. 选中**跳过页面并重定向复选框。**
6. 粘贴您希望订阅者重定向到的 URL。 ![自定义重定向菜单，选中复选框以跳过页面并重定向，并在重定向 URL 框中粘贴示例 URL。](https://klaviyo.zendesk.com/hc/article_attachments/28705636097563)
7. 完成所有其他设计编辑后，单击****发布。****
