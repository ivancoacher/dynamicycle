## 你将会学到

了解如何向流程添加列表更新操作，以便在配置文件到达流程的特定部分后从列表中添加或删除配置文件。

通过此流程操作，您可以：

- 添加到列表
- 从列表中删除
- 创建列表

  通过使用列表更新操作，您可以更改某人所在的目标列表，而无需手动更新或创建细分。这允许个人资料在完成当前旅程后开始新的旅程，并且可以减少您帐户中使用的列表和细分的数量。

  您可以在各种情况下使用此操作，例如：
- 在赢回流程中打开电子邮件后，将客户添加到重新参与列表中。
- 在购买后流程中打开电子邮件后，将客户添加到 VIP 列表。
- 在订阅者与请求内容偏好的电子邮件交互后将其添加到不同的列表。

## 开始之前

确保您了解列表更新操作的以下影响：

- 通过列表更新操作将配置文件添加到列表将触发与该列表相关的任何流程，例如欢迎系列。与所有列表触发的流一样，配置文件仅在以前从未进入过流时才会进入该流。
- 列表更新操作不会影响同意状态。
- 列表更新操作会将某人添加到列表中，无论列表的选择加入设置如何，即，即使列表设置为双重选择加入，列表更新操作仍会将个人资料添加到列表中。

## 添加列表更新动作

- 您帐户中要添加或删除配置文件的现有列表。
- 创建一个新列表。为列表选择名称和标签。创建新列表后，它将在侧栏中被选中。

![](https://klaviyo.zendesk.com/hc/article_attachments/30165367183515)

1. 导航至特定流程。
2. 从**操作**侧栏中，将****列表更新****操作拖放到流程中。
   ![](https://klaviyo.zendesk.com/hc/article_attachments/30165367179163)
3. 在侧面板中，为更新操作命名并选择 ****添加到列表**** 或 ****从列表中删除****。
   ![](https://klaviyo.zendesk.com/hc/article_attachments/30165355171867)
4. 从下拉列表中选择：
5. 将状态从****草稿****更改为****实时****，或者如果您想在更改列表成员资格之前查看个人资料，请选择****手动****。您可以稍后更改状态，但如果配置文件保留为草稿状态，则会跳过此步骤。
6. 单击****保存**** 完成操作。

如果您在选择某个列表进行列表更新操作后将其删除，则该操作将变为未配置状态，并且需要您重新进行设置。否则，配置文件将跳过未配置的操作。

## 查看活动

单击该操作后，您可以在详细信息侧栏中查看谁正在等待以及谁已完成此步骤的摘要。

在侧边栏的 **性能** 部分中，您可以看到以下内容：

- 有多少个配置文件已安排或处于**等待**状态
- **审查**中有多少个配置文件（如果流程组件处于/曾经处于手动模式）
- 有多少个人资料已成功完成该操作，并更新了他们的个人资料

单击****查看详细信息**** 查看活动页面，了解有关将要或已经执行此操作的配置文件的更多信息。
