了解降价流程如何运作以及如何在 Klaviyo 中进行设置。降价流程适用于电子商务集成中的目录或自定义目录。降价流程不会发送给已经购买该商品的任何人，无论他们是以全价购买还是以折扣价购买。此外，如果库存为 0 或负数或者未发布变体，则不会发送降价流程。降价流程让客户知道他们所关注的产品何时降价。这对您来说意味着轻松销售，因为客户喜欢优惠，尤其是他们真正想要的商品。这些流对于营销人员来说也是一个有价值的工具，因为这些消息通常会获得很高的参与度和转化率。 ## 开始之前

- 降价流程适用于使用 Shopify、BigCommerce、WooCommerce、Magento 2、PrestaShop、Salesforce Commerce Cloud 或通过自定义目录源或 API 同步的目录的商店。 - 降价流程只会针对列为库存的商品触发。 ## 通过自定义目录源或 API 同步目录的要求

如果您还没有这样做，请查阅我们的开发人员资源：

- [如何将自定义目录源同步到 Klaviyo](https://developers.klaviyo.com/en/docs/guide_to_syncing_a_custom_catalog_feed_to_klaviyo)
- [目录 API 概述](https://developers.klaviyo.com/en/reference/catalogs_api_overview)

  为了创建降价流程，请确保您的目录满足以下要求：
- 产品或变体必须具有与可用数据映射的**价格**和**库存**字段。 - **订购的产品**和**查看的产品**或**开始结账**事件之一或两者必须具有**价格**和**产品** ID字段作为事件负载的一部分，以及您帐户中这些事件的现有实例。 - 即使目录包含产品变体，这些事件也必须包含父产品级别 ID。在设置降价之前，请注意以下事项：
- 如果您使用目录 API，您的目录必须包含变体，即使该变体与主产品重复。 - 如果您除了电子商务集成中的目录之外还使用自定义目录，则降价流程将仅根据这些目录之一触发。如果您将流程设置为触发自定义目录，您可以联系 Klaviyo 支持人员将其恢复到您的集成目录。 ### 后续步骤

1. 从 Klaviyo 主菜单中，导航至****内容 >********产品****，确认自定义目录中的产品已同步。 2. [联系我们的支持团队](https://help.klaviyo.com/hc/en-us/articles/115001002272-How-to-Contact-Support) 并请求访问“自定义目录降价触发器”功能。确保指定以下内容：

   - 具有自定义目录或 API 目录的帐户（如果您有多个帐户）。 - 用作产品数据触发器的所有指标的事件 ID，例如 **订购的产品**、**开始结账** 和 **查看的产品**。 - 对于每个事件，产品 ID 和价格的字段名称。 - 对于 **开始结帐**，包含结帐产品的列表的字段名称。 3. 支持团队完成您的请求后，您可以继续创建流程。 ## 如何触发降价流程

1. 导航到****流 > 创建流 > 构建您自己的****。 2. 为流程命名并添加标签。 3. 单击****创建流程****继续。 4. 在流程构建器中，从 **推荐** 或 **所有触发器** 选项卡中选择 **降价****。 ![在“触发器设置”菜单中，“降价”选项位于列表底部](https://klaviyo.zendesk.com/hc/article_attachments/31432288697371)
5. 选择何时触发降价流程；即产品价格需要下降多少或百分比。 ![对于流量触发降价选项，有一个用于输入价格下降金额的文本框以及用于输入美元金额或百分比的按钮。](https://klaviyo.zendesk.com/hc/article_attachments/28717389650075)

   您可以随时调整触发器，但它仅适用于更改后触发的事件。 6. 选择您希望将此流程发送给以下人员：

   - 开始在购物车中结帐该产品 - 这将包括最少的人数，但他们更有可能进行转化。 - 查看了产品——这将包括更多人参与流程，但他们购买的可能性较小。 - 两者 - 此选项将拉入两组。在触发时和发送任何消息之前都会检查这些条件，以确保您不会发送给那些已经购买或只看到较低价格的人。 Klaviyo 不会吸引任何在流程触发事件后购买产品或在商品价格较低时查看/开始结账的人。 7. （可选）更改您希望某人查看或开始结账该商品的时间段。默认为过去 30 天。 ![降价配置菜单底部有一个选项，用于配置某人查看或签出该商品的时间段。](https://klaviyo.zendesk.com/hc/article_attachments/28717389665947)
8. 完成后，保存触发器。 9. 在触发后立即添加消息。 10. 添加任何分段、时间延迟和后续消息。不建议延迟时间，因为您希望在价格发生变化时立即通知客户。 11. 当您准备好流程开始发送时，选择****更新状态****。 12. 从下拉列表中选择****实时****。 13. 单击****保存****。 ## 如何预览和测试降价流程

与其他指标不同，只有在发生价格下跌时将价格下跌流程设置为**实时**或**手动**状态，才会在 Klaviyo 中注册价格下跌事件。这意味着降价流程中至少需要有 1 条消息是实时消息或手动消息，才能将事件添加到您的帐户中以进行预览。如果您想在消息中使用降价事件变量，例如原价和降价：

1. 使用操作卡上的下拉菜单将流程中的消息设置为****手动****状态。 ![](https://klaviyo.zendesk.com/hc/article_attachments/34454394354203)
2. 通过开始结帐或查看带有商品的产品（取决于您的降价流程设置），然后降低该商品的价格，从您的商店触发降价事件。 3. 在流程中选择一条消息，然后从操作按钮（3 个点）或侧边栏单击****编辑****。 ![](https://klaviyo.zendesk.com/hc/article_attachments/34454411028763)
4. 单击****编辑电子邮件****以获取电子邮件。 5. 在编辑器中，单击右上角的****预览和测试****。 ![](https://klaviyo.zendesk.com/hc/article_attachments/34454394359963)
6. 在侧边栏中，选择您想要直接在 Klaviyo 中查看预览的事件和人物。 7. 将鼠标悬停在变量名称上，直到看到消息 **复制 {{ person.variable\_name }} 变量**，然后单击以复制它。 8. 将变量粘贴到您希望在消息中显示的位置。 9. 添加完所需的所有变量后，单击****发送测试****将预览发送到您自己的收件箱。 ## 降价流程示例

根据您希望降价流程如何发挥作用，您可以通过多种方式进行设置。让我们从一个发送两条消息的基本示例开始：一条立即发送，一条提醒尚未购买的人。对于此流程，它将如下所示。 ![价格下降流程示例，触发后立即发送一封电子邮件，延迟 1 天后发送第二封电子邮件](https://klaviyo.zendesk.com/hc/article_attachments/28717383340699)

您可以使用电子邮件、短信或 WhatsApp 发送这些消息。 Klaviyo 只会向明确选择加入该频道的个人资料发送 SMS 或 WhatsApp 消息。该消息将自动跳过未经特定频道同意的个人资料。 ### 同时使用短信、WhatsApp 和电子邮件

对于多渠道降价流程，请在触发器后直接添加条件拆分。使用拆分来检查某人是否订阅了 SMS 或 WhatsApp。将获得 SMS 或 WhatsApp 同意的订阅者发送到一条路径，将其他人发送到另一条路径。这使您可以优先发送短信，同时继续向未选择使用 SMS 或 WhatsApp 的个人资料发送电子邮件。 ![](https://klaviyo.zendesk.com/hc/article_attachments/34454394363291)

### 首先发送给非客户

营销漏斗中最大的下降之一是当您尝试将某人转变为客户时。降价流是将网站浏览者转变为买家的绝佳工具。在 Klaviyo 中，您可以通过在触发器之后直接放置条件拆分来设置此功能，以将回头客发送到不同的路径。然后，在向回头客发送消息之前添加一个时间延迟。 下面的示例显示了包含短信和电子邮件的降价流程。 ![](https://klaviyo.zendesk.com/hc/article_attachments/34454411041947)

### 根据产品设置不同的规则

要根据产品的价格或类别设置不同的规则，您需要设置多个降价流程，然后使用过滤器来定位特定的商品。假设您想根据商品的初始价格和价格下降幅度来更改消息。也许对于大多数商品，您希望在价格下降至少 10% 时发送消息。但是，假设您的产品价格低于 20 美元，并且对于这些产品，您希望在价格下降 2.00 美元或更多时发送消息。在这种情况下，创建两个降价流并添加触发过滤器以定位您想要的产品。 ## 价格下跌报告

随着时间的推移，监控价格下降流的表现非常重要。要访问此报告，请单击流程的触发器，然后单击****查看价格下降报告****。您可以将此报告导出为 CSV。如果您有同一产品的多个版本和不同的变体，您需要将所有这些产品及其变体降到相同的价格，以便它们出现在您的降价报告中。价格下降报告将仅包括流程设置后发生的价格下降事件。它不会包括所有降价活动的历史记录。该报告将按最近到最近的顺序显示以下内容：

- SKU
- 产品标题
- 原价
- 降价
- 价格下跌时间戳
- 已发送
