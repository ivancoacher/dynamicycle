## 你将会学到

了解如何设置日落流程，旨在逐步淘汰不再与您的品牌互动的客户。您可以使用此流程作为赢回业务的最后努力，然后删除或压制任何不响应的人。您还将看到这个推荐的****sunset段****定义如何连接到段库中预构建的****Sunset（电子邮件）****段。这将帮助您保持一份干净的列表，并避免不活跃的客户为您的 Klaviyo 计费计划做出贡献。 ## 何时取消订阅者

由于日落流是吸引个人资料的最后努力，因此您应该取消计划抑制的列表和细分。一旦您隐藏个人资料，他们将无法收到您品牌的营销电子邮件和促销信息。通过取消这些配置文件，您有机会将与流量相关的配置文件排除在抑制之外，因为它们仍然很有价值，可以保持活动状态并发送到。您还应该在他们变得不活跃或客户流失时关闭他们的档案。让它们在您的帐户中保持活跃状态​​并让它们为您的 Klaviyo 计费计划做出贡献不再有意义。这些配置文件显示出长期、持续的不活动状态（即没有网站访问、购买或营销参与）。由于这段持续不活动的时间，这些资料不太可能再次与您的品牌互动。一旦某个配置文件不再为您在 Klaviyo 中的业务产生任何收入，并且您看不到任何赢回它们的机会，您就可以采取行动抑制它们，这样它们就不会计入您的 Klaviyo 计费计划。 ## 设置日落段

当配置文件添加到特定段时，会触发日落流。虽然下面推荐的分段使您能够识别和取消已表现出长期不活动状态的配置文件，但您可以运行计划通过日落流抑制的任何分段或列表。要识别已表现出持续不活动期的配置文件，您可以构建以下分段并通过日落流运行它：

- 如果某人可以或不能接收营销信息 > 人****可以接收**** ****电子邮件营销****
  和
- 关于某人的属性 > ****创建****至少是 ****180**** 天前
  和
- 某人做了什么（或没有做什么）> 在过去 ****72**** 周内****收到了至少 5**** 封电子邮件
  和
- 某人做过（或未做过）的事情 > ****打开电子邮件 0 次**** ****一直以来****
  和
- 某人做过（或未做过）的事情 > ****一直以来点击电子邮件 0 次****
  和
- 某人做过（或未做过）的事情 > ****在网站上活跃 0 次**** ****一直以来****
  和
- 某人做过（或未做过）的事情 > 一直以来****查看产品 0 次****
  和
- 某人做过（或未做过）的事情> ****结帐开始 0 次 一直以来****
  和
- 某人做过（或未做过）的事情 > 一直以来 ****下订单 0 次****

此定义还显示为细分库中的预构建 Sunset（电子邮件）细分，并且与 Klaviyo 在“抑制的配置文件”页面上用于[抑制建议](https://help.klaviyo.com/hc/en-us/articles/24312135764251) 的逻辑相同。首先导航到细分库，您将看到“日落（电子邮件）”选项。 ![](https://klaviyo.zendesk.com/hc/article_attachments/47698582815515)

当您选择它时，您将看到日落（电子邮件）段的以下定义，并能够对其进行命名和添加标签。 ![](https://klaviyo.zendesk.com/hc/article_attachments/47698545407771)

## 交付能力优势

构建此细分的主要好处之一是抑制它并停止向不受监控的配置文件发送邮件，因为随着时间的推移，发送到不受监控的收件箱会损害您的送达能力。当[推荐低参与度配置文件](https://help.klaviyo.com/hc/en-us/articles/24312135764251)时，Klaviyo 使用相同的日落定义从****抑制的配置文件****页面进行抑制。继续发送到该群组中的个人资料会降低您的打开率，这是邮箱提供商用来确定未来电子邮件的去向（收件箱或垃圾邮件文件夹）的最重要信号

当不活跃的个人资料进入此细分市场时，他们将触发日落流并自动收到来自您的品牌的一些最终电子邮件，然后才能最终被抑制。 如果您尝试向这些不活动的配置文件发送电子邮件，则会产生相反的效果。这样做不仅不会提高您的发送声誉，反而会使您的声誉面临风险。请务必谨慎行事。 ## 设置日落流

设置日落段后，您将需要构建一个通过添加到日落段而触发的流程。我们建议使用流库中预构建的日落流。 1. 导航至****流****选项卡。 2. 点击****创建流****查看流库。 3. 在搜索栏中搜索“日落”即可查看 Klaviyo 预建的日落流程。 4. 单击预先构建的“日落未参与订阅者”流程。 5. 在触发器下拉列表中，选择您的日落片段。 6. 单击模式底部的****创建流****。 7. 自定义消息内容以匹配您的品牌。 8. 如果您为现有列表或细分创建了过去的配置文件，请将其添加到您的流程中。 ****从头开始创建日落流****

如果您想从头开始创建流程：

1. 导航至****流****选项卡。 2. 单击****创建流****。 3. 单击右上角的****从头开始创建****。 4. 为您的流程命名并点击 ****创建流程****。 5. 在**触发器设置**侧栏中，单击****分段****。 6. 在下拉列表中，选择您的日落片段。 7. 添加流过滤器以排除自启动流以来打开或单击电子邮件的任何人。任何参与您的日落电子邮件（或您在流程中时向他们发送的任何其他电子邮件）的人都将自动从流程中删除，并且不会被标记为抑制。请参阅下面的屏幕截图以供参考。 ![带有触发器过滤器的日落流程，用于检查配置文件自启动流程以来是否未打开过电子邮件且未单击过电子邮件](https://klaviyo.zendesk.com/hc/article_attachments/28704485061403)
8. 添加一到三封电子邮件，提示客户在不再有兴趣接收您的电子邮件时取消订阅。最好将此流程限制为不超过三封电子邮件，因为您不想重复联系不参与的人，因为这可能会损害您的送达率。任何取消订阅的人都将被自动抑制，您（或他们）无需采取进一步的操作。 9. 在收到最后一封电子邮件后，拖入一个短时间延迟，以便为收件人提供打开或单击电子邮件的宽限期。此处，假设每天发送频率，宽限期为三天。如果您发送的频率较低，请将宽限期延长至更长的时间，例如 7-10 天。 ![流量触发后设置1天的时间延迟示例](https://klaviyo.zendesk.com/hc/article_attachments/28704485062811)
10. 拖入更新配置文件属性流操作。这将标记那些不参与电子邮件的人，从而被动地表明他们想要取消订阅。 11. 配置标签以指定应抑制这些联系人。您可以通过创建一个新的布尔配置文件属性来实现此目的，其中“Unengged”的值为“True”。
    ![流程结束时将 Unengged 属性设置为 True 的更新配置文件属性操作示例](https://klaviyo.zendesk.com/hc/article_attachments/28704476922651)

借助流过滤器，任何打开或单击电子邮件的人都将在此操作之前退出流，并且标签不会添加到他们的个人资料中。一旦未参与的订阅者被标记为**未参与 = True**，他们将退出流程。 ### 禁止未参与的配置文件

任何经历过整个日落流程的人都将被标记为未参与，现在可以被压制。要抑制这些配置文件：

1. 导航至您帐户的****列表和细分****选项卡。 2. 选择****新建**** > ****创建段****。 3. 为您的片段命名，以明确其是为了抑制。 4. 添加以下段定义：
   1. ****关于某人的属性**** > ****未婚****> ****是真实的****。 ![](https://klaviyo.zendesk.com/hc/article_attachments/33901479807131)
5. 单击 ****创建分段****。 6. 返回****列表和细分****选项卡，单击新细分右侧的操作按钮。 7. 选择****禁止当前成员****。 ![Klaviyo 中列表的批量抑制选项](https://klaviyo.zendesk.com/hc/article_attachments/33901479809563)此操作适用于抑制时列表或段中的所有配置文件，并且不会影响之后加入的配置文件。如果组中的配置文件已被抑制，则其状态不会受到影响。 请注意，您每次发送营销活动之前都必须执行此操作，以有效地从未来的发送中逐步淘汰不活动的配置文件。目前无法将配置文件作为流操作进行抑制。有一个解决方法，但您需要利用 Klaviyo 的 API 来执行此操作。这将需要开发人员。如果您是开发人员，请参阅文章“[解决方案 9：使用 Klaviyo Flow Webhooks 使用分段和 Klaviyo 的 API 自动进行抑制”中记录的流程.](https://www.klaviyo.com/blog/solution-recipe-9-use-klaviyo-flow-webhooks-to-automate-suppressions-using-segments-and-klaviyos-apis)

当您抑制可能包含最近活跃客户的其他列表或细分时，Klaviyo 可能会显示一个抑制模式，根据最近验证的电子邮件参与度或购买情况总结将抑制多少个配置文件与保持活动状态。对于上面定义的严格“日落”细分（无打开、点击、网站活动或订单），您通常不会看到此模式，因为这些配置文件已被归类为长期不活动并准备被抑制。详细了解[如何管理电子邮件抑制和批量删除配置文件。](https://klaviyo.zendesk.com/hc/en-us/articles/24312135764251)

### 流内容最佳实践

我们建议使用纯文本，并通过使用“{{first_name}}”标签和发件人地址（例如“Marissa from Klaviyo”）在电子邮件中尽可能体现个性化。包括自他们不再参与以来发布的任何新产品的内容，并考虑提供折扣以吸引他们购买。您将需要包含显着的取消订阅和管理首选项链接，以防订阅者想要更新其设置而不是完全取消订阅。 ![消息内容编辑器，其中消息包含适合日落电子邮件的语言](https://klaviyo.zendesk.com/hc/article_attachments/28704476913691)

在电子邮件中，让收件人可以选择浏览您的网站或以其他方式与您互动（如果他们确实想保持订阅）。以下是来自 [Princess Awesome](https://princess-awesome.com/) 的示例。 ![日落电子邮件示例，其中包含可供客户设置电子邮件首选项的链接](https://klaviyo.zendesk.com/hc/article_attachments/28704485056795)

此外，请在电子邮件主题行中表明，如果这些订阅者继续不参与，您将与他们说再见（例如，“是时候说再见了吗？”或“我们已经想念你了”）。例如，下面来自 Framebridge 的电子邮件的主题行是：“再见很难……”

![带有链接的日落电子邮件示例，客户可以单击该链接将其保留在订阅列表中](https://klaviyo.zendesk.com/hc/article_attachments/28704485058715)

## 添加过去的个人资料

当您创建日落段时，它将填充先前符合段定义中的条件的配置文件。但是，该流程只会针对有机进入分段的配置文件（即创建后满足分段标准的配置文件）触发。如果您想将过去的个人资料添加到您的流程中：

1. 在添加过去的配置文件之前，请确保流程的消息设置为手动或实时状态。 2. 单击触发卡上的****添加过去的配置文件**** 图标
