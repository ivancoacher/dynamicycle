## 你将会学到

了解如何将更新配置文件属性操作添加到流程中，以便您可以收集和跟踪配置文件数据。

此流程操作允许您：

- 更新现有的配置文件属性
- 删除现有的配置文件属性
- 创建并设置新的配置文件属性

此操作可用于多种用例，例如：

- 收集感兴趣的类别
- 用特定日期标记个人资料
- 将性别添加到个人资料中

了解有关[更新配置文件属性操作用例的更多信息。](https://help.klaviyo.com/hc/en-us/articles/360050420371)

如果有人在到达更新配置文件属性操作之前在流程中的某个点未通过配置文件过滤器，他们将跳过该操作，并显示跳过原因 **已跳过：流程条件失败**。

## 添加更新配置文件属性操作

1. 导航至特定流程。
2. 将****配置文件属性更新****操作拖放到流程中。
3. 单击****+ 添加步骤****。
   ![配置文件属性下拉列表，下面带有添加步骤按钮](https://klaviyo.zendesk.com/hc/article_attachments/28717850779931)
4. 选择以下选项之一：
   - ****更新现有属性****此选项允许您更新现有自定义属性的值。如果您选择的属性是值列表，您可以选择在列表中添加或删除值。
     - 如果收件人配置文件尚不存在该属性，则将首先创建该属性，然后更新该值。
     - Klaviyo 自动检测并验证您选择的属性的数据类型。例如，如果您有“Age”之类的属性，并且所有现有值都是数字，那么您尝试将该值更新为“tom”，我们将显示错误，因为“tom”不是数字。
     - 如果要将多个值添加到列表属性，请创建单独的步骤并将每个值添加为更新。
       ![](https://klaviyo.zendesk.com/hc/article_attachments/34693858870939)
   - ****创建新财产****
     此选项允许您创建全新的自定义属性并分配值。如果给定收件人配置文件的属性已存在，我们将更新该值。在这里，您还可以配置新属性的数据类型：
     - ****文本****这是任何常规文本字符串，例如“Tom”或“Chocolate”。
     - ****数字****这是任何数值，例如 0、5 或 750。
     - ****列表****这是一个值列表，我们将让您输入想要成为新列表一部分的所有值。
     - ****布尔**** 布尔值是一个二进制变量，有两个可能的值：“真”和“假”。您可以从下拉列表中选择 true 或 false。
     - ****日期****
       这是一个日期属性，必须采用[可接受的日期格式](https://developers.klaviyo.com/en/docs/acceptable_date_and_timestamp_formats_for_profile_and_event_properties)。
   - ****删除现有属性****该选项允许您从配置文件中删除现有的自定义属性。这不仅会清除值，还会从配置文件中完全删除该属性。
5.（可选）再次单击****+添加步骤****一次更新多个配置文件属性
   - 您可以添加的步骤数量没有限制。
   - 步骤将按照它们出现的顺序发生。
   - 可以重新排序步骤。
6. 单击 ****保存****。

如果您有多个彼此相邻的更新配置文件属性操作，请在它们之间添加至少一分钟的时间延迟，以便更新不会相互干扰。

## 查看活动

您可以在右侧详细信息侧栏中查看谁正在等待以及谁已完成此步骤的摘要。

如果您单击消息步骤，在右侧详细信息侧边栏的 **性能** 部分中，您将能够看到以下内容：

- 谁已安排或正在**等待**
- 谁处于**需要审查**（如果流程组件处于/曾经处于手动模式）
- 谁已成功完成该组件并位于 **是** 分组中
- 由于流量过滤器失败或在发送时不再符合资格而被跳过或处于 **否** 分组中的人员
