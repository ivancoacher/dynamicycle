了解如何创建分段或列表触发的流程及其重新进入设置。每当有人新加入段或列表时，段触发流和列表触发流就会分别开始。通过 Klaviyo 更新的流条目设置，您现在可以更好地控制配置文件是否（以及多久一次）可以进入或重新进入这些流。这使得支持生命周期消息传递、基于行为的自动化和定期参与活动变得更加容易。 ## 段和列表触发的流程如何工作

当配置文件新符合段或列表资格时，将触发基于段或列表的流。对于细分市场，这意味着：

- 该配置文件以前不在该段中
  和
- 数据更改（例如配置文件属性或事件）导致他们有机地进入细分市场。对于列表，这是他们第一次加入列表的时间，例如当他们通过表单加入时。 ### 列出特定详细信息

请记住，如果将配置文件导入列表，它将触发任何列表触发的流。这意味着，如果您设置欢迎系列并导入现有订阅者列表，这些订阅者将进入欢迎系列。为了避免这种情况，请在导入之前关闭所有列表触发的流。 ### 特定于细分市场的详细信息

对于细分市场，有一些重要事项需要牢记：

- 手动编辑段的定义不会触发流程。 - 如果您想在手动更新定义后将分段的所有成员推送到连接的流中，则需要[将过去的配置文件添加到流中](https://help.klaviyo.com/hc/en-us/articles/115002779231)。 - 仅当配置文件的数据导致其有机地进入细分市场时才会触发流。 - 重复的活动（例如，重复的事件）不会重新触发流程，除非分段成员资格实际发生变化。 - 仅当接收者在发送时仍然是已连接网段的成员时，才会接收流内的消息。 ## 创建分段或列表触发的流

1. 导航至 Klaviyo 中的****Flows**** 选项卡。 2. 单击****创建流程****并选择****构建您自己的****。 3. 为您的流程命名并单击****创建流程****。 4. 在 Flow Builder 中，选择 ****已添加到段**** 或 ****已添加到列表**** 作为触发器。 5. 选择应启动流程的段或列表。 6. 在触发设置面板中配置****重新进入标准****。 ## 重新输入设置

如果您在帐户中没有看到此设置，请继续关注！此设置很快将可供所有人使用。当配置文件满足段的定义或加入列表时，段或列表触发的流开始。配置文件现在可以输入这些流：

- 仅限一次
- 每当他们重新获得资格时
- 经过最短时间后

这些选项由流程触发器中新的****重新进入标准****设置控制。 ![流程的重新输入设置](https://klaviyo.zendesk.com/hc/article_attachments/44565688213659)

您可以通过调整触发面板中的****重新进入标准****来控制配置文件进入流程的频率。您的选择包括：

|  |  |  |
| --- | --- | --- |
|设置|描述 |使用案例 |
|不可重新进入|配置文件只会进入流程一次。 |欢迎系列 法律或合规通知 |
|允许重新进入 |只要个人资料新符合列表或细分的资格，他们就会重新进入流程。 |生命周期流 基于行为的分段流，其中消息传递应随时间重复。 |
|允许在一段时间后重新进入 |当配置文件新获得资格**且**自上次输入以来已过了所选时间段时，配置文件将重新触发流程。 |保留流 赢回流。 |

重新进入标准现在作为流进入行为的单一事实来源。您不再需要添加“尚未流入”过滤器来控制频率。 ### 新流程的默认设置

当您创建新流程时，Klaviyo 根据触发器类型应用默认的重新进入设置：

|  |  |  |
| --- | --- | --- |
| ****触发类型**** | ****默认重新输入设置**** | ****注释**** |
|细分 |不可重新进入|客户可以更改为允许重新进入或基于时间的重新进入 |
|列表 |不可重新进入 |与段 | 相同的默认值
|指标（例如，**下订单、** **查看产品**、**降价**、低库存**）|允许重新进入 |包括降价和低库存|
|日期属性 |允许重新进入 |行为不变；日期更新时重复或每年重复 |

您可以随时调整这些默认值。 ### 不触发重入的路径

仅当配置文件的数据导致分段或列表成员资格发生更改时，才会发生重新输入。以下情况不会触发流程：

- 手动编辑分段规则
- 手动将配置文件添加到列表或分段
- 合并配置文件或列表
- 重复的订阅或事件活动，其中配置文件已在细分中
- 有意添加配置文件而不触发流程的集成

### 常见问题解答

#### 是否“添加过去的配置文件：重新触发流程？不。添加过去的配置文件不算作新的资格，也不会重新触发流程。配置文件必须有机地满足流程再次运行的分段条件。#### 以前我无法重新触发我的流程。我的现有流程会发生什么情况？现有流程保留与引入新设置之前的功能一致的行为。它们的配置会自动转换到新系统中。#### 现有行为 →新的重新进入设置

- 没有重入过滤器的列表或分段流 → ****无重入****
- 没有重入过滤器的事件（公制）流 → ****允许重入****
- 带有“一直未处于流动状态”过滤器的公制流量 → ****不可重新进入****
- 具有“X 天内未流入”过滤器的公制流量 → ****允许在一段时间（X 天）后重新输入****

#### 这会改变我的流发送频率吗？不可以，除非您调整重新进入标准。 #### 我可以限制个人资料只能输入一次吗？是的。将重新进入标准设置为****禁止重新进入****。 #### 我可以控制指标触发流的重新进入吗？是的。现在，直接在触发器设置中以相同的方式管理所有流类型的重新进入。了解其他流类型：
