请注意，只有所有者和管理员可以向帐户添加新用户。 ## 你将会学到

了解不同的 Klaviyo 用户角色、他们的帐户权限和访问权限，以及他们在平台内的潜在限制。根据您的角色，Klaviyo 的视图可能会有所不同。例如，所有者看到的帐户设置选项与管理员看到的不同。本文讨论帐户用户的权限。如果这不是您想要的内容，您可能需要查看我们关于[如何添加或删除帐户用户](https://help.klaviyo.com/hc/en-us/articles/360053547071) 或[组合用户权限](https://help.klaviyo.com/hc/en-us/articles/25181702319643) 的文章。 ## 可用的用户角色

目前有以下用户角色：

- 业主
- 管理员
- 经理
- 分析师
- 活动协调员
- 内容创作者
- 支持
- 社交媒体经理

打开下拉菜单以了解有关每个角色的更多信息。 ****业主****

一个帐户只能有 1 位所有者，他们可以：

- 访问完整帐户
- 编辑和关闭帐户
- 创建私有 API 密钥
- 编辑[域身份验证](https://help.klaviyo.com/hc/en-us/articles/115000357752#navigate-to-domain-authentication2)页面

默认情况下，第一个创建 Klaviyo 帐户的人将是该帐户的所有者。随着时间的推移，他们将收到来自 Klaviyo 的重要帐户通知，并且可以编辑公司中接收计费相关通知的人员。如果您想更改所有者，请了解[如何转移帐户所有权](https://help.klaviyo.com/hc/en-us/articles/360051946112)。 ****管理员****

管理员拥有完整的帐户访问权限。管理员可以：

- 编辑帐户详细信息（例如更新付款计划）
- 添加或删除用户
- 从账单中取消付费订阅
- 创建私有 API 密钥
- 编辑域名认证页面
- 编辑公司中接收计费相关通知的人员
- 访问评论选项卡

管理员不能： 完全关闭帐户（例如，禁用帐户并删除所有用户）。 ****经理****

经理可以访问 Klaviyo 的所有核心功能，但在流程、列表、细分和分析方面存在一些限制。他们有权访问的选项卡是：

- 活动选项卡
  - 可以创建活动、导出分析等。 - 无法导出任何收件人活动。 - 流程选项卡
  - 无法导出任何收件人活动
- 评论选项卡
- 注册表单选项卡
- 观众选项卡
  - 列表和细分
    - 无法从 Klaviyo 导出任何活动或抑制的地址
  - 个人资料
- 分析选项卡
  - 可以访问：
    - 仪表板
    - 指标
    - 基准
    - 自定义报告
  - 无法导出分析（自定义报告除外）
- 设置选项卡，其中：
  - 可以
    - 编辑某些帐户详细信息（例如更改任何付费计划或托管页面）
    - 设置短信
  - 不能
    - 访问下载选项卡
    - 编辑或删除帐户用户
    - 降级为免费计划
    - 取消账户

****分析师****

分析师可以访问分析、细分和报告。他们有权访问的选项卡是：

- 活动选项卡
  - 只能查看草稿营销活动列表和已发送营销活动的详细信息
- 流程选项卡
  - 只能查看分析、导出分析和预览流消息
- 注册表单选项卡
  - 只能看到表单分析
  - 无权访问表单生成器或 A/B 测试设置
- 观众选项卡
  - 列表和细分
  - 个人资料
    - 无法创建、更新或删除配置文件或访问“消息”选项卡（即，他们无法查看为配置文件发送、跳过或计划的哪些消息）
- 集成
  - 可以查看安装了哪些集成
  - 无法编辑、添加或删除集成
- 分析选项卡
  - 仪表板
  - 指标
  - 基准
  - 自定义报告

****活动协调员****

活动协调员可以创建和发送活动以及创建和编辑模板。他们有权访问的选项卡是：

- 活动选项卡
- 流程选项卡
  - 只能编辑流详情（名称和标签）、编辑消息内容、预览流消息
- 观众选项卡
  - 列表和细分
- 内容选项卡
  - 模板
  - 数据馈送
  - 优惠券
- 设置选项卡
  - 同意书页
  - 域名页面

****内容创建者****

内容创建者可以创建和编辑模板。 他们有权访问的选项卡是：

- 活动选项卡，但只能查看此选项卡；他们无法安排或发送营销活动、编辑模板或查看已发送营销活动的分析
- 流，但只能编辑流详细信息（名称和标签）、编辑消息内容和预览流消息
- 注册表单，但他们无法创建或删除表单、查看分析、发布任何更改、发布 A/B 测试或发布对正在运行的测试中的变体的更改。 - 列表和段，但只能查看段定义
- 内容选项卡和同意页面

****支持****

支持代表可以访问收件箱，这将是他们登录 Klaviyo 后的默认登录页面。他们有权访问的选项卡是：

- 收件箱选项卡
  - 可以查看个人资料信息并使用收件箱聊天控制台。 - 无法调整设置。 - 个人资料选项卡
  - 可以查看个人资料列表视图、个人资料详细信息、活动源、联系信息和频道。 ****社交媒体经理****

社交媒体管理员可以在您的 Klaviyo 帐户内创建、编辑和管理社交媒体内容和数据。他们有权访问：

- 社交标签
- 受众选项卡
  - 列表和细分
- 内容选项卡
  - 媒体与品牌
- 分析选项卡
  - 仪表板
  - 指标
  - 自定义报告
