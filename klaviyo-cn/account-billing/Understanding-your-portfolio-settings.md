只有投资组合所有者和管理员才能访问投资组合的设置，**个人**选项卡除外。

## 你将会学到

了解项目组合中的设置，包括谁可以访问它们以及它们的影响。

您投资组合中的设置不会影响任何链接的帐户。如果您更改投资组合中的某些内容，则只会影响该投资组合。唯一的例外是“个人”选项卡，该选项卡特定于每个用户并且在其帐户中保持一致。

## 投资组合设置

组合中有 4 个设置选项卡：

- [个人](#h_01HWNQTZWDNQPMTNM1KP1J9WFT)
- [作品集](#h_01HWNQTZWDX28CAZNN2Y1P5TCG)
- [API密钥](#h_01HWNQTZWD5HTW4WJDZH9SYDCY)
- [安全](#h_01HWNQTZWDFHNVC8BZ2J8CQCH9)

## 个人

**个人**选项卡特定于每个投资组合用户，并且在与该用户关联的每个帐户中都是一致的。它是所有用户都可以访问的唯一设置选项卡，包含有关用户的详细信息：

- 姓名
- 个人语言
- 电子邮件
- 克拉维约密码

如果您更改任何此类个人信息，您有权访问的所有其他帐户中的信息也会发生变化。

****我如何更改我的名字？****

更改您的姓名：

1. 导航至****个人****选项卡。
2. 在 **信息** 部分中，编辑您的名字或姓氏。
   ![投资组合设置中的个人选项卡](https://klaviyo.zendesk.com/hc/article_attachments/28716119019163)
3. 单击****保存****。

## 投资组合

**产品组合**选项卡包含有关产品组合本身及其代表的品牌的信息，包括：

- 投资组合名称
- 企业网站（可选）
- 公司地址
- [默认语言](https://help.klaviyo.com/hc/en-us/articles/25956849989531)（英语或法语）。请注意，如果您更改投资组合的语言，更改将立即应用到您的帐户，并且所有用户都将以所选语言体验 Klaviyo。

![设置中的投资组合选项卡](https://klaviyo.zendesk.com/hc/article_attachments/28716058257563)

## API 密钥

在这里，您可以查看投资组合的公共 API 密钥。该密钥目前不能用于任何 API；它只是投资组合的 ID。投资组合也没有私有 API 密钥。

出于安全原因，请勿共享您的公共 API 密钥。

## 安全

**安全**选项卡允许您调整以下两项：

- 多重身份验证（MFA）
- 单点登录 (SSO) 和跨域身份管理系统 (SCIM)

![投资组合设置中的安全选项卡](https://klaviyo.zendesk.com/hc/article_attachments/28716058260763)

### 艺术硕士

您可以为以下任一情况启用 MFA：

- 你自己
- 投资组合中的所有用户

此设置不会影响链接到投资组合的任何 Klaviyo 帐户。

要打开此功能，您可以按照相同的[在帐户中启用 MFA 的步骤](https://help.klaviyo.com/hc/en-us/articles/360026617692)。唯一的区别是您必须是投资组合所有者（而不是管理员）。

### SSO 和 SCIM

如果您想使用 SSO 或 SCIM 登录您的投资组合，所有者可以在账户中进行设置。请注意，在投资组合中启用 SSO 会影响账户中的所有用户，您必须在 [SCIM](https://help.klaviyo.com/hc/en-us/articles/10952782535579) 之前[设置 SSO](https://help.klaviyo.com/hc/en-us/articles/9353860331035)。
