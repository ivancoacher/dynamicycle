## 你将会学到

了解如何克隆表单、流程、分段、营销活动和模板。克隆时，您可以复制：

1. 至您所在的同一个帐户
   或者
2. 对于另一个帐户或多个其他帐户，您可以访问

## 开始之前

您必须在您要克隆的帐户和要克隆的帐户中拥有适当的[用户权限](https://help.klaviyo.com/hc/en-us/articles/115005231648)。例如，假设您是账户 A 和 B 中的管理员，但账户 C 中的内容创建者。在这种情况下，您可以将流从账户 A 克隆到 B（反之亦然），但无法克隆流向账户 C 或从账户 C 克隆流。

您可以同时在最多 100 个其他帐户中创建克隆。

## 哪些内容无法克隆

克隆允许您复制表单、流程、段、营销活动或模板。

在同一个帐户中，克隆是完全相同的副本。

但是，当克隆到另一个帐户时，传输中可能会遗漏一些信息。这是因为这两个帐户可能具有不同的渠道、指标、列表名称等。在大多数情况下，您只需在克隆过程中更改此信息（例如，切换指标或列表名称）即可。

某些内容（例如优惠券、评论块、降价流以及动态或通用内容）将不会被克隆。虽然对象本身（例如文本框）将被克隆，但这些对象中的内容不会被克隆。

任何时候克隆流时，都无法更改触发器类型（例如，无法将指标触发的流转换为列表触发的流）。但是，您可以更改触发流程的指标、列表、细分或日期（例如，**已下订单**而不是**订单已确认**）。

此外，使用[高级运算符](https://help.klaviyo.com/hc/en-us/articles/115005062847#h_01HCJ107VYYC96Y95SPAGYP9AJ)的分段（即，超出“等于”和“包括任何”的事件运算符）或[多个，其中条款](https://help.klaviyo.com/hc/en-us/articles/115005062847#section1) 目前无法跨帐户克隆。

## 如何克隆

对于段、流程、表单、营销活动和模板来说，克隆过程几乎完全相同。唯一的区别在于流，它多了 1 个额外步骤。

1. 单击要复制的表单、流程、段、营销活动或模板右侧的 3 个垂直点。
2. 选择****克隆****。
3. 选择：

   - ****克隆到此帐户****。
   - ****克隆到多个帐户****！[](https://klaviyo.zendesk.com/hc/article_attachments/28720898833947)
4. 选择****继续****。

### 在帐户内克隆

如果在同一帐户内克隆，您需要做的就是：

1. 为克隆的段命名。
2. 单击****克隆****。

### 克隆到另一个或多个其他帐户

1. 如果您选择克隆到同一帐户，您将在列表中看到具有您选择的名称的克隆。
2. 要克隆到另一个帐户，请搜索并选中您要复制到的帐户。您最多可以选择 100 个帐户。
   注意：您必须在转入和转出的帐户中拥有适当的用户权限。
   ![替代](https://klaviyo.zendesk.com/hc/article_attachments/28720904150171)
3. 单击****下一步****。
4. 可选：编辑每个帐户的克隆名称。
5. 选择****下一步****。
6. 检查并修复以下任何内容，因为某些详细信息将不会被克隆，或者需要为您的其他帐户进行更改（例如，分段条件、指标等）。

   |  |  |  |  |  |
   | --- | --- | --- | --- | --- |
   | ****表格**** | ****细分**** | ****流动**** | ****活动**** | ****模板**** |
   |目的地列表 |名单名称 |指标、列表、段、日期属性 |收件人（列表或细分）|友情链接 |
   |定位设置（可选）|日期范围 |任何过滤器（触发、流或附加）|频道消息在目标帐户中不可用 |  |
   |年龄限制块（如果需要）|型材属性 |任何配置文件或事件属性 | UTM跟踪参数|  |
   |短信设置（如果需要）|自定义指标 |  |标签 |  |
7. 单击克隆按钮。

克隆过程可能需要几分钟。您可以在加载窗口中查看进度，或者如果您离开，克隆完成时，铃声图标会提醒您。

请注意，如果目标帐户有任何错误，则不会创建克隆。例如，如果目标帐户之一的分段条件存在错误，则不会在该帐户中创建该分段的克隆。
