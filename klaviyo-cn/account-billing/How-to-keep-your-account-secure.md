## 你将会学到

了解如何确保您的 Klaviyo 帐户和数据尽可能安全。正确配置沟通和分配角色至关重要，尤其是当您的网站流量和品牌消息增加时。 ## 开始之前

有 2 项重要的安全检查需要审查：

1. [公共与私有API密钥安全检查](#h_01GJ33R2BZ1HEWB9DT772KX8J5)
2. [用户审核和访问检查](#h_01GJ33R9C41E21390FTKJW9VJ5)

## 公共与私有 API 密钥安全检查

要访问您帐户的 API 密钥：

1. 单击左下角您的组织名称。 2. 选择****设置 > API 密钥****。您的公钥（也称为站点 ID）位于本页第一部分的表中，而您的私钥则列在标有 **私有 API 密钥** 的第二个表中。 - ****公共 API 密钥****
  您可以与其他人共享的 API，以便他们可以从您的 API 获取某些信息。您的公共 API 密钥是您的帐户标识符。配置和使用 Klaviyo JavaScript 库时，请使用您的公共 API 密钥，而不是私有 API 密钥。 - ****私人 API 密钥****
  读取数据和操作敏感对象（例如 Klaviyo 中的列表）的 API 密钥。保持 API 私钥的私密性非常重要。将它们视为密码，保存在安全的地方并且永远不会暴露给公众。,
  在 Klaviyo 中，私有 API 密钥均以前缀“pk\_”开头，后跟 34 个字母数字字符。例如，私钥将类似于：**pk\_abc123def456ghi789jkl0mno123pqrst4**。创建 API 私钥后，您将无法查看任何私钥。 ![](https://klaviyo.zendesk.com/hc/article_attachments/28717388789659)

****为什么不能使用私有 API 密钥代替公共 API 密钥？****

如果恶意行为者发现私钥，则意外使用私有 API 密钥而不是公共密钥可能会导致您的帐户被滥用。如果您在 JavaScript 中使用了错误的 API 密钥，您也将无法成功收集或利用适用的数据。 ### 验证所有客户端代码都使用您的公共 API 密钥

您是否使用[Learnq、klOnsite 或 Klaviyo 对象](https://developers.klaviyo.com/en/docs/introduction_to_the_klaviyo_object) 编写了任何自定义代码、调用我们的[客户端 API 端点](https://developers.klaviyo.com/en/reference/create_client_subscription) 的代码，或者您是否[安装了 Klaviyo.js手动](https://help.klaviyo.com/hc/en-us/articles/360020342232)？如果上述任何一项的答案是肯定的，那么请务必验证您是否仅在这些情况下使用公共 API 密钥。您需要使用自定义代码检查网站上的每个页面。您可以从您的主页开始：

1. 打开您的网站。 2. 右键单击​​并选择****查看页面源代码****。 3. 当新页面打开时，选择****编辑 > 查找 > 查找...**** 并搜索“pk\_”。 4. 确保没有私钥用作公司\_id、“令牌”值，或者在极少数情况下用作帐户值。 5. 如果您发现任何私有 API 密钥（值以“pk\_”开头），请查看[下面](#h_01EPWC58AT8C1BEP4HZGXNNCG6) 部分，了解当您的私有 API 密钥暴露时该怎么做。 ### 如果您的 API 私钥被泄露该怎么办

如果使用您的私有 API 密钥而不是公共 API 密钥：

1. 记录私有 API 密钥（稍后您将需要它）并将其替换为您的公共 API 密钥。这将使您的代码能够在 Klaviyo 平台中按预期工作。 2. 删除并替换暴露的密钥，以保护您的公司和客户数据免遭未经授权的暴露。 3. 确定您可能拥有的所有私钥集成和应用程序，包括自定义代码。 4. 对于使用公开的私有 API 密钥的每个集成和应用程序，请选择“****创建私有 API 密钥****”，在您的[帐户设置](https://www.klaviyo.com/account#api-keys-tab)中创建一个新密钥。 5. 给密钥一个有意义的标签，以便快速识别以及特定范围。 6. 为每个集成创建唯一的私有 API 密钥后，使用新的私有 API 密钥更新集成。 7. 更新所有使用公开密钥的集成后，将鼠标悬停在公开密钥上，然后单击****删除****。 - 请小心选择要删除的正确键，因为选择删除按钮时不会进行验证。删除后，您将通过暴露的私钥保护您的数据免遭未经授权的访问。 有关 API 密钥安全性的更多信息，请前往[管理您的帐户 API 密钥](https://help.klaviyo.com/hc/en-us/articles/115005062267)。 ## 用户管理和数据访问检查

了解谁有权访问您帐户中的不同功能和信息非常重要。要查看有权访问您帐户的所有用户：

1. 前往左下角您的组织名称。 2. 选择****设置****。 ![帐户设置中的“用户”选项卡](https://klaviyo.zendesk.com/hc/article_attachments/28717388785563)

定期检查帐户内的用户及其访问级别是一项重要的安全活动。以下三项活动将有助于保护您的帐户：

- ****用户评论****
  查看您帐户中的所有用户并确定任何不再需要访问权限的用户。通过选择电子邮件旁边的 ****X**** 删除不应再处于活动状态的任何用户。删除访问权限的常见原因包括：
  - 公司内部角色变更
  - 解雇员工
  - 第三方供应商的合同到期。 - ****角色回顾****
  确保每个用户都具有适当的权限，并且只能访问执行其作业所需的数据和功能。有关用户角色有权访问的信息，请前往[用户管理和权限](https://help.klaviyo.com/hc/en-us/articles/115005231648)。 - ****多重身份验证****
  [多重身份验证](https://help.klaviyo.com/hc/en-us/articles/360026617692) 除了标准用户名和密码之外，还需要一次性密码，为您的帐户增加了一层额外的安全保障。这可以防止密码猜测和网络钓鱼攻击，并且是一般安全最佳实践。在“**用户**”选项卡（****设置 > 用户****）中，将选项切换为“**要求所有用户进行两步身份验证**”。如果用户尚未配置多重身份验证，则将需要为其帐户配置多重身份验证。 ## 其他资源
