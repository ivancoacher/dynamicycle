## 概述

安全联系人可让您的公司指定特定帐户管理员作为来自 Klaviyo 的安全相关通信的主要联系人 - 例如违规警报、可疑活动警告和合规性请求。

默认情况下，每个 Klaviyo 帐户都会自动将帐户所有者设置为安全联系人。这意味着每个帐户都已经配置了一个安全联系人，即使您从未自己设置过。如果您希望其他管理员接收安全通信，您可以随时更新。

## 谁可以设置为安全联系人

如果用户满足以下所有条件，则可以被指定为安全联系人：

- 他们的角色是管理员或所有者，或者具有帐户设置编辑权限
- 他们的帐户处于活动状态
- 他们在过去 365 天内登录过
- 他们不属于受限制的员工角色

没有计费等级限制 - 免费和付费帐户均可使用此功能。

## 如何设置安全联系人

1. 导航至****帐户 > 设置 > 安全****。
2. 找到****安全联系人****字段。
3. 搜索并选择您要指定的管理员或所有者。
4. 保存您的更改。

管理员和所有者可以看到并编辑“安全联系人”字段。角色较低的用户将看不到或无法编辑此字段。

## 安全联系人更改时会发生什么

更新安全联系人后，之前的联系人和新分配的联系人都会收到一封电子邮件通知，通知他们发生了更改。

## 默认行为和自动验证

Klaviyo 自动将帐户所有者指定为所有新帐户和现有帐户的安全联系人。如果您尚未手动配置安全联系人，则您的所有者已被设置为默认联系人。

Klaviyo 还定期进行背景调查以验证指定的安全联系人。如果联系人无效（例如，如果他们的帐户被停用），Klaviyo 会自动将安全联系人恢复为帐户所有者。

## 未来会发生什么

安全联系人功能是 Klaviyo 平台的新增功能。目前，没有向该联系人发送具体通知。将来，Klaviyo 将开始向安全联系人发送特定的安全通知，包括：

- 可疑账户活动警告
- 异常登录尝试警报
- 提示采取安全措施，例如轮换暴露的 API 密钥
