## 你将会学到

了解 CSS 优化，这是确保您的电子邮件不会被夹在收件箱中的一种方法。

****为什么 CSS 优化很重要****

确保您的电子邮件到达收件箱对于电子邮件营销的成功至关重要。同样，确保您的电子邮件不被剪裁对于客户获取您邮件中的所有信息至关重要。 CSS 优化是您可以用来避免剪切的众多工具之一。

## 关于 Klaviyo 中的 CSS 优化

当您在帐户中构建电子邮件时，Klaviyo 使用称为嵌入样式的东西来添加您在“样式”和“阻止”选项卡中选择的品牌。

### 收件箱提供程序是否允许嵌入样式？

通过使用这些来自定义您的电子邮件，您的品牌电子邮件可以拥有尽可能小的文件大小，以防止它们被剪裁。最大的收件箱提供商（Gmail、Yahoo、Apple、Outlook、AOL）都接受并呈现嵌入样式。

较小的收件箱提供程序不会呈现嵌入样式。如果您发现[大量客户](https://help.klaviyo.com/hc/en-us/articles/115005258568-Review-Campaign-Analytics#advanced-reports--email-only-10)正在使用下面的收件箱提供程序或其他不呈现嵌入样式的提供程序，请考虑取消选中****CSS优化****框，以便您的电子邮件看起来像您设计的那样。

## 关闭 CSS 优化（和嵌入样式）

请注意，如果关闭嵌入样式，您的电子邮件将面临被其他收件箱提供商剪辑的风险，因此[在发送电子邮件之前测试您的电子邮件](https://klaviyo.zendesk.com/hc/en-us/articles/115005081907)。

1. 在左下角选择您的组织名称。
2. 单击 ****设置****。
3. 选择****电子邮件****选项卡。
4. 导航至****发送首选项****。
5. 取消选中标有“**启用嵌入样式**”的框。
6. 单击****保存。****
