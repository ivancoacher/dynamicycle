## 你将会学到

了解如何请求不同的支持和成功包。 Klaviyo 提供 3 个级别的支持和成功：

- 标准
- 专业
- 企业

想要了解更多有关不同级别包含哪些内容的信息？请联系您的 Klaviyo 支持代表。

## 开始之前

请注意，专业和企业支持和成功计划仅适用于每月支付一定金额以上的帐户。请参阅下表了解资格。

|  |  |  |  |
| --- | --- | --- | --- |
| ****每月计划总费用**** | ****标准**** | ****专业**** | ****企业**** |
|低于 5,000 美元 | ✔ | ✖ | ✖ |
| 5,000 美元至 9,999 美元 | ✔ | ✔ | ✖ |
| 10,000 美元或以上 | ✔ | ✔ | ✔ |

## 请求不同的支持计划

1. 在左下角选择您的组织名称。
2. 单击****计费 > 更改计划****。
3. 选择****当前计划**** 或****选择计划**** 分别保留当前计划或升级。
   ![账单概览页面顶部](https://klaviyo.zendesk.com/hc/article_attachments/28723662081947)
4. 在 **成功和支持包** 部分中，单击 ****编辑****。
   请注意，如果您不符合专业或企业计划的资格，则不会显示此部分。
   ![显示成功和支持包部分的结帐页面](https://klaviyo.zendesk.com/hc/article_attachments/28723662096283)
5. 选择符合条件的计划。
   ![所有成功和支持包的下拉菜单](https://klaviyo.zendesk.com/hc/article_attachments/28723662090779)
6. 点击****确认****完成****.****
