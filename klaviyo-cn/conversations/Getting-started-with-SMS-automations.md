只有所有者、管理员和经理才能访问此功能。 ## 你将会学到

了解 Klaviyo 中的自动化，您可以使用它与 SMS 订阅者创建自动的一对一对话。自动化让您可以轻松地提出问题、识别响应并为客户提供个性化建议。通过构建自动化，您可以：

- 创建调查以收集客户反馈。 - 建立提供个性化推荐的购买指南。 - 进行测验以了解有关订阅者的更多信息并收集个人资料属性。 ## 开始之前

请注意以下事项：

- 在使用自动化之前，您必须[设置短信](https://help.klaviyo.com/hc/en-us/articles/360035285472)。 - 自动化仅回复短信订阅者。 - 短信自动化不适用于[品牌发件人 ID](https://help.klaviyo.com/hc/en-us/articles/6637671573403#branded-sender-ids2)，因为此号码类型无法接收短信。 - 您的出站短信使用计费计划中的积分。 - 入站短信（即发送到您的品牌的消息）不消耗积分。 - 每个自动化必须至少包括：
  - 1 条消息。 - 或
  - 1 条建议，前面有问题。 ****流程与对话自动化****

在这两种情况下，这些功能都可以作为您与客户沟通的自动接触点，并可用于：

- 创建自定义消息
- 收集触发关键字和选项的配置文件属性
- 自动化通讯

它们之间的主要区别如下表所示。 |  |  |  |
| --- | --- | --- |
|  | ****流动**** | ****对话**** |
| ****触发**** |可以由客户在您的网站、细分和列表、日期等上的操作触发。仅当有人发送特定单词的短信时触发。 |
| ****消息类型**** |任何渠道（电子邮件、短信、移动推送）|仅短信 |
| ****响应时间**** |无法等待响应，消息总是立即发送或在设定的时间段内发送。 |等待订阅者的文本包含已识别的答案。 |

这意味着流程更适合在客户旅程的关键时刻接触订阅者（例如通过欢迎消息、废弃购物车提醒、购买后跟进）。至于自动化，它们更擅长处理来回沟通、提出问题和跟进建议。 ### 自动化示例：调查

自动化是一种对话式短信：假设您是一家宠物店，想要收集有关客户宠物的信息。在这种情况下，您可以发送短信活动，要求订阅者发送“PETS”一词以参与调查并接收自定义优惠券。当他们回复“PETS”时，订阅者进入自动化状态。 ![客户向您的品牌发送“PETS”一词](https://klaviyo.zendesk.com/hc/article_attachments/34179397822875)

然后，您可以询问他们养的是什么类型的宠物（1.猫，2.狗等）。如果需要，您可以问另一个问题（例如，它们的尺寸是多少？）。 ![自动化触发询问他们的宠物，顾客回复“狗”这个词，自动化询问宠物的大小](https://klaviyo.zendesk.com/hc/article_attachments/34179435230747)

在自动化结束时，您可以提供推荐（例如尺寸合适的床或安全带）以及您承诺的优惠券。 ![顾客回复Large后，自动化推荐Jumbo尺寸的狗床并提供优惠券](https://klaviyo.zendesk.com/hc/article_attachments/34179397838747)

这不仅有助于立即推动购买，您还可以存储此信息，以便将来发送更有针对性的消息。 ## 自动化的关键术语和设置

### 自动化功能

在设置自动化时，您必须具备 1 个或多个：

- ****触发关键字****
  要输入自动化的单词或短语订阅者文本。单个自动化可以有多个触发关键字。这些关键字必须是唯一的，同一单词不能在多个自动化中使用，也不能成为合规或订阅关键字。 - ****问题****
  您在自动化中发送的包含问题的短信。问题必须包括 2 个或更多选择。如果包含建议，则每个自动化至少需要 1 个问题。 - ****选择****
  订阅者如何回答问题的选项。选择总是编号的，订阅者可以通过文本发送选择的单词/短语或其相应的编号。 每个问题至少必须有 2 个选择。 - ****留言****
  自动化结束时发送短信。发送消息之前不需要提出问题。 - ****推荐****
  自动化结束时发送短信。在自动化结束时，您至少必须有至少 1 条建议。 ### 自动化设置

自动化具有以下关键设置：

- ****重新回复****
  这是发送给订阅者的回复，如果订阅者在自动化过程中发送了无法与选项匹配的入站文本。请参阅本节了解[如何识别选择](#h_01JMDF730GNVBDJ683KATS00D0)。 - ****后备响应****
  当某人达到最大重新提示次数或最大超时时发送的消息。 - ****最大重新提示次数****
  当用户发送不包含可识别的消息选项的入站 SMS 时，Klaviyo 尝试重新吸引用户的次数。默认情况下，该值设置为 1。如果订阅者达到此最大值，然后发送另一个无法识别的选择，他们将退出自动化并收到回退响应。 - ****最大超时（以小时为单位）****
  自动化的会话时间；即自动化活动的持续时间。默认情况下，会话时间设置为 24 小时。当有人发送触发关键字并收到第一条消息时，时间就开始计算。当有人收到后续消息时，时间不会重置。如果有人达到最大超时而没有收到建议，他们就会退出自动化。 #### 访问自动化设置

要访问所有自动化设置：

1. 单击自动化中的齿轮图标。 2. 选择****会话设置****。 ![齿轮图标下的会话设置选项](https://klaviyo.zendesk.com/hc/article_attachments/34179397843995)

## 自动化是如何工作的

它的工作原理是：

1. 有人向您发送自动化触发关键字的短信。 2. 如果他们是 SMS 订阅者，他们会收到自动发送的第一条消息。 1. 非 SMS 订阅者会从您的 SMS 设置中接收自动回复消息。 3. 如果订阅者以认可的选择进行响应，他们将继续处理下一个问题或消息
   1. 如果无法识别答案，他们会收到重新提示消息。 4. 当发生以下任何一种情况时，订阅者退出自动化：
   1. 订阅者收到推荐。 2. 订阅者收到消息。 3. 订阅者达到重新提示响应的最大数量，然后接收回退响应。 4. 订阅者达到最大超时时间。当某人处于自动化状态时，他们在退出之前无法进入任何其他自动化状态。 ## 触发自动化

### 触发器类型

有 2 种类型的触发器：

- ****永远在线****
  这意味着每当有人发送触发关键字的短信时，该人就会进入自动化状态。 - ****留言回复****
  使用此选项，您必须选择营销活动或流消息。要进入自动化，有人必须在设定的时间范围内收到所选消息并发送触发关键字。 ![自动化触发器类型](https://klaviyo.zendesk.com/hc/article_attachments/36044065155099)

这两种触发类型之间的主要区别在于，某人是否可以在客户旅程中的任何时刻进入，或者只能在收到另一条特定消息后进入。例如，当自动化充当支持工具、正在进行的测验或调查等时，“始终开启”会更好。在这种情况下，您可以根据常用文本单词或在商店中的特定表单上显示关键字时触发关键字。另一方面，当您想要推动营销活动或流程接收者使用自动化时，消息响应会更好。假设您只想调查最近收到欢迎系列第二条消息的人。在这种情况下，您可以制作第二条消息以包含触发关键字，并将自动化设置为仅发送给最近收到该消息的用户。 ![消息响应触发器，您可以在其中选择活动或流程](https://klaviyo.zendesk.com/hc/article_attachments/36044065161755)

### 触发关键词

SMS 订阅者在发送触发关键字时进入自动化状态。每个自动化可以有超过 1 个触发关键字。请注意触发关键字：

- 必须是 3 个或更多字符。 - 允许使用表情符号。 - 不区分大小写。 - 如果订阅者的入站消息与触发关键字完全匹配，则会被识别。 - 默认情况下不识别拼写错误或缩写。 - 可以是一个短语。 - 可以是一个单词。 - 每个自动化必须是唯一的（即，不能对多个自动化使用相同的关键字）。 - 无法链接到订阅或合规关键字（即 STOP、JOIN）。对于我们的宠物示例，假设我们使用 2 个单独的触发器，如下表所示。 |  |  |  |
| --- | --- | --- |
| ****触发关键词**** | ****认可**** | ****未识别**** |
|调查 |调查，调查|乌斯维 |
|宠物 |宠物 |宠物 |

对于触发器，我们建议使用简短、易于拼写的单词。如果您确实使用短语（例如“Quiz me”）或具有常见缩写的单词，请仅包含该短语或缩写的第一个单词作为另一个触发器（例如，同时使用“Quiz me”和“Quiz”）。 ## 问题、消息和建议

任何自动化中有 3 个选项，所有选项都是出站 SMS 消息：

- 问题
- 留言
- 推荐

所有自动化都需要至少 1 条消息或 1 条带有问题的建议。您可以在消息和推荐中使用模板标签（例如，名字）或 JSON，但请注意，这些标签和代码在预览中不可见。如果您想使用它们，请确保在向订阅者告知触发关键字之前测试实时自动化。 ### 问题

当您创建问题时，您必须：

- 问题文本（例如“您养的宠物是什么？”之类的问题）
- 2 个或更多选择（例如“猫”和“狗”）

例如，第一个问题可能会问某人有什么样的宠物。 |  |  |
| --- | --- |
|问题 | ****预览**** |
|你有什么宠物？ 1. 猫 2. 狗 3. 鸟 4. 其他 | ![询问某人宠物类型的消息预览](https://cdn.sanity.io/images/6ct6b26e/help-center-dev/7a27327fdf858a75118375fe82fca802d096d9b6-784x590.png) |

****自动化中我可以提出多少个问题？****

问题数量有限，具体取决于自动化触发器。始终在线 仅限 4 个问题。活动或流程仅限 3 个问题。但是，最佳做法是包含不超过 2 个问题。 ### 问题选择

选项按顺序编号，如上例所示。我们建议将每个问题的选项数量限制为 3-5 个。选择可以是：

- 单个单词或短语
- 任何大小写或大小写
- 认可：
  - 在较长的消息字内（即，自动检查订阅者的入站消息是否“包含”选择）。 - 由于模糊匹配，某些拼写错误（特别是超过 5 个字母的单词）可能会被识别。 - 作为选择文本或数字。继续宠物示例，自动化会将以下所有内容归因于第一个选择（“1.猫”）：
- 猫，猫，还是猫
- 1
- 我有一只猫
- 抓住

### 建议

您还必须为每个选择提供建议或使用默认建议。 ****什么是默认推荐？****

## 指标

任何自动化都有 3 个指标：

- ****开始自动化****
  当配置文件进入自动化时。 - ****实现自动化****
  当个人资料收到自动化的推荐时。 - ****结束自动化****
  当配置文件退出自动化时（例如，当他们超时或收到推荐时）。
