## 你将会学到

在本文中，您将了解客户代理的订阅技能如何工作以及运行它需要什么。这项技能可以让您的客户通过自助服务暂停、取消或更新他们的订阅交付首选项，从而减少支持请求数量、提高解决率，并通过使帐户管理变得顺畅来帮助您留住订阅者。 ## 开始之前

在设置订阅技能之前，请确认以下内容：

- ****客户代理****已在您的帐户上启用。 - ****客户中心**** 已激活并为您的店面进行配置。 - ****订阅提供商****已连接（例如 Recharge、Skio）。 Ordergroove 支持计划作为后续措施。 - 您已在客户代理内容设置中上传了有关您的订阅策略（取消规则、修改选项、常见问题解答）的****知识库内容****。 - ****可用性：**** 订阅技能适用于****网络聊天****、****短信****、****电子邮件****和****WhatsApp**** 渠道。所有角色均可查看技能； ****管理员****和****所有者****可以配置它。 - ****完成时间：**** 如果满足先决条件，大约需要 5-10 分钟。 ****重要：**** 代理不会直接修改订阅。它通过正确的上下文和链接引导客户访问您的订阅门户。如果没有客户中心或连接的订阅提供商，代理将执行向人工代理的软切换。 ****注意：**** 代理可见的订阅数据取决于您的提供商。 Recharge 返回活动、暂停和取消的订阅。 Skio 返回****仅限活动订阅**** — 暂停和取消的订阅无法通过 Skio 的 API 获得。有关详细信息，请参阅[按提供商提供的订阅可见性](#subscription-visibility-by-provider)。 ## 概述

订阅技能使客户代理能够端到端处理与订阅相关的查询——从回答政策问题到显示经过身份验证的自助服务链接。客户无需等待人工代理，即可立即获得有关如何暂停、取消、更改频率、交换产品或更新付款和运输详细信息的指导。 ### 什么时候使用这个技能

当您的客户提出以下问题时，客户代理将使用订阅技能：

- “如何取消订阅？”
- “我想更新我的送货频率。”
- “我的订阅仍然有效吗？”
- “我可以更改订阅中的产品吗？”
- “如何更新我的付款信息？”

### 它与相邻技能有何不同

- ****退货和换货技能**** -- 处理一次性订单的购买后退货和换货请求。订阅技能特别关注定期订阅管理。 - ****订单编辑技能**** -- 在履行之前处理一次性订单的更改。订阅技能涵盖正在进行的订阅修改。 - ****一般问答技巧**** -- 从您的知识库回答一般品牌问题，无需身份验证。订阅技能将知识库答案与经过身份验证的、特定于帐户的订阅数据相结合。 ### 提供商的订阅可见性

代理会显示从您的提供商处收到的所有订阅状态。然而，每个提供商的 API 返回不同的数据：

|供应商|活跃|暂停 |取消 |
| --- | --- | --- | --- |
| ****充电**** |是的 |是的 |是的 |
| ****滑雪**** |是的 |没有 |没有 |
| ****订购槽**** |计划|计划|计划|

- ****Recharge**** 返回活动、暂停和取消的订阅。代理可以回答有关所有订阅状态的问题并显示每个状态的卡片。 - ****Skio**** 返回****仅限活跃订阅****。如果客户询问暂停或取消的订阅，代理无法检索它，并且可能会报告未找到订阅。考虑添加知识库内容，解释客户如何联系支持人员解决有关非活动 Skio 订阅的问题。 - ****Ordergroove**** 集成计划作为后续行动。 ### 代理如何处理订阅查询

1. 客户询问订阅事宜（例如，“如何暂停订阅？”）。 2. 代理使用****Klaviyo - 搜索内容**** 在您的知识库中搜索订阅策略。 3. 如果问题是特定于帐户的，客服人员会检查客户是否已登录。如果没有，则会提示客户登录。 4. 登录后，代理将使用 ****Klaviyo - 获取个人资料**** 检索客户的个人资料。 5. 代理调用只读工具来检查订阅状态，确认注册和当前计划详细信息。这可以防止代理为没有有效订阅的客户提供空的订阅卡。 6. 代理提供直接链接或按钮来管理订阅：

   - ****在网络聊天上：**** 显示订阅详细信息和订阅门户链接的订阅卡或轮播。 - ****关于短信和 WhatsApp：**** 指向客户中心“为您”页面的链接，客户可以在其中管理他们的订阅。 - ****通过电子邮件：**** 指向客户中心“为您”页面的链接，其中包含简短回复。 7. 代理清楚地传达可用的操作（暂停、取消、更新频率、更改产品、编辑付款或运输详细信息）。 ## 设置

### 第 1 步：连接您的订阅提供商

1. 在 **设置集成** 中，确认您的订阅提供商（例如 Recharge 或 Skio）已连接并处于活动状态。预期结果：集成状态显示****已连接****。 ****注意：**** 如果您没有连接订阅提供商，则订阅技能将不可用。相反，代理将向人工代理执行软切换以进行订阅查询。 ### 第 2 步：验证客户中心是否处于活动状态

1. 在 **客户中心设置** 中，确认客户中心已启用并且您的店面已连接。预期结果：客户中心状态显示****活动****。 [屏幕截图：客户中心设置页面显示活动状态]

### 第三步：上传订阅知识库内容

1. 导航至 **客户代理内容**。 2. 上传或验证是否包含您的订阅政策文件。这些应涵盖：

- 取消政策和任何所需的通知期
- 暂停和跳过选项
- 频率变化规则
- 产品交换或附加政策
- 付款和运输更新程序

预期结果：您的订阅相关内容出现在内容库中，可供客服人员搜索。 ****提示：**** 您的订阅策略内容越具体、越完整，代理在需要将客户引导至门户之前就能更好地回答问题。 ### 步骤 4：确认技能已激活

1. 导航至 **客户代理技能**。 2. 在技能列表中找到****订阅****技能。当满足您的先决条件时，它默认处于活动状态。 3. 确认状态显示****Live****。如果显示****不可用****，请检查客户中心是否处于活动状态并且订阅提供商是否已连接。预期结果：订阅技能在您的技能概览中显示 ****Live**** 状态。 [屏幕截图：技能概述页面显示具有实时状态的订阅技能]

### 第 5 步：测试技能

1. 在网络聊天、短信、电子邮件或 WhatsApp 频道上打开测试对话。 2. 提出与订阅相关的问题（例如，“如何取消订阅？”）。 3. 验证客服人员是否回复了政策信息，并在登录后出示订阅卡（网络聊天）或客户中心链接（短信、WhatsApp、电子邮件）。预期结果：代理提供准确的策略信息和管理订阅的工作链接。 [屏幕截图：显示带有订阅详细信息和管理链接的订阅卡的网络聊天]

## 最佳实践

- ****保持订阅政策内容最新**** -- 每当您更改订阅条款时，请查看并刷新您的知识库内容。过时的政策会导致客服人员做出错误的反应并导致客户感到沮丧。影响：解决率、客户满意度。 - ****涵盖您知识库中的所有常见场景**** -- 包括暂停、取消、频率更改、产品交换和支付更新的内容。代理可以仅根据内容回答的场景越多，升级到人工代理的次数就越少。影响：票据偏差、解决率。 - ****为边缘情况配置切换消息**** -- 设置明确的切换指令，以便当代理无法解决订阅问题（例如，没有连接订阅提供商）时，客户会收到有用的消息并顺利过渡到人工代理。影响：客户满意度。 - ****将此技能与退货和换货一起使用**** -- 想要取消订阅的客户实际上可能更喜欢暂停或产品交换。 当满足先决条件时，这两种技能都会自动激活，因此代理可以建议替代方案。影响：订阅保留。 - ****通过主动消息传递促进自助服务**** -- 让订阅者知道他们可以通过任何客户代理渠道（网络聊天、短信、电子邮件或 WhatsApp）管理订阅。在订阅确认电子邮件或续订提醒中添加备注。影响：票据偏差、客户满意度。 ## 衡量成功

### 在哪里查看结果

- 导航至 **客户代理绩效** 以查看与订阅相关的查询的对话量、解决率和移交率。 - 通过比较启用该技能之前和之后与订阅相关的工单数量，查看帮助台或支持平台中的工单偏转趋势。 ### 需要关注的关键指标

|公制|它告诉你什么 |
| --- | --- |
| ****分辨率**** |代理在没有人工交接的情况下解决的订阅查询的百分比
| ****票偏转**** |减少与订阅相关的支持请求|
| ****订阅保留**** |自助服务管理是否会减少客户流失还是增加取消？
| ****切换率**** |代理升级为人工代理的频率 - 越低越好 |

### 如果指标较低，请尝试这些修复

- ****低分辨率**** -- 将更详细的订阅政策内容添加到您的知识库中。检查您的订阅提供商集成是否处于活动状态并正确返回数据。 - ****高切换率**** -- 检查切换触发器。确保客户中心和您的订阅提供商正确连接，以便代理可以提供自助服务链接。 - ****票务偏转没有变化**** -- 向现有订户推广自助服务渠道。检查您的网络聊天、短信、电子邮件或 WhatsApp 渠道是否可以从客户通常寻求订阅帮助的页面访问。 ## 故障排除

****症状：**** 代理不显示订阅详细信息并立即转交给人工代理。 ****可能的原因：**** 客户中心未激活，或未连接订阅提供商。 ****修复：**** 导航至 **客户中心设置** 并确认客户中心已启用。然后检查 **设置集成** 以验证您的订阅提供商（例如 Recharge）显示 ****已连接**** 状态。一旦两者都处于活动状态，订阅技能将自动变为可用。 ---

****症状：**** 尽管客户已订阅，但代理仍显示“未找到有效订阅”。 ****可能的原因：**** 客户未登录，或者客户在 Klaviyo 中的电子邮件与订阅提供商帐户关联的电子邮件不匹配。 ****修复：**** 确保客户完成登录流程。验证 Klaviyo 个人资料上的电子邮件地址是否与订阅提供商帐户匹配。如果存在不匹配，客户可能需要在其中一个系统中更新其电子邮件，或者人工代理可以提供帮助。 ---

****症状：**** 客户询问暂停或取消订阅的情况，但代理表示未找到订阅。 ****可能的原因：**** 您的帐户使用 Skio 作为订阅提供商。 Skio 的 API 仅返回活动订阅 - 代理无法使用暂停和取消的订阅。 ****修复：**** 这是 Skio API 的已知限制。添加知识库内容，指示代理引导已暂停或取消 Skio 订阅的客户联系您的支持团队或直接访问订阅门户。如果您需要全面了解所有订阅状态，Recharge 可提供活动、暂停和取消的订阅数据。 ---

****症状：**** 代理响应中的订阅门户链接导致页面损坏或 404 错误。 ****可能的原因：**** 客户中心中配置的订阅门户 URL 不正确或已过时。 ****修复：**** 导航到 **客户中心设置** 并验证订阅门户 URL。直接在浏览器中测试链接以确认其解析。如果您的订阅提供商更改了其门户路径，请更新 URL。 ---

****症状：**** 代理回答订阅政策问题，但从不提示客户登录或出示订阅卡。 ****可能的原因：**** 代理将查询视为一般知识库问题，而不是特定于帐户的订阅请求。 ****修复：**** 检查客户的消息措辞。 代理区分一般政策问题（“您的取消政策是什么？”）和帐户特定请求（“我想取消我的订阅”）。对于特定于帐户的请求，代理应提示登录。如果没有，请检查订阅技能是否在 **客户代理技能** 中显示 ****Live**** 状态，以及您的订阅提供商是否已连接。 ---

****症状：**** 在短信或 WhatsApp 上，客户收到纯文本回复，没有指向客户中心的链接。 ****可能的原因：**** 客户未登录，或未为您的帐户配置客户中心。 ****修复：**** 确认客户中心处于活动状态并支持您的订阅提供商。确保客户在代理尝试检索订阅数据之前完成身份验证。在短信和 WhatsApp 上，当找到订阅时，代理会链接到客户中心的“为您”页面。 ## 常见问题解答

****问：代理可以直接代表客户取消或暂停订阅吗？****
****答：**** 不会。代理提供订阅数据的只读访问权限，并引导客户访问订阅门户，他们可以在其中自行采取行动。此设计可确保订阅修改通过提供商的标准工作流程，保留您配置的任何确认步骤或保留优惠。 ****问：支持哪些订阅提供商？****
****答：**** 发布时支持 Recharge 和 Skio。 Ordergroove 集成计划作为后续行动。您的订阅提供商必须通过 Klaviyo 的集成进行连接并链接到客户中心。 ****问：代理可以看到暂停和取消的订阅吗？****
****答：**** 这取决于您的提供商。 Recharge 返回活动、暂停和取消的订阅，以便代理可以显示所有订阅。 Skio 仅通过其 API 返回活动订阅 - 代理无法检索暂停或取消的 Skio 订阅。如果您使用 Skio，请添加知识库内容，以帮助客服人员指导对您的支持团队或门户进行非活动订阅的客户。 ****问：客户是否需要登录才能让代理帮助进行订阅？****
****答：**** 对于一般政策问题（例如，“您的取消政策是什么？”），无需登录 - 客服人员会根据您的知识库进行回答。对于特定于帐户的请求（例如，“我想暂停我的订阅”），代理会提示客户登录，以便检索其订阅详细信息并提供个性化的自助服务链接。 ****问：如果客户询问订阅但没有订阅，会发生什么情况？****
****A:**** 客户登录后，代理会检查活动订阅。如果没有找到，代理会通知客户没有与其帐户关联的有效订阅，并提供帮助解决其他问题。 ****问：订阅技能是否适用于所有频道？****
****答：**** 订阅技能可在 ****网络聊天****、****短信****、****电子邮件**** 和 ****WhatsApp**** 上使用。在网络聊天中，代理会显示带有详细信息和管理链接的订阅卡或轮播。在短信和 WhatsApp 上，客服人员会提供指向客户中心“为您服务”页面的链接。通过电子邮件，代理会发送简短的回复，其中包含指向客户中心的链接。 ****问：代理在检查订阅时会访问哪些数据？****
****A:**** 代理进行只读 API 调用来检索订阅状态、计划详细信息和注册信息。它没有写入权限，也不能修改任何订阅数据。在访问任何特定于帐户的数据之前，客户必须进行身份验证。 ## 后续步骤

- ****设置客户中心****，确保您的客户拥有一个自助服务门户来管理订阅、订单和帐户详细信息。 - ****连接您的退货提供商****，以便激活退货和换货技能，并且代理可以处理更广泛的购买后查询以及订阅。 - ****上传全面的知识库内容****涵盖所有订阅场景，最大限度提高座席的解决率。 - ****配置客户代理交接**** 定义订阅查询如何以及何时升级给人工代理。 - ****在一到两周后查看您的订阅分析****，以确定内容或配置中的差距。 ## 其他资源
