## 你将会学到

在本文中，您将了解如何删除商品、调整数量、更改地址或取消 Shopify 订单 - 所有这些都无需离开服务台。就地完成编辑可以缩短平均解决时间、减少手动错误，并帮助您提供更好的客户体验。

## 在开始之前，请确认：

- 您已将 Shopify 与 Klaviyo 集成。
- 您可以在对话中看到****订单部分****。
- 订单必须****开放****且未完全履行。锁定订单无法编辑。

## 概述

**编辑订单****模式可让您执行最常见的中期履行修复 - 更改数量、编辑送货地址或取消订单。由于该模式通过 REST Admin API 直接写入 Shopify，因此编辑是实时的。当您在帮助客户的同时需要更正订单时，请使用它。

![屏幕截图 2025-10-23 6.29.03 PM.png](https://klaviyo.zendesk.com/hc/article_attachments/42876399554587)

## 设置

1. 在帮助台中，打开包含需要更改的 Shopify 订单的对话。
2. 在****订单卡****中，选择****编辑订单****。

   - ****预期结果：**** ****编辑订单**** 模式打开并从 Shopify 获取最新订单数据。
3. 在****项目****选项卡上：
   1. 要更改数量，请使用项目旁边的 ****+ / –**** 控件。
   2. 要删除项目，请单击垃圾桶图标。
4. 在****地址部分，****单击铅笔图标以编辑尚未发货的订单的地址。
   ![屏幕截图 2025-10-23 6.28.49 PM.png](https://klaviyo.zendesk.com/hc/article_attachments/42876399555611)
5. 查看更改，然后选择****编辑订单**** 保存更改。****成功标准：**** 您会看到绿色的“订单已更新”提示框。

****注意****：如果****编辑订单****按钮呈灰色，请将鼠标悬停以查看原因（订单已锁定或权限被拒绝）。

## 最佳实践

- 让客户随时了解情况——保存后立即发送一条快速确认消息。
- 使用****撤消****选项进行快速反转，而不是编辑两次。

## 常见问题解答

还没有。退款必须在 Shopify 中处理。
