> ****Beta 功能。**** 从头开始​​创建完全自定义的工具目前处于封闭管理测试阶段。如果您在客户代理中没有看到“工具”页面，则您的帐户尚不具备测试版访问权限。 ## 你将会学到

如何使用完全自定义的工具将客户代理连接到任何 HTTP 端点，编写客户代理将实际使用的工具描述，并在将工具附加到技能之前测试您的工具。 ## 开始之前

你需要：

- 启用客户代理和测试版访问权限，以创建完全自定义的工具
- 您希望客户代理调用的 HTTP 端点 — **** 不需要秘密凭证（API 密钥、不记名令牌等）即可立即访问的端点****（经过身份验证的端点即将推出，请参阅下面的警告）
- 附加该工具的技能 - 客户代理附带的技能或您创建的完全自定义技能

如果您还没有设置技能，请先创建一个。工具本身并不能做任何事情——它们必须依附于技能。 > ****警告：**** API 密钥和其他机密的安全存储即将推出。在发布之前，请勿将 API 密钥、不记名令牌或其他敏感凭证放入完全自定义的工具中 - 工具配置还不是存储它们的安全位置。目前，仅使用具有无需秘密身份验证即可安全调用的端点的工具（例如，IP 白名单后面的内部端点或接受非敏感标识符的端点）。对经过身份验证的端点的支持正在进行中。 ## 什么是完全自定义工具

完全自定义的工具是客户代理可以在对话期间发出的 HTTP 请求。创建完全自定义的工具处于测试阶段，在我们扩展该功能时，仅向有限的品牌提供。当客户代理附带的工具不能满足您的需求时，请使用其中之一 - 例如，在您自己的订单管理系统而不是 Shopify 中查找订单，在自定义仓库系统中检查库存，或者在 Klaviyo 本身未集成的服务台中创建票证。有关基本概念，请参阅了解客户代理工具文章。 ## 何时创建完全自定义的工具

在以下情况下使用完全定制的工具：

- ****您需要来自 Klaviyo 尚未集成的系统的实时数据****
- ****您希望客户代理在外部系统中采取操作****（取消专有系统中的订阅、创建票证、更新记录）
- ****现有工具不适合**** — 例如，您使用自定义 OMS 而不是 Shopify 来处理订单

如果信息不经常更改并且对于每个客户都相同，请将其添加为内容。工具用于动态的、针对每个客户的数据和操作。 ## 设置

### 1. 打开工具页面

导航到****客户代理 > 工具****，然后单击****创建工具****。 ### 2. 命名并描述该工具

- ****名称**** — 一个简短的标识符，例如“获取库存”或“创建回程票”。
- ****描述**** — 自然语言解释该工具的用途以及何时使用它。客户代理阅读此描述来决定是否针对给定请求使用该工具。具体一点。一个很好的描述示例：

> 从仓库系统获取给定产品 SKU 的实时库存计数。当购物者询问特定产品是否有库存时使用。模糊的描述示例（避免）：

> 获取产品信息。 ### 3.配置HTTP请求

- ****方法**** — GET、POST、PUT、DELETE 或 PATCH。 - ****URL**** — 完整端点 URL。您可以包含动态值的占位符（请参阅步骤 5）。 - ****标头**** — 您的端点需要的任何标头，包括“Content-Type”和身份验证标头。 ### 4.配置请求正文（对于POST、PUT、PATCH）

提供 JSON 正文。使用占位符来表示客户代理应在运行时填写的值。示例正文：

{
"客户\_id": "{{个人资料\_id}}",
"sku": "{{产品\_sku}}"
}

### 5. 使用占位符表示动态值

客户代理可以在运行时使用占位符填充值。常见占位符：

- `{{profile_id}}` — 对话中客户的 Klaviyo 个人资料 ID
- `{{conversation_id}}` — 当前对话 ID
- 您在输入架构中定义的任何参数（例如，“{{product_sku}}”、“{{order_id}}”）

占位符在 URL、标头和正文中起作用。 ### 6. 身份验证

对经过身份验证的端点的支持即将推出。在此之前，请勿将 API 密钥、不记名令牌或其他机密放入完全自定义的工具中。 仅使用无需秘密凭据即可安全调用的端点 - 例如，受 IP 白名单保护的内部端点或接受非敏感标识符的公共端点。安全秘密存储即将推出，并将解锁经过身份验证的端点。 ### 7. 测试工具

单击****测试工具****。为任何输入参数提供示例值。检查：

- 响应成功返回
- 响应格式是客户代理所期望的
- 处理任何错误情况

### 8.保存并附加到技能

单击****保存****。要使客户代理实际使用该工具，请打开您要使用它的技能并在其中添加该工具。 ## 写一个好的工具描述

描述是最重要的字段。客户代理完全根据描述（而不是名称）来选择要使用的工具。好的描述：

- 用一句话说出****该工具的用途****
- 用一句话说****何时使用****
- 具体说明返回的数据或采取的操作

不好的描述是模糊的（“获取客户信息”），太宽泛（“处理与订单相关的任何事情”），或者告诉客户代理如何行为而不是工具做什么。 ## 安全考虑

- ****不要对需要秘密凭证的端点使用完全自定义的工具。**** 对经过身份验证的端点的支持即将推出。在发布之前，仅使用无需秘密身份验证即可安全调用的端点。 - ****尽可能使用 IP 白名单。**** 如果您的端点是内部端点，请限制对 Klaviyo IP 范围的访问，而不是依赖机密。 - ****注意您发送的数据。**** 客户代理根据技能说明将客户数据传递到工具中。查看您的端点收到的字段。 - ****速率限制。**** 如果您的端点有速率限制，请确保它们足够高以处理您预期的对话量。 ## 故障排除

****症状：**** 客户代理从不使用该工具。 ****可能的原因：**** 描述太模糊，或者该工具未附加到使用它的技能上。 ****修复：**** 重写描述以具体描述何时应该使用它。确认该工具出现在技能的工具列表中。 ****症状：**** 该工具在测试期间返回错误。 ****可能的原因：**** 错误的 URL、格式错误的正文或您的端点不接受的有效负载。 ****修复：**** 使用测试工具功能检查原始请求和响应。根据端点的预期输入验证 URL 和正文格式。 ****症状：**** 客户代理使用该工具但传递了错误的参数。 ****可能的原因：**** 占位符名称与模式不匹配，或者技能说明不清楚要传递的内容。 ****修复：**** 检查占位符名称是否完全匹配。更新技能说明，明确何时使用该工具以及提供哪些参数。 ****症状：**** 该工具速度缓慢，导致响应延迟。 ****可能的原因：**** 端点延迟。 ****修复：**** 优化您的端点。检查您是否可以在您这边缓存结果。 ## 常见问题解答

****一种工具可以被多种技能使用吗？****
是的。创建后，工具可以附加到任意数量的技能。 ****支持哪些身份验证方法？****
对经过身份验证的端点的支持即将推出。目前，使用不需要秘密凭据的端点（具有 IP 白名单的内部端点，或具有非敏感标识符的公共端点）。 ****如果我的端点关闭或返回错误会发生什么？****
完全自定义工具的错误处理尚未构建。如果您的端点出现故障，客户代理可能会产生降级或混乱的响应。在错误处理发布之前，仅使用您有信心的端点 - 并密切监视工具行为。 ****创建工具后我可以编辑它吗？****
是的。您可以随时编辑名称、描述、配置和附加技能。 ****我可以对工具进行版本控制吗？****
尚不支持版本控制。对工具的编辑会立即在使用该工具的每个技能中生效。
