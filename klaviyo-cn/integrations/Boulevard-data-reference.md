## 你将会学到

了解将 Boulevard 与 Klaviyo 帐户集成时同步的数据。当您集成时，我们会同步 Boulevard 中存储的所有历史数据，然后实时同步正在进行的数据。 ## 如何查看您的数据

要查看您的 Boulevard 数据：

1. 单击左侧导航侧栏中的****分析****下拉列表。 2. 选择****指标****。在这里，您可以查看帐户中的所有指标。带有 Boulevard 图标的指标代表从 Boulevard 集成同步的所有指标。 3. 使用搜索栏旁边的过滤器选择器过滤此视图以仅查看 Boulevard 指标。 ![在 Klaviyo 的“指标”页面上找到的 Boulevard 指标列表。](https://klaviyo.zendesk.com/hc/article_attachments/28723545640987)

## 预约指标

### 已预约

当客户预订新预约时，系统会跟踪此事件。 - ****员工姓名****
  与任命相关的工作人员名单。 - ****服务名称****与预约相关的服务列表。 - ****开始于****约会的开始日期时间戳（UTC 格式），即 **YYYY-MM-DDThh:mmTZD。**

- ****结束于**** UTC 格式的约会结束日期时间戳，即 **YYYY-MM-DDThh:mmTZD。**

- ****订单 ID ****与预约关联的购买 ID。 - ****地点名称****与约会相关的地点的名称。 - ****位置 ID ****与位置关联的 ID。 - ****持续时间**** 约会的持续时间（以分钟为单位）。 - ****预订人****预订预约的人，例如**客户**。 ### 取消预约

### 已下订单

当客户通过 Boulevard 下订单并完成付款时，系统会跟踪此事件。订单可以包括零售产品、礼品卡或服务。 - ****应用优惠券****
  适用于购买的任何优惠券的列表。 - ****关闭者****关闭购买的工作人员的姓名。 - ****订单 ID ****与购买关联的订单 ID。 - ****位置名称****与订单关联的位置的名称。 - ****位置 ID ****与订单关联的位置的 ID。 - ****订单号****与订单关联的唯一编号。 - ****摘要****付款详细信息列表，包括折扣、小费、小计和总计。 - ****行组****与订单关联的项目列表。 - ****注释****与订单相关的任何注释的列表。 - ****退款****已退款的所有商品的列表。 - ****总计****订单的总价值。 ## 同步的客户端数据

Klaviyo 使用电子邮件、名字和姓氏、电话号码为每个客户创建或更新个人资料，并将设置以下自定义个人资料属性：

- ****预约计数****
  约会总数。 - ****大道ID****
  分配给 Boulevard 中的客户端的 ID。 - ****电子邮件营销****客户是否选择接收营销电子邮件。 （正确/错误）

- ****短信营销****客户是否选择接收营销短信。 （正确/错误）

- ****推送营销****客户是否可以接收营销推送通知。 （正确/错误）

- ****电子邮件提醒****客户是否可以接收交易电子邮件。 （正确/错误）

- ****短信提醒****客户端是否可以接收交易短信。 （正确/错误）

- ****推送提醒****客户端是否可以接收事务推送通知。 （正确/错误）

- ****Boulevard 标签****在 Boulevard 中分配给客户端的任何标签。 - ****生日****客户的出生日期。 - ****主要地点名称****客户接受服务的主要地点。 - ****主要位置 ID****客户端主要位置的 ID。 Klaviyo 还将电子邮件和短信同意从 Boulevard 同步到 Klaviyo 个人资料。 ## 其他资源
