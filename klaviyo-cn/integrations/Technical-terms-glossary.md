## 你将会学到

以下术语表概述了首次学习 Klaviyo 的 API 时需要熟悉的基本技术术语。正在寻找 Klaviyo 特定术语的词汇表？查看我们的 [Klaviyo 术语表](https://help.klaviyo.com/hc/en-us/articles/115005251588-Klaviyo-Glossary)。

### 一个

- ****API**** - 应用程序编程接口。允许一个软件与另一个软件对话并在它们之间传递信息。
- ****身份验证****- 在尝试连接到 API 时验证您的凭据，帮助确保您的帐户安全。

### C

- ****客户端****- 您（最终用户）用于通过 API 与 Klaviyo 进行通信的硬件或软件。

### D

- ****DELETE**** - HTTP 方法允许您从 Klaviyo 帐户中删除资源。

### E

- ****端点****- 可以访问您的资源的 Klaviyo 服务器的 URL。

### G

- ****GET****- HTTP 方法允许您从 Klaviyo 帐户检索或读取数据。

### H

- ****HTTP****- 用于客户端和服务器之间交换数据的标准 Web 协议。
- ****HTTP 方法****- 用于限制您进行的 API 调用类型的动词或操作。

### J

- ****JSON****- JavaScript 对象表示法。一种用于存储数据并将其从服务器传输到客户端或网页的格式。

### L

- ****语言库****- 在计算机编程中，程序使用的预编译例程的集合。
- ****Lists API**** - Klaviyo 用于管理列表的 API。

### P

- ****参数****- 可包含在 API 调用中以影响响应的变量选项
- ****PATCH****- 允许您修改资源的 HTTP 方法。
- ****POST****- HTTP 方法允许您创建新资源或将新资源写入您的 Klaviyo 帐户。
- ****Postman****- 可用于进行API调用的第三方软件。
- ****PUT****- 允许您更新 Klaviyo 帐户中现有资源的 HTTP 方法。

### R

- ****REST****- 代表性状态转移。使系统更容易相互通信的编程架构。
- ****响应****- 对 API 请求的答复，以可读格式返回所请求的资源。

### S

- ****服务器****- 管理资源并向客户端提供功能的计算机硬件或软件。

### W

- ****Webhook****- 允许应用程序在彼此之间实时传输数据。
