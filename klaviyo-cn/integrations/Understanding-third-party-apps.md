## 你将会学到

了解如何查找第三方应用程序，这些应用程序是由第三方（而不是 Klaviyo）使用 Klaviyo 的 API 构建的应用程序。 Klaviyo 的 API 使各种第三方能够构建应用程序并与我们的平台集成。您可以在我们的[应用程序市场](https://marketplace.klaviyo.com/en-us/)中搜索 Klaviyo 构建的集成并选择第三方应用程序。如果您正在寻找在我们的市场上找不到的应用程序，我们建议您直接联系该平台。

## 查找第三方应用

要查找第三方应用程序：

1. 在 Klaviyo 中，选择****集成****选项卡。
2. 单击****探索应用程序****。
3. 您将被带到我们的应用程序市场，您可以在其中浏览和搜索应用程序。
   ![](https://klaviyo.zendesk.com/hc/article_attachments/39451226896539)
4. 选择一个应用程序以了解有关它的更多信息。
   ![](https://klaviyo.zendesk.com/hc/article_attachments/39451202479003)

## 在哪里可以找到帮助资源

所有 Klaviyo 构建的（或“本机”）集成在我们的帮助中心都有帮助文档，而第三方应用程序则没有。您可以在[集成部分](https://help.klaviyo.com/hc/en-us/categories/115000032731-Ecommerce-Integrations)中找到 Klaviyo 构建的集成的集成指南。对于第三方应用程序，文档链接在我们市场中各个应用程序页面的**帮助资源**下。
