## 你将会学到

了解如何将 NeonCRM 与 Klaviyo 集成，以便根据每个贡献者的捐赠和活动注册活动个性化和定位电子邮件。从 NeonCRM 同步到 Klaviyo 的数据包括：

- 发生捐赠时，提供有关捐赠的详细信息
- 联系信息，包括名字和姓氏、位置和自定义字段
- 当有人注册参加活动时，提供有关注册的详细信息

## 将 NeonCRM 与 Klaviyo 集成

1. 在 Klaviyo 中，选择****集成****选项卡。 2. 单击****探索应用程序****，搜索 **NeonCRM**，然后单击该卡。然后，单击****安装****。 3. 您将需要 NeonCRM API 密钥和组织 ID。要生成 NeonCRM API 密钥，请打开一个新选项卡并登录到您的 NeonCRM 系统。 4. 导航至****系统设置 > 系统用户****。 5、点击****新用户****；您可以为该用户命名任何您喜欢的名称，但我们建议为该用户命名一些能够区分其用途的名称，例如 **Klaviyo** **API User**。 6. 指定用户名和密码。 7. 单击复选框为此用户帐户启用 API 访问。 8. 输入电子邮件地址；该地址将接收来自 NeonCRM 团队的与 API 相关的警报和更新。 9. 点击****生成****来创建您的API密钥；您需要复制此 API 密钥以粘贴到 Klaviyo 中。 10. 单击****下一步**** 完成创建此用户的过程。 11. 切换回 Klaviyo 并粘贴您的 API 密钥。 ![](https://klaviyo.zendesk.com/hc/article_attachments/28722594435995)
12. 要查找您的组织 ID，请导航至 NeonCRM 系统的登录屏幕。 13. 在网络浏览器中查看 URL； /clients/ 之后和 /login.jsp 之前的文本是您的组织 ID。 14. 将您的组织 ID 复制并粘贴到 Klaviyo 中。 15. 单击****连接到 NeonCRM****。 16. 如果您要将 NeonCRM 帐户添加到 Klaviyo 中的列表，请选中此设置并选择一个列表。 17. 单击****完成设置****。 ## 添加 Klaviyo 现场跟踪

最后一步是将 Klaviyo 的 A**active on Site** 跟踪代码添加到您的网站页脚。此代码片段将使 Klaviyo 能够跟踪 **Active on Site** 指标，以便您可以利用与已知浏览器的网站访问和行为相关的数据。例如，您可以使用**网站活跃**指标来创建访问过您的网站（登录时）但尚未捐款的用户细分。 1. 复制下面的 **Active on Site** 跟踪代码片段：

   ````
   <script type="application/javascript" async src="https://static.klaviyo.com/onsite/js/klaviyo.js?company_id=Public API Key"></script>
   ````
2. 将代码片段粘贴到应用程序主模板中的 </body> 标记之前。 3. 将代码片段中的“公共 API 密钥”替换为您自己的 Klaviyo 公共 API 密钥，该密钥可以在****帐户名称 > 设置 > API 密钥****下找到。 4. 在 Klaviyo 中，选择****集成****选项卡。 5. 在右上角，单击****管理数据> 设置网络跟踪****。 6. 如果工作成功，将出现带有绿色复选标记的成功页面。 ![neon.jpg](https://klaviyo.zendesk.com/hc/article_attachments/34274027896859)

## 监控 Klaviyo 同步

要通过 NeonCRM 集成检查数据同步：

1. 单击 Klaviyo 中的****分析****下拉列表，然后选择****指标****。 2. 单击 **Made Contribution** 指标以验证是否已填充该指标的数据；请注意，您的初始 NeonCRM 集成同步可能需要长达几个小时，具体取决于您帐户中的数据量。 3. Klaviyo 将导入您所有的 NeonCRM 历史数据；为了验证这一点，您可以将 Klaviyo 中特定日期的贡献数量与您的 NeonCRM 帐户中的数量进行比较，并确认它们匹配。 4. 如果不匹配，则问题很可能是您的 Klaviyo 帐户的时区与您的 NeonCRM 时区不匹配。 5. 要检查您在 Klaviyo 的时区设置：
   - 单击左下角您的帐户名。 - 选择然后单击****设置**** ****> 组织****。 - 向下滚动到**时区**。 ## 从 NeonCRM 同步的数据

有两个主要指标从 NeonCRM 同步到 Klaviyo：**做出的贡献**和**注册** **活动**。 ![Klaviyo 中的指标页面显示 NeonCRM 指标做出贡献并注册活动](https://klaviyo.zendesk.com/hc/article_attachments/28722594432027)

NeonCRM 中的指标和配置文件属性每 30 分钟同步一次。 ### 做出贡献

当支持者在 NeonCRM 中做出贡献时，就会跟踪此事件。 Klaviyo 跟踪的事件包括 NeonCRM 收集的所有信息，您可以根据以下条件过滤和定位 **Made Contribution** 事件：

- ****匿名捐赠****
  表明该捐赠者是否希望保持匿名（是/否）
- ****活动结束日期****
  活动结束日期（如果有）
- ****活动目标****
  活动目标（如果有）
- ****活动名称****
  活动名称
- ****活动开始日期****
  活动开始日期（如果有）
- ****捐款金额****
  捐赠价值
- ****捐赠日期****
  捐赠事件时间戳
- ****捐赠 ID****与捐赠活动相关的 ID
- ****募捐方式****
  捐款是如何募集的
- ****捐赠律师****
  协助这笔捐款的律师
- ****捐赠状态****
  捐赠交易情况
- ****捐赠类型****捐赠类型（捐赠、质押、质押支付、配捐）
- ****捐赠者姓名****
  通常用于表明捐赠者希望如何公开承认（如果有）
- ****捐助者说明****
  捐赠时选民填写的备注（如有）
- ****基金****捐款应归属哪个基金（如果有）
- ****荣誉/记忆全名****
  本次捐赠获奖者（如有）
- ****质押金额****
  捐助者认捐金额
- ****承诺状态****
  捐助者认捐情况
- ****交易ID****
  交易ID

### 已注册活动

当支持者在 NeonCRM 中注册活动时，系统会跟踪此活动。 Klaviyo 跟踪的事件包括 NeonCRM 收集的所有信息，您可以根据以下条件过滤和定位这些事件：

- ****活动代码****
  活动代码
- ****活动结束日期****
  活动结束日期（如果有）
- ****活动目标****
  活动目标（如果有）
- ****活动名称****
  活动名称
- ****活动开始日期****
  活动开始日期（如果有）
- ****活动入场费****活动入场费
- ****活动类别名称****
  活动类别名称
- ****活动代码****
  事件代码
- ****活动结束日期****
  活动结束日期
- ****事件 ID****
  事件ID
- ****活动名称****
  活动名称
- ****活动开始日期****
  活动开始日期
- ****基金****活动费用应归入哪个基金（如果有）

Klaviyo 目前不会收到每个注册事件的“注册时间”时间戳。事件显示的时间戳是其同步到 Klaviyo 时的时间戳。 ### 客户数据

除了 Klaviyo 从 NeonCRM 同步的 2 个关键事件指标之外，Klaviyo 还同步您在 NeonCRM 中拥有的每个联系人/帐户的信息，包括个人帐户和组织帐户。从 NeonCRM 自动同步的默认帐户属性为：

- 帐户创建日期/时间
- 账户类型
- 地址行 1
- 地址行 2
- 城市
- 公司名称
- 国家
- 已故
- 请勿联系
- 电子邮件 1
- 电子邮件选择退出
- 名字
- 完整邮政编码
- 个人型
- 职位名称
- 姓氏
- 组织类型
- 电话1
- 来源
- 省份
- 状态

Klaviyo 还同步 NeonCRM 中联系人周围的所有自定义字段；这些自定义字段将显示为附加到联系人的 Klaviyo 个人资料的自定义属性。 ![Klaviyo 中的个人资料信息显示关联的 NeonCRM 贡献、联系信息以及从 NeonCRM 同步的自定义属性，例如帐户类型和职位](https://klaviyo.zendesk.com/hc/article_attachments/28722556008347)
