## 你将会学到

了解哪些数据从 Shopware 6 同步到 Klaviyo、如何查看此数据以及 Shopware 事件包含哪些属性。 ## 开始之前

在继续阅读本文之前，请阅读我们关于[Shopware 入门](https://help.klaviyo.com/hc/en-us/articles/13001662470939) 的文章，了解有关如何集成商店的分步说明。 ## 如何查看您的数据

要查看从 Shopware 同步到 Klaviyo 的数据：

1. 在您的 Klaviyo 帐户中，单击左侧导航栏中的****分析****。 2. 选择****指标****。 3. 按****API**** 过滤指标列表。由于 Shopware 集成不是由 Klaviyo 直接构建的，因此事件将与 API 标签同步并具有齿轮图标。按 API 过滤还将显示您通过 API 同步的任何自定义指标。 4. 单击单个指标（例如**已下订单**）以查看一段时间内的活动图表。您还可以通过选择顶部的各个指标的选项卡来查看活动源、群组、最佳人员和活动地图。 5. 单击****活动源****，然后单击单个事件的时间戳。在这里，您可以查看与该事件关联的属性。 ## 从 Shopware 同步的数据

如果您在集成设置中配置了以下类型的数据，则会从 Shopware 同步到 Klaviyo：

- 电子邮件订阅者（通过 Shopware 或 Klaviyo 表单订阅）
- 产品目录（如果您设置了自定义目录提要同步）
- 现场活动

- 现场活跃
- 查看过的产品/最近查看过的商品
- 开始结账

- 交易事件

- 添加到购物车
- 已下订单
- 订购的产品
- 已履行的订单
- 取消订单
- 已退款的订单
- 已付款订单
- 订阅返回库存

## 电子邮件订阅如何同步

如果您在 Shopware 扩展设置中选择了 Klaviyo 列表，则通过 Shopware 表单注册的电子邮件订阅者将同步为 Klaviyo 中的订阅者。 ![Klaviyo 列表名称用于订户同步设置与框中的新闻通讯](https://klaviyo.zendesk.com/hc/article_attachments/28716066677531)

如果订阅者在 Klaviyo 中取消订阅，他们也会在 Shopware 中取消订阅。在您的 Shopware 时事通讯列表中，那些在 Klaviyo 中取消订阅的用户将被标记为“等待删除”状态。如果有人取消订阅您从 Shopware 发送的电子邮件，他们将不会在 Klaviyo 中取消订阅。 ## 同步事件及其顶级属性

### 现场活跃

当 cookied 用户在您的网站上处于活动状态时，Klaviyo 会跟踪此默认事件。此事件不包含用于分段的其他属性。 ### 查看的产品

当 cookied 用户查看您网站上的产品页面时，将跟踪 **查看的产品** 事件。最近查看的项目将添加到他们的个人资料中。该事件包含以下顶级属性：

- 产品名称
- 产品ID
- SKU
- 类别（数组）
- 图片网址
- 网址
- 品牌
- 价格
- 比较价格

### 添加到购物车

每当登录用户将商品添加到购物车时，就会跟踪此事件。在此事件中，**Items** 数组将列出创建此事件时购物车中当前的所有其他商品。此事件中的 **CheckoutURL** 可用于重建当前购物车。 **添加到购物车** 事件包含以下顶级属性：

- 添加了项目产品名称
- 添加了ItemProductID
- 添加了项目SKU
- 添加了项目类别
- 添加了ItemImageURL
- 添加了项目URL
- 添加了商品价格
- 添加了物品数量
- 物品名称
- 结账网址
- 物品
- 价值$

### 开始结帐

此事件跟踪 cookie 用户在第一个结帐页面上输入电子邮件后何时被带到第二个结帐页面。 **Started Checkout** 事件包含以下顶级属性：

- 结账网址
- 项目名称（数组）
- 类别
- 项目（数组）
- 价值”：19.99

### 已下订单

**已下订单** 在下订单时进行跟踪，并包含一个 **Items** 数组，其中包含订单中的所有商品。 **已下订单** 与 **已订购产品** 的不同之处在于，**已订购产品** 事件针对订单中的每件商品进行跟踪，而 **已下订单** 则针对整个订单进行一次跟踪，并包含送货地址等信息。 **已下订单** 事件包含以下顶级属性：

- 订单编号
- 类别
- 物品名称
- 品牌
- 折扣码
- 折扣值
- 物品
- 帐单地址
- 送货地址
- 价值$

### 订购的产品

**订购的产品** 事件针对订单中的每个商品进行跟踪，包含以下顶级属性：

- 产品名称
- 订单编号
- 产品ID
- SKU
- 数量
- 产品网址
- 图片网址
- 类别
- 产品品牌
- 价值$

### 已履行订单

**已完成订单** 事件包含以下顶级属性：

- 订单ID
- 类别
- 物品名称
- 品牌
- 折扣码
- 折扣值
- 物品
- 帐单地址
- 送货地址

### 取消订单

**取消订单**事件包含以下顶级属性：

- 订单ID
- 类别
- 物品名称
- 品牌
- 折扣码
- 折扣值
- 物品
- 帐单地址
- 送货地址
- 原因
- 价值$

### 订单退款

**退款订单**事件包含以下顶级属性：

- 订单ID
- 类别
- 物品名称
- 品牌
- 折扣码
- 折扣值
- 物品
- 帐单地址
- 送货地址
- 原因
- 价值$

### 已付款订单

当订单在 Shopware 中设置为 **付费** 时，会触发 **付费订单** 事件。它包含以下顶级属性：

- 订单ID
- 类别
- 物品名称
- 品牌
- 折扣码
- 折扣值
- 物品
- 帐单地址
- 送货地址
- 原因
- 价值$
