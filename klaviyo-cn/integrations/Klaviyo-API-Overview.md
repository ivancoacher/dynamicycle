## 概述

Klaviyo 的 API 旨在帮助用户和开发人员与 Klaviyo 集成。

这些指南旨在帮助您充分利用 Klaviyo API 的开发经验：

- ****JavaScript API****JavaScript API 用于轻松跟踪您网站上的人员。从开始到结束，读完整个指南大约需要 5 到 10 分钟。
- ****服务器端 API ****服务器端 API 由识别 API 和跟踪 API 组成。 这些 API 用于跟踪人员以及他们在您的网站内外所做的事件/操作。 它们针对低延迟和大量请求进行了优化，因此它们不遵守我们其他 API 使用的相同 REST 原则。
- ****Metrics API****Metrics API 用于检索 Klaviyo 中的历史事件数据。
- ****个人资料 API****个人资料 API 用于管理 Klaviyo 中的人员记录。
- ****列表 API ****列表和列表管理 API 用于在 Klaviyo 中创建和管理列表。
- ****营销活动 API**** 营销活动 API 用于在 Klaviyo 中创建和发送营销活动。
- ****模板 API ****模板 API 用于与 Klaviyo 中存储的电子邮件模板进行交互。
