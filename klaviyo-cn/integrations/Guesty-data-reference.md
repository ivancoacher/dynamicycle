了解哪些数据从 Guesty 同步到 Klaviyo 以及在哪里查看这些数据。这包括预订、客人和消息信息。如果您还没有阅读我们的 [Guesty 入门](https://help.klaviyo.com/hc/en-us/articles/37673288455323) 指南，了解有关集成的分步说明，然后再继续阅读本文。 ## 同步频率

当您与 Guesty 集成时，Klaviyo 将同步所有历史预订和客人数据。未来，预订、消息和宾客数据将实时同步。 ## 如何查看您的 Guesty 数据

要查看您的 Guesty 数据：

1. 导航至****分析 > 指标****。 2. 在这里，您可以查看帐户中的所有指标。带有 Guesty 图标的指标代表从 Guesty 集成同步的所有指标。 3. 使用 **所有集成** 下拉列表并选择 **Guesty** 以仅查看 Guesty 指标。 ![](https://klaviyo.zendesk.com/hc/article_attachments/38042545410971)

## 预订指标

以下预订指标从 Guesty 同步：

- ****确认预订****
  当客人的预订在 Guesty 中得到确认时。 - ****取消预订****
  当工作人员或客人取消已确认的预订时。 - ****预订已结束****
  当工作人员手动将**查询**或**已预订**的状态更改为**已关闭**以拒绝预订时。 - ****拒绝预订****
  当客人拒绝处于**已预订**状态的预订时。 - ****过期预订****当批准**保留**预订的时间结束时。 - ****保留预订****当客人要求预订酒店时。要进行预订**已确认**，必须由工作人员确认。 - ****询问预订****当客人提出一般性问题但尚未提交正式预订请求时。 - ****等待付款****当工作人员已确认预订但客人的付款尚未处理时

  对于每个指标，以下顶级属性都会同步到 Klaviyo：
- ****回头客****
  客人过去是否曾进行过预订（正确/错误）。 - ****客人数量****预订的客人总数。 - ****成人人数****预订的成人总数。 - ****儿童人数****预订的儿童总数。 - ****婴儿人数****预订的婴儿总数。 - ****预订 ID ****来自 Guesty 的预订 ID。 - ****查询 ID ****来自 Guesty 的 **查询预订** 活动的查询 ID。 - ****确认码****供客人参考的唯一 ID，以确认预订已完成。 - ****预订状态****预订的状态。 - ****入住日期****预订入住日期采用 UTC 格式（即 YYYY-MM-DD）。 - ****入住日期和时间****预订入住日期和时间采用 UTC 格式（即 YYYY-MM-DDThh:mmTZD）。 - ****退房日期****预订退房日期，采用 UTC 格式（即 YYYY-MM-DD）。 - ****退房日期和时间****预订退房日期和时间，采用 UTC 格式（即 YYYY-MM-DDThh:mmTZD）。 - ****晚数**** 预订的总晚数。 - ****预订来源****预订的来源（例如 Airbnb、VRBO、手册等）
- ****住宿费用****预订的基本价格，根据列表的基本价格计算。等于预订日期每晚房价的总和。 - ****住宿票价折扣****适用于**住宿票价**的折扣金额（如有）。 - ****货币****用于预订的货币类型。 - ****清洁费****清洁费用总额。 - ****总费用****费用总额。 - ****总税金****税金总额。 - ****房东付款****房东在预订时支付的总金额。 - ****小计价格****小计价格。 - ****应付余额****客人应付的金额。 - ****应付付款****客人应付的付款金额。 - ****是否已全额付款****预订是否已全额付款。 - ****已付总额****客人已支付的总金额。 - ****退款总额****退还给客人的总金额。 - ****房源 ID **** 预订时酒店的 ID。 - ****挂牌地址****预订时酒店的地址。 - ****房源缩略图****预订时酒店的缩略图 URL。 - ****房源公开描述摘要****预订中的房产的公开描述。 - ****列出设施****预订时酒店提供的设施。 - ****房源昵称****预订时酒店的内部昵称。 - ****房源名称****预订中房产的公开房源名称。 - ****列出默认入住时间****
  列表的默认签入时间。 - ****列表默认退房时间****
  列表的默认退房时间。 - ****列出时区****
  列表的时区。 - ****帐户 ID ****客人的宾客帐户 ID。 ## 消息指标

Klaviyo 同步两个反映 Guesty 中消息的指标：

- ****消息已发送****
  消息已发送给客人。 - ****收到消息****收到来自客人的消息。 ### 消息已发送

同步到 Klaviyo 的每个 **已发送消息** 指标都具有以下属性：

- 预订ID
- 确认码
- 入住日期
- 退房日期
- 客人姓名
- 宾客 ID
- 访客最后更新的消息
- 留言平台
- 消息优先级
- 创建于
- 最后修改

### 已收到消息

同步到 Klaviyo 的每个 **已接收消息** 指标都具有以下属性：

- 预订ID
- 确认码
- 入住日期
- 退房日期
- 客人姓名
- 消息语言
- 消息已读
- 留言主题
- 消息优先级
- 消息延后至
- 宾客 ID
- 消息对话

## 预订对象

对于每个预留对象，以下顶级属性会同步到 Klaviyo：

- ****价值****预订的价值，来自“money.hostPayout”。 - ****客人计数****预订的客人总数。 - ****成人人数****预订的成人总数。 - ****NumberOfChildren**** 预订中的儿童总数。 - ****NumberOfInfants****预订的婴儿总数。 - ****ReservationID****来自 Guesty 的预订 ID。用作对象 ID。 - ****确认代码****供客人参考的唯一 ID，用于确认预订已完成。 - ****预订状态****预订的状态。 - ****入住日期****预订入住日期。 - ****退房日期****预订退房日期。 - ****CheckInDateAndTime**** UTC 格式的预订入住日期和时间（即 YYYY-MM-DDThh:mmTZD）。 - ****CheckOutDateAndTime**** UTC 格式的预订退房日期和时间（即 YYYY-MM-DDThh:mmTZD）。 - ****晚数**** 预订的总晚数。 - ****BookingSource****预订的来源（例如 Airbnb、VRBO、手册等）
- ****货币****用于预订的货币类型。 - ****清洁费****清洁费用总额。 - ****总费用****费用总额。 - ****总税金****税金总额。 - ****HostPayout**** 房东在预订时支付的总金额。 - ****小计价格****小计价格。 - ****应付余额**** 客人应付的金额。 - ****应付付款****客人应付的付款金额。 - ****是否已全额付款****预订是否已全额付款。 - ****TotalPaid****客人已支付的总金额。 - ****退款总额****退还给客人的总金额。 - ****ListingID**** 预订时酒店的 ID。 - ****房源地址****预订时酒店的地址。 - ****ListingThumbnail****预订时酒店的缩略图 URL。 - ****列出设施****预订时酒店提供的设施。 - ****ListingNickname**** 预订时酒店的内部昵称。 - ****ListingTitle**** 预订中房产的公开列表名称。 - ****挂牌房间类型****
  列表中的房间类型。 - ****ListingPropertyType**** 列表的属性类型。 ## 访客数据

Klaviyo 从 Guesty 同步访客数据。请注意，我们不会同步与在线旅行社 (OTA) 关联的任何个人资料。 我们将以下访客数据同步到 Klaviyo 个人资料：

- 电子邮件
- 电话号码
- 名字
- 姓氏
- 街道
- 城市
- 状态
- 国家
- 宾客 ID
- 宾客标签
- 宾客兴趣
- 客人过敏
- 宾客饮食偏好
- 宾客沟通方式
- 客座笔记
- 宾客附加说明
- 宾客首选语言
- 宾至如归的故乡
- 客座性别
- 宾客婚姻状况
- 客座代词
- 客座儿童人数
- 嘉宾国籍
- 客人回访
- 客座生日
- 电子邮件同意

请注意，短信同意不会从 Guesty 同步。
