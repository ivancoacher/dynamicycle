Klaviyo 的 Magento 1 集成不再接受新安装，并将于 2027 年末完全终止支持。Klaviyo 支持不再能够协助处理 Magento 1 相关请求。 ## 你将会学到

了解当您集成两个平台时，Magento 1 的哪些数据会导入到 Klaviyo 中。 Klaviyo 与 Magento 的集成会在首次历史同步时提取 Magento 商店中的所有历史数据。启用后，集成将开始近乎实时地同步指标和客户数据。此数据的示例包括与过去下的订单、已履行的订单等相关的信息。在 Klaviyo 中，您可以导航到左侧边栏中帐户的****分析****选项卡，以查看帐户中的所有指标；带有 Magento 图标的指标是从 Magento 集成同步的指标。 ![Klaviyo 中提供的 Magento 1 指标](https://klaviyo.zendesk.com/hc/article_attachments/28715969069339)

Klaviyo 将您可以创建的唯一指标的数量限制为 200 个。当您接近此阈值时，您将通过帐户中的警告以及发送给帐户所有者的电子邮件收到提醒。 ## Magento 指标

### 取消订单

当客户在您的 Magento 商店中创建订单但在履行之前取消订单时，系统会跟踪此事件。 Klaviyo 跟踪相关数据，包括有关某人购买的商品的所有产品信息。产品信息包括产品名称、图像和型号信息，您可以在购买后续电子邮件中使用这些信息。您可以根据以下条件过滤和定位取消订单事件：

- ****价值****：订单总价值（小计 + 运费 - 任何折扣）。 - ****商品****：某人订单中的产品名称。例如：**T 恤**或**裤子**。如果多次订购，将显示同一商品的多个
- ****物品类别****：某人订单中物品的完整类别集； （例如，**T 恤、男装、裤子**和促销）。 - ****商品数量****：订单中的商品数量（例如 **2）。**
- ****货币代码****：根据国家/地区为商品支付的特定货币（例如，**美元、欧元**）**。**
- ****折扣****：如果该特定商品有折扣（即，真/假）。 - ****优惠券****：应用的优惠券代码。 - ****独特商品****：订单中包含的单个商品（例如，**衬衫、短裤**）**。**如果订购了多个产品，则该独特商品将仅显示一次。 - ****独特商品类别****：独特商品的分组类别（例如，**男士、**促销）。 - ****属性（可选）****：自定义产品属性。 ### 结帐完成

当客户在您的 Magento 商店中完成结账时，系统会跟踪此事件。结账完成事件在历史上并不同步，因此在查看一段时间内的事件总数时并不总是准确的衡量标准。要跟踪收入和细分，请使用已下订单事件。您可以根据以下条件过滤和定位“结账已完成”事件：

- ****价值：****订单的总价值。 - ****折扣代码****：应用的任何优惠券或折扣代码。 - ****商品****：某人购物车中的产品名称（例如，**T 恤**或 **裤子**）。 - ****物品计数****：某人购物车中的物品总数。 - ****总折扣（可选）****：任何优惠券或折扣的总美元价值。 ### 结账开始

当客户在 Magento 结账流程的第一页上输入联系信息和送货信息，然后单击 **继续** 时，就会跟踪此事件。 Klaviyo 跟踪某人购物车中商品的相关产品数据，包括您可以在废弃购物车电子邮件中使用的产品名称、图像和变体信息。此事件有一个结账 URL 属性，该属性链接回每个客户的确切购物车，并且如果客户从新设备打开电子邮件，则可以使用该属性重建购物车。您可以根据以下条件过滤和定位“结账已开始”事件：

- ****价值****：结账时购物车的价值（小计 + 运费 - 任何折扣）。 - ****商品****：某人购物车中的产品名称（例如，**T 恤**或 **裤子**）。 - ****物品计数****：某人购物车中的物品总数。 - ****折扣代码（可选）****：应用的任何优惠券或折扣代码。 - ****总折扣（可选）****：任何优惠券或折扣的总美元价值。 ### 已履行订单

当您在 Magento 商店中将订单标记为已发货时，系统会跟踪此事件。 Klaviyo 跟踪某人购买的商品的相关产品信息，包括产品名称、图像和可在购买后续电子邮件中使用的变体信息。您可以根据以下条件过滤和定位已配送订单事件：

- ****价值****：订单总价值（小计 + 运费 - 任何折扣）。 - ****商品****：某人订单中的产品名称（例如，**T 恤**或 **裤子**）。如果多次订购，则会出现同一商品的多个。 - ****商品类别****：某人订单中商品的完整类别集（例如，**T 恤、男装、裤子**和促销）。 - ****商品数量****：订单中的商品数量。 （例如，**2**）。 - ****货币代码****：根据国家/地区为商品支付的特定货币（例如，**美元、欧元**）**。**
- ****折扣****：如果该特定商品有折扣（即，真/假）。 - ****优惠券****：应用的优惠券代码。 - ****独特商品****：订单中创建的单个商品（例如，**衬衫、**短裤）。如果订购了多个产品，则该独特商品只会显示一次。 - ****独特商品类别****：独特商品的分组类别（例如，**男士、**促销）。 - ****属性（可选）****：自定义产品属性。 ### 订购的产品

当客户下订单时，系统会跟踪此事件。对于某人购买的每件商品，都会跟踪一个订购产品事件。例如，如果有人购买一件 T 恤和一条裤子，则会跟踪一个已下订单事件并记录两个已订购产品事件 - 一个为 T 恤事件，一个为裤子事件。订购的产品事件包括有关某人购买的每个产品的详细信息。当根据产品变体选项和已下订单事件中不可用的其他详细信息创建行为细分时，这非常有用。您可以根据以下条件过滤和定位订购产品事件：

- ****价值****：商品的总价（不包括运费或任何折扣）。 - ****名称****：为此特定项目指定的名称。 - ****SKU****：分配用于跟踪商品的特定 SKU（例如，**REDMEDIUMTSHIRT**）**。**
- ****类别****：某人订单中的完整产品系列（例如，**T 恤、男装、裤子**和促销）。 - ****价格****：特定产品的美元价值（例如，**衬衫 25.50，鞋子 50.25**）**.**
- ****成本****：制造产品的成本（例如，**衬衫 13.85，鞋子 20.00**）**.**
- ****货币代码****：根据国家/地区为商品支付的特定货币（例如，**美元、欧元**）**。**
- ****折扣****：如果该特定商品有折扣（即，真或假）。 - ****ProductID****：您商店中特定产品的 ID。 - ****数量：****订购数量。 - ****属性（可选）****：自定义产品属性。 ### 已下订单

当客户完成结账流程并在您的 Magento 商店中创建订单时，系统会跟踪此事件。 Klaviyo 跟踪相关数据，包括有关某人购买的商品的产品信息，包括产品名称、图像以及您可以在购买后续电子邮件中使用的变体信息。您可以根据以下条件过滤和定位****已下订单****事件：

- ****价值****：订单总价值（小计 + 运费 - 任何折扣）。 - ****商品****：某人订单中的产品名称，例如：**T 恤**或**裤子**。如果多次订购，将显示同一商品的多个。 - ****商品类别****：某人订单中商品的完整类别集（例如，**T 恤、男装、裤子**和**促销**）**。**
- ****商品数量****：订单中的商品数量（例如 **2**）**.**
- ****货币代码****：根据国家/地区为商品支付的特定货币（例如，**美元、**欧元）。 - ****折扣****：如果该特定商品有折扣（即，真/假）。 - ****优惠券****：应用的优惠券代码。 - ****独特商品****：订单中创建的单个商品（例如，**衬衫、短裤**）**。** 如果订购了多个产品，则该独特商品只会显示一次。 - ****独特商品类别****：独特商品的类别分组（例如，**男士、促销**）**。**
- ****属性（可选）****：最多可以为已下订单同步 10 个自定义产品属性 在自定义属性数据流入您的 Klaviyo 帐户之前，需要启用此同步。 [请参阅下面有关如何设置的部分](#h_935cad58-8ae4-4df6-9b3f-c9f7ce12d53e)。 ### 订单退款

当 Magento 中的订单退款时，会跟踪此事件。 - ****价值****：订单总价值（小计 + 运费 - 任何折扣）。 - ****优惠券****：应用的优惠券代码。 - ****货币代码****：根据国家/地区为商品支付的特定货币（例如，**美元、**欧元）。 - ****折扣****：如果该特定商品有折扣（即，真/假）。 - ****商品类别****：某人订单中商品的完整类别集（例如，**T 恤、男装、裤子**和**促销**）**。**
- ****商品数量****：订单中的商品数量（例如 **2**）**.**
- ****商品****：某人订单中的产品名称（例如，**T 恤**或 **裤子**）。如果多次订购，将显示同一商品的多个。 - ****独特商品类别****：独特商品类别分组（例如，**男士、促销**）**。**
- ****独特商品****：订单中创建的单个商品，例如：**衬衫、短裤。**如果订购了多个产品，则该独特商品只会显示一次。收入或**已下订单**值的计算方式如下：（订单价格 + 运费 - 折扣）。要根据 $value 过滤分段，请使用 ****Revenue**** 过滤分段。 ****付款****可作为****额外****字段下的二级属性使用。您无法过滤掉二级属性进行分段，但可以在电子邮件模板中[将此数据用作事件变量](https://help.klaviyo.com/hc/en-us/articles/115005084927-Template-Tags-and-Variable-Syntax#event-variables-)。 ## 同步的客户数据

Klaviyo 在创建现有订单、现有客户记录或开始结帐时创建联系人。 Klaviyo 将为每个同步的联系人创建一个新的 Klaviyo 配置文件，并将使用以下信息填充此配置文件：

- 电子邮件
- 名字和姓氏
- 城市、州/地区、邮政编码、国家
- 电话号码
- Magento 帐户已创建（例如，2015-05-01 00:00:00）
- Magento 客户群（例如批发）
- Magento 商店（例如美国商店）
- 出生日期（例如，1990-01-01）
- 性别
- 网站\_ID不会被拉取
- 抑制不会复制到 Klaviyo 中，因此它们不会出现在 Klaviyo 平台中

如果您在 Magento 中更新客户组，即使在 Klaviyo 中创建原始配置文件后，客户组也会在 Klaviyo 中更新。 - 网站\_ID不会被拉取。抑制不会复制到 Klaviyo 中，因此它们不会出现在 Klaviyo 平台中。 - 自定义图像位置不会被拉取。 Klaviyo 无法提取自定义图像位置。 ## 同步已下订单的自定义产品属性

Klaviyo 可以为已下订单指标同步最多 10 个自定义产品属性。自定义产品属性不会自动流入Klaviyo；但是，您可以请求 Klaviyo 将它们拉入。为此，您应该收集自定义属性 ID（说明如下）并向[我们的支持团队](https://klaviyo.zendesk.com/hc/en-us/articles/115001002272) 发送请求。通过转到****目录 > 属性 > 管理属性**** 并单击属性，可以在 Magento 的管理面板中找到自定义产品 ID。 ID 可以在 url 中找到，如下所示：

## 验证您同步的订单数据

Klaviyo 导入您的所有 Magento 数据。要验证这一点，您可以将特定日期的订单数量与 Magento 界面中的订单数量进行比较，并确认它们匹配。单击左侧边栏中的 **Analytics**，找到“已下订单”指标并单击它。这将带您进入指标图表页面，并默认显示最近 30 天的数据。您可以看到下面显示的指标图表示例。将鼠标悬停在昨天的数据点上或查看图表下方的数据表，了解您昨天有多少订单。将该数字与 Magento 中存储的数字进行比较，您应该会看到它们完全匹配。如果没有，最可能的问题是您的 Klaviyo 帐户的时区与您的 Magento 时区不匹配。 要检查您的时区设置：

1. 单击左下角的组织名称。 2. 单击****设置****。 3. 选择****组织******。**

![Magento 1 下订单指标随时间变化的图表](https://klaviyo.zendesk.com/hc/article_attachments/28715962468891)

您可能会发现 Klaviyo 仪表板上的 **收入** 值并不总是与您在 Magento 中看到的收入值匹配；这是因为 Klaviyo 不会从我们的收入计算中减去取消和退款的订单。 ## 同步的 magento 订单的属性

以下是“已下订单”、“已订购产品”和“已完成订单”指标的示例 JSON 负载，这些负载与我们为通过 Magento SOAP API 同步的订单存储的属性相匹配。这对于发送将与 Magento 订单数据合并的订单的正确属性非常有用。 ### 已下订单

````
//
// 已下订单
// ------------------------------------------

{
  “令牌”：“PUBLIC_API_KEY”，
  “服务”：“magento”，
  "event" : "已下订单",
  “客户属性”：{
    "$email" : "john.smith@test.com",
    "$first_name" : "约翰",
    "$last_name" : "史密斯"
  },
  “属性”：{
    “$event_id”：“1234”，
    “价值”：29.98，
    “$额外”：{}，
    “货币代码”：“美元”，
    “项目数”：2，
    "Items" : ["Winnie the Pooh", "A Tale of Two Cities"], // 如果某个项目被订购多次，则重复它。例如，某人订购了两件 T 恤，这将是：[“T 恤”、“T 恤”]
    “折扣”：真实，
    “优惠券”：“COUPON123”，
    “独特物品”：[“小熊维尼”、“两个城市的故事”]、
    “项目类别”：[“小说”、“经典”、“儿童”]，
    “独特项目类别”：[“小说”、“经典”、“儿童”]
  },
  “时间”：1387302423
}
````

### 订购的产品

````

// 订购的产品

    "$event_id" : "123456789", // LineId（唯一）

    “货币代码”：“美元”，
    “名称”：“小熊维尼”，
    “SKU”：“温尼波”，
    “产品ID”：“567”，
    "类别" : ["小说", "经典"],
    「价格」：9.99，
    “折扣”：真实，
    “成本”：5.00，//（可选），
````
