## 你将会学到

了解如何访问浏览器的开发人员控制台，这是大多数现代 Web 浏览器的标准工具，用于记录页面错误和警告。开发者控制台有助于调试技术问题。

Klaviyo 支持团队可能会要求您在浏览器的开发者控制台中找到其他信息，以帮助进行故障排除。如果开发人员控制台要求您提供屏幕截图或日志，请按照以下步骤在您选择的浏览器中访问此信息。

## 在 Chrome 中打开

![](https://fast.wistia.com/embed/medias/t3qbca2ics/swatch)

您可以从 Chrome 菜单栏访问 Chrome 开发者控制台：

1. 打开 Chrome 窗口。
2. 从 Chrome 菜单栏中，打开****查看****菜单。
3. 选择****开发人员 > JavaScript 控制台**** 打开开发人员控制台。
   ![访问 Chrome 开发者控制台](https://klaviyo.zendesk.com/hc/article_attachments/28722595908635)

您还可以通过打开开发人员工具的“检查元素”选项卡导航到 JavaScript 控制台：

1. 打开 Chrome 窗口并导航至任意网页。
2. 在浏览器窗口中右键单击网页。
3. 选择****检查****。
4. 导航至****控制台****选项卡。

或者，使用键盘快捷键 ****Option + Command + J**** (Mac) 或 ****Control + Shift + J**** (PC) 直接打开控制台。

成功打开“控制台”选项卡后，刷新页面或执行导致技术问题的操作，并在控制台窗口中截取结果的完整屏幕截图。

## 在 Safari 中打开

在访问 Safari 中的开发者控制台之前，您首先需要在浏览器的首选项中启用开发者菜单。

1. 从 Safari 菜单栏中，单击 ****Safari**** > ****首选项****。
2. 选择****高级****选项卡。
3. 在“高级”选项卡中，单击****在菜单栏中显示“开发”菜单****，以便轻松访问开发人员控制台。

启用该菜单后，您可以从菜单栏访问开发人员控制台：

1. 打开 Safari 窗口。
2. 从菜单栏中，单击****开发 > 显示 JavaScript 控制台****。
   ![访问 Safari 开发者控制台](https://klaviyo.zendesk.com/hc/article_attachments/28722595905947)

或者，使用键盘快捷键****Option + Command + C****直接快速打开控制台。

成功打开“控制台”选项卡后，刷新页面或执行导致技术问题的操作，并在控制台窗口中截取结果的完整屏幕截图。

## 在火狐中打开

1. 打开 Firefox 浏览器窗口。
2. 单击右上角的菜单按钮。
3. 选择****更多工具****。
4. 从可用选项中，单击****Web 开发人员工具****。
   ![访问 Firefox 开发者控制台](https://klaviyo.zendesk.com/hc/article_attachments/28722595903899)

在 Firefox 中打开 Web 控制台的键盘快捷键是 ****Option + Command + K**** (Mac) 或 ****Command + Shift + J**** (PC)。

成功打开 Web 控制台后，刷新页面或执行导致技术问题的操作，并在控制台窗口中截取结果的完整屏幕截图。

在 Firefox 中访问此信息时，您必须使用 Web 控制台，而不是浏览器控制台。浏览器控制台会记录浏览器窗口中所有选项卡的警告和错误，并且此控制台的屏幕截图可能包含与您遇到的技术问题无关的信息。

## 在其他浏览器中访问开发者控制台

许多浏览器提供有关如何使用自己的开发人员工具的指南。如果您使用的浏览器未包含在上述说明中，我们建议您搜索您首选浏览器的文档以获取更具体的说明。
