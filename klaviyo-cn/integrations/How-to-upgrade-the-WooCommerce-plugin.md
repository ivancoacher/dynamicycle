## 你将会学到

了解如何将现有 WooCommerce 集成的 Klaviyo WooCommerce 插件更新到最新版本。如果您需要首次启用 WooCommerce 集成，请访问 [WooCommerce 入门](https://klaviyo.zendesk.com/hc/en-us/articles/115005255808)。

您使用的 WooCommerce 插件版本是否低于 3.3.0？我们建议立即升级到版本 3.3.0 或更高版本。该插件的旧版本使用 Klaviyo 的 v1 和 v2 API，这些 API 已停用并且不再按预期运行。

## 开始之前

- 您无需删除现有的集成即可升级到最新的插件版本。
- WooCommerce 集成将数据实时同步到 Klaviyo。

## 更新 WooCommerce 中的 Klaviyo 插件

最新的 Klaviyo 插件可以直接从 WooCommerce 安装和更新：

1. 在 WooCommerce 中，单击****插件****选项卡。
2. 向下滚动找到 **Klaviyo** 插件。
3. 如果出现显示可用更新的横幅，请单击****立即更新****。
4. 如果您愿意，可以单击****启用自动更新****。

更新插件版本时，您可能希望查看修改了哪些功能。要了解每个版本中所做的更改，请前往[我们的变更日志](https://wordpress.org/plugins/klaviyo/#developers)。
