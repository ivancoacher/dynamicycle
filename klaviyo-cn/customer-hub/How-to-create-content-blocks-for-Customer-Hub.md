## 你将会学到

了解如何为您的客户中心创建内容块。内容块是高度可定制和个性化的块，可以访问 Klaviyo 配置文件数据，使您可以显示集成（例如忠诚度积分余额）、个性化优惠等。 Shopify 客户中心目前支持标准店面和 Shopify Headless。对于 WooCommerce，请导航至 https://help.klaviyo.com/hc/en-us/articles/47792369863451

有关客户中心功能的反馈，请发送电子邮件至 customerhub@klaviyo.com。 ## 开始之前

本指南介绍了如何设置内容块，以便它们显示在您网站的客户中心上。继续之前，请确保您已[在 Klaviyo 中启用客户中心功能](https://klaviyo.com/try-service)。 [了解有关客户中心的更多信息](https://help.klaviyo.com/hc/en-us/articles/33660324811675)。 ## 您可以使用内容块做什么

内容块可帮助您自定义客户中心界面的**为您**选项卡。您可以使用它们来显示特定于客户的信息或鼓励访问者采取特定操作，以便每个人在与您的现场客户中心互动时都能享受量身定制的体验。您可以创建自己的自定义内容块或使用 Klaviyo 内容块库中的模板，其中包括针对常见场景的预配置块以及来自各种集成的客户数据（例如忠诚度积分或订阅状态）。 ### 内容块的常见用例

- 鼓励行动
  - 提示访客与您联系（例如“给我们发电子邮件”）
  - 将购物者引导至特定 URL 或页面（例如订阅管理或推荐信息页面）
- 突出并引导客户旅程
  - 为登录购物者推广特别优惠或独家系列
  - 通过评论和图片展示评价较高的产品
- 显示 Klaviyo 个人资料中的个性化信息
  - 使用个性化标签动态显示 Klaviyo 个人资料中的客户特定详细信息。这可以是您通过 Klaviyo 收集、导入或从其他平台或集成同步的信息，例如：
    - 忠诚度积分
    - 订阅状态
    - 会员等级
- 高级个性化
  - 使用 if/else 条件逻辑根据客户资料数据控制内容块中显示的信息（例如，专门向奖励计划成员显示奖励信息并向其他所有人显示默认消息）。 ![客户中心抽屉式界面在示例品牌网站的右侧打开，并显示两个示例内容块。](https://klaviyo.zendesk.com/hc/article_attachments/34193321673883)

### 内容块事件

创建内容块时，必须为其指定名称。 Klaviyo 使用您提供的用于报告和过滤的名称，将每次网站访问者点击内容块作为**客户中心点击内容块**事件进行跟踪。因此，最好选择熟悉且与每个块中的内容相关的名称。请记住，名称仅供内部使用；您的客户看不到它们。创建块后您也无法更改其名称。 ## 创建一个新的内容块

需要遵循几个步骤来创建内容块并将其发布到您的客户中心界面。接下来的几节将介绍此设置。 ### 访问内容块

1. 导航至 Klaviyo 左侧导航栏中的****服务 - 客户中心****选项卡。 2. 单击 ****设计****。 3. 在右侧预览中，找到“+”按钮
   ![](https://klaviyo.zendesk.com/hc/article_attachments/40774144359707)
4. 点击“+”按钮选择如何添加内容块：
   - 使用内容块库中的预构建模板。 - 按类别（例如忠诚度、交易、列表增长）浏览库或按集成过滤。单击任何模板上的****添加块****，以在内容块编辑器中打开它，其中包含预填充但完全可编辑的字段

       特定于集成的内容块要求您已在 Klaviyo 中启用相应的集成。 - 构建您自己的内容块。 - 单击****构建您自己的****以在编辑器中打开空白设置菜单
       ![CHContent0.jpg](https://klaviyo.zendesk.com/hc/article_attachments/37969305318427)

### 配置您的内容块

选择起点（模板或从头开始）后，内容块将显示在预览中。您可以单击任何内容块来编辑其配置。 1. 在**内容**下，您可以编辑：
   - ****区块标题****
     - 撰写标题或号召性用语（例如，购买 Spring Collection）。 - ****块描述****
     - 使用常规静态文本添加详细信息或上下文，或插入个性化标签以提取动态的、客户特定的信息（例如可用奖励积分）。不支持事件数据。如果您使用特定于集成的模板，则会预先配置个性化标签以匹配平台的自定义属性名称。 - ****链接****（可选）
     - 提供 URL 以在访问者单击该块时引导他们（例如，访问产品页面）。您还可以选择链接是否应在新选项卡中打开。 - ****内部名称****
     - 创建一个可识别的名称（例如，“奖励”用于显示奖励积分的块）。 ****请注意，该名称用于报告，一旦保存就无法更改。****
   - ****横幅图片****（可选）
     - 上传图像以显示在此内容块的顶部。 2. 在**定位**下，选择哪些类型的访问者可以看到内容块：
   - ****登录状态****
     根据登录状态选择哪些类型的访问者可以看到内容块。 - ****注意：如果您选择向已识别/已识别的购物者显示自定义内容块，请确保该块不包含敏感个人信息 (PII)。**** 虽然 Klaviyo 会自动在**订单**和**个人资料**等本机选项卡中编辑 PII，但品牌应对添加到自定义内容块的数据的隐私负责。 - ****列表/分段成员资格****
     显示或隐藏某些列表或段的块：
     - ****显示到****：选择应该看到该块的列表/段。 - ****不显示****：选择不应看到该块的列表/段。 3. 完成后，点击 ****添加****。要预览内容块在客户中心中的外观，请切换到左侧的****设计****菜单。从这里，您可以在客户中心预览画布中查看您的内容，也可以选择任何内容块进行编辑。 ![contentblocknew.jpg](https://klaviyo.zendesk.com/hc/article_attachments/39337663805595)

## 安排内容块

您可以安排内容块在特定日期和时间上线、更新或删除，而无需立即手动发布或删除它们。这对于时间敏感的活动（例如限时抢购、假日促销或您想要精确控制内容何时出现在网站上的任何情况）非常有用。计划的更改适用于所有现场访客，包括尚未登录的未经身份验证的购物者。这意味着您可以使用计划的内容块作为漏斗顶部营销工具，而不仅仅是针对已识别的客户。 ### 安排一个新的内容块

创建内容块时，您可以选择立即发布或设置未来的上线日期和时间。 1. 按照上面的****创建新内容块****中的步骤操作。 2. 在单击“****添加****”之前，请在编辑器中查找“****计划****”选项。 3. 切换****安排稍后****并设置区块上线的日期和时间。 4. 单击 ****保存****。该区块将在预定时间之前保持非活动状态，然后自动发布。 ### 安排对现有内容块的更新

您可以对已发布内容块的更改进行排队 - 例如交换图像、更新描述或调整定位 - 以便在将来生效。 1. 在设计画布中单击要更新的内容块。 2. 对块的内容、图像、链接或定位设置进行所需的更改。 3. 选择****安排更新****而不是立即保存，然后选择应用更改的时间。 4. 点击 ****确认****。您当前的块将保持原样，直到计划的更新生效。 ### 安排删除内容块

您可以安排在特定日期和时间自动删除内容块 - 例如，促销结束时。 1. 单击要删除的内容块。 2. 选择****安排删除****并设置日期和时间。 3. 点击 ****确认****。该块将继续显示，直到预定的删除时间，然后自动从客户中心消失。 ### 预览计划的更改

在计划的更新上线之前，您可以逐步浏览内容块，以准确查看客户中心在给定时间点的外观。这对于质量检查、审查翻译或验证一系列更新看起来是否正确很有帮助。 1. 在****设计****视图中，找到画布上方的时间线或****已安排****指示器。 2. 使用预览控件及时向前移动，并查看每次计划的更改生效后内容块将如何显示。 3. 单击预览中的任何内容块以查看其当时的配置。注意：预览反映了每次计划更新后内容块的状态 - 它不是对所有可能时间的连续清理。 ### 管理、修改或取消计划的更新

您可以从“设计”视图查看和管理所有待定的计划更改。 1. 导航至****服务 > 客户中心 > 设计****。 2. 单击****已安排****选项卡或查找已安排的更改面板以查看内容块中所有即将进行的更新。 3. 从这里您可以：
   - ****编辑****预定的更新以更改其内容或时间。 - ****取消**** 计划的更新以完全放弃更改，而不影响当前的活动。 ![截图 2026-04-02 12.07.48PM.png](https://klaviyo.zendesk.com/hc/article_attachments/49379754900123)

### 客户将如何看到您的内容块

您的网站访问者看到的内容块以及这些块中显示的详细信息取决于他们是否已登录其帐户以及 Klaviyo 是否已识别出他们。请记住：

- Klaviyo 只能向已登录帐户或已被 Klaviyo 以其他方式（例如，点击电子邮件中的链接或填写注册表单）识别的访问者显示针对特定列表或细分的内容块。匿名、注销的访问者将看不到这些块。 - 带有个性化标签的内容块将仅显示登录访问者的个人资料数据。如果访问者注销，将显示默认值。如果没有默认值，则不会显示文本。如果您将内容块配置为仅向特定细分显示，并且[该细分变为非活动状态](https://help.klaviyo.com/hc/en-us/articles/360015118592)，则任何人都将无法再看到或访问该内容块。为了防止您的分段被停用，并确保继续访问您的内容块，请在 Klaviyo 的****分段****区域中单击分段名称旁边的星形图标。 ## 使用个性化标签来显示个人资料数据

内容块支持使用[个人资料和自定义个性化](https://klaviyo.zendesk.com/hc/en-us/articles/4408802648731) 从每个客户的 Klaviyo 个人资料中动态提取信息。内容块库具有多个特定于集成的模板，这些模板已使用针对该平台和特定用例的正确个性化标签进行设置。但是，如果您有不同的集成或用例，您可以在内容块的描述中添加或修改个性化标签以显示您需要的数据。请注意，客户中心中的内容块当前不支持事件数据。 ### 带有个性化标签的示例用例

在个性化标签中引用自定义配置文件属性时，请确保“查找”部分中的值与您在 Klaviyo 中存储该属性的方式匹配。自定义属性的格式或命名可能与提供的示例不同。 - 表面可用的忠诚度积分：
  您拥有`{{ person|lookup:'loyalty_points'|default:'0'|floatformat:0 }}` 积分
- 提醒购物者他们的会员级别（例如铜牌、银牌、金牌）：
  `{{ person|lookup:'会员级别'|default:'无会员资格' }}` 状态
- 通过个性化提示特定的购物旅程：
  庆祝您的‘{{ person|lookup:'breed_type'|default:'dog' }}`

提示：请记住，使用个性化标签时，可能有些访问者未提供标签引用的所有数据。为了解决这些情况，[使用默认文本来防止用空格代替缺失的数据](https://help.klaviyo.com/hc/en-us/articles/18986347580827#h_01HBRK2VCRPDGMYPAH5V2ZFX6W)。 ### 使用条件逻辑

对于更高级的自定义，您可以使用条件 if 语句来根据不同购物者的个人资料信息控制某个区块对他们的显示方式。 ### if/else 语句示例

- 帮助会员管理当前订阅，同时激励非会员启动订阅计划：
  `{% if person.subscription_status not “Cancelled” and person.subscription_status %}管理您的订阅 {% else %}开始订阅并保存！ {% endif %}`
- 吸引 VIP 忠诚会员，同时向非会员显示 CTA 加入：
  `{% if person|lookup:'忠诚度积分' > 150 %}嘿 VIP！您始终享受免费送货和免费退货服务 {% else %}您听说过我们的 VIP 计划吗？今天加入我们的网站即可开始赚取奖励。 {% endif %}`
